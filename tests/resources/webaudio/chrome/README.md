# Web Audio 참조 비교 자료 (Chromium)

`ChromeReferenceTest`(`tests/src/org/duckdns/hjow/swingwebpanel/js/host/webaudio/`)가 쓰는 자료이다. 이 프로젝트의 Web Audio 엔진을 실제 브라우저와 비교하기 위해,
같은 스크립트(`scenarios.js`)를 Chromium 에서 `OfflineAudioContext` 로 렌더링한 결과를 `ref/<시나리오>.json` 에 Float32 표본(채널마다 base64, 리틀 엔디언)으로 저장했다.
참조는 **다른 독립 구현의 출력**이며 합격 기준의 일부로만 쓴다(외부 엔진을 제품이나 시험의 실행 의존성으로 쓰지 않는다: 시험은 저장된 파일만 읽는다).

## 판본과 조건

- 브라우저: `ref/_meta.json` 에 `userAgent`(Chrome 156.0.8078.100, Claude 데스크톱 앱의 내장 브라우저)와 생성 날짜가 있다.
- 시나리오 67개: 발진기(모든 파형, 사용자 파형, 주파수 램프, 시작/정지 시각), 쌍이차 필터 8종과 IIR, 지연(분수 지연, 변하는 지연, 되먹임), AudioParam 자동화 6가지,
  버퍼 원천(재생 속도, 루프, 디튠, 시작 오프셋), 웨이브셰이퍼(과표본화 3종), 컨볼버(정규화 여부), 컴프레서, 스테레오 패너와 3D 패너(거리 모델 3종, 원뿔, 리스너), 채널 믹스 8가지,
  스플리터/머저, 파라미터 연결(진폭 변조). 잡음은 시드가 있는 선형 합동 생성기이므로 두 엔진의 입력이 같다. HRTF 패너와 AnalyserNode 는 비교하지 않는다(HRTF 자료가 다르다).

## 다시 만드는 방법

1. `tests/resources/webaudio/chrome` 를 루트로 하는 정적 서버를 띄운다. 요청 `POST /save?name=<이름>` 은 본문을 `ref/<이름>.json` 으로 저장해야 한다(Node 로 20줄 정도의 서버면 된다).
2. Chromium 으로 `run.html` 을 열고 개발자 도구(또는 자동화 도구)에서 `await runAll()` 을 실행한다. 모든 시나리오가 렌더링되어 `ref/` 에 저장되고 `_meta.json` 이 갱신된다.
3. `ChromeReferenceTest` 를 실행해 차이를 확인한다.

## 알려진 차이(시험이 단언한다)

| 시나리오 | 차이 | 이 엔진의 동작 |
| --- | --- | --- |
| `shaper_2x`, `shaper_4x` | 과표본화 필터의 지연이 다르다(Chromium 은 임펄스의 정점이 2배에서 128, 4배에서 192 프레임 늦고 크기는 0.992). 규격은 지연을 구현에 맡긴다. 지연을 맞추면 파형은 일치한다(제곱 평균 오차 2e-5 이하) | 63 / 74.5 프레임 지연(4배의 반 프레임은 정점을 0.64 로 낮춘다) |
| `osc_sine_nyq`, `osc_saw21k` | Chromium 은 나이퀴스트 가까이(21900 Hz, 21500 Hz)에서 기본파를 크게 줄인다(사인 진폭이 이상값의 약 3%) | 규격대로 나이퀴스트보다 낮은 기본파는 줄이지 않는다 |
| `delay_feedback` | 순환 안의 지연: 규격은 `delayTime` 을 최소 한 render quantum(128 프레임)으로 제한한다. Chromium 은 직접 경로를 제한하지 않고(44 프레임) 되먹임 경로에 한 quantum 을 더한다 | 규격대로 128 프레임 |
| `bufsrc_offset` | `offset` 0.003초(132.3 프레임): Chromium 은 정수 프레임(132)에서 읽는다 | 132.3 프레임 위치를 보간한다 |
| `osc_start_mid` | 시작 시각 100.5 프레임: Chromium 은 프레임으로 올려 위상 0 으로 시작한다 | 프레임 사이의 정확한 시각에서 시작한다(반 프레임의 위상 차이 0.0712 라디안) |
| `conv_norm` | 정규화 보정 상수: 규격 본문은 0.00125, Chromium 은 10^(-58/20)=0.0012589 | 규격 본문의 상수(출력이 0.99293 배) |

그 밖의 시나리오는 float 정밀도(최대 절대 오차 2e-5, 일부 1e-4)로 일치하며 믹스, IIR 필터, 계단 자동화처럼 비트 단위로 같은 것도 많다.
