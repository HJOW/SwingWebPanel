# netstormrun (AI용)

외부 NetStorm 샘플을 실제 `SwingWebPanel`과 일반 클래스패스 리소스 로더로 연다. 지정한 HTML의 head에 `probe.js`를 메모리에서 추가한다. 외부 파일은 읽기 전용으로 사용한다. 게임 상태나 값은 바꾸지 않고 콘솔, 프레임 콜백, Fetch와 게임 적재 진행을 측정한다.

- 먼저 제품 JAR를 만들고 `tools/netstormrun/build.bat` 또는 `build.sh`에서 JDK 6으로 도구를 컴파일한다.
- 저장소 루트에서 `tools/netstormrun/run.bat <www 경로> <index|debug> <출력 경로> <초> [작업 한도 ms [--window]]`를 실행한다. 선택 한도는 시험하는 정확한 최상위 URL에만 적용한다. 기본 JDK는 `JAVA6_HOME`의 JDK 6이며 `NETSTORM_JAVA_HOME`을 지정하면 해당 JRE로 실행한다.
- `sample|` 행은 상태, 로딩 크기, 페이지 경과 시간, 마지막 표본 구간의 rAF 횟수·누계·최대 시간·길이, Fetch 응답 수·대기 헤더 수·읽은 본문 크기·첫 Fetch부터 마지막 관측 지점까지의 시간, audio·music 상태, 대화 키와 게임이 시작했다고 보고한 효과음 수를 출력한다. 앱 초기화에서 본문 크기와 게임 적재 크기는 서로 다른 집계다.
- `runtime` 행은 JRE 버전과 Java Sound 믹서 수를 출력한다. `console|` 행은 오류·경고와 스크립트 위치를 포함한다. `result` 행에는 마지막 상태·오류 여부·벽시계 경과·힙 사용량·컴포넌트 로딩률, 실제 클릭 확인 및 효과음 시작 여부가 있다.
- 시작 화면에서 AWT 클릭을 넣고 원본 시작 그림의 자동 진행을 기다린다. `--window`에서는 실제 Swing 창을 열어 `Robot`으로 시작과 환영 버튼을 클릭하고 `Welcome2` 도달을 확인한다. 기본 실행은 Swing `paint`, 창 실행은 화면 캡처로 시작 및 마지막 화면을 PNG에 저장한다. 종료 코드 0은 메인 메뉴를 5초 동안 유지하고 콘솔 오류가 없으며 창 모드에서 환영 버튼이 동작했다는 뜻이다. 1은 제한 시간·게임 상태·콘솔·실행 실패, 2는 인수 오류다.

Java 6 API로 작성한다. `--window`에는 화면을 캡처하고 입력할 수 있는 데스크톱이 필요하다. 음악 상태와 효과음 횟수는 게임에서 보고한 값이다. 오디오 장치의 출력은 별도로 확인한다. 측정 중 rAF와 Fetch를 감싸므로 절대 시간에 계측 비용이 포함된다.

JRE 6u45와 7u80에서 실행했다. 실행 결과는 `docs/progress/netstorm.md` P28-07을 참조한다.
