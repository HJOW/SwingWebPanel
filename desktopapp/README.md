# SwingWebPanel Browser (desktopapp)

SwingWebPanel 컴포넌트로 만든 Swing 웹 브라우저입니다. 외부 라이브러리 없이 Java 6 이상에서 동작합니다.
이 프로그램은 SwingWebPanel 의 공개 API 만 사용하므로, SwingWebPanel 을 자기 프로그램에 넣어 쓰는 방법의 예이기도 합니다.

## 요구 사항

- 실행: Java 6 이상(JRE 6u45 와 JRE 8u202 에서 확인).
- 빌드: Maven 3.8.8 이상과 JDK 8 이상(Maven 실행용), JDK 6(컴파일과 시험 실행용, `JAVA6_HOME` 으로 경로 지정).

## 빌드와 실행

저장소 루트에서 실행합니다.

```sh
desktopapp/run.sh                       # 빌드한 뒤 설정의 시작 페이지로 시작
desktopapp/run.sh https://example.com/  # 시작 주소 지정
```

Windows 에서는 `desktopapp\run.bat` 을 같은 방식으로 씁니다.

직접 빌드하고 실행하려면 다음과 같이 합니다.

```sh
mvn -B -pl desktopapp -am -Dmaven.test.skip=true package
java -jar desktopapp/target/swingwebpanel-desktopapp.jar [시작 주소]
```

`swingwebpanel-desktopapp.jar` 는 앱과 SwingWebPanel 을 합친 단일 실행 JAR 입니다. 다른 JAR 없이 이 파일 하나로 실행됩니다.

### HTTPS

실행 JAR에 선택 TLS 모듈이 들어 있습니다. Java 6·7에서는 앱이 모든 탭과 창에서 모듈을 켜 TLS 1.3·1.2를 사용합니다.
Java 8 이상에서는 JRE의 TLS를 사용합니다. TLS 1.3이 없는 8u261 이전 Java 8도 동일합니다.
모듈 초기화에 실패하면 JRE 경로로 실행하고 콘솔에 한 번 알립니다. 도움말의 정보 창에서 현재 TLS 경로를 확인할 수 있습니다.
내장 루트의 수동 갱신과 인증서 폐기 확인 범위는 모듈 문서를 참고하세요. [TLS 모듈의 한계](../tls13/README.md)

## 화면 구성

- **제목 표시줄**: 페이지 제목(없으면 주소)과 프로그램 이름.
- **메뉴 막대**: 파일, 편집, 보기, 이동, 탭, 북마크, 도구, 도움말.
- **탐색 도구 모음**: 뒤로, 앞으로, 새로고침, 멈춤, 홈 버튼과 주소 표시줄, 새 탭(`+`) 단추.
  - 뒤로·앞으로 버튼을 오른쪽 클릭하면 그 방향의 방문 기록이 나옵니다.
  - Shift 를 누른 채 새로고침을 누르면 캐시 없이 다시 읽습니다. 멈춤 버튼은 페이지를 읽는 동안에만 켜집니다.
- **탭 줄**: 탭마다 제목, 읽는 중 표시, 닫기 단추가 있습니다. 탭을 가운데 단추로 눌러도 닫힙니다.
- **찾기 막대**: Ctrl+F 로 상태 표시줄 위에 나타납니다.
- **상태 표시줄**: 페이지의 상태 문구(링크 위에 마우스를 올리면 그 주소), 읽는 동안의 진행 막대, 확대 비율, 차단된 팝업을 여는 단추.

화면의 글은 JVM 의 기본 언어가 한국어이면 한국어로, 아니면 영어로 보입니다(`-Dswingwebpanel.desktopapp.lang=ko` 또는 `en` 으로 지정 가능).

## 기능

### 주소 표시줄

- 주소를 입력하고 Enter 를 누르면 이동하고, Esc 를 누르면 원래 주소로 돌아갑니다. 입력 중인 글은 페이지가 바뀌어도 지워지지 않습니다.
- `example.com` 처럼 스킴 없이 입력하면 `https://` 를 붙입니다(보안 연결이 실패하면 HTTP 로 다시 시도합니다).
- `C:\폴더\파일.html` 같은 파일 경로를 입력하면 그 파일을 엽니다.
- 주소가 아닌 글은 설정의 "검색 주소"가 있을 때 그 주소로 검색합니다(기본값은 비어 있습니다).

### 탭과 창

- 새 탭 Ctrl+T, 탭 닫기 Ctrl+W, 닫은 탭 다시 열기 Ctrl+Shift+T, 다음·이전 탭 Ctrl+Tab·Ctrl+Shift+Tab, 번호로 고르기 Ctrl+1~8(Ctrl+9 는 마지막 탭).
- 새 창 Ctrl+N, 창 닫기 Ctrl+Shift+W. 탭이 여러 개인 창을 닫을 때는 먼저 묻습니다(설정에서 끌 수 있습니다). 마지막 창을 닫으면 프로그램이 끝납니다.
- 링크를 Ctrl+클릭하거나 가운데 단추로 누르면 새 탭, Shift+클릭하면 새 창에서 엽니다. 링크를 오른쪽 클릭하면 "새 탭에서 열기", "새 창에서 열기", "링크 주소 복사"가 나옵니다.
- 모든 탭과 창은 쿠키를 함께 씁니다(한 탭에서 로그인하면 다른 탭에서도 로그인되어 있습니다). 방문 기록과 sessionStorage 는 탭마다 따로입니다.

### 팝업

- 페이지가 사용자의 조작(클릭, 키 누름) 없이 여는 창은 기본적으로 차단합니다. 차단하면 상태 표시줄에 알림과 "이 팝업 열기" 단추가 나옵니다.
- 사용자의 조작으로 연 창은 기본적으로 작은 팝업 창에 열립니다. 설정에서 새 창이나 새 탭에 열도록 바꿀 수 있습니다.
- 팝업 창은 자신을 연 브라우저 창에 속합니다: 그 브라우저 창을 닫으면 팝업도 닫힙니다.

### 북마크

- 이 페이지를 북마크에 추가 Ctrl+D, 모든 탭을 북마크에 추가 Ctrl+Shift+D, 북마크 관리 Ctrl+Shift+B.
- 북마크 메뉴에서 그냥 누르면 현재 탭, Ctrl 을 누르고 누르면 새 탭, Shift 를 누르고 누르면 새 창에서 엽니다.
- 관리 창에서 이름·주소 편집, 폴더, 순서 변경, 삭제, HTML 파일(Netscape 북마크 형식)로 가져오기·내보내기를 할 수 있습니다.

### 페이지 도구

- **찾기** Ctrl+F: 입력하는 즉시 페이지에서 찾아 모든 일치를 강조합니다. Enter(또는 F3, Ctrl+G)는 다음, Shift+Enter(Shift+F3, Ctrl+Shift+G)는 이전 일치로 갑니다. Esc 로 닫습니다.
  폼 입력란 안의 글과 프레임 안의 글은 찾지 않습니다.
- **확대·축소** Ctrl+`=`, Ctrl+`-`, Ctrl+0(원래 크기), Ctrl+마우스 휠.
- **페이지 원본** Ctrl+U: 서버에서 받은 글을 그대로 보입니다.
- **콘솔** Ctrl+Shift+J: 페이지 스크립트의 `console.log` 등 출력과 스크립트 오류를 수준별 색으로 보입니다.
- **방문 기록** Ctrl+H: 현재 탭의 방문 기록을 보이고 고른 항목으로 이동합니다. 프로그램을 끝내면 방문 기록은 남지 않습니다.
- **페이지 저장** Ctrl+S: 받은 원문을 파일로 저장합니다. **파일 열기** Ctrl+O.
- **다운로드**: 표시할 수 없는 파일이나 첨부 파일은 다운로드 창이 받습니다. 저장 폴더는 설정에서 정합니다.

### 인쇄

- **페이지 설정**(파일 메뉴): 용지 크기, 방향, 여백을 정합니다. 고른 용지는 설정에 보관됩니다. 기본 용지는 A4(북미는 Letter) 세로, 여백 반 인치입니다.
- **인쇄 미리 보기**(파일 메뉴): 인쇄될 쪽을 한 쪽씩 보입니다. 이전·다음 쪽, 크기(쪽 맞춤, 50~200%), 인쇄 단추가 있습니다.
- **인쇄** Ctrl+P: 운영 체제의 인쇄 대화 상자에서 프린터를 고르고 인쇄합니다. 페이지의 `window.print()` 도 같은 일을 합니다.
- 페이지의 인쇄용 스타일(`@media print`)과 `@page` 의 크기·여백, 쪽 나눔(`break-before: page` 등)을 따릅니다. 줄과 이미지는 쪽 경계에서 가르지 않습니다.
  쪽보다 넓은 페이지는 용지 폭에 맞게 줄여 인쇄합니다.
- 설정의 "인쇄" 구역에서 배경색·배경 이미지를 인쇄할지(기본: 인쇄하지 않음), 머리글·바닥글(제목, 날짜, 주소, 쪽 번호)을 넣을지(기본: 넣음) 정합니다.

### 설정 (도구 메뉴)

- 일반: 홈 페이지, 시작할 때 열 페이지(홈/빈 페이지/지난번의 창과 탭), 검색 주소, 다운로드 폴더, 기본 확대 비율.
- 탭과 창: 새 탭 페이지, 새 탭으로 바로 전환할지, 창을 닫을 때 확인할지, 팝업 차단, 팝업을 열 위치(팝업 창/새 창/새 탭), 새 창을 요청하는 링크를 열 위치(새 탭/새 창).
- 글꼴: 표준·serif·sans-serif·고정폭 글꼴과 크기(미리보기 포함). 페이지가 글꼴을 정하지 않은 글에 쓰입니다.
- 콘텐츠: JavaScript 사용, 스크립트가 탭을 닫는 것을 허용할지, User-Agent, 룩앤필.
- 인쇄: 배경 인쇄, 머리글·바닥글.

확인을 누르면 열려 있는 모든 창과 탭에 바로 적용되고 저장됩니다.

**룩앤필**은 메뉴, 단추, 탭, 대화 상자 같은 프로그램 화면의 모양입니다. 사용 중인 Java 가 제공하는 것 가운데 고릅니다(Windows 의 JDK 6 에서는 Metal, Nimbus, CDE/Motif, Windows, Windows Classic).
`(기본값)`은 Nimbus 이며, 따로 고르지 않으면 Nimbus 로 시작합니다. Nimbus 가 없는 Java 에서는 Java 가 처음에 쓰는 모양이 됩니다.
Java 가 처음에 쓰는 모양(보통 Metal)을 원하면 목록에서 직접 고릅니다. 웹 페이지의 내용은 룩앤필에 따라 바뀌지 않습니다.
저장한 룩앤필을 쓸 수 없으면(예: 다른 Java 로 실행해 그 룩앤필이 없는 경우) 실행 중에는 쓰던 모양을 그대로 두고, 시작할 때에는 기본값을 씁니다.
설정 값은 지우지 않습니다.

### 개인 정보 삭제 (도구 메뉴, Ctrl+Shift+Delete)

먼저 묻고, 동의하면 모든 창의 모든 탭과 팝업을 빈 페이지로 되돌리며 방문 기록, 캐시, sessionStorage, 쿠키, localStorage, 지난 세션의 탭 목록을 지웁니다.
북마크와 설정은 남습니다.

## 사용자 데이터

설정(`settings.properties`), 북마크(`bookmarks.txt`), 지난 세션의 탭 목록(`session.txt`)은 `사용자 홈/.swingwebpanel/desktopapp/` 아래에 UTF-8 텍스트 파일로 저장합니다.
JVM 옵션 `-Dswingwebpanel.desktopapp.home=폴더` 로 위치를 바꿀 수 있습니다.
읽을 수 없는 파일은 `이름.broken` 으로 보존하고 기본값으로 시작합니다. 쿠키는 파일에 저장하지 않으므로 프로그램을 끝내면 사라집니다.

## 하지 않는 것

- 확장 프로그램, 동기화, 프로필, 시크릿 창, 암호 저장, 개발자 도구(콘솔 보기는 있습니다), 주소 자동 완성은 없습니다.
- 비디오 재생, WebGL/WebGPU 는 SwingWebPanel 이 지원하지 않습니다(그 자리에 미지원 표시가 나옵니다).
- 인쇄에서 `@page` 의 여백 상자(`@top-center` 등)와 쪽 번호 카운터는 그리지 않습니다. 머리글·바닥글은 브라우저가 직접 그립니다.

## 점검용 옵션

`java -jar swingwebpanel-desktopapp.jar --smoke`는 창을 보이지 않고 페이지 하나를 읽습니다. Java 버전에 맞는 TLS 경로(`desktopapp TLS=module` 또는 `desktopapp TLS=JRE`)와 `desktopapp smoke ok`를 출력하고 종료 코드 0으로 끝납니다.
빌드(`mvn verify`)가 패키징한 JAR 을 JDK 6 에서 이 옵션으로 실행해 봅니다.
