Root certificate list of the swingwebpanel TLS module
=====================================================

The file org/duckdns/hjow/swingwebpanel/tls13/x509/mozilla-roots.txt in this module contains data from the
Common CA Database (CCADB, https://www.ccadb.org/): the root certificates of the "Mozilla Included CA Certificate Report"
(https://ccadb.my.salesforce-sites.com/mozilla/IncludedCACertificateReportPEMCSV) that carry the "Websites" trust bit,
with their "Distrust for TLS After Date" and "Mozilla Applied Constraints". The header of that file states the day the
report was retrieved and the SHA-256 of the report.
