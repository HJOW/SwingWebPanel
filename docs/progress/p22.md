## 2. 측정 방법(재현용)
- 실제 창·입력: `tools/uicheck`(Java 6, `java.awt.Robot`, `InputContext`). 명령은 `uicheck.md` 와 도구 문서.
- 오디오 피크 미터: Windows Core Audio 의 `IMMDeviceEnumerator.GetDefaultAudioEndpoint` → `IAudioMeterInformation.GetPeakValue`(끝점), `IAudioSessionManager2` → 세션별 미터와 프로세스 ID. PowerShell 의 .NET COM 상호 운용으로 20~400 ms 마다 읽었다. 이것은 **저장소 밖의 측정 수단**(오실로스코프 같은 관측 도구)이며 제품·시험·도구 코드에 들어가지 않는다(Java 6 로는 OS 오디오 미터를 읽을 공개 API 가 없다). 측정 대상 소리는 `tools/uicheck` 내장 서버의 `/tone.wav`(사인파)와 `pages/audio.html`, `audio2.html`.
- 클립보드 교차 확인: PowerShell(.NET `System.Windows.Forms.Clipboard`)로 다른 프로세스에서 넣고 읽었다.
