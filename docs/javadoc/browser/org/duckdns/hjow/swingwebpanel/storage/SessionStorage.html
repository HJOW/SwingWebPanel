org.duckdns.hjow.swingwebpanel.storage
Class SessionStorage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.storage.SessionStorage

public final class SessionStorage
extends java.lang.Object

The sessionStorage of one browser component: one StorageArea per origin, kept in memory as an ordinary field of the component's session. Nothing static refers to it, so it disappears together with the component (plan items P16-02, P21-06). A change of one document is reported to the other documents of the same component and origin (frames); it is never visible to other components.

브라우저 컴포넌트 하나의 sessionStorage: 오리진마다 StorageArea 하나이며 컴포넌트 세션의 일반 필드로 메모리에 둔다. 정적 변수가 이것을 가리키지 않으므로 컴포넌트와 함께 사라진다(계획 P16-02, P21-06). 한 문서의 변경은 같은 컴포넌트·같은 오리진의 다른 문서(프레임)에 보고되며 다른 컴포넌트에는 보이지 않는다.

getSlot

public java.lang.Object getSlot(java.lang.String name,
                                SessionStorage.SlotFactory factory)
Returns the object that another part of the product keeps for this component under a name, creating it with the factory the first time. This is where state that belongs to the whole component, not to one page (for example the shared workers and the broadcast channels of the pages of the component), lives: it is an ordinary field of this object, so it disappears with the component and no static variable has to hold it. It is neither part of the storage areas nor cleared with them.

제품의 다른 부분이 이 컴포넌트를 위해 이름으로 보관하는 객체를 반환하며 처음에는 팩토리로 만든다. 페이지 하나가 아니라 컴포넌트 전체에 속하는 상태(예: 컴포넌트의 페이지들이 공유하는 공유 worker 와 브로드캐스트 채널)가 사는 곳이다. 이 객체의 일반 필드이므로 컴포넌트와 함께 사라지고 정적 변수가 붙잡을 필요가 없다. 저장 영역의 일부가 아니며 영역과 함께 지워지지도 않는다.
