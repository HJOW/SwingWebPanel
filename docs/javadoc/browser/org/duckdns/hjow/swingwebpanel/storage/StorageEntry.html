org.duckdns.hjow.swingwebpanel.storage
Class StorageEntry

java.lang.Object
  org.duckdns.hjow.swingwebpanel.storage.StorageEntry

public final class StorageEntry
extends java.lang.Object

One item of a web storage area (localStorage or sessionStorage) as seen by the host application: the origin it belongs to, its key and its value. Instances are immutable, so the collections returned by getLocalStorage() and getSessionStorage() are read-only copies that never change the real storage.

호스트 애플리케이션이 보는 웹 저장소(localStorage 또는 sessionStorage) 항목 하나: 속한 오리진, 키, 값. 불변 객체이므로 getLocalStorage() 와 getSessionStorage() 가 반환하는 컬렉션은 실제 저장소를 바꾸지 않는 읽기 전용 복사본이다.
