org.duckdns.hjow.swingwebpanel.storage
Interface StorageListener

public interface StorageListener

Receives the changes of a storage so that other documents of the same origin can fire storage events (plan item P16-08). The change made by a document is not reported to that document itself (the source argument identifies it). The method is called on the thread that changed the storage: an implementation must hand over to its document thread.

같은 오리진의 다른 문서가 storage 이벤트를 일으킬 수 있도록 저장소의 변경을 받는다(계획 P16-08). 문서가 만든 변경은 그 문서 자신에게 보고되지 않는다(source 인수가 그 문서를 가리킨다). 저장소를 바꾼 스레드에서 호출되므로 구현은 자신의 문서 스레드로 넘겨야 한다.
