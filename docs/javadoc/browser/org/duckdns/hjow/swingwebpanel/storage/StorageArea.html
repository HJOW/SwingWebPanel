Class StorageArea

java.lang.Object

All Implemented Interfaces:
WebStorage
public final class StorageArea
extends java.lang.Object
implements WebStorage

An in-memory storage area of one origin: an insertion-ordered map of string keys to string values with a size limit (see StorageLimits). It is the data structure behind sessionStorage and behind each origin of localStorage. All methods are synchronized. A change that would exceed the limit throws StorageQuotaException before anything is modified.

한 오리진의 메모리 저장 영역: 문자열 키를 문자열 값에 대응시키는 삽입 순서 맵이며 크기 제한(StorageLimits 참조)이 있다. sessionStorage 와 localStorage 의 각 오리진 뒤에 있는 자료 구조이다. 모든 메서드는 동기화되어 있다. 제한을 넘게 되는 변경은 아무것도 바꾸기 전에 StorageQuotaException 을 던진다.
