StorageArea
public interface WebStorage

One storage area as web pages see it (the Storage interface): the items of one origin in localStorage or sessionStorage. The JavaScript layer exposes exactly these operations (plus the named property access that maps to getItem/setItem/removeItem). Keys and values are strings; the order of key(i) is the insertion order and stable while the storage is unchanged.

웹 페이지가 보는 저장 영역 하나(Storage 인터페이스): localStorage 또는 sessionStorage 에서 한 오리진의 항목들. JavaScript 계층은 정확히 이 연산들(과 getItem/setItem/removeItem 에 대응하는 이름 있는 프로퍼티 접근)을 노출한다. 키와 값은 문자열이며 key(i) 의 순서는 삽입 순서이고 저장소가 바뀌지 않는 동안 안정적이다.
