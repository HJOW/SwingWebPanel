Class StorageLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.storage.StorageLimits

public final class StorageLimits
extends java.lang.Object

The size limits of web storage (plan item P16-07). Sizes are counted in UTF-16 code units of keys plus values, as web browsers do (5 MiB per origin = 2.5 million code units at 2 bytes each). Exceeding a limit makes setItem fail with a StorageQuotaException, which the JavaScript layer reports as QuotaExceededError; the storage is left unchanged.

웹 저장소의 크기 제한(계획 P16-07). 크기는 웹 브라우저처럼 키와 값의 UTF-16 코드 단위 수로 센다(오리진당 5 MiB = 코드 단위당 2 바이트로 250만 코드 단위). 제한을 넘으면 setItem 이 StorageQuotaException 으로 실패하고 JavaScript 계층은 이를 QuotaExceededError 로 보고하며, 저장소는 바뀌지 않는다.
