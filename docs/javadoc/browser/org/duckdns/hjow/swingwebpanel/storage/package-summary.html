Package org.duckdns.hjow.swingwebpanel.storage

Web Storage: StorageEntry, per-origin storage areas, process-wide localStorage file store, per-component sessionStorage.

See:
          Description

Interface Summary
SessionStorage.SlotFactory Creates the object that a slot of the component holds.
StorageListener Receives the changes of a storage so that other documents of the same origin can fire storage events (plan item P16-08).
WebStorage One storage area as web pages see it (the Storage interface): the items of one origin in localStorage or sessionStorage.
 

Class Summary
LocalStorageManager The process-wide localStorage: one store per origin shared by all components of the JVM process, kept in one temporary file that is private to this process (the name contains the process id, a time stamp and a random number; files of other processes are never read, changed or deleted).
SessionStorage The sessionStorage of one browser component: one StorageArea per origin, kept in memory as an ordinary field of the component's session.
StorageArea An in-memory storage area of one origin: an insertion-ordered map of string keys to string values with a size limit (see StorageLimits).
StorageEntry One item of a web storage area (localStorage or sessionStorage) as seen by the host application: the origin it belongs to, its key and its value.
StorageEvent The storage event that a document receives when another document of the same origin changed a storage area.
StorageLimits The size limits of web storage (plan item P16-07).
 

Exception Summary
StorageQuotaException Thrown when a storage limit would be exceeded (see StorageLimits).
