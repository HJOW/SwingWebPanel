Class Summary
ClipboardBindings The JavaScript interfaces of the clipboard events (plan item P11-08): ClipboardEvent (clipboardData, the events copy, cut and paste) and the clipboard part of DataTransfer (getData, setData, clearData, types).
CssomInterfaces The script interfaces of the CSS Object Model that wrap the objects of the CSS engine (CSSOM, W3C Working Draft 26 August 2021, https://www.w3.org/TR/cssom-1/): StyleSheet and CSSStyleSheet, MediaList, CSSRuleList, and the rule interfaces CSSRule, CSSStyleRule, CSSGroupingRule, CSSConditionRule, CSSMediaRule, CSSSupportsRule, CSSLayerBlockRule, CSSLayerStatementRule, CSSImportRule, CSSFontFaceRule, CSSKeyframesRule, CSSKeyframeRule and CSSNamespaceRule, and the interfaces of the newer rules CSSContainerRule, CSSScopeRule, CSSStartingStyleRule, CSSPropertyRule, CSSCounterStyleRule, CSSPageRule and CSSMarginRule.
CssomMembers Installs the members of the CSSOM interfaces that the short member specifications of DomBridge.defineInterface(java.lang.String, java.lang.String, java.lang.Class, java.lang.String[]) cannot describe (an attribute that forwards its assignment, an operation with a default that depends on the object, a result that needs the page).
DatasetObject The dataset object of an element (DOMStringMap): a property fooBar stands for the content attribute data-foo-bar.
DocumentExtras The members of Document that are computed from the tree (body, head, title, the forms, images, links and scripts collections ...).
DomBridge The bridge between the Java host objects of one page (DOM nodes, events, collections ...) and the JavaScript realm of that page.
DomBridge.InterfaceInfo The runtime description of one interface.
DomExceptionObjects Creates the JavaScript DOMException objects (name, message and the legacy numeric code).
DomExceptionObjects.Value DOMException with the ErrorData brand and its serializable Web IDL values.
DomInterfaces The table of the DOM interfaces that scripts see (DOM Standard and the common HTML element interfaces) and the code that installs them into a DomBridge.
EditBindings The JavaScript interfaces that editing adds (plan item P20-06): StaticRange (the target ranges of InputEvent.getTargetRanges(); the constructor takes startContainer, startOffset, endContainer and endOffset), and the helpers that read the dataTransfer and targetRanges of an InputEvent init dictionary.
EventHandlers The event handler IDL attributes (onclick, onload ...) of one page.
FormBindings Connects the HTML form elements of org.duckdns.hjow.swingwebpanel.dom.html to JavaScript (plan items P11-05 to P11-07 and P15-02): the interfaces HTMLFormElement, HTMLInputElement, HTMLButtonElement, HTMLSelectElement, HTMLOptionElement, HTMLOptGroupElement, HTMLTextAreaElement, HTMLLabelElement, HTMLFieldSetElement, HTMLLegendElement, HTMLOutputElement, HTMLDataListElement, HTMLProgressElement, HTMLMeterElement, the collections HTMLFormControlsCollection, HTMLOptionsCollection and RadioNodeList, ValidityState, FileList and the Option constructor.
GeometryBindings The geometry interfaces that the layout queries return (plan item P20-03, Geometry Interfaces Module): DOMRectReadOnly, DOMRect (x, y, width, height, the edges top, right, bottom, left, toJSON(), the static fromRect(), a constructor that takes the four numbers), DOMRectList (what getClientRects() returns: length, item(), indexed access and iteration), and DOMPointReadOnly/DOMPoint (x, y, z, w, toJSON(), fromPoint()).
HandlerListener The listener behind an event handler IDL attribute such as onclick or an event handler content attribute: it is registered once, at the first assignment, and later assignments only replace the callback, so the handler keeps its position in the listener list.
HistoryBindings The JavaScript interfaces of the two events that session history moves fire at the window (HTML5 2014 REC 5.6.10.1): PopStateEvent (state) and HashChangeEvent (oldURL, newURL), with their constructors and the init dictionaries of the specification.
HostObject The JavaScript object that stands for one Java host object (a DOM node, an event, a collection ...).
IndexedObject A wrapper for list-like host objects (NodeList, HTMLCollection, NamedNodeMap, DOMTokenList): integer keys read the live list, an optional named lookup serves keys such as element ids, and everything else is an ordinary property (including the prototype's length and item).
JsListener A DOM event listener that calls a JavaScript function or the handleEvent method of a JavaScript object.
JsNodeFilter Adapts the NodeFilter callback of a script to the Java NodeFilter: a function is called with the node as its only argument, any other object must have an acceptNode method that is called with the object as this (the rules of a WebIDL callback interface).
MatrixBindings The matrix interfaces of the Geometry Interfaces Module Level 1 (section 6, https://www.w3.org/TR/geometry-1/, read 2026-11-17): DOMMatrixReadOnly and DOMMatrix with the sixteen elements m11 to m44 and the aliases a to f, is2D, isIdentity, the constructors (nothing, a CSS transform list string, a list of 6 or 16 numbers), fromMatrix(), fromFloat32Array(), fromFloat64Array(), the immutable transformations (translate, scale, scaleNonUniform, scale3d, rotate, rotateFromVector, rotateAxisAngle, skewX, skewY, multiply, flipX, flipY, inverse), transformPoint(), toFloat32Array(), toFloat64Array(), the stringifier and toJSON(), and on DOMMatrix the mutable transformations (multiplySelf, preMultiplySelf, translateSelf ...
RangeBindings The JavaScript interfaces of ranges, selections and traversal (plan item P20-03): Range with its constructor, Selection, NodeIterator, TreeWalker and the NodeFilter constants, and the members that create them: document.createRange(), createNodeIterator(), createTreeWalker(), document.getSelection() and window.getSelection().
StorageObject The wrapper of a Storage object (localStorage, sessionStorage) with its named properties: reading storage.name gives the item (unless the name is a member of the interface such as length or getItem), assigning stores the string value (a quota error becomes QuotaExceededError), delete removes the item and the property keys are the item keys (plan item P16-01).
StyleObject The script object of a CSSStyleDeclaration: either the inline style of an element (element.style, readable and writable; every write parses the style attribute, changes one declaration and writes the attribute back, so the style resolver and the serialization always agree) or a computed style snapshot (getComputedStyle, read-only).
