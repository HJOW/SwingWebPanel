org.duckdns.hjow.swingwebpanel.js.host.structured
Interface StructuredClone.TransferHandler

Enclosing class:
StructuredClone
public static interface StructuredClone.TransferHandler

The hook through which objects other than ArrayBuffers (for example a MessagePort) are put in a transfer list. The serializer calls prepare(JsObject) for every such entry without changing anything, then commit(JsObject, Object) once the whole serialization succeeded (that is where the source gives up the object), and a receiver turns the payload into an object of its own realm with receive(JsRealm, Object). A payload is moved, so it can be received once.

ArrayBuffer 가 아닌 객체(예: MessagePort)를 전달 목록에 넣기 위한 훅. 직렬화기는 그런 항목마다 아무것도 바꾸지 않고 prepare(JsObject) 를 부르고, 직렬화 전체가 성공하면 commit(JsObject, Object) 를 한 번씩 부르며(여기서 원본이 객체를 내놓는다), 받는 쪽은 receive(JsRealm, Object) 로 내용물을 자기 realm 의 객체로 바꾼다. 내용물은 옮겨지므로 한 번만 받을 수 있다.
