org.duckdns.hjow.swingwebpanel.js.host
Class WebRequest

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.WebRequest

public final class WebRequest
extends java.lang.Object

One request that a page script asks the component to make through XMLHttpRequest or fetch(). The page layer has already resolved the URL against the document's base URL, validated the method and the header names and applied the Fetch rules for forbidden headers, so the component only has to enforce its network policy (schemes, User-Agent, extra headers, cookies, SSL hook, cache, same-origin policy and CORS). The object is a plain value holder that is filled by the page layer before WebRequestSource.start(WebRequest, WebRequestSource.Callback) and never changed afterwards.

페이지 스크립트가 XMLHttpRequest 나 fetch() 로 컴포넌트에 요청하는 요청 하나. 페이지 계층이 URL을 문서 기준 URL로 이미 해석했고 메서드와 헤더 이름을 검증했으며 금지 헤더에 대한 Fetch 규칙을 적용했으므로 컴포넌트는 자기 네트워크 정책(스킴, User-Agent, 추가 헤더, 쿠키, SSL 훅, 캐시, 동일 출처 정책, CORS)만 적용하면 된다. 페이지 계층이 WebRequestSource.start(WebRequest, WebRequestSource.Callback) 전에 채우는 단순 값 보관 객체이며 그 뒤에는 바꾸지 않는다.
