EventListener
public final class HandlerListener
extends java.lang.Object
implements EventListener

The listener behind an event handler IDL attribute such as onclick or an event handler content attribute: it is registered once, at the first assignment, and later assignments only replace the callback, so the handler keeps its position in the listener list. A callback that returns false cancels the event. The callback may also be compiled lazily from the attribute text.

onclick 같은 이벤트 핸들러 IDL 속성이나 이벤트 핸들러 콘텐츠 속성 뒤의 리스너. 첫 대입 때 한 번 등록하며 이후 대입은 콜백만 바꾸므로 핸들러가 리스너 목록에서 자기 위치를 유지한다. false 를 반환하는 콜백은 이벤트를 취소한다. 콜백은 속성 텍스트에서 필요할 때 컴파일할 수도 있다.
