org.duckdns.hjow.swingwebpanel.js.host.canvas
Class CanvasBitmap

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasBitmap

public final class CanvasBitmap
extends java.lang.Object

The pixel store of a canvas: width * height pixels of non-premultiplied 0xAARRGGBB in one int[], a BufferedImage of type TYPE_INT_ARGB that shares that array, and the Graphics2D of the image (created once, configured for antialiasing). It is plain Java2D: nothing uses the GPU or a native surface. A bitmap of width or height 0, or one that exceeds CanvasLimits, is "empty": it has no pixels, no image and no graphics. All methods must be called while holding the monitor of the owner (CanvasSurface); the class itself is not synchronized.

캔버스의 화소 저장소: 알파를 미리 곱하지 않은 0xAARRGGBB 형식의 width * height 화소를 담은 int[] 하나, 그 배열을 공유하는 TYPE_INT_ARGB 형식의 BufferedImage, 그 이미지의 Graphics2D(한 번 만들고 안티앨리어싱으로 설정). 순수 Java2D 이며 GPU 나 네이티브 표면을 쓰지 않는다. 너비나 높이가 0 이거나 CanvasLimits 를 넘는 비트맵은 "비어 있다": 화소, 이미지, 그래픽스가 없다. 모든 메서드는 소유자(CanvasSurface)의 모니터를 잡고 불러야 하며 이 클래스는 동기화하지 않는다.
