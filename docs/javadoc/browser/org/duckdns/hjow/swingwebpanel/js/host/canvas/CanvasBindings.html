Class CanvasBindings

CanvasSource
public final class CanvasBindings
extends java.lang.Object
implements CanvasSource

The canvas of one page (plan items P20-05, P00-08): it installs the script interface of HTMLCanvasElement (width, height, getContext, toDataURL, toBlob), CanvasRenderingContext2D, CanvasGradient, CanvasPattern, TextMetrics and ImageData, owns the CanvasSurface of every canvas element that a script touched, and answers the renderer as a CanvasSource. getContext("2d") returns the one context of the canvas; every other context type (webgl, webgl2, experimental-webgl, webgpu, bitmaprenderer, unknown names) returns null, no WebGL or WebGPU interface object is defined and navigator.gpu does not exist, because 3D acceleration is not supported by this project. Setting the width or height attribute, even to the same value, replaces the bitmap with a transparent one and resets the context. Reading pixels back from a canvas that drew cross-origin images without permission (getImageData, toDataURL, toBlob) throws SecurityError.

한 페이지의 캔버스(계획 P20-05, P00-08): HTMLCanvasElement(width, height, getContext, toDataURL, toBlob), CanvasRenderingContext2D, CanvasGradient, CanvasPattern, TextMetrics, ImageData 의 스크립트 인터페이스를 설치하고, 스크립트가 건드린 모든 canvas 요소의 CanvasSurface 를 소유하며, CanvasSource 로서 렌더러에 답한다. getContext("2d") 는 캔버스의 하나뿐인 컨텍스트를 반환하고, 다른 모든 컨텍스트 형식 (webgl, webgl2, experimental-webgl, webgpu, bitmaprenderer, 모르는 이름)은 null 을 반환한다. 이 프로젝트는 3D 가속을 지원하지 않으므로 WebGL 이나 WebGPU 인터페이스 객체도 navigator.gpu 도 정의하지 않는다. width 나 height 속성을 (같은 값이라도) 지정하면 비트맵이 투명한 새것으로 바뀌고 컨텍스트가 초기화된다. 허락 없이 다른 오리진의 이미지를 그린 캔버스에서 화소를 읽어 오면(getImageData, toDataURL, toBlob) SecurityError 를 던진다.

installShared

public void installShared(org.duckdns.hjow.swingwebpanel.js.JsObject g)
Installs what every script context that has canvases needs, a page and a worker alike: the interfaces CanvasRenderingContext2D, OffscreenCanvasRenderingContext2D, CanvasGradient, CanvasPattern, TextMetrics, ImageData, Path2D, OffscreenCanvas and ImageBitmap and the global function createImageBitmap(). The canvas element is not part of it (a worker has no elements).

캔버스를 가진 모든 스크립트 문맥(페이지와 worker)이 필요로 하는 것을 설치한다: 인터페이스 CanvasRenderingContext2D, OffscreenCanvasRenderingContext2D, CanvasGradient, CanvasPattern, TextMetrics, ImageData, Path2D, OffscreenCanvas, ImageBitmap 과 전역 함수 createImageBitmap(). canvas 요소는 여기에 속하지 않는다(worker 에는 요소가 없다).
