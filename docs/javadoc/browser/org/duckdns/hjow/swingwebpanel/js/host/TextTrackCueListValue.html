Class TextTrackCueListValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.TextTrackCueListValue

public final class TextTrackCueListValue
extends java.lang.Object

The script object of a list of text track cues (TextTrackCueList, HTML 4.8.11.11.5): the list of the cues of a text track or the list of its active cues. The list is live: it is read from the track at each access, in the text track cue order. The class is public because the DOM bridge reads its accessors by reflection.

텍스트 트랙 cue 목록의 스크립트 객체(TextTrackCueList, HTML 4.8.11.11.5): 텍스트 트랙의 cue 목록 또는 활성 cue 목록. 목록은 살아 있다: 접근할 때마다 트랙에서 텍스트 트랙 cue 순서로 읽는다. DOM 브리지가 접근자를 리플렉션으로 읽으므로 클래스는 public 이다.
