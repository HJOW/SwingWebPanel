Class CanvasEncoder

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasEncoder

public final class CanvasEncoder
extends java.lang.Object

Serializes canvas pixels to a file for toDataURL() and toBlob() with the public javax.imageio API: PNG (the default and the fallback for every other type) and JPEG (transparent pixels become black, as in browsers; the quality is a number from 0 to 1, default 0.92). WebP and the other types that the canvas specification lists are not encoded: the encoder answers with PNG, as the specification requires for unsupported types.

toDataURL() 과 toBlob() 을 위해 공개 javax.imageio API 로 캔버스 화소를 파일로 직렬화한다: PNG(기본이며 다른 모든 형식의 대체)와 JPEG(투명한 화소는 브라우저처럼 검정이 된다. 품질은 0 에서 1 사이의 숫자이며 기본 0.92). WebP 와 캔버스 규격이 나열하는 다른 형식은 인코딩하지 않고, 규격이 지원하지 않는 형식에 요구하는 대로 PNG 로 답한다.
