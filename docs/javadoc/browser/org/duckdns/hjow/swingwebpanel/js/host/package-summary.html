Package org.duckdns.hjow.swingwebpanel.js.host

Interface Summary
BrowsingContext A browsing context as the script host sees it: the top-level document of the component or a nested context of an iframe or frame element.
CorsImageRequestSource An ImageRequestSource that also fetches images in CORS mode, for an img element with a crossorigin attribute: a cross-origin request carries the Origin header, the cookies follow the mode, and a response that does not grant access to the document ends the load with an error (so the error event fires and a canvas never gets the pixels), while a granted image can be read back without tainting a canvas.
HostConsole The console hook of a page that also knows where a message comes from when it was not written by the page's own scripts: a worker of the page.
HostEnvironment.ClipboardResult Receives the result of an asynchronous clipboard text operation on the document thread.
ImageRequestSource The service through which a page asks the component to load the images of its img elements (plan item P18-05).
ImageRequestSource.Callback Receives the result of one image request.
MediaRequestSource The service through which a page asks the component to fetch the resource of an audio or video element (plan items P18-05-c, P18-08).
MediaRequestSource.AudioCallback Accepts an audio result backed by memory or a temporary file.
MediaRequestSource.Callback Receives the result of one media request.
MediaRequestSource.ProgressCallback A receiver that is also told how far the transfer has come (plan item P18-08: the progress and stalled events of the media element).
MediaRequestSource.Request A running request that can be cancelled.
ModuleScriptSource A ScriptSource that also knows the browser rules of module scripts: the request uses CORS mode (a cross-origin module must be allowed by the server), cookies are sent to the page's own origin only unless the page asked for credentials (crossorigin="use-credentials"), the response must have a JavaScript MIME type, and the final URL after redirects is reported so that the module's relative imports resolve against it.
ModuleScriptSource.WithAttributes Provides typed module responses with the host's MIME and origin checks.
PointerService The pointer capture service of a page (W3C Pointer Events, "Pointer capture"): the component keeps the state of the pointer, a script asks for capture through the Element methods setPointerCapture, releasePointerCapture and hasPointerCapture, which the page layer checks against this service.
Scheduler The clock and timer service of a page.
Scheduler.Handle A scheduled task that can be cancelled.
ScriptSource Supplies the text of external scripts and modules to the page (the component fetches them through its request layer, so User-Agent, extra headers, cookies, SSL hook, scheme limits and cancellation apply).
ScriptSource.WithResponse A host source that supplies response metadata for classic scripts.
StreamingWebRequestSource The streaming companion of WebRequestSource for requests whose answer is not a finished body but a stream that stays open and is read while it arrives (the event streams of EventSource).
StreamingWebRequestSource.Listener Receives a stream on a request thread; every method must only hand the data over (no JavaScript runs here).
WebRequestSource The asynchronous request service of a page, parallel to ScriptSource: the component implements it with its common request layer, so User-Agent, extra headers, cookies, SSL hook, scheme limits, cache, same-origin policy and cancellation apply to XMLHttpRequest and fetch() exactly as they do to scripts, styles and images.
WebRequestSource.BodyCallback Optional extension for a receiver that can consume filtered HTTP body chunks before completion.
WebRequestSource.Call A started request that can be cancelled.
WebRequestSource.Callback Receives the progress and the result of a request; every method is called on a request thread and must only hand the data over.
 

Class Summary
DomParsing DOMParser and XMLSerializer of a page (plan item P20-04; HTML Standard "DOMParser" and DOM Parsing and Serialization "XML Serialization").
DomParsing.Parser The DOMParser object (script visible members: parseFromString).
DomParsing.Serializer The XMLSerializer object (script visible members: serializeToString).
HostEnvironment What a page needs from the component around it: the user agent, how to fetch scripts, timers, cookies, storage, the viewport size, and the hooks for navigation and repaint requests.
MediaErrorValue The value behind a script's MediaError object (the error attribute of a media element, plan item P18-08): the error code of HTML5 section 4.7.10.1 and a message.
MessagingApi Messaging of a page (plan items P20-09 and P20-09-b; W3C Web Messaging REC 2015-05-19 and the HTML Standard "Web messaging" of 2026-11-17): window.postMessage(message, targetOrigin [, transfer]) and window.postMessage(message, {targetOrigin, transfer}), MessageEvent, and structuredClone(value [, {transfer}]); MessageChannel and MessagePort are installed through PortApi, because their ports are shared with workers.
ModuleSources Module source lookup shared by browser scripting hosts.
PageLifecycle The life cycle events of a page that the host reports (HTML Standard "Page lifecycle": browsing the web, unloading documents; Page Visibility Level 2; the window focus/blur events and the online/offline events of the network state): pageshow is fired by the page itself after load; this class remembers that it happened (PageScripts.isPageShown()), because a page that was never shown has nothing to unload; PageLifecycle.unload() runs the unloading sequence of a page that is left (a navigation, clean(), dispose()): beforeunload at the window (a BeforeUnloadEvent that can be cancelled), pagehide (PageTransitionEvent, persisted false), visibilitychange at the document (the state becomes hidden) and unload.
PageScripts The JavaScript side of one page (plan items P15-01, P15-04 to P15-07, P15-09, P15-11): it owns the realm, the DOM bridge, the window, the event loop (tasks, timers, microtasks, mutation observers) and the script execution model.
ScriptText The text of a fetched script together with the URL that finally served it.
TextTrackCueListValue The script object of a list of text track cues (TextTrackCueList, HTML 4.8.11.11.5): the list of the cues of a text track or the list of its active cues.
TextTrackCueValue The script object of a text track cue (TextTrackCue and VTTCue, HTML 4.8.11.11.5 and WebVTT 9.1): the getters and setters read and write the VttCue that it stands for, and the changes that matter to the playback (the start and end time, the pause-on-exit flag) tell the text track manager so that the cues that are active are worked out again.
TextTrackListValue The script object of the list of the text tracks of a media element (TextTrackList, HTML 4.8.11.11.5): media.textTracks.
TextTrackValue The script object of a text track (TextTrack, HTML 4.8.11.11.1 and 4.8.11.11.5) and the state that goes with it: the kind, label, language and identifier, the readiness state, the mode, the list of cues and what the track processing model needs while the file of a track element is fetched.
ThreadScheduler A Scheduler that runs the tasks on one daemon thread.
TimeRangesValue The value behind a script's TimeRanges object (buffered, seekable and played of a media element, plan item P18-08): a static normalized list of ranges in seconds (HTML5 section 4.7.10.14).
UnscriptedMedia Runs HTML audio through the common media state machine without a script realm.
VttRegionValue The script object of a WebVTT region (VTTRegion, WebVTT 9.2): the getters and setters read and write the VttRegion that it stands for.
WebRequest One request that a page script asks the component to make through XMLHttpRequest or fetch().
WebResponse The result of a WebRequest, already filtered by the component's network policy the way the Fetch Standard filters responses: a basic response (same origin, without Set-Cookie), a cors response (cross origin that the server allowed, with only the safelisted and the exposed headers), an opaque response (cross origin no-cors: status 0, no headers, no body) or an error response (network error: refused by CORS or by the scheme policy, blocked redirect, failed connection, cancelled request).
Window The Java side of the window object: an event target that is the end of every document event path (the DOM calls it through Document.setEventWindow(EventTarget)).
 

Enum Summary
ModuleScriptSource.Credentials Fetch credentials mode for a module graph.
