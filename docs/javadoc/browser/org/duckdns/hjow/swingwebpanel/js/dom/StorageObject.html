public final class StorageObject
extends HostObject

The wrapper of a Storage object (localStorage, sessionStorage) with its named properties: reading storage.name gives the item (unless the name is a member of the interface such as length or getItem), assigning stores the string value (a quota error becomes QuotaExceededError), delete removes the item and the property keys are the item keys (plan item P16-01).

Storage 객체(localStorage, sessionStorage)의 래퍼. 이름 있는 프로퍼티를 가진다: storage.name 을 읽으면 항목이 나오고(이름이 length, getItem 같은 인터페이스 멤버가 아니면), 대입하면 문자열 값을 저장하며(쿼터 오류는 QuotaExceededError 가 된다), delete 는 항목을 지우고 프로퍼티 키는 항목 키이다(계획 P16-01).
