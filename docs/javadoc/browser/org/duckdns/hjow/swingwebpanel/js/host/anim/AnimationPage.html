org.duckdns.hjow.swingwebpanel.js.host.anim
Interface AnimationPage

public interface AnimationPage

What the script binding of Web Animations needs from the page whose scripts it serves: the realm, the DOM bridge, the document, the environment, the document clock (the clock of performance.now() and requestAnimationFrame), whether scripts may run, error reporting, and animation frames shared with requestAnimationFrame (the step "update animations and send events" runs right before the animation frame callbacks of the same frame, with the same time). The page's script host provides it.

Web Animations 의 스크립트 연결이 그 스크립트를 담당하는 페이지에서 필요로 하는 것: realm, DOM 브리지, 문서, 환경, 문서 시계(performance.now() 와 requestAnimationFrame 의 시계), 스크립트를 실행할 수 있는지 여부, 오류 보고, requestAnimationFrame 과 함께 쓰는 애니메이션 프레임("update animations and send events" 단계는 같은 프레임의 애니메이션 프레임 콜백 바로 전에 같은 시각으로 실행된다). 페이지의 스크립트 호스트가 제공한다.
