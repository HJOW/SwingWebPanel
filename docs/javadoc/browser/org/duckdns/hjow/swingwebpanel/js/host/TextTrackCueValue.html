org.duckdns.hjow.swingwebpanel.js.host
Class TextTrackCueValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.host.TextTrackCueValue

public final class TextTrackCueValue
extends EventTarget

The script object of a text track cue (TextTrackCue and VTTCue, HTML 4.8.11.11.5 and WebVTT 9.1): the getters and setters read and write the VttCue that it stands for, and the changes that matter to the playback (the start and end time, the pause-on-exit flag) tell the text track manager so that the cues that are active are worked out again. Every cue of this component is a WebVTT cue (a script cannot construct another kind). The cue is an EventTarget: enter and exit fire at it. The members region, line and position (which take objects and the keyword auto) are defined by TextTrackBindings itself. The class is public because the DOM bridge reads its accessors by reflection.

텍스트 트랙 cue 의 스크립트 객체(TextTrackCue, VTTCue. HTML 4.8.11.11.5 와 WebVTT 9.1): getter 와 setter 가 그것이 나타내는 VttCue 를 읽고 쓰며, 재생에 영향을 주는 변경(시작/끝 시각, pause-on-exit 표시)은 활성 cue 를 다시 계산하도록 텍스트 트랙 관리자에 알린다. 이 컴포넌트의 모든 cue 는 WebVTT cue 이다(스크립트는 다른 종류를 만들 수 없다). cue 는 EventTarget 이며 enter, exit 가 그 위에서 발생한다. 객체와 키워드 auto 를 받는 region, line, position 은 TextTrackBindings 가 직접 정의한다. DOM 브리지가 접근자를 리플렉션으로 읽으므로 클래스는 public 이다.
