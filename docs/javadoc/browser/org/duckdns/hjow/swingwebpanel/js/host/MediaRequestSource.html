Interface MediaRequestSource

public interface MediaRequestSource

The service through which a page asks the component to fetch the resource of an audio or video element (plan items P18-05-c, P18-08). The component fetches the whole resource with the common request layer (user agent, extra headers, cookies, the SSL extension point, the scheme restrictions and the HTTP cache) and hands over the encoded bytes with the MIME type that the server declared; the decoding and the playback happen in the page, outside of this service, and the bytes never reach scripts. A page without such a service (a test host) cannot play media: the resource fails like an unsupported one.

페이지가 audio 또는 video 요소의 리소스를 컴포넌트에 가져오게 하는 서비스(계획 P18-05-c, P18-08). 컴포넌트가 공통 요청 계층(User-Agent, 추가 헤더, 쿠키, SSL 확장 지점, 스키마 제한, HTTP 캐시)으로 리소스 전체를 가져와 인코딩된 바이트를 서버가 선언한 MIME 타입과 함께 넘긴다. 디코딩과 재생은 이 서비스 밖의 페이지에서 일어나며 바이트는 스크립트에 전달되지 않는다. 이 서비스가 없는 페이지(시험 호스트)는 미디어를 재생할 수 없으며 리소스는 지원하지 않는 것처럼 실패한다.
