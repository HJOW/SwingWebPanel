Interface WebRequestSource.Callback

Enclosing interface:

public static interface WebRequestSource.Callback

Receives the progress and the result of a request; every method is called on a request thread and must only hand the data over.

요청의 진행과 결과를 받는다. 모든 메서드는 요청 스레드에서 호출되며 데이터를 넘기기만 해야 한다.

Method Detail

onHeaders

void onHeaders(WebResponse head)
Called when the status line and the headers of an acceptable response are known (before the body is read). It is optional: a request may report everything with onComplete(WebResponse) only (error statuses, cached answers, small bodies).

받아들일 수 있는 응답의 상태 줄과 헤더를 알게 되었을 때(본문을 읽기 전) 호출된다. 선택 사항이다. 요청은 onComplete(WebResponse) 만으로 모든 것을 알릴 수도 있다(오류 상태, 캐시 응답, 작은 본문).

Parameters:
head - the response without a body / 본문 없는 응답

onComplete
