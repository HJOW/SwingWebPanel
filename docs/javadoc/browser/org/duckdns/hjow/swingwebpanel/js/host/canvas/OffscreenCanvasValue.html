Class OffscreenCanvasValue

public final class OffscreenCanvasValue
extends EventTarget

An OffscreenCanvas value (HTML Standard 4.12.5.3): a bitmap and its 2D context without a place in the document. It is an EventTarget (contextlost and contextrestored listeners can be added; the canvas never loses its context here). The pixels live in a CanvasSurface, the same engine that a canvas element uses, so an offscreen canvas and the context of a canvas element draw alike. An offscreen canvas that came from HTMLCanvasElement.transferControlToOffscreen() shares the surface of its placeholder element, so whatever is drawn is shown by the element; moving the object to a worker (a transfer) detaches it: it gives its surface to the receiver, its size is 0 and it cannot be used any more. All members are meant for the thread that owns the script realm of the object.

OffscreenCanvas 값(HTML 표준 4.12.5.3): 문서에 자리가 없는 비트맵과 그 2D 컨텍스트. EventTarget 이다(contextlost, contextrestored 리스너를 더할 수 있으나 여기서 캔버스는 컨텍스트를 잃지 않는다). 화소는 canvas 요소가 쓰는 것과 같은 엔진인 CanvasSurface 에 있으므로 offscreen 캔버스와 canvas 요소의 컨텍스트는 똑같이 그린다. HTMLCanvasElement.transferControlToOffscreen() 이 만든 offscreen 캔버스는 자리표시 요소의 표면을 공유하므로 그려진 것은 요소가 보여 준다. 객체를 worker 로 옮기면(전달) 떼어 내진다: 표면을 받는 쪽에 내주고 크기가 0 이 되며 더 쓸 수 없다. 모든 멤버는 객체의 스크립트 realm 을 소유한 스레드에서 쓰도록 만들었다.
