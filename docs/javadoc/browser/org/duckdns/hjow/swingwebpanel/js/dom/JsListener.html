Class JsListener

EventListener
public final class JsListener
extends java.lang.Object
implements EventListener

A DOM event listener that calls a JavaScript function or the handleEvent method of a JavaScript object. Two listeners are equal when they wrap the same callback object, which is how removeEventListener finds the listener that addEventListener registered. An error thrown by the callback is reported to the page (DomBridge.reportError(java.lang.RuntimeException)) and does not stop the other listeners.

JavaScript 함수 또는 JavaScript 객체의 handleEvent 메서드를 부르는 DOM 이벤트 리스너. 같은 콜백 객체를 감싼 두 리스너는 같다. removeEventListener 가 addEventListener 가 등록한 리스너를 찾는 방법이다. 콜백이 던진 오류는 페이지에 보고하며 (DomBridge.reportError(java.lang.RuntimeException)) 다른 리스너를 멈추지 않는다.
