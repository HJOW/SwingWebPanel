org.duckdns.hjow.swingwebpanel.js.host.canvas
Class Context2D

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.Context2D

public final class Context2D
extends java.lang.Object

The drawing engine behind CanvasRenderingContext2D: the state stack, the transformation matrix, the current path, filling, stroking (with dashes, caps and joins), clipping with antialiased masks, rectangles, text, images, pixel data, shadows with Gaussian blur and all 26 compositing operators. It is pure Java2D on a BufferedImage of the CanvasSurface; nothing uses the GPU. The methods take Java numbers and objects; the script bindings do the WebIDL conversions and the type checks. Where the specification says "if any argument is infinite or NaN, return" the methods return without doing anything, and invalid values of attributes are ignored. Methods that must throw (IndexSizeError, SecurityError, InvalidStateError) throw DomException. The methods are not synchronized; the caller holds the monitor of the surface.

Drawing model: a shape (or the glyph outline of a text, or an image) is painted into a transparent layer, the layer is multiplied by the clip mask and by the global alpha, and then composited with the operator onto the bitmap, over the whole clipped canvas for the operators that change pixels where the source is transparent. Plain source-over drawing without a shadow and without a non-rectangular clip skips the layer and paints straight onto the bitmap.

CanvasRenderingContext2D 뒤의 그리기 엔진: 상태 스택, 변환 행렬, 현재 경로, 채우기, 선 긋기(점선, 끝 모양, 꺾임 포함), 안티앨리어싱된 마스크로 클리핑, 사각형, 텍스트, 이미지, 화소 데이터, 가우시안 번짐 그림자, 합성 연산자 26 개 전부. CanvasSurface 의 BufferedImage 위의 순수 Java2D 이며 GPU 를 쓰지 않는다. 메서드는 Java 숫자와 객체를 받으며 WebIDL 변환과 형식 검사는 스크립트 연결이 한다. 규격이 "인수가 무한대나 NaN 이면 반환" 이라고 한 곳에서는 아무것도 하지 않고 반환하며, 속성의 잘못된 값은 무시한다. 던져야 하는 경우(IndexSizeError, SecurityError, InvalidStateError)는 DomException 을 던진다. 메서드는 동기화하지 않으며 호출자가 표면의 모니터를 잡는다.

그리기 모델: 도형(또는 텍스트의 글리프 윤곽, 이미지)을 투명한 레이어에 칠하고, 레이어에 클립 마스크와 전역 알파를 곱한 뒤, 연산자로 비트맵에 합성한다. 원본이 투명한 곳의 화소도 바꾸는 연산자는 클리핑된 캔버스 전체에 합성한다. 그림자와 사각형이 아닌 클립이 없는 평범한 source-over 그리기는 레이어를 건너뛰고 비트맵에 바로 칠한다.

Writes pixels into the bitmap, replacing what is there: the matrix, the clip, the global alpha, the shadow and the compositing operator do not apply.

화소를 비트맵에 써서 그 자리를 교체한다: 행렬, 클립, 전역 알파, 그림자, 합성 연산자는 적용되지 않는다.

Parameters:
data - the RGBA bytes of the image data / 이미지 데이터의 RGBA 바이트
iw - the width of the image data / 이미지 데이터의 너비
ih - the height of the image data / 이미지 데이터의 높이
dx - destination x / 대상 x
dy - destination y / 대상 y
dirtyX - x of the dirty rectangle / 변경 사각형의 x
dirtyY - y of the dirty rectangle / 변경 사각형의 y
dirtyW - width of the dirty rectangle (may be negative) / 변경 사각형의 너비(음수 가능)
dirtyH - height of the dirty rectangle (may be negative) / 변경 사각형의 높이(음수 가능)
