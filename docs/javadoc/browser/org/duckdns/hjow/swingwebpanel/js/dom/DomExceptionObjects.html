Class DomExceptionObjects

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.DomExceptionObjects

public final class DomExceptionObjects
extends java.lang.Object

Creates the JavaScript DOMException objects (name, message and the legacy numeric code). They inherit from the DOMException prototype, which inherits from Error.prototype, so e instanceof Error and e instanceof DOMException are both true.

JavaScript DOMException 객체(name, message, 예전 숫자 code)를 만든다. DOMException 프로토타입을 상속하고 그것이 Error.prototype 을 상속하므로 e instanceof Error 와 e instanceof DOMException 이 모두 참이다.
