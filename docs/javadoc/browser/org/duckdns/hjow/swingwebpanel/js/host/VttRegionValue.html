org.duckdns.hjow.swingwebpanel.js.host
Class VttRegionValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.VttRegionValue

public final class VttRegionValue
extends java.lang.Object

The script object of a WebVTT region (VTTRegion, WebVTT 9.2): the getters and setters read and write the VttRegion that it stands for. A number that is not finite is a TypeError (the attributes are restricted doubles); a percentage outside the range 0 to 100 is an IndexSizeError. The class is public because the DOM bridge reads its accessors by reflection.

WebVTT region 의 스크립트 객체(VTTRegion, WebVTT 9.2): getter 와 setter 가 그것이 나타내는 VttRegion 을 읽고 쓴다. 유한하지 않은 수는 TypeError(속성은 제한된 double)이고 0~100 밖의 백분율은 IndexSizeError 이다. DOM 브리지가 접근자를 리플렉션으로 읽으므로 클래스는 public 이다.
