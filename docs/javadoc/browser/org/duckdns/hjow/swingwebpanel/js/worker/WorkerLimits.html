org.duckdns.hjow.swingwebpanel.js.worker
Class WorkerLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.worker.WorkerLimits

public final class WorkerLimits
extends java.lang.Object

The limits of workers and broadcast channels. A page that spawns workers in a loop gets an error instead of exhausting the threads of the process, and a sender that outruns a receiver cannot grow a queue without bound.

worker 와 브로드캐스트 채널의 한도. 반복문으로 worker 를 만드는 페이지는 프로세스의 스레드를 고갈시키는 대신 오류를 받고, 받는 쪽보다 빠른 보내는 쪽은 큐를 끝없이 키울 수 없다.

MAX_WORKERS_PER_PAGE

public static final int MAX_WORKERS_PER_PAGE
The largest number of live workers of one page; the next new Worker() throws a QuotaExceededError. A worker that was terminated or that closed itself does not count.

페이지 하나의 살아 있는 worker 의 최대 수. 그다음 new Worker() 는 QuotaExceededError 를 던진다. 종료했거나 스스로 닫은 worker 는 세지 않는다.
