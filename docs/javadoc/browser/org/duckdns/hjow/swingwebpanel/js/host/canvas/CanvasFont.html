org.duckdns.hjow.swingwebpanel.js.host.canvas
Class CanvasFont

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasFont

public final class CanvasFont
extends java.lang.Object

A parsed value of the font attribute of the 2D context (the CSS font shorthand without line height): optional style (italic, oblique), variant (small-caps, parsed and ignored), weight (bold, bolder, lighter, 100 to 900), stretch keywords (parsed and ignored), a size and a family list. The size units px pt pc in cm mm q em rem ex % and the size keywords xx-small to xxx-large, smaller and larger are understood; em and percentages are relative to the font size of the canvas element. System fonts and calc() are not supported (the assignment is then ignored, as for any invalid value). The families map to Java fonts as the layout engine maps them (serif, sans-serif, monospace and the installed families; the first family that can display the text is used).

2D 컨텍스트의 font 속성 값을 해석한 결과(줄 높이가 없는 CSS font 단축 속성): 선택적인 스타일(italic, oblique), 변형(small-caps, 해석만 하고 무시), 굵기(bold, bolder, lighter, 100~900), 늘임 키워드(해석만 하고 무시), 크기, 글꼴 패밀리 목록. 크기 단위 px pt pc in cm mm q em rem ex % 와 크기 키워드 xx-small ~ xxx-large, smaller, larger 를 이해하며 em 과 백분율은 캔버스 요소의 글꼴 크기에 상대적이다. 시스템 글꼴과 calc() 는 지원하지 않는다(그러면 다른 잘못된 값처럼 대입이 무시된다). 패밀리는 레이아웃 엔진과 같게 Java 글꼴에 대응한다(serif, sans-serif, monospace, 설치된 패밀리. 텍스트를 표시할 수 있는 첫 패밀리를 쓴다).
