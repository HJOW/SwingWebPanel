Class JsNodeFilter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.JsNodeFilter
All Implemented Interfaces:
NodeFilter
public final class JsNodeFilter
extends java.lang.Object
implements NodeFilter

Adapts the NodeFilter callback of a script to the Java NodeFilter: a function is called with the node as its only argument, any other object must have an acceptNode method that is called with the object as this (the rules of a WebIDL callback interface). The result is converted to an unsigned short, like WebIDL does. An exception of the script goes through to the traversal call of the caller.

스크립트의 NodeFilter 콜백을 Java NodeFilter 에 맞춘다: 함수는 노드를 유일한 인수로 호출하고, 그 밖의 객체는 acceptNode 메서드가 있어야 하며 그 객체를 this 로 호출한다(WebIDL 콜백 인터페이스의 규칙). 결과는 WebIDL 처럼 unsigned short 로 바꾼다. 스크립트의 예외는 호출자의 탐색 호출까지 전달된다.
