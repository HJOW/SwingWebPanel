org.duckdns.hjow.swingwebpanel.js.host
Class PageLifecycle

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.PageLifecycle

public final class PageLifecycle
extends java.lang.Object

The life cycle events of a page that the host reports (HTML Standard "Page lifecycle": browsing the web, unloading documents; Page Visibility Level 2; the window focus/blur events and the online/offline events of the network state):

  • pageshow is fired by the page itself after load; this class remembers that it happened (PageScripts.isPageShown()), because a page that was never shown has nothing to unload;
  • unload() runs the unloading sequence of a page that is left (a navigation, clean(), dispose()): beforeunload at the window (a BeforeUnloadEvent that can be cancelled), pagehide (PageTransitionEvent, persisted false), visibilitychange at the document (the state becomes hidden) and unload. The page cannot hold the navigation back: this component has no dialog, so the answer of beforeunload is only reported back to the host, which tells it in the status text;
  • visibilityChanged() fires visibilitychange at the document when the host says that the page became visible or hidden (the component is shown or hidden on screen);
  • windowFocus(boolean) fires focus or blur at the window (they do not bubble);
  • onlineChanged() fires online or offline at the window when the host's network state changed.
Every method must be called on the document queue (they are page tasks); none of them throws.

호스트가 알리는 페이지 수명 이벤트(HTML Standard "Page lifecycle": 웹 탐색, 문서 언로드, Page Visibility Level 2, window 의 focus/blur 이벤트, 네트워크 상태의 online/offline 이벤트):

  • pageshow 는 페이지가 load 뒤 스스로 발생시킨다. 이 클래스는 그 사실을 기억하며(PageScripts.isPageShown()) 한 번도 보이지 않은 페이지는 언로드할 것이 없다.
  • unload() 는 떠나는 페이지(이동, clean(), dispose())의 언로드 순서를 실행한다: window 의 beforeunload(취소할 수 있는 BeforeUnloadEvent), pagehide(PageTransitionEvent, persisted false), 문서의 visibilitychange(상태가 hidden 이 됨), unload. 페이지는 이동을 붙잡을 수 없다. 이 컴포넌트에는 대화상자가 없으므로 beforeunload 의 답은 호스트에 알리기만 하며 호스트가 상태 메시지로 알린다.
  • visibilityChanged() 는 호스트가 페이지가 보이게/가려졌다고 알릴 때(컴포넌트가 화면에 나타나거나 사라질 때) 문서에 visibilitychange 를 발생시킨다.
  • windowFocus(boolean) 는 window 에 focus 또는 blur 를 발생시킨다(버블링하지 않는다).
  • onlineChanged() 는 호스트의 네트워크 상태가 바뀌었을 때 window 에 online 또는 offline 을 발생시킨다.
모든 메서드는 문서 큐에서 불러야 한다(페이지 작업이다). 어느 것도 예외를 던지지 않는다.

unload

public java.lang.String unload()
Runs the unloading sequence of a page that is left: beforeunload, pagehide, visibilitychange (hidden), unload. A page that was never shown (no pageshow), or that was unloaded before, or that cannot run scripts, hears nothing.

떠나는 페이지의 언로드 순서를 실행한다: beforeunload, pagehide, visibilitychange(hidden), unload. 한 번도 보이지 않은 페이지 (pageshow 없음), 전에 언로드한 페이지, 스크립트를 실행할 수 없는 페이지는 아무것도 듣지 않는다.

Returns:
the text of the confirmation that beforeunload asked for (the empty string if it only cancelled the event), or null if it did not ask / beforeunload 가 요청한 확인 문구(이벤트만 취소했으면 빈 문자열). 요청하지 않았으면 null
