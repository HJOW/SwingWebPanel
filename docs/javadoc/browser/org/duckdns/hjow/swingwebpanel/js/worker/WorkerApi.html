org.duckdns.hjow.swingwebpanel.js.worker
Class WorkerApi

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.worker.WorkerApi

public final class WorkerApi
extends java.lang.Object

The worker API of one page (plan item P20-09-b; HTML Standard "Web workers", checked on 2026-11-17): it installs Worker (new Worker(url [, {name, type}]), postMessage, terminate, onmessage, onmessageerror, onerror) and BroadcastChannel into the page, keeps the list of the live workers of the page, and terminates all of them when the page ends. A dedicated worker runs the script of a same-origin URL (a SecurityError otherwise) in a realm and on a thread of its own, see WorkerScope. At most WorkerLimits.MAX_WORKERS_PER_PAGE workers can live at the same time. SharedWorker (new SharedWorker(url [, name | options]), port) connects the page to the shared worker of the component that has the same origin, script URL and name, which it starts if it does not exist; the shared worker lives as long as one page owns it, see SharedEntry and WorkerRegistry. Both worker constructors accept classic and module entries. Nested workers and blob: or data: worker scripts are outside the supported URL policy.

Page life cycle: terminateAll() (called when the page is asked to stop: navigation, clean(), dispose(), JavaScript switched off) terminates every worker at once without waiting; dispose() forgets them afterwards.

한 페이지의 worker API(계획 P20-09-b. HTML 표준 "Web workers", 2026-11-17 확인): 페이지에 Worker(new Worker(url [, {name, type}]), postMessage, terminate, onmessage, onmessageerror, onerror)와 BroadcastChannel 을 설치하고, 페이지의 살아 있는 worker 목록을 관리하며, 페이지가 끝나면 모두 종료한다. 전용 worker 는 같은 오리진 URL의 스크립트를(아니면 SecurityError) 자기 realm 과 스레드에서 실행한다(WorkerScope 참고). 동시에 살아 있는 worker 는 최대 WorkerLimits.MAX_WORKERS_PER_PAGE 개이다. SharedWorker(new SharedWorker(url [, 이름 | 옵션]), port)는 페이지를 컴포넌트에서 오리진, 스크립트 URL, 이름이 같은 공유 worker 에 연결하며(없으면 시작한다), 공유 worker 는 페이지 하나라도 소유하는 동안 산다(SharedEntry, WorkerRegistry 참고). 두 생성자는 일반 스크립트와 모듈 스크립트를 받는다. worker 안의 worker와 blob:·data: worker 스크립트는 지원 범위 밖이다.

페이지 수명: terminateAll()(페이지에 중지를 요청할 때 호출: 이동, clean(), dispose(), JavaScript 끄기)는 기다리지 않고 모든 worker 를 즉시 종료하고, dispose() 는 그 뒤에 이들을 잊는다.

terminateAll

public void terminateAll()
Terminates every worker of the page at once, without waiting for anything, from any thread (also from the EDT while a script runs): the scripts of the workers are cancelled, their requests are cancelled and their threads end. No worker can be created afterwards and the broadcast channels are dropped.

페이지의 모든 worker 를 아무것도 기다리지 않고 어느 스레드에서나(스크립트가 실행되는 동안의 EDT 에서도) 즉시 종료한다: worker 의 스크립트와 요청이 취소되고 스레드가 끝난다. 그 뒤에는 worker 를 만들 수 없고 브로드캐스트 채널은 버려진다.
