Class ProgressEvent

public final class ProgressEvent
extends Event

The Java side of a ProgressEvent (XMLHttpRequest Standard, section 5): an event that tells how many bytes of a known or unknown total were transferred. The events of XMLHttpRequest (loadstart, progress, load, error, abort, timeout, loadend) use this class; scripts can also create their own.

ProgressEvent 의 Java 쪽(XMLHttpRequest 표준 5절): 알려진 또는 모르는 전체 중 몇 바이트를 전송했는지 알리는 이벤트. XMLHttpRequest 의 이벤트(loadstart, progress, load, error, abort, timeout, loadend)가 이 클래스를 쓰며 스크립트가 직접 만들 수도 있다.
