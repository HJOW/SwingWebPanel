Class Window

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.host.Window

public final class Window
extends EventTarget

The Java side of the window object: an event target that is the end of every document event path (the DOM calls it through Document.setEventWindow(EventTarget)). In scripts the window is the global object of the realm; the bridge maps this Java object to it, so event.currentTarget === window holds.

window 객체의 Java 쪽: 모든 문서 이벤트 경로의 끝인 이벤트 대상이다(DOM 이 Document.setEventWindow(EventTarget) 로 이를 부른다). 스크립트에서 window 는 realm 의 전역 객체이며 브리지가 이 Java 객체를 그것에 대응시키므로 event.currentTarget === window 가 성립한다.
