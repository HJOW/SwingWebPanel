Interface CorsImageRequestSource

All Superinterfaces:
ImageRequestSource
public interface CorsImageRequestSource
extends ImageRequestSource

An ImageRequestSource that also fetches images in CORS mode, for an img element with a crossorigin attribute: a cross-origin request carries the Origin header, the cookies follow the mode, and a response that does not grant access to the document ends the load with an error (so the error event fires and a canvas never gets the pixels), while a granted image can be read back without tainting a canvas. A host that offers only the plain interface loads such images without CORS.

crossorigin 속성이 있는 img 요소를 위해 이미지를 CORS 모드로도 가져오는 ImageRequestSource: 교차 오리진 요청은 Origin 헤더를 싣고, 쿠키는 모드를 따르며, 문서에 접근을 허용하지 않는 응답은 로드를 오류로 끝내고(그래서 error 이벤트가 나고 캔버스는 화소를 받지 못한다) 허용된 이미지는 캔버스를 오염시키지 않고 다시 읽을 수 있다. 일반 인터페이스만 주는 호스트는 그런 이미지를 CORS 없이 로드한다.

request

void request(java.lang.String absoluteUrl,
             java.lang.String crossOrigin,
             ImageRequestSource.Callback callback)
Starts loading an image in CORS mode, or joins a load of the same URL and mode that is running or has finished. The callback is called exactly once unless the page is closed first.

이미지 로드를 CORS 모드로 시작한다. 같은 URL 과 모드의 진행 중이거나 끝난 로드가 있으면 거기에 합류한다. 그 전에 페이지가 닫히지 않으면 콜백은 정확히 한 번 호출된다.

Parameters:
absoluteUrl - the absolute URL of the image / 이미지의 절대 URL
crossOrigin - anonymous (cookies only for the origin of the document) or use-credentials (cookies for every origin, the response must allow credentials) / anonymous(쿠키는 문서의 오리진에만) 또는 use-credentials(모든 오리진에 쿠키, 응답이 자격 증명을 허용해야 함)
callback - the receiver / 받는 쪽
