done

void done(byte[] data,
          java.lang.String mimeType,
          java.lang.String error)
Reports the result, exactly once unless the request was cancelled or the page was closed. It may be called on any thread, also before MediaRequestSource.request(String, Callback) returned.

결과를 알린다. 요청이 취소되었거나 페이지가 닫히지 않는 한 정확히 한 번 호출된다. 어느 스레드에서나, 그리고 MediaRequestSource.request(String, Callback) 가 돌아오기 전에도 호출될 수 있다.

Parameters:
data - the encoded resource, null on failure / 인코딩된 리소스. 실패하면 null
mimeType - the MIME type that the server declared (without parameters is fine), may be null / 서버가 선언한 MIME 타입(매개변수 없어도 됨). null 가능
error - null on success, else a short description of the failure (network error, status code, blocked address, too large) / 성공하면 null, 아니면 실패의 짧은 설명(네트워크 오류, 상태 코드, 차단된 주소, 너무 큼)
