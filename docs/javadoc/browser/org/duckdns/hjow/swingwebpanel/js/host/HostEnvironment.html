org.duckdns.hjow.swingwebpanel.js.host
Class HostEnvironment

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.HostEnvironment

public abstract class HostEnvironment
extends java.lang.Object

What a page needs from the component around it: the user agent, how to fetch scripts, timers, cookies, storage, the viewport size, and the hooks for navigation and repaint requests. Every method has a harmless default, so a test or an embedder overrides only what it provides. The component creates one environment per page.

페이지가 주변 컴포넌트에 필요로 하는 것: User-Agent, 스크립트를 가져오는 방법, 타이머, 쿠키, 저장소, 뷰포트 크기, 이동과 다시 그리기 요청용 훅. 모든 메서드에 무해한 기본값이 있으므로 시험이나 임베더는 제공하는 것만 재정의한다. 컴포넌트가 페이지마다 환경 하나를 만든다.
