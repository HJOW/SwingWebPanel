Package org.duckdns.hjow.swingwebpanel.js.host.canvas

The HTML Canvas 2D API (plan items P20-05, P00-08): the bitmap of a canvas element, the drawing engine behind CanvasRenderingContext2D (pure Java2D on a BufferedImage, no GPU), the JavaScript bindings of HTMLCanvasElement, CanvasRenderingContext2D, CanvasGradient, CanvasPattern, ImageData and TextMetrics, and the immutable snapshots that the renderer paints.

See:
          Description

Interface Summary
CanvasHost What the canvas bindings need from the page that owns them: the realm, the DOM bridge, the document, the style resolver (for the font size and color of a canvas element), the pixels of the images that scripts draw, the notification that a canvas changed, and the state of the page.
CanvasSurface.Listener The receiver of change notifications.
 

Class Summary
CanvasBindings The canvas of one page (plan items P20-05, P00-08): it installs the script interface of HTMLCanvasElement (width, height, getContext, toDataURL, toBlob), CanvasRenderingContext2D, CanvasGradient, CanvasPattern, TextMetrics and ImageData, owns the CanvasSurface of every canvas element that a script touched, and answers the renderer as a CanvasSource.
CanvasBitmap The pixel store of a canvas: width * height pixels of non-premultiplied 0xAARRGGBB in one int[], a BufferedImage of type TYPE_INT_ARGB that shares that array, and the Graphics2D of the image (created once, configured for antialiasing).
CanvasColors Parses and serializes the colors of the canvas API with the CSS color parser of the project: named colors, #rgb, #rrggbb, #rgba, #rrggbbaa, rgb(), rgba(), hsl(), hsla() and the other forms that CssColor knows.
CanvasEncoder Serializes canvas pixels to a file for toDataURL() and toBlob() with the public javax.imageio API: PNG (the default and the fallback for every other type) and JPEG (transparent pixels become black, as in browsers; the quality is a number from 0 to 1, default 0.92).
CanvasEncoder.Encoded The encoded file.
CanvasFont A parsed value of the font attribute of the 2D context (the CSS font shorthand without line height): optional style (italic, oblique), variant (small-caps, parsed and ignored), weight (bold, bolder, lighter, 100 to 900), stretch keywords (parsed and ignored), a size and a family list.
CanvasGradient A CanvasGradient: a linear gradient along a line, a radial (two-circle, cone) gradient or a conic gradient around a center, with color stops (the conic form is CanvasGradient.conic(double, double, double): the offset is the clockwise angle from the start angle as a fraction of a turn).
CanvasImage The pixels of an image source that drawImage() and createPattern() read: a decoded img, another canvas or a copy of the canvas itself.
CanvasLimits The size limits of canvas bitmaps and the default size of a canvas element.
CanvasPattern A CanvasPattern: a snapshot of an image that is repeated in x, in y, in both or in neither direction.
CanvasSurface The drawing surface of one canvas element: its bitmap, its 2D context (created by the first getContext("2d")), the origin-clean flag and the change tracking for the renderer.
Composites The compositing operators of globalCompositeOperation: the Porter-Duff operators (source-over, source-in, source-out, source-atop, destination-over, destination-in, destination-out, destination-atop, xor, copy), lighter (plus), the separable blend modes (multiply, screen, overlay, darken, lighten, color-dodge, color-burn, hard-light, soft-light, difference, exclusion) and the non-separable ones (hue, saturation, color, luminosity), computed pixel by pixel on non-premultiplied ARGB values with the formulas of the Compositing and Blending specification.
Context2D The drawing engine behind CanvasRenderingContext2D: the state stack, the transformation matrix, the current path, filling, stroking (with dashes, caps and joins), clipping with antialiased masks, rectangles, text, images, pixel data, shadows with Gaussian blur and all 26 compositing operators.
Context2D.RawImage Pixel data read from the bitmap: its size and the RGBA bytes.
ImageBitmapValue An ImageBitmap value (HTML Standard 8.11.2): an immutable picture, a copy of the pixels of its source (an image, a canvas, an ImageData, a Blob or another bitmap) cropped, scaled and flipped as createImageBitmap() asked, together with the origin-clean flag that taints a canvas which draws it.
ImageDataValue An ImageData value: a width, a height and the RGBA bytes (width * height * 4) that the data attribute shows as a Uint8ClampedArray.
OffscreenCanvasValue An OffscreenCanvas value (HTML Standard 4.12.5.3): a bitmap and its 2D context without a place in the document.
Path2DValue A Path2D value: a path that is not tied to a context.
TextMetricsValue The result of measureText(): a TextMetrics value.
 

Package org.duckdns.hjow.swingwebpanel.js.host.canvas Description

The HTML Canvas 2D API (plan items P20-05, P00-08): the bitmap of a canvas element, the drawing engine behind CanvasRenderingContext2D (pure Java2D on a BufferedImage, no GPU), the JavaScript bindings of HTMLCanvasElement, CanvasRenderingContext2D, CanvasGradient, CanvasPattern, ImageData and TextMetrics, and the immutable snapshots that the renderer paints. WebGL, WebGL2 and WebGPU are not supported: getContext answers null for them.

HTML Canvas 2D API(계획 P20-05, P00-08): canvas 요소의 비트맵, CanvasRenderingContext2D 뒤의 그리기 엔진(GPU 없이 BufferedImage 위의 순수 Java2D), HTMLCanvasElement, CanvasRenderingContext2D, CanvasGradient, CanvasPattern, ImageData, TextMetrics 의 JavaScript 연결, 렌더러가 그리는 불변 스냅샷. WebGL, WebGL2, WebGPU 는 지원하지 않으며 getContext 는 이들에 null 로 답한다.
