Class CanvasPattern

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasPattern

public final class CanvasPattern
extends java.lang.Object

A CanvasPattern: a snapshot of an image that is repeated in x, in y, in both or in neither direction. Like a gradient it lives in the coordinate space that is current when it is painted. The pixels are copied when the pattern is created, so later changes of the source canvas do not change the pattern. A pattern made from an image that is not origin-clean taints every canvas that paints with it.

CanvasPattern: x 방향, y 방향, 양방향 또는 반복 없이 되풀이되는 이미지의 스냅샷. 그라디언트처럼 칠할 때의 좌표계에 놓인다. 화소는 패턴을 만들 때 복사하므로 원본 캔버스가 나중에 바뀌어도 패턴은 바뀌지 않는다. origin-clean 이 아닌 이미지로 만든 패턴은 그것으로 칠하는 모든 캔버스를 오염시킨다.

Sets the transformation of the pattern itself (CanvasPattern.setTransform()): it is applied to the pattern space before the current transformation matrix of the painting, so it moves, scales or rotates the tiles. The initial value is the identity. A matrix with a NaN or infinite element is stored but nothing is painted with it.

패턴 자신의 변환을 정한다(CanvasPattern.setTransform()): 칠할 때의 현재 변환 행렬보다 먼저 패턴 좌표계에 적용되므로 타일을 옮기고, 키우고, 돌린다. 처음 값은 단위 행렬이다. NaN 이나 무한대 요소가 있는 행렬은 저장하지만 그것으로는 아무것도 칠하지 않는다.
