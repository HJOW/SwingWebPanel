Called when the module and its imports were evaluated (also when the module threw while it ran: that is reported to the console and the promise resolves), or when the call failed.

모듈과 그것이 import 하는 것을 평가했을 때(모듈이 실행 중 던졌어도 마찬가지: 콘솔에 보고하고 프라미스는 resolve 된다), 또는 호출이 실패했을 때 불린다.

Parameters:
errorName - how the promise is rejected, or null if it resolves: AbortError (a fetch failure: network, scheme, origin policy, MIME type) and InvalidStateError are DOMException names; SyntaxError (a syntax error or a module that cannot be linked) and TypeError (a specifier that cannot be resolved) are plain error objects of that kind / 프라미스를 어떻게 reject 하는지. resolve 되면 null. AbortError(가져오기 실패: 네트워크, 스킴, 오리진 정책, MIME 타입)와 InvalidStateError 는 DOMException 이름이고, SyntaxError(구문 오류, 링크할 수 없는 모듈)와 TypeError(해석할 수 없는 지정자)는 그 종류의 일반 오류 객체이다
message - the message of the error, null on success / 오류 메시지. 성공하면 null
