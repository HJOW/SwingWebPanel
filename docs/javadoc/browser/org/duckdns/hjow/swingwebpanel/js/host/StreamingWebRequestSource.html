Interface StreamingWebRequestSource

public interface StreamingWebRequestSource

The streaming companion of WebRequestSource for requests whose answer is not a finished body but a stream that stays open and is read while it arrives (the event streams of EventSource). A component that implements WebRequestSource also implements this interface when it can stream; a page checks it with instanceof and an EventSource of a page without it fails like a connection that cannot be made. The request goes through the same common request layer as every other page request (User-Agent, extra headers, cookies according to the credentials mode, SSL hook, scheme limits, same-origin policy and CORS, cancellation), but it does not use up one of the few concurrent request slots for as long as it stays open, and it is not read into memory.

WebRequestSource 의 스트리밍 짝. 응답이 끝난 본문이 아니라 열려 있으면서 도착하는 대로 읽는 스트림인 요청(EventSource 의 이벤트 스트림)을 위한 것이다. WebRequestSource 를 구현한 컴포넌트가 스트리밍할 수 있으면 이 인터페이스도 구현하며, 페이지는 instanceof 로 확인한다. 이것이 없는 페이지의 EventSource 는 만들 수 없는 연결처럼 실패한다. 요청은 다른 모든 페이지 요청과 같은 공통 요청 계층(User-Agent, 추가 헤더, 자격 증명 모드에 따른 쿠키, SSL 훅, 스킴 제한, 동일 출처 정책과 CORS, 취소)을 거치지만 열려 있는 동안 소수의 동시 요청 칸 하나를 차지하지 않고 메모리에 읽지도 않는다.
