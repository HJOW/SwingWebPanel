org.duckdns.hjow.swingwebpanel.js.host
Interface PointerService

public interface PointerService

The pointer capture service of a page (W3C Pointer Events, "Pointer capture"): the component keeps the state of the pointer, a script asks for capture through the Element methods setPointerCapture, releasePointerCapture and hasPointerCapture, which the page layer checks against this service. All methods are called on the document queue (the thread that runs the scripts of the page and delivers its input events), so the state needs no locking.

페이지의 포인터 캡처 서비스(W3C Pointer Events, "Pointer capture"). 컴포넌트가 포인터의 상태를 보관하고, 스크립트는 요소의 setPointerCapture, releasePointerCapture, hasPointerCapture 메서드로 캡처를 요청하며, 페이지 계층이 이 서비스에 대어 확인한다. 모든 메서드는 문서 큐(페이지의 스크립트를 실행하고 입력 이벤트를 전달하는 스레드)에서 호출하므로 상태에 잠금이 필요 없다.

setCapture

void setCapture(int pointerId,
                Element element)
Sets the pending pointer capture of a pointer to an element. It has no effect (and no error) when the pointer has no button down or the element is not in the document that the pointer is active in; the capture starts with the next pointer event (gotpointercapture).

포인터의 대기 중인 포인터 캡처를 요소로 정한다. 포인터에 눌린 버튼이 없거나 요소가 포인터가 활성인 문서에 있지 않으면 효과도 오류도 없다. 캡처는 다음 포인터 이벤트와 함께 시작한다(gotpointercapture).
