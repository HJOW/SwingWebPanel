The script interface of Web Animations Level 1 (W3C Working Draft 5 June 2023, https://www.w3.org/TR/2023/WD-web-animations-1-20230605/, plan item P10-08-h): Animation (constructor, id, effect, timeline, startTime, currentTime, playbackRate, playState, replaceState, pending, ready, finished, onfinish, oncancel, onremove, play(), pause(), reverse(), finish(), cancel(), updatePlaybackRate(), persist(), commitStyles()), AnimationEffect (getTiming(), getComputedTiming(), updateTiming()), KeyframeEffect (both constructors, target, pseudoElement, composite, iterationComposite of Level 2 which is stored only, getKeyframes(), setKeyframes()), AnimationTimeline and DocumentTimeline (constructor with originTime), AnimationPlaybackEvent, Element.animate(), Element.getAnimations({subtree}), Document.getAnimations() and document.timeline. The model lives in org.duckdns.hjow.swingwebpanel.css.anim: the binding connects to the WebAnimationSet of the page's AnimationEngine (so the effects reach the computed style and the rendering) and acts as its WebAnimationHost: promises are real promises of the realm, the finish notification steps are microtasks, and the step "update animations and send events" runs in the animation frames of requestAnimationFrame with the same time, followed by a microtask checkpoint and the dispatch of the playback events. All methods run on the thread that owns the page's scripts.

Web Animations Level 1(W3C Working Draft 2023-06-05, 계획 P10-08-h)의 스크립트 인터페이스: Animation(생성자와 모든 속성·메서드), AnimationEffect, KeyframeEffect(두 생성자, Level 2 의 iterationComposite 는 보관만), AnimationTimeline, DocumentTimeline(originTime 생성자), AnimationPlaybackEvent, Element.animate(), Element.getAnimations({subtree}), Document.getAnimations(), document.timeline. 모델은 org.duckdns.hjow.swingwebpanel.css.anim 에 있다: 연결은 페이지의 AnimationEngine 이 가진 WebAnimationSet 에 이어지고(그래서 효과가 계산 스타일과 렌더링에 닿는다) 그 WebAnimationHost 역할을 한다: 프라미스는 realm 의 실제 프라미스, 끝 알림 단계는 마이크로태스크이며, "update animations and send events" 단계는 requestAnimationFrame 의 애니메이션 프레임에서 같은 시각으로 실행되고 마이크로태스크 검사점과 재생 이벤트 전달이 뒤따른다. 모든 메서드는 페이지 스크립트를 소유한 스레드에서 실행된다.
