Package org.duckdns.hjow.swingwebpanel.js.worker

Web Workers and the BroadcastChannel (plan item P20-09-b): a dedicated worker runs a script in a realm of its own, on a thread of its own, with a restricted set of objects (no window, no document, no DOM, no storage), and talks to the page only through messages that are copied with the structured clone algorithm and delivered as tasks of the receiving side.

          Description

Interface Summary
ScriptContext A place where script runs: the page (its realm is owned by the document thread) or a dedicated worker (a realm of its own on a thread of its own).
 

Class Summary
BroadcastChannelTarget The Java side of one BroadcastChannel object (HTML Standard "Broadcasting to other browsing contexts"): a named channel that belongs to one script context.
ChannelPorts The way for other script contexts (the audio worklet of the Web Audio API, for example) to use the channel messaging of this package: it installs the MessagePort interface into the realm of a ScriptContext and creates a channel whose two ends belong to two contexts at once.
ChannelTarget The Java side of a MessageChannel object (HTML Standard "Message channels"): it only holds the two entangled MessagePort objects port1 and port2 that were created together in one context.
PortApi Channel messaging of a script context (HTML Standard "Channel messaging", plan item P20-09-b): installs MessageChannel and MessagePort (postMessage, start, close, onmessage, onmessageerror, the message event) into the realm of a page or of a worker, and offers the steps that window.postMessage and structuredClone of the page need to send ports along with a message.
PortTarget The Java side of one MessagePort object of a script context (HTML Standard "Message ports"): the event target at which the message events of the port are dispatched, bound to the PortCore (the end of the channel) that it shows to the script.
SharedHandle The Java side of a SharedWorker object of a page (HTML Standard "Shared workers and the SharedWorker interface"): it holds the outside port of the connection (port) and is the event target at which the page receives the error event when the shared worker could not be loaded or when the constructor arguments do not fit the shared worker that already exists.
WorkerApi The worker API of one page (plan item P20-09-b; HTML Standard "Web workers", checked on 2026-11-17): it installs Worker (new Worker(url [, {name, type}]), postMessage, terminate, onmessage, onmessageerror, onerror) and BroadcastChannel into the page, keeps the list of the live workers of the page, and terminates all of them when the page ends.
WorkerHandle The Java side of a Worker object of the page (HTML Standard "Web workers", interface Worker): the event target at which the page receives the message events of the worker and its error events, and the handle with which the page posts messages to the worker and terminates it.
WorkerLimits The limits of workers and broadcast channels.
