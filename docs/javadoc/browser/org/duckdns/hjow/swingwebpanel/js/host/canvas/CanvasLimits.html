Class CanvasLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasLimits

public final class CanvasLimits
extends java.lang.Object

The size limits of canvas bitmaps and the default size of a canvas element. A bitmap larger than MAX_DIMENSION on a side, or with more than MAX_PIXELS pixels, is not allocated: such a canvas still has a 2D context but drawing on it is ignored, getImageData throws InvalidStateError and toDataURL answers "data:,". The layout still uses the width and height of the attributes.

캔버스 비트맵의 크기 한도와 canvas 요소의 기본 크기. 한 변이 MAX_DIMENSION 보다 크거나 화소가 MAX_PIXELS 보다 많은 비트맵은 할당하지 않는다: 이런 캔버스에도 2D 컨텍스트는 있지만 그리기는 무시되고, getImageData 는 InvalidStateError 를 던지며, toDataURL 은 "data:," 로 답한다. 레이아웃은 속성의 너비와 높이를 그대로 쓴다.
