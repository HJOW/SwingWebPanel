Class CssomInterfaces

public final class CssomInterfaces
extends java.lang.Object

The script interfaces of the CSS Object Model that wrap the objects of the CSS engine (CSSOM, W3C Working Draft 26 August 2021, https://www.w3.org/TR/cssom-1/): StyleSheet and CSSStyleSheet, MediaList, CSSRuleList, and the rule interfaces CSSRule, CSSStyleRule, CSSGroupingRule, CSSConditionRule, CSSMediaRule, CSSSupportsRule, CSSLayerBlockRule, CSSLayerStatementRule, CSSImportRule, CSSFontFaceRule, CSSKeyframesRule, CSSKeyframeRule and CSSNamespaceRule, and the interfaces of the newer rules CSSContainerRule, CSSScopeRule, CSSStartingStyleRule, CSSPropertyRule, CSSCounterStyleRule, CSSPageRule and CSSMarginRule. A script reaches the very objects that the style resolver reads, so inserting a rule, changing a declaration, the selector, the media or the disabled flag changes the page at once. A rule kind that has no interface of its own (@font-feature-values ...) is a plain CSSRule with its type and cssText. Whether a script may read the rules of a style sheet that came from another origin is decided by the CssomInterfaces.Guard that the page gives (the CSSOM makes such a sheet unreadable). The page-specific parts (document.styleSheets, constructed style sheets, sheet of the elements) are installed by the page.

CSS 엔진의 객체를 감싸는 CSS 객체 모델(CSSOM, W3C 작업 초안 2021-08-26, https://www.w3.org/TR/cssom-1/)의 스크립트 인터페이스: StyleSheet 와 CSSStyleSheet, MediaList, CSSRuleList, 규칙 인터페이스 CSSRule, CSSStyleRule, CSSGroupingRule, CSSConditionRule, CSSMediaRule, CSSSupportsRule, CSSLayerBlockRule, CSSLayerStatementRule, CSSImportRule, CSSFontFaceRule, CSSKeyframesRule, CSSKeyframeRule, CSSNamespaceRule. 스크립트는 스타일 리졸버가 읽는 바로 그 객체에 닿으므로 규칙을 넣거나 선언, 선택자, 미디어, 비활성 플래그를 바꾸면 페이지가 즉시 바뀐다. 새 규칙의 인터페이스 CSSContainerRule, CSSScopeRule, CSSStartingStyleRule, CSSPropertyRule, CSSCounterStyleRule, CSSPageRule, CSSMarginRule 도 있다. 자신의 인터페이스가 없는 규칙 종류(@font-feature-values 등)는 type 과 cssText 만 가진 일반 CSSRule 이다. 다른 오리진에서 온 스타일 시트의 규칙을 스크립트가 읽을 수 있는지는 페이지가 주는 CssomInterfaces.Guard 가 정한다(CSSOM 은 그런 시트를 읽을 수 없게 한다). 페이지에 따라 달라지는 부분(document.styleSheets, 생성 스타일 시트, 요소의 sheet)은 페이지가 설치한다.
