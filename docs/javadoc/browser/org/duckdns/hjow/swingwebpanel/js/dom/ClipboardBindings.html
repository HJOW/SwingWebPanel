Class ClipboardBindings

java.lang.Object

public final class ClipboardBindings
extends java.lang.Object

The JavaScript interfaces of the clipboard events (plan item P11-08): ClipboardEvent (clipboardData, the events copy, cut and paste) and the clipboard part of DataTransfer (getData, setData, clearData, types). The component fires copy when the user copies the selection; a listener that calls setData and preventDefault puts its own data on the clipboard. Files, items and the drag and drop members of DataTransfer are not part of this interface (drag and drop is plan item P20-06).

클립보드 이벤트의 JavaScript 인터페이스(계획 P11-08): ClipboardEvent(clipboardData, copy, cut, paste 이벤트)와 DataTransfer 의 클립보드 부분(getData, setData, clearData, types). 컴포넌트는 사용자가 선택을 복사할 때 copy 를 보내며, setData 와 preventDefault 를 부르는 리스너는 자기 데이터를 클립보드에 넣는다. 파일, 항목, DataTransfer 의 끌어다 놓기 멤버는 이 인터페이스에 없다(끌어다 놓기는 계획 P20-06).
