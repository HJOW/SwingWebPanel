Interface WebApis.Host

All Known Subinterfaces:
WebApis.ObjectUrlHost
Enclosing class:
WebApis
public static interface WebApis.Host

What these APIs need from the script context that they are installed in: a page or a worker (plan item P20-09-b). Everything the request APIs used to read from the page goes through this interface, so the same code runs in a dedicated worker, which has its own realm and its own thread but no document.

이 API가 설치되는 스크립트 문맥(페이지 또는 worker. 계획 P20-09-b)에서 필요로 하는 것. 요청 API가 페이지에서 읽던 모든 것이 이 인터페이스를 거치므로, 같은 코드가 자기 realm 과 스레드는 있으나 문서가 없는 전용 worker 에서도 실행된다.
