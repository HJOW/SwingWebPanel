org.duckdns.hjow.swingwebpanel.js.host.canvas
Class CanvasColors

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasColors

public final class CanvasColors
extends java.lang.Object

Parses and serializes the colors of the canvas API with the CSS color parser of the project: named colors, #rgb, #rrggbb, #rgba, #rrggbbaa, rgb(), rgba(), hsl(), hsla() and the other forms that CssColor knows. currentcolor is the color of the canvas element, which the caller passes in. The serialization follows the rule of the canvas specification: an opaque color is #rrggbb in lower case, any other color is rgba(r, g, b, a).

프로젝트의 CSS 색 파서로 캔버스 API 의 색을 해석하고 직렬화한다: 이름 있는 색, #rgb, #rrggbb, #rgba, #rrggbbaa, rgb(), rgba(), hsl(), hsla() 와 CssColor 가 아는 그 밖의 형식. currentcolor 는 캔버스 요소의 색이며 호출자가 넘긴다. 직렬화는 캔버스 규격의 규칙을 따른다: 불투명한 색은 소문자 #rrggbb, 그 밖의 색은 rgba(r, g, b, a) 이다.
