public final class DatasetObject
extends org.duckdns.hjow.swingwebpanel.js.JsObject

The dataset object of an element (DOMStringMap): a property fooBar stands for the content attribute data-foo-bar. Reading gives the attribute value, assigning stores a string, delete removes the attribute and the property keys are the converted attribute names.

요소의 dataset 객체(DOMStringMap): 프로퍼티 fooBar 는 콘텐츠 속성 data-foo-bar 를 나타낸다. 읽으면 속성 값이 나오고, 대입하면 문자열을 저장하며, delete 는 속성을 지우고, 프로퍼티 키는 변환한 속성 이름이다.
