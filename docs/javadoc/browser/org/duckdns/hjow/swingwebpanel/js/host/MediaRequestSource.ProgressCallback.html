public static interface MediaRequestSource.ProgressCallback
extends MediaRequestSource.Callback

A receiver that is also told how far the transfer has come (plan item P18-08: the progress and stalled events of the media element). A request whose callback is not a ProgressCallback simply reports the end.

전송이 어디까지 왔는지도 알려 받는 받는 쪽(계획 P18-08: 미디어 요소의 progress, stalled 이벤트). 콜백이 ProgressCallback 이 아닌 요청은 끝만 알린다.

Method Detail

progress

void progress(long received,
              long total)
Reports the bytes that arrived so far, while the resource is on its way. It is called on the thread that fetches, possibly many times, never after MediaRequestSource.Callback.done(byte[], String, String) and never after the request was cancelled or the page closed.

리소스가 오는 동안 지금까지 도착한 바이트를 알린다. 가져오는 스레드에서, 여러 번 호출될 수 있으며, MediaRequestSource.Callback.done(byte[], String, String) 뒤에는 호출되지 않고 요청이 취소되었거나 페이지가 닫힌 뒤에도 호출되지 않는다.

Parameters:
received - the bytes received so far / 지금까지 받은 바이트
total - the expected total, or -1 if not known / 예상 전체 크기. 모르면 -1
