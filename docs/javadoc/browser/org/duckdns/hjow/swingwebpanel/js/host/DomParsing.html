DOMParser and XMLSerializer of a page (plan item P20-04; HTML Standard "DOMParser" and DOM Parsing and Serialization "XML Serialization"). They are tools for scripts: they make new documents and markup text, and they never change the document of the page and never touch the source text that getContent() returns.

  • new DOMParser().parseFromString(text, type): text/html parses with the HTML parser (scripting disabled, so scripts do not run and noscript content is parsed as markup); text/xml, application/xml, application/xhtml+xml and image/svg+xml parse with the XML parser of the component (external entities and external DTDs are never fetched); if the text is not well-formed XML the result is a document whose only child is a parsererror element in the namespace http://www.mozilla.org/newlayout/xml/parsererror.xml that holds the position and message of the error. Any other type, and a missing argument, is a TypeError. The URL of the new document is the URL of the page.
  • new XMLSerializer().serializeToString(node): the XML serialization of XmlSerializer.

페이지의 DOMParser 와 XMLSerializer(계획 P20-04, HTML 표준 "DOMParser", DOM Parsing and Serialization "XML Serialization"). 스크립트가 쓰는 도구이며 새 문서와 마크업 텍스트를 만들 뿐 페이지의 문서를 바꾸거나 getContent() 가 반환하는 원문을 건드리지 않는다.

  • new DOMParser().parseFromString(text, type): text/html 은 HTML 파서로 해석한다(스크립트 비활성이므로 스크립트는 실행되지 않고 noscript 내용도 마크업으로 해석한다). text/xml, application/xml, application/xhtml+xml, image/svg+xml 은 컴포넌트의 XML 파서로 해석한다(외부 엔티티와 외부 DTD 는 가져오지 않는다). 텍스트가 well-formed XML 이 아니면 결과는 오류의 위치와 메시지를 담은 http://www.mozilla.org/newlayout/xml/parsererror.xml 네임스페이스의 parsererror 요소 하나만 자식으로 가진 문서이다. 그 밖의 type 과 인수 누락은 TypeError. 새 문서의 URL은 페이지의 URL이다.
  • new XMLSerializer().serializeToString(node): XmlSerializer 의 XML 직렬화.
