public interface ImageRequestSource

The service through which a page asks the component to load the images of its img elements (plan item P18-05). The component fetches and decodes the image with the common request layer and keeps the result in the cache that the renderer paints from, so loading an image for the load event and painting it share one fetch. The page only learns whether the image became available and its natural size; it never receives the pixels. A page without such a service (a test host) simply never loads images.

페이지가 img 요소의 이미지를 컴포넌트에 가져오게 하는 서비스(계획 P18-05). 컴포넌트가 공통 요청 계층으로 이미지를 가져와 디코딩하고 결과를 렌더러가 그리는 캐시에 보관하므로, load 이벤트를 위한 로드와 그리기가 한 번의 가져오기를 공유한다. 페이지는 이미지를 쓸 수 있게 되었는지와 자연 크기만 알고 픽셀은 받지 않는다. 이 서비스가 없는 페이지(시험 호스트)는 이미지를 로드하지 않는다.

Starts loading an image, or joins a load of the same URL that is running or has finished. The callback is called exactly once unless the page is closed first.

이미지 로드를 시작한다. 같은 URL 의 진행 중이거나 끝난 로드가 있으면 거기에 합류한다. 그 전에 페이지가 닫히지 않으면 콜백은 정확히 한 번 호출된다.
