Package org.duckdns.hjow.swingwebpanel.js.host.structured

Interface Summary
StructuredClone.TransferHandler The hook through which objects other than ArrayBuffers (for example a MessagePort) are put in a transfer list.
 

Class Summary
ClonedValue The serialized form of a script value made by StructuredClone.serialize(org.duckdns.hjow.swingwebpanel.js.JsRealm, org.duckdns.hjow.swingwebpanel.js.JsValue): an immutable tree of Java data that belongs to no realm.
HostMessageValues Copies host message data without a script realm or a reference to a live Java value.
HostMessageValues.JavaMessage A copied page message and its estimated footprint. / 페이지 메시지 복사본과 예상 점유 크기.
SharedMemoryScope The agent-cluster and origin identity used for sharing buffers across browser realms.
StructuredClone The structured clone algorithm of the HTML Standard (StructuredSerialize and StructuredDeserialize, section "Safe passing of structured data"): a script value of one realm is turned into a realm independent, immutable Java tree (ClonedValue), and that tree is turned into a fresh value of the same or another realm.
 

Exception Summary
StructuredCloneException Thrown when a value cannot be copied by the structured clone algorithm (a function, a symbol, a DOM node, a Proxy ..., a structure that is too deep or too large, or a bad transfer list).
