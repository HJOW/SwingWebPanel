Class MatrixBindings

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.MatrixBindings

public final class MatrixBindings
extends java.lang.Object

The matrix interfaces of the Geometry Interfaces Module Level 1 (section 6, https://www.w3.org/TR/geometry-1/, read 2026-11-17): DOMMatrixReadOnly and DOMMatrix with the sixteen elements m11 to m44 and the aliases a to f, is2D, isIdentity, the constructors (nothing, a CSS transform list string, a list of 6 or 16 numbers), fromMatrix(), fromFloat32Array(), fromFloat64Array(), the immutable transformations (translate, scale, scaleNonUniform, scale3d, rotate, rotateFromVector, rotateAxisAngle, skewX, skewY, multiply, flipX, flipY, inverse), transformPoint(), toFloat32Array(), toFloat64Array(), the stringifier and toJSON(), and on DOMMatrix the mutable transformations (multiplySelf, preMultiplySelf, translateSelf ... invertSelf) and setMatrixValue(). It also adds matrixTransform() to DOMPointReadOnly, and the legacy names SVGMatrix and WebKitCSSMatrix for DOMMatrix. The dictionary arguments (DOMMatrixInit) accept any object with the members, among them another matrix. There is no 3D rendering: 3D values are stored, multiplied and inverted. The arithmetic is in DomMatrix, the string syntax in DomMatrixParser.

Geometry Interfaces Module Level 1 의 행렬 인터페이스(6 절, https://www.w3.org/TR/geometry-1/, 조회 2026-11-17): 열여섯 요소 m11 ~ m44 와 별칭 a ~ f, is2D, isIdentity, 생성자(인수 없음, CSS 변환 목록 문자열, 숫자 6개 또는 16개 목록), fromMatrix(), fromFloat32Array(), fromFloat64Array(), 새 행렬을 돌려주는 변환(translate, scale, scaleNonUniform, scale3d, rotate, rotateFromVector, rotateAxisAngle, skewX, skewY, multiply, flipX, flipY, inverse), transformPoint(), toFloat32Array(), toFloat64Array(), 문자열 변환, toJSON(), 그리고 DOMMatrix 의 자기 자신을 바꾸는 변환(multiplySelf, preMultiplySelf, translateSelf ... invertSelf)과 setMatrixValue(). DOMPointReadOnly 에 matrixTransform() 을 더하고 DOMMatrix 의 옛 이름 SVGMatrix, WebKitCSSMatrix 도 정의한다. 사전 인수 (DOMMatrixInit)는 멤버를 가진 아무 객체(다른 행렬 포함)나 받는다. 3D 그리기는 없다: 3D 값은 저장, 곱셈, 역행렬만 한다. 계산은 DomMatrix, 문자열 문법은 DomMatrixParser 에 있다.

fromInit2D

public static DomMatrix fromInit2D(org.duckdns.hjow.swingwebpanel.js.JsValue v)
Creates a matrix from a DOMMatrix2DInit dictionary (an object with a to f or m11, m12, m21, m22, m41, m42): "validate and fixup (2D)" of section 6.1. An a and an m11 (and the other pairs) that are both present must be the same value (SameValueZero), else it is a TypeError. The members are read in the order of the specification (alphabetical). Another matrix is a valid argument. Used by the canvas (setTransform, addPath, CanvasPattern.setTransform).

DOMMatrix2DInit 사전(a ~ f 또는 m11, m12, m21, m22, m41, m42 를 가진 객체)으로 행렬을 만든다: 6.1 절의 "validate and fixup (2D)". a 와 m11(다른 쌍도) 이 둘 다 있으면 같은 값 (SameValueZero)이어야 하고 아니면 TypeError 이다. 멤버는 규격의 순서(사전순)로 읽는다. 다른 행렬도 올바른 인수이다. 캔버스(setTransform, addPath, CanvasPattern.setTransform)가 쓴다.

Parameters:
v - the dictionary argument (undefined is the identity) / 사전 인수(undefined 는 단위 행렬)

the 2D matrix / 2D 행렬

fromInit

public static DomMatrix fromInit(org.duckdns.hjow.swingwebpanel.js.JsValue v)
Creates a matrix from a DOMMatrixInit dictionary: "validate and fixup" of section 6.1 followed by "create from the dictionary" of section 6.3. A 3D member that is not the identity value, or is2D: false, makes the matrix 3D; a 3D member together with is2D: true is a TypeError.

DOMMatrixInit 사전으로 행렬을 만든다: 6.1 절의 "validate and fixup" 다음에 6.3 절의 "create from the dictionary". 단위 행렬의 값이 아닌 3D 멤버나 is2D: false 는 행렬을 3D 로 만들고, 3D 멤버와 is2D: true 가 함께 있으면 TypeError 이다.
