Class ClonedValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.structured.ClonedValue

public final class ClonedValue
extends java.lang.Object

The serialized form of a script value made by StructuredClone.serialize(org.duckdns.hjow.swingwebpanel.js.JsRealm, org.duckdns.hjow.swingwebpanel.js.JsValue): an immutable tree of Java data that belongs to no realm. Primitive values are stored as Java values, objects as numbered cells (so cycles and shared references need no Java object cycles). Ordinary data can be stored for later deserialization. A shared buffer cell holds a reference to shared storage and requires a compatible receiving scope.

StructuredClone.serialize(org.duckdns.hjow.swingwebpanel.js.JsRealm, org.duckdns.hjow.swingwebpanel.js.JsValue) 가 만든 스크립트 값의 직렬화된 형태: 어떤 realm 에도 속하지 않는 Java 데이터의 불변 트리. 원시 값은 Java 값으로, 객체는 번호가 붙은 칸으로 저장한다. 일반 데이터는 나중에 역직렬화할 수 있다. 공유 버퍼 칸은 공유 저장소 참조를 간직하며 호환되는 수신 범위에서만 복원할 수 있다.
