public class HostObject
extends org.duckdns.hjow.swingwebpanel.js.JsObject

The JavaScript object that stands for one Java host object (a DOM node, an event, a collection ...). It keeps the Java target and tells the bridge when it receives own properties, because a wrapper that holds script-defined data must stay alive as long as its target (the wrapper cache holds wrappers weakly otherwise). Wrappers are created only by DomBridge; scripts can never reach the Java class.

Java 호스트 객체(DOM 노드, 이벤트, 컬렉션 등) 하나를 나타내는 JavaScript 객체. Java 대상을 보관하고, 자체 프로퍼티를 받으면 브리지에 알린다. 스크립트가 정의한 데이터를 가진 래퍼는 대상과 같은 기간 살아 있어야 하기 때문이다(래퍼 캐시는 그 밖의 경우 래퍼를 약하게 보관한다). 래퍼는 DomBridge 만 만들며 스크립트는 Java 클래스에 접근할 수 없다.
