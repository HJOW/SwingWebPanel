public final class IndexedObject
extends HostObject

A wrapper for list-like host objects (NodeList, HTMLCollection, NamedNodeMap, DOMTokenList): integer keys read the live list, an optional named lookup serves keys such as element ids, and everything else is an ordinary property (including the prototype's length and item). Indexed properties are read-only, enumerable and configurable as WebIDL requires; writes and deletes of them are ignored.

목록 형태의 호스트 객체(NodeList, HTMLCollection, NamedNodeMap, DOMTokenList)의 래퍼: 정수 키는 살아 있는 목록을 읽고, 선택적인 이름 조회가 요소 id 같은 키를 처리하며, 나머지는 일반 프로퍼티(프로토타입의 length 와 item 포함)이다. 인덱스 프로퍼티는 WebIDL 요구대로 읽기 전용, 열거 가능, 설정 가능이며 쓰기와 삭제는 무시한다.
