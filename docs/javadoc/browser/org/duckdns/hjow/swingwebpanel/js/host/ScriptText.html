Class ScriptText

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.ScriptText

public final class ScriptText
extends java.lang.Object

The text of a fetched script together with the URL that finally served it. The final URL differs from the requested one after a redirect, and relative specifiers inside a module resolve against it (the module's base URL), while the module keeps the requested URL as its identity in the module map.

가져온 스크립트의 텍스트와 그것을 최종적으로 제공한 URL. 최종 URL은 리디렉션 뒤에는 요청한 URL과 다르며, 모듈 안의 상대 지정자는 이 URL (모듈의 기준 URL)을 기준으로 해석한다. 모듈은 모듈 맵에서 요청한 URL을 자기 식별자로 유지한다.
