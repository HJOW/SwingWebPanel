Package org.duckdns.hjow.swingwebpanel.js.host.webaudio.worklet

The audio worklet of the Web Audio API (plan item P25-06; Web Audio API 1.0 1.32 and the HTML Worklets model): a script realm of its own, WorkletScope, that has no DOM and no window, loads ES2015 modules through the request layer of the component and runs the process() method of the AudioWorkletProcessor classes that the modules register, on the rendering thread of the audio context, through the engine node AudioWorkletNode.

Interface Summary
WorkletHost What a WorkletScope needs from the page that owns it: the page (the environment for the request layer, the console, the address that relative module URLs resolve against) and the way to run something as a task of the page, on the thread that owns the page's script realm.
WorkletScope.Completion Told on the page, as a task of the page, how a call of addModule() ended.
 

Class Summary
WorkletLimits The limits of the audio worklet.
WorkletScope The AudioWorkletGlobalScope of one audio context and everything that runs in it (Web Audio API 1.0, 1.32; HTML Worklets): a script realm of its own with the built-in objects of ECMAScript 2015, the channel messaging and registerProcessor() (see WorkletGlobals), but no DOM and no window; it loads ES2015 modules for audioWorklet.addModule(), creates the AudioWorkletProcessor instance of every AudioWorkletNode and calls its process() method in every render quantum.
 

Package org.duckdns.hjow.swingwebpanel.js.host.webaudio.worklet Description

The audio worklet of the Web Audio API (plan item P25-06; Web Audio API 1.0 1.32 and the HTML Worklets model): a script realm of its own, WorkletScope, that has no DOM and no window, loads ES2015 modules through the request layer of the component and runs the process() method of the AudioWorkletProcessor classes that the modules register, on the rendering thread of the audio context, through the engine node AudioWorkletNode. The page side (AudioWorklet, AudioWorkletNode) is in org.duckdns.hjow.swingwebpanel.js.host.webaudio.

Web Audio API 의 오디오 worklet(계획 P25-06. Web Audio API 1.0 1.32 와 HTML Worklets 모델): DOM 도 window 도 없는 자기만의 스크립트 realm WorkletScope. 컴포넌트의 요청 계층으로 ES2015 모듈을 불러오고, 모듈이 등록한 AudioWorkletProcessor 클래스의 process() 메서드를 엔진 노드 AudioWorkletNode 를 통해 오디오 컨텍스트의 렌더링 스레드에서 실행한다. 페이지 쪽 (AudioWorklet, AudioWorkletNode)은 org.duckdns.hjow.swingwebpanel.js.host.webaudio 에 있다.
