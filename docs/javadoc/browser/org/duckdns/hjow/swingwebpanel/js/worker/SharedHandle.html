Class SharedHandle

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.worker.SharedHandle

public final class SharedHandle
extends EventTarget

The Java side of a SharedWorker object of a page (HTML Standard "Shared workers and the SharedWorker interface"): it holds the outside port of the connection (port) and is the event target at which the page receives the error event when the shared worker could not be loaded or when the constructor arguments do not fit the shared worker that already exists. The messages travel through the port, not through this object.

페이지의 SharedWorker 객체의 Java 쪽(HTML 표준 "Shared workers and the SharedWorker interface"): 연결의 바깥 포트(port)를 가지며, 공유 worker 를 가져올 수 없거나 생성자 인수가 이미 있는 공유 worker 와 맞지 않을 때 페이지가 error 이벤트를 받는 이벤트 대상이다. 메시지는 이 객체가 아니라 포트를 거쳐 오간다.
