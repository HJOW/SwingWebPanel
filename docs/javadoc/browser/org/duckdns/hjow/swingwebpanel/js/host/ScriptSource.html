Interface ScriptSource

All Known Subinterfaces:
ModuleScriptSource, ModuleScriptSource.WithAttributes, ScriptSource.WithResponse
public interface ScriptSource

Supplies the text of external scripts and modules to the page (the component fetches them through its request layer, so User-Agent, extra headers, cookies, SSL hook, scheme limits and cancellation apply). The call may block the calling thread.

페이지에 외부 스크립트와 모듈의 텍스트를 공급한다(컴포넌트가 요청 계층으로 가져오므로 User-Agent, 추가 헤더, 쿠키, SSL 훅, 스킴 제한, 취소가 적용된다). 호출한 스레드를 막을 수 있다.
