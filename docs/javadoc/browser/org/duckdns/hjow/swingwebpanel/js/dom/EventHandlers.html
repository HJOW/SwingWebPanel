Class EventHandlers

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.EventHandlers

public final class EventHandlers
extends java.lang.Object

The event handler IDL attributes (onclick, onload ...) of one page. A handler is stored per event target and event type in a HandlerListener; the listener is registered with the target at the first assignment, so the handler keeps its place among the listeners when it is replaced. The same registry serves event handler content attributes (<a onclick="...">).

한 페이지의 이벤트 핸들러 IDL 속성(onclick, onload 등). 핸들러는 이벤트 대상과 이벤트 종류마다 HandlerListener 에 보관한다. 리스너는 첫 대입 때 대상에 등록되므로 핸들러를 바꿔도 리스너 목록에서 자기 위치를 유지한다. 이벤트 핸들러 콘텐츠 속성 (<a onclick="...">)도 같은 등록부를 쓴다.
