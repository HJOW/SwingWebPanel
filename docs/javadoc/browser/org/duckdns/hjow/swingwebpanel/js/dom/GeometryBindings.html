Class GeometryBindings

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.GeometryBindings

public final class GeometryBindings
extends java.lang.Object

The geometry interfaces that the layout queries return (plan item P20-03, Geometry Interfaces Module): DOMRectReadOnly, DOMRect (x, y, width, height, the edges top, right, bottom, left, toJSON(), the static fromRect(), a constructor that takes the four numbers), DOMRectList (what getClientRects() returns: length, item(), indexed access and iteration), and DOMPointReadOnly/DOMPoint (x, y, z, w, toJSON(), fromPoint()). Their instances are real instances of these interfaces, so rect instanceof DOMRect is true. Matrix transforms (DOMMatrix, DOMQuad) are not part of it.

레이아웃 조회가 돌려주는 기하 인터페이스(계획 P20-03, Geometry Interfaces Module): DOMRectReadOnly, DOMRect(x, y, width, height, 가장자리 top, right, bottom, left, toJSON(), 정적 fromRect(), 숫자 네 개를 받는 생성자), DOMRectList(getClientRects() 의 반환값: length, item(), 위치 접근, 반복), DOMPointReadOnly/DOMPoint(x, y, z, w, toJSON(), fromPoint()). 인스턴스는 이 인터페이스의 진짜 인스턴스이므로 rect instanceof DOMRect 가 참이다. 행렬 변환(DOMMatrix, DOMQuad)은 포함하지 않는다.
