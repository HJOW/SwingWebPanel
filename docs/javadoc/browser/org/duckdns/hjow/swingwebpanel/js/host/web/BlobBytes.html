org.duckdns.hjow.swingwebpanel.js.host.web
Class BlobBytes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.web.BlobBytes

public final class BlobBytes
extends java.lang.Object

Read access to the bytes of a script Blob (or File) for the other host APIs that take a blob as an input, for example createImageBitmap(blob) of the canvas package. The Blob object itself stays private to the web request package; this class only answers whether a value is a blob and gives its immutable bytes and type.

스크립트 Blob(또는 File)의 바이트를 읽는 통로. 블롭을 입력으로 받는 다른 호스트 API(예: 캔버스 패키지의 createImageBitmap(blob))를 위한 것이다. Blob 객체 자체는 웹 요청 패키지 안에 두고, 이 클래스는 값이 블롭인지와 바뀌지 않는 바이트, 타입만 알려 준다.
