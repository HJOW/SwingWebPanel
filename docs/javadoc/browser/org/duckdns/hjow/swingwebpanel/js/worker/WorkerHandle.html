Class WorkerHandle

java.lang.Object

      org.duckdns.hjow.swingwebpanel.js.worker.WorkerHandle

public final class WorkerHandle
extends EventTarget

The Java side of a Worker object of the page (HTML Standard "Web workers", interface Worker): the event target at which the page receives the message events of the worker and its error events, and the handle with which the page posts messages to the worker and terminates it. It lives on the page; the worker is a separate WorkerScope. The calls from the worker arrive on the worker thread and are handed over to the page as page tasks, so an event of the worker is dispatched on the thread that owns the page and never while a page script runs. After terminate() nothing is dispatched any more, also not what was already posted to the page.

페이지의 Worker 객체(HTML 표준 "Web workers", 인터페이스 Worker)의 Java 쪽: 페이지가 worker 의 message 이벤트와 error 이벤트를 받는 이벤트 대상이며, 페이지가 worker 에 메시지를 보내고 종료하는 핸들이다. 페이지에 있으며 worker 는 별개의 WorkerScope 이다. worker 에서 오는 호출은 worker 스레드에 도착해 페이지 작업으로 넘겨지므로 worker 의 이벤트는 페이지를 소유한 스레드에서, 페이지 스크립트가 실행되는 동안이 아닐 때 전달된다. terminate() 뒤에는 이미 페이지에 올려 보낸 것도 포함해 아무것도 전달되지 않는다.

terminate

public void terminate()
Terminates the worker at once (Worker.terminate()): the running script is cancelled, no message and no event is delivered any more, and its thread ends. Calling it again does nothing.

worker 를 즉시 종료한다(Worker.terminate()): 실행 중인 스크립트는 취소되고, 더 이상 메시지도 이벤트도 전달되지 않으며, 스레드가 끝난다. 다시 불러도 아무 일도 없다.
