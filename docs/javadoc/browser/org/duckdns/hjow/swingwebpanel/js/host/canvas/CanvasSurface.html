org.duckdns.hjow.swingwebpanel.js.host.canvas
Class CanvasSurface

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasSurface

public final class CanvasSurface
extends java.lang.Object

The drawing surface of one canvas element: its bitmap, its 2D context (created by the first getContext("2d")), the origin-clean flag and the change tracking for the renderer. The script thread draws through the context; the renderer reads an immutable snapshot with snapshot(), a copy of the pixels that is made only when something changed since the last snapshot (so an unchanged canvas costs nothing per frame and a changing one costs one copy per rendered frame). One change notification is sent per snapshot, however many drawing calls happened in between. All methods are synchronized on the surface, and the script bindings hold the same monitor while a context method runs.

canvas 요소 하나의 그리기 표면: 비트맵, 2D 컨텍스트(첫 getContext("2d") 가 만든다), origin-clean 표시, 렌더러를 위한 변경 추적. 스크립트 스레드는 컨텍스트로 그리고, 렌더러는 snapshot() 으로 불변 스냅샷을 읽는다. 스냅샷은 마지막 스냅샷 이후 무언가 바뀌었을 때만 화소를 복사해 만들므로(바뀌지 않은 캔버스는 프레임마다 비용이 없고 바뀌는 캔버스는 그려진 프레임마다 복사 한 번이 든다) 그 사이에 그리기 호출이 몇 번이든 변경 알림은 스냅샷마다 한 번만 보낸다. 모든 메서드는 표면에서 동기화하며, 스크립트 연결은 컨텍스트 메서드가 도는 동안 같은 모니터를 잡는다.

public void setOpaque(boolean value)
Makes the canvas opaque (the context attribute alpha: false): the bitmap becomes opaque black now, and whatever is drawn is flattened onto black whenever the pixels are read, so scripts and the renderer never see a transparent pixel.
