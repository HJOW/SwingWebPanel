public final class StructuredCloneException
extends java.lang.RuntimeException

Thrown when a value cannot be copied by the structured clone algorithm (a function, a symbol, a DOM node, a Proxy ..., a structure that is too deep or too large, or a bad transfer list). The host turns it into a DataCloneError DOMException of the page; the engine code and the tests catch it as a plain Java exception.

구조화 복제 알고리즘이 값을 복사할 수 없을 때 던진다(함수, 심볼, DOM 노드, Proxy 등, 너무 깊거나 큰 구조, 잘못된 전달 목록). 호스트는 이것을 페이지의 DataCloneError DOMException 으로 바꾸고, 엔진 코드와 시험은 일반 Java 예외로 잡는다.
