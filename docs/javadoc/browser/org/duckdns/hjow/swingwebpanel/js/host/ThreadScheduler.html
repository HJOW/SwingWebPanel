Scheduler
public final class ThreadScheduler
extends java.lang.Object
implements Scheduler

A Scheduler that runs the tasks on one daemon thread. PageScripts serializes all JavaScript with a lock, so the thread that runs the tasks does not have to be the one that loaded the page. shutdown() ends the thread (dispose of the component).

작업을 데몬 스레드 하나에서 실행하는 Scheduler. PageScripts 가 모든 JavaScript 를 잠금으로 직렬화하므로 작업을 실행하는 스레드가 페이지를 읽은 스레드일 필요는 없다. shutdown() 이 스레드를 끝낸다(컴포넌트 폐기).
