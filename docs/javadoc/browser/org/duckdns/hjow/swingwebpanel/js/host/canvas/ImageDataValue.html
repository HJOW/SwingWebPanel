Class ImageDataValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.ImageDataValue

public final class ImageDataValue
extends java.lang.Object

An ImageData value: a width, a height and the RGBA bytes (width * height * 4) that the data attribute shows as a Uint8ClampedArray. The bytes are shared with that typed array, so scripts that change data change the pixels that putImageData() writes.

ImageData 값: 너비, 높이, 그리고 data 속성이 Uint8ClampedArray 로 보여 주는 RGBA 바이트 (width * height * 4). 바이트는 그 형식화 배열과 공유되므로 스크립트가 data 를 바꾸면 putImageData() 가 쓰는 화소도 바뀐다.
