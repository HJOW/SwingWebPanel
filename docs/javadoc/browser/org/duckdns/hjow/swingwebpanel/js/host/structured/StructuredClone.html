org.duckdns.hjow.swingwebpanel.js.host.structured
Class StructuredClone

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.structured.StructuredClone

public final class StructuredClone
extends java.lang.Object

The structured clone algorithm of the HTML Standard (StructuredSerialize and StructuredDeserialize, section "Safe passing of structured data"): a script value of one realm is turned into a realm independent, immutable Java tree (ClonedValue), and that tree is turned into a fresh value of the same or another realm. It copies primitives (also -0 and NaN), Boolean, Number and String wrapper objects, Date, RegExp (lastIndex becomes 0), Array (holes and length), ordinary objects (own enumerable string keyed properties; getters are read), Map, Set, ArrayBuffer, the typed arrays, DataView and Error objects (name, message and stack), and it keeps cycles and shared references. Functions, symbols, DOM nodes and other host objects, Proxy objects, WeakMap, Promise and so on cannot be cloned and raise a StructuredCloneException. A depth limit, a cell limit and a byte limit protect the process; the walk is iterative, so a deep structure never overflows the Java stack. ArrayBuffers in the transfer list are moved instead of copied (the source is detached). The messaging entry points preserve shared buffers within an agent cluster.

Usage: ClonedValue c = StructuredClone.serialize(realm, value); JsValue copy = StructuredClone.deserialize(otherRealm, c);

HTML 표준의 구조화 복제 알고리즘("Safe passing of structured data" 절의 StructuredSerialize, StructuredDeserialize): 한 realm 의 스크립트 값을 realm 에 독립적인 불변 Java 트리(ClonedValue)로 바꾸고, 그 트리를 같은 또는 다른 realm 의 새 값으로 바꾼다. 원시 값(-0 과 NaN 포함), Boolean/Number/String 래퍼 객체, Date, RegExp(lastIndex 는 0), Array(빈 칸과 length), 일반 객체(자체 열거 가능한 문자열 키 프로퍼티, getter 는 값을 읽음), Map, Set, ArrayBuffer, 형식화 배열, DataView, Error 객체(name, message, stack)를 복사하며 순환과 공유 참조를 유지한다. 함수, 심볼, DOM 노드 등 호스트 객체, Proxy, WeakMap, Promise 등은 복제할 수 없어 StructuredCloneException 을 던진다. 깊이, 칸 수, 바이트 한도가 프로세스를 보호하며 탐색은 반복문이므로 깊은 구조도 Java 스택을 넘치게 하지 않는다. 전달 목록의 ArrayBuffer 는 복사하지 않고 옮긴다(원본은 분리된다). 메시징 진입점은 같은 에이전트 클러스터에서 버퍼 공유를 유지한다.

사용법: ClonedValue c = StructuredClone.serialize(realm, value); JsValue copy = StructuredClone.deserialize(otherRealm, c);

Serializes a value. Getters of the value run script code, so the call must be made on the thread that owns the realm. When the transfer list holds ArrayBuffers, their bytes move into the result and the source buffers are detached after a successful serialization.

값을 직렬화한다. 값의 getter 는 스크립트 코드를 실행하므로 realm 을 소유한 스레드에서 불러야 한다. 전달 목록에 ArrayBuffer 가 있으면 그 바이트는 결과로 옮겨지고 직렬화에 성공한 뒤 원본 버퍼는 분리된다.
