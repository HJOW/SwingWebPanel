org.duckdns.hjow.swingwebpanel.js.host
Class TextTrackValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.host.TextTrackValue

public final class TextTrackValue
extends EventTarget

The script object of a text track (TextTrack, HTML 4.8.11.11.1 and 4.8.11.11.5) and the state that goes with it: the kind, label, language and identifier, the readiness state, the mode, the list of cues and what the track processing model needs while the file of a track element is fetched. A track either belongs to a track element (its kind, label, language and identifier are read from the element when they are asked for, so they change with the attributes) or was made by addTextTrack() (the values are fixed). The cues are kept in the text track cue order: the start time, then the end time (the later one first), then the order of insertion. cuechange fires at the track. The class is public because the DOM bridge reads its accessors by reflection; everything that changes the state of the page goes through the TextTracks manager.

텍스트 트랙의 스크립트 객체(TextTrack, HTML 4.8.11.11.1, 4.8.11.11.5)와 거기 딸린 상태: 종류, 레이블, 언어, 식별자, 준비 상태, 모드, cue 목록, track 요소의 파일을 가져오는 동안 트랙 처리 모델이 필요로 하는 것. 트랙은 track 요소에 속하거나(종류, 레이블, 언어, 식별자는 물을 때 요소에서 읽으므로 속성을 따라 바뀐다) addTextTrack() 이 만든 것이다(값이 고정). cue 는 텍스트 트랙 cue 순서로 보관한다: 시작 시각, 끝 시각(늦은 것 먼저), 들어온 순서. cuechange 는 트랙에서 발생한다. DOM 브리지가 접근자를 리플렉션으로 읽으므로 클래스는 public 이며 페이지의 상태를 바꾸는 모든 것은 TextTracks 관리자를 거친다.
