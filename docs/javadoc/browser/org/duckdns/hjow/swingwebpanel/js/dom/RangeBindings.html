Class RangeBindings

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.RangeBindings

public final class RangeBindings
extends java.lang.Object

The JavaScript interfaces of ranges, selections and traversal (plan item P20-03): Range with its constructor, Selection, NodeIterator, TreeWalker and the NodeFilter constants, and the members that create them: document.createRange(), createNodeIterator(), createTreeWalker(), document.getSelection() and window.getSelection(). The geometry of ranges (getBoundingClientRect) needs the layout of the page and is added by the host (see RangeGeometry of the host package).

범위, 선택, 탐색의 JavaScript 인터페이스(계획 P20-03): 생성자가 있는 Range, Selection, NodeIterator, TreeWalker, NodeFilter 상수와 이것들을 만드는 멤버 document.createRange(), createNodeIterator(), createTreeWalker(), document.getSelection(), window.getSelection(). 범위의 기하(getBoundingClientRect)는 페이지의 레이아웃이 필요하므로 호스트가 더한다(호스트 패키지의 RangeGeometry 참조).
