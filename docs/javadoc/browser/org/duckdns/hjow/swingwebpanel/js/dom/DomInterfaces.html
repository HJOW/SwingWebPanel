org.duckdns.hjow.swingwebpanel.js.dom
Class DomInterfaces

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.dom.DomInterfaces

public final class DomInterfaces
extends java.lang.Object

The table of the DOM interfaces that scripts see (DOM Standard and the common HTML element interfaces) and the code that installs them into a DomBridge. Most interfaces are described by member specification strings (see DomBridge.defineInterface(String, String, Class, String[])); the few members that need real logic (event listener registration, event and exception constructors, iteration helpers) are written out here.

스크립트가 보는 DOM 인터페이스(DOM Standard 와 흔한 HTML 요소 인터페이스)의 표와 이를 DomBridge 에 설치하는 코드. 대부분의 인터페이스는 멤버 명세 문자열로 기술하며(DomBridge.defineInterface(String, String, Class, String[]) 참고) 실제 논리가 필요한 몇몇 멤버(이벤트 리스너 등록, 이벤트와 예외 생성자, 반복 도우미)는 여기에 직접 쓴다.

installEventCore

public static void installEventCore(DomBridge bridge)
Installs only what a script context without a document needs (a worker, plan item P20-09-b): DOMException, Event, CustomEvent, ErrorEvent and EventTarget with its three methods. No node, collection, document, UI event or storage interface is defined, so none of them is reachable from such a context.

문서가 없는 스크립트 문맥(worker, 계획 P20-09-b)에 필요한 것만 설치한다: DOMException, Event, CustomEvent, ErrorEvent, 메서드 셋을 가진 EventTarget. 노드, 컬렉션, 문서, UI 이벤트, 저장소 인터페이스는 정의하지 않으므로 그런 문맥에서는 어느 것에도 닿을 수 없다.
