org.duckdns.hjow.swingwebpanel.js.host.canvas
Interface CanvasHost

public interface CanvasHost

What the canvas bindings need from the page that owns them: the realm, the DOM bridge, the document, the style resolver (for the font size and color of a canvas element), the pixels of the images that scripts draw, the notification that a canvas changed, and the state of the page. The page implements it (PageScripts through a small adapter), so the canvas package does not depend on the internals of the script host.

캔버스 연결이 그것을 소유한 페이지에 필요로 하는 것: realm, DOM 브리지, 문서, 스타일 리졸버(캔버스 요소의 글꼴 크기와 색을 위해), 스크립트가 그리는 이미지의 화소, 캔버스가 바뀌었다는 알림, 페이지의 상태. 페이지가 이를 구현하므로(PageScripts 가 작은 어댑터로), 캔버스 패키지는 스크립트 호스트의 내부에 의존하지 않는다.
