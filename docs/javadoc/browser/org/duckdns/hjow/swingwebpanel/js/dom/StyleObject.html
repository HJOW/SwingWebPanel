public final class StyleObject
extends HostObject

The script object of a CSSStyleDeclaration: either the inline style of an element (element.style, readable and writable; every write parses the style attribute, changes one declaration and writes the attribute back, so the style resolver and the serialization always agree) or a computed style snapshot (getComputedStyle, read-only). CSS properties are reachable by their dashed names and by their camel-case names (style.backgroundColor, style['background-color'], style.cssFloat); other names are ordinary properties.

CSSStyleDeclaration 의 스크립트 객체: 요소의 인라인 스타일(element.style, 읽기/쓰기. 쓸 때마다 style 속성을 해석해 선언 하나를 바꾸고 속성에 다시 써서 스타일 리졸버와 직렬화가 항상 일치한다) 또는 계산 스타일 스냅샷 (getComputedStyle, 읽기 전용). CSS 프로퍼티는 대시 이름과 카멜 케이스 이름(style.backgroundColor, style['background-color'], style.cssFloat)으로 접근하며 그 밖의 이름은 일반 프로퍼티이다.
