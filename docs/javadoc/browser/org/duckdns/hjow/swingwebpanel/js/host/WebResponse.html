org.duckdns.hjow.swingwebpanel.js.host
Class WebResponse

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.WebResponse

public final class WebResponse
extends java.lang.Object

The result of a WebRequest, already filtered by the component's network policy the way the Fetch Standard filters responses: a basic response (same origin, without Set-Cookie), a cors response (cross origin that the server allowed, with only the safelisted and the exposed headers), an opaque response (cross origin no-cors: status 0, no headers, no body) or an error response (network error: refused by CORS or by the scheme policy, blocked redirect, failed connection, cancelled request). A response with an HTTP error status such as 404 is a normal response, not an error.

컴포넌트의 네트워크 정책이 Fetch 표준이 응답을 거르는 방식으로 이미 거른 WebRequest 의 결과: basic 응답(같은 오리진, Set-Cookie 제외), cors 응답(서버가 허용한 교차 오리진, 안전 목록과 노출한 헤더만), opaque 응답(교차 오리진 no-cors: 상태 0, 헤더와 본문 없음), error 응답(네트워크 오류: CORS 나 스킴 정책이 거부, 막힌 리디렉션, 연결 실패, 취소된 요청). 404 같은 HTTP 오류 상태의 응답은 오류가 아닌 일반 응답이다.

futileError

public static WebResponse futileError(java.lang.String message)
Creates a network error response that a retry cannot fix: a scheme that is not allowed, a cross-origin access that the server does not grant, a redirect that the request forbids. A consumer that retries after network errors (an event stream) gives up on such an error.

다시 시도해도 고쳐지지 않는 네트워크 오류 응답을 만든다: 허용되지 않은 스킴, 서버가 허락하지 않는 교차 오리진 접근, 요청이 금지한 리디렉션. 네트워크 오류 뒤에 다시 시도하는 쪽(이벤트 스트림)은 이런 오류에서는 포기한다.

Parameters:

the error response / 오류 응답
