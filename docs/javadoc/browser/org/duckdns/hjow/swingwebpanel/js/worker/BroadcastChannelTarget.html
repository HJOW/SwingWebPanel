Class BroadcastChannelTarget

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.worker.BroadcastChannelTarget

public final class BroadcastChannelTarget
extends EventTarget

The Java side of one BroadcastChannel object (HTML Standard "Broadcasting to other browsing contexts"): a named channel that belongs to one script context. A message that another channel of the same name posts reaches it as a message event, as a task of the context that owns the channel, never while the sender runs. A closed channel receives nothing.

BroadcastChannel 객체 하나의 Java 쪽(HTML 표준 "Broadcasting to other browsing contexts"): 스크립트 문맥 하나에 속한 이름 있는 채널. 같은 이름의 다른 채널이 보낸 메시지는 채널을 소유한 문맥의 작업으로, 보내는 쪽이 실행되는 동안이 아닐 때 message 이벤트로 도착한다. 닫힌 채널은 아무것도 받지 않는다.
