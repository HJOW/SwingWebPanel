Package org.duckdns.hjow.swingwebpanel.js.host.webaudio Description

The script interface of the Web Audio API (plan item P25): AudioContext, OfflineAudioContext, AudioNode and the nodes, AudioParam, AudioBuffer, AudioListener, PeriodicWave and the events, over the pure Java engine org.duckdns.hjow.swingwebpanel.media.webaudio. WebAudioApi installs it on the global object of a page and disposes everything with the page. A real-time context plays to the output that the host chose (SwingWebPanel.createWebAudioOutputFactory()), the deprecated ScriptProcessorNode runs its handlers as tasks of the page, and createMediaElementSource routes the sound of an audio element into the graph.

Web Audio API 의 스크립트 인터페이스(계획 P25): AudioContext, OfflineAudioContext, AudioNode 와 노드, AudioParam, AudioBuffer, AudioListener, PeriodicWave, 이벤트를 순수 Java 엔진 org.duckdns.hjow.swingwebpanel.media.webaudio 위에 만든다. WebAudioApi 가 페이지의 전역 객체에 설치하고 페이지와 함께 모든 것을 폐기한다. 실시간 컨텍스트는 호스트가 고른 출력 (SwingWebPanel.createWebAudioOutputFactory())으로 재생하고, 폐기 예정인 ScriptProcessorNode 는 핸들러를 페이지의 작업으로 실행하며, createMediaElementSource 는 audio 요소의 소리를 그래프로 돌린다.
