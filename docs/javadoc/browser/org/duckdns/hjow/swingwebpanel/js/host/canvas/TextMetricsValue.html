org.duckdns.hjow.swingwebpanel.js.host.canvas
Class TextMetricsValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.TextMetricsValue

public final class TextMetricsValue
extends java.lang.Object

The result of measureText(): a TextMetrics value. All lengths are in CSS pixels. The horizontal values are measured from the alignment point of the text (the x that would be given to fillText) and the vertical values from the current text baseline, positive upwards for the ascents and downwards for the descents.

measureText() 의 결과인 TextMetrics 값. 모든 길이는 CSS 픽셀이다. 가로 값은 텍스트의 정렬 기준점(fillText 에 주는 x)에서, 세로 값은 현재 텍스트 기준선에서 재며 ascent 는 위쪽, descent 는 아래쪽이 양수이다.
