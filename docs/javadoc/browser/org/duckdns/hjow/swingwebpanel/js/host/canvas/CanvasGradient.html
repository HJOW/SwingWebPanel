Class CanvasGradient

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.host.canvas.CanvasGradient

public final class CanvasGradient
extends java.lang.Object

A CanvasGradient: a linear gradient along a line, a radial (two-circle, cone) gradient or a conic gradient around a center, with color stops (the conic form is conic(double, double, double): the offset is the clockwise angle from the start angle as a fraction of a turn). The gradient lives in the coordinate space that is current when it is painted, not when it was created (so the context passes the current transformation matrix to toPaint(AffineTransform)). Colors are interpolated in non-premultiplied RGBA; before the first stop the first color and after the last stop the last color is used; stops with the same offset make a hard edge; a gradient without stops paints transparent black. The radial form follows the algorithm of the canvas specification: for every point the largest w whose circle (x(w), y(w), r(w) with r(w) >= 0) contains the point decides the color.

CanvasGradient: 직선을 따르는 선형 그라디언트, 두 원(원뿔)의 방사형 그라디언트, 중심 둘레의 원뿔형 그라디언트와 색 정지점(원뿔형은 conic(double, double, double): 오프셋은 시작 각도에서 시계 방향으로 잰 각도를 한 바퀴에 대한 비율로 나타낸 것). 그라디언트는 만들 때가 아니라 칠할 때의 좌표계에 놓인다(그래서 컨텍스트가 현재 변환 행렬을 toPaint(AffineTransform) 에 넘긴다). 색은 알파를 곱하지 않은 RGBA 로 보간한다. 첫 정지점 앞은 첫 색, 마지막 정지점 뒤는 마지막 색이며, 같은 오프셋의 정지점은 날카로운 경계를 만들고, 정지점이 없으면 투명한 검정을 칠한다. 방사형은 캔버스 규격의 알고리즘을 따른다: 각 점은 그 점을 포함하는 원(x(w), y(w), r(w), r(w) >= 0) 중 가장 큰 w 가 색을 정한다.
