Class TextTrackListValue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.js.host.TextTrackListValue

public final class TextTrackListValue
extends EventTarget

The script object of the list of the text tracks of a media element (TextTrackList, HTML 4.8.11.11.5): media.textTracks. The list is live and has the order of the specification (the tracks of the track children in tree order, then the tracks that addTextTrack() made). change, addtrack and removetrack fire at it. The class is public because the DOM bridge reads its accessors by reflection.

미디어 요소의 텍스트 트랙 목록의 스크립트 객체(TextTrackList, HTML 4.8.11.11.5): media.textTracks. 목록은 살아 있고 규격의 순서를 가진다(track 자식의 트랙이 트리 순서로, 그 뒤에 addTextTrack() 이 만든 트랙). change, addtrack, removetrack 이 그 위에서 발생한다. DOM 브리지가 접근자를 리플렉션으로 읽으므로 클래스는 public 이다.
