Interface StreamingWebRequestSource.Listener

Enclosing interface:
StreamingWebRequestSource
public static interface StreamingWebRequestSource.Listener

Receives a stream on a request thread; every method must only hand the data over (no JavaScript runs here).

요청 스레드에서 스트림을 받는다. 모든 메서드는 데이터를 넘기기만 해야 한다(여기서 JavaScript 를 실행하지 않는다).

Method Detail

onHeaders

boolean onHeaders(WebResponse head)
Called once when the response head of the final non-error response (status below 400) is known and passed the page rules (the same-origin policy and CORS): the listener decides whether the body is wanted.

최종 비오류 응답(상태 400 미만)의 응답 머리를 알고 페이지 규칙(동일 출처 정책과 CORS)을 통과했을 때 한 번 호출된다. 본문을 받을지 정한다.

Parameters:
head - the response without a body / 본문 없는 응답
Returns:
true to receive the body through onData(byte[], int); false to refuse it (the stream then ends with onEnd(WebResponse) carrying this head) / 본문을 onData(byte[], int) 로 받으려면 true. 거부하면 false 이며 스트림은 이 머리를 담은 onEnd(WebResponse) 로 끝난다

onEnd

void onEnd(WebResponse end)
Called exactly once when the stream ended: with a network error (isError(); isCancelled() tells a cancelled request), with the head that the listener refused or an error status (a response that is not an error), or with the final response of a body that ended normally (it carries the status and the headers, no body).

스트림이 끝났을 때 정확히 한 번 호출된다: 네트워크 오류(isError(), isCancelled() 는 취소된 요청), 받는 쪽이 거부한 머리 또는 오류 상태(오류가 아닌 응답), 또는 정상적으로 끝난 본문의 최종 응답(상태와 헤더를 담고 본문은 없다).

Parameters:
end - the end of the stream / 스트림의 끝
