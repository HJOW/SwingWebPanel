Package org.duckdns.hjow.swingwebpanel.js.host.anim

Interface Summary
AnimationPage What the script binding of Web Animations needs from the page whose scripts it serves: the realm, the DOM bridge, the document, the environment, the document clock (the clock of performance.now() and requestAnimationFrame), whether scripts may run, error reporting, and animation frames shared with requestAnimationFrame (the step "update animations and send events" runs right before the animation frame callbacks of the same frame, with the same time).
AnimationPage.FrameHook A receiver of the animation frames.
 

Class Summary
WebAnimationsApi The script interface of Web Animations Level 1 (W3C Working Draft 5 June 2023, https://www.w3.org/TR/2023/WD-web-animations-1-20230605/, plan item P10-08-h): Animation (constructor, id, effect, timeline, startTime, currentTime, playbackRate, playState, replaceState, pending, ready, finished, onfinish, oncancel, onremove, play(), pause(), reverse(), finish(), cancel(), updatePlaybackRate(), persist(), commitStyles()), AnimationEffect (getTiming(), getComputedTiming(), updateTiming()), KeyframeEffect (both constructors, target, pseudoElement, composite, iterationComposite of Level 2 which is stored only, getKeyframes(), setKeyframes()), AnimationTimeline and DocumentTimeline (constructor with originTime), AnimationPlaybackEvent, Element.animate(), Element.getAnimations({subtree}), Document.getAnimations() and document.timeline.
