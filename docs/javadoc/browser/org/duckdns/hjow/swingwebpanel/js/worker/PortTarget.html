Class PortTarget

java.lang.Object

      org.duckdns.hjow.swingwebpanel.js.worker.PortTarget

public final class PortTarget
extends EventTarget

The Java side of one MessagePort object of a script context (HTML Standard "Message ports"): the event target at which the message events of the port are dispatched, bound to the PortCore (the end of the channel) that it shows to the script. A port that was transferred to another context is detached: it loses its core, so it does nothing any more, while the same end of the channel lives on as a new port object of the receiving context. Every method must be called from a task of the context that owns the object, except core().

스크립트 문맥의 MessagePort 객체 하나의 Java 쪽(HTML 표준 "Message ports"): 포트의 message 이벤트가 전달되는 이벤트 대상이며, 스크립트에 보여 주는 채널의 끝 PortCore 에 묶여 있다. 다른 문맥으로 전달된 포트는 분리되어 코어를 잃고 더 이상 아무 일도 하지 않으며, 채널의 같은 끝은 받는 문맥의 새 포트 객체로 계속 산다. core() 를 뺀 모든 메서드는 객체를 소유한 문맥의 작업에서 불러야 한다.
