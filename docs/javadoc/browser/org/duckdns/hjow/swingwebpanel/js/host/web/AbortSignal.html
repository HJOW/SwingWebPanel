EventTarget.ListenerSignal
public final class AbortSignal
extends EventTarget
implements EventTarget.ListenerSignal

The Java side of an AbortSignal (DOM Standard, section 3.2): an event target with an aborted flag and a reason, a list of internal "abort algorithms" that fetch() and XMLHttpRequest register (they cancel the network request), and the abort event. A signal aborts at most once. The script object is a bridge wrapper of this class, so addEventListener and onabort work like on every other event target. All methods run on the thread that owns the page's JavaScript.

AbortSignal 의 Java 쪽(DOM 표준 3.2절): 중단 플래그와 이유를 가진 이벤트 대상. fetch() 와 XMLHttpRequest 가 등록하는 내부 "중단 알고리즘" 목록(네트워크 요청을 취소한다)과 abort 이벤트를 가진다. 신호는 많아야 한 번 중단된다. 스크립트 객체는 이 클래스의 연결 래퍼이므로 addEventListener 와 onabort 가 다른 이벤트 대상과 똑같이 동작한다. 모든 메서드는 페이지 JavaScript 를 소유한 스레드에서 실행된다.
