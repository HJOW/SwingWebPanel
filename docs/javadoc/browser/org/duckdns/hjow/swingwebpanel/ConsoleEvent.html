Class ConsoleEvent

All Implemented Interfaces:
java.io.Serializable
public final class ConsoleEvent
extends java.util.EventObject

One message of the page scripts' console, delivered to a ConsoleListener. It is immutable and holds only strings and numbers (no script object), so a listener may keep it. The source of the event is the SwingWebPanel. Besides the message it tells which document wrote it (fixed when the message was written, so a message that arrives after a navigation still names the page that wrote it), which script and line, and whether the document, one of its frames or a worker wrote it.

페이지 스크립트의 콘솔 메시지 하나로, ConsoleListener 에 전달된다. 불변이며 문자열과 숫자만 가지므로(스크립트 객체 없음) 리스너가 보관해도 된다. 이벤트의 source 는 SwingWebPanel 이다. 메시지 외에 어느 문서가 썼는지(메시지를 쓴 시점에 고정되므로 이동 뒤에 도착한 메시지도 그것을 쓴 페이지를 가리킨다), 어느 스크립트의 몇 번째 줄인지, 문서·프레임·worker 중 누가 썼는지를 알려 준다.

getMessage

public java.lang.String getMessage()
Returns the message text: the arguments after the format string (%s %d %i %f %o %O %c %%) was applied, joined by spaces, indented by the open console.groups. Objects are shown in a compact readable form without running script code.

메시지 문자열을 반환한다: 서식 문자열(%s %d %i %f %o %O %c %%)을 적용하고 공백으로 이은 인수를 열린 console.group 만큼 들여 쓴 것. 객체는 스크립트 코드를 실행하지 않고 간결하고 읽기 쉬운 형태로 나타낸다.
