org.duckdns.hjow.swingwebpanel.content.error
Class ErrorPage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.error.ErrorPage

public final class ErrorPage
extends java.lang.Object

A generated error page (plan item P17-06): the HTML source and the facts it was made from. The source is what the component keeps as the page source when no server body exists (see the getContent() contract), and the same string is parsed by the normal HTML path, so the page is shown, scrolled and navigated like any other. Every value that came from outside (the address, messages of the network layer or the XML parser) is HTML-escaped in the source; the plain values are available through the getters. Instances are immutable and the HTML is deterministic: the same input always gives the same string.

생성한 오류 페이지(계획 P17-06): HTML 원문과 그 재료가 된 사실들. 원문은 서버 본문이 없을 때 컴포넌트가 페이지 원문으로 보관하는 값이며 (getContent() 계약 참조), 같은 문자열을 일반 HTML 경로가 해석하므로 다른 페이지처럼 보이고 스크롤되고 이동된다. 바깥에서 온 모든 값(주소, 네트워크 계층이나 XML 파서의 메시지)은 원문에서 HTML 이스케이프된다. 이스케이프하지 않은 값은 getter 로 얻는다. 인스턴스는 불변이며 HTML 은 결정적이다: 같은 입력은 항상 같은 문자열을 준다.

public boolean hasRetryLink()
Tells whether the page contains a link that tries the address again. It does not for addresses that the component would refuse to load anyway (a blocked scheme, an address with control characters or white space, a very long address).
