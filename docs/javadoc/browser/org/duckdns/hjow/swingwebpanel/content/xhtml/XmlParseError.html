Class XmlParseError

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.xhtml.XmlParseError

public final class XmlParseError
extends java.lang.Object

A structured XML error (plan items P17-05, P17-06): what went wrong, where (line and column of the document text, both 1 based) and the text of the offending line. XML has no error recovery: the first well-formedness error ends the parse, and a caller shows an error page built from this object instead of falling back to the forgiving HTML parser. Instances are immutable.

구조화된 XML 오류(계획 P17-05, P17-06): 무엇이 잘못되었는지, 어디인지(문서 텍스트의 줄과 열, 둘 다 1부터), 문제의 줄 텍스트. XML 에는 오류 복구가 없다: 첫 well-formed 오류가 해석을 끝내며, 호출자는 관대한 HTML 파서로 되돌아가는 대신 이 객체로 만든 오류 페이지를 보여 준다. 인스턴스는 불변이다.
