org.duckdns.hjow.swingwebpanel.content.xhtml
Class XmlText

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.xhtml.XmlText

public final class XmlText
extends java.lang.Object

The result of decoding the bytes of an XML document: the text, the encoding that was used, where that decision came from and, if the bytes are not valid in that encoding, a description of the first problem. The text is the "received source" of the document and is what getContent() returns; its line ends are not changed. If an encoding error was found, the text ends just before the malformed bytes, because an XML document with an invalid byte sequence is not well-formed (XML 1.0, section 4.3.3) and must not be shown as if it were.

XML 문서 바이트를 디코딩한 결과: 텍스트, 사용한 인코딩, 그 판정의 출처, 그리고 바이트가 그 인코딩에서 올바르지 않다면 첫 문제의 설명. 텍스트는 문서의 "수신 원문"이며 getContent() 가 반환하는 값이다. 줄 끝은 바꾸지 않는다. 인코딩 오류가 있으면 올바르지 않은 바이트 직전에서 텍스트가 끝난다. 잘못된 바이트 순서가 있는 XML 문서는 well-formed 가 아니므로(XML 1.0, 4.3.3절) 그대로 보여 주면 안 되기 때문이다.
