org.duckdns.hjow.swingwebpanel.content.text
Class PlainTextDocumentBuilder

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.text.PlainTextDocumentBuilder

public final class PlainTextDocumentBuilder
extends java.lang.Object

Builds the DOM document of a plain text page (plan item P17-02). The text is never interpreted: whatever it contains (tags, script elements, character references, an XML declaration) is the data of one text node, so it can neither run a script nor change the page. The shape of the document follows the HTML Standard's rule for text files and what browsers build: 

 html > head
      > body > pre style="word-wrap: break-word; white-space: pre-wrap;" > (text)
The line structure of the text is kept: CR LF and CR become LF (the input stream preprocessing that the HTML Standard applies to text files as well), NUL becomes U+FFFD (the PLAINTEXT tokenizer state of the standard), and nothing else is touched, so leading white space, blank lines and a trailing newline stay as they are. white-space: pre-wrap shows them as written and wraps lines that are longer than the window (as browsers do for text/plain); the page has no title.

The builder is used for text/plain and for the other text types that are shown as text (CSS, JavaScript, JSON, XML source). It does not change the received source: getContent() keeps returning the original string.

일반 텍스트 페이지의 DOM 문서를 만든다(계획 P17-02). 텍스트는 절대 해석되지 않는다: 무엇이 들어 있든(태그, script 요소, 문자 참조, XML 선언) 텍스트 노드 하나의 데이터이므로 스크립트를 실행하거나 페이지를 바꿀 수 없다. 문서의 모양은 HTML 표준의 텍스트 파일 규칙과 브라우저가 만드는 것을 따른다 (위의 영문 트리 참조). 텍스트의 줄 구조는 유지한다: CR LF 와 CR 은 LF 가 되고(HTML 표준이 텍스트 파일에도 적용하는 입력 스트림 전처리), NUL 은 U+FFFD 가 되며(표준의 PLAINTEXT 토큰화 상태), 그 밖에는 손대지 않으므로 앞쪽 공백, 빈 줄, 끝의 줄 바꿈이 그대로 남는다. white-space: pre-wrap 이 이를 쓴 그대로 보여 주며 창보다 긴 줄은 줄바꿈한다(브라우저가 text/plain 에 하는 것과 같다). 페이지에는 제목이 없다.

이 생성기는 text/plain 과 텍스트로 보여 주는 다른 타입(CSS, JavaScript, JSON, XML 소스)에 쓴다. 수신 원문은 바꾸지 않으며 getContent() 는 계속 원래 문자열을 반환한다.

normalize

public static java.lang.String normalize(java.lang.String text)
Normalizes a text the way the HTML Standard does for the input stream of a text file: CR LF and CR become LF and NUL becomes U+FFFD. The input string is not modified; if there is nothing to change the same string is returned.

HTML 표준이 텍스트 파일의 입력 스트림에 하는 대로 텍스트를 정규화한다: CR LF 와 CR 은 LF, NUL 은 U+FFFD 가 된다. 입력 문자열은 바꾸지 않으며 바꿀 것이 없으면 같은 문자열을 반환한다.

Parameters:
text - the text, null is treated as empty / 텍스트(null 은 빈 문자열)
Returns:
the normalized text / 정규화한 텍스트
