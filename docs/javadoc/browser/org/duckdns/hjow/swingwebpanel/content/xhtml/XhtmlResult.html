org.duckdns.hjow.swingwebpanel.content.xhtml
Class XhtmlResult

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.xhtml.XhtmlResult

public final class XhtmlResult
extends java.lang.Object

The result of XhtmlParser: the DOM document, the decoded text (the "received source" that getContent() keeps), the encoding decision and, if the document is not well-formed or exceeds a limit, the structured error. When there is an error the document holds what had been built before the error (a prefix of the tree); callers that follow the XML rule "no error recovery" show an error page from getError() and do not use that partial tree.

XhtmlParser 의 결과: DOM 문서, 디코딩한 텍스트(getContent() 가 보관하는 "수신 원문"), 인코딩 판정, 그리고 문서가 well-formed 가 아니거나 상한을 넘으면 구조화된 오류. 오류가 있으면 문서에는 오류 전에 만든 것(트리의 앞부분)이 들어 있다. "오류 복구 없음"이라는 XML 규칙을 따르는 호출자는 getError() 로 오류 페이지를 보여 주고 그 부분 트리는 쓰지 않는다.
