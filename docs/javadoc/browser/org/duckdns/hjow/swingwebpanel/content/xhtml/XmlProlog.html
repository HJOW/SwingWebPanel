org.duckdns.hjow.swingwebpanel.content.xhtml
Class XmlProlog

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.xhtml.XmlProlog

public final class XmlProlog
extends java.lang.Object

A lightweight, never-failing scan of the beginning of an XML text: the XML declaration, the DOCTYPE declaration (name, public and system identifier, internal subset and its position in the text) and the start tag of the root element (its name and namespace declarations). It does not validate anything; a text that does not follow the XML syntax simply ends the scan early, and the real parser reports the error. Two users: the XHTML parser rewrites the DOCTYPE with it (so that no external DTD can be named, see XhtmlParser) and the content classifier looks at the root element to find out whether a text/xml or application/xml document is XHTML.

XML 텍스트의 앞부분을 훑는 가볍고 실패하지 않는 검사: XML 선언, DOCTYPE 선언(이름, 공개/시스템 식별자, 내부 서브셋과 텍스트 안의 위치), 루트 요소의 시작 태그(이름과 네임스페이스 선언). 아무것도 검증하지 않는다. XML 구문을 따르지 않는 텍스트는 검사가 일찍 끝날 뿐이며 오류는 실제 파서가 보고한다. 쓰는 곳은 둘이다: XHTML 파서는 이것으로 DOCTYPE 을 다시 써서 외부 DTD 를 지정할 수 없게 하고(XhtmlParser 참조), 콘텐츠 분류기는 루트 요소를 보고 text/xml, application/xml 문서가 XHTML 인지 판단한다.

public static XmlProlog scan(java.lang.String text)
Scans the beginning of an XML text. A leading byte order mark character (U+FEFF) is skipped. The method never throws.
