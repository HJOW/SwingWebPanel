org.duckdns.hjow.swingwebpanel.content.markdown
Class MarkdownConverter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.markdown.MarkdownConverter

public final class MarkdownConverter
extends java.lang.Object

Converts Markdown text to HTML (plan items P17-03, P17-04). The converter follows CommonMark 0.31.2 and, unless switched off in the MarkdownOptions, the GitHub Flavored Markdown extensions (tables, strikethrough, task lists, extended autolinks). By default raw HTML in the Markdown is escaped and shown as text and links with the schemes javascript:, vbscript:, data: and file: lose their destination. The conversion never changes its input; the browser component keeps returning the original Markdown from getContent() and uses this class only to build the page that is displayed.

Usage: String html = MarkdownConverter.toHtml("# Title\n\ntext"); for a fragment or MarkdownConverter.toHtmlDocument(markdown, "Title") for a complete HTML5 page.

All methods are thread-safe (no shared state). Input longer than MarkdownOptions.getMaxInputLength() throws MarkdownLimitException; deeply nested blocks and inline elements are limited without failing (see the options).

Markdown 텍스트를 HTML 로 변환한다(계획 P17-03, P17-04). 변환기는 CommonMark 0.31.2 를 따르며 MarkdownOptions 에서 끄지 않으면 GitHub Flavored Markdown 확장(표, 취소선, 작업 목록, 확장 자동 링크)도 처리한다. 기본적으로 Markdown 안의 원시 HTML 은 이스케이프하여 텍스트로 보여 주고 javascript:, vbscript:, data:, file: 스킴의 링크는 목적지를 잃는다. 변환은 입력을 바꾸지 않으며, 브라우저 컴포넌트는 getContent() 로 원래 Markdown 을 계속 돌려주고 이 클래스는 화면에 보일 페이지를 만드는 데에만 쓴다.

사용법: 조각은 String html = MarkdownConverter.toHtml("# Title\n\ntext");, 완전한 HTML5 페이지는 MarkdownConverter.toHtmlDocument(markdown, "Title").

모든 메서드는 스레드 안전하다(공유 상태 없음). MarkdownOptions.getMaxInputLength() 보다 긴 입력은 MarkdownLimitException 을 던지며, 깊게 중첩된 블록과 인라인 요소는 실패 없이 제한된다(옵션 참조).
