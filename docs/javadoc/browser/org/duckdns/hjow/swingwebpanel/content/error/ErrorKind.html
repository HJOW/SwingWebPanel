public enum ErrorKind
extends java.lang.Enum<ErrorKind>

The reasons for which the component shows a generated error page instead of the page that was asked for (plan item P17-06). Every kind has a short title and an explanation in ErrorPageBuilder; the kind is also written into the page as a CSS class (swp-error-<kind>, lower case, with hyphens) so that a host can style or recognize the page.

컴포넌트가 요청한 페이지 대신 생성한 오류 페이지를 보이는 이유(계획 P17-06). 종류마다 ErrorPageBuilder 에 짧은 제목과 설명이 있다. 종류는 CSS 클래스(swp-error-<종류>, 소문자, 하이픈)로도 페이지에 쓰이므로 호스트가 페이지를 꾸미거나 알아볼 수 있다.
