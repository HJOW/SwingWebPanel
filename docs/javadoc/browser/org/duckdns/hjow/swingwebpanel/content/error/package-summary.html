Package org.duckdns.hjow.swingwebpanel.content.error Description

Generated error pages (plan item P17-06): ErrorPageBuilder builds the HTML source and the facts of the page that is shown for HTTP errors, network failures, blocked schemes, missing class path resources, FTP failures and XML parsing errors. Everything that comes from outside is HTML-escaped.

생성 오류 페이지(계획 P17-06): ErrorPageBuilder 는 HTTP 오류, 네트워크 실패, 차단된 스킴, 없는 클래스패스 리소스, FTP 실패, XML 해석 오류에서 보이는 페이지의 HTML 원문과 사실들을 만든다. 바깥에서 온 모든 것은 HTML 이스케이프한다.
