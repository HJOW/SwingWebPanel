org.duckdns.hjow.swingwebpanel.content.error
Class ErrorPageBuilder

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.error.ErrorPageBuilder

public final class ErrorPageBuilder
extends java.lang.Object

The generator of the error pages (plan item P17-06): HTTP error statuses without a body, DNS, connection, timeout and TLS failures, redirect problems, blocked schemes, missing classpath:// resources, FTP failures (shown as 404, a project requirement), invalid addresses and XML parsing errors of XHTML documents. Every method returns an ErrorPage: the HTML source plus the plain facts. This class replaces the small core.ErrorPages, whose titles and explanations it keeps word for word.

The pages are deterministic and safe:

  • Everything that comes from outside (the address, the reason phrase of the server, the messages of the network layer and of the XML parser, a line of the broken document) is HTML-escaped by escape(String): the five markup characters, control characters and the bidirectional override characters (which could disguise an address) are neutralized. An address can never become markup.
  • The page has a stable <title> that equals the heading (404 Not Found), the explanation, the address, and, if the address can be loaded again, a link to it (<a href>) as the retry link. An address with a scheme that the component does not load (javascript:, data:, file: and so on) or with white space or control characters is shown as text without a link; so is an address longer than 8192 characters. An address that is displayed is cut to 2000 characters.
  • The page uses only plain HTML and a few simple CSS rules, and the CSS classes swp-error and swp-error-<kind> on the body.

오류 페이지 생성기(계획 P17-06): 본문 없는 HTTP 오류 상태, DNS, 연결, 시간 초과, TLS 실패, 리디렉션 문제, 차단된 스킴, 없는 classpath:// 리소스, FTP 실패(404 로 표시. 프로젝트 요구사항), 잘못된 주소, XHTML 문서의 XML 해석 오류. 모든 메서드는 ErrorPage(HTML 원문과 이스케이프하지 않은 사실들)를 반환한다. 이 클래스는 작은 core.ErrorPages 를 대체하며 그 제목과 설명을 그대로 유지한다.

페이지는 결정적이고 안전하다:

  • 바깥에서 온 모든 것(주소, 서버의 이유 문구, 네트워크 계층과 XML 파서의 메시지, 깨진 문서의 한 줄)은 escape(String) 로 HTML 이스케이프한다: 마크업 문자 다섯 개, 제어 문자, 주소를 위장할 수 있는 양방향 덮어쓰기 문자를 무력화한다. 주소는 마크업이 될 수 없다.
  • 페이지에는 제목줄과 같은 안정적인 <title>(404 Not Found), 설명, 주소, 그리고 주소를 다시 읽을 수 있으면 다시 시도 링크로서 그 주소로 가는 <a href> 가 있다. 컴포넌트가 읽지 않는 스킴(javascript:, data:, file: 등)이나 공백/제어 문자가 든 주소, 8192 자보다 긴 주소는 링크 없이 텍스트로만 보인다. 표시하는 주소는 2000 자에서 자른다.
  • 페이지는 일반 HTML 과 단순한 CSS 몇 줄만 쓰며 body 에 CSS 클래스 swp-error 와 swp-error-<종류> 를 단다.

escape

public static java.lang.String escape(java.lang.String s)
Escapes a text for HTML text and attribute values. The characters & < > " ' become character references, control characters (except tab and line feed), the C1 controls and the bidirectional formatting characters (U+200E, U+200F, U+061C, U+202A to U+202E, U+2066 to U+2069) become U+FFFD so that they cannot hide or reorder the text of an address. null is treated as empty.

텍스트를 HTML 본문과 속성 값용으로 이스케이프한다. & < > " ' 는 문자 참조가 되고, 제어 문자(탭과 줄 바꿈 제외), C1 제어 문자, 양방향 서식 문자(U+200E, U+200F, U+061C, U+202A~U+202E, U+2066~U+2069)는 주소의 텍스트를 숨기거나 순서를 바꾸지 못하도록 U+FFFD 가 된다. null 은 빈 문자열로 본다.

Parameters:
s - the text or null / 텍스트 또는 null
Returns:
the escaped text / 이스케이프한 텍스트
