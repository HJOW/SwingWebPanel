Package org.duckdns.hjow.swingwebpanel.content

Content handling by MIME type (plain text, Markdown, XHTML) and error page generation.

See:
          Description

Class Summary
ContentClassifier Decides which processor shows a body (plan items P17-01, P01-17, P01-18).
ContentDecision The outcome of ContentClassifier: which processor shows a response body, the media type that was used for the decision (the declared one, or the sniffed one if the type was missing), the declared charset label and, for a download, why the body is not shown.
ContentType A parsed Content-Type value (plan item P17-01): the lower-cased type and subtype and all parameters.
 

Enum Summary
ContentDecision.Reason Why a body is downloaded instead of shown.
ContentKind The kinds of processors that a document body can be handed to (plan items P17-01, P01-18): the four text formats that become a DOM document, the media types that are shown through a generated wrapper document (image, audio) or a placeholder (video), and the download path for everything that cannot be shown as a main document.
