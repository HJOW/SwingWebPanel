Package org.duckdns.hjow.swingwebpanel.content.xhtml Description

XHTML documents (plan item P17-05): XhtmlParser reads application/xhtml+xml with the XML parser of the Java platform (public JAXP/SAX API) and builds the project's own DOM. XML is strict (no error recovery), names are case sensitive, external DTDs, entities and XInclude are never loaded, and every parse is bounded by XhtmlLimits. Errors are reported as XmlParseError with line, column and source line.

XHTML 문서(계획 P17-05): XhtmlParser 는 Java 플랫폼의 XML 파서(공개 JAXP/SAX API)로 application/xhtml+xml 을 읽어 프로젝트 자체 DOM 을 만든다. XML 은 엄격하며(오류 복구 없음), 이름은 대소문자를 구분하고, 외부 DTD, 엔티티, XInclude 는 절대 읽지 않으며, 모든 해석은 XhtmlLimits 로 한정된다. 오류는 줄, 열, 소스 줄이 있는 XmlParseError 로 보고한다.
