Package org.duckdns.hjow.swingwebpanel.content.text Description

Plain text documents (plan item P17-02): PlainTextDocumentBuilder turns a text into a DOM document in which the text is the data of a single text node of a pre element, so it is never interpreted as markup or script.

일반 텍스트 문서(계획 P17-02): PlainTextDocumentBuilder 는 텍스트를 pre 요소의 텍스트 노드 하나의 데이터로 담은 DOM 문서로 만든다. 그래서 텍스트는 마크업이나 스크립트로 해석되지 않는다.
