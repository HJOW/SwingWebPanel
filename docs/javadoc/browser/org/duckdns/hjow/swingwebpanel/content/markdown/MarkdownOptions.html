org.duckdns.hjow.swingwebpanel.content.markdown
Class MarkdownOptions

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.markdown.MarkdownOptions

public final class MarkdownOptions
extends java.lang.Object

Options of a Markdown conversion. The defaults are the safe ones: GitHub Flavored Markdown extensions on, raw HTML escaped (shown as text), dangerous link schemes neutralized. An instance is mutable while it is configured; the converter copies the values it needs, so changing an instance later does not affect a conversion in progress. Configure it on one thread and then share it read-only.

Markdown 변환 옵션. 기본값은 안전한 쪽이다: GitHub Flavored Markdown 확장 켜짐, 원시 HTML 은 이스케이프(텍스트로 표시), 위험한 링크 스킴은 무력화. 설정하는 동안에는 인스턴스를 바꿀 수 있고 변환기는 필요한 값을 복사해 쓰므로 나중에 바꿔도 진행 중인 변환에는 영향이 없다. 한 스레드에서 설정한 뒤 읽기 전용으로 공유한다.

isAllowRawHtml

public boolean isAllowRawHtml()
Tells whether raw HTML blocks and inline HTML are written to the output as they are (default false: they are escaped and shown as text). When true and GFM is on, the GFM tag filter still escapes the leading < of title, textarea, style, xmp, iframe, noembed, noframes, script and plaintext tags.

원시 HTML 블록과 인라인 HTML 을 그대로 출력하는지 알려 준다(기본 false: 이스케이프하여 텍스트로 보여 준다). true 이고 GFM 이 켜져 있어도 GFM 태그 필터가 위의 태그들의 여는 < 를 이스케이프한다.

Returns:
