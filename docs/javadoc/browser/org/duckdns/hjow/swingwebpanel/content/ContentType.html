org.duckdns.hjow.swingwebpanel.content
Class ContentType

java.lang.Object
  org.duckdns.hjow.swingwebpanel.content.ContentType

public final class ContentType
extends java.lang.Object

A parsed Content-Type value (plan item P17-01): the lower-cased type and subtype and all parameters. The algorithm is the "parse a MIME type" algorithm of the WHATWG MIME Sniffing Standard (https://mimesniff.spec.whatwg.org/#parse-a-mime-type): leading and trailing HTTP white space is removed, the type and the subtype must consist of HTTP token characters, parameter names are lower-cased, parameter values may be quoted strings with backslash escapes, parameters without a valid value are skipped and the first parameter of a name wins. A value that does not follow this form (no slash, empty parts, white space inside a part, */*, several comma separated types) is not valid: isValid() is false and getMime() is the empty string, which the content layer treats as "the type is missing".

Use: ContentType.parse("TEXT/HTML ; Charset=\"UTF-8\"").getMime() is text/html and getCharset() is UTF-8. Instances are immutable and thread safe. The older, smaller org.duckdns.hjow.swingwebpanel.net.ContentType keeps only the media type and the charset; this class additionally keeps every parameter and tells the structured suffix (+xml).

해석한 Content-Type 값(계획 P17-01): 소문자 type, subtype 과 모든 매개변수. 알고리즘은 WHATWG MIME Sniffing 표준의 "parse a MIME type"(https://mimesniff.spec.whatwg.org/#parse-a-mime-type)이다: 앞뒤 HTTP 공백을 제거하고, type 과 subtype 은 HTTP 토큰 문자로만 이루어져야 하며, 매개변수 이름은 소문자로 바꾸고, 값은 백슬래시 이스케이프가 있는 따옴표 문자열일 수 있으며, 올바른 값이 없는 매개변수는 건너뛰고 같은 이름은 처음 것이 이긴다. 이 형식을 따르지 않는 값(슬래시 없음, 빈 부분, 부분 안의 공백, */*, 쉼표로 이은 여러 타입)은 올바르지 않다: isValid() 는 false 이고 getMime() 은 빈 문자열이며 콘텐츠 계층은 이를 "타입이 없음"으로 본다.

사용: ContentType.parse("TEXT/HTML ; Charset=\"UTF-8\"").getMime() 은 text/html 이고 getCharset() 은 UTF-8 이다. 인스턴스는 불변이며 스레드에 안전하다. 더 작은 org.duckdns.hjow.swingwebpanel.net.ContentType 은 미디어 타입과 charset 만 보관하지만, 이 클래스는 모든 매개변수를 보관하고 구조적 접미사(+xml)를 알려 준다.
