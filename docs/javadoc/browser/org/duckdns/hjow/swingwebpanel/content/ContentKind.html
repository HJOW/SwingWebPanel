public enum ContentKind
extends java.lang.Enum<ContentKind>

The kinds of processors that a document body can be handed to (plan items P17-01, P01-18): the four text formats that become a DOM document, the media types that are shown through a generated wrapper document (image, audio) or a placeholder (video), and the download path for everything that cannot be shown as a main document. UNKNOWN only occurs as the result of looking at a media type alone when the type is missing; a full decision (ContentDecision) never has it.

문서 본문을 넘길 처리기의 종류(계획 P17-01, P01-18): DOM 문서가 되는 네 가지 텍스트 형식, 생성한 감싸기 문서(이미지, 오디오)나 대체 표시(비디오)로 보이는 미디어 타입, 주 문서로 보일 수 없는 모든 것을 위한 다운로드 경로. UNKNOWN 은 타입이 없을 때 미디어 타입만 보고 판정한 결과로만 나오며, 완전한 결정(ContentDecision)에는 나오지 않는다.
