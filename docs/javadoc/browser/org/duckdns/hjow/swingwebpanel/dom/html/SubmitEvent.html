public final class SubmitEvent
extends Event

The submit event (HTML Standard 4.10.22.10 SubmitEvent): fired at a form before it is submitted, cancelable and bubbling. getSubmitter() is the button that started the submission, or null if the submission did not come from a button.

submit 이벤트(HTML 표준 4.10.22.10 SubmitEvent): 폼을 제출하기 전에 폼에 발생하며 취소 가능하고 버블링한다. getSubmitter() 는 제출을 시작한 버튼이며, 버튼이 아닌 곳에서 시작되었으면 null 이다.
