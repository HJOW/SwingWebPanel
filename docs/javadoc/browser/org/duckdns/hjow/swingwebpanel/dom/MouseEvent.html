public class MouseEvent
extends UiEvent

A mouse event (UI Events): the position in screen, client (the visible part of the page), page (the whole document) and target element coordinates, the button that changed and the buttons that are down, and the element that the pointer came from or goes to. The component fills the coordinates from the AWT event with the scroll position of the viewport.

마우스 이벤트(UI Events): 화면, client(페이지의 보이는 부분), page(문서 전체), 대상 요소 좌표의 위치, 바뀐 버튼과 눌려 있는 버튼, 포인터가 온 곳이나 가는 곳의 요소. 컴포넌트가 AWT 이벤트에서 뷰포트의 스크롤 위치를 반영해 좌표를 채운다.
