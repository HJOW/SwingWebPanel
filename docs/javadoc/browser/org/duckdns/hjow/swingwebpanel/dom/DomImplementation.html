createDocument

public Document createDocument(java.lang.String namespace,
                               java.lang.String qualifiedName,
                               DocumentType doctype)
Creates an XML document, optionally with a document type and a root element (createDocument). The content type follows the namespace of the root element: XHTML gives application/xhtml+xml, SVG gives image/svg+xml, everything else application/xml.

문서 유형과 루트 요소를 선택적으로 가진 XML 문서를 만든다(createDocument). 콘텐츠 타입은 루트 요소의 네임스페이스를 따른다: XHTML 은 application/xhtml+xml, SVG 는 image/svg+xml, 그 밖에는 application/xml.

Parameters:
namespace - namespace of the root element or null / 루트 요소의 네임스페이스 또는 null
qualifiedName - qualified name of the root element, null or empty for none / 루트 요소의 이름. null 이나 빈 문자열이면 없음
doctype - document type or null / 문서 유형 또는 null
Returns:
the document / 문서
Throws:
DomException - InvalidCharacterError or NamespaceError / InvalidCharacterError 또는 NamespaceError
