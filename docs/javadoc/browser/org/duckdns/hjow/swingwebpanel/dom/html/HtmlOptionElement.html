public final class HtmlOptionElement
extends HtmlControl

The option element (HTML Standard 4.10.10): one choice of a select or one suggestion of a datalist. Besides its attributes it has the state "selectedness" (whether it is selected) and "dirtiness" (whether the user or a script changed the selectedness, which stops the selected attribute from changing it). The selection rules between the options of a single-choice select belong to HtmlSelectElement.

option 요소(HTML 표준 4.10.10): select 의 선택지 하나 또는 datalist 의 제안 하나. 속성 외에 "selectedness"(선택되었는지)와 "dirtiness"(사용자나 스크립트가 selectedness 를 바꿨는지. 바꿨으면 selected 속성이 더는 바꾸지 못한다) 상태를 가진다. 단일 선택 select 의 option 사이의 선택 규칙은 HtmlSelectElement 가 맡는다.
