Class Event

Direct Known Subclasses:
AnimationPlaybackEvent, BeforeUnloadEvent, ClipboardEvent, CloseEvent, CssAnimationEvent, CustomEvent, ErrorEvent, HashChangeEvent, MediaQueryListEvent, MessageEvent, PageTransitionEvent, PopStateEvent, ProgressEvent, StorageEvent, SubmitEvent, TrackEvent, UiEvent
public class Event
extends java.lang.Object

A DOM event (DOM Standard section 2). It carries the event type, the flags that control propagation and cancellation, and, during dispatch, the target, current target and phase. Subclasses add event specific data (mouse position, key, ...). An event can be dispatched with EventTarget.dispatchEvent(Event); after the dispatch, isDefaultPrevented() tells the caller whether the default action must be skipped.

DOM 이벤트(DOM 표준 2절). 이벤트 종류, 전파와 취소를 제어하는 플래그, 그리고 전달 중의 대상, 현재 대상, 단계를 가진다. 하위 클래스가 이벤트별 데이터(마우스 위치, 키 등)를 더한다. 이벤트는 EventTarget.dispatchEvent(Event) 로 전달하며, 전달 후 isDefaultPrevented() 가 호출자에게 기본 동작을 건너뛰어야 하는지 알려 준다.
