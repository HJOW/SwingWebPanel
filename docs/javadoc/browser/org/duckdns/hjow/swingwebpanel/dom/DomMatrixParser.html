Class DomMatrixParser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.DomMatrixParser

public final class DomMatrixParser
extends java.lang.Object

Parses the string form of a matrix, a CSS transform list, into a DomMatrix (section 6.2 of the Geometry Interfaces Module, "parse a string into an abstract matrix"; used by new DOMMatrix(string) and setMatrixValue()). The grammar is that of the CSS transform property: none, or a whitespace separated list of the functions matrix, matrix3d, translate, translateX/Y/Z, translate3d, scale, scaleX/Y/Z, scale3d, rotate, rotateX/Y/Z, rotate3d, skew, skewX/Y and perspective with comma separated arguments. Lengths must have an absolute unit (px, cm, mm, q, in, pt, pc) or be a plain 0; relative units and calc() make the string invalid, as the specification demands for units that need a context. Angles are deg, grad, rad, turn or a plain 0. The result is 2D when only the 2D functions are used; the 3D functions (including rotateZ(), which the module counts as 3D) produce a 3D matrix. The list is multiplied left to right.

행렬의 문자열 형태인 CSS transform 목록을 DomMatrix 로 해석한다(Geometry Interfaces Module 6.2 절 "parse a string into an abstract matrix", new DOMMatrix(문자열) 과 setMatrixValue() 가 쓴다). 문법은 CSS transform 속성과 같다: none 이거나, 쉼표로 구분한 인수를 가진 함수 matrix, matrix3d, translate, translateX/Y/Z, translate3d, scale, scaleX/Y/Z, scale3d, rotate, rotateX/Y/Z, rotate3d, skew, skewX/Y, perspective 를 공백으로 구분한 목록이다. 길이는 절대 단위(px, cm, mm, q, in, pt, pc)이거나 단위 없는 0 이어야 한다. 문맥이 필요한 상대 단위와 calc() 는 규격이 요구하듯 문자열을 무효로 만든다. 각도는 deg, grad, rad, turn 이거나 단위 없는 0 이다. 2D 함수만 쓰면 결과는 2D 이고, 3D 함수(모듈이 3D 로 세는 rotateZ() 포함)를 쓰면 3D 행렬이다. 목록은 왼쪽에서 오른쪽으로 곱한다.
