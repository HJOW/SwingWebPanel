org.duckdns.hjow.swingwebpanel.dom.edit
Class EditingHosts

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.edit.EditingHosts

public final class EditingHosts
extends java.lang.Object

Which parts of a document the user can edit (HTML Standard, "Editing", 6.8): the state of the contenteditable attribute, the editing hosts, and the editable nodes. An editing host is an HTML element whose contenteditable is in the true or the plaintext-only state, or, when the document is in design mode, the root element of the document; a node is editable when it is inside an editing host and no element on the way says contenteditable="false". The class has only static methods and reads the attributes of the DOM, so it works without layout.

사용자가 문서의 어느 부분을 편집할 수 있는지(HTML Standard "Editing" 6.8): contenteditable 속성의 상태, 편집 호스트(editing host), 편집 가능한 노드. 편집 호스트는 contenteditable 가 true 나 plaintext-only 상태인 HTML 요소이거나, 문서가 디자인 모드이면 문서의 루트 요소이다. 노드는 편집 호스트 안에 있고 그 사이의 어느 요소도 contenteditable="false" 가 아닐 때 편집 가능하다. 정적 메서드만 있고 DOM 의 속성을 읽으므로 레이아웃 없이 동작한다.

hostOf

public static Element hostOf(Node n)
Returns the editing host of a node: the outermost editing host that contains the node (or is the node) without a contenteditable="false" element between them, or null if the node is not editable. A host inside another editable region belongs to that outer region, as in the browsers.

노드의 편집 호스트를 반환한다: 노드를 포함하는(또는 노드 자신인) 가장 바깥의 편집 호스트이며 둘 사이에 contenteditable="false" 요소가 없다. 노드가 편집 가능하지 않으면 null. 편집 가능한 영역 안의 호스트는 브라우저처럼 그 바깥 영역에 속한다.
