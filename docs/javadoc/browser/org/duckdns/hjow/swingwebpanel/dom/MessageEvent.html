Class MessageEvent

public class MessageEvent
extends Event

The message event (MessageEvent, W3C Web Messaging 3): fired for a message of cross-document messaging (window.postMessage) and of channel messaging (MessagePort). Its data is the cloned message, its origin the origin of the sender (empty for channel messaging), its source the sending window, and its ports the ports that came with the message. The data is an arbitrary object; the JavaScript layer keeps a script value in it.

message 이벤트(MessageEvent, W3C Web Messaging 3): 문서 간 메시징(window.postMessage)과 채널 메시징(MessagePort)의 메시지에 발생한다. data 는 복제된 메시지, origin 은 보낸 쪽의 오리진(채널 메시징은 빈 문자열), source 는 보낸 window, ports 는 메시지와 함께 온 포트이다. 데이터는 임의의 객체이며 JavaScript 계층은 스크립트 값을 담는다.
