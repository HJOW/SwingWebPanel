public final class HtmlFieldSetElement
extends HtmlListedElement

The fieldset element (HTML Standard 4.10.15). A fieldset is a listed element that is barred from constraint validation. Its disabled attribute disables the form controls inside it, except those inside its first legend child (see HtmlListedElement.isDisabled()); this class provides that first legend and the elements collection.

fieldset 요소(HTML 표준 4.10.15). fieldset 은 목록에 오르는 요소이며 제약 검증에서 제외된다. disabled 속성은 안의 폼 컨트롤을 비활성으로 만들고, 첫 legend 자식 안의 컨트롤만 예외이다(HtmlListedElement.isDisabled() 참조). 이 클래스는 그 첫 legend 와 elements 컬렉션을 제공한다.
