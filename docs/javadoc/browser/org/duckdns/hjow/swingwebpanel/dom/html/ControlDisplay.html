org.duckdns.hjow.swingwebpanel.dom.html
Class ControlDisplay

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.ControlDisplay

public final class ControlDisplay
extends java.lang.Object

Read-only helpers that tell the renderer and the layout what a form control shows: which kind of control an element is, the label of a button, the text of a text field (the placeholder when it is empty), the labels of the options of a select element. They only read the live state of the controls, so they must be called on the document thread (or on a thread that owns the document).

렌더러와 레이아웃에 폼 컨트롤이 무엇을 보여 주는지 알려 주는 읽기 전용 도우미: 요소가 어떤 종류의 컨트롤인지, 버튼의 라벨, 텍스트 필드의 글(비어 있으면 placeholder), select 요소의 option 라벨. 컨트롤의 살아 있는 상태만 읽으므로 문서 스레드(또는 문서를 소유한 스레드)에서 불러야 한다.

public static java.util.List<Element> rowElements(Element select)
Returns the rows of a select element in the order in which a list shows them: an optgroup element (a label row) is followed by its option children, and option children of the select element itself stand alone. The renderer and the host use the same list, so that the row under the mouse is the same element in both.
