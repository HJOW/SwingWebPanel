Package org.duckdns.hjow.swingwebpanel.dom.edit

Interface Summary
Editor.Environment What the engine needs from the host: how events are sent, and the facts about the page that only the layout knows.
 

Class Summary
EditingHosts Which parts of a document the user can edit (HTML Standard, "Editing", 6.8): the state of the contenteditable attribute, the editing hosts, and the editable nodes.
Editor The editing engine of one document (plan item P20-06): it changes the DOM the way the browsers do when the user types, deletes, breaks a line, formats, cuts, pastes or drops in an editing host (contenteditable or design mode), and it is the implementation of document.execCommand().
UndoManager The undo history of the editor: every editing operation is recorded as the list of DOM mutations that it caused (the MutationRecords of the document, which carry the old values), and undoing replays the inverse of those mutations in reverse order, so that the DOM is exactly as it was and the nodes keep their identity.
