Class Namespaces

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Namespaces

public final class Namespaces
extends java.lang.Object

Namespace URIs and the name validation rules of the DOM Standard (validate and extract, XML Name production, ASCII whitespace helpers). The name checks follow the XML 1.0 (fifth edition) Name and QName productions closely enough for HTML and XML documents; characters outside the Basic Multilingual Plane are accepted as name characters.

네임스페이스 URI 와 DOM 표준의 이름 검증 규칙(validate and extract, XML Name 생성 규칙, ASCII 공백 도우미). 이름 검사는 HTML 과 XML 문서에 충분하도록 XML 1.0(제5판)의 Name, QName 생성 규칙을 따르며 기본 다국어 평면 밖의 문자는 이름 문자로 받아들인다.
