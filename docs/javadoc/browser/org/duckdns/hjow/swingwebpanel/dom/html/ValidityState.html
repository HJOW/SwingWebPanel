org.duckdns.hjow.swingwebpanel.dom.html
Class ValidityState

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.ValidityState

public final class ValidityState
extends java.lang.Object

The ValidityState of a form control (HTML Standard 4.10.21.3): which constraints the control currently violates. The object is a live view: every getter asks the control, so the same object can be kept and read again after the control changed.

폼 컨트롤의 ValidityState(HTML 표준 4.10.21.3): 컨트롤이 지금 어떤 제약을 어기고 있는지. 이 객체는 라이브 뷰이다. 모든 getter 가 컨트롤에 물어보므로 같은 객체를 두고 컨트롤이 바뀐 뒤 다시 읽어도 된다.
