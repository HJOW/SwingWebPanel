Class DomMatrixReadOnly

DomMatrix
public class DomMatrixReadOnly
extends java.lang.Object

A 4x4 matrix of the geometry interfaces (DOMMatrixReadOnly, Geometry Interfaces Module Level 1, section 6): the sixteen elements m11 to m44 and the flag is2D. The elements are stored in column-major order (the first four numbers are m11, m12, m13, m14, the first column; m41, m42, m43 are the translation), the way the specification, matrix3d() and toFloat64Array() list them; a to f are the aliases m11, m12, m21, m22, m41, m42. Points are column vectors, a matrix transforms a point as M x p, and the multiplication methods post-multiply (A.multiplySelf(B) is A x B, so B is applied to a point first). This class only reads; the variant that scripts and the canvas may change is DomMatrix. There is no 3D rendering: 3D values are stored, multiplied and inverted, and the canvas uses only the 2D part (see the canvas notes in docs/progress/canvas.md).

기하 인터페이스의 4x4 행렬(DOMMatrixReadOnly, Geometry Interfaces Module Level 1, 6 절): 열여섯 요소 m11 ~ m44 와 플래그 is2D. 요소는 열 우선 순서로 저장한다(처음 네 숫자가 첫 열인 m11, m12, m13, m14 이고 m41, m42, m43 이 이동이다). 규격과 matrix3d(), toFloat64Array() 가 나열하는 순서와 같다. a ~ f 는 m11, m12, m21, m22, m41, m42 의 별칭이다. 점은 열 벡터이고 행렬은 점을 M x p 로 변환하며, 곱셈 메서드는 뒤에 곱한다(A.multiplySelf(B) 는 A x B 이므로 점에는 B 가 먼저 적용된다). 이 클래스는 읽기만 하며 스크립트와 캔버스가 바꿀 수 있는 변종은 DomMatrix 이다. 3D 그리기는 없다: 3D 값은 저장, 곱셈, 역행렬만 하고 캔버스는 2D 부분만 쓴다(docs/progress/canvas.md 의 캔버스 메모 참고).

transformPoint

public DomPoint transformPoint(DomPointReadOnly p)
Transforms a point (section 2.1 of the module): the point as a column vector (x, y, z, w) is pre-multiplied by this matrix. A 2D matrix with a point whose z is 0 and w is 1 uses only the 2D part, so the other elements never turn an infinite coordinate into NaN.

점을 변환한다(모듈 2.1 절): 열 벡터 (x, y, z, w) 인 점에 이 행렬을 앞에서 곱한다. 2D 행렬이고 점의 z 가 0, w 가 1 이면 2D 부분만 쓰므로 다른 요소가 무한대 좌표를 NaN 으로 만들지 않는다.

Parameters:
p - the point / 점
Returns:
