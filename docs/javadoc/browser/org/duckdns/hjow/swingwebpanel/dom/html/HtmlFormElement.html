public final class HtmlFormElement
extends HtmlControl

The form element (HTML Standard 4.10.3): the owner of a group of form controls. It provides the elements collection, the enumerated attributes method and enctype, and the algorithms of the standard: submit() and requestSubmit() (the form submission algorithm: interactive constraint validation, the cancelable submit event, constructing the entry list, picking the encoding, encoding the entries for the method and enctype and the action URL), reset() (the cancelable reset event and the reset algorithm of every resettable control), checkValidity(), reportValidity() and implicit submission. The navigation itself is up to the FormHost.

form 요소(HTML 표준 4.10.3): 폼 컨트롤 묶음의 소유자. elements 컬렉션, 열거형 속성 method, enctype, 표준의 알고리즘을 제공한다: submit() 과 requestSubmit()(폼 제출 알고리즘: 대화형 제약 검증, 취소 가능한 submit 이벤트, 항목 목록 만들기, 인코딩 고르기, method 와 enctype 과 action URL 에 맞게 항목 인코딩), reset()(취소 가능한 reset 이벤트와 초기화 가능한 모든 컨트롤의 초기화 알고리즘), checkValidity(), reportValidity(), 암묵적 제출. 이동 자체는 FormHost 의 몫이다.

implicitSubmit

public void implicitSubmit()
Implements implicit submission (the user pressed Enter in a text field): if the form has a default button it receives a click (nothing happens if the button is disabled); without one the form is submitted only if it has at most one field that blocks implicit submission. The host calls it when the Enter key is pressed in a text control.

암묵적 제출을 구현한다(사용자가 텍스트 필드에서 Enter 를 눌렀다): 폼에 기본 버튼이 있으면 그 버튼에 클릭을 보낸다(버튼이 비활성이면 아무 일도 없다). 기본 버튼이 없으면 암묵적 제출을 막는 필드가 하나 이하일 때만 폼을 제출한다. 호스트가 텍스트 컨트롤에서 Enter 키를 눌렀을 때 부른다.
