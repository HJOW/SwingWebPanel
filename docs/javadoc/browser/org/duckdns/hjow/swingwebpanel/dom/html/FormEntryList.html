public final class FormEntryList
extends java.lang.Object

"Constructing the entry list" of a form (HTML Standard 4.10.22.4): the list of name and value pairs that a submission (and new FormData(form)) contains. It walks the submittable elements whose form owner is the form, in tree order, and skips the controls that a submission must skip (disabled controls, controls without a name, unchecked checkboxes and radio buttons, buttons other than the submitter, controls inside a datalist). Image buttons contribute the coordinates of the click, file upload controls the selected files (or an empty file), select elements their selected options, and an _charset_ hidden input the name of the encoding.

폼의 "constructing the entry list"(HTML 표준 4.10.22.4): 제출(과 new FormData(form))이 담는 이름과 값 쌍의 목록. 폼 소유자가 그 폼인 제출 가능 요소를 트리 순서로 훑으며 제출이 건너뛰어야 하는 컨트롤(비활성 컨트롤, 이름 없는 컨트롤, 체크되지 않은 체크박스와 라디오 버튼, submitter 가 아닌 버튼, datalist 안의 컨트롤)을 건너뛴다. 이미지 버튼은 클릭 좌표를, 파일 업로드 컨트롤은 선택한 파일(또는 빈 파일)을, select 는 선택한 option 을, _charset_ hidden input 은 인코딩 이름을 낸다.
