Class PageTransitionEvent

public class PageTransitionEvent
extends Event

The pageshow and pagehide events (PageTransitionEvent, HTML5 2014 REC section 5.5.? "Page show and page hide events"): persisted tells whether the page came from or goes into a back-forward cache. This component has no such cache, so persisted is always false; the event is fired at the window after the load event. It does not bubble and cannot be cancelled.

pageshow, pagehide 이벤트(PageTransitionEvent, HTML5 2014 REC "Page show and page hide events"): persisted 는 페이지가 뒤로/앞으로 이동 캐시에서 왔는지, 그곳으로 가는지 알려 준다. 이 컴포넌트에는 그런 캐시가 없으므로 persisted 는 항상 false 이며, 이벤트는 load 이벤트 뒤에 window 에 발생한다. 버블링하지 않고 취소할 수 없다.
