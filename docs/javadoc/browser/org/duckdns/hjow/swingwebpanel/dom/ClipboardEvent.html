public class ClipboardEvent
extends Event

The clipboard events copy, cut and paste (ClipboardEvent, Clipboard API and events): a cancelable, bubbling event with the ClipboardData of the operation. The component fires copy at the element that has the focus (the body if none has it) when the user copies the selection; a listener that calls preventDefault replaces what the user selected with the data it put into getClipboardData().

클립보드 이벤트 copy, cut, paste(ClipboardEvent, Clipboard API and events): 취소할 수 있고 버블하는 이벤트이며 작업의 ClipboardData 를 가진다. 컴포넌트는 사용자가 선택을 복사할 때 포커스를 가진 요소(없으면 body)에 copy 를 보내며, preventDefault 를 부른 리스너는 사용자가 선택한 것 대신 getClipboardData() 에 넣은 데이터를 쓴다.
