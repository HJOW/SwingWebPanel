public abstract class HtmlListedElement
extends HtmlControl

The base class of the listed form-associated elements (button, fieldset, input, output, select, textarea): the form owner (the form attribute, the owner that the parser assigned, or the nearest form ancestor), the disabled state including the effect of a disabled fieldset, and the constraint validation API (willValidate, validity, validationMessage, setCustomValidity, checkValidity, reportValidity). Subclasses compute which constraints they violate.

목록에 오르는 폼 연관 요소(button, fieldset, input, output, select, textarea)의 기반 클래스: 폼 소유자(form 속성, 파서가 지정한 소유자, 가장 가까운 form 조상), 비활성 fieldset 의 영향을 포함한 disabled 상태, 제약 검증 API(willValidate, validity, validationMessage, setCustomValidity, checkValidity, reportValidity). 하위 클래스가 어떤 제약을 어기는지 계산한다.

public final boolean checkValidity()
