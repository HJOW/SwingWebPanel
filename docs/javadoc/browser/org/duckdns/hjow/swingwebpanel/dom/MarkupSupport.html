Interface MarkupSupport

All Known Implementing Classes:
HtmlMarkupSupport
public interface MarkupSupport

Parsing and serializing of markup, provided by the HTML (or XML) layer. The DOM methods innerHTML, outerHTML and insertAdjacentHTML delegate to it (plan items P07-06 and P20-04). Until the HTML layer installs an implementation with Document.setMarkupSupport(MarkupSupport), these DOM methods throw a NotSupportedError.

HTML(또는 XML) 계층이 제공하는 마크업 해석과 직렬화. DOM 메서드 innerHTML, outerHTML, insertAdjacentHTML 이 여기에 위임한다(계획 P07-06, P20-04). HTML 계층이 Document.setMarkupSupport(MarkupSupport) 로 구현을 설치하기 전에는 이 DOM 메서드들이 NotSupportedError 를 던진다.
