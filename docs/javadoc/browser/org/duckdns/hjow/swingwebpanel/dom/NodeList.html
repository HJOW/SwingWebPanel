public interface NodeList

An ordered list of nodes (NodeList). It is live when it comes from Node.getChildNodes() and static when it is the result of a selector query.

노드의 순서 있는 목록(NodeList). Node.getChildNodes() 에서 온 것은 라이브이고 선택자 질의의 결과는 정적이다.
