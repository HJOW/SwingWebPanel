org.duckdns.hjow.swingwebpanel.dom
Class TreeWalker

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Traversal
      org.duckdns.hjow.swingwebpanel.dom.TreeWalker

public final class TreeWalker
extends Traversal

A walker over the nodes of a subtree that sees the tree structure (DOM Standard, "Interface TreeWalker"): besides the document order traversal of nextNode() and previousNode() it moves to the parent, the first and last child and the siblings of its current node, always over the nodes that the NodeFilter and whatToShow accept. A node that the filter rejects hides its whole subtree from the walker, a skipped node only itself. The current node can be set to any node; it is not adjusted when nodes are removed.

하위 트리의 노드를 트리 구조를 보며 걷는 도구(DOM 표준 "Interface TreeWalker"): nextNode(), previousNode() 의 문서 순서 탐색 외에 현재 노드의 부모, 첫째/마지막 자식, 형제로 옮겨 가며 언제나 NodeFilter 와 whatToShow 가 받아들이는 노드만 넘어간다. 필터가 거부한 노드는 하위 트리 전체를, 건너뛴 노드는 자신만 걷는 도구에게서 감춘다. 현재 노드는 아무 노드로나 지정할 수 있으며 노드가 제거되어도 조정하지 않는다.
