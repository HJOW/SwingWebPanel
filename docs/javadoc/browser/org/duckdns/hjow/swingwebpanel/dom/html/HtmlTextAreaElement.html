public final class HtmlTextAreaElement
extends HtmlListedElement

The textarea element (HTML Standard 4.10.11): a multi-line plain text control. Its state is the "raw value", the "dirty value flag" (once the value was set, the child text no longer defines it), the "last changed by a user edit" flag that maxlength and minlength checks need, and the selection. The "API value" that scripts read and that is submitted is the raw value with every line break normalized to LF (submission turns them into CRLF); the default value is the text of its child text nodes.

textarea 요소(HTML 표준 4.10.11): 여러 줄 일반 텍스트 컨트롤. 상태는 "raw value", "dirty value flag"(값이 한 번 지정되면 자식 글이 더는 값을 정의하지 않는다), maxlength/minlength 검사에 필요한 "사용자 편집으로 마지막에 바뀜" 플래그, 선택이다. 스크립트가 읽고 제출되는 "API value" 는 모든 줄 바꿈을 LF 로 정규화한 raw value 이다(제출할 때 CRLF 가 된다). 기본값은 자식 텍스트 노드의 글이다.

setValueFromUser

public void setValueFromUser(java.lang.String value)
Sets the value as a result of an edit by the user (the host calls this when the user typed, pasted or deleted text). The value becomes dirty and "changed by the user", which enables the maxlength and minlength checks. The host fires the input event afterwards with HtmlControl.fireInputEvent(String, String).

사용자의 편집 결과로 값을 지정한다(사용자가 글을 입력, 붙여넣기, 삭제했을 때 호스트가 부른다). 값은 dirty 가 되고 "사용자가 바꿈"이 되어 maxlength, minlength 검사가 켜진다. 호스트는 이어서 HtmlControl.fireInputEvent(String, String) 로 input 이벤트를 발생시킨다.

setSelectionFromUser

public void setSelectionFromUser(int start,
                                 int end,
                                 java.lang.String direction)
Records the selection that the user made in the editor of the host (the caret moved, text was selected). Unlike setSelectionRange(int, int, String) it does not tell the host that the state changed (the host made the change itself), and a select event is fired only if some text is selected afterwards.

사용자가 호스트의 편집기에서 만든 선택(캐럿 이동, 글 선택)을 기록한다. setSelectionRange(int, int, String) 와 달리 호스트에 상태가 바뀌었다고 알리지 않으며(호스트가 직접 바꾼 것), 선택된 글이 있을 때만 select 이벤트를 발생시킨다.

Parameters:
start - the start / 시작
end - the end / 끝
direction - forward, backward or none / forward, backward, none
