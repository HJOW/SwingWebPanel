public final class HtmlInputElement
extends HtmlListedElement

The input element (HTML Standard 4.10.5), the most varied form control: its type attribute selects one of 22 states (InputKinds), and the state decides the value mode, the value sanitization, the constraints and the activation behavior. What this class keeps besides the attributes is the state that the standard defines for the control: the value (and the "dirty value flag" that stops the value attribute from changing it), the checkedness (and its dirty flag), the indeterminateness, the list of selected files, the selection of text controls and the "bad input" report of the host. Every IDL attribute and method works on that state, never on the content attribute alone.

input 요소(HTML 표준 4.10.5): 가장 다양한 폼 컨트롤. type 속성이 22개 상태(InputKinds) 중 하나를 고르고, 상태가 value 모드, 값 정리, 제약, 활성화 동작을 정한다. 이 클래스가 속성 외에 가지는 것은 표준이 컨트롤에 정의한 상태이다: 값(과 value 속성이 값을 바꾸지 못하게 하는 "dirty value flag"), checkedness(와 그 dirty 플래그), indeterminateness, 선택한 파일 목록, 텍스트 컨트롤의 선택, 호스트의 "bad input" 보고. 모든 IDL 속성과 메서드는 콘텐츠 속성만이 아니라 이 상태에 대해 동작한다.

setSelectionFromUser

public void setSelectionFromUser(int start,
                                 int end,
                                 java.lang.String direction)
Records the selection that the user made in the editor of the host (the caret moved, text was selected). Unlike setSelectionRange(int, int, String) it does not tell the host that the state changed (the host made the change itself), and a select event is fired only if some text is selected afterwards. Types without a selection ignore the call.

사용자가 호스트의 편집기에서 만든 선택(캐럿 이동, 글 선택)을 기록한다. setSelectionRange(int, int, String) 와 달리 호스트에 상태가 바뀌었다고 알리지 않으며(호스트가 직접 바꾼 것), 선택된 글이 있을 때만 select 이벤트를 발생시킨다. 선택이 없는 종류는 호출을 무시한다.

Parameters:

end - the end / 끝
