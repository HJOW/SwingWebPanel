Class ElementCollection

Direct Known Subclasses:
PropertiesCollection
public abstract class ElementCollection
extends java.lang.Object

A live collection of elements (HTMLCollection): the result of getElementsByTagName, getElementsByClassName and children. It re-reads the tree when the document changed since the last access and otherwise answers from a cache, so repeated access in a loop stays cheap while the result always reflects the current tree.

요소의 라이브 컬렉션(HTMLCollection): getElementsByTagName, getElementsByClassName, children 의 결과. 마지막 접근 뒤에 문서가 바뀌었으면 트리를 다시 읽고, 아니면 캐시로 답하므로 반복문에서 되풀이해 접근해도 저렴하면서 결과는 항상 현재 트리를 반영한다.
