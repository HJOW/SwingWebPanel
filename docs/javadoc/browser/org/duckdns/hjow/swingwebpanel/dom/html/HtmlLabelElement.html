public final class HtmlLabelElement
extends HtmlControl

The label element (HTML Standard 4.10.4). Its labeled control is the labelable element that the for attribute names (an element of the same tree that is labelable), or, without that attribute, its first labelable descendant. Activating a label (a click that is not on interactive content inside it) focuses and clicks the labeled control.

label 요소(HTML 표준 4.10.4). labeled control 은 for 속성이 가리키는, 같은 트리에서 라벨을 붙일 수 있는 요소이며, 속성이 없으면 첫 번째 라벨을 붙일 수 있는 후손이다. label 을 활성화하면(안의 상호작용 콘텐츠가 아닌 곳의 클릭) labeled control 에 포커스를 주고 클릭한다.
