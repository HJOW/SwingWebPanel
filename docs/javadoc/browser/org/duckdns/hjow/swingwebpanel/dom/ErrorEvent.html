Class ErrorEvent

      org.duckdns.hjow.swingwebpanel.dom.ErrorEvent

public class ErrorEvent
extends Event

The error event of a runtime script error (ErrorEvent, HTML Standard "Runtime script errors"): it carries the message, the filename of the script, the line and the column (lineno, colno) and the thrown value (error). A worker fires one at its own global scope for an uncaught error, and then at the Worker object of the page (with a null error, because the thrown value cannot leave the worker). The thrown value is an arbitrary object; the JavaScript layer keeps a script value in it.

실행 중 스크립트 오류의 error 이벤트(ErrorEvent, HTML 표준 "Runtime script errors"): message, 스크립트의 filename, 줄과 열(lineno, colno), 던져진 값(error)을 가진다. worker 는 잡히지 않은 오류에 대해 자기 전역 범위에 하나를 발생시키고, 이어서 페이지의 Worker 객체에도 발생시킨다(던져진 값은 worker 밖으로 나갈 수 없으므로 error 는 null). 던져진 값은 임의의 객체이며 JavaScript 계층은 스크립트 값을 담는다.
