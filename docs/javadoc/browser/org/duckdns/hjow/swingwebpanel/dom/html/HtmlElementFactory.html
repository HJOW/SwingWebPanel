ElementFactory
public final class HtmlElementFactory
extends java.lang.Object
implements ElementFactory

The default element factory of documents: it creates the specialized classes of the HTML form elements (form, input, button, select, option, optgroup, textarea, label, fieldset, legend, datalist, output, progress, meter) for the HTML namespace and HtmlGenericElement for everything else. Names are matched in lower case, as the HTML parser and createElement of an HTML document produce them; an XML document keeps the case, so <INPUT> of an XHTML document is a plain element.

문서의 기본 요소 팩터리: HTML 네임스페이스의 HTML 폼 요소(form, input, button, select, option, optgroup, textarea, label, fieldset, legend, datalist, output, progress, meter)에는 특화된 클래스를, 그 밖의 모든 것에는 HtmlGenericElement 를 만든다. 이름은 HTML 파서와 HTML 문서의 createElement 가 만드는 대로 소문자로 비교한다. XML 문서는 대소문자를 유지하므로 XHTML 문서의 <INPUT> 은 일반 요소이다.
