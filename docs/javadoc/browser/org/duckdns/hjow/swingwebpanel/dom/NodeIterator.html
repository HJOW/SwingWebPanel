Class NodeIterator

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Traversal
      org.duckdns.hjow.swingwebpanel.dom.NodeIterator

public final class NodeIterator
extends Traversal

A flat, live iterator over the nodes of a subtree in tree order (DOM Standard, "Interface NodeIterator"). It sits at a reference node, before or after it; nextNode() and previousNode() move over the next node that the NodeFilter and whatToShow accept. It is live: when a node that holds the reference node is removed from the tree, the iterator moves its reference so that it stays valid (the "NodeIterator pre-removing steps"). One restriction against the Standard: when the removed node contains the root of the iterator itself, nothing moves.

하위 트리의 노드를 트리 순서로 훑는 평평하고 살아 있는 반복자(DOM 표준 "Interface NodeIterator"). 기준 노드의 앞이나 뒤에 서 있고 nextNode(), previousNode() 는 NodeFilter 와 whatToShow 가 받아들이는 다음 노드를 넘어간다. 살아 있다: 기준 노드를 가진 노드가 트리에서 제거되면 반복자가 유효하게 남도록 기준을 옮긴다("NodeIterator pre-removing steps"). 표준과 다른 제한 하나: 제거되는 노드가 반복자의 루트 자신을 포함하면 아무것도 옮기지 않는다.
