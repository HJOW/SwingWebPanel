Class XmlSerializer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.XmlSerializer

public final class XmlSerializer
extends java.lang.Object

The XML serialization of a DOM node, as defined for XMLSerializer (W3C DOM Parsing and Serialization, "XML Serialization", with the require well-formed flag unset): elements and attributes are written so that their namespaces are kept, with prefixes and namespace declarations added, replaced or dropped as needed (xmlns and xmlns:prefix are generated where a namespace has no usable prefix; ns1, ns2 ... are generated prefixes); an HTML element without children is written with a start and end tag, except the void elements, which are written as <br />; elements of other namespaces without children are written as <a/>; text escapes & < >, attribute values also escape the quotation mark, tab, line feed and carriage return. Documents, document fragments, comments, CDATA sections, processing instructions and document types are serialized too. This is not the HTML serialization of innerHTML.

DOM 노드의 XML 직렬화. XMLSerializer 가 쓰는 방식이다(W3C DOM Parsing and Serialization 의 "XML Serialization", require well-formed 플래그는 끈 상태): 요소와 속성은 네임스페이스가 유지되도록 쓰며, 필요하면 접두사와 네임스페이스 선언을 더하거나 바꾸거나 버린다(쓸 만한 접두사가 없는 네임스페이스에는 xmlns 와 xmlns:prefix 를 만들고, 만든 접두사는 ns1, ns2 ...). 자식이 없는 HTML 요소는 시작·끝 태그로 쓰되 void 요소만 <br /> 로 쓰고, 다른 네임스페이스의 자식 없는 요소는 <a/> 로 쓴다. 텍스트는 & < > 를 이스케이프하고 속성 값은 따옴표, 탭, 줄바꿈, 캐리지 리턴도 이스케이프한다. 문서, 문서 조각, 주석, CDATA 섹션, 처리 명령, 문서 유형도 직렬화한다. innerHTML 의 HTML 직렬화와는 다르다.
