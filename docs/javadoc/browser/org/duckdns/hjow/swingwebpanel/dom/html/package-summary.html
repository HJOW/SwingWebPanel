Package org.duckdns.hjow.swingwebpanel.dom.html

Interface Summary
FormHost The services that the browser component provides to the form controls of a document.
 

Class Summary
ControlDisplay Read-only helpers that tell the renderer and the layout what a form control shows: which kind of control an element is, the label of a button, the text of a text field (the placeholder when it is empty), the labels of the options of a select element.
FileEntry One file that the user selected for a file upload control (input type=file): the file name without any directory, the MIME type, the modification time and the bytes.
FileList The list of the files selected in a file upload control (input.files): an immutable snapshot.
FormControlsCollection The HTMLFormControlsCollection of a form (form.elements): the live list of its listed elements, in tree order (image buttons excluded for historical reasons).
FormElementList A live list of elements that the form layer exposes (form.elements, select.options, select.selectedOptions, control.labels, datalist.options, radio node lists).
FormEntry One entry of a form's entry list (HTML Standard 4.10.22.4): a name and a value that is either a string or a file.
FormEntryList "Constructing the entry list" of a form (HTML Standard 4.10.22.4): the list of name and value pairs that a submission (and new FormData(form)) contains.
FormHostAdapter A FormHost whose methods do nothing (submissions are dropped, invalid controls are not shown, no file can be chosen, state changes are ignored).
FormStates The form related selector states of the elements that the form layer implements (HTML Standard 4.16.3 "Pseudo-classes"): :checked, :disabled, :enabled, :indeterminate, :default, :required, :optional, :read-write, :valid, :invalid, :in-range, :out-of-range and :placeholder-shown.
FormSubmission The result of a form submission: what the host must request.
FormSupport The per-document support of the HTML form controls.
HtmlButtonElement The button element (HTML Standard 4.10.6).
HtmlControl The base class of the HTML elements that take part in forms (form, input, button, select, option, textarea, label, fieldset ...).
HtmlDataListElement The datalist element (HTML Standard 4.10.10): a set of suggested values for an input.
HtmlElementFactory The default element factory of documents: it creates the specialized classes of the HTML form elements (form, input, button, select, option, optgroup, textarea, label, fieldset, legend, datalist, output, progress, meter) for the HTML namespace and HtmlGenericElement for everything else.
HtmlFieldSetElement The fieldset element (HTML Standard 4.10.15).
HtmlFormElement The form element (HTML Standard 4.10.3): the owner of a group of form controls.
HtmlGenericElement An element that has no specialized class: every element that the HtmlElementFactory does not know (other HTML elements, SVG, MathML, custom names).
HtmlInputElement The input element (HTML Standard 4.10.5), the most varied form control: its type attribute selects one of 22 states (InputKinds), and the state decides the value mode, the value sanitization, the constraints and the activation behavior.
HtmlLabelElement The label element (HTML Standard 4.10.4).
HtmlLegendElement The legend element (HTML Standard 4.10.16).
HtmlListedElement The base class of the listed form-associated elements (button, fieldset, input, output, select, textarea): the form owner (the form attribute, the owner that the parser assigned, or the nearest form ancestor), the disabled state including the effect of a disabled fieldset, and the constraint validation API (willValidate, validity, validationMessage, setCustomValidity, checkValidity, reportValidity).
HtmlMeterElement The meter element (HTML Standard 4.10.14): a scalar measurement within a known range.
HtmlOptGroupElement The optgroup element (HTML Standard 4.10.9): a labelled group of the options of a select.
HtmlOptionElement The option element (HTML Standard 4.10.10): one choice of a select or one suggestion of a datalist.
HtmlOptionsCollection The HTMLOptionsCollection of a select (select.options): the live list of its options, which, unlike a plain collection, can be changed: length, add, remove, selectedIndex and assignment to an index.
HtmlOutputElement The output element (HTML Standard 4.10.12): the result of a calculation.
HtmlProgressElement The progress element (HTML Standard 4.10.13): a completion bar.
HtmlSelectElement The select element (HTML Standard 4.10.7): a choice of one option (or of several with multiple).
HtmlTextAreaElement The textarea element (HTML Standard 4.10.11): a multi-line plain text control.
RadioNodeList The RadioNodeList (HTML Standard 2.7.2.?
SubmitEvent The submit event (HTML Standard 4.10.22.10 SubmitEvent): fired at a form before it is submitted, cancelable and bubbling.
TableOps The table object model of the HTML specification (HTML5 2014 REC section 4.9, interfaces HTMLTableElement, HTMLTableSectionElement, HTMLTableRowElement and HTMLTableCellElement): the parts of a table (caption, tHead, tFoot, tBodies), the live collections of rows and cells, and the operations that create, insert and delete them with the index rules of the specification (an index of -1 means the end, an index outside the range is an IndexSizeError).
ValidityState The ValidityState of a form control (HTML Standard 4.10.21.3): which constraints the control currently violates.
