public final class HtmlSelectElement
extends HtmlListedElement

The select element (HTML Standard 4.10.7): a choice of one option (or of several with multiple). The options and their selectedness are the state of the control; this class implements the "selectedness setting algorithm" (a single-choice select with a display size of 1 always has one selected option unless all are disabled, and never more than one), the value, selectedIndex, options and selectedOptions APIs, the reset algorithm and the constraint validation of a required select. The rules are applied lazily: a change of the options only marks them pending and the next read applies them, so that building a select with thousands of options does not cost quadratic time.

select 요소(HTML 표준 4.10.7): option 하나(multiple 이면 여러 개)의 선택. option 과 그 selectedness 가 컨트롤의 상태이며, 이 클래스는 "selectedness setting algorithm"(표시 크기 1 인 단일 선택 select 는 모두 비활성이 아닌 한 항상 하나가 선택되고 둘 이상은 선택되지 않는다), value, selectedIndex, options, selectedOptions API, 초기화 알고리즘, 필수 select 의 제약 검증을 구현한다. 규칙은 게으르게 적용한다: option 이 바뀌면 보류 표시만 하고 다음 읽기에서 적용하므로 수천 개의 option 으로 select 를 만들어도 제곱 시간이 들지 않는다.
