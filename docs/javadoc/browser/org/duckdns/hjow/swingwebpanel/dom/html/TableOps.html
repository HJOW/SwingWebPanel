org.duckdns.hjow.swingwebpanel.dom.html
Class TableOps

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.TableOps

public final class TableOps
extends java.lang.Object

The table object model of the HTML specification (HTML5 2014 REC section 4.9, interfaces HTMLTableElement, HTMLTableSectionElement, HTMLTableRowElement and HTMLTableCellElement): the parts of a table (caption, tHead, tFoot, tBodies), the live collections of rows and cells, and the operations that create, insert and delete them with the index rules of the specification (an index of -1 means the end, an index outside the range is an IndexSizeError). The functions work on the DOM tree directly, so the result is the same for the parser, the scripts and the layout; the script bindings are in js.dom.TableBindings. The live row list is in tree order (thead rows, body rows and foot rows as they stand in the markup), which equals the order of the specification for the usual order thead, tbody, tfoot.

HTML 규격의 표 객체 모델(HTML5 2014 REC 4.9절, 인터페이스 HTMLTableElement, HTMLTableSectionElement, HTMLTableRowElement, HTMLTableCellElement): 표의 부분(caption, tHead, tFoot, tBodies), 행과 셀의 라이브 컬렉션, 규격의 인덱스 규칙(-1 은 끝, 범위 밖은 IndexSizeError)으로 그것들을 만들고 넣고 지우는 연산. 함수는 DOM 트리를 직접 다루므로 파서, 스크립트, 배치에서 결과가 같으며 스크립트 연결은 js.dom.TableBindings 에 있다. 라이브 행 목록은 트리 순서(마크업에 놓인 thead 행, 본문 행, tfoot 행)이며, 흔한 순서 thead, tbody, tfoot 에서는 규격의 순서와 같다.
