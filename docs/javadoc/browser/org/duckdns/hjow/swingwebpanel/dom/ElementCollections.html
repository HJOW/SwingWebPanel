org.duckdns.hjow.swingwebpanel.dom
Class ElementCollections

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.ElementCollections

public final class ElementCollections
extends java.lang.Object

Factory of the live element collections of the DOM Standard: by tag name, by namespace and local name, by class names, and the element children of a node. The matching rules follow the standard, including the case rules of HTML documents (HTML elements match a lower-cased tag name) and quirks mode (class names compare case-insensitively).

DOM 표준의 라이브 요소 컬렉션 팩터리: 태그 이름별, 네임스페이스와 로컬 이름별, 클래스 이름별, 노드의 요소 자식. 일치 규칙은 HTML 문서의 대소문자 규칙(HTML 요소는 소문자로 바꾼 태그 이름과 일치)과 호환 모드(클래스 이름을 대소문자 구분 없이 비교)를 포함해 표준을 따른다.

documentNames

public static java.util.List<java.lang.String> documentNames(Element e)
Returns the names under which an element is a named property of an HTML document (HTML5 REC 2014-10-28 section 5.3, named access on the Document object, https://www.w3.org/TR/2014/REC-html5-20141028/dom.html#dom-document-nameditem, retrieved 2026-11-17): the name of an applet, embed, form, img or object element, the id of an applet or object element, and the id of an img element that also has a name. An embed or object element inside an object element is not exposed. The names are not empty and appear in the order name, id.

요소가 HTML 문서의 이름 있는 프로퍼티가 되는 이름들을 반환한다(HTML5 REC 2014-10-28 §5.3, Document 객체의 이름 접근): applet, embed, form, img, object 요소의 name, applet, object 요소의 id, 이름도 있는 img 요소의 id. object 요소 안의 embed, object 요소는 노출되지 않는다. 이름은 비어 있지 않으며 name, id 순서이다.

Parameters:
e - the element / 요소
Returns:
the names, empty for most elements / 이름. 대부분의 요소는 비어 있다
