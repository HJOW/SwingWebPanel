Class Selection

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Selection

public final class Selection
extends java.lang.Object

The selection of a document (W3C Selection API, Selection): none or one Range and a direction, so that the anchor (where the selection started) and the focus (where it ends now) can be told apart from the range's start and end. This is the model only: the screen (marking the selected text, mouse and keyboard selection, the clipboard) is connected by the component (plan item P11-08). The range of the selection is live, like every Range; scripts can read it with getRangeAt(int) and change it directly. Only one range is supported, as in the browsers that follow the specification (rangeCount is 0 or 1).

문서의 선택(W3C Selection API 의 Selection): 없거나 Range 하나와 방향으로 이루어지며, 선택이 시작한 곳인 anchor 와 지금 끝나는 곳인 focus 를 범위의 시작과 끝과 구별한다. 모델만 담당한다: 화면(선택한 텍스트 표시, 마우스와 키보드 선택, 클립보드)은 컴포넌트가 연결한다(계획 P11-08). 선택의 범위는 모든 Range 처럼 살아 있으며 스크립트가 getRangeAt(int) 로 읽고 직접 바꿀 수 있다. 규격을 따르는 브라우저처럼 범위는 하나만 지원한다(rangeCount 는 0 또는 1).

containsNode

public boolean containsNode(Node node,
                            boolean allowPartialContainment)
Tells whether the selection contains a node. With partial containment any overlap counts; without it the node must lie completely inside the range (a node whose start and end touch the boundary points of the range counts as inside).

선택이 노드를 포함하는지 알려 준다. 부분 포함을 허용하면 조금이라도 겹치면 되고, 아니면 노드가 범위 안에 완전히 있어야 한다(노드의 시작과 끝이 범위의 경계점에 닿아도 안에 있는 것으로 본다).

Parameters:
node - the node / 노드
allowPartialContainment - true to count a node that only overlaps / 겹치기만 하는 노드도 세려면 true
Returns:
true if contained / 포함하면 true
