The PropertyNodeList of the Note "HTML Microdata" (section 6.1): the elements of an item that add a property of one name, in tree order, read from the tree at every access. getValues() gives the values of the elements (itemValue: a string, or the element itself for a nested item).

노트 "HTML Microdata"(6.1절)의 PropertyNodeList: 아이템에서 이름 하나의 프로퍼티를 더하는 요소를 트리 순서로 나열하며 접근할 때마다 트리에서 읽는다. getValues() 는 요소의 값(itemValue: 문자열, 중첩된 아이템이면 요소 자신)을 준다.
