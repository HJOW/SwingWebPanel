public class Element
extends Node

An element: a node with a namespace, a name, attributes and children. The names follow the DOM Standard: the tag name of an element in the HTML namespace of an HTML document is upper case and attribute names of such elements are matched in lower case. Attribute changes are reported to the document's listeners; the HTML layer overrides attributeChanged(String, String, String, String) in its element classes (created by the ElementFactory) to react to changes.

요소: 네임스페이스, 이름, 속성, 자식을 가진 노드. 이름은 DOM 표준을 따른다: HTML 문서의 HTML 네임스페이스 요소는 태그 이름이 대문자이고 그런 요소의 속성 이름은 소문자로 맞춰 비교한다. 속성 변경은 문서의 리스너에 보고된다. HTML 계층은 ElementFactory 가 만드는 요소 클래스에서 attributeChanged(String, String, String, String) 를 재정의해 변경에 반응한다.
