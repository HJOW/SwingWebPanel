DomRect
public class DomRectReadOnly
extends java.lang.Object

A rectangle of the geometry interfaces (DOMRectReadOnly, Geometry Interfaces Module): the origin and the size as numbers, and the four edges that follow from them (a negative width or height puts the edge on the other side). The layout results that scripts read (getBoundingClientRect(), getClientRects()) are such rectangles. Create one with the constructor and read it with the getters; DomRect is the variant that scripts may change.

기하 인터페이스의 사각형(DOMRectReadOnly, Geometry Interfaces Module): 원점과 크기 숫자, 그로부터 나오는 네 가장자리(너비나 높이가 음수이면 가장자리가 반대쪽에 놓인다). 스크립트가 읽는 레이아웃 결과(getBoundingClientRect(), getClientRects())가 이런 사각형이다. 생성자로 만들고 접근자로 읽으며, 스크립트가 바꿀 수 있는 변종이 DomRect 이다.
