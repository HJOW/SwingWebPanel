Class Node

public abstract class Node
extends EventTarget

The base of all DOM tree objects (DOM Standard Node): the tree structure (parent, first/last child, siblings), the mutation algorithms (pre-insert, replace, remove, adopt, clone with the validity rules and the exceptions the standard prescribes), text content, normalization, equality and document position. Every change of the tree goes through the same few private methods, which keep the links consistent, bump the document's mutation version (live collections use it to refresh themselves) and report a MutationRecord to the document's listeners. A node belongs to exactly one Document and must only be used on that document's thread.

모든 DOM 트리 객체의 기반(DOM 표준 Node): 트리 구조(부모, 첫/마지막 자식, 형제), 변경 알고리즘(pre-insert, replace, remove, adopt, 표준이 정한 유효성 규칙과 예외를 갖춘 복제), 텍스트 내용, 정규화, 동등성, 문서 내 위치. 트리의 모든 변경은 같은 몇 개의 비공개 메서드를 거치며 이 메서드들이 연결을 일관되게 유지하고, 문서의 변경 버전을 올리고(라이브 컬렉션이 이를 보고 갱신한다), 문서의 리스너에게 MutationRecord 를 보고한다. 노드는 정확히 하나의 Document 에 속하며 그 문서의 스레드에서만 써야 한다.

setTextContent

public void setTextContent(java.lang.String text)
Sets the text content: elements and fragments get one text node with the given text (or no child for an empty string); character nodes get new data; other nodes ignore it. The text is never parsed as markup.

텍스트 내용을 지정한다: 요소와 조각은 주어진 텍스트의 텍스트 노드 하나를 갖고(빈 문자열이면 자식 없음), 문자 노드는 새 데이터를 갖고, 다른 노드는 무시한다. 텍스트는 마크업으로 해석되지 않는다.
