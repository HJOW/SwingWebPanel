org.duckdns.hjow.swingwebpanel.dom
Class HighlightRegistry

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.HighlightRegistry

public final class HighlightRegistry
extends java.lang.Object

The highlight registry of a document (CSS Custom Highlight API Level 1, section 3.2): a map from custom highlight names to Highlights, in the order in which the names were first set (as a JavaScript Map; setting an existing name keeps its place). A highlight that is registered later has the higher effective priority among highlights of the same priority (4.2.5). Every change of the registry or of a registered highlight is reported to the listener that the page installs, which paints the page again (section 5.1).

Use: Document.getHighlights() returns the registry of a document; the renderer reads getEntries() while it paints the text. Change it on the document thread only.

문서의 하이라이트 등록부(CSS Custom Highlight API Level 1, 3.2 절): 사용자 정의 하이라이트 이름에서 Highlight 로 가는 맵이며 이름을 처음 정한 순서를 지킨다 (JavaScript Map 처럼 이미 있는 이름을 다시 정하면 자리를 지킨다). 같은 우선순위의 하이라이트 중에서는 나중에 등록한 것의 실제 우선순위가 더 높다(4.2.5 절). 등록부나 등록된 하이라이트의 모든 변경은 페이지가 설치한 리스너에 알려 페이지를 다시 그리게 한다(5.1 절).

사용법: Document.getHighlights() 가 문서의 등록부를 반환하고, 렌더러는 텍스트를 그릴 때 getEntries() 를 읽는다. 문서 스레드에서만 바꾼다.
