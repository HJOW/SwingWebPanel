Class Microdata

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Microdata

public final class Microdata
extends java.lang.Object

The microdata model of the W3C Working Group Note "HTML Microdata" (29 October 2013; the HTML5 2014 Recommendation has no microdata chapter and the Note is the last published form of the feature): which elements are items, the item types, the property names, the properties of an item (the "crawl" of the Note, section 5.2, with itemref), the top-level items of a document and the value of a property element (itemValue). The functions only read the tree. Microdata attributes are defined for HTML elements only, so an element of another namespace (SVG, MathML) is never an item and has no property names. Use: Microdata.topLevelItems(document, types), Microdata.properties(itemElement).

W3C 작업 그룹 노트 "HTML Microdata"(2013-10-29; HTML5 2014 권고안에는 마이크로데이터 장이 없고 이 노트가 이 기능의 마지막 공개 형태이다)의 마이크로데이터 모델: 어떤 요소가 아이템인지, 아이템 타입, 프로퍼티 이름, 아이템의 프로퍼티(노트 5.2절의 "crawl", itemref 포함), 문서의 최상위 아이템, 프로퍼티 요소의 값(itemValue). 함수는 트리를 읽기만 한다. 마이크로데이터 속성은 HTML 요소에만 정의되므로 다른 네임스페이스(SVG, MathML)의 요소는 아이템이 아니고 프로퍼티 이름도 없다. 사용: Microdata.topLevelItems(document, types), Microdata.properties(itemElement).
