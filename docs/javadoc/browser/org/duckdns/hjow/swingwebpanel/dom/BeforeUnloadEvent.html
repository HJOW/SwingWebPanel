Class BeforeUnloadEvent

java.lang.Object

      org.duckdns.hjow.swingwebpanel.dom.BeforeUnloadEvent

public class BeforeUnloadEvent
extends Event

The beforeunload event (HTML Standard "BeforeUnloadEvent"): it is fired at the window of a page that is about to be left, it can be cancelled, and a string in returnValue also asks to confirm the leaving. This component has no dialog for it; the page is left in any case and the status text tells that the page asked (see docs/progress/webapi2.md).

beforeunload 이벤트(HTML Standard "BeforeUnloadEvent"): 떠나려는 페이지의 window 에서 발생하고 취소할 수 있으며, returnValue 의 문자열도 떠나기 전 확인을 요청한다. 이 컴포넌트에는 그 대화상자가 없다. 어느 경우에도 페이지를 떠나며 상태 메시지로 페이지가 요청했음을 알린다 (docs/progress/webapi2.md 참조).
