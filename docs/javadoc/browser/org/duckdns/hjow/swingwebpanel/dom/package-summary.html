DomMatrixReadOnly A 4x4 matrix of the geometry interfaces (DOMMatrixReadOnly, Geometry Interfaces Module Level 1, section 6): the sixteen elements m11 to m44 and the flag is2D.
DomPoint A point that scripts may change (DOMPoint): DomPointReadOnly with setters.

DomRectReadOnly A rectangle of the geometry interfaces (DOMRectReadOnly, Geometry Interfaces Module): the origin and the size as numbers, and the four edges that follow from them (a negative width or height puts the edge on the other side).

ErrorEvent The error event of a runtime script error (ErrorEvent, HTML Standard "Runtime script errors"): it carries the message, the filename of the script, the line and the column (lineno, colno) and the thrown value (error).
Event A DOM event (DOM Standard section 2).
EventTarget An object that can receive events and have listeners (DOM Standard section 2.7): every node, and later the window and other script-visible objects.
FocusEvent A focus event (UI Events): focus, blur, focusin and focusout, with the element that loses or gets the focus at the same time.
FocusManager The focus of a document (HTML Standard, "focus"): which elements can have the focus, the order of the Tab key, moving the focus with the blur, focusout, focus and focusin events in the order of the UI Events specification, and the effect that the focus of the window (the component) has on the event of the focused element.
HashChangeEvent The hashchange event (HashChangeEvent, HTML5 2014 REC 5.6.10.1): fired at the window after a move between two entries of the same document whose URLs differ in the fragment.

HighlightRegistry The highlight registry of a document (CSS Custom Highlight API Level 1, section 3.2): a map from custom highlight names to Highlights, in the order in which the names were first set (as a JavaScript Map; setting an existing name keeps its place).
InputEvent An input event (UI Events and Input Events): a change of the value of an editable element, with the text that was inserted and the kind of change (insertText, deleteContentBackward ...), also used for beforeinput.
KeyboardEvent A keyboard event (UI Events): the value of the key (key), the physical key (code), where on the keyboard it is, whether it repeats, and the legacy keyCode, charCode and which that old scripts read.
MediaQueryListEvent The change event of a media query list (MediaQueryListEvent, CSSOM View Module 4.2.1): it carries the text of the query (media) and its new result (matches).
MessageEvent The message event (MessageEvent, W3C Web Messaging 3): fired for a message of cross-document messaging (window.postMessage) and of channel messaging (MessagePort).
Microdata The microdata model of the W3C Working Group Note "HTML Microdata" (29 October 2013; the HTML5 2014 Recommendation has no microdata chapter and the Note is the last published form of the feature): which elements are items, the item types, the property names, the properties of an item (the "crawl" of the Note, section 5.2, with itemref), the top-level items of a document and the value of a property element (itemValue).
MouseEvent A mouse event (UI Events): the position in screen, client (the visible part of the page), page (the whole document) and target element coordinates, the button that changed and the buttons that are down, and the element that the pointer came from or goes to.
MutationRecord A description of one change of the DOM (the data of a MutationRecord of the DOM Standard).
NamedAttributeMap The live view of the attributes of an element (NamedNodeMap of the attributes property).
NamespaceLookup The namespace lookups of Node (lookupNamespaceURI, lookupPrefix, isDefaultNamespace), the algorithms "locate a namespace" and "locate a namespace prefix" of the WHATWG DOM Standard (section 4.4 "Interface Node").
Namespaces Namespace URIs and the name validation rules of the DOM Standard (validate and extract, XML Name production, ASCII whitespace helpers).
Namespaces.QualifiedName Result of Namespaces.validateAndExtract(String, String).
Node The base of all DOM tree objects (DOM Standard Node): the tree structure (parent, first/last child, siblings), the mutation algorithms (pre-insert, replace, remove, adopt, clone with the validity rules and the exceptions the standard prescribes), text content, normalization, equality and document position.
NodeIterator A flat, live iterator over the nodes of a subtree in tree order (DOM Standard, "Interface NodeIterator").

PointerEvent A pointer event (W3C Pointer Events Level 3): a mouse event with the identity of the pointer that caused it (pointerId, pointerType, isPrimary) and the properties of its contact (width, height, pressure, tangentialPressure, tilt, twist and the altitude and azimuth angles).
PopStateEvent The popstate event (PopStateEvent, HTML5 2014 REC 5.6.10.1): fired at the window when the document moves to another entry of the session history.

PropertyNodeList The PropertyNodeList of the Note "HTML Microdata" (section 6.1): the elements of an item that add a property of one name, in tree order, read from the tree at every access.
Range A range of content in a DOM tree (DOM Standard, "Interface Range"): two boundary points, each a node and an offset in it (a character offset in a text-like node, a child index in any other node).

UiEvent An event that comes from the user interface (UI Events): a detail number and the state of the modifier keys that were down when it happened.
WheelEvent A wheel event (UI Events): a mouse event with the amount that the wheel turned along the three axes and the unit of the amount.
XmlSerializer The XML serialization of a DOM node, as defined for XMLSerializer (W3C DOM Parsing and Serialization, "XML Serialization", with the require well-formed flag unset): elements and attributes are written so that their namespaces are kept, with prefixes and namespace declarations added, replaced or dropped as needed (xmlns and xmlns:prefix are generated where a namespace has no usable prefix; ns1, ns2 ... are generated prefixes); an HTML element without children is written with a start and end tag, except the void elements, which are written as <br />; elements of other namespaces without children are written as <a/>; text escapes & < >, attribute values also escape the quotation mark, tab, line feed and carriage return.
