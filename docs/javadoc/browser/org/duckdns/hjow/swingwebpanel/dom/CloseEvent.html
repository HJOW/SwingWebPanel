Class CloseEvent

java.lang.Object

      org.duckdns.hjow.swingwebpanel.dom.CloseEvent

public class CloseEvent
extends Event

The close event of a WebSocket (CloseEvent, HTML Standard "Network" chapter): it tells whether the connection was closed cleanly (wasClean), the status code that the server sent or that the user agent chose (code, 1006 for a connection that was lost or never opened) and the reason text (reason). It does not bubble and cannot be cancelled.

WebSocket 의 close 이벤트(CloseEvent, HTML Standard "Network" 장): 연결이 정상적으로 닫혔는지 (wasClean), 서버가 보냈거나 사용자 에이전트가 고른 상태 코드(code, 끊어졌거나 열리지 않은 연결은 1006), 이유 문자열 (reason)을 알려 준다. 버블링하지 않고 취소할 수 없다.
