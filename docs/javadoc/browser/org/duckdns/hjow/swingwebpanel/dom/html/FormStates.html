org.duckdns.hjow.swingwebpanel.dom.html
Class FormStates

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.FormStates

public final class FormStates
extends java.lang.Object

The form related selector states of the elements that the form layer implements (HTML Standard 4.16.3 "Pseudo-classes"): :checked, :disabled, :enabled, :indeterminate, :default, :required, :optional, :read-write, :valid, :invalid, :in-range, :out-of-range and :placeholder-shown. Every method answers from the live state of the control (the typed value, the checkedness, the selectedness, the validity), not from the content attributes. A method returns null for an element that the form layer does not implement, so that the selector engine falls back to the content attributes.

폼 계층이 구현하는 요소의 폼 관련 선택자 상태(HTML 표준 4.16.3 "Pseudo-classes"): :checked, :disabled, :enabled, :indeterminate, :default, :required, :optional, :read-write, :valid, :invalid, :in-range, :out-of-range, :placeholder-shown. 모든 메서드는 콘텐츠 속성이 아니라 컨트롤의 실제 상태(입력한 값, checkedness, selectedness, 유효성)로 답한다. 폼 계층이 구현하지 않는 요소에는 null 을 반환해, 선택자 엔진이 콘텐츠 속성으로 대신하게 한다.
