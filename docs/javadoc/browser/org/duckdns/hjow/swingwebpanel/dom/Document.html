Class Document

public class Document
extends Node

A document: the root of a DOM tree and the factory of its nodes (DOM Standard Document). It also holds the state shared by all nodes of the tree: the mutation version used by live collections, the listeners of DOM changes, the id index, and the services that other layers install (element factory, selector engine, markup parser/serializer, error handler for event listeners and the window that follows the document in the event path). All nodes of a document must be used on the same thread, the document thread of the owning browser component.

문서: DOM 트리의 루트이자 그 노드들의 팩터리(DOM 표준 Document). 트리의 모든 노드가 공유하는 상태도 가진다: 라이브 컬렉션이 쓰는 변경 버전, DOM 변경 리스너, id 색인, 그리고 다른 계층이 설치하는 서비스(요소 팩터리, 선택자 엔진, 마크업 파서/직렬화기, 이벤트 리스너 오류 핸들러, 이벤트 경로에서 문서 뒤에 오는 window). 문서의 모든 노드는 같은 스레드, 즉 소유 브라우저 컴포넌트의 문서 스레드에서 써야 한다.
