org.duckdns.hjow.swingwebpanel.dom.xpath
Class XPathExpression

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.xpath.XPathExpression

public final class XPathExpression
extends java.lang.Object

A compiled XPath 1.0 expression (XML Path Language 1.0, W3C Recommendation 16 November 1999, Last-Modified 2 October 2017, fetched 2026-11-18) over the DOM of this project, as the DOM XPath interfaces use it (WHATWG DOM section 8). It has the whole syntax of the Recommendation: location paths with all the axes (the namespace axis is always empty: the DOM has no namespace nodes), node tests and predicates, the abbreviated syntax, filter expressions, unions, all the operators with the comparison rules of node sets, and the core function library (node-set, string, boolean and number functions). Values are Double, String, Boolean and a node set, which is a List of Node and Attr objects without duplicates in document order. Variable references are a XPathException.TYPE error (a DOM XPath expression has no variables). Choices for HTML documents (as browsers do): a name test without a prefix also matches elements in the HTML namespace, and it matches their lower case names, so that //DIV finds div elements. An expression is immutable and may be evaluated many times, also from different threads.

컴파일된 XPath 1.0 식(XML Path Language 1.0, W3C 권고안 1999-11-16, Last-Modified 2017-10-02, 2026-11-18 조회)이며 DOM XPath 인터페이스가 쓰는 이 프로젝트의 DOM 위에서 동작한다(WHATWG DOM 8절). 권고안의 구문 전체를 갖춘다: 모든 축이 있는 위치 경로(namespace 축은 DOM 에 네임스페이스 노드가 없으므로 항상 비어 있다), 노드 테스트와 술어, 약식 구문, 필터 식, 합집합, 노드 집합의 비교 규칙이 있는 모든 연산자, 핵심 함수 라이브러리(노드 집합, 문자열, 불리언, 숫자 함수). 값은 Double, String, Boolean, 그리고 노드 집합이며 노드 집합은 중복 없이 문서 순서로 놓인 Node 와 Attr 의 List 이다. 변수 참조는 XPathException.TYPE 오류이다 (DOM XPath 식에는 변수가 없다). HTML 문서에서의 선택(브라우저와 같다): 접두사 없는 이름 테스트는 HTML 네임스페이스의 요소도 일치시키며 소문자 이름으로 비교하므로 //DIV 가 div 요소를 찾는다. 식은 불변이고 여러 번, 여러 스레드에서 평가할 수 있다.
