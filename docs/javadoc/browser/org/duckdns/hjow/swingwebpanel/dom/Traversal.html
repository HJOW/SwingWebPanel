org.duckdns.hjow.swingwebpanel.dom
Class Traversal

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Traversal
Direct Known Subclasses:
NodeIterator, TreeWalker
public abstract class Traversal
extends java.lang.Object

The part that NodeIterator and TreeWalker share (DOM Standard, "Interface NodeIterator" and "Interface TreeWalker"): the root node, the whatToShow bit mask, the optional NodeFilter and the algorithm that filters one node. The filter must not be re-entered: while it runs, calling the traversal again is an InvalidStateError.

NodeIterator 와 TreeWalker 가 공유하는 부분(DOM 표준 "Interface NodeIterator", "Interface TreeWalker"): 루트 노드, whatToShow 비트 마스크, 선택적 NodeFilter, 노드 하나를 걸러 내는 알고리즘. 필터는 재진입할 수 없다. 필터가 실행되는 동안 탐색을 다시 부르면 InvalidStateError 이다.
