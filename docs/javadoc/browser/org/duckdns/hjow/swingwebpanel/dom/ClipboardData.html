org.duckdns.hjow.swingwebpanel.dom
Class ClipboardData

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.ClipboardData

public final class ClipboardData
extends java.lang.Object

The data of a clipboard operation or of a drag and drop (HTML DataTransfer): the clipboard part of it (ClipboardEvent.clipboardData, InputEvent.dataTransfer) and the drag-and-drop part (DragEvent.dataTransfer, effectAllowed, dropEffect, items). It holds the drag data store: a list of text items, one per type string (lower case, text means text/plain and url means text/uri-list, the legacy names of the specification). For a copy event it starts with what the user selected (text/plain and text/html); a script that calls setData and cancels the event puts its own data on the clipboard instead. This component has text items only, no files.

The mode says what a script may do (HTML Standard, drag data store mode): read/write (the clipboard data of copy and cut, and dragstart: data can be read and added), read-only (paste and drop: data can be read, nothing can be added) and protected (the other drag events: the types can be listed, the data cannot be read). In the disabled mode (the data transfer is no longer tied to a drag operation) nothing is visible. The component itself fills and reads the data through put(java.lang.String, java.lang.String) and peek(java.lang.String), which ignore the mode.

클립보드 작업이나 끌어다 놓기의 데이터(HTML DataTransfer): 클립보드 부분(ClipboardEvent.clipboardData, InputEvent.dataTransfer)과 끌어다 놓기 부분(DragEvent.dataTransfer, effectAllowed, dropEffect, items). 드래그 데이터 저장소를 가진다: 타입 문자열(소문자. text 는 text/plain, url 은 text/uri-list 를 뜻하며 규격의 옛 이름이다)마다 하나인 텍스트 항목의 목록. copy 이벤트에서는 사용자가 선택한 것(text/plain 과 text/html)으로 시작하며, setData 를 부르고 이벤트를 취소한 스크립트는 대신 자기 데이터를 클립보드에 넣는다. 이 컴포넌트는 텍스트 항목만 가지며 파일은 없다.

모드는 스크립트가 할 수 있는 일을 정한다(HTML 표준의 드래그 데이터 저장소 모드): 읽기/쓰기(copy, cut 의 클립보드 데이터와 dragstart: 데이터를 읽고 더할 수 있다), 읽기 전용(paste, drop: 읽을 수 있고 더할 수 없다), 보호(나머지 끌기 이벤트: 종류는 나열할 수 있고 데이터는 읽을 수 없다). 무효화 모드(데이터 전달 객체가 더는 끌기 작업에 묶여 있지 않다)에서는 아무것도 보이지 않는다. 컴포넌트 자신은 모드를 무시하는 put(java.lang.String, java.lang.String) 과 peek(java.lang.String) 로 데이터를 채우고 읽는다.
