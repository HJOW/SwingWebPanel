org.duckdns.hjow.swingwebpanel.dom
Class DataTransferItem

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.DataTransferItem

public final class DataTransferItem
extends java.lang.Object

One item of a data transfer (HTML DataTransferItem): its kind (this component only has text items, kind string), its type string and its data. An item stays tied to its ClipboardData; once it is removed from it, or the data transfer is disabled, the item reads as disabled (empty kind and type).

데이터 전달 객체의 항목 하나(HTML DataTransferItem): 종류(이 컴포넌트는 텍스트 항목, 종류 string 만 가진다), 타입 문자열, 데이터. 항목은 자기 ClipboardData 에 묶여 있으며, 거기서 제거되었거나 데이터 전달 객체가 무효화되면 비활성(빈 종류와 타입)으로 읽힌다.
