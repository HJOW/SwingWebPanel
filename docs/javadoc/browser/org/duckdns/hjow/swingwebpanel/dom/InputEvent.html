public class InputEvent
extends UiEvent

An input event (UI Events and Input Events): a change of the value of an editable element, with the text that was inserted and the kind of change (insertText, deleteContentBackward ...), also used for beforeinput.

입력 이벤트(UI Events, Input Events): 편집 가능한 요소의 값이 바뀌었다는 이벤트이며 삽입한 텍스트와 변경 종류(insertText, deleteContentBackward 등)를 가진다. beforeinput 에도 쓴다.
