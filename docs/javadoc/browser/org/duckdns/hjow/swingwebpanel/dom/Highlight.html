Class Highlight

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Highlight

public final class Highlight
extends java.lang.Object

A custom highlight of the CSS Custom Highlight API Level 1 (https://www.w3.org/TR/css-highlight-api-1/, W3C Working Draft of 14 December 2021, section 3.1): a set of ranges (live Ranges or StaticRanges, compared by identity and kept in insertion order) with a priority (default 0; a higher priority is painted above) and a type (highlight, spelling-error or grammar-error; an unknown type is ignored, as for an IDL enumeration). A highlight has an effect only when it is registered in the HighlightRegistry of a document under a name that the pseudo-element ::highlight(name) styles. Every change is reported to the registries that hold the highlight, so the page is painted again.

Use: Highlight h = new Highlight(); h.add(range); document.getHighlights().set("found", h);. Change it on the document thread only.

CSS Custom Highlight API Level 1 의 사용자 정의 하이라이트(W3C Working Draft 2021-12-14, 3.1 절): 범위(살아 있는 Range 나 StaticRange. 동일성으로 비교하고 넣은 순서로 보관)의 집합이며, 우선순위(기본 0, 높을수록 위에 그린다)와 종류(highlight, spelling-error, grammar-error. IDL 열거형처럼 모르는 종류는 무시)를 가진다. 문서의 HighlightRegistry 에 의사 요소 ::highlight(이름) 이 꾸미는 이름으로 등록되어야 효과가 있다. 모든 변경은 이 하이라이트를 가진 등록부에 알려 페이지를 다시 그리게 한다.

사용법: Highlight h = new Highlight(); h.add(range); document.getHighlights().set("found", h);. 문서 스레드에서만 바꾼다.
