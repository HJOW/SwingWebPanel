Class FormSupport

DomMutationListener
public final class FormSupport
extends java.lang.Object
implements DomMutationListener

The per-document support of the HTML form controls. A document gets one on first use (Document.getFormSupport()). It holds the FormHost, a state version that the live lists use to notice changes that are not DOM changes, and it observes the child list changes of the document for the things that the HTML Standard defines as reactions to insertion and removal: the selectedness of the options of a select, the radio button group of an inserted checked radio button and the form owner that the parser assigned. The observation starts when the first control element of the document is created, so a document without forms pays nothing.

문서별 HTML 폼 컨트롤 지원. 문서는 처음 쓸 때(Document.getFormSupport()) 하나를 얻는다. FormHost, DOM 변경이 아닌 변경을 라이브 목록이 알아채는 데 쓰는 상태 버전을 가지며, HTML 표준이 삽입과 제거에 대한 반응으로 정의한 것들을 위해 문서의 자식 목록 변경을 관찰한다: select 의 option 의 selectedness, 삽입된 체크된 라디오 버튼의 라디오 그룹, 파서가 지정한 폼 소유자. 관찰은 문서의 첫 컨트롤 요소가 만들어질 때 시작하므로 폼이 없는 문서는 비용이 없다.
