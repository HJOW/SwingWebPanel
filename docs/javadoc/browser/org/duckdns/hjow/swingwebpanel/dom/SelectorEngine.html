Interface SelectorEngine

All Known Implementing Classes:
CssSelectorEngine
public interface SelectorEngine

The selector matching service used by querySelector, querySelectorAll, matches and closest. The DOM package only defines the interface; the CSS package implements it (plan item P08-09) and installs it with Document.setSelectorEngine(SelectorEngine). Until then these DOM methods throw a NotSupportedError.

querySelector, querySelectorAll, matches, closest 가 쓰는 선택자 일치 서비스. DOM 패키지는 인터페이스만 정의하고 CSS 패키지가 구현하여(계획 P08-09) Document.setSelectorEngine(SelectorEngine) 로 설치한다. 그때까지 이 DOM 메서드들은 NotSupportedError 를 던진다.
