public abstract class EventTarget
extends java.lang.Object

An object that can receive events and have listeners (DOM Standard section 2.7): every node, and later the window and other script-visible objects. It stores the listeners and implements the dispatch algorithm: the event path is built with getEventParent(Event), the event goes through the capture phase (root to parent), the target phase and, if it bubbles, the bubble phase. A failing listener is reported to the ListenerErrorHandler and the remaining listeners still run. All methods must be called on the document thread of the owning document.

이벤트를 받고 리스너를 가질 수 있는 객체(DOM 표준 2.7절): 모든 노드이며 이후 window 와 다른 스크립트에 보이는 객체도 해당한다. 리스너를 보관하고 전달 알고리즘을 구현한다: getEventParent(Event) 로 이벤트 경로를 만들고, 이벤트는 캡처 단계(루트에서 부모까지), 대상 단계, 그리고 버블하면 버블 단계를 거친다. 실패한 리스너는 ListenerErrorHandler 에 보고되고 나머지 리스너는 계속 실행된다. 모든 메서드는 소유 문서의 문서 스레드에서 호출해야 한다.
