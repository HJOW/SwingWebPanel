public final class HtmlOptionsCollection
extends FormElementList

The HTMLOptionsCollection of a select (select.options): the live list of its options, which, unlike a plain collection, can be changed: length, add, remove, selectedIndex and assignment to an index.

select 의 HTMLOptionsCollection(select.options): option 의 라이브 목록이며 일반 컬렉션과 달리 바꿀 수 있다: length, add, remove, selectedIndex, 위치에 대한 대입.
