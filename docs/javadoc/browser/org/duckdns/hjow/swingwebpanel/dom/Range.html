org.duckdns.hjow.swingwebpanel.dom
Class Range

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Range

public final class Range
extends java.lang.Object

A range of content in a DOM tree (DOM Standard, "Interface Range"): two boundary points, each a node and an offset in it (a character offset in a text-like node, a child index in any other node). A range is live: when nodes are inserted or removed, or character data is replaced, the boundary points move with the content (see LiveRanges), so that a range keeps standing for the same content. It offers the boundary operations (setStart(org.duckdns.hjow.swingwebpanel.dom.Node, int), selectNode(org.duckdns.hjow.swingwebpanel.dom.Node), collapse(boolean) ...), the comparison of boundary points, the operations on the content (cloneContents(), extractContents(), deleteContents(), insertNode(org.duckdns.hjow.swingwebpanel.dom.Node), surroundContents(org.duckdns.hjow.swingwebpanel.dom.Node)), toString(), and createContextualFragment(java.lang.String) of the DOM Parsing specification. Geometry (getBoundingClientRect) is not part of this class; the host adds it because it needs the layout.

Restriction against the Standard: the changes of a tree of another document do not move a boundary point that was set into that tree (the registry of live ranges belongs to the document that created the range).

DOM 트리 안의 내용 범위(DOM 표준 "Interface Range"): 두 경계점이며 각각 노드와 그 안의 오프셋(텍스트 계열 노드는 문자 오프셋, 그 밖의 노드는 자식 인덱스)이다. 범위는 살아 있다: 노드가 삽입되거나 제거되거나 문자 데이터가 바뀌면 경계점이 내용과 함께 움직여(LiveRanges 참조) 범위가 계속 같은 내용을 가리킨다. 경계 연산(setStart(org.duckdns.hjow.swingwebpanel.dom.Node, int), selectNode(org.duckdns.hjow.swingwebpanel.dom.Node), collapse(boolean) 등), 경계점 비교, 내용 연산(cloneContents(), extractContents(), deleteContents(), insertNode(org.duckdns.hjow.swingwebpanel.dom.Node), surroundContents(org.duckdns.hjow.swingwebpanel.dom.Node)), toString(), DOM Parsing 규격의 createContextualFragment(java.lang.String) 를 제공한다. 기하(getBoundingClientRect)는 레이아웃이 필요하므로 이 클래스가 아니라 호스트가 더한다.

표준과 다른 제한: 다른 문서의 트리에 정한 경계점은 그 문서의 변경을 따라가지 않는다(살아 있는 범위의 등록부는 범위를 만든 문서의 것이다).
