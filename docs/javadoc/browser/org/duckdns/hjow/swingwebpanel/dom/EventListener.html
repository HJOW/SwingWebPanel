public interface EventListener

A callback that receives DOM events. The JavaScript layer wraps script functions and objects with a handleEvent method in implementations of this interface; Java code (the library itself, tests, hosts) can implement it directly. Equality of listeners uses equals, so wrappers of the same script function must be equal to each other for duplicate registrations to be ignored.

DOM 이벤트를 받는 콜백. JavaScript 계층은 스크립트 함수와 handleEvent 메서드를 가진 객체를 이 인터페이스의 구현으로 감싼다. Java 코드(라이브러리 자신, 시험, 호스트)가 직접 구현해도 된다. 리스너의 동등성은 equals 를 쓰므로, 같은 스크립트 함수를 감싼 객체들은 서로 같아야 중복 등록이 무시된다.

void handleEvent(Event event)
Handles an event. A failure (exception) is reported to the document's ListenerErrorHandler and does not stop the remaining listeners.

이벤트를 처리한다. 실패(예외)는 문서의 ListenerErrorHandler 에 보고되며 나머지 리스너의 실행을 막지 않는다.
