org.duckdns.hjow.swingwebpanel.dom.html
Class FormSubmission

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.FormSubmission

public final class FormSubmission
extends java.lang.Object

The result of a form submission: what the host must request. For GET the entry list is already merged into the query of getUrl() (a fragment of the action is preserved) and there is no body; for POST the body and its content type (including the boundary of multipart/form-data) are ready. Instances are immutable.

폼 제출의 결과: 호스트가 요청해야 하는 것. GET 은 항목 목록이 이미 getUrl() 의 쿼리에 합쳐져 있고(action 의 프래그먼트는 유지) 본문이 없다. POST 는 본문과 콘텐츠 타입(multipart/form-data 의 경계 포함)이 준비되어 있다. 인스턴스는 불변이다.
