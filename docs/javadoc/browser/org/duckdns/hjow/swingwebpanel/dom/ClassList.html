org.duckdns.hjow.swingwebpanel.dom
Class ClassList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.ClassList

public final class ClassList
extends java.lang.Object

The token list view of the class attribute of an element (classList, a DOMTokenList). It reads and writes the attribute directly, so it is always in sync; every change re-serializes the tokens separated by one space (the "update steps" of the DOM Standard) and is reported like a setAttribute call.

요소의 class 속성에 대한 토큰 목록 뷰(classList, DOMTokenList). 속성을 직접 읽고 쓰므로 항상 동기화되어 있다. 모든 변경은 토큰을 공백 하나로 구분해 다시 직렬화하며(DOM 표준의 "update steps") setAttribute 호출처럼 보고된다.
