org.duckdns.hjow.swingwebpanel.dom
Class MutationRecord

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.MutationRecord

public final class MutationRecord
extends java.lang.Object

A description of one change of the DOM (the data of a MutationRecord of the DOM Standard). The document passes one record to its DomMutationListeners for every change of a child list, an attribute or the data of a character node. The lists are immutable copies.

DOM 의 변경 하나에 대한 설명(DOM 표준 MutationRecord 의 데이터). 문서는 자식 목록, 속성, 문자 노드 데이터가 바뀔 때마다 기록 하나를 DomMutationListener 에게 넘긴다. 목록은 변경할 수 없는 복사본이다.
