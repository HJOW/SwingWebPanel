Class Attr

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Attr

public final class Attr
extends java.lang.Object

An attribute of an element: namespace, prefix, local name and value. Attributes are not tree nodes in this implementation (the DOM Standard no longer makes them nodes either); they live in the attribute list of their owner element. Changing the value of an attribute that belongs to an element is reported like setAttribute.

요소의 속성: 네임스페이스, 접두사, 로컬 이름, 값. 이 구현에서 속성은 트리 노드가 아니며(DOM 표준도 더 이상 노드로 보지 않는다) 소유 요소의 속성 목록에 산다. 요소에 속한 속성의 값을 바꾸면 setAttribute 처럼 보고된다.
