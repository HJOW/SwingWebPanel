public final class FormControlsCollection
extends FormElementList

The HTMLFormControlsCollection of a form (form.elements): the live list of its listed elements, in tree order (image buttons excluded for historical reasons). namedItem returns the element itself if only one control has the name or id, and a RadioNodeList of all of them otherwise.

폼의 HTMLFormControlsCollection(form.elements): 목록 요소의 라이브 목록(트리 순서. 이미지 버튼은 역사적인 이유로 제외). namedItem 은 이름이나 id 가 같은 컨트롤이 하나이면 그 요소를, 여럿이면 모두를 담은 RadioNodeList 를 반환한다.
