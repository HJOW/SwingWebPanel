org.duckdns.hjow.swingwebpanel.dom.html
Class FileList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.FileList

public final class FileList
extends java.lang.Object

The list of the files selected in a file upload control (input.files): an immutable snapshot. A page can only read the name, size, type and modification time of the files, and a page can never add a file by path: only the host creates FileEntry objects (from what the user chose).

파일 업로드 컨트롤에서 선택한 파일의 목록(input.files): 불변 스냅샷. 페이지는 파일의 이름, 크기, 타입, 수정 시각만 읽을 수 있으며 경로로 파일을 추가할 수는 없다. FileEntry 는 호스트(사용자가 고른 것)만 만든다.
