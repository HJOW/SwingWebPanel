Comment, ProcessingInstruction, Text
public abstract class CharacterData
extends Node

Base of the nodes that hold character data: text, comments, CDATA sections and processing instructions. Offsets and counts are in UTF-16 code units, as in the DOM Standard. Every change of the data is reported to the document's listeners with the old value.

문자 데이터를 가진 노드(텍스트, 주석, CDATA 섹션, 처리 명령)의 기반. 오프셋과 개수는 DOM 표준과 같이 UTF-16 코드 단위이다. 데이터의 모든 변경은 이전 값과 함께 문서의 리스너에 보고된다.
