public class KeyboardEvent
extends UiEvent

A keyboard event (UI Events): the value of the key (key), the physical key (code), where on the keyboard it is, whether it repeats, and the legacy keyCode, charCode and which that old scripts read.

키보드 이벤트(UI Events): 키의 값(key), 물리적 키(code), 키보드의 위치, 반복 여부, 오래된 스크립트가 읽는 예전 keyCode, charCode, which.
