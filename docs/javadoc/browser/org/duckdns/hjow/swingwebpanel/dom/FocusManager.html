org.duckdns.hjow.swingwebpanel.dom
Class FocusManager

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.FocusManager

public final class FocusManager
extends java.lang.Object

The focus of a document (HTML Standard, "focus"): which elements can have the focus, the order of the Tab key, moving the focus with the blur, focusout, focus and focusin events in the order of the UI Events specification, and the effect that the focus of the window (the component) has on the event of the focused element. The judgment is made from the DOM only (attributes, tree); elements that are not displayed are excluded by the caller that knows the layout.

문서의 포커스(HTML 표준 "focus"): 포커스를 가질 수 있는 요소, Tab 키의 순서, UI Events 명세의 순서로 blur, focusout, focus, focusin 이벤트를 보내며 포커스를 옮기는 일, 창(컴포넌트)의 포커스가 포커스를 가진 요소의 이벤트에 주는 영향. 판정은 DOM(속성, 트리)만으로 하며, 표시되지 않는 요소는 레이아웃을 아는 호출자가 제외한다.

Gives the focus to an element if it can have it (the focus() method and the focus of a click). Events are sent in the order blur, focusout to the old element and focus, focusin to the new one. The events are trusted: the user agent sends them.

next

public static Element next(Document doc,
                           Element from,
                           boolean forward,
                           FocusManager.Visibility visible)
Finds the element that the Tab key (or Shift+Tab) moves the focus to: elements with a positive tabindex come first, in the order of their values and then the document order, then the others in document order; elements with a negative tabindex are skipped. Returns null after the last (or before the first) element, which is the moment to leave the document.

Tab 키(또는 Shift+Tab)가 포커스를 옮길 요소를 찾는다: tabindex 가 양수인 요소가 값 순서와 문서 순서대로 먼저 오고, 그다음 나머지가 문서 순서로 온다. tabindex 가 음수인 요소는 건너뛴다. 마지막 요소 다음(또는 첫 요소 이전)이면 null 이며, 문서를 떠날 때이다.

from - the element that has the focus now, or null / 지금 포커스를 가진 요소. 없으면 null
forward - true for Tab, false for Shift+Tab / Tab 이면 true, Shift+Tab 이면 false
visible - tells whether an element is displayed, or null to accept all / 요소가 표시되는지 알려 준다. 모두 받으려면 null
