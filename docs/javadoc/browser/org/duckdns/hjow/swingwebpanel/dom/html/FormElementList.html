Class FormElementList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.FormElementList
Direct Known Subclasses:
FormControlsCollection, HtmlOptionsCollection, RadioNodeList
public abstract class FormElementList
extends java.lang.Object

A live list of elements that the form layer exposes (form.elements, select.options, select.selectedOptions, control.labels, datalist.options, radio node lists). Like the DOM's live collections it is computed again when the document changed since the last access, and also when the state version of the form support changed (the selectedness of an option is state, not an attribute), and otherwise answers from a cache. Subclasses only say how to compute the elements.

폼 계층이 노출하는 요소의 라이브 목록(form.elements, select.options, select.selectedOptions, control.labels, datalist.options, 라디오 노드 목록). DOM 의 라이브 컬렉션처럼 마지막 접근 뒤 문서가 바뀌었거나 폼 지원의 상태 버전이 바뀌었으면(option 의 selectedness 는 속성이 아니라 상태이다) 다시 계산하고 아니면 캐시로 답한다. 하위 클래스는 요소를 계산하는 방법만 말한다.
