All Known Implementing Classes:
HtmlElementFactory
public interface ElementFactory

Creates the element objects of a document. The DOM package creates plain Element objects; the HTML layer installs a factory that creates the specialized element classes (anchor, image, form control ...) for HTML-namespace elements (plan items HEI-01 to HEI-09).

문서의 요소 객체를 만든다. DOM 패키지는 일반 Element 를 만들고, HTML 계층이 HTML 네임스페이스 요소에 대해 특화된 요소 클래스 (앵커, 이미지, 폼 컨트롤 등)를 만드는 팩터리를 설치한다(계획 HEI-01~HEI-09).
