org.duckdns.hjow.swingwebpanel.dom.html
Class FileEntry

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.html.FileEntry

public final class FileEntry
extends java.lang.Object

One file that the user selected for a file upload control (input type=file): the file name without any directory, the MIME type, the modification time and the bytes. The host (the file chooser of the Swing component) reads the file the user picked and hands it over; a page can only see the name, size, type and modification time of such files and can never choose a path itself. Instances are immutable.

파일 업로드 컨트롤(input type=file)에 사용자가 선택한 파일 하나: 디렉터리가 없는 파일 이름, MIME 타입, 수정 시각, 바이트. 호스트(Swing 컴포넌트의 파일 선택기)가 사용자가 고른 파일을 읽어 넘기며, 페이지는 그런 파일의 이름, 크기, 타입, 수정 시각만 볼 수 있고 스스로 경로를 고를 수는 없다. 인스턴스는 불변이다.
