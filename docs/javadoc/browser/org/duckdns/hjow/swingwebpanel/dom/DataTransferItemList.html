org.duckdns.hjow.swingwebpanel.dom
Class DataTransferItemList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.DataTransferItemList

public final class DataTransferItemList
extends java.lang.Object

The list of the items of a data transfer (HTML DataTransferItemList, dataTransfer.items): a view of the ClipboardData that made it, so it shows what the data transfer holds now, and it follows the mode of the data transfer (it can be read in every mode but the disabled one, and changed in the read/write mode only).

데이터 전달 객체의 항목 목록(HTML DataTransferItemList, dataTransfer.items): 이것을 만든 ClipboardData 의 뷰이므로 데이터 전달 객체가 지금 가진 것을 보이며, 데이터 전달 객체의 모드를 따른다(무효화 모드를 빼고 읽을 수 있고, 읽기/쓰기 모드에서만 바꿀 수 있다).
