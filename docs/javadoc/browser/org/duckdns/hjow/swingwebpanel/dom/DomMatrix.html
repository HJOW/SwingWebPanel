Class DomMatrix

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.DomMatrixReadOnly

public class DomMatrix
extends DomMatrixReadOnly

A matrix that scripts and the canvas may change (DOMMatrix, Geometry Interfaces Module Level 1, section 6): the transformation methods of DomMatrixReadOnly that change the matrix itself (multiplySelf, translateSelf, scaleSelf, rotateSelf, skewXSelf, invertSelf ...). Every method post-multiplies the transformation (the new transformation is applied to a point first) and returns this matrix, so calls can be chained. The is2D flag turns false as soon as a 3D operation or a 3D element is applied and never comes back (only setValues(double[], boolean) restores it). A rotation or skew by 0 and a scale around the origin do not touch the elements they cannot change, so an infinite element is not turned into NaN by a multiplication with zero.

스크립트와 캔버스가 바꿀 수 있는 행렬(DOMMatrix, Geometry Interfaces Module Level 1, 6 절): DomMatrixReadOnly 의 변환 메서드 중 행렬 자신을 바꾸는 것들(multiplySelf, translateSelf, scaleSelf, rotateSelf, skewXSelf, invertSelf 등). 모든 메서드는 변환을 뒤에 곱하고(새 변환이 점에 먼저 적용된다) 이 행렬을 반환하므로 호출을 이어 쓸 수 있다. is2D 플래그는 3D 연산이나 3D 요소가 적용되는 즉시 false 가 되며 되돌아오지 않는다(setValues(double[], boolean) 만 복원한다). 0 도 회전과 기울이기, 원점 둘레의 확대는 바꿀 수 없는 요소를 건드리지 않으므로 무한대 요소가 0 과의 곱으로 NaN 이 되지 않는다.
