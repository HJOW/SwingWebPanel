public class UiEvent
extends Event

An event that comes from the user interface (UI Events): a detail number and the state of the modifier keys that were down when it happened. It is the base of the mouse, keyboard, focus, input and composition events.

사용자 인터페이스에서 오는 이벤트(UI Events): 상세 숫자와 이벤트가 일어날 때 눌려 있던 보조 키의 상태. 마우스, 키보드, 포커스, 입력, 조합 이벤트의 기반이다.
