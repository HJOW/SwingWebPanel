Class PropertiesCollection

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.ElementCollection
      org.duckdns.hjow.swingwebpanel.dom.PropertiesCollection

public final class PropertiesCollection
extends ElementCollection

The HTMLPropertiesCollection of the Note "HTML Microdata" (section 6.1): the collection of the property elements of one item (element.properties). It is live in the sense that every access reads the tree again (Microdata.properties(Element)), so it follows changes of the document; it is empty while the element is not an item. names lists the property names in tree order without duplicates, and getNamed(String) returns the PropertyNodeList of one name (the same object every time).

노트 "HTML Microdata"(6.1절)의 HTMLPropertiesCollection: 아이템 하나의 프로퍼티 요소 컬렉션(element.properties). 접근할 때마다 트리를 다시 읽으므로(Microdata.properties(Element)) 문서의 변경을 따르며, 요소가 아이템이 아니면 비어 있다. names 는 프로퍼티 이름을 중복 없이 트리 순서로 나열하고, getNamed(String) 는 이름 하나의 PropertyNodeList 를 반환한다(매번 같은 객체).
