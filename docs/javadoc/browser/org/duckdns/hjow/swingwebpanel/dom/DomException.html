public class DomException
extends java.lang.RuntimeException

The DOM exception (DOMException of the DOM Standard). Every DOM operation that fails by specification throws it, with the standard error name (for example HierarchyRequestError) and the legacy numeric code. The JavaScript layer converts it into a DOMException object with the same name, code and message.

DOM 예외(DOM 표준의 DOMException). 규격에 따라 실패하는 모든 DOM 연산이 표준 오류 이름(예: HierarchyRequestError)과 옛 숫자 코드와 함께 이 예외를 던진다. JavaScript 계층은 같은 이름, 코드, 메시지의 DOMException 객체로 바꾼다.
