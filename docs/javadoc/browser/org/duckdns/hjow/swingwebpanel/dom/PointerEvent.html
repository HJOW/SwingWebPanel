public class PointerEvent
extends MouseEvent

A pointer event (W3C Pointer Events Level 3): a mouse event with the identity of the pointer that caused it (pointerId, pointerType, isPrimary) and the properties of its contact (width, height, pressure, tangentialPressure, tilt, twist and the altitude and azimuth angles). The mouse of this component is the only pointer: the id MOUSE_POINTER_ID, the type mouse, always primary, a contact of 1 by 1 pixels, a pressure of 0.5 while a button is down and 0 otherwise, and the neutral values (altitude PI / 2) for everything that a mouse cannot report. Events that the component fires are trusted; events that a script constructs take their values from the dictionary (the defaults of the specification), and the lists of coalesced and predicted events are copies of the dictionary lists (empty for events of the component).

포인터 이벤트(W3C Pointer Events Level 3): 이벤트를 일으킨 포인터의 정체(pointerId, pointerType, isPrimary)와 접촉의 속성(width, height, pressure, tangentialPressure, 기울기, 비틀림, 고도각과 방위각)을 가진 마우스 이벤트. 이 컴포넌트의 마우스가 유일한 포인터이다: ID MOUSE_POINTER_ID, 종류 mouse, 항상 주 포인터, 1 x 1 픽셀 접촉, 버튼이 눌려 있는 동안 압력 0.5(아니면 0), 마우스가 보고할 수 없는 것은 중립 값(고도각 PI / 2). 컴포넌트가 발생시키는 이벤트는 신뢰 이벤트이다. 스크립트가 만든 이벤트는 사전의 값(규격의 기본값)을 쓰고, 합쳐진 이벤트와 예측 이벤트의 목록은 사전 목록의 복사본이다(컴포넌트의 이벤트는 비어 있다).
