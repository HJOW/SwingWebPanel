public abstract class HtmlControl
extends Element

The base class of the HTML elements that take part in forms (form, input, button, select, option, textarea, label, fieldset ...). It connects an element to the form support of its document, offers the helpers that the elements share (attribute shortcuts, events of the user agent, labels, state notifications), and runs the activation behavior of a click event that is dispatched on such an element (see FormActivation).

폼에 참여하는 HTML 요소(form, input, button, select, option, textarea, label, fieldset 등)의 기반 클래스. 요소를 문서의 폼 지원에 연결하고, 요소들이 공유하는 도우미(속성 단축 접근, 사용자 에이전트의 이벤트, labels, 상태 통지)를 제공하며, 이런 요소에 전달된 click 이벤트의 활성화 동작(FormActivation 참조)을 실행한다.
