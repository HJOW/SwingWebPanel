public final class HtmlProgressElement
extends HtmlControl

The progress element (HTML Standard 4.10.13): a completion bar. It is labelable but not a listed form control. Without a valid value attribute the progress bar is indeterminate (its position is -1).

progress 요소(HTML 표준 4.10.13): 진행 막대. 라벨을 붙일 수 있지만 목록에 오르는 폼 컨트롤은 아니다. 올바른 value 속성이 없으면 진행 막대는 불확정 상태이다(position 이 -1).
