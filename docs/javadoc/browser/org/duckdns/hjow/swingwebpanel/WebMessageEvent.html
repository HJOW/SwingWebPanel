Class WebMessageEvent

public final class WebMessageEvent
extends java.util.EventObject

A copied message sent by a document through its Java host window. The document URL and origin are captured at send time. The component and reply target may be collected independently.

문서가 Java 호스트 창으로 보낸 복사 메시지. 송신 시의 문서 주소와 오리진을 보관한다. 컴포넌트와 응답 대상은 메시지와 독립적으로 수거될 수 있다.

reply

public void reply(java.lang.Object message)
Copies and replies to the sending document. Call from any thread. Check the sender origin and data before replying. An expired document discards the reply.

값을 복사해 보낸 문서에 응답한다. 어느 스레드에서나 호출할 수 있다. 응답을 보내기 전에 발신 오리진과 데이터를 확인한다. 문서 수명이 끝났으면 응답을 버린다.

Parameters:
message - plain Java data / Java 데이터
Throws:
java.lang.IllegalArgumentException - if the message cannot be copied / 메시지를 복사할 수 없으면
