public class SwingDownloadDialog
extends javax.swing.JDialog
implements DownloadHandle

The popup of one download (plan item P11-09): a non-modal dialog that shows the file name, the source address, the target path with a button to choose another place (a JFileChooser), the progress bar (indeterminate if the size is unknown), the number of bytes and the speed, a Cancel button that becomes Close when the download has ended, and a result line. Closing the window cancels a running download. Every method must be called on the event dispatch thread.

다운로드 하나의 팝업(계획 P11-09): 파일 이름, 출처 주소, 대상 경로와 다른 곳을 고르는 버튼(JFileChooser), 진행 막대(크기를 모르면 불확정), 받은 바이트와 속도, 다운로드가 끝나면 닫기로 바뀌는 취소 버튼, 결과 줄을 보여 주는 모달이 아닌 대화상자이다. 창을 닫으면 실행 중인 다운로드를 취소한다. 모든 메서드는 이벤트 디스패치 스레드에서 호출해야 한다.
