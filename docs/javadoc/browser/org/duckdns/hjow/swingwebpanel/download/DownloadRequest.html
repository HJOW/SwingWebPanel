org.duckdns.hjow.swingwebpanel.download
Class DownloadRequest

java.lang.Object
  org.duckdns.hjow.swingwebpanel.download.DownloadRequest

public final class DownloadRequest
extends java.lang.Object

Everything a download needs to know: where to fetch it, how to ask for it (the user agent and extra headers of the component that found it) and what the server said about it (type, declared size, Content-Disposition), plus the safe file name derived from that. It is immutable and can be handed to a popup implementation and to the transfer thread.

다운로드에 필요한 모든 정보: 어디서 가져올지, 어떻게 요청할지(발견한 컴포넌트의 User-Agent 와 추가 헤더), 서버가 알려 준 것(형식, 선언된 크기, Content-Disposition), 그리고 그로부터 정한 안전한 파일 이름. 불변이며 팝업 구현과 전송 스레드에 넘길 수 있다.
