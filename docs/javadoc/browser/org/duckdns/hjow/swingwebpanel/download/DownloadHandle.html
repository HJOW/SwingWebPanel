org.duckdns.hjow.swingwebpanel.download
Interface DownloadHandle

All Known Implementing Classes:
SwingDownloadDialog
public interface DownloadHandle

The popup of one download as seen by the download manager (the object returned by SwingDownloadHandler.createDownloadPopup(org.duckdns.hjow.swingwebpanel.download.DownloadRequest, org.duckdns.hjow.swingwebpanel.download.DownloadControl)). The real implementation is a dialog; tests and hosts can provide their own. All methods are called on the event dispatch thread, except that implementations must tolerate dispose() being called more than once.

다운로드 관리자가 보는 다운로드 하나의 팝업(SwingDownloadHandler.createDownloadPopup(org.duckdns.hjow.swingwebpanel.download.DownloadRequest, org.duckdns.hjow.swingwebpanel.download.DownloadControl) 이 반환하는 객체). 실제 구현은 대화상자이며 시험과 호스트는 자신의 구현을 줄 수 있다. 모든 메서드는 이벤트 디스패치 스레드에서 호출되며, 구현은 dispose() 가 여러 번 호출되어도 견뎌야 한다.
