Interface DownloadControl

public interface DownloadControl

What a popup may ask the download manager to do. The manager passes an instance to the popup it creates; the methods may be called on any thread.

holdForChoice

void holdForChoice(boolean holding)
Tells the download that the user is choosing another target now (true) or has finished choosing (false). While it holds, a transfer that finishes waits before it moves the file to the target, so that the choice of the user applies even if the data arrived meanwhile; a popup calls it around its file chooser (call changeTarget(File) before releasing the hold). Cancelling ends the wait as well.

사용자가 지금 다른 대상을 고르고 있음(true) 또는 고르기를 마쳤음(false)을 다운로드에 알린다. 붙잡혀 있는 동안 끝난 전송은 파일을 대상으로 옮기기 전에 기다리므로, 그 사이에 데이터가 다 와도 사용자의 선택이 적용된다. 팝업이 파일 선택기 앞뒤로 부른다(붙잡기를 풀기 전에 changeTarget(File) 을 부른다). 취소해도 기다림이 끝난다.

Parameters:
holding - true while the user chooses / 사용자가 고르는 동안 true
