Package org.duckdns.hjow.swingwebpanel.download

File downloads: download decision, download manager and Swing download popup.

See:
          Description

Interface Summary
DownloadControl What a popup may ask the download manager to do.
DownloadHandle The popup of one download as seen by the download manager (the object returned by SwingDownloadHandler.createDownloadPopup(org.duckdns.hjow.swingwebpanel.download.DownloadRequest, org.duckdns.hjow.swingwebpanel.download.DownloadControl)).
DownloadStatusSink Receives the short messages of the download manager (started, completed, failed, cancelled, refused in a headless environment) so the browser component can show them in its status text.
 

Class Summary
DownloadFileNames Chooses the file name of a download and makes it safe to use as a file name on every operating system (plan item P11-09).
DownloadRequest Everything a download needs to know: where to fetch it, how to ask for it (the user agent and extra headers of the component that found it) and what the server said about it (type, declared size, Content-Disposition), plus the safe file name derived from that.
SwingDownloadDialog The popup of one download (plan item P11-09): a non-modal dialog that shows the file name, the source address, the target path with a button to choose another place (a JFileChooser), the progress bar (indeterminate if the size is unknown), the number of bytes and the speed, a Cancel button that becomes Close when the download has ended, and a result line.
SwingDownloadHandler The download manager of a browser component (plan item P11-09, API contract section 7): it receives the navigations that must be downloaded, shows one non-modal popup per download, transfers the data on a background thread through the component's request layer (user agent, extra headers, cookies, the SSL extension point and the scheme restrictions of the ResourceFetcher) and saves it as a file.
 

Enum Summary
DownloadState The state of one download as shown in its popup.
