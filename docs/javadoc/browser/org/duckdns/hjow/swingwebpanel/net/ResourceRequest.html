org.duckdns.hjow.swingwebpanel.net
Class ResourceRequest

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.ResourceRequest

public final class ResourceRequest
extends java.lang.Object

Describes one resource request for ResourceFetcher: method, URL, optional body, the component's User-Agent and extra headers, its CookieStore, cache mode, purpose, cancellation token, referrer and initiating origin. All setters return the request for chaining. The fetch layer never changes a request.

Use: new ResourceRequest("http://host/").setUserAgent(ua).setCookies(store).setPurpose(RequestPurpose.DOCUMENT).

ResourceFetcher 에 줄 리소스 요청 하나를 기술한다. 메서드, URL, 선택적 본문, 컴포넌트의 User-Agent 와 추가 헤더, CookieStore, 캐시 모드, 목적, 취소 토큰, 참조 페이지, 요청을 일으킨 오리진을 가진다. 모든 setter 는 연쇄 호출을 위해 요청 자신을 돌려준다. 가져오기 계층은 요청을 바꾸지 않는다.

사용: new ResourceRequest("http://host/").setUserAgent(ua).setCookies(store).setPurpose(RequestPurpose.DOCUMENT).

setStreaming

public ResourceRequest setStreaming(boolean value)
Marks this request as one for a response that stays open for long. The request layer then uses its own socket connection (which can be closed at once, even while a thread waits for the next piece of data) instead of the connection of the JRE (which cannot be closed while another thread waits in a read of it), unless a proxy applies to the URL.

이 요청을 오래 열려 있는 응답을 위한 것으로 표시한다. 그러면 요청 계층은 JRE 의 연결(다른 스레드가 읽기를 기다리는 동안에는 닫을 수 없다) 대신 자체 소켓 연결(다음 데이터를 기다리는 스레드가 있어도 곧바로 닫을 수 있다)을 쓴다. URL 에 프록시가 적용되면 그렇지 않다.

Parameters:
value - true for a stream / 스트림이면 true
Returns:
this / 자기 자신
