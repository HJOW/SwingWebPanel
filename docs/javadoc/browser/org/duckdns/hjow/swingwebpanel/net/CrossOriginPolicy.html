requiresGroupSwitch

public static boolean requiresGroupSwitch(boolean initial,
                                          java.lang.String active,
                                          Origin activeOrigin,
                                          java.lang.String response,
                                          Origin responseOrigin)
Tells whether a navigation of a top-level window must move the window into a browsing context group of its own, which cuts its connection to its opener and to the windows that it opened (WHATWG HTML 7.1.3.1, "check if COOP values require a browsing context group switch").

최상위 창의 이동이 그 창을 자기만의 브라우징 문맥 그룹으로 옮겨야 하는지 알려 준다. 옮기면 여는 창, 그리고 자기가 연 창들과의 관계가 끊긴다(WHATWG HTML 7.1.3.1, "check if COOP values require a browsing context group switch").

Parameters:
initial - true if the window still shows its first about:blank document / 창이 아직 처음 about:blank 문서를 보이면 true
active - the opener policy value of the document that the window shows / 창이 보이는 문서의 opener 정책 값
activeOrigin - the origin of that document / 그 문서의 오리진
response - the opener policy value of the response / 응답의 opener 정책 값
responseOrigin - the origin of the response / 응답의 오리진
Returns:
true if the window must leave its group / 창이 그룹을 떠나야 하면 true
