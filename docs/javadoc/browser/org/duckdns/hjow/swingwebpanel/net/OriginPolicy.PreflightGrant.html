OriginPolicy
public static final class OriginPolicy.PreflightGrant
extends java.lang.Object

What a CORS-preflight response grants: the methods and header names that the server allows and how long the answer may be reused. A * grants everything (except Authorization for headers) when the request has no credentials.

CORS 사전 요청 응답이 허용하는 것: 서버가 허용하는 메서드와 헤더 이름, 그리고 답을 얼마나 오래 다시 쓸 수 있는지. 요청에 자격 증명이 없으면 * 은 모든 것(헤더의 Authorization 은 제외)을 허용한다.
