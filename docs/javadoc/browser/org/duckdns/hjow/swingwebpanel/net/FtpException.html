public class FtpException
extends java.io.IOException

An FTP protocol failure: the server answered with an unexpected reply code. getCode() tells which one so that callers can decide on fallbacks (for example from MLSD to LIST).

FTP 프로토콜 실패: 서버가 예상하지 못한 응답 코드를 돌려주었다. getCode() 로 코드를 알 수 있어 호출자가 대체 동작 (예: MLSD 에서 LIST 로)을 정할 수 있다.
