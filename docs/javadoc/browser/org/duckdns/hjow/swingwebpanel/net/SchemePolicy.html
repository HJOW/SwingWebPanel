org.duckdns.hjow.swingwebpanel.net
Class SchemePolicy

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.SchemePolicy

public final class SchemePolicy
extends java.lang.Object

Decides which URL schemes the component may fetch. Only http, https and ftp are network schemes; classpath://, file:, blob:, about:blank and the internal about:text are local or special addresses. Everything else (jar, mailto, javascript, data, ws, wss, other about: pages, ...) is blocked: the fetch layer must refuse it without connecting anywhere. The check is applied to the first URL, every redirect target and every sub-resource.

구성 요소가 가져올 수 있는 URL 스킴을 판정한다. 네트워크 스킴은 http, https, ftp 뿐이고 classpath://, file:, blob:, about:blank, 내부용 about:text 는 로컬 또는 특수 주소이다. 그 밖의 모든 스킴(jar, mailto, javascript, data, ws, wss, 다른 about: 페이지 등)은 차단하며, 가져오기 계층은 어디에도 연결하지 않고 거부해야 한다. 이 검사는 최초 주소, 모든 리디렉션 대상, 모든 하위 리소스에 적용한다.
