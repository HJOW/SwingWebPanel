Class CancelToken

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.CancelToken

public final class CancelToken
extends java.lang.Object

A cancellation flag shared between the thread that waits for a resource and the thread that wants to stop it. Network code registers CancelToken.Hooks (for example "disconnect this HTTP connection" or "close this socket"); cancel() sets the flag once and runs every hook so that blocked reads end promptly. A token can be cancelled only once; later hooks run immediately. Hooks must be quick and must not throw.

Use: CancelToken t = new CancelToken(); request.setCancelToken(t); ... t.cancel();

리소스를 기다리는 스레드와 이를 멈추려는 스레드가 공유하는 취소 표시. 네트워크 코드는 CancelToken.Hook(예: "이 HTTP 연결을 끊어라", "이 소켓을 닫아라")을 등록하고, cancel() 은 표시를 한 번 세운 뒤 모든 훅을 실행해 막힌 읽기가 곧바로 끝나게 한다. 토큰은 한 번만 취소할 수 있으며 그 뒤에 등록한 훅은 즉시 실행된다. 훅은 빠르고 예외를 던지지 않아야 한다.

사용: CancelToken t = new CancelToken(); request.setCancelToken(t); ... t.cancel();
