Class FtpListing

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.FtpListing

public final class FtpListing
extends java.lang.Object

Builds the HTML page that shows an FTP directory. Directories come first and are links (with a trailing slash) that lead to the sub directory; the very first entry is a ../ link to the parent directory except at the FTP root, where nothing links above the root. Files are links too (so that a click downloads or shows them). Every name is HTML-escaped, so a file name can never become a tag, and every link is a percent-encoded relative URL that starts with ./ (a name such as a:b can therefore not be mistaken for a scheme). Lines that could not be parsed are listed as plain escaped text without a link.

FTP 디렉터리를 보여 주는 HTML 페이지를 만든다. 디렉터리를 먼저 나열하고 하위 디렉터리로 가는 링크(끝에 슬래시)로 만들며, FTP 루트가 아니면 가장 먼저 상위 디렉터리로 가는 ../ 링크를 둔다(루트 위로 가는 링크는 없다). 파일도 링크이다(클릭하면 내려받거나 표시). 모든 이름은 HTML 이스케이프하므로 파일 이름이 태그가 될 수 없고, 링크는 모두 ./ 로 시작하는 퍼센트 인코딩된 상대 URL 이다(a:b 같은 이름이 스킴으로 오해되지 않는다). 해석하지 못한 줄은 링크 없이 이스케이프한 평문으로 나열한다.
