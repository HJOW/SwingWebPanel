org.duckdns.hjow.swingwebpanel.net
Class Cookie

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.Cookie

public final class Cookie
extends java.lang.Object

One stored cookie (RFC 6265). Instances are immutable. A host-only cookie matches exactly the host that set it, a domain cookie also matches sub domains. The expiry is an absolute time in milliseconds; session cookies have no expiry.

저장된 쿠키 하나(RFC 6265). 인스턴스는 불변이다. 호스트 전용 쿠키는 설정한 호스트에만 일치하고 도메인 쿠키는 하위 도메인에도 일치한다. 만료는 밀리초 단위의 절대 시각이며 세션 쿠키는 만료가 없다.
