org.duckdns.hjow.swingwebpanel.net
Class ResourceFetcher

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.ResourceFetcher

public final class ResourceFetcher
extends java.lang.Object

The single entry point of the resource layer. It dispatches by scheme to HttpFetcher (http and https), FtpFetcher (ftp) and ClasspathLoader (classpath) and enforces the allowed-scheme policy of SchemePolicy: any other scheme is answered with FailureKind.BLOCKED_SCHEME without contacting anything.

  • about:blank gives an empty HTML response; about:text and every other address are refused here (the component handles them itself).
  • A document served from the network (http, https, ftp initiator) may not load classpath:// resources: such a request is blocked, so remote pages cannot read the application's class path.
One instance can be shared by all requests of a component. fetch(ResourceRequest, ResponseHandler) never throws for network or file problems and may be called from any thread; the call blocks the calling thread, so call it from the document owner thread or a worker, never from the EDT.

Use: new ResourceFetcher(sslConfigurer, FetchLimits.DEFAULT, null).fetch(new ResourceRequest(url)).

리소스 계층의 단일 진입점. 스킴에 따라 HttpFetcher(http, https), FtpFetcher(ftp), ClasspathLoader(classpath)로 분기하며 SchemePolicy 의 허용 스킴 정책을 강제한다. 그 밖의 스킴은 어디에도 연결하지 않고 FailureKind.BLOCKED_SCHEME 로 답한다.

  • about:blank 는 빈 HTML 응답을 돌려주고, about:text 와 그 밖의 주소는 여기서 거부한다(컴포넌트가 직접 처리).
  • 네트워크에서 온 문서(http, https, ftp 를 initiator 로 가진 요청)는 classpath:// 리소스를 읽을 수 없다. 그런 요청은 차단되므로 원격 페이지가 애플리케이션의 클래스패스를 읽을 수 없다.
인스턴스 하나를 컴포넌트의 모든 요청이 공유할 수 있다. fetch(ResourceRequest, ResponseHandler) 는 네트워크나 파일 문제로 예외를 던지지 않으며 어느 스레드에서나 호출할 수 있다. 호출한 스레드를 막으므로 EDT 가 아니라 문서 소유 스레드나 작업 스레드에서 호출한다.

사용: new ResourceFetcher(sslConfigurer, FetchLimits.DEFAULT, null).fetch(new ResourceRequest(url)).

setCache

public void setCache(HttpCache newCache)
Installs the HTTP cache that every http/https GET goes through (plan item P19-03). A component uses one cache per fetcher so that responses are never shared between components. Responses that the body handler streams (downloads), unsafe methods and non-HTTP schemes are not stored.

모든 http/https GET 이 거치는 HTTP 캐시를 설치한다(계획 P19-03). 컴포넌트는 가져오기 객체마다 캐시 하나를 쓰므로 응답이 컴포넌트 사이에 공유되지 않는다. 본문 처리기가 스트림으로 보낸 응답(다운로드), 안전하지 않은 메서드, HTTP 가 아닌 스킴은 저장하지 않는다.

Parameters:
newCache - the cache, or null to switch caching off / 캐시. null 이면 캐시를 끈다
