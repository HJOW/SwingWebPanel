org.duckdns.hjow.swingwebpanel.net
Class UrlUtil

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.UrlUtil

public final class UrlUtil
extends java.lang.Object

URL helper implementing RFC 3986 parsing, relative reference resolution and dot-segment removal on plain strings, plus the project specific classpath:// canonical form. It never decodes percent escapes while resolving (no double decoding) and never treats + in a path as a space; decoding is an explicit single step (percentDecode(String)) used only where a protocol needs the decoded path (FTP and classpath).

The classpath://a/b.html form means: everything after classpath: and any slashes is the resource path a/b.html (never an authority), so classpath://a/b.html resolved with c.css is classpath://a/c.css; .. cannot climb above the class path root.

Use: UrlUtil.resolve("http://h/a/b.html", "../c.css") gives http://h/c.css.

RFC 3986 의 해석, 상대 참조 결합, 점 세그먼트 제거를 문자열 위에서 구현한 URL 도우미이며 프로젝트 전용 classpath:// 정규 형식도 다룬다. 결합 중에는 퍼센트 인코딩을 디코딩하지 않으며(중복 디코딩 없음) 경로의 + 를 공백으로 보지 않는다. 디코딩은 프로토콜이 필요로 하는 곳(FTP, 클래스패스)에서만 percentDecode(String) 로 한 번 명시적으로 수행한다.

classpath://a/b.html 형식은 classpath: 와 이어지는 슬래시 뒤의 전부가 리소스 경로 a/b.html 이라는 뜻이다(authority 가 아님). 이 주소에 c.css 를 결합하면 classpath://a/c.css 이고, .. 는 클래스패스 루트 위로 올라갈 수 없다.

사용: UrlUtil.resolve("http://h/a/b.html", "../c.css") 의 결과는 http://h/c.css 이다.

encodeIllegal

public static java.lang.String encodeIllegal(java.lang.String input)
Makes user typed text safe for parsing: trims, removes tab/CR/LF, turns '\' into '/' in the path of special schemes, and percent-encodes spaces, control characters, non-ASCII characters (as UTF-8) and other characters that are not allowed in URLs. A '%' that is not followed by two hex digits becomes %25. Existing valid escapes stay.

사용자가 입력한 문자열을 해석하기 안전하게 만든다. 앞뒤 공백과 탭/CR/LF 를 지우고, 특수 스킴에서는 경로의 '\' 를 '/' 로 바꾸며, 공백/제어 문자/비 ASCII 문자(UTF-8)와 URL 에 허용되지 않는 문자를 퍼센트 인코딩한다. 16진수 두 자리가 뒤따르지 않는 '%' 는 %25 가 된다. 이미 올바른 이스케이프는 그대로 둔다.

Parameters:
input - raw text / 원본 문자열
Returns:
a string that contains only URL characters / URL 문자만 가진 문자열
