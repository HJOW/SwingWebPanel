org.duckdns.hjow.swingwebpanel.net
Class Origin

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.Origin

public final class Origin
extends java.lang.Object

A web origin: scheme, host and effective port (RFC 6454 / HTML origin). Origins of http, https and ftp URLs are tuples; all classpath:// documents share the tuple origin classpath:// (same JVM, same class path); about:blank, about:text and unparsable or blocked addresses have an opaque origin that equals no other origin (not even another opaque one) and serializes as null.

Use of(String) and isSameOrigin(Origin). Cross origin response bodies must never be exposed to scripts only because they can be displayed; see OriginPolicy.

웹 오리진: 스킴, 호스트, 실효 포트(RFC 6454 / HTML 오리진). http, https, ftp URL 의 오리진은 튜플이고, 모든 classpath:// 문서는 같은 튜플 오리진 classpath:// 를 공유한다(같은 JVM, 같은 클래스패스). about:blank, about:text, 해석 불가 또는 차단된 주소는 어떤 오리진과도(다른 불투명 오리진과도) 같지 않은 불투명 오리진이며 null 로 직렬화된다.

of(String) 와 isSameOrigin(Origin) 를 사용한다. 교차 오리진 응답 본문은 표시할 수 있다는 이유만으로 스크립트에 노출해서는 안 된다. OriginPolicy 를 참조한다.
