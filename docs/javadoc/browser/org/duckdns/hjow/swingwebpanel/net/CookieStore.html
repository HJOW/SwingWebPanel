org.duckdns.hjow.swingwebpanel.net
Class CookieStore

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.CookieStore

public final class CookieStore
extends java.lang.Object

A per-component cookie jar implementing RFC 6265 storage and retrieval without any JVM wide state (java.net.CookieHandler.setDefault is never used). It parses Set-Cookie values (Domain, Path, Expires, Max-Age, Secure, HttpOnly), handles deletion (past expiry, Max-Age <= 0), keeps cookies with the same name but different domain/path, and produces three views:

  • getCookieHeader(String): the Cookie request header for a URL (includes HttpOnly, Secure only for https);
  • getDocumentCookie(String): what document.cookie returns for a URL (hides HttpOnly);
  • getCookies(): every unexpired cookie as name=value; name=value ordered by domain, path and name.
Deliberate policies: a Secure cookie is accepted only from an https URL; a script (see setFromScript(String, String)) cannot create or overwrite HttpOnly cookies; Domain attributes that are a single label (for example "com") are rejected unless they equal the request host, because no public suffix list is available (multi label public suffixes such as "co.kr" are therefore NOT rejected - a documented limitation). All methods are thread safe.

컴포넌트별 쿠키 저장소. JVM 전역 상태 없이(java.net.CookieHandler.setDefault 를 쓰지 않음) RFC 6265 의 저장과 조회를 구현한다. Set-Cookie 값(Domain, Path, Expires, Max-Age, Secure, HttpOnly)을 해석하고, 삭제(지난 만료, Max-Age <= 0)를 처리하며, 이름이 같아도 도메인/경로가 다른 쿠키를 모두 보존하고, 세 가지 보기를 제공한다.

  • getCookieHeader(String): URL 의 Cookie 요청 헤더(HttpOnly 포함, Secure 는 https 만);
  • getDocumentCookie(String): URL 에서 document.cookie 가 돌려줄 값(HttpOnly 숨김);
  • getCookies(): 만료되지 않은 모든 쿠키를 도메인, 경로, 이름 순의 name=value; name=value 로.
의도한 정책: Secure 쿠키는 https URL 에서만 받는다. 스크립트(setFromScript(String, String))는 HttpOnly 쿠키를 만들거나 덮어쓸 수 없다. 단일 레이블 Domain 속성(예: "com")은 요청 호스트와 같을 때만 허용한다(공개 접미사 목록이 없기 때문이며, "co.kr" 같은 다중 레이블 공개 접미사는 거부되지 않는다는 한계가 있다). 모든 메서드는 스레드 안전하다.
