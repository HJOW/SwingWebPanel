Class RequestHeaders

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.RequestHeaders

public final class RequestHeaders
extends java.lang.Object

The additional request headers of one component. Names are matched case-insensitively and a new value overwrites the old one without removing other headers (the position and the spelling of the latest name are kept). The User-Agent header (in any letter case) is never accepted here: it is silently ignored and never reported, because it is managed with setUserAgent. Input is validated as a whole: null maps or entries, keys/values that are not String, empty or illegal names, and values containing CR, LF or NUL reject the complete call with IllegalArgumentException and nothing is applied. toMap() returns a copy.

한 컴포넌트의 추가 요청 헤더. 이름은 대소문자를 구분하지 않고 매칭하며, 새 값은 다른 헤더를 지우지 않고 기존 값을 덮어쓴다 (위치는 유지하고 이름 표기는 마지막 입력을 따른다). User-Agent 헤더(대소문자 불문)는 setUserAgent 로 관리하므로 여기서는 받지 않고 조용히 무시하며 조회 결과에도 나오지 않는다. 입력은 전체를 한꺼번에 검증한다. null 맵/항목, String 이 아닌 키/값, 빈 이름이나 잘못된 이름, CR/LF/NUL 을 포함한 값이 하나라도 있으면 IllegalArgumentException 으로 호출 전체를 거부하고 아무것도 적용하지 않는다. toMap() 은 복사본을 돌려준다.
