Class FetchLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.FetchLimits

public final class FetchLimits
extends java.lang.Object

Timeouts and size limits of the fetch layer (documented defaults of API_CONTRACT section 9). Instances are immutable; use the with... methods to derive a changed copy (tests use small values).

Limit / 제한Default / 기본값On exceed / 초과 시
connect timeout15 sFailureKind.TIMEOUT
read timeout30 sFailureKind.TIMEOUT
redirects20FailureKind.TOO_MANY_REDIRECTS
in-memory response body16 MiB (after decompression)FailureKind.TOO_LARGE
streamed downloadunlimited-

가져오기 계층의 제한 시간과 크기 제한(API_CONTRACT 9절의 기본값). 인스턴스는 불변이며 with... 메서드로 바꾼 복사본을 만든다(시험은 작은 값을 쓴다). 위 표 참조: 연결 15초, 읽기 30초, 리디렉션 20회, 메모리 응답 본문 16 MiB(압축 해제 후), 스트리밍 다운로드는 제한 없음.
