SslConfigurer
public final class DefaultSslConfigurer
extends java.lang.Object
implements SslConfigurer

The default SSL behaviour: keep the JRE default trust store and host name verification untouched, and only enable the newest TLS protocol versions (TLSv1.3, TLSv1.2, TLSv1.1, TLSv1 - in that preference) that the running JRE supports, because older JREs do not enable the newer ones by default. SSLv3 and SSLv2Hello are never enabled by this class. The change is made per connection through a delegating socket factory; no JVM-wide state is modified.

JRE 6 (6u45) supports only TLSv1 (no TLS 1.2, no client SNI), so modern https sites may fail there; the fetch layer then retries once over http as required by the project.

기본 SSL 동작: JRE 기본 신뢰 저장소와 호스트 이름 검증은 건드리지 않고, 실행 중인 JRE 가 지원하는 최신 TLS 프로토콜 버전 (TLSv1.3, TLSv1.2, TLSv1.1, TLSv1 순의 선호)만 켠다. 오래된 JRE 는 새 버전을 기본으로 켜지 않기 때문이다. 이 클래스는 SSLv3 와 SSLv2Hello 를 켜지 않는다. 변경은 위임하는 소켓 팩토리로 연결마다 적용하며 JVM 전역 상태는 바꾸지 않는다.

JRE 6(6u45)은 TLSv1 만 지원하므로(TLS 1.2, 클라이언트 SNI 없음) 요즘 https 사이트는 실패할 수 있고, 그 경우 가져오기 계층이 프로젝트 요구대로 http 로 한 번 재시도한다.
