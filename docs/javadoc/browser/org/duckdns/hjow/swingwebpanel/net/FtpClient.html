org.duckdns.hjow.swingwebpanel.net
Class FtpClient

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.FtpClient

public final class FtpClient
extends java.lang.Object

An anonymous FTP client on plain sockets (RFC 959, EPSV from RFC 2428, MLSD from RFC 3659); no JRE internal FTP class is used. One instance serves one control connection and is not thread safe.

  • Login: always USER anonymous with the password ANONYMOUS_PASSWORD; user info in a URL is never used. Multi-line replies (220- ... 220 ) are handled for every command.
  • Data connections are passive: EPSV first, PASV when EPSV is refused. The data connection always goes to the address of the control connection (the address in a PASV reply is validated but ignored, which also defeats FTP bounce attacks); ports outside 1-65535 are refused. The completion reply (226/250) of every transfer is always read.
  • Listings: MLSD is tried first; if the server does not support it (any 5xx reply) LIST is used. Names are decoded as UTF-8, or as a legacy Korean charset / ISO-8859-1 when the bytes are not valid UTF-8.
  • Safety: a path or any command text containing CR, LF or NUL is rejected before anything is sent.
  • Time and cancel: connect and read timeouts; CancelToken.cancel() closes the control and data sockets.

평문 소켓으로 만든 익명 FTP 클라이언트(RFC 959, RFC 2428 의 EPSV, RFC 3659 의 MLSD). JRE 내부 FTP 클래스는 쓰지 않는다. 인스턴스 하나가 제어 연결 하나를 맡으며 스레드 안전하지 않다.

  • 로그인: 항상 USER anonymous 와 비밀번호 ANONYMOUS_PASSWORD 를 쓰며 URL 의 사용자 정보는 쓰지 않는다. 모든 명령에서 여러 줄 응답(220- ... 220 )을 처리한다.
  • 데이터 연결은 수동 방식이다. EPSV 를 먼저 쓰고 거부되면 PASV 를 쓴다. 데이터 연결은 항상 제어 연결의 주소로 가며(PASV 응답의 주소는 검증하되 무시하므로 FTP bounce 공격도 막음) 1~65535 밖의 포트는 거부한다. 모든 전송의 완료 응답(226/250)을 반드시 읽는다.
  • 목록: MLSD 를 먼저 시도하고 서버가 지원하지 않으면(5xx 응답) LIST 를 쓴다. 이름은 UTF-8 로 해독하고, 올바른 UTF-8 이 아니면 옛 한국어 문자셋 또는 ISO-8859-1 로 해독한다.
  • 안전: CR, LF, NUL 이 들어 있는 경로나 명령 문자열은 아무것도 보내기 전에 거부한다.
  • 시간과 취소: 연결/읽기 제한 시간이 있으며 CancelToken.cancel() 이 제어/데이터 소켓을 닫는다.
