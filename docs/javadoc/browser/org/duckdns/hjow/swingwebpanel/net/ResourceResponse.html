org.duckdns.hjow.swingwebpanel.net
Class ResourceResponse

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.ResourceResponse

public final class ResourceResponse
extends java.lang.Object

The result of a fetch: status, headers, media type, charset, decoded body, final URL, origin and, for failures, the FailureKind with a message. A fetch never throws for I/O problems; it returns a response whose getFailureKind() is not FailureKind.NONE. HTTP error statuses (404, 500, ...) are normal responses with their body kept (isHttpError()). The body is already decompressed (gzip/deflate). When the body was streamed to a ResponseHandler stream, getBody() is empty and isStreamed() is true.

가져오기 결과: 상태, 헤더, 미디어 타입, 문자셋, 해독된 본문, 최종 URL, 오리진, 실패 시 FailureKind 와 메시지. 가져오기는 입출력 문제로 예외를 던지지 않고 getFailureKind() 가 FailureKind.NONE 이 아닌 응답을 돌려준다. HTTP 오류 상태(404, 500 등)는 본문을 유지한 정상 응답이다(isHttpError()). 본문은 이미 압축이 풀려 있다(gzip/deflate). 본문을 ResponseHandler 의 스트림으로 흘렸으면 getBody() 는 비어 있고 isStreamed() 가 true 이다.
