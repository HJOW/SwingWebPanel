Class FtpEntry

java.lang.Object
  org.duckdns.hjow.swingwebpanel.net.FtpEntry

public final class FtpEntry
extends java.lang.Object

One entry of an FTP directory listing. Entries that cannot be classified safely have the type FtpEntry.Type.UNKNOWN and keep the original raw line so that nothing is ever shown as a directory by guessing.

FTP 디렉터리 목록의 항목 하나. 안전하게 분류할 수 없는 항목은 FtpEntry.Type.UNKNOWN 이며 원문 줄(raw)을 보관하여 추측으로 디렉터리처럼 보이는 일이 없게 한다.
