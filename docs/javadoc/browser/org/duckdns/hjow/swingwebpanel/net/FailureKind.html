public enum FailureKind
extends java.lang.Enum<FailureKind>

Why a fetch did not produce a normal response. An HTTP error status (404, 500, ...) is not a failure kind: such responses carry their status and body and have kind NONE. The content layer maps failure kinds to error pages (plan item P17-06).

가져오기가 정상 응답을 만들지 못한 이유. HTTP 오류 상태(404, 500 등)는 실패 종류가 아니며 상태와 본문을 가진 NONE 응답이다. 콘텐츠 계층이 실패 종류를 오류 페이지로 바꾼다(계획 P17-06).
