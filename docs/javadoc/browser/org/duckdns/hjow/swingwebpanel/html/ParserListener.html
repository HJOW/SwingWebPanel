org.duckdns.hjow.swingwebpanel.html
Interface ParserListener

All Known Implementing Classes:
ParserListenerAdapter
public interface ParserListener

Observer of a running HtmlParser: it learns about diagnostics, the document mode, the resources that the document refers to (scripts, style sheets, images, base URL, refresh) and elements that have just been created or closed. This is how the loading model of the browser (P07-08) hooks into the parser without the parser knowing anything about networking or scripting.

All callbacks are made on the thread that runs the parser, between two tokens, so the document tree is consistent (pending text has been flushed) and the callback may inspect or even modify the tree. Subclass ParserListenerAdapter to override only some of the callbacks.

실행 중인 HtmlParser 의 관찰자: 진단, 문서 모드, 문서가 참조하는 자원(스크립트, 스타일시트, 이미지, 기준 URL, 새로고침), 방금 만들어지거나 닫힌 요소를 알려 준다. 이를 통해 브라우저의 로딩 모델(P07-08)이 파서가 네트워크나 스크립트를 몰라도 되도록 파서에 연결된다.

모든 콜백은 파서를 실행하는 스레드에서 토큰과 토큰 사이에 호출되므로 문서 트리는 일관된 상태(대기 중인 텍스트가 반영됨)이며, 콜백이 트리를 살펴보거나 수정할 수도 있다. 일부 콜백만 재정의하려면 ParserListenerAdapter 를 상속한다.

scriptReady

void scriptReady(Element script,
                 ParserControl control)
Called when the end tag of a script element (HTML or SVG) has been processed, at the point where the HTML Standard says to "prepare the script element". The element's text content is complete. The listener may run the script (which may call ParserControl.insertAtInsertionPoint(String) for document.write) or call ParserControl.pause() while an external script is loading and HtmlParser.resume() later. Scripts of fragment parsing are not reported (they are marked "already started" instead).

script 요소(HTML 또는 SVG)의 종료 태그를 처리했을 때, HTML 표준이 "prepare the script element" 를 하라고 한 지점에서 호출된다. 요소의 텍스트 내용은 완성되어 있다. 리스너는 스크립트를 실행하거나(document.write 를 위해 ParserControl.insertAtInsertionPoint(String) 를 호출할 수 있다), 외부 스크립트를 불러오는 동안 ParserControl.pause() 를 호출하고 나중에 HtmlParser.resume() 을 호출할 수 있다. 조각 파싱의 스크립트는 보고하지 않는다(대신 "already started" 로 표시한다).

Parameters:
script - the script element / script 요소
control - control of the parser / 파서 제어
