Class ParseError

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.ParseError

public final class ParseError
extends java.lang.Object

One parse error (a diagnostic) reported while decoding, tokenizing or tree building. HTML parse errors never stop parsing; they are only collected for diagnostics. The code is the error code of the HTML Standard (for example eof-in-tag) or a tree construction code of this implementation (for example unexpected-start-tag).

디코딩, 토큰화, 트리 생성 중 보고되는 파싱 오류(진단) 하나. HTML 파싱 오류는 파싱을 멈추지 않으며 진단용으로만 모은다. code 는 HTML 표준의 오류 코드(예: eof-in-tag)이거나 이 구현의 트리 생성 코드(예: unexpected-start-tag)이다.
