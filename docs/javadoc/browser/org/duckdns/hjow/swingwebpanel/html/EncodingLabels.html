org.duckdns.hjow.swingwebpanel.html
Class EncodingLabels

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.EncodingLabels

public final class EncodingLabels
extends java.lang.Object

Label and name handling of the Encoding Standard: it maps the labels that appear in HTTP headers and meta elements (utf8, euc-kr, ks_c_5601-1987, ...) to the canonical encoding names (UTF-8, EUC-KR, ...) using the generated table EncodingLabelData, and maps each canonical name to a charset that the running JRE can decode with. The table is built once on first use.

Encoding 표준의 라벨과 이름 처리: HTTP 헤더와 meta 요소에 나오는 라벨(utf8, euc-kr, ks_c_5601-1987 등)을 생성된 표 EncodingLabelData 로 표준 인코딩 이름(UTF-8, EUC-KR 등)에 대응시키고, 각 표준 이름을 실행 중인 JRE 가 디코딩할 수 있는 charset 에 대응시킨다. 표는 처음 쓸 때 한 번 만든다.

decode

public static java.lang.String decode(byte[] bytes,
                                      int offset,
                                      java.lang.String canonical)
Decodes bytes in a canonical encoding. Malformed or unmappable input becomes U+FFFD, as the Encoding Standard requires; no exception is thrown. An encoding that this JRE cannot decode is decoded as windows-1252.

표준 인코딩의 바이트를 디코딩한다. Encoding 표준대로 잘못되었거나 대응할 수 없는 입력은 U+FFFD 가 되며 예외는 던지지 않는다. 이 JRE 가 디코딩할 수 없는 인코딩은 windows-1252 로 디코딩한다.

Parameters:
bytes - bytes / 바이트
offset - first byte to decode / 디코딩할 첫 바이트의 위치
canonical - canonical name / 표준 이름
Returns:
decoded text / 디코딩된 문자열
