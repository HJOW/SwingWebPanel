org.duckdns.hjow.swingwebpanel.html
Class HtmlTags

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.HtmlTags

public final class HtmlTags
extends java.lang.Object

Numeric ids of the element names that the tree builder treats specially, plus the name categories of the HTML Standard (special, formatting, scope boundaries). The tree builder compares small integers in switch statements instead of strings, which Java 6 cannot switch on. Id 0 stands for every other name. The names are lower case; the SVG element foreignObject is known as foreignobject because lookups use the lower-cased local name.

트리 생성기가 특별히 다루는 요소 이름의 숫자 번호와 HTML 표준의 이름 범주(special, formatting, 범위 경계). 트리 생성기는 Java 6 에서 switch 할 수 없는 문자열 대신 작은 정수를 switch 로 비교한다. 번호 0 은 그 밖의 모든 이름이다. 이름은 소문자이며, SVG 요소 foreignObject 는 소문자로 바꾼 로컬 이름으로 찾으므로 foreignobject 로 알려져 있다.
