org.duckdns.hjow.swingwebpanel.html
Class DecodedText

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.DecodedText

public final class DecodedText
extends java.lang.Object

The result of decoding a document: the text, the encoding that was used, how sure the decision is and the original bytes. The text keeps line ends and white space exactly as received (it is what getContent() returns); the normalization that the HTML parser needs is done separately by InputPreprocessor. The bytes are kept so that the parser can start over with another encoding when a late meta element reveals that the prescan guessed wrong (redecode(String)).

문서를 디코딩한 결과: 문자열, 사용한 인코딩, 판정의 확실성, 원본 바이트. 문자열은 줄 끝과 공백을 받은 그대로 보존한다(getContent() 가 반환하는 값이다). HTML 파서에 필요한 정규화는 InputPreprocessor 가 따로 한다. 늦게 나온 meta 요소가 사전 검사의 추측이 틀렸음을 알려 줄 때 파서가 다른 인코딩으로 다시 시작할 수 있도록 바이트를 보관한다(redecode(String)).

redecode

public DecodedText redecode(java.lang.String canonicalName)
Decodes the original bytes again with another encoding and marks the result certain ("change the encoding"). A byte order mark of the original bytes is skipped as before. Returns this object if there are no bytes or the encoding is the same.

원본 바이트를 다른 인코딩으로 다시 디코딩하고 결과를 확실로 표시한다("change the encoding"). 원본의 BOM 은 전과 같이 건너뛴다. 바이트가 없거나 인코딩이 같으면 이 객체를 반환한다.
