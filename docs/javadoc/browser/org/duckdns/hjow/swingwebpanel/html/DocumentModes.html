Class DocumentModes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.DocumentModes

public final class DocumentModes
extends java.lang.Object

Determination of the document mode (no-quirks, limited-quirks, quirks) from a DOCTYPE token, as the "initial" insertion mode of the HTML Standard prescribes: the force-quirks flag, a name other than html, a list of public identifiers (the old HTML 2.0, 3.2 and 4.0 era DTDs and some vendor DTDs) and the rules for the HTML 4.01 and XHTML 1.0 transitional and frameset DTDs, which depend on the presence of a system identifier. All identifier comparisons ignore ASCII case. The mode decides, among other things, the layout rules of old documents (P07-07).

DOCTYPE 토큰에서 문서 모드(no-quirks, limited-quirks, quirks)를 정한다. HTML 표준의 "initial" 삽입 모드가 정한 대로이다: force-quirks 플래그, html 이 아닌 이름, 공개 식별자 목록(HTML 2.0, 3.2, 4.0 시대의 옛 DTD 와 일부 공급자 DTD), 시스템 식별자 유무에 따라 달라지는 HTML 4.01 과 XHTML 1.0 의 transitional/frameset DTD 규칙. 모든 식별자 비교는 ASCII 대소문자를 무시한다. 문서 모드는 옛 문서의 레이아웃 규칙 등을 결정한다(P07-07).
