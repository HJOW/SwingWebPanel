Interface ParserControl

All Known Implementing Classes:
HtmlParser
public interface ParserControl

The part of a running HtmlParser that a ParserListener may use while it handles a callback: inserting markup at the insertion point (document.write) and pausing the parser (a pending parsing-blocking script).

ParserListener 가 콜백을 처리하는 동안 쓸 수 있는, 실행 중인 HtmlParser 의 부분: 삽입 지점에 마크업 삽입 (document.write)과 파서 일시 정지(파싱을 막는 스크립트 대기).

insertAtInsertionPoint

void insertAtInsertionPoint(java.lang.String text)
Inserts text into the input stream just before the next input character, exactly as document.write does while the parser is running. The text is tokenized after the callback returns. Ignored in fragment parsing.

다음 입력 문자 바로 앞의 입력 스트림에 문자열을 삽입한다. 파서가 실행 중일 때 document.write 가 하는 것과 같다. 문자열은 콜백이 반환된 뒤 토큰화된다. 조각 파싱에서는 무시된다.

Parameters:
text - markup text / 마크업 문자열

pause

void pause()
Requests that HtmlParser.run() returns after the current token so that a blocking script can be loaded; continue with HtmlParser.resume().

파싱을 막는 스크립트를 불러올 수 있도록 현재 토큰 뒤에 HtmlParser.run() 이 반환되게 요청한다. HtmlParser.resume() 으로 계속한다.
