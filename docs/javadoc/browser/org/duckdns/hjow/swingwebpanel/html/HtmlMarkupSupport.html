Class HtmlMarkupSupport

MarkupSupport
public final class HtmlMarkupSupport
extends java.lang.Object
implements MarkupSupport

The HTML implementation of the DOM's MarkupSupport service: it gives innerHTML, outerHTML, insertAdjacentHTML their meaning. Serialization follows "serializing HTML fragments" of the HTML Standard (escaping of text and attribute values, void elements, raw text elements, template contents, namespaced attribute names) and parsing uses the fragment parsing algorithm of HtmlParser. Install it with document.setMarkupSupport(new HtmlMarkupSupport()). The serializer walks the tree iteratively, so very deep trees do not overflow the Java stack.

The fragment parser and the serializer do not insert a line feed after the start tag of pre, textarea and listing (current browsers and the standard do not either).

DOM 의 MarkupSupport 서비스의 HTML 구현: innerHTML, outerHTML, insertAdjacentHTML 에 의미를 준다. 직렬화는 HTML 표준의 "serializing HTML fragments"(텍스트와 속성 값 이스케이프, void 요소, 원문 텍스트 요소, template 내용, 네임스페이스가 있는 속성 이름)를 따르고 파싱은 HtmlParser 의 조각 파싱 알고리즘을 쓴다. document.setMarkupSupport(new HtmlMarkupSupport()) 로 설치한다. 직렬화기는 트리를 반복문으로 훑으므로 아주 깊은 트리에서도 자바 스택이 넘치지 않는다.

조각 파서와 직렬화기는 pre, textarea, listing 시작 태그 뒤에 줄바꿈을 넣지 않는다(현재 브라우저와 표준도 그렇다).
