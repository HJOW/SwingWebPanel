org.duckdns.hjow.swingwebpanel.html
Class ParseErrorLog

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.ParseErrorLog

public final class ParseErrorLog
extends java.lang.Object

Collector of ParseErrors shared by the tokenizer and the tree builder of one parse. It converts offsets to line and column numbers lazily (only when an error actually occurs), caps the number of stored errors and forwards each error to an optional ParserListener. Not thread-safe: it belongs to the one thread that runs the parser.

한 번의 파싱에서 토큰화기와 트리 생성기가 공유하는 ParseError 수집기. 오류가 실제로 생길 때만 위치를 줄/열 번호로 바꾸고, 저장하는 오류 수에 상한을 두며, 각 오류를 선택적인 ParserListener 에 전달한다. 스레드 안전하지 않다: 파서를 실행하는 한 스레드의 것이다.
