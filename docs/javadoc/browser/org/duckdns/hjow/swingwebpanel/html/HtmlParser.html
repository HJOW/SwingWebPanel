org.duckdns.hjow.swingwebpanel.html
Class HtmlParser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.HtmlParser
All Implemented Interfaces:
ParserControl
public final class HtmlParser
extends java.lang.Object
implements ParserControl

The HTML parser: it connects the encoding detection (EncodingSniffer), the input preprocessing (InputPreprocessor), the HtmlTokenizer and the HtmlTreeBuilder and builds a DOM tree of org.duckdns.hjow.swingwebpanel.dom from markup. It is implemented from scratch after the parsing chapter of the HTML Standard; nothing of the JRE's HTML or XML parsers is used.

Typical use: 

 Document doc = HtmlParser.parseDocument("<p>Hello <b>world");              // a whole document
 Document doc2 = HtmlParser.parseDocument(bytes, "euc-kr", "http://host/a.html");  // bytes of a response, with encoding detection
 DocumentFragment f = HtmlParser.parseFragment(contextElement, "<li>one<li>two"); // innerHTML
For documents that load resources while they are parsed (scripts, document.write), create an instance, set a ParserListener and call run(); when the listener calls ParserControl.pause() (for example to wait for an external script), run() returns and resume() continues. HTML parse errors never stop the parser; they are collected in getErrors().

Threading: an instance is used by one thread at a time (the thread that owns the document).

HTML 파서: 인코딩 판정(EncodingSniffer), 입력 전처리(InputPreprocessor), HtmlTokenizer, HtmlTreeBuilder 를 이어 마크업으로부터 org.duckdns.hjow.swingwebpanel.dom 의 DOM 트리를 만든다. HTML 표준의 파싱 장을 따라 처음부터 구현했으며 JRE 의 HTML/XML 파서는 쓰지 않는다.

사용 예: 

 Document doc = HtmlParser.parseDocument("<p>Hello <b>world");              // 문서 전체
 Document doc2 = HtmlParser.parseDocument(bytes, "euc-kr", "http://host/a.html");  // 응답 바이트(인코딩 판정 포함)
 DocumentFragment f = HtmlParser.parseFragment(contextElement, "<li>one<li>two"); // innerHTML
파싱 중 자원을 불러오는 문서(스크립트, document.write)는 인스턴스를 만들어 ParserListener 를 지정하고 run() 을 호출한다. 리스너가 (예: 외부 스크립트를 기다리려고) ParserControl.pause() 를 호출하면 run() 이 반환되고 resume() 으로 계속한다. HTML 파싱 오류는 파서를 멈추지 않으며 getErrors() 에 모인다.

스레드: 인스턴스는 한 번에 한 스레드(문서를 소유한 스레드)가 쓴다.

parseFragment

public static DocumentFragment parseFragment(Element context,
                                             java.lang.String markup)
Parses markup in the context of an element ("HTML fragment parsing algorithm", the algorithm behind innerHTML). The nodes are created in the owner document of the context element and returned in a new document fragment; scripts in the markup are marked "already started" so that they never run.

요소를 컨텍스트로 마크업을 파싱한다("HTML fragment parsing algorithm", innerHTML 의 알고리즘). 노드는 컨텍스트 요소의 소유 문서에서 만들어 새 문서 조각에 담아 반환한다. 마크업 안의 스크립트는 "already started" 로 표시되어 절대 실행되지 않는다.

Parameters:
context - the context element (for innerHTML the element itself) / 컨텍스트 요소(innerHTML 이면 요소 자신)
markup - markup text / 마크업 텍스트
