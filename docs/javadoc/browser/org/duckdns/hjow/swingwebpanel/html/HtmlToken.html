org.duckdns.hjow.swingwebpanel.html
Class HtmlToken

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.HtmlToken

public final class HtmlToken
extends java.lang.Object

One token produced by the HtmlTokenizer: a DOCTYPE, a start tag, an end tag, a comment, a run of characters or the end of the file. Character tokens are runs (not single characters) to keep the number of objects small; the tree builder splits them where its rules need single characters. A token is not modified after the tokenizer has handed it out, so the tree builder may keep references to it (the list of active formatting elements does).

HtmlTokenizer 가 만드는 토큰 하나: DOCTYPE, 시작 태그, 종료 태그, 주석, 문자 연속 또는 파일 끝. 문자 토큰은 객체 수를 줄이려고 한 글자가 아닌 연속 구간이며, 트리 생성기가 규칙상 한 글자씩 필요할 때 나눈다. 토큰은 토큰화기가 내준 뒤에는 바뀌지 않으므로 트리 생성기가 참조를 보관해도 된다 (활성 서식 요소 목록이 그렇게 한다).
