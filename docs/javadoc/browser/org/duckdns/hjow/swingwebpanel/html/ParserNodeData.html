org.duckdns.hjow.swingwebpanel.html
Class ParserNodeData

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.ParserNodeData

public final class ParserNodeData
extends java.lang.Object

Parser metadata: template contents owned by each element, weak form owners and script flags ("parser document", "already started", "force async"). The side tables contain no strong reference back to an element or its document.

Access template contents only on the document thread, like other DOM operations. The stored data only has a meaning for elements created by the parser or by HtmlMarkupSupport.

HTML 파서의 부가 정보: 각 요소가 직접 소유하는 template 내용, 약한 폼 소유자와 스크립트 플래그. 보조 표에는 요소나 문서로 돌아가는 강한 참조가 없다.

template 내용은 다른 DOM 연산처럼 문서 스레드에서만 접근한다. 저장된 데이터는 파서나 HtmlMarkupSupport 가 만든 요소에서만 의미가 있다.
