Class InputPreprocessor

java.lang.Object
  org.duckdns.hjow.swingwebpanel.html.InputPreprocessor

public final class InputPreprocessor
extends java.lang.Object

The preprocessing that the HTML Standard applies to the input stream before tokenization ("preprocessing the input stream"): every CR LF pair and every lone CR becomes a single LF. This is kept apart from decoding on purpose: DecodedText.getText() keeps the received text (it is what getContent() returns) while the parser works on the normalized copy.

It can also scan the text for the input stream parse errors of the standard (control characters, noncharacters, lone surrogates).

토큰화 전에 HTML 표준이 입력 스트림에 적용하는 전처리("preprocessing the input stream"): 모든 CR LF 쌍과 홀로 있는 CR 은 LF 하나가 된다. 이것은 의도적으로 디코딩과 분리했다. DecodedText.getText() 는 받은 텍스트(getContent() 가 반환하는 값)를 그대로 두고 파서는 정규화된 복사본으로 일한다.

표준의 입력 스트림 파싱 오류(제어 문자, 비문자, 짝 없는 서로게이트)를 텍스트에서 찾아 보고할 수도 있다.
