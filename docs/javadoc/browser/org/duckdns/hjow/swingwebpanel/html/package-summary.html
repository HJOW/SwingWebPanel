Package org.duckdns.hjow.swingwebpanel.html

HTML parsing: encoding detection, tokenizer state machine, tree builder, named character references and document modes.

See:
          Description

Interface Summary
ParserControl The part of a running HtmlParser that a ParserListener may use while it handles a callback: inserting markup at the insertion point (document.write) and pausing the parser (a pending parsing-blocking script).
ParserListener Observer of a running HtmlParser: it learns about diagnostics, the document mode, the resources that the document refers to (scripts, style sheets, images, base URL, refresh) and elements that have just been created or closed.
 

Class Summary
DecodedText The result of decoding a document: the text, the encoding that was used, how sure the decision is and the original bytes.
DocumentModes Determination of the document mode (no-quirks, limited-quirks, quirks) from a DOCTYPE token, as the "initial" insertion mode of the HTML Standard prescribes: the force-quirks flag, a name other than html, a list of public identifiers (the old HTML 2.0, 3.2 and 4.0 era DTDs and some vendor DTDs) and the rules for the HTML 4.01 and XHTML 1.0 transitional and frameset DTDs, which depend on the presence of a system identifier.
EncodingLabels Label and name handling of the Encoding Standard: it maps the labels that appear in HTTP headers and meta elements (utf8, euc-kr, ks_c_5601-1987, ...) to the canonical encoding names (UTF-8, EUC-KR, ...) using the generated table EncodingLabelData, and maps each canonical name to a charset that the running JRE can decode with.
EncodingSniffer The encoding sniffing algorithm of the HTML Standard ("determining the character encoding") for documents that arrive as bytes.
HtmlMarkupSupport The HTML implementation of the DOM's MarkupSupport service: it gives innerHTML, outerHTML, insertAdjacentHTML their meaning.
HtmlParser The HTML parser: it connects the encoding detection (EncodingSniffer), the input preprocessing (InputPreprocessor), the HtmlTokenizer and the HtmlTreeBuilder and builds a DOM tree of org.duckdns.hjow.swingwebpanel.dom from markup.
HtmlTags Numeric ids of the element names that the tree builder treats specially, plus the name categories of the HTML Standard (special, formatting, scope boundaries).
HtmlToken One token produced by the HtmlTokenizer: a DOCTYPE, a start tag, an end tag, a comment, a run of characters or the end of the file.
HtmlTokenizer The tokenizer of the HTML Standard ("tokenization", 13.2.5) as an explicit state machine with all of its 80 states: data, RCDATA, RAWTEXT, script data (with its escaped and double escaped variants), PLAINTEXT, tags and attributes, comments, DOCTYPE, CDATA sections and the character reference states.
InputPreprocessor The preprocessing that the HTML Standard applies to the input stream before tokenization ("preprocessing the input stream"): every CR LF pair and every lone CR becomes a single LF.
NamedCharacterReferences The table of named character references (&amp;, &eacute;, &NotEqualTilde;, ...) of the HTML Standard with its 2231 entries.
ParseError One parse error (a diagnostic) reported while decoding, tokenizing or tree building.
ParseErrorLog Collector of ParseErrors shared by the tokenizer and the tree builder of one parse.
ParserListenerAdapter Empty implementation of ParserListener to subclass when only some callbacks are of interest.
ParserNodeData Parser metadata: template contents owned by each element, weak form owners and script flags ("parser document", "already started", "force async").
ParserNodeData.ScriptFlags Script flags of one script element.
