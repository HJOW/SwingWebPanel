Class Summary
VttCue A WebVTT cue (WebVTT 3.2/3.3 and the VTTCue interface of 9.1, with the text track cue of HTML 4.8.11.11.1): the identifier, the times, the pause-on-exit flag, the cue settings and the raw cue text.
VttCueText The WebVTT cue text parser (WebVTT 6.4 "WebVTT cue text parsing rules" with its tokenizer, and 6.6 "rules for extracting the chapter title"): the cue text becomes a tree of VttNode objects.
VttFile The result of parsing a WebVTT file (WebVTT 6.1): the cues in file order, the regions, the style sheet blocks, and whether the file had the WebVTT file signature (a file without it is not a WebVTT file and was not processed).
VttNode A WebVTT node object (WebVTT 6.4): a node of the tree that the cue text parser builds.
VttParser The WebVTT file parser (WebVTT 6.1 "WebVTT file parsing", 6.2 region settings, 6.3 cue timings and settings), after the W3C Candidate Recommendation of 2026-05-20.
VttRegion A WebVTT region (WebVTT 3.4 and the VTTRegion interface of 9.2): the data of a REGION block of a file or of a VTTRegion that a script created.
 

Package org.duckdns.hjow.swingwebpanel.media.vtt Description

The WebVTT file format (plan item P20-13, WebVTT: The Web Video Text Tracks Format, W3C Candidate Recommendation 2026-05-20): the file parser with its cue and region data, the cue timings and settings parser, the cue text parser and the character references of cue text. Nothing here depends on the DOM or on the script engine, so the classes can be tested alone.

WebVTT 파일 형식(계획 P20-13, WebVTT: The Web Video Text Tracks Format, W3C 후보 권고안 2026-05-20): 파일 파서와 그 cue/region 데이터, cue 타이밍과 설정 파서, cue 텍스트 파서, cue 텍스트의 문자 참조. 여기의 어떤 클래스도 DOM 이나 스크립트 엔진에 의존하지 않으므로 클래스만으로 시험할 수 있다.
