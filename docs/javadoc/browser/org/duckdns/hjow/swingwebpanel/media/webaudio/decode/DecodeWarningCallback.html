org.duckdns.hjow.swingwebpanel.media.webaudio.decode
Interface DecodeWarningCallback

All Superinterfaces:
DecodeCallback
public interface DecodeWarningCallback
extends DecodeCallback

A DecodeCallback that also wants to know when the data was decoded only in part: the specification (Web Audio API 1.1 draft) encourages an implementation to warn the author when the compressed data is corrupted but the decoding can otherwise proceed, for example in the developer tools. The service calls onWarning(String) before DecodeCallback.onSuccess(org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBuffer) of the same result, on the same thread, only for a result that is truncated (see DecodeResult.isTruncated()); a callback that does not implement this interface simply does not hear of it, and DecodeCallback.onSuccess(org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBuffer) is unchanged.

데이터가 일부만 디코딩되었을 때 그것도 알고 싶은 DecodeCallback: 규격(Web Audio API 1.1 초안)은 압축된 데이터가 손상되었지만 디코딩을 계속할 수 있을 때 구현이 작성자에게(예: 개발자 도구에) 경고하도록 권장한다. 서비스는 잘린 결과에 대해서만 같은 결과의 DecodeCallback.onSuccess(org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBuffer) 앞에서 같은 스레드에서 onWarning(String) 을 부른다. 이 인터페이스를 구현하지 않은 콜백은 그것을 듣지 못할 뿐이며 DecodeCallback.onSuccess(org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBuffer) 는 바뀌지 않는다.
