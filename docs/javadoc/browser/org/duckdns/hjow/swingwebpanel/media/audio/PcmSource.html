org.duckdns.hjow.swingwebpanel.media.audio
Interface PcmSource

All Known Implementing Classes:
AdpcmSource, BlockPcmSource, RawPcmSource
public interface PcmSource

A stream of decoded audio: 16-bit signed little-endian interleaved PCM that is produced on demand, so a long recording is never decoded into memory as a whole (plan item P18-08). The playback code reads blocks and writes them to a Java Sound line. Not thread-safe: one thread reads and seeks at a time.

디코딩된 오디오의 스트림: 16비트 부호 있는 리틀 엔디언 인터리브 PCM 을 요청할 때 만들어 내므로 긴 녹음을 통째로 메모리에 디코딩하지 않는다 (계획 P18-08). 재생 코드는 블록을 읽어 Java Sound 라인에 쓴다. 스레드 안전하지 않으며 한 번에 한 스레드만 읽고 탐색한다.
