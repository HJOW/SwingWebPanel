org.duckdns.hjow.swingwebpanel.media.vtt
Class VttCue

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.vtt.VttCue

public final class VttCue
extends java.lang.Object

A WebVTT cue (WebVTT 3.2/3.3 and the VTTCue interface of 9.1, with the text track cue of HTML 4.8.11.11.1): the identifier, the times, the pause-on-exit flag, the cue settings and the raw cue text. The fields are public because the class is a plain record that the file parser fills and the script interface checks; the defaults are those of the file parser and of the constructor of VTTCue. The values that can be auto (line, position) are AUTO (not-a-number, which a real value never is) in that case.

WebVTT cue(WebVTT 3.2/3.3 과 9.1 의 VTTCue 인터페이스, HTML 4.8.11.11.1 의 텍스트 트랙 cue 포함): 식별자, 시각, pause-on-exit 표시, cue 설정, 원문 cue 텍스트. 클래스는 파일 파서가 채우고 스크립트 인터페이스가 검사하는 단순한 기록이므로 필드는 public 이다. 기본값은 파일 파서와 VTTCue 생성자의 값이다. auto 가 될 수 있는 값(line, position)은 그때 AUTO(실제 값이 될 수 없는 NaN)이다.
