Class PeriodicWave

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.PeriodicWave

public final class PeriodicWave
extends java.lang.Object

An arbitrary periodic waveform of an OscillatorNode (Web Audio API 1.28): the Fourier coefficients x(t) = sum (a[k] cos 2 pi k t + b[k] sin 2 pi k t) turned into band-limited wave tables. The oscillator plays a table by reading it at a phase that advances by the frequency; a table that contains partials above the Nyquist frequency would alias, so the wave keeps several tables (three per octave) and each one has fewer partials than the one before it. A frequency selects the two neighbouring tables and the sample is the interpolation of both. Unless the normalization is disabled the whole waveform is scaled so that the maximum of the table with all partials is 1 (section 1.28.5). The table size depends on the sample rate (2048 up to 24 kHz, 4096 up to 88.2 kHz, 16384 above), as in the reference implementation. The object is immutable and is shared by the oscillators of one context.

OscillatorNode 의 임의 주기 파형(Web Audio API 1.28): 푸리에 계수 x(t) = sum (a[k] cos 2 pi k t + b[k] sin 2 pi k t) 를 대역 제한된 파형 표로 바꾼 것. 발진기는 주파수만큼 나아가는 위상으로 표를 읽어 재생한다. 나이퀴스트 주파수 위의 부분음이 든 표는 에일리어싱이 생기므로 파형은 표를 여러 개(옥타브당 세 개) 가지며 각 표는 앞의 표보다 부분음이 적다. 주파수가 이웃한 두 표를 고르고 표본은 둘의 보간이다. 정규화를 끄지 않는 한 파형 전체는 모든 부분음이 든 표의 최댓값이 1 이 되도록 크기가 조정된다(1.28.5절). 표 크기는 참조 구현처럼 샘플링 주파수에 따라 정해진다(24 kHz 까지 2048, 88.2 kHz 까지 4096, 그 위는 16384). 객체는 불변이며 한 컨텍스트의 발진기들이 공유한다.
