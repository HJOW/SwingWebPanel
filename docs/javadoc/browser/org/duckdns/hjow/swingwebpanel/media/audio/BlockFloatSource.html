Class BlockFloatSource

FloatPcmSource
public abstract class BlockFloatSource
extends java.lang.Object
implements FloatPcmSource

Base class of FloatPcmSource implementations that decode in blocks, the counterpart of BlockPcmSource: a subclass only has to produce the next block of decoded samples (fill(float[][])). This class keeps the block buffer, the end of the stream and the error state. When a block fails to decode, the frames decoded before it are still delivered: the failure is reported by the read that follows and every later read. The source does not seek (the wide path is read from the start to the end).

블록 단위로 디코딩하는 FloatPcmSource 구현의 기반 클래스. BlockPcmSource 의 짝이다: 하위 클래스는 다음 샘플 블록을 만들어 내는 일 (fill(float[][]))만 하면 된다. 이 클래스는 블록 버퍼, 스트림 끝, 오류 상태를 관리한다. 블록 디코딩이 실패해도 그 앞까지 디코딩한 프레임은 전달하며 실패는 바로 다음 읽기와 이후의 모든 읽기에서 보고한다. 이 소스는 탐색하지 않는다(넓은 경로는 처음부터 끝까지 읽는다).
