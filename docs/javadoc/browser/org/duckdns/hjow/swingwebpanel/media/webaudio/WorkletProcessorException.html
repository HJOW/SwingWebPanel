public final class WorkletProcessorException
extends java.lang.RuntimeException

The failure of an audio worklet processor (Web Audio API 1.32): the constructor or the process() method of the processor threw, or a limit stopped it. It carries what the processorerror event reports (the ErrorEvent attributes message, filename, lineno and colno) as plain text and numbers, so that the script layer can build the event on the control thread without touching the realm of the processor, which belongs to the rendering side.

오디오 worklet 프로세서의 실패(Web Audio API 1.32): 프로세서의 생성자나 process() 메서드가 예외를 던졌거나 한도가 중단시켰다. processorerror 이벤트가 보고하는 것(ErrorEvent 의 message, filename, lineno, colno)을 문자열과 숫자로 담고 있으므로, 스크립트 계층은 렌더링 쪽이 소유한 프로세서의 realm 을 건드리지 않고 제어 스레드에서 이벤트를 만들 수 있다.
