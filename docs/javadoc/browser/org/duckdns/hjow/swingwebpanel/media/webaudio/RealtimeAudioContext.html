Class RealtimeAudioContext

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.BaseAudioContext
      org.duckdns.hjow.swingwebpanel.media.webaudio.RealtimeAudioContext

public final class RealtimeAudioContext
extends BaseAudioContext

A context whose time advances with the wall clock and whose graph is rendered by a RealtimeAudioContext.Driver (Web Audio API 1.2, AudioContext): the real-time counterpart of OfflineAudioContext. The context itself does not own a thread. It owns the state (suspended, running, closed) and a driver that calls the rendering of one render quantum again and again while the context runs. The driver of this stage is the ClockRenderDriver, which renders at the pace of the wall clock and discards the output (the time advances and the graph works, but nothing is heard); a driver that writes the output to a sound device replaces it without any change of the script layer. The control methods may be called from any thread; the rendering thread is the thread of the driver.

Latency: resolveLatency(java.lang.String, double) turns the latencyHint of the script layer into a number of seconds; the context rounds it up to a whole number of render quanta and reports it as baseLatency. The driver reports the latency of its output device through reportOutputLatency(double).

시간이 벽시계와 함께 흐르고 그래프를 RealtimeAudioContext.Driver 가 렌더링하는 컨텍스트(Web Audio API 1.2, AudioContext): OfflineAudioContext 의 실시간 짝이다. 컨텍스트 자신은 스레드를 갖지 않는다. 상태(suspended, running, closed)와, 컨텍스트가 도는 동안 render quantum 하나의 렌더링을 되풀이해서 부르는 드라이버를 가진다. 이 단계의 드라이버는 ClockRenderDriver 이며 벽시계의 속도로 렌더링하고 출력은 버린다(시간이 흐르고 그래프가 동작하지만 소리는 나지 않는다). 소리 장치로 출력을 쓰는 드라이버는 스크립트 계층을 바꾸지 않고 이것을 대신한다. 제어 메서드는 어느 스레드에서나 부를 수 있고 렌더링 스레드는 드라이버의 스레드이다.

지연: resolveLatency(java.lang.String, double) 가 스크립트 계층의 latencyHint 를 초 단위 수로 바꾸고, 컨텍스트는 이를 render quantum 의 정수 배로 올림해 baseLatency 로 알린다. 드라이버는 출력 장치의 지연을 reportOutputLatency(double) 로 알린다.
