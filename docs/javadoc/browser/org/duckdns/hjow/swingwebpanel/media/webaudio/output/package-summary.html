Package org.duckdns.hjow.swingwebpanel.media.webaudio.output

The sound output of a real-time Web Audio context (plan item P25-07): the AudioOutput that the rendering thread writes float audio to, the OutputFactory that opens it, and two implementations: JavaSoundOutput (a Java Sound line, public API javax.sound.sampled only) and NullOutput (no device: the sound is discarded but the writes are paced to wall-clock time, so the context clock runs at real speed).

Interface Summary
AudioOutput One open sound output of a real-time Web Audio context (plan item P25-07): a queue of float audio of a fixed sample rate and channel count that a device (or a stand-in for it) plays at real speed.
JavaSoundOutput.Lines The access to the lines of the sound system; a test replaces it with a fake device, and JavaSoundOutput.system() gives the real one.

Class Summary
JavaSoundOutput The output on a Java Sound SourceDataLine of the default mixer (public API javax.sound.sampled only), playing 16-bit signed little-endian PCM.
NullOutput The output for a machine without a sound device (plan item P25-07): it discards the audio, but it behaves like a device of a fixed buffer that plays at real speed.
SystemOutputFactory The default OutputFactory: it opens a JavaSoundOutput on the default mixer of Java Sound.
 

Package org.duckdns.hjow.swingwebpanel.media.webaudio.output Description

The sound output of a real-time Web Audio context (plan item P25-07): the AudioOutput that the rendering thread writes float audio to, the OutputFactory that opens it, and two implementations: JavaSoundOutput (a Java Sound line, public API javax.sound.sampled only) and NullOutput (no device: the sound is discarded but the writes are paced to wall-clock time, so the context clock runs at real speed). The package is pure Java and knows nothing about the graph; the OutputRenderDriver in the parent package owns the rendering thread.

실시간 Web Audio 컨텍스트의 소리 출력(계획 P25-07): 렌더링 스레드가 float 오디오를 쓰는 AudioOutput, 그것을 여는 OutputFactory, 그리고 구현 둘: JavaSoundOutput(Java Sound 라인, 공개 API javax.sound.sampled 만 사용)과 NullOutput(장치 없음: 소리는 버리지만 쓰기를 벽시계 속도로 늦추므로 컨텍스트 시계가 실제 속도로 진행한다). 이 패키지는 순수 Java 이며 그래프를 모른다. 렌더링 스레드는 상위 패키지의 OutputRenderDriver 가 가진다.
