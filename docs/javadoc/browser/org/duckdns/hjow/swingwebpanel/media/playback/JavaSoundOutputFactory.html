implements AudioOutputFactory

The standard output: a SourceDataLine of the default mixer of Java Sound (public API javax.sound.sampled only). The line buffer holds about 150 ms, so a pause or a seek reacts at once (the queue is stopped or flushed) and a change of the volume is heard within that time. When the machine has no audio device, or the device cannot play the format, open(int, int) fails with MediaException.Kind#ACCESS_FAILED.

표준 출력: Java Sound 의 기본 믹서의 SourceDataLine(공개 API javax.sound.sampled 만 사용). 라인 버퍼는 약 150 ms 를 담으므로 일시정지와 탐색은 곧바로 반응하고(큐를 멈추거나 비움) 음량 변경은 그 시간 안에 들린다. 컴퓨터에 오디오 장치가 없거나 장치가 그 형식을 재생할 수 없으면 open(int, int) 는 MediaException.Kind#ACCESS_FAILED 로 실패한다.
