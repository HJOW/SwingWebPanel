org.duckdns.hjow.swingwebpanel.media.webaudio.decode
Class DecodeResult

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.decode.DecodeResult

public final class DecodeResult
extends java.lang.Object

The result of a decoding that succeeded: the AudioBuffer and, if the data was damaged or cut off, the warning that the script layer shows to the author (the Web Audio API 1.1 draft encourages implementations to warn authors in case of a corrupted file whose decoding can otherwise proceed; a browser shows it in its developer tools, this component has no log, so the caller learns it here). The buffer holds everything that could be decoded; whether it is complete is told by isTruncated(). A result is immutable.

성공한 디코딩의 결과: AudioBuffer 와, 데이터가 손상되었거나 잘렸으면 스크립트 계층이 작성자에게 보여 줄 경고(Web Audio API 1.1 초안은 손상되었지만 디코딩을 계속할 수 있는 파일에 대해 구현이 작성자에게 경고하도록 권장한다. 브라우저는 개발자 도구에 보여 주며, 이 컴포넌트에는 로그가 없으므로 호출한 쪽이 여기서 알게 된다). 버퍼는 디코딩할 수 있었던 모든 것을 담는다. 완전한지는 isTruncated() 가 알려 준다. 결과는 불변이다.
