org.duckdns.hjow.swingwebpanel.media.webaudio
Class PannerNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioNode
      org.duckdns.hjow.swingwebpanel.media.webaudio.PannerNode

public final class PannerNode
extends AudioNode

Positions an incoming audio stream in three-dimensional space in relation to the AudioListener of the context (Web Audio API 1.27). The input has one or two channels; the output is always stereo (one silent channel while the node is not processing).

The geometry (azimuth, elevation, distance, cone) is Spatial. With the equalpower model the azimuth is panned between the two channels with equal power (the elevation is ignored): a mono input is panned across the image, a stereo input is balanced as in the StereoPannerNode; the position and orientation parameters of the panner and of the listener are a-rate if any of them is automated at that rate. With the HRTF model all parameters are read once per render quantum and the source (a stereo input is first down-mixed to mono) is convolved with the measured head-related impulse responses of the direction (see HrtfDatabase for the data and its credit); if the HRTF data cannot be loaded the node falls back to the equalpower processing. The gain of the distance model and of the sound cone multiplies the result in both models.

입력 오디오 스트림을 컨텍스트의 AudioListener 에 대한 3차원 공간에 배치한다(Web Audio API 1.27). 입력은 채널이 하나나 둘이고 출력은 항상 스테레오이다(노드가 처리 중이 아니면 무음 채널 하나).

기하(방위각, 고도, 거리, 원뿔)는 Spatial 이다. equalpower 모델은 방위각을 두 채널 사이에 등전력으로 나눈다(고도는 무시한다). 모노 입력은 이미지 전체에 패닝되고 스테레오 입력은 StereoPannerNode 처럼 균형이 맞춰진다. 패너와 청취자의 위치·방향 파라미터는 그중 하나라도 그 속도로 자동화되면 a-rate 이다. HRTF 모델은 모든 파라미터를 render quantum 마다 한 번 읽고, 음원(스테레오 입력은 먼저 모노로 다운믹스한다)을 방향의 측정한 머리 임펄스 응답과 합성곱한다(자료와 출처 표기는 HrtfDatabase 참고). HRTF 자료를 읽을 수 없으면 노드는 equalpower 처리로 대신한다. 거리 모델과 음향 원뿔의 게인은 두 모델 모두에서 결과에 곱해진다.
