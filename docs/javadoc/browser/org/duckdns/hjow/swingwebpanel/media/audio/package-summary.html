Package org.duckdns.hjow.swingwebpanel.media.audio

Interface Summary
AudioDecoder A decoder for one audio container/codec family (plan items P18-02, P18-07).
ByteSource Random-access bytes of an encoded audio resource (plan item P18-08): the length is known and any position can be read, so a decoder can read the headers, an index and then frame after frame without the whole resource in memory.
FloatPcmSource A stream of decoded audio with the channels and the precision of the file: 32 bit floating point samples in the range -1 to 1 (a sample of an N bit integer file is exactly sample / 2^(N-1), a lossy codec delivers its own float output without the rounding to 16 bits and without the clipping), one array per channel, produced on demand so that a long recording is never decoded into memory as a whole (plan item P25-05, the wide path of the decoders).
PcmSource A stream of decoded audio: 16-bit signed little-endian interleaved PCM that is produced on demand, so a long recording is never decoded into memory as a whole (plan item P18-08).
WideAudioDecoder An AudioDecoder that can also deliver the channels and the precision of the file (plan item P25-05): in addition to AudioDecoder.open(byte[], DecodeLimits), which gives 16 bit PCM of at most two channels for playing, WideAudioDecoder.openWide(byte[], DecodeLimits) gives a FloatPcmSource.
 

Class Summary
ArrayByteSource A ByteSource over a byte array that is already in memory (a short resource, a test, the derived Ogg stream of a small WebM file).
AudioDecoders The registry of audio decoders and the single entry point of the audio pipeline (plan items P18-01, P18-02, P18-07): it chooses the decoder from the signature of the data and uses the MIME type of the response only as a hint (a decoder that names the hinted MIME type is asked first), so the same extension or MIME type with a different real codec is decoded correctly and a wrong MIME type does not make a valid file fail.
BlockFloatSource Base class of FloatPcmSource implementations that decode in blocks, the counterpart of BlockPcmSource: a subclass only has to produce the next block of decoded samples (BlockFloatSource.fill(float[][])).
BlockPcmSource Base class of PcmSource implementations that decode in blocks: a subclass only has to produce the next block of decoded PCM (BlockPcmSource.fill(byte[])) and, if it can, jump to a position (BlockPcmSource.seekTo(long)).
ByteAudioDecoder A decoder for an array or a seekable byte source.
Bytes Helpers to read integers of a given byte order from a byte array, with overflow-safe range checks.
ChannelMixer Mixes the channels of a multi-channel layout down to stereo (plan item P18-07).
FileByteSource A ByteSource over a complete file (the temporary file into which a long media resource was spooled, plan item P18-08).
MediaData The encoded bytes of one fetched media resource (plan item P18-08), either in memory (a short resource) or in a temporary file that this object owns (a long one, see MediaSpool).
MediaSpool The receiver of the body of a media response while it streams in (plan item P18-08): the first MediaSpool.MEMORY_LIMIT bytes stay in memory; when the body grows beyond that, everything moves to a temporary file (File.createTempFile in the default temporary directory) and the rest is appended there, so a long recording never sits in the heap.
PcmConverter Sample conversions shared by the decoders: clipping a full-scale float to 16 bits, narrowing integer samples of any width to 16 bits with rounding, and the ITU-T G.711 mu-law and A-law expansion tables.
PcmFloatAdapter Presents a 16 bit PcmSource as a FloatPcmSource: every sample becomes sample / 32768, which is exact.
 

Exception Summary
ByteSourceException An input error of a ByteSource: the temporary file of a media resource could not be read (it was closed because the page or the element went away, or it was removed from outside).
