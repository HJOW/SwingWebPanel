org.duckdns.hjow.swingwebpanel.media.playback
Class MediaRanges

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.playback.MediaRanges

public final class MediaRanges
extends java.lang.Object

A normalized list of time ranges in seconds (the data of a TimeRanges object): the ranges are ordered, not empty and neither overlapping nor touching (plan item P18-08). Immutable; add(double, double) returns a new list.

초 단위 시간 범위의 정규화된 목록(TimeRanges 객체의 데이터): 범위는 순서대로이고 비어 있지 않으며 겹치거나 맞닿지 않는다(계획 P18-08). 불변이며 add(double, double) 는 새 목록을 반환한다.
