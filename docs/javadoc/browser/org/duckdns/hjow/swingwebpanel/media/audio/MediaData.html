org.duckdns.hjow.swingwebpanel.media.audio
Class MediaData

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.MediaData

public final class MediaData
extends java.lang.Object

The encoded bytes of one fetched media resource (plan item P18-08), either in memory (a short resource) or in a temporary file that this object owns (a long one, see MediaSpool). Readers get a ByteSource from open(); nothing reads the whole file into memory. release() closes every source that is still open and deletes the temporary file; it is idempotent and safe from any thread. The fetch worker gives the finished resource to a page task, which transfers it to the player. Cancelled requests, discarded tasks and closed players release the resources they own. A derived stream such as WebM audio remuxed to Ogg can tie its lifetime to a single reader using openOwned(). No JVM-wide state is used (no deleteOnExit): a file that a crashed process left behind stays for the temporary-file cleaning of the operating system, like the localStorage files.

가져온 미디어 리소스 하나의 인코딩된 바이트(계획 P18-08). 메모리(짧은 리소스)나 이 객체가 소유한 임시 파일(긴 리소스, MediaSpool 참고)에 있다. 읽는 쪽은 open() 으로 ByteSource 를 받으며 파일 전체를 메모리로 읽는 곳은 없다. release() 는 아직 열린 원천을 모두 닫고 임시 파일을 지운다. 여러 번 불러도 되고 어느 스레드에서나 안전하다. 스풀을 완성한 요청 작업자가 페이지 작업에 넘기고 페이지 작업은 재생기에 넘긴다. 요청의 취소, 페이지 작업의 폐기, 재생기의 닫힘 때 해당 소유자가 리소스를 해제한다. WebM을 Ogg로 재포장한 파생 리소스는 openOwned()로 단일 판독기와 수명을 맞출 수 있다. JVM 전역 상태 (deleteOnExit)는 쓰지 않는다. 비정상 종료한 프로세스가 남긴 파일은 localStorage 파일처럼 운영체제의 임시 파일 정리에 맡긴다.
