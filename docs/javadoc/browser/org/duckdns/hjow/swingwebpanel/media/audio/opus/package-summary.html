Package org.duckdns.hjow.swingwebpanel.media.audio.opus

Class Summary
OpusDecoder Decoder of Ogg Opus (plan item P18-07, FEATURE_MATRIX AUD-08), a pure Java implementation of RFC 6716 (the SILK, CELT and hybrid modes with all frame sizes from 2.5 to 60 ms, the four frame packing codes, mono and stereo, redundancy frames, packet loss concealment) and of the Ogg encapsulation of RFC 7845 (header packets, pre-skip, output gain, channel mapping families 0 and 1 with up to eight channels, chained streams, trimming of the last page).
OpusInOgg Wraps the Opus track of a WebM/Matroska file into an Ogg Opus stream so that the Ogg Opus decoder can play it: the CodecPrivate of the track is the identification header (OpusHead, RFC 7845 section 5.1; it is rebuilt from the track channels and the CodecDelay if it is missing or damaged), every block is one audio packet, and the granule positions of the pages count the decoded samples, with the DiscardPadding of the last block trimmed from the end.
