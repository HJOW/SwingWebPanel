org.duckdns.hjow.swingwebpanel.media
Class DecodeLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.DecodeLimits

public final class DecodeLimits
extends java.lang.Object

Limits that every decoder must respect so that damaged or hostile data cannot exhaust memory or time (plan items P18-10, P22-09). A decoder checks the limits before it allocates buffers from sizes found in the data, and reports MediaException.Kind.TOO_LARGE when one is exceeded.

손상되었거나 악의적인 데이터가 메모리나 시간을 고갈시키지 못하도록 모든 디코더가 지켜야 하는 제한(계획 P18-10, P22-09). 디코더는 데이터에서 읽은 크기로 버퍼를 할당하기 전에 제한을 확인하며 초과하면 MediaException.Kind.TOO_LARGE 를 보고한다.
