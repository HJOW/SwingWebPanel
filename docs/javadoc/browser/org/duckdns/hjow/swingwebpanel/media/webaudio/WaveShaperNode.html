Class WaveShaperNode

public final class WaveShaperNode
extends AudioNode

A non-linear distortion effect (Web Audio API 1.31). Every input sample in [-1, 1] indexes the curve with linear interpolation (values below -1 give the first curve value, values above 1 the last one); without a curve the input passes unchanged. The optional oversampling (2x, 4x) applies the curve to an up-sampled signal and filters it back (see WaveShaperKernel), which avoids some aliasing at the price of a delay of the filters and a tail time. The number of output channels equals the number of input channels (the node has channelCount 2, mode max and interpretation speakers by default).

A curve that maps zero to a non-zero value makes the node produce a constant signal even without any input; the context keeps such a node processed for as long as the curve is set.

비선형 왜곡 효과(Web Audio API 1.31). [-1, 1] 의 입력 샘플은 선형 보간으로 curve 를 색인한다(-1 보다 작으면 곡선의 첫 값, 1 보다 크면 마지막 값). 곡선이 없으면 입력이 그대로 지나간다. 선택 사항인 오버샘플링(2x, 4x)은 업샘플링한 신호에 곡선을 적용하고 다시 필터링해 내려보내므로(WaveShaperKernel 참고) 앨리어싱을 일부 막는 대신 필터의 지연과 꼬리 시간이 생긴다. 출력 채널 수는 입력 채널 수와 같다(노드의 기본값은 channelCount 2, 모드 max, 해석 speakers).

0 을 0 이 아닌 값으로 옮기는 곡선은 입력이 없어도 노드가 일정한 신호를 만들게 한다. 컨텍스트는 곡선이 설정된 동안 그런 노드를 계속 처리한다.
