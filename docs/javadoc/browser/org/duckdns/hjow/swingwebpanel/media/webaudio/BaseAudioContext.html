org.duckdns.hjow.swingwebpanel.media.webaudio
Class BaseAudioContext

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.BaseAudioContext
Direct Known Subclasses:
OfflineAudioContext, RealtimeAudioContext
public abstract class BaseAudioContext
extends java.lang.Object

A set of audio nodes and their connections, and the loop that renders them (Web Audio API 1.1 and 2): the base of the real-time and the offline context. A context has a sample rate, a destination node, the current time and the rendering order of its nodes. The class implements the processing model of section 2:

  • Control methods (those of the nodes and the parameters) may be called from any thread. They check their arguments at once and queue a control message; renderQuantum() applies the messages in the order of their insertion at the start of a render quantum.
  • renderQuantum() renders one render quantum (128 frames by default): it applies the messages, orders the nodes when the graph has changed (see RenderGraph), and renders every node in that order. It is called by one thread at a time, the rendering thread; the offline context calls it from the thread that asks for the rendering.
  • The context keeps a node alive (pinned) while it is started and has not ended, or while it is active or within its tail time, and processes the nodes that can be reached from the pinned nodes and from the destination. A node that is neither connected to a started source nor started itself is not processed, so the value of its parameters does not advance with time.

오디오 노드의 집합과 그 연결, 그리고 그것을 렌더링하는 루프(Web Audio API 1.1과 2절): 실시간 컨텍스트와 오프라인 컨텍스트의 기반. 컨텍스트는 샘플링 주파수, 목적지 노드, 현재 시간, 노드의 렌더링 순서를 가진다. 이 클래스는 2절의 처리 모델을 구현한다:

  • 제어 메서드(노드와 파라미터의 메서드)는 어느 스레드에서나 부를 수 있다. 인수를 즉시 검사하고 제어 메시지를 쌓으며, renderQuantum() 이 render quantum 시작에 메시지를 넣은 순서대로 적용한다.
  • renderQuantum() 은 render quantum 하나(기본 128 프레임)를 렌더링한다: 메시지를 적용하고, 그래프가 바뀌었으면 노드의 순서를 정하고 (RenderGraph 참고), 그 순서대로 모든 노드를 렌더링한다. 한 번에 한 스레드(렌더링 스레드)가 부르며 오프라인 컨텍스트는 렌더링을 요청한 스레드에서 부른다.
  • 컨텍스트는 노드가 시작되어 끝나지 않았거나 활성이거나 꼬리 시간 안에 있는 동안 노드를 붙잡아 두며(pinned), 붙잡은 노드와 목적지에서 도달할 수 있는 노드를 처리한다. 시작한 원천에도 연결되지 않고 스스로도 시작하지 않은 노드는 처리하지 않으므로 그 파라미터의 값은 시간에 따라 변하지 않는다.
