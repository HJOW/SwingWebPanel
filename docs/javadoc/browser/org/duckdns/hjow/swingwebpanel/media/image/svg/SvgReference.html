org.duckdns.hjow.swingwebpanel.media.image.svg
Class SvgReference

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.svg.SvgReference

public final class SvgReference
extends java.lang.Object

The SVG definitions that an HTML element refers to with filter: url(#id), clip-path: url(#id) or mask-image: url(#id) (CSS Filter Effects Level 1 section 5, https://www.w3.org/TR/filter-effects-1/#FilterProperty, and CSS Masking Level 1 sections 5 and 7, https://www.w3.org/TR/css-masking-1/): the svg element that contains the definitions, parsed once, and the operations that apply a filter, a clipPath or a mask element of it to the pixels of an HTML element. The same engine as for SVG images does the work (every filter primitive, nested clip paths and masks, use, units), so the result is the one that an SVG element with the same attribute would have. The HTML element plays the part of the filtered element: its border box is the bounding box (objectBoundingBox units) and its top left corner is the origin of the user space (userSpaceOnUse units); the lengths of percentages are relative to the box. Only definitions in the same document are used: nothing is loaded and no script runs. The methods change the helper element of the document and are therefore synchronized.

HTML 요소가 filter: url(#id), clip-path: url(#id), mask-image: url(#id) 로 가리키는 SVG 정의(CSS Filter Effects Level 1 5 절, https://www.w3.org/TR/filter-effects-1/#FilterProperty, CSS Masking Level 1 5, 7 절, https://www.w3.org/TR/css-masking-1/): 정의가 든 svg 요소를 한 번 해석해 두고, 그 안의 filter, clipPath, mask 요소를 HTML 요소의 픽셀에 적용하는 연산을 제공한다. SVG 이미지와 같은 엔진이 일하므로(모든 필터 기본 요소, 중첩된 클립 경로와 마스크, use, 단위) 같은 속성을 가진 SVG 요소와 같은 결과이다. HTML 요소가 필터가 걸리는 요소 역할을 한다: border box 가 경계 상자(objectBoundingBox 단위)이고 왼쪽 위 모서리가 사용자 공간의 원점(userSpaceOnUse 단위)이며 백분율 길이는 상자 기준이다. 같은 문서의 정의만 쓴다: 아무것도 가져오지 않고 스크립트도 실행하지 않는다. 메서드는 문서의 보조 요소를 바꾸므로 동기화되어 있다.

Applies a filter element to the pixels of an HTML element: the result replaces the pixels and everything outside of the filter region is removed. The pixels of a layer that is not wide enough for the filter region are cut off at the edge of the layer.

HTML 요소의 픽셀에 filter 요소를 적용한다: 결과가 픽셀을 대체하고 필터 영역 밖은 모두 지워진다. 필터 영역에 비해 좁은 레이어의 픽셀은 레이어 가장자리에서 잘린다.

Parameters:
id - the id of the filter element / 필터 요소의 id
layer - the pixels (ARGB, not premultiplied), changed in place / 픽셀(알파를 미리 곱하지 않은 ARGB). 제자리에서 바뀐다
ctm - the transform from the user space of the element (the origin is the top left corner of its border box) to the layer / 요소의 사용자 공간(원점은 border box 의 왼쪽 위 모서리)에서 레이어로의 변환
w - the width of the border box / border box 너비
h - the height of the border box / border box 높이
Returns:
true if the filter was applied, false if it could not be (a filter that is not available, or the drawing stopped because of the limits) / 필터를 적용했으면 true. 쓸 수 없는 필터이거나 제한 때문에 그리기가 멈추면 false
