Class VttRegion

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.vtt.VttRegion

public final class VttRegion
extends java.lang.Object

A WebVTT region (WebVTT 3.4 and the VTTRegion interface of 9.2): the data of a REGION block of a file or of a VTTRegion that a script created. The fields are public because the class is a plain record that the file parser fills and the script interface checks; the defaults are those of the constructor of VTTRegion.

WebVTT region(WebVTT 3.4 와 9.2 의 VTTRegion 인터페이스): 파일의 REGION 블록 또는 스크립트가 만든 VTTRegion 의 데이터. 클래스는 파일 파서가 채우고 스크립트 인터페이스가 검사하는 단순한 기록이므로 필드는 public 이다. 기본값은 VTTRegion 생성자의 값이다.
