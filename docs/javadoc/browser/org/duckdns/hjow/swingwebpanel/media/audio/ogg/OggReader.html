Class OggReader

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.ogg.OggReader

public final class OggReader
extends java.lang.Object

Index of an Ogg file (RFC 3533): every page is located (garbage between pages is skipped by searching for the next capture pattern) and assigned to its logical bitstream by serial number. The result lists the logical streams in the order in which they begin: several streams at the start are a multiplexed ("grouped") file, streams that follow an ended one are "chained" files. Codec decoders choose the stream they can play with findFirst(String) and read its packets with OggStream.openPackets(int). Only the page headers are read while indexing; checksums are verified when pages are read.

Ogg 파일(RFC 3533)의 색인: 모든 페이지의 위치를 찾고(페이지 사이의 쓰레기는 다음 캡처 패턴을 찾아 건너뛴다) 시리얼 번호로 논리 비트스트림에 배정한다. 결과는 논리 스트림을 시작한 순서대로 나열한다. 처음에 스트림이 여럿이면 다중화된("grouped") 파일이고, 끝난 스트림 뒤에 이어지는 스트림은 "chained" 파일이다. 코덱 디코더는 findFirst(String) 으로 재생할 수 있는 스트림을 고르고 OggStream.openPackets(int) 로 패킷을 읽는다. 색인하는 동안은 페이지 헤더만 읽으며 체크섬은 페이지를 읽을 때 확인한다.

findFirst

public OggStream findFirst(java.lang.String codec)
Returns the first logical stream of a codec, or null. A chained file continues after the first stream: only that first stream is returned, so a player plays the first link of a chain.

코덱의 첫 논리 스트림을 반환한다. 없으면 null. chained 파일은 첫 스트림 뒤에 이어지는데 그 첫 스트림만 반환하므로 재생기는 체인의 첫 고리를 재생한다.
