Class OggPacketStream

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.ogg.OggPacketStream

public final class OggPacketStream
extends java.lang.Object

Sequential reader of the packets of one logical Ogg bitstream. Packets are reassembled from the lacing segments of the pages; each page is checked against its CRC-32 when it is read. A page that fails the check, a gap in the page sequence and a continuation without its beginning (after a seek) lose the packet that is affected and the stream goes on with the next packet boundary, so one damaged page does not end the stream (the number of damaged pages is available from getDamagedPages()).

논리 Ogg 비트스트림 하나의 패킷을 순서대로 읽는 객체. 패킷은 페이지의 래이싱 세그먼트에서 다시 조립한다. 페이지는 읽을 때마다 CRC-32 를 확인한다. 확인에 실패한 페이지, 페이지 순서의 빈틈, (탐색 뒤) 시작이 없는 이어진 패킷은 해당 패킷을 잃고 다음 패킷 경계부터 계속하므로 손상된 페이지 하나가 스트림을 끝내지 않는다(손상된 페이지 수는 getDamagedPages() 로 알 수 있다).
