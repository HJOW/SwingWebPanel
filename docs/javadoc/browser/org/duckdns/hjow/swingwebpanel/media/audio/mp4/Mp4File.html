org.duckdns.hjow.swingwebpanel.media.audio.mp4
Class Mp4File

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.mp4.Mp4File

public final class Mp4File
extends java.lang.Object

A demultiplexer of the ISO base media file format (MP4, M4A, ISO/IEC 14496-12): it reads the box structure, the tracks with their sample tables (stts, stsc, stsz, stco/co64), the sample entries with the elementary stream descriptor of AAC (esds) and the Opus configuration (dOps), the edit list and fragmented files (moof, traf, tfhd, trun). All sizes are checked against the data before arrays are allocated.

ISO 기본 미디어 파일 형식(MP4, M4A, ISO/IEC 14496-12)의 역다중화기: 박스 구조, 샘플 표(stts, stsc, stsz, stco/co64)가 있는 트랙, AAC 의 기본 스트림 서술자(esds)와 Opus 구성(dOps)이 있는 샘플 엔트리, 편집 목록, 조각화된 파일(moof, traf, tfhd, trun)을 읽는다. 모든 크기는 배열을 할당하기 전에 데이터와 대조한다.
