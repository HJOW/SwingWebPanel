Class HrtfSet

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.HrtfSet

public final class HrtfSet
extends java.lang.Object

The HRTF data of HrtfDatabase prepared for one sample rate, and the interpolation between the measured directions: for any azimuth and elevation it produces the pair of impulse responses (the kernels of the left and the right ear) that a source in that direction needs. The object is immutable after construction and may be shared by any number of renderers and threads; the caller passes the work arrays.

Method (the specification of the PannerNode leaves the HRTF processing to the implementation):

  1. The measured responses are stored as minimum phase kernels with a separate delay per ear (see tools/hrtfgen), so that they can be averaged without the comb filtering that unaligned responses would cause: the weighted sum of the kernels and the weighted sum of the delays are taken separately.
  2. The data is converted to the sample rate of the context (kernels with the band-limited interpolation of HrirResampler, delays scaled by the ratio of the rates).
  3. A direction is interpolated bilinearly: the azimuth between the two nearest measured azimuths of each of the two nearest elevations, then between the two elevations. Negative azimuths (the left side) use the right side measurements with the ears swapped. Elevations below the lowest measured one (-40 degrees) use the lowest elevation.
  4. The delay of every ear is put into its kernel with an eight point Lagrange fractional delay, so that the result is one ready-to-use FIR kernel per ear of the fixed length getKernelLength().

HrtfDatabase 의 HRTF 자료를 한 샘플링 주파수에 맞게 준비한 것과 측정한 방향 사이의 보간: 임의의 방위각과 고도에 대해 그 방향의 음원이 필요로 하는 임펄스 응답 쌍(왼쪽과 오른쪽 귀의 커널)을 만든다. 객체는 만든 뒤에는 불변이라 여러 렌더러와 스레드가 공유할 수 있고 작업 배열은 호출자가 넘긴다.

방법(PannerNode 규격은 HRTF 처리를 구현에 맡긴다):

  1. 측정한 응답은 귀마다 지연을 따로 둔 최소 위상 커널로 저장된다(tools/hrtfgen 참고). 그래서 정렬되지 않은 응답을 평균할 때 생기는 빗살 필터링 없이 평균할 수 있다. 커널의 가중 합과 지연의 가중 합을 따로 구한다.
  2. 자료는 컨텍스트의 샘플링 주파수로 바꾼다(커널은 HrirResampler 의 대역 제한 보간, 지연은 속도 비로 환산).
  3. 방향은 쌍선형으로 보간한다. 가장 가까운 두 고도 각각에서 가장 가까운 두 측정 방위각 사이를, 그다음 두 고도 사이를 보간한다. 음의 방위각(왼쪽)은 귀를 바꾼 오른쪽 측정을 쓴다. 가장 낮은 측정 고도(-40도) 아래의 고도는 가장 낮은 고도를 쓴다.
  4. 귀마다의 지연은 8점 라그랑주 소수 지연으로 커널에 넣는다. 그래서 결과는 귀마다 고정 길이 getKernelLength() 의 바로 쓸 수 있는 FIR 커널 하나이다.

public static final int LEAD
The number of taps by which both kernels start later than the measured responses (a constant latency of both ears, which does not change the interaural time difference): it keeps the precursor of the fractional delay interpolation, which would be cut off if the kernel had to start at the tap 0.

두 커널이 측정한 응답보다 늦게 시작하는 탭 수(두 귀에 같은 고정 지연이므로 두 귀 사이의 시간차는 바뀌지 않는다). 소수 지연 보간의 선행 성분을 지킨다. 커널이 탭 0 에서 시작해야 한다면 그 성분이 잘려 나간다.
