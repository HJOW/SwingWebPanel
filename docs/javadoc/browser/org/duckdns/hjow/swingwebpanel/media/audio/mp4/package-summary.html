Package org.duckdns.hjow.swingwebpanel.media.audio.mp4

Class Summary
Mp4File A demultiplexer of the ISO base media file format (MP4, M4A, ISO/IEC 14496-12): it reads the box structure, the tracks with their sample tables (stts, stsc, stsz, stco/co64), the sample entries with the elementary stream descriptor of AAC (esds) and the Opus configuration (dOps), the edit list and fragmented files (moof, traf, tfhd, trun).
Mp4Track One track of an MP4 / ISO base media file: its sample entry (codec, channels, sampling frequency, codec configuration) and the sample table (position, size and duration of every sample), with the edit list start offset.
