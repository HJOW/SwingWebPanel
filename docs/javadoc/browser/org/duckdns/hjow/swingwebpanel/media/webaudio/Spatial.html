Class Spatial

public final class Spatial
extends java.lang.Object

The geometry of the spatialization (Web Audio API 6.2, 6.4 and 6.5): the azimuth and the elevation of a source as the listener perceives them, the distance, the distance gain of the three distance models, and the gain of the sound cone. The methods are pure functions in double precision; the coordinate system is right-handed (the default listener looks along -z with +y up, so +x is to its right).

공간화의 기하(Web Audio API 6.2, 6.4, 6.5): 청취자가 지각하는 음원의 방위각과 고도, 거리, 세 거리 모델의 거리 게인, 음향 원뿔의 게인. 메서드는 배정밀도의 순수 함수이다. 좌표계는 오른손 좌표계이다(기본 청취자는 +y 가 위인 채로 -z 방향을 보므로 +x 가 오른쪽이다).

Computes the azimuth and the elevation of a source for a listener with the algorithm of the specification. The azimuth is in degrees from -180 to 180 (0 in front, 90 to the right, -90 to the left, 180 behind), the elevation in degrees from -90 to 90. If the source is at the listener, or the forward and up vectors of the listener are parallel (the right side is undefined), both are 0.

규격의 알고리즘으로 청취자에 대한 음원의 방위각과 고도를 계산한다. 방위각은 -180 ~ 180도(0 정면, 90 오른쪽, -90 왼쪽, 180 뒤), 고도는 -90 ~ 90도이다. 음원이 청취자의 위치에 있거나 청취자의 forward 와 up 벡터가 나란하면(오른쪽을 정할 수 없다) 둘 다 0 이다.

Returns the gain of the sound cone of a source for a listener: 1 inside the inner cone, the outer gain outside the outer cone, and a linear change between them. 1 if the orientation vector is zero or both cone angles are 360 degrees. The angle is taken between the orientation vector and the vector from the source to the listener (a source that points at the listener is heard fully), as in Chromium; the pseudo code of the specification names that vector sourceToListener but builds it as the listener-to-source difference of the positions, which would make a source that points at the listener silent.

청취자에 대한 음원의 음향 원뿔 게인을 반환한다. 안쪽 원뿔 안에서는 1, 바깥 원뿔 밖에서는 바깥 게인이고 그 사이는 선형으로 바뀐다. 방향 벡터가 0 이거나 두 원뿔 각이 모두 360도이면 1 이다. 각은 방향 벡터와 음원에서 청취자로 향하는 벡터 사이에서 잰다(청취자를 향한 음원은 온전히 들린다. Chromium 과 같다). 규격의 의사 코드는 그 벡터를 sourceToListener 라고 부르지만 위치의 차이를 청취자에서 음원으로 만들어 청취자를 향한 음원이 무음이 되어 버린다.

Parameters:
ox - the x of the source orientation / 음원 방향 x

lz - the z of the listener position / 청취자 위치 z
