Class AudioNode

public abstract class AudioNode
extends java.lang.Object

The base of all audio nodes (Web Audio API 1.5). A node has a number of inputs and outputs, the channel attributes channelCount, channelCountMode and channelInterpretation that decide how the inputs are mixed, and zero or more AudioParams. The control methods (connect, disconnect, the channel attributes) may be called from any thread: they validate at once, keep the connections of the node in a list for the later validation, and queue a control message that the rendering thread applies at the next render quantum boundary. The rendering thread calls renderStep(long, int, long, int) once per quantum: the parameters are computed, the inputs are pulled and mixed, and the node processes if it is actively processing (a source that plays, a node with an active input, or a node inside its tail time); otherwise its outputs are a single channel of silence. The hierarchy is closed: the abstract hooks are package private.

모든 오디오 노드의 기반(Web Audio API 1.5). 노드는 여러 입력과 출력, 입력을 섞는 방식을 정하는 채널 속성 channelCount, channelCountMode, channelInterpretation, 그리고 0개 이상의 AudioParam 을 가진다. 제어 메서드(connect, disconnect, 채널 속성)는 어느 스레드에서나 부를 수 있다: 즉시 검증하고, 이후 검증을 위해 노드의 연결을 목록에 두고, 렌더링 스레드가 다음 render quantum 경계에서 적용하는 제어 메시지를 쌓는다. 렌더링 스레드는 quantum 마다 renderStep(long, int, long, int) 를 한 번 부른다: 파라미터를 계산하고, 입력을 끌어와 섞고, 노드가 활성(재생 중인 원천, 활성 입력이 있는 노드, 꼬리 시간 안의 노드)이면 처리하며, 아니면 출력은 무음 채널 하나이다. 계층은 닫혀 있다: 추상 훅은 package-private 이다.
