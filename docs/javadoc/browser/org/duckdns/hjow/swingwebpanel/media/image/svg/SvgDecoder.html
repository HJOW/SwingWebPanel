public final class SvgDecoder
extends java.lang.Object
implements ImageDecoder

The decoder of SVG images (plan item P18-04; FEATURE_MATRIX IMG-07): the registry ImageDecoders loads this class by name. It recognizes an SVG document by its first bytes (an optional byte order mark, an XML declaration, comments or DOCTYPE and then an svg start tag; gzip compressed svgz data whose content starts like that is accepted too), parses it with SvgImage and rasterizes it at the natural size of the document with Java2D. The result is a single non-animated frame. Use SvgImage.parse(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) directly to draw the same document at other sizes without losing sharpness. External resources are never loaded and scripts never run.

SVG 이미지의 디코더(계획 P18-04; FEATURE_MATRIX IMG-07). 등록부 ImageDecoders 가 이 클래스를 이름으로 읽어 온다. 첫 바이트(선택적 바이트 순서 표시, XML 선언, 주석이나 DOCTYPE, 그리고 svg 시작 태그)로 SVG 문서를 알아보며(내용이 그렇게 시작하는 gzip 압축 svgz 도 받는다), SvgImage 로 해석해 문서의 자연 크기로 Java2D 로 래스터화한다. 결과는 애니메이션 없는 프레임 하나이다. 같은 문서를 선명도를 잃지 않고 다른 크기로 그리려면 SvgImage.parse(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 를 직접 쓴다. 외부 자원은 읽지 않고 스크립트는 실행하지 않는다.
