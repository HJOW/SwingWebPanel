org.duckdns.hjow.swingwebpanel.media.webaudio
Class AudioListener

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioListener

public final class AudioListener
extends java.lang.Object

The listener of a context: its position and the two vectors that give its orientation, in the right-handed coordinate system of the spatialization (Web Audio API 1.11). Every PannerNode of the context spatializes in relation to this one listener. The nine parameters are a-rate by default (a node with the HRTF model reads them once per quantum) and are computed by the context before its nodes, so a node sees consistent values within a quantum. By default the listener is at the origin, looks along the negative z axis (forward is (0, 0, -1)) and has the positive y axis above it (up is (0, 1, 0)); then the positive x axis is on its right.

Limitation: because the parameters are computed before the nodes, an audio node cannot drive a parameter of the listener (a connection to it would act one quantum late).

컨텍스트의 청취자: 공간화의 오른손 좌표계에서 위치와 방향을 주는 두 벡터(Web Audio API 1.11). 컨텍스트의 모든 PannerNode 가 이 청취자 하나에 대해 공간화한다. 아홉 파라미터는 기본이 a-rate 이고(HRTF 모델의 노드는 quantum 마다 한 번 읽는다) 컨텍스트가 노드보다 먼저 계산하므로 노드는 한 quantum 안에서 일관된 값을 본다. 기본 청취자는 원점에서 -z 방향을 보며(forward 는 (0, 0, -1)) 위쪽이 +y 이다(up 은 (0, 1, 0)). 그러면 +x 가 오른쪽이다.

제한: 파라미터를 노드보다 먼저 계산하므로 오디오 노드는 청취자의 파라미터를 구동할 수 없다(연결해도 한 quantum 늦게 작동한다).
