org.duckdns.hjow.swingwebpanel.media.webaudio.decode
Interface DecodeRequest

public interface DecodeRequest

The handle of an asynchronous decoding request returned by AudioDecodeService.decode(byte[], java.lang.String, float, org.duckdns.hjow.swingwebpanel.media.webaudio.decode.DecodeCallback, java.util.concurrent.Executor): it can cancel the request and tell its state. The methods may be called from any thread.

AudioDecodeService.decode(byte[], java.lang.String, float, org.duckdns.hjow.swingwebpanel.media.webaudio.decode.DecodeCallback, java.util.concurrent.Executor) 가 반환하는 비동기 디코딩 요청의 핸들. 요청을 취소하고 상태를 알려 줄 수 있다. 메서드는 어느 스레드에서나 부를 수 있다.

Method Detail

cancel

boolean cancel()
Cancels the request. A request that has not started is removed, a running decoding is interrupted and ends at its next block, and a result that is waiting for its callback is dropped. After this method returned true no callback is started for the request (a callback that is already running cannot be stopped; then the method returns false).

요청을 취소한다. 시작하지 않은 요청은 제거하고, 실행 중인 디코딩은 인터럽트하여 다음 블록에서 끝나며, 콜백을 기다리는 결과는 버린다. 이 메서드가 true 를 반환한 뒤에는 그 요청의 콜백이 시작되지 않는다(이미 실행 중인 콜백은 멈출 수 없으며 그때는 false 를 반환한다).

Returns:
true if the request was cancelled before its callback started / 콜백이 시작되기 전에 요청이 취소되었으면 true

Returns:
true if nothing more will happen for the request / 그 요청에 더는 아무 일도 일어나지 않으면 true
