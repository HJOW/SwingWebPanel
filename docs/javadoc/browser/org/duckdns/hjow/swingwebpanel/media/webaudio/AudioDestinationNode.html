Class AudioDestinationNode

public final class AudioDestinationNode
extends AudioNode

The final destination of a context (Web Audio API 1.10): all audio that is heard is routed to it. It has one input and no output (browsers report 0 outputs, although the tables of the specification say 1). Its input has the mode explicit: the channelCount is the number of channels that the context renders. For a real-time context it can be set from 1 to getMaxChannelCount(); for an offline context it is the number of channels given to the constructor and cannot change. The audio of the last quantum is the mixed input bus, which the context reads after each render quantum.

컨텍스트의 최종 목적지(Web Audio API 1.10): 들리는 모든 오디오가 여기로 간다. 입력이 하나이고 출력은 없다(규격 표는 1 이라고 적지만 브라우저는 출력 0 으로 보고한다). 입력은 explicit 모드이며 channelCount 는 컨텍스트가 렌더링하는 채널 수이다. 실시간 컨텍스트에서는 1 부터 getMaxChannelCount() 까지 정할 수 있고, 오프라인 컨텍스트에서는 생성자에 준 채널 수이며 바꿀 수 없다. 마지막 quantum 의 오디오는 섞인 입력 버스이며 컨텍스트가 render quantum 마다 읽는다.
