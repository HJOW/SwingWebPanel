Class WaveShaperKernel

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.WaveShaperKernel

public final class WaveShaperKernel
extends java.lang.Object

The processing of a wave shaper for one channel (Web Audio API 1.31): the shaping curve with linear interpolation and the optional oversampling. With the oversampling factor 1 the curve is applied to the input frames. With the factor 2 or 4 the signal is up-sampled by half-band interpolation stages, shaped at the high rate and down-sampled again by the matching half-band decimation stages, so the harmonics that the curve creates above the original Nyquist frequency are filtered out instead of folding back as aliasing.

Filters: the factor 2 uses one interpolator and one decimator of the half length 32 (a delay of 63 frames), the factor 4 adds an inner stage pair of the half length 12 at the doubled rate (a delay of 74.5 frames). The filters are linear phase with about 80 dB of stop band attenuation; the identity processing is flat within 0.01 dB up to 0.46 of the sample rate (about 20 kHz at 44.1 kHz, measured with sine tones, see the tests). The delay is the price of the filters and is reported by getLatency(); the specification leaves the filters and their latency to the implementation.

웨이브셰이퍼 한 채널의 처리(Web Audio API 1.31): 선형 보간하는 변환 곡선과 선택 사항인 오버샘플링. 오버샘플링 배수가 1 이면 곡선을 입력 프레임에 바로 적용한다. 배수가 2 나 4 이면 신호를 반대역 보간 단계로 업샘플링하고 높은 주파수에서 곡선을 적용한 뒤 짝이 되는 반대역 데시메이션 단계로 다시 다운샘플링하므로, 곡선이 원래 나이퀴스트 주파수 위에 만든 고조파는 앨리어싱으로 접히지 않고 걸러진다.

필터: 배수 2 는 반 길이 32 의 보간기와 데시메이터 하나씩(지연 63 프레임)을 쓰고, 배수 4 는 두 배 속도에서 반 길이 12 의 안쪽 단계 쌍을 더한다(지연 74.5 프레임). 필터는 선형 위상이며 저지 대역 감쇠가 약 80 dB 이다. 반 길이 32 는 샘플링 주파수의 0.46 배(44.1 kHz 에서 약 20 kHz)까지 항등 처리의 이득이 0.01 dB 안에서 평탄하다(사인으로 잰 값, 시험 참고). 지연은 필터의 대가이고 getLatency() 가 알려 준다. 규격은 필터와 그 지연을 구현에 맡긴다.

shape

public static double shape(double x,
                           float[] curve)
Applies the shaping curve to one value with the linear interpolation of the specification: with N curve values, v = (N - 1) / 2 * (x + 1), the result is the first value for v < 0, the last value for v >= N - 1 and otherwise the interpolation of the values at floor(v) and floor(v) + 1. A NaN input is treated as 0.

규격의 선형 보간으로 변환 곡선을 값 하나에 적용한다. 곡선 값이 N 개이면 v = (N - 1) / 2 * (x + 1) 이고, 결과는 v < 0 이면 첫 값, v >= N - 1 이면 마지막 값이며 그 밖에는 floor(v) 와 floor(v) + 1 의 값을 보간한 것이다. NaN 입력은 0 으로 본다.

Parameters:
x - the input sample / 입력 샘플
curve - the curve / 곡선
Returns:
the output sample / 출력 샘플
