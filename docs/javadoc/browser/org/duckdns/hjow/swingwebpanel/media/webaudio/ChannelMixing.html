public final class ChannelMixing
extends java.lang.Object

The channel up-mixing and down-mixing of Web Audio API section 4. With the interpretation speakers the layouts mono (1), stereo (2), quad (4: L R SL SR) and 5.1 (6: L R C LFE SL SR) are mixed with the equations of the specification; every other pair of channel counts, and the interpretation discrete, fill the channels one by one and drop or zero the rest. The matrices are the equations of sections 4.4 and 4.5 written as weights.

Web Audio API 4절의 채널 업믹스/다운믹스. 해석이 speakers 이면 모노(1), 스테레오(2), 쿼드(4: L R SL SR), 5.1(6: L R C LFE SL SR) 배치를 규격의 식으로 섞고, 그 밖의 채널 수 쌍과 해석 discrete 는 채널을 하나씩 채우고 남는 것은 버리거나 0 으로 둔다. 행렬은 4.4절과 4.5절의 식을 가중치로 적은 것이다.

Mixes the source bus into the destination bus, converting the channel count with the interpretation. The two buses have the same number of frames (the shorter one decides if they differ).

원본 버스를 대상 버스로 섞으며 해석에 따라 채널 수를 변환한다. 두 버스는 프레임 수가 같다(다르면 짧은 쪽을 따른다).

Parameters:
src - the source / 원본
dst - the destination; its number of channels decides the result / 대상. 채널 수가 결과를 정한다
interpretation - how to convert the channels / 채널 변환 방식
accumulate - true to add to the destination, false to overwrite it / 대상에 더하면 true, 덮어쓰면 false
