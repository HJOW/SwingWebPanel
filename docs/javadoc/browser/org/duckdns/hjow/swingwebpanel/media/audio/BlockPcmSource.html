Class BlockPcmSource

public abstract class BlockPcmSource
extends java.lang.Object
implements PcmSource

Base class of PcmSource implementations that decode in blocks: a subclass only has to produce the next block of decoded PCM (fill(byte[])) and, if it can, jump to a position (seekTo(long)). This class keeps the output buffer, the frame position, the end of stream and the error state, and gives seeking an exact frame position by decoding forward and discarding. When a block fails to decode, the PCM decoded before it is still delivered: the failure is reported by the read that follows and every later read.

블록 단위로 디코딩하는 PcmSource 구현의 기반 클래스: 하위 클래스는 다음 PCM 블록을 만들어 내는 일(fill(byte[]))과, 가능하면 위치로 이동하는 일(seekTo(long))만 하면 된다. 이 클래스는 출력 버퍼, 프레임 위치, 스트림 끝, 오류 상태를 관리하며 앞으로 디코딩하며 버리는 방식으로 탐색이 정확한 프레임 위치에 닿게 한다. 블록 디코딩이 실패해도 그 앞까지 디코딩한 PCM 은 전달하며 실패는 바로 다음 읽기와 이후의 모든 읽기에서 보고한다.
