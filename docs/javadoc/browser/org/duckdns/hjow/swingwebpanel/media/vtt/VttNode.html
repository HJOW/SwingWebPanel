org.duckdns.hjow.swingwebpanel.media.vtt
Class VttNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.vtt.VttNode

public final class VttNode
extends java.lang.Object

A WebVTT node object (WebVTT 6.4): a node of the tree that the cue text parser builds. An internal node (the root list, a class span, italic, bold, underline, ruby, ruby text, voice or language span) has children, applicable classes and an applicable language; a leaf is a text or a timestamp. The fields are public because the class is a plain record.

WebVTT 노드 객체(WebVTT 6.4): cue 텍스트 파서가 만드는 트리의 노드. 내부 노드(루트 목록, 클래스/기울임/굵게/밑줄/루비/루비 텍스트/목소리/언어 span)는 자식, 적용되는 클래스, 적용되는 언어를 가지며, 잎은 텍스트 또는 타임스탬프이다. 클래스는 단순한 기록이므로 필드는 public 이다.
