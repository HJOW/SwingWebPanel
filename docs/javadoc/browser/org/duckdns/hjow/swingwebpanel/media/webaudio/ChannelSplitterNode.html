public final class ChannelSplitterNode
extends AudioNode

Gives access to the individual channels of its input (Web Audio API 1.15): it has one input and a fixed number of outputs of one channel each. Output k carries the channel k of the input; an output without a matching channel is silent. The node does not interpret the channel identities. Its input has the fixed settings channelCount equal to the number of outputs, channelCountMode explicit and channelInterpretation discrete.

입력의 개별 채널에 접근하게 한다(Web Audio API 1.15): 입력이 하나이고 채널이 하나씩인 출력이 정해진 수만큼 있다. 출력 k 는 입력의 채널 k 를 싣고, 대응하는 채널이 없는 출력은 무음이다. 노드는 채널의 의미를 해석하지 않는다. 입력은 channelCount 가 출력 수와 같고 channelCountMode 가 explicit, channelInterpretation 이 discrete 로 고정이다.
