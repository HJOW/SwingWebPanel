public class MediaException
extends java.lang.Exception

Failure of an image or audio operation (plan item P18-01). The MediaException.Kind separates the three failures that the page shows differently: the resource could not be fetched, its format is not supported, or the data is damaged.

이미지/오디오 작업의 실패(계획 P18-01). MediaException.Kind 는 페이지가 다르게 표시해야 하는 세 가지 실패를 구분한다: 리소스를 가져올 수 없음, 형식을 지원하지 않음, 데이터가 손상됨.
