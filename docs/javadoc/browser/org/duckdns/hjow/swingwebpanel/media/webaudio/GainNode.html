public final class GainNode
extends AudioNode

Multiplies every sample of every channel of its input by the computed value of the gain parameter (Web Audio API 1.20). The number of channels of the output equals the number of channels of the input.

입력의 모든 채널의 모든 샘플에 gain 파라미터의 계산된 값을 곱한다(Web Audio API 1.20). 출력의 채널 수는 입력의 채널 수와 같다.
