Class VttParser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.vtt.VttParser

public final class VttParser
extends java.lang.Object

The WebVTT file parser (WebVTT 6.1 "WebVTT file parsing", 6.2 region settings, 6.3 cue timings and settings), after the W3C Candidate Recommendation of 2026-05-20. parse(byte[]) decodes UTF-8 (a byte order mark is dropped, a malformed sequence becomes U+FFFD) and parse(String) reads text. The parser works as the specification says: the file must start with WEBVTT (otherwise the result is not VttFile.valid), the header block is skipped, and the blocks that follow are cues, REGION blocks, STYLE blocks, comments (NOTE, which is a block that no rule accepts) or garbage; a cue block whose timing line is wrong is dropped without hurting the cues after it.

WebVTT 파일 파서(WebVTT 6.1 "WebVTT file parsing", 6.2 region 설정, 6.3 cue 타이밍과 설정. 2026-05-20 W3C 후보 권고안). parse(byte[]) 는 UTF-8 을 해독하고(바이트 순서 표시는 버리고 잘못된 열은 U+FFFD) parse(String) 은 텍스트를 읽는다. 파서는 규격대로 동작한다: 파일은 WEBVTT 로 시작해야 하며(아니면 결과가 VttFile.valid 가 아니다) 머리 블록은 건너뛰고, 이어지는 블록은 cue, REGION 블록, STYLE 블록, 주석(NOTE: 어떤 규칙도 받아들이지 않는 블록) 또는 쓰레기이다. 타이밍 줄이 틀린 cue 블록은 뒤의 cue 를 해치지 않고 버려진다.
