A pure Java decoder for Windows icon and cursor files (.ico, .cur; plan items P18-02, P18-03; FEATURE_MATRIX IMG-06). A file holds several images of different sizes; every image is either an embedded PNG (decoded by PngDecoder) or a device independent bitmap with a 1-bit AND mask (decoded by BmpDecoder; a 32-bit bitmap with alpha ignores the mask). The decode(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) method returns the largest image (ties go to the first entry), decodeAll(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) returns all of them. Directory entries whose image cannot be decoded are skipped; if none can be decoded the file is CORRUPT.

Windows 아이콘/커서 파일(.ico, .cur)을 위한 순수 Java 디코더(계획 P18-02, P18-03; FEATURE_MATRIX IMG-06). 파일에는 크기가 다른 이미지가 여러 개 있으며 각 이미지는 내장 PNG(PngDecoder 가 디코딩)이거나 1비트 AND 마스크가 있는 장치 독립 비트맵(BmpDecoder 가 디코딩. 알파가 있는 32비트 비트맵은 마스크를 무시)이다. decode(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 는 가장 큰 이미지(같으면 앞선 항목)를 반환하고 decodeAll(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 은 모두 반환한다. 이미지를 디코딩할 수 없는 디렉터리 항목은 건너뛰며 하나도 디코딩하지 못하면 CORRUPT 이다.
