Class StereoPannerNode

public final class StereoPannerNode
extends AudioNode

Positions its input in a stereo image with the low-cost equal power panning of the specification (Web Audio API 1.30, section 6.3.3). The input has at most two channels (a mono input is panned across the image, a stereo input is balanced) and the output always has two. With pan clamped to [-1, 1], x = (pan + 1) / 2 for a mono input and x = pan + 1 or x = pan for a stereo input, the gains are cos(x pi / 2) for the left and sin(x pi / 2) for the right side.

입력을 규격의 저비용 등전력 패닝으로 스테레오 이미지 안에 배치한다(Web Audio API 1.30, 6.3.3절). 입력은 채널이 최대 둘이고(모노 입력은 이미지 전체에 패닝되고 스테레오 입력은 균형이 맞춰진다) 출력은 항상 둘이다. pan 을 [-1, 1] 로 제한하고, 모노 입력은 x = (pan + 1) / 2, 스테레오 입력은 x = pan + 1 또는 x = pan 이며, 이득은 왼쪽이 cos(x pi / 2), 오른쪽이 sin(x pi / 2) 이다.
