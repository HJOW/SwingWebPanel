Class PartitionedConvolver

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.PartitionedConvolver

public final class PartitionedConvolver
extends java.lang.Object

Convolves one input channel with one impulse response channel in blocks of a render quantum, without any latency and with the cost of a partitioned FFT convolution (see ConvolutionKernel for the layout). The object keeps the input history and the frequency domain delay lines of the levels; the kernel with the spectra of the response is shared and is not changed.

At every quantum the new input block is appended to the history. Level 0 transforms the last 2Q input frames (the current block included), multiplies the spectra with the spectra of its partitions and adds them over the delay line. A level with a block of B > Q frames does that only when a block of B frames starts: it transforms the last 2B frames that arrived before the block (the response of the level starts at least one block late, so the block does not depend on later input) and delivers the result block of B frames in pieces of one quantum.

입력 채널 하나를 임펄스 응답 채널 하나와 render quantum 블록 단위로, 지연 없이, 분할 FFT 합성곱의 비용으로 합성곱한다(배치는 ConvolutionKernel 참고). 객체는 입력 이력과 레벨의 주파수 영역 지연선을 가지며, 응답의 스펙트럼을 가진 커널은 공유되고 바뀌지 않는다.

quantum 마다 새 입력 블록을 이력에 덧붙인다. 레벨 0 은 마지막 2Q 입력 프레임(현재 블록 포함)을 변환해 파티션 스펙트럼과 곱하고 지연선 위에서 더한다. 블록이 B > Q 프레임인 레벨은 B 프레임의 블록이 시작될 때만 그렇게 한다. 블록보다 앞에 도착한 마지막 2B 프레임을 변환하고(레벨의 응답이 블록 하나 이상 늦게 시작하므로 블록은 이후 입력에 의존하지 않는다) B 프레임의 결과 블록을 quantum 한 조각씩 내보낸다.
