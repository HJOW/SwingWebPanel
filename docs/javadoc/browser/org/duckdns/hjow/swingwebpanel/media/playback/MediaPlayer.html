org.duckdns.hjow.swingwebpanel.media.playback
Class MediaPlayer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.playback.MediaPlayer

public final class MediaPlayer
extends java.lang.Object

The player of one audio resource (plan items P18-08, P18-10). It owns the encoded data in memory or on disk (within DecodeLimits), decodes it block by block on a daemon thread and writes every PCM block to an AudioOutput. The media element creates one player per loaded resource, calls play(), pause(), seek(double) and the setters from any thread, reads getPosition() when a script asks for currentTime, and receives the facts through a PlaybackListener.

The clock is the sound itself: the position is the source frame after the last frame handed to the output minus the frames that are still queued in the output, so it stands still while paused, follows the real device and needs no timer. Pausing stops the output and seeking flushes it, both before the call returns; the volume is applied to the samples in software (a gain of the 16-bit values), so it is the same on every device and exact in tests. The playback rate may be a quarter to four times (see setRate(double) and RateConverter); the position clock follows it.

A player is used once: load(byte[], String) is called a single time, and close() releases the thread, the decoder and the output (also when the owner is garbage collected: the listener is held weakly, so an abandoned player ends itself). All outputs are closed on the playback thread before it ends, and close() waits a short time for that.

오디오 리소스 하나의 재생기(계획 P18-08, P18-10). 리소스의 인코딩된 데이터를 메모리나 디스크에 소유하며(DecodeLimits 한도), 데몬 스레드에서 블록 단위로 디코딩해 PCM 블록을 AudioOutput에 쓴다. 미디어 요소가 로드한 리소스마다 재생기 하나를 만들고, 어느 스레드에서나 play(), pause(), seek(double) 과 설정 메서드를 부르며, 스크립트가 currentTime 을 물으면 getPosition() 을 읽고, 사실은 PlaybackListener 로 받는다.

시계는 소리 자체이다: 위치는 출력에 넘긴 마지막 프레임 다음의 소스 프레임에서 출력에 아직 큐에 있는 프레임을 뺀 값이므로 일시정지 중에는 멈춰 있고, 실제 장치를 따라가며, 타이머가 필요 없다. 일시정지는 출력을 멈추고 탐색은 출력을 비우며 둘 다 호출이 돌아오기 전에 끝난다. 음량은 샘플에 소프트웨어로(16비트 값에 이득) 적용하므로 장치와 상관없이 같고 시험에서 정확하다. 재생 속도는 4분의 1배에서 4배까지 가능하며 (setRate(double) 와 RateConverter 참고) 위치 시계가 이를 따른다.

재생기는 한 번만 쓴다: load(byte[], String) 는 한 번 부르고, close() 는 스레드, 디코더, 출력을 해제한다(소유자가 가비지 컬렉션되는 경우에도: 리스너를 약하게 잡으므로 버려진 재생기는 스스로 끝난다). 모든 출력은 재생 스레드가 끝나기 전에 그 스레드에서 닫으며 close() 는 그것을 잠깐 기다린다.

seek

public void seek(double seconds)
Moves the position. The position reads as the new value at once; the sound continues from there as soon as the playback thread flushed the output and moved the decoder, which is reported as PlaybackListener.seeked(). Ignored before the media is loaded. A position past the end moves to the end, a negative one to the start.

위치를 옮긴다. 위치는 곧바로 새 값으로 읽히고, 재생 스레드가 출력을 비우고 디코더를 옮기는 대로 거기서 소리가 이어지며 PlaybackListener.seeked() 로 알린다. 미디어가 로드되기 전에는 무시한다. 끝을 넘는 위치는 끝으로, 음수는 처음으로 옮긴다.

Parameters:
seconds - the new position in seconds / 새 위치(초)

reopenOutput

public void reopenOutput()
Asks the player to give up the output that is open and to open a new one through its factory at the next write, continuing at the position that is heard now (the sound that was queued in the old output is dropped and decoded again for the new one, so nothing is skipped and nothing is repeated). It is for a factory that decided to serve another destination since the output was opened: the host of the Web Audio API routes the sound of an element into the graph of an audio context when a script connects the element, and a paused element still holds the output that it opened for the speakers. Nothing is reported to the listener (this is not a seek). It has no effect if no output is open (the next one is opened through the factory anyway); it is done by the playback thread, and the call returns at once.

열려 있는 출력을 놓고 다음 쓰기 때 팩터리를 통해 새 출력을 열도록 요청한다. 지금 들리는 위치에서 이어 간다(이전 출력에 큐에 있던 소리는 버리고 새 출력을 위해 다시 디코딩하므로 건너뛰는 것도 반복되는 것도 없다). 출력을 연 뒤 팩터리가 다른 곳을 맡기로 한 경우를 위한 것이다: Web Audio API 의 호스트는 스크립트가 요소를 연결하면 요소의 소리를 오디오 컨텍스트의 그래프로 돌리는데, 일시정지된 요소도 스피커용으로 열어 둔 출력을 아직 쥐고 있다. 리스너에는 아무것도 알리지 않는다(탐색이 아니다). 열린 출력이 없으면 효과가 없다(다음 출력은 어차피 팩터리를 통해 연다). 재생 스레드가 하며 호출은 곧바로 돌아온다.

setRate

public boolean setRate(double value)
Sets the playback rate: 1.0 is the normal speed, 2.0 twice as fast. From a quarter to four times the speed is supported (see RateConverter); the pitch stays the same unless setPreservesPitch(boolean) says otherwise. It applies to the sound that is decoded from now on (the 150 ms in the output buffer keep their speed), and the position clock follows the speed. A value that is not supported (zero, negative, outside the range, not a number) is refused, returning false and keeping the old rate.

재생 속도를 정한다: 1.0 이 보통 속도이고 2.0 은 두 배 빠르다. 4분의 1배에서 4배까지 지원하며(RateConverter 참고) 음높이는 setPreservesPitch(boolean) 가 달리 정하지 않는 한 그대로이다. 지금부터 디코딩하는 소리에 적용되고(출력 버퍼에 있는 150 ms 는 속도를 유지한다) 위치 시계는 속도를 따른다. 지원하지 않는 값(0, 음수, 범위 밖, 숫자 아님)은 거절하며 false 를 반환하고 이전 속도를 유지한다.

Parameters:
value - the rate / 속도
Returns:
true if the rate is supported and was set / 지원하는 속도라서 정했으면 true

close

public void close()
Stops everything: the playback thread, the decoder and the output. Safe to call repeatedly and from any thread; after it returned (the wait for the thread is limited to two seconds) nothing is reported any more and the output is closed.

모든 것을 멈춘다: 재생 스레드, 디코더, 출력. 여러 번, 어느 스레드에서나 안전하게 부를 수 있다. 돌아온 뒤에는(스레드를 기다리는 시간은 2초로 제한) 더 이상 아무것도 알리지 않으며 출력은 닫혀 있다.
