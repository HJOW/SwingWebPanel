public interface AudioDecoder

A decoder for one audio container/codec family (plan items P18-02, P18-07). Implementations are pure Java (Java 6) and use only the public JRE API; they never start external programs and never call a native codec. The registry AudioDecoders picks a decoder from the file signature (first bytes) and uses the MIME type only as a hint, so the same extension with a different real codec is handled correctly.

오디오 컨테이너/코덱 계열 하나의 디코더(계획 P18-02, P18-07). 구현은 순수 Java(Java 6)이며 JRE 공개 API 만 쓰고 외부 프로그램을 실행하거나 네이티브 코덱을 호출하지 않는다. 등록부 AudioDecoders 는 파일 시그니처(첫 바이트)로 디코더를 고르고 MIME 타입은 힌트로만 쓰므로 확장자가 같아도 실제 코덱이 다른 경우를 올바르게 처리한다.
