org.duckdns.hjow.swingwebpanel.media.image
Class DecodedFrame

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.DecodedFrame

public final class DecodedFrame
extends java.lang.Object

One fully composed frame of a decoded image: the complete canvas (not a sub-rectangle) as non-premultiplied ARGB pixels. Animation decoders apply disposal and blend rules themselves, so a consumer only has to show the frames one after another for their delay.

디코딩된 이미지의 완전히 합성된 프레임 하나: 부분 사각형이 아니라 캔버스 전체를 알파 미리 곱하지 않은 ARGB 픽셀로 가진다. 애니메이션 디코더가 처리 방법(disposal)과 합성 규칙을 스스로 적용하므로 사용하는 쪽은 프레임을 지연 시간만큼씩 차례로 보여 주기만 하면 된다.
