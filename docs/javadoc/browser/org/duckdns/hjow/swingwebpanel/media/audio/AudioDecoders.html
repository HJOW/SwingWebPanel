org.duckdns.hjow.swingwebpanel.media.audio
Class AudioDecoders

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.AudioDecoders

public final class AudioDecoders
extends java.lang.Object

The registry of audio decoders and the single entry point of the audio pipeline (plan items P18-01, P18-02, P18-07): it chooses the decoder from the signature of the data and uses the MIME type of the response only as a hint (a decoder that names the hinted MIME type is asked first), so the same extension or MIME type with a different real codec is decoded correctly and a wrong MIME type does not make a valid file fail. Decoders of the other audio families (MP3, AAC, Opus, WebM) are found by name when their classes exist; a missing class is skipped silently. The registry is thread-safe.

오디오 디코더 등록부이자 오디오 파이프라인의 유일한 진입점(계획 P18-01, P18-02, P18-07): 디코더를 데이터의 시그니처로 고르고 응답의 MIME 타입은 힌트로만 쓴다(힌트의 MIME 타입을 선언한 디코더에게 먼저 묻는다). 그래서 확장자나 MIME 타입이 같아도 실제 코덱이 다른 경우를 올바르게 디코딩하고 잘못된 MIME 타입 때문에 올바른 파일이 실패하지 않는다. 다른 계열(MP3, AAC, Opus, WebM)의 디코더는 클래스가 있으면 이름으로 찾으며 없으면 조용히 건너뛴다. 등록부는 스레드 안전하다.

openWide

public static FloatPcmSource openWide(byte[] data,
                                      java.lang.String mimeHint,
                                      DecodeLimits limits)
                               throws MediaException
Opens encoded audio for decoding with the channels and the precision of the file (plan item P25-05): the decoder is chosen exactly as open(byte[], java.lang.String, org.duckdns.hjow.swingwebpanel.media.DecodeLimits) chooses it (by the signature of the data, the MIME type is only a hint); a decoder that implements WideAudioDecoder delivers 32 bit float samples in every channel of the file, any other decoder is used through its 16 bit path (PcmFloatAdapter, at most two channels). The result is read from the start to the end.

파일의 채널과 정밀도로 디코딩하려고 인코딩된 오디오를 연다(계획 P25-05). 디코더는 open(byte[], java.lang.String, org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 이 고르는 것과 똑같이 고른다(데이터의 시그니처로. MIME 타입은 힌트일 뿐이다). WideAudioDecoder 를 구현한 디코더는 파일의 모든 채널을 32비트 float 표본으로 주고, 다른 디코더는 16비트 경로로 쓴다(PcmFloatAdapter, 채널은 최대 둘). 결과는 처음부터 끝까지 읽는다.

canPlayType

public static java.lang.String canPlayType(java.lang.String type)
The answer of HTMLMediaElement.canPlayType for a MIME type: the empty string when the type or one of the listed codecs is not supported, "probably" when the type and all listed codecs are supported, and "maybe" for a supported type without a codecs list.
