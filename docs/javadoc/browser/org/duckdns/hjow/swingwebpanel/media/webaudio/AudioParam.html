org.duckdns.hjow.swingwebpanel.media.webaudio
Class AudioParam

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioParam

public final class AudioParam
extends java.lang.Object

A parameter of an audio node (Web Audio API 1.6): a value that can be set at once, scheduled with automation events, and modulated by the output of other nodes. The control thread calls the methods of this class; they validate the arguments, clamp the times to the current time of the context and put the event on the AudioParamTimeline. The rendering thread calls computeValues(long, int) for every render quantum: it evaluates the timeline, adds the sum of the connected node outputs (mixed down to mono), replaces a NaN with the default value and clamps the result to the nominal range.

오디오 노드의 파라미터(Web Audio API 1.6): 한 번에 설정하거나, 자동화 이벤트로 예약하거나, 다른 노드의 출력으로 변조할 수 있는 값. 제어 스레드가 이 클래스의 메서드를 부르면 인수를 검증하고, 시간을 컨텍스트의 현재 시간 이상으로 맞추고, 이벤트를 AudioParamTimeline 에 넣는다. 렌더링 스레드는 render quantum 마다 computeValues(long, int) 를 부른다: 타임라인을 계산하고, 연결된 노드 출력의 합(모노로 다운믹스)을 더하고, NaN 을 기본 값으로 바꾸고, 결과를 명목 범위로 제한한다.
