org.duckdns.hjow.swingwebpanel.media.audio.ogg
Class OggPage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.ogg.OggPage

public final class OggPage
extends java.lang.Object

One page of an Ogg physical bitstream (RFC 3533): the header fields and the position of the segment table and the payload inside the file data. A page is only a view on the data array; nothing is copied.

Ogg 물리 비트스트림(RFC 3533)의 페이지 하나: 헤더 필드와 파일 데이터 안의 세그먼트 표와 페이로드의 위치. 페이지는 데이터 배열에 대한 보기일 뿐이며 아무것도 복사하지 않는다.
