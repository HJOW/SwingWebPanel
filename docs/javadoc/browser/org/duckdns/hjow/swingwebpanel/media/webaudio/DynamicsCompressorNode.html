Class DynamicsCompressorNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioNode
      org.duckdns.hjow.swingwebpanel.media.webaudio.DynamicsCompressorNode

public final class DynamicsCompressorNode
extends AudioNode

A dynamics compression effect (Web Audio API 1.19): it lowers the volume of the loudest parts of the signal, so that loud and soft sounds that play together stay under control and clipping is avoided. The processing has a look-ahead of 6 milliseconds (a fixed latency), the parameters threshold, knee, ratio, attack and release are read once per render quantum (they are k-rate and cannot be changed to a-rate), and reduction reports the gain reduction in decibels. The input has one or two channels and the output has as many; the detector is linked across the channels, so every channel gets the same gain. See DynamicsCompressorKernel for the algorithm.

다이내믹 압축 효과(Web Audio API 1.19): 신호에서 가장 큰 부분의 음량을 낮춰 함께 재생되는 큰 소리와 작은 소리를 다스리고 클리핑을 피한다. 처리는 6 ms 의 선행 지연(고정 지연)이 있고, threshold, knee, ratio, attack, release 파라미터는 render quantum 마다 한 번 읽으며(k-rate 이고 a-rate 로 바꿀 수 없다), reduction 이 이득 감소량(dB)을 알린다. 입력은 채널이 하나나 둘이고 출력은 같은 수이다. 검출기가 채널을 묶으므로 모든 채널이 같은 게인을 받는다. 알고리즘은 DynamicsCompressorKernel 을 본다.
