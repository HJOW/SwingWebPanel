AudioBufferSourceNode, ConstantSourceNode, OscillatorNode
public abstract class AudioScheduledSourceNode
extends AudioNode

The base of the source nodes that are started and stopped at a time: OscillatorNode, ConstantSourceNode and AudioBufferSourceNode (Web Audio API 1.7). Before start and after stop the node outputs silence. The start and the stop time are used exactly (not rounded to a sample frame): a sample frame is played when its time is at or after the start time and before the stop time. A time of 0, or one in the past, means "at once". The engine keeps a started node alive until it has ended; when it ends the ended listener is called through the task sink of the context.

정해진 시간에 시작하고 멈추는 원천 노드의 기반: OscillatorNode, ConstantSourceNode, AudioBufferSourceNode(Web Audio API 1.7). start 전과 stop 후에 노드는 무음을 출력한다. 시작 시간과 정지 시간은 정확히(샘플 프레임으로 반올림하지 않고) 쓴다: 샘플 프레임은 그 시간이 시작 시간 이후이고 정지 시간 이전일 때 재생된다. 시간이 0 이거나 과거이면 "즉시"이다. 엔진은 시작된 노드를 끝날 때까지 붙잡고, 끝나면 컨텍스트의 작업 싱크를 통해 ended 리스너를 부른다.
