Class ColorProfile

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.color.ColorProfile

public final class ColorProfile
extends java.lang.Object

The colour management of the image decoders (plan item P18-03; FEATURE_MATRIX IMG-01 to IMG-09): the conversion of the pixels of an image from the colour space that the file describes into sRGB, the colour space of the screen. A browser does the same once per image, after decoding; the work here is also done once, over the pixel array that the decoder has just made, with 256-entry tables for the linearisation of the 8-bit channels and one table for the encoding of the result, so that the cost is a few table look-ups and nine multiplications per pixel.

The colour spaces that can be described are: ICC profiles of the matrix/TRC and gray TRC kinds (fromIcc(byte[])), PNG gAMA and cHRM (fromGamma(double, double[])), coding-independent code points of ITU-T H.273 (cICP of PNG, nclx of AVIF; fromCicp(int, int)) with the primaries of Rec. 709, Rec. 470, SMPTE 170M and 240M, generic film, Rec. 2020, DCI-P3, Display P3 and EBU 3213 and the transfer functions of sRGB (which Rec. 709, SMPTE 170M and Rec. 2020 use too, as in Chromium), gamma 2.2 and 2.8, linear, SMPTE 240M, PQ and HLG, and the calibrated RGB endpoints of a BMP (fromCalibrated(double[], double, double, double)). The conversion is relative colorimetric with Bradford adaptation to the D65 white of sRGB, and components that fall outside the sRGB gamut are clipped. The HDR curves are mapped to the standard dynamic range with the HDR reference white of 203 cd/m2 of ITU-R BT.2408: a PQ image has its absolute luminance divided by 203 cd/m2, an HLG image goes through the system gamma 1.2 of ITU-R BT.2100 for a nominal peak of 1000 cd/m2 and the same division, and everything above the white of the display is clipped. LUT-based profiles (the A2B0 family, CMYK, Lab) are not converted: they give null and the image stays as sRGB.

A profile that is equivalent to sRGB (every channel value changes by at most one level) is SRGB and skips the conversion, so that images that are sRGB in fact keep their pixels exactly.

이미지 디코더의 색 관리(계획 P18-03; FEATURE_MATRIX IMG-01~IMG-09): 이미지의 픽셀을 파일이 기술하는 색 공간에서 화면의 색 공간인 sRGB 로 바꾼다. 브라우저도 이미지마다 디코딩 뒤에 한 번 같은 일을 한다. 여기서도 디코더가 방금 만든 픽셀 배열에 대해 한 번만 하며, 8비트 채널의 선형화를 256 항목 표로, 결과의 부호화를 표 하나로 하므로 픽셀당 비용은 표 조회 몇 번과 곱셈 아홉 번이다.

기술할 수 있는 색 공간: 행렬/TRC 와 회색조 TRC 종류의 ICC 프로파일(fromIcc(byte[])), PNG gAMA, cHRM (fromGamma(double, double[])), ITU-T H.273 의 코딩 독립 코드 값(PNG 의 cICP, AVIF 의 nclx. fromCicp(int, int). 원색은 Rec. 709, Rec. 470, SMPTE 170M/240M, 일반 필름, Rec. 2020, DCI-P3, Display P3, EBU 3213, 전달 함수는 sRGB, (Rec. 709, SMPTE 170M, Rec. 2020 도 Chromium 처럼 sRGB 곡선), 감마 2.2/2.8, 선형, SMPTE 240M, PQ, HLG), BMP 의 보정된 RGB 끝점(fromCalibrated(double[], double, double, double)). 변환은 sRGB 의 D65 백색에 대한 Bradford 적응을 쓰는 상대 색도 측정 방식이며 sRGB 영역 밖의 성분은 자른다. HDR 곡선은 ITU-R BT.2408 의 HDR 기준 백색 203 cd/m2 로 표준 동적 범위에 맞춘다: PQ 이미지는 절대 휘도를 203 cd/m2 로 나누고, HLG 이미지는 공칭 최고 1000 cd/m2 에 대한 ITU-R BT.2100 의 시스템 감마 1.2 를 거친 뒤 같은 나눗셈을 하며, 화면의 흰색을 넘는 값은 자른다. 룩업 테이블 기반 프로파일(A2B0 계열, CMYK, Lab)은 변환하지 않는다. null 을 주고 이미지는 sRGB 로 남는다.

sRGB 와 같은 프로파일(모든 채널 값이 최대 한 단계만 바뀜)은 SRGB 이며 변환을 건너뛰므로, 실제로 sRGB 인 이미지는 픽셀이 그대로 남는다.

fromGamma

public static ColorProfile fromGamma(double fileGamma,
                                     double[] chrm)
Builds the conversion for the gAMA and cHRM chunks of a PNG file: the samples are the intensity raised to the file gamma, so the linear value is the sample to the power of 1/gamma; the chromaticities give the primaries and the white point (sRGB and D65 if the file has no cHRM chunk). A gamma within 0.1 of 1/2.2 on sRGB primaries counts as sRGB.

PNG 파일의 gAMA 와 cHRM 청크의 변환을 만든다: 샘플은 강도의 파일 감마 거듭제곱이므로 선형 값은 샘플의 1/감마 거듭제곱이다. 색도 좌표는 원색과 백색점을 준다(cHRM 청크가 없으면 sRGB 와 D65). sRGB 원색에서 1/2.2 와 0.1 이내인 감마는 sRGB 로 센다.

Parameters:
fileGamma - the file gamma, the value of gAMA divided by 100000 (for example 0.45455), or 0 if there is no gamma / 파일 감마, gAMA 의 값을 100000 으로 나눈 것(예: 0.45455). 감마가 없으면 0
chrm - {white x, white y, red x, red y, green x, green y, blue x, blue y} or null / {백색 x, 백색 y, 빨강 x, 빨강 y, 초록 x, 초록 y, 파랑 x, 파랑 y}. 없으면 null
Returns:
the conversion, SRGB if it is equivalent to sRGB, or null if the values are unusable / 변환. sRGB 와 같으면 SRGB. 값을 쓸 수 없으면 null

fromCicp

public static ColorProfile fromCicp(int primaries,
                                    int transfer)
Builds the conversion for coding-independent code points of ITU-T H.273 (the cICP chunk of PNG, the nclx colour description of AVIF). Unspecified or unknown primaries are taken as those of sRGB and an unspecified transfer function as the sRGB curve, as browsers do; the logarithmic transfer functions and SMPTE ST 428 are not supported.

ITU-T H.273 의 코딩 독립 코드 값의 변환을 만든다(PNG 의 cICP 청크, AVIF 의 nclx 색 설명). 지정되지 않았거나 모르는 원색은 브라우저처럼 sRGB 의 것으로, 지정되지 않은 전달 함수는 sRGB 곡선으로 본다. 로그 전달 함수와 SMPTE ST 428 은 지원하지 않는다.

Parameters:
primaries - the colour primaries code point (1 Rec. 709, 4 Rec. 470 M, 5 Rec. 470 BG, 6 SMPTE 170M, 7 SMPTE 240M, 8 generic film, 9 Rec. 2020, 11 DCI-P3, 12 Display P3, 22 EBU 3213) / 색 원색 코드 값
transfer - the transfer characteristics code point (1, 6, 11, 12, 13, 14, 15 the sRGB curve, 4 gamma 2.2, 5 gamma 2.8, 7 SMPTE 240M, 8 linear, 16 PQ, 18 HLG) / 전달 특성 코드 값
Returns:
the conversion, SRGB if it is equivalent to sRGB, or null if a code point is not supported / 변환. sRGB 와 같으면 SRGB. 지원하지 않는 코드 값이면 null
