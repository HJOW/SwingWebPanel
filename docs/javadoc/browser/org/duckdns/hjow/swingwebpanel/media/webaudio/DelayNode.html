Class DelayNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioNode
      org.duckdns.hjow.swingwebpanel.media.webaudio.DelayNode

public final class DelayNode
extends AudioNode

Delays its input by the value of delayTime seconds (Web Audio API 1.18): output(t) = input(t - delayTime(t)). delayTime is an a-rate parameter from 0 to maxDelayTime; a fractional delay interpolates linearly between the two neighbouring samples. The node has a tail time of maxDelayTime, and the number of channels of its output equals the number of channels of its input (a change of the channel count shows when the delayed samples reach the output; the samples that are already in the delay line are mixed to the prevailing layout).

A delay node can be part of a cycle of the graph (a feedback loop). The rendering order then splits it into a reader step that reads the delay line first, like a source, and a writer step that writes the delay line after its inputs; the delayTime is limited to at least one render quantum, because the reader cannot see what the writer writes in the same quantum. A delay node in a cycle is active only while its output is not silent (the magnitude of a sample is at least 2^-126) or it is within its tail time.

입력을 delayTime 초만큼 지연시킨다(Web Audio API 1.18): output(t) = input(t - delayTime(t)). delayTime 은 0 에서 maxDelayTime 까지의 a-rate 파라미터이며 소수 지연은 이웃한 두 샘플 사이를 선형 보간한다. 노드의 꼬리 시간은 maxDelayTime 이고 출력의 채널 수는 입력의 채널 수와 같다(채널 수 변화는 지연된 샘플이 출력에 닿을 때 나타나며, 이미 지연선에 있는 샘플은 그때의 배치로 섞는다).

지연 노드는 그래프의 순환(피드백 루프)의 일부일 수 있다. 렌더링 순서는 그때 노드를 원천처럼 지연선을 먼저 읽는 읽기 단계와 입력 뒤에 지연선에 쓰는 쓰기 단계로 나눈다. 읽기 단계는 같은 quantum 에서 쓰기 단계가 쓰는 것을 볼 수 없으므로 delayTime 은 최소 render quantum 하나로 제한된다. 순환 안의 지연 노드는 출력이 무음이 아닌 동안(샘플 크기가 2^-126 이상) 또는 꼬리 시간 안에서만 활성이다.
