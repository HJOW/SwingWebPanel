public final class ByteSourceException
extends java.lang.RuntimeException

An input error of a ByteSource: the temporary file of a media resource could not be read (it was closed because the page or the element went away, or it was removed from outside). It is unchecked so that the container parsers, which read bytes in many small helpers, need no extra declarations; AudioDecoders and the players turn it into a MediaException of kind MediaException.Kind#ACCESS_FAILED (see toMediaException()).

ByteSource 의 입력 오류: 미디어 리소스의 임시 파일을 읽을 수 없다(페이지나 요소가 사라져 닫혔거나 밖에서 지워졌다). 많은 작은 도우미에서 바이트를 읽는 컨테이너 해석기에 선언을 더하지 않도록 비검사 예외이며, AudioDecoders 와 재생기는 이것을 MediaException.Kind#ACCESS_FAILED 종류의 MediaException 으로 바꾼다(toMediaException() 참고).
