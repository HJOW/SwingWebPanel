Interface ImageDecoder

All Known Implementing Classes:
AvifDecoder, BmpDecoder, GifDecoder, IcoDecoder, JpegDecoder, PngDecoder, SvgDecoder, WebpDecoder
public interface ImageDecoder

A decoder for one image format (plan items P18-02, P18-03). Implementations are pure Java (Java 6) and use only the public JRE API; they never start external programs. The registry ImageDecoders picks a decoder by looking at the first bytes of the data (file signature) and uses the MIME type only as a hint, so a wrong extension or MIME type does not decide the format.

이미지 형식 하나의 디코더(계획 P18-02, P18-03). 구현은 순수 Java(Java 6)이며 JRE 공개 API 만 쓰고 외부 프로그램을 실행하지 않는다. 등록부 ImageDecoders 는 데이터의 첫 바이트(파일 시그니처)로 디코더를 고르고 MIME 타입은 힌트로만 쓰므로 잘못된 확장자나 MIME 타입이 형식을 결정하지 못한다.
