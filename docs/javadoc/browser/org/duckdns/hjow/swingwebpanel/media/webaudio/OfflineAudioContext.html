org.duckdns.hjow.swingwebpanel.media.webaudio
Class OfflineAudioContext

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.BaseAudioContext
      org.duckdns.hjow.swingwebpanel.media.webaudio.OfflineAudioContext

public final class OfflineAudioContext
extends BaseAudioContext

A context that renders a graph as fast as possible into an AudioBuffer instead of to a device (Web Audio API 1.3). The destination has the number of channels that the constructor was given and the sample rate is the one given too. startRendering() renders the whole length on the calling thread: before the rendering starts and between the quanta the control methods of the nodes may be called, and the control messages are applied at the start of every quantum, so the result is the same as for a real-time context that renders without delays. The length is rounded up to a whole number of quanta while rendering and the result is cut to the length. The script layer wraps the call in a promise and fires oncomplete; suspending and resuming a rendering is provided by renderNextQuantum() and finishRendering().

장치가 아니라 AudioBuffer 로 그래프를 가능한 한 빠르게 렌더링하는 컨텍스트(Web Audio API 1.3). 목적지는 생성자에 준 채널 수를 가지며 샘플링 주파수도 생성자에 준 값이다. startRendering() 은 호출한 스레드에서 전체 길이를 렌더링한다: 렌더링이 시작되기 전과 quantum 사이에 노드의 제어 메서드를 부를 수 있고, 제어 메시지는 quantum 마다 시작에 적용되므로 결과는 지연 없이 렌더링하는 실시간 컨텍스트와 같다. 길이는 렌더링 중에 quantum 의 정수 배로 올림하고 결과는 길이로 자른다. 스크립트 계층은 이 호출을 promise 로 감싸고 oncomplete 를 발생시킨다. 렌더링의 일시 중단과 재개는 renderNextQuantum() 과 finishRendering() 으로 제공한다.
