Class NullOutput

AudioOutput
public final class NullOutput
extends java.lang.Object
implements AudioOutput

The output for a machine without a sound device (plan item P25-07): it discards the audio, but it behaves like a device of a fixed buffer that plays at real speed. A started output "plays" the queue as wall-clock time passes, a write(float[][], int) waits while the queue is full, and the queue drains to 0 when the writer is too slow (an underrun, after which the virtual device waits for new data). A context that renders into it therefore advances its currentTime at the real speed of the clock, as it would with a real device, and a page that measures time with the context still works on a computer without sound.

소리 장치가 없는 컴퓨터를 위한 출력(계획 P25-07): 오디오를 버리지만 고정 버퍼를 가진, 실제 속도로 재생하는 장치처럼 동작한다. 시작된 출력은 벽시계 시간이 지나는 만큼 큐를 "재생"하고, 큐가 가득 차 있으면 write(float[][], int) 가 기다리며, 쓰는 쪽이 너무 느리면 큐가 0 으로 비워진다(언더런. 그 뒤 가상 장치는 새 데이터를 기다린다). 그래서 이것으로 렌더링하는 컨텍스트는 실제 장치처럼 currentTime 이 시계의 실제 속도로 진행하고, 컨텍스트로 시간을 재는 페이지는 소리가 없는 컴퓨터에서도 동작한다.
