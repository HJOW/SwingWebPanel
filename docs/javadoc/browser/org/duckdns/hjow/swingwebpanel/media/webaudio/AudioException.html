public final class AudioException
extends java.lang.RuntimeException

The error of a Web Audio operation. The AudioException.Kind tells which exception the script layer must throw: a DOMException with the name of the kind, or a RangeError / TypeError of the language. The engine never throws a Java checked exception, so a control method can be called from any thread without a throws clause.

Web Audio 작업의 오류. AudioException.Kind 는 스크립트 계층이 던져야 할 예외를 알려 준다: 종류 이름을 가진 DOMException 이거나 언어의 RangeError / TypeError. 엔진은 Java 검사 예외를 던지지 않으므로 제어 메서드를 throws 절 없이 어느 스레드에서나 부를 수 있다.
