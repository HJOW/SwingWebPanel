Class ConvolutionKernel

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.ConvolutionKernel

public final class ConvolutionKernel
extends java.lang.Object

The frequency-domain form of one impulse response channel for a PartitionedConvolver: the impulse response is cut into partitions, and the spectrum of every partition is computed once. The object is immutable after construction, so several convolvers (several channels of one node) can share it.

Layout (non-uniform partitioned convolution, so that the output has no latency beyond the render quantum and a long response is cheap): level 0 uses blocks of one render quantum Q and covers the first 4 Q taps (4 partitions) with the current input block included, so the output block needs only input that has arrived. Level j uses blocks of Q 4^j, starts at the tap Q 4^j (never earlier than one block, which is what allows its output block to be computed from the input that arrived before it) and covers three partitions, except for the last level, which uses blocks of at most 8192 frames and covers all the remaining taps. A block of B frames is transformed with an FFT of 2B points (overlap-save).

PartitionedConvolver 를 위한 임펄스 응답 채널 하나의 주파수 영역 형태: 임펄스 응답을 파티션으로 자르고 파티션마다 스펙트럼을 한 번 계산한다. 객체는 만든 뒤에는 불변이므로 여러 컨볼버(한 노드의 여러 채널)가 공유할 수 있다.

배치(균일하지 않은 분할 합성곱. 출력이 render quantum 이상의 지연이 없고 긴 응답이 싸다): 레벨 0 은 render quantum Q 크기의 블록을 쓰고 현재 입력 블록을 포함해 앞쪽 4 Q 탭(파티션 4개)을 맡는다. 그래서 출력 블록은 이미 도착한 입력만 있으면 계산된다. 레벨 j 는 Q 4^j 크기의 블록을 쓰고 탭 Q 4^j 에서 시작하며(블록 하나보다 앞서지 않으므로 그 출력 블록을 그 전에 도착한 입력만으로 계산할 수 있다) 파티션 셋을 맡는다. 마지막 레벨만 예외로 최대 8192 프레임의 블록을 쓰고 남은 탭 전체를 맡는다. B 프레임의 블록은 2B 점 FFT 로 변환한다(overlap-save).
