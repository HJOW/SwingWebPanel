Package org.duckdns.hjow.swingwebpanel.media.audio.ogg

Class Summary
OggPacket One packet of a logical Ogg bitstream, reassembled from the segments of one or more pages.
OggPacketStream Sequential reader of the packets of one logical Ogg bitstream.
OggPage One page of an Ogg physical bitstream (RFC 3533): the header fields and the position of the segment table and the payload inside the file data.
OggPageWriter Writes one logical Ogg stream to a caller-owned sink.
OggReader Index of an Ogg file (RFC 3533): every page is located (garbage between pages is skipped by searching for the next capture pattern) and assigned to its logical bitstream by serial number.
OggStream One logical bitstream of an Ogg file: its serial number, the codec recognized from its first packet and an index of its pages (offset, granule position, flags) that makes seeking possible without reading the whole file again.
