Class AnalyserNode

public final class AnalyserNode
extends AudioNode

Real-time frequency and time-domain analysis (Web Audio API 1.8). The audio passes unchanged from the input to the output (the output may stay unconnected, and the node is processed as long as a started source feeds it). The node keeps the last 32768 frames of the input, down-mixed to mono with the rules of the speakers interpretation whatever the settings of the node are, and the reading methods work on the most recent fftSize frames of it.

Frequency data (getFloatFrequencyData, getByteFrequencyData): the time-domain data is windowed with the Blackman window w[n] = a0 - a1 cos(2 pi n / N) + a2 cos(4 pi n / N) (alpha = 0.16, a0 = (1 - alpha) / 2, a1 = 1 / 2, a2 = alpha / 2), transformed with the discrete Fourier transform and scaled by 1 / N; the magnitudes |X[k]| are smoothed over time, X'[k] = tau X'_prev[k] + (1 - tau) |X[k]| with tau = smoothingTimeConstant, and converted to decibels, Y[k] = 20 log10 X'[k] (minus infinity for a magnitude of 0). The bytes are floor(255 (Y - min) / (max - min)) clipped to 0..255 and, for the time domain, floor(128 (1 + x)) clipped to 0..255; a byte is an unsigned value (use b & 0xFF). The frequency data is computed again only when the render time has advanced since the last call, so several calls within one render quantum return the same data and smooth only once.

A reading method may be called from any thread while the context renders: the rendering thread writes the history in short critical sections and the readers copy what they need.

실시간 주파수와 시간 영역 분석(Web Audio API 1.8). 오디오는 입력에서 출력으로 그대로 지나간다(출력은 연결하지 않아도 되고, 시작한 원천이 노드를 먹이는 동안 처리된다). 노드는 입력의 마지막 32768 프레임을 보관하는데 노드의 설정과 무관하게 speakers 해석의 규칙으로 모노로 다운믹스한 것이며, 읽기 메서드는 그중 가장 최근 fftSize 프레임을 쓴다.

주파수 데이터(getFloatFrequencyData, getByteFrequencyData): 시간 영역 데이터에 Blackman 창 w[n] = a0 - a1 cos(2 pi n / N) + a2 cos(4 pi n / N)(alpha = 0.16, a0 = (1 - alpha) / 2, a1 = 1 / 2, a2 = alpha / 2)을 곱하고 이산 푸리에 변환한 뒤 1 / N 로 크기를 맞춘다. 크기 |X[k]| 를 시간에 따라 평활(X'[k] = tau X'_prev[k] + (1 - tau) |X[k]|, tau = smoothingTimeConstant)하고 데시벨로 바꾼다(Y[k] = 20 log10 X'[k], 크기가 0 이면 음의 무한대). 바이트는 floor(255 (Y - min) / (max - min)) 을 0~255 로 자른 값이고 시간 영역은 floor(128 (1 + x)) 을 0~255 로 자른 값이다. 바이트는 부호 없는 값이다(b & 0xFF 를 쓴다). 주파수 데이터는 마지막 호출 뒤 렌더링 시간이 흘렀을 때만 다시 계산하므로 한 render quantum 안의 여러 호출은 같은 데이터를 돌려주고 평활도 한 번만 한다.

읽기 메서드는 컨텍스트가 렌더링하는 동안 어느 스레드에서든 부를 수 있다. 렌더링 스레드는 짧은 임계 구역에서 이력을 쓰고 읽는 쪽은 필요한 만큼 복사한다.
