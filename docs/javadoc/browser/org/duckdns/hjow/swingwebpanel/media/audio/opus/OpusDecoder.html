Decoder of Ogg Opus (plan item P18-07, FEATURE_MATRIX AUD-08), a pure Java implementation of RFC 6716 (the SILK, CELT and hybrid modes with all frame sizes from 2.5 to 60 ms, the four frame packing codes, mono and stereo, redundancy frames, packet loss concealment) and of the Ogg encapsulation of RFC 7845 (header packets, pre-skip, output gain, channel mapping families 0 and 1 with up to eight channels, chained streams, trimming of the last page). The data is recognized by the OpusHead signature of the first packet of a logical stream and not by the file name or the MIME type. The output is 16-bit PCM at 48 kHz; more than two channels are mixed down to stereo. Opus in WebM/Matroska is decoded through WebmDecoder.

Ogg Opus 디코더(계획 P18-07, FEATURE_MATRIX AUD-08). RFC 6716(2.5~60 ms 모든 프레임 크기의 SILK, CELT, 하이브리드 모드, 프레임 묶음 코드 넷, 모노와 스테레오, 중복 프레임, 패킷 손실 은닉)과 RFC 7845 의 Ogg 캡슐화(헤더 패킷, 사전 건너뛰기, 출력 이득, 최대 8채널의 채널 매핑 군 0 과 1, 체인 스트림, 마지막 페이지 자르기)를 순수 Java 로 구현했다. 파일 이름이나 MIME 타입이 아니라 논리 스트림 첫 패킷의 OpusHead 시그니처로 알아본다. 출력은 48 kHz 16비트 PCM 이며 채널이 둘보다 많으면 스테레오로 다운믹스한다. WebM/Matroska 안의 Opus 는 WebmDecoder 를 통해 디코딩한다.

Opens the data as 16-bit PCM or in float with every channel of the stream. A chained stream whose links differ in the channel layout cannot be given with a fixed number of channels; it is given through the 16 bit path (stereo).

16비트 PCM 또는 스트림의 모든 채널을 담은 float으로 데이터를 연다. 고리마다 채널 배치가 다른 연결된 스트림은 고정된 채널 수로 줄 수 없으므로 16비트 경로(스테레오)로 준다.
