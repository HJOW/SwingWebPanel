public final class IIRFilterNode
extends AudioNode

A general IIR filter with fixed coefficients (Web Audio API 1.21): H(z) = sum b[m] z^-m / sum a[n] z^-n with at most 20 coefficients in each array. The coefficients cannot change after the node is created. The number of channels of the output equals that of the input. The tail time is estimated from the impulse response of the filter when the node is created (limited to WebAudioLimits.MAX_TAIL_SECONDS seconds).

계수가 고정된 일반 IIR 필터(Web Audio API 1.21): H(z) = sum b[m] z^-m / sum a[n] z^-n 이며 각 배열의 계수는 최대 20개이다. 노드를 만든 뒤에는 계수를 바꿀 수 없다. 출력의 채널 수는 입력과 같다. 꼬리 시간은 노드를 만들 때 필터의 임펄스 응답으로 추정한다(WebAudioLimits.MAX_TAIL_SECONDS 초로 제한).
