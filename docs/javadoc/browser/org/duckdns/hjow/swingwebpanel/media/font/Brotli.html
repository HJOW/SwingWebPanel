org.duckdns.hjow.swingwebpanel.media.font
Class Brotli

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.font.Brotli

public final class Brotli
extends java.lang.Object

A decoder for the Brotli compressed data format (RFC 7932, https://www.rfc-editor.org/rfc/rfc7932.txt, July 2016), written in plain Java without a library: it reads the stream header and every meta-block (empty and metadata blocks, uncompressed blocks, and compressed blocks with their block types, context maps, prefix codes, insert-and-copy commands, the ring buffer of distances and the static dictionary with its 121 transformations; the tables come from BrotliData, which the tool tools/brotlidict made from the RFC). The whole result is built in memory, so the caller gives the largest output that it accepts: a stream that would produce more is rejected, and so is every stream that breaks a rule of the RFC ("the stream should be rejected as invalid"), with a BrotliException; the decoder never reads or writes outside of its arrays. WOFF 2.0 files (see Woff2) are the user.

Brotli 압축 데이터 형식(RFC 7932, https://www.rfc-editor.org/rfc/rfc7932.txt, 2016 년 7 월)의 디코더이며 라이브러리 없이 순수 Java 로 썼다: 스트림 머리와 모든 메타 블록(빈 블록과 메타데이터 블록, 압축하지 않은 블록, 블록 종류와 문맥 지도와 접두사 코드와 삽입·복사 명령과 거리 링 버퍼와 121 개의 변환이 있는 정적 사전을 가진 압축 블록)을 읽는다. 표는 tools/brotlidict 도구가 RFC 에서 만든 BrotliData 에서 온다. 결과는 통째로 메모리에 만들므로 호출자가 받아들이는 최대 출력을 준다. 그보다 많이 만드는 스트림과 RFC 규칙을 어기는 모든 스트림(RFC: "스트림을 잘못된 것으로 거부")은 BrotliException 으로 거부한다. 디코더는 자기 배열 밖을 읽거나 쓰지 않는다. WOFF 2.0 파일(Woff2)이 쓴다.
