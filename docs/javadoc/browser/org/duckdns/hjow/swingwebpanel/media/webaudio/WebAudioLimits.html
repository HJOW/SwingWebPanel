org.duckdns.hjow.swingwebpanel.media.webaudio
Class WebAudioLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.WebAudioLimits

public final class WebAudioLimits
extends java.lang.Object

The limits and fixed sizes of the Web Audio engine (plan item P25-02). Every limit has a name so that the exception for a value outside it can say which limit it was, and so that a test can read the value. The limits protect the memory of the host application: a page cannot ask for more than these sizes.

Web Audio 엔진의 제한과 고정 크기(계획 P25-02). 모든 제한에 이름이 있어 범위를 벗어난 값의 예외가 어느 제한인지 말할 수 있고 시험이 값을 읽을 수 있다. 제한은 호스트 애플리케이션의 메모리를 지킨다: 페이지는 이 크기를 넘게 요청할 수 없다.
