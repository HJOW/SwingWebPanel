org.duckdns.hjow.swingwebpanel.media.audio
Class ChannelMixer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.ChannelMixer

public final class ChannelMixer
extends java.lang.Object

Mixes the channels of a multi-channel layout down to stereo (plan item P18-07). Every input channel has a role; front left/right keep their side, front/back centre go to both sides at -3 dB, left/right surround and back channels go to their side at -3 dB, and the low frequency channel is dropped. The weights of each side are then scaled by one common factor so that full-scale input can never exceed full scale at the output. Layouts with one or two channels are not mixed (mono stays mono).

다채널 배치를 스테레오로 다운믹스한다(계획 P18-07). 입력 채널마다 역할이 있다: 앞 왼쪽/오른쪽은 자기 쪽을 유지하고, 앞/뒤 중앙은 -3 dB 로 양쪽에 들어가며, 왼쪽/오른쪽 서라운드와 뒤 채널은 -3 dB 로 자기 쪽에 들어가고, 저주파 채널은 버린다. 각 쪽의 가중치는 공통 계수로 나누어 풀 스케일 입력이 출력에서 풀 스케일을 넘지 않게 한다. 채널이 하나나 둘인 배치는 섞지 않는다(모노는 모노로 남는다).

forWavMask

public static ChannelMixer forWavMask(int channels,
                                      long mask)
Returns a mixer for the speaker mask of a WAVE_FORMAT_EXTENSIBLE header: the set bits, from the lowest, name the roles in channel order (bit 0 front left, 1 front right, 2 front centre, 3 LFE, 4 back left, 5 back right, 8 back centre, 9 side left, 10 side right; other speakers are not mixed). If the number of set bits differs from the channel count the default layout is used.

WAVE_FORMAT_EXTENSIBLE 헤더의 스피커 마스크용 믹서를 반환한다: 설정된 비트가 낮은 쪽부터 채널 순서대로 역할을 나타낸다(비트 0 앞 왼쪽, 1 앞 오른쪽, 2 앞 중앙, 3 LFE, 4 뒤 왼쪽, 5 뒤 오른쪽, 8 뒤 중앙, 9 옆 왼쪽, 10 옆 오른쪽, 다른 스피커는 섞지 않음). 설정된 비트 수가 채널 수와 다르면 기본 배치를 쓴다.

forVorbisOrder

public static ChannelMixer forVorbisOrder(int channels)
Returns a mixer for the channel order of Vorbis I (section 4.3.9 of the specification), which Opus uses for its channel mapping family 1: it differs from the order of WAV and FLAC for three channels and more (centre before right: 3 = L C R, 5 = L C R BL BR, 6 = L C R BL BR LFE, 7 = L C R SL SR BC LFE, 8 = L C R SL SR BL BR LFE). Up to two channels and four channels are the same as in forChannels(int).

Vorbis I 의 채널 순서(규격 4.3.9절)로 믹서를 만든다. Opus 의 채널 매핑 계열 1 이 이 순서를 쓴다. 채널이 셋 이상일 때 WAV 와 FLAC 의 순서와 다르다(오른쪽보다 중앙이 먼저: 3 = L C R, 5 = L C R BL BR, 6 = L C R BL BR LFE, 7 = L C R SL SR BC LFE, 8 = L C R SL SR BL BR LFE). 채널이 둘 이하이거나 넷이면 forChannels(int) 와 같다.

canonicalOrder

public int[] canonicalOrder()
Returns the order in which the input channels have to be taken to get the canonical order of the wide decoding path (plan item P25-05): front left, front right, front centre, LFE, back left, back right, back centre, side left, side right (the order of the WAVEFORMATEXTENSIBLE mask, FFmpeg and the speaker layouts of Web Audio). The role constants are numbered in this order, so the channels are sorted by role (stable). If a role is unknown or occurs twice the layout is not trusted and the order of the file is kept.

입력 채널을 넓은 디코딩 경로의 표준 순서로 얻으려면 어떤 순서로 가져와야 하는지 반환한다(계획 P25-05): 앞 왼쪽, 앞 오른쪽, 앞 중앙, LFE, 뒤 왼쪽, 뒤 오른쪽, 뒤 중앙, 옆 왼쪽, 옆 오른쪽(WAVEFORMATEXTENSIBLE 마스크, FFmpeg, Web Audio 스피커 배치의 순서). 역할 상수가 이 순서로 번호가 매겨져 있으므로 채널을 역할로 정렬한다(안정 정렬). 역할을 모르거나 같은 역할이 두 번 나오면 배치를 믿지 않고 파일의 순서를 유지한다.

Returns:
for every output channel the index of the input channel / 출력 채널마다 입력 채널의 인덱스
