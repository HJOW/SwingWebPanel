Class IirFilter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.IirFilter

public final class IirFilter
extends java.lang.Object

A general IIR filter of the Web Audio API (1.21): the transfer function H(z) = sum b[m] z^-m / sum a[n] z^-n with at most 20 coefficients in each array. The coefficients are divided by a[0] once; the processing is the direct form I in double precision with a circular history of the inputs and the outputs of every channel. The coefficients cannot change after the filter is created.

Web Audio API 의 일반 IIR 필터(1.21): 전달 함수 H(z) = sum b[m] z^-m / sum a[n] z^-n 이며 각 배열의 계수는 최대 20개이다. 계수는 a[0] 로 한 번 나누고, 처리는 채널마다 입력과 출력의 순환 이력을 가진 배정밀도 직접형 I 이다. 필터를 만든 뒤에는 계수를 바꿀 수 없다.

estimateTailFrames

public long estimateTailFrames(long maxFrames)
Estimates the tail time of the filter in frames by running its impulse response until it stays below the threshold of 16 bit audio for a while, but not longer than the given maximum (a filter that does not decay has the maximum).

필터의 임펄스 응답을 16비트 오디오의 문턱 아래로 한동안 머물 때까지 돌려 꼬리 시간(프레임)을 추정한다. 단 주어진 최댓값을 넘지 않는다(감쇠하지 않는 필터는 최댓값을 가진다).

Parameters:
maxFrames - the largest value to return / 반환할 최댓값
Returns:
the tail time in frames / 꼬리 시간(프레임)
