Package org.duckdns.hjow.swingwebpanel.media.webaudio.dsp

Signal processing helpers of the Web Audio engine (plan items P25-02 to P25-04): the FFT, the biquad filter coefficients and kernel and the general IIR kernel.

See:
          Description

Class Summary
BiquadCoefficients The coefficients of a biquad filter (Web Audio API 1.13.5, "Filters Characteristics").
BiquadFilter The processing of a biquad filter (direct form I, double precision): for every channel it keeps the last two inputs and the last two outputs and applies the coefficients that are given for the block.
ConvolutionKernel The frequency-domain form of one impulse response channel for a PartitionedConvolver: the impulse response is cut into partitions, and the spectrum of every partition is computed once.
DynamicsCompressorKernel The signal processing of a dynamics compressor (Web Audio API 1.19, section 1.19.4): a look-ahead pre-delay of 6 ms, a peak detector on the undelayed input that is linked across the channels, the static compression curve with a soft knee, an envelope with an attack and an adaptive release, a fixed makeup gain, and the metering of the gain reduction.
Fft An in-place complex FFT of a power-of-two size (radix 2, iterative).
HrtfDatabase The head-related transfer functions (HRTF) that the HRTF panning model of the PannerNode uses: the measurements of the MIT KEMAR dummy head microphone, loaded from the resource kemar-compact.hrtf that sits next to this class (it is part of the product JAR and is read from the class path).
HrtfRenderer Renders a mono source into the two ears with the HRTF of a direction: the signal is convolved with the left and the right ear kernels of HrtfSet (one FIR filter per ear, with the interaural delay inside the kernel).
HrtfSet The HRTF data of HrtfDatabase prepared for one sample rate, and the interpolation between the measured directions: for any azimuth and elevation it produces the pair of impulse responses (the kernels of the left and the right ear) that a source in that direction needs.
IirFilter A general IIR filter of the Web Audio API (1.21): the transfer function H(z) = sum b[m] z^-m / sum a[n] z^-n with at most 20 coefficients in each array.
PartitionedConvolver Convolves one input channel with one impulse response channel in blocks of a render quantum, without any latency and with the cost of a partitioned FFT convolution (see ConvolutionKernel for the layout).
WaveShaperKernel The processing of a wave shaper for one channel (Web Audio API 1.31): the shaping curve with linear interpolation and the optional oversampling.
 

Package org.duckdns.hjow.swingwebpanel.media.webaudio.dsp Description

Signal processing helpers of the Web Audio engine (plan items P25-02 to P25-04): the FFT, the biquad filter coefficients and kernel and the general IIR kernel. The classes know nothing about the audio graph, so they can be tested with plain arrays.

Web Audio 엔진의 신호 처리 도우미(계획 P25-02~P25-04): FFT, 쌍이차 필터 계수와 커널, 일반 IIR 커널. 이 클래스들은 오디오 그래프를 모르므로 단순한 배열로 시험할 수 있다.
