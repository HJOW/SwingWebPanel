Class AudioBus

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBus

public final class AudioBus
extends java.lang.Object

A block of audio: a number of channels of one render quantum of float samples. The engine allocates the buses of a node once and reuses them for every quantum; only a change of the number of channels reallocates, and only when the new number exceeds the capacity that was allocated before. The channels are live arrays: the node that owns the bus writes them, the nodes that read the bus must not change them.

오디오 블록: render quantum 하나 분량의 float 샘플로 된 여러 채널. 엔진은 노드의 버스를 한 번 할당해 quantum 마다 다시 쓰며, 채널 수가 바뀌고 새 수가 이전에 할당한 용량을 넘을 때만 다시 할당한다. 채널은 살아 있는 배열이다: 버스를 가진 노드가 쓰고 버스를 읽는 노드는 바꾸면 안 된다.
