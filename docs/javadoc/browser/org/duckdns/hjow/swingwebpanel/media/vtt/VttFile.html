Class VttFile

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.vtt.VttFile

public final class VttFile
extends java.lang.Object

The result of parsing a WebVTT file (WebVTT 6.1): the cues in file order, the regions, the style sheet blocks, and whether the file had the WebVTT file signature (a file without it is not a WebVTT file and was not processed).

WebVTT 파일을 해석한 결과(WebVTT 6.1): 파일 순서의 cue, region, 스타일 시트 블록, 파일에 WebVTT 파일 서명이 있었는지 여부(서명이 없는 파일은 WebVTT 파일이 아니며 처리되지 않았다).
