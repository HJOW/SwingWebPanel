Class ExifOrientation

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.ExifOrientation

public final class ExifOrientation
extends java.lang.Object

Reads the orientation tag of an EXIF block and applies it to a decoded image (plan item P18-03). The EXIF block is a TIFF structure (CIPA DC-008, Exif 2.32, section 4.5: the TIFF header, then the first image file directory with 12-byte entries); the orientation is the SHORT tag 0x0112 with the values 1 to 8 (1 upright, 2 mirrored horizontally, 3 rotated by 180 degrees, 4 mirrored vertically, 5 transposed, 6 rotated by 90 degrees clockwise, 7 transversed, 8 rotated by 270 degrees clockwise). JPEG carries the block in an APP1 segment, PNG in an eXIf chunk and WebP in an EXIF chunk; this class reads the block of all three the same way, so one description of the byte layout serves every format. Browsers apply the orientation by default (CSS Images 3, image-orientation: from-image), so the decoders apply it to the pixels and keep the applied value in the image (DecodedImage.getAppliedOrientation()); the style image-orientation: none then asks for the inverse.

EXIF 블록의 방향 태그를 읽고 디코딩된 이미지에 적용한다(계획 P18-03). EXIF 블록은 TIFF 구조이다(CIPA DC-008, Exif 2.32, 4.5절: TIFF 헤더 뒤에 12바이트 항목이 있는 첫 이미지 파일 디렉터리). 방향은 SHORT 태그 0x0112 이고 값은 1~8 이다(1 정상, 2 좌우 반전, 3 180도 회전, 4 상하 반전, 5 전치, 6 시계 방향 90도 회전, 7 역전치, 8 시계 방향 270도 회전). JPEG 은 APP1 세그먼트에, PNG 는 eXIf 청크에, WebP 는 EXIF 청크에 이 블록을 담는데, 이 클래스가 셋을 같은 방식으로 읽으므로 바이트 배치의 설명이 모든 형식에 하나이다. 브라우저는 방향을 기본으로 적용하므로(CSS Images 3, image-orientation: from-image) 디코더가 픽셀에 적용하고 적용한 값을 이미지에 남기며 (DecodedImage.getAppliedOrientation()), 스타일 image-orientation: none 이 오면 그 역변환을 쓴다.

read

public static int read(byte[] d,
                       int pos,
                       int len)
Reads the orientation from an EXIF block that starts at the TIFF header. A block that carries the six bytes Exif\0\0 in front of the header (JPEG always has them; some PNG and WebP writers add them although the formats do not) is accepted too. Everything that is damaged (a missing header, the number 42 wrong, offsets outside the block, a tag of another type, a value outside 1 to 8) gives 1, which means upright, never an exception.

TIFF 헤더에서 시작하는 EXIF 블록에서 방향을 읽는다. 헤더 앞에 여섯 바이트 Exif\0\0 가 있는 블록(JPEG 은 항상 있고 일부 PNG 와 WebP 작성기는 형식에 없는데도 붙인다)도 받는다. 손상된 모든 것(헤더 없음, 숫자 42 가 다름, 블록 밖을 가리키는 위치, 다른 형식의 태그, 1~8 밖의 값)은 예외 없이 1(정상)을 준다.

Returns:

inverse

public static int inverse(int orientation)
Returns the orientation that undoes the given one: applying an orientation and then its inverse gives the original pixels. Only the two rotations by a quarter turn differ from their inverse (6 and 8); all other orientations (the mirror images, the half turn and the two diagonal flips) undo themselves.

주어진 방향을 되돌리는 방향을 반환한다. 방향을 적용한 뒤 그 역을 적용하면 원래 픽셀이 된다. 4분의 1 회전 둘(6, 8)만 자기 자신과 다르고, 나머지 방향(거울상, 반 바퀴, 대각선 반전 둘)은 자기 자신이 역이다.

Parameters:
orientation - orientation 1 to 8 / 방향 1~8

the inverse orientation; 1 for a value outside 1 to 8 / 역방향. 1~8 밖의 값이면 1

Applies an orientation to an image: the pixels of every frame are turned into display orientation, the size is swapped for 5 to 8 and the applied value is kept in the result. Orientation 1 returns the same object.

이미지에 방향을 적용한다. 모든 프레임의 픽셀을 표시 방향으로 돌리고 5~8 이면 크기를 바꾸며 적용한 값을 결과에 남긴다. 방향 1 은 같은 객체를 반환한다.
