Class MediaElementAudioSourceNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioNode
      org.duckdns.hjow.swingwebpanel.media.webaudio.MediaElementAudioSourceNode

public final class MediaElementAudioSourceNode
extends AudioNode

A source that takes the audio of a media element into the graph (Web Audio API 1.22). The node has no input and one output with as many channels as the media (one silent channel if the media has no audio). The audio comes from a MediaElementPcmSource that the host implements on top of the player of the element; the node pulls one render quantum of the playing media at a time. While the media is paused or has ended, or while nothing was delivered, the output is silent; if the media is from another origin without the permission of the server (MediaElementPcmSource.isOutputAllowed() is false) the output is silent too and nothing is pulled.

If the sample rate of the media differs from the one of the context the samples are resampled with a linear interpolation (exact for equal rates; for other rates the interpolation is a simple, cheap method that leaves some imaging and aliasing at high frequencies).

The context keeps the node processed from its creation until close() is called (the host calls it when the element goes away), because the context cannot tell whether the page still refers to the node.

미디어 요소의 오디오를 그래프로 가져오는 원천(Web Audio API 1.22). 노드는 입력이 없고 미디어와 같은 채널 수의 출력 하나를 가진다(미디어에 오디오가 없으면 무음 채널 하나). 오디오는 호스트가 요소의 재생기 위에서 구현한 MediaElementPcmSource 에서 오며, 노드는 재생 중인 미디어를 render quantum 하나씩 가져간다. 미디어가 일시 정지되었거나 끝났거나 아무것도 오지 않는 동안 출력은 무음이다. 미디어가 서버의 허가 없이 가져온 다른 오리진의 것이면 (MediaElementPcmSource.isOutputAllowed() 가 false) 출력은 역시 무음이고 아무것도 가져오지 않는다.

미디어의 샘플링 주파수가 컨텍스트와 다르면 선형 보간으로 리샘플링한다(같은 주파수이면 정확하다. 다른 주파수에서는 단순하고 값싼 방법이라 높은 주파수에 이미징과 앨리어싱이 조금 남는다).

컨텍스트는 페이지가 노드를 아직 참조하는지 알 수 없으므로 노드를 만든 때부터 close() 가 불릴 때까지 처리 대상으로 붙잡는다(호스트는 요소가 사라질 때 부른다).
