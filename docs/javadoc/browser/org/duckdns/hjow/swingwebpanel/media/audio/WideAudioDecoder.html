Interface WideAudioDecoder

AudioDecoder
All Known Implementing Classes:
AacDecoder, AiffDecoder, AuDecoder, ByteAudioDecoder, FlacDecoder, Mp3Decoder, OpusDecoder, VorbisDecoder, WavDecoder, WebmDecoder
public interface WideAudioDecoder
extends AudioDecoder

An AudioDecoder that can also deliver the channels and the precision of the file (plan item P25-05): in addition to AudioDecoder.open(byte[], DecodeLimits), which gives 16 bit PCM of at most two channels for playing, openWide(byte[], DecodeLimits) gives a FloatPcmSource. A decoder that does not implement this interface is used through the 16 bit path by AudioDecoders.openWide(byte[], java.lang.String, org.duckdns.hjow.swingwebpanel.media.DecodeLimits). Both methods accept and reject the same data.

파일의 채널과 정밀도도 줄 수 있는 AudioDecoder(계획 P25-05): 재생용으로 채널이 최대 둘인 16비트 PCM 을 주는 AudioDecoder.open(byte[], DecodeLimits) 에 더해 openWide(byte[], DecodeLimits) 는 FloatPcmSource 를 준다. 이 인터페이스를 구현하지 않은 디코더는 AudioDecoders.openWide(byte[], java.lang.String, org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 가 16비트 경로로 쓴다. 두 메서드는 같은 데이터를 받아들이고 같은 데이터를 거부한다.

openWide

FloatPcmSource openWide(byte[] data,
                        DecodeLimits limits)
                        throws MediaException
Opens the data for decoding with the channels and the precision of the file. Headers are validated here (so unsupported or damaged files fail early) but samples are decoded only when FloatPcmSource.read(float[][], int, int) is called.

파일의 채널과 정밀도로 디코딩하려고 데이터를 연다. 헤더는 여기서 검증하지만(지원하지 않거나 손상된 파일이 일찍 실패하도록) 샘플은 FloatPcmSource.read(float[][], int, int) 를 호출할 때 디코딩한다.

Parameters:
data - the whole encoded data (kept by the source; not modified) / 인코딩된 전체 데이터(소스가 보관하며 수정하지 않음)
limits - limits to respect / 지켜야 할 제한
Returns:
a float source positioned at the start / 처음에 위치한 float 소스
Throws:
MediaException - the same failures as AudioDecoder.open(byte[], DecodeLimits) / AudioDecoder.open(byte[], DecodeLimits) 와 같은 실패
