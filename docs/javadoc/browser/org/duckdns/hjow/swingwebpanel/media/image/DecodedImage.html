org.duckdns.hjow.swingwebpanel.media.image
Class DecodedImage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.DecodedImage

public final class DecodedImage
extends java.lang.Object

The result of decoding an image: its natural size, one or more composed frames and the animation loop count. A still image has exactly one frame. Orientation (for example EXIF) is already applied to the pixels and to the size.

이미지 디코딩 결과: 자연 크기, 합성된 프레임 하나 이상, 애니메이션 반복 횟수. 정지 이미지는 프레임이 정확히 하나이다. 방향 정보(예: EXIF)는 이미 픽셀과 크기에 적용되어 있다.

unoriented

public DecodedImage unoriented()
Returns the image as it is stored in the file, that is with the applied EXIF orientation undone. This is what the style image-orientation: none shows (CSS Images 3, section 5.2). An image without an applied orientation returns itself; the other one is created on the first call and kept. Never throws: the work does not look at the interrupt flag, because it runs while the page is painted.

파일에 저장된 그대로의 이미지, 즉 적용한 EXIF 방향을 되돌린 이미지를 반환한다. 스타일 image-orientation: none 이 보여 주는 것이다(CSS Images 3, 5.2절). 적용한 방향이 없는 이미지는 자기 자신을 반환하고, 있는 이미지는 처음 부를 때 만들어 보관한다. 예외를 던지지 않는다. 페이지를 그리는 동안 도는 작업이라 인터럽트 표시를 보지 않는다.

Returns:
the image in stored orientation / 저장된 방향의 이미지
