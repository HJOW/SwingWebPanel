Class BiquadCoefficients

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.BiquadCoefficients

public final class BiquadCoefficients
extends java.lang.Object

The coefficients of a biquad filter (Web Audio API 1.13.5, "Filters Characteristics"). The transfer function is H(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2) where the coefficients are already divided by a0. The formulas of the eight filter types are those of the specification (the Audio EQ Cookbook). Where the formulas are not defined (a frequency of 0 or of the Nyquist frequency, a Q of 0) the limit of the transfer function is used, so that automating a parameter through such a value does not produce a NaN: this is the behavior of the reference implementation (Chromium, biquad.cc).

쌍이차 필터의 계수(Web Audio API 1.13.5, "Filters Characteristics"). 전달 함수는 H(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2) 이며 계수는 이미 a0 로 나눈 값이다. 여덟 가지 필터 종류의 식은 규격(Audio EQ Cookbook)의 식이다. 식이 정의되지 않는 곳(주파수 0 또는 나이퀴스트 주파수, Q 0)에서는 전달 함수의 극한을 써서 파라미터를 그 값 위로 자동화해도 NaN 이 생기지 않게 한다: 참조 구현(Chromium, biquad.cc)의 동작이다.

tailFrames

public long tailFrames(long maxFrames)
Estimates the number of frames after which the response of the filter to a silent input has decayed below the threshold of 16 bit audio, from the radius of the poles. The estimate is limited to the given maximum (a filter that does not decay, because it is unstable or has a pole on the unit circle, has the maximum).

필터가 무음 입력에 대해 응답이 16비트 오디오의 문턱 아래로 줄어들기까지의 프레임 수를 극의 반지름으로 추정한다. 추정값은 주어진 최댓값으로 제한된다(불안정하거나 단위원 위에 극이 있어 감쇠하지 않는 필터는 최댓값을 가진다).

Parameters:
maxFrames - the largest value to return / 반환할 최댓값
Returns:
the tail time in frames / 꼬리 시간(프레임)
