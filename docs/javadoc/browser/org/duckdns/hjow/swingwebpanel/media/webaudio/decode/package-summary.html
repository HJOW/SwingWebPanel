Package org.duckdns.hjow.swingwebpanel.media.webaudio.decode

The decoding of audio file data into AudioBuffers for decodeAudioData (plan item P25-05), still without any JavaScript: the sample rate converter Resampler, the pipeline AudioBufferDecoder that reuses the audio decoders of AudioDecoders (chosen by the signature of the data) and resamples to the sample rate of the context, and the background service AudioDecodeService that decodes on its own daemon threads, can cancel a request and reports the result through a callback on a thread of the caller's choice.

Interface Summary
DecodeCallback The receiver of the result of an asynchronous decoding (DecodeSuccessCallback and DecodeErrorCallback of the specification; the script layer turns the pair into the resolution or the rejection of a promise).
DecodeCancellation A flag that a long decoding polls between blocks to learn that its result is no longer wanted (the request was cancelled, the context was closed, the page was left).
DecodeRequest The handle of an asynchronous decoding request returned by AudioDecodeService.decode(byte[], java.lang.String, float, org.duckdns.hjow.swingwebpanel.media.webaudio.decode.DecodeCallback, java.util.concurrent.Executor): it can cancel the request and tell its state.
DecodeWarningCallback A DecodeCallback that also wants to know when the data was decoded only in part: the specification (Web Audio API 1.1 draft) encourages an implementation to warn the author when the compressed data is corrupted but the decoding can otherwise proceed, for example in the developer tools.
 

Class Summary
AudioBufferDecoder The decoding pipeline of decodeAudioData (plan item P25-05): encoded audio file data in, an AudioBuffer at the sample rate of the context out.
AudioDecodeService The background decoder behind decodeAudioData (plan item P25-05): a request carries the bytes of an audio file, the sample rate of the context and a DecodeCallback; the service decodes it on one of its own threads with AudioBufferDecoder (so neither the control thread, the rendering thread nor the event dispatch thread ever waits for a decoding, the "decoding thread" of the specification) and reports the result to the callback.
DecodeResult The result of a decoding that succeeded: the AudioBuffer and, if the data was damaged or cut off, the warning that the script layer shows to the author (the Web Audio API 1.1 draft encourages implementations to warn authors in case of a corrupted file whose decoding can otherwise proceed; a browser shows it in its developer tools, this component has no log, so the caller learns it here).
Resampler A streaming sample rate converter for one channel of floating point audio (plan item P25-05: the resampling of decodeAudioData to the sample rate of the context).
 

Package org.duckdns.hjow.swingwebpanel.media.webaudio.decode Description

The decoding of audio file data into AudioBuffers for decodeAudioData (plan item P25-05), still without any JavaScript: the sample rate converter Resampler, the pipeline AudioBufferDecoder that reuses the audio decoders of AudioDecoders (chosen by the signature of the data) and resamples to the sample rate of the context, and the background service AudioDecodeService that decodes on its own daemon threads, can cancel a request and reports the result through a callback on a thread of the caller's choice. The script layer turns a callback into the resolution of a promise, detaches the ArrayBuffer and moves the callback to the document queue.

decodeAudioData 를 위해 오디오 파일 데이터를 AudioBuffer 로 디코딩하는 부분(계획 P25-05). 아직 JavaScript 와 무관하다. 표본율 변환기 Resampler, AudioDecoders 의 오디오 디코더(데이터의 시그니처로 고른다)를 재사용하고 컨텍스트의 표본율로 리샘플링하는 파이프라인 AudioBufferDecoder, 자기 데몬 스레드에서 디코딩하고 요청을 취소할 수 있으며 호출한 쪽이 고른 스레드에서 콜백으로 결과를 알리는 백그라운드 서비스 AudioDecodeService 로 이루어진다. 스크립트 계층이 콜백을 promise 의 이행으로 바꾸고 ArrayBuffer 를 분리(detach)하며 콜백을 문서 큐로 옮긴다.
