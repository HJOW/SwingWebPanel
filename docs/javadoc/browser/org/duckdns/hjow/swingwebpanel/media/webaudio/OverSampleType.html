public enum OverSampleType
extends java.lang.Enum<OverSampleType>

The OverSampleType of a wave shaper: whether the shaping curve is applied to the input directly or to a signal that is up-sampled to two or four times the sample rate (Web Audio API 1.31, OverSampleType).

웨이브셰이퍼의 OverSampleType: 변환 곡선을 입력에 바로 적용하는지, 샘플링 주파수의 두 배나 네 배로 업샘플링한 신호에 적용하는지(Web Audio API 1.31, OverSampleType).
