org.duckdns.hjow.swingwebpanel.media.webaudio.dsp
Class HrtfRenderer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.HrtfRenderer

public final class HrtfRenderer
extends java.lang.Object

Renders a mono source into the two ears with the HRTF of a direction: the signal is convolved with the left and the right ear kernels of HrtfSet (one FIR filter per ear, with the interaural delay inside the kernel). When the direction changes from one render quantum to the next the output of the old kernels is cross-faded into the output of the new kernels over the quantum, so a moving source makes no clicks; the gain (the distance and cone attenuation) is ramped linearly over the quantum for the same reason. The object keeps the input history, so one renderer belongs to one source.

단일 채널 원천을 방향의 HRTF 로 두 귀에 렌더링한다. 신호를 HrtfSet 의 왼쪽과 오른쪽 귀 커널로 합성곱한다(귀마다 FIR 필터 하나이며 귀 사이의 지연은 커널 안에 있다). render quantum 사이에 방향이 바뀌면 이전 커널의 출력을 quantum 동안 새 커널의 출력으로 크로스페이드하므로 움직이는 음원이 딸깍 소리를 내지 않는다. 같은 이유로 게인(거리와 원뿔 감쇠)도 quantum 동안 선형으로 바뀐다. 객체가 입력 이력을 가지므로 렌더러 하나는 음원 하나에 속한다.
