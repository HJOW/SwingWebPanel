org.duckdns.hjow.swingwebpanel.media.audio.webm
Class WebmFile

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.webm.WebmFile

public final class WebmFile
extends java.lang.Object

A demultiplexer of WebM / Matroska files (EBML, RFC 8794 and the Matroska specification): it reads the segment info (time scale), the audio tracks (codec id, channels, sampling frequency, codec private data, codec delay) and every block of every cluster (SimpleBlock and BlockGroup, with Xiph, EBML and fixed-size lacing), also in files with unknown-size segments and clusters (live style). The frames are kept as positions in the original data, so no frame is copied.

WebM / Matroska 파일(EBML, RFC 8794 와 Matroska 규격)의 역다중화기: 세그먼트 정보(시간 단위), 오디오 트랙(코덱 id, 채널, 샘플링 주파수, 코덱 비공개 데이터, 코덱 지연), 모든 클러스터의 모든 블록(SimpleBlock 과 BlockGroup, Xiph/EBML/고정 크기 레이싱)을 읽으며 크기를 모르는 세그먼트와 클러스터(라이브 방식)가 있는 파일도 다룬다. 프레임은 원본 데이터 안의 위치로 보관하므로 복사하지 않는다.
