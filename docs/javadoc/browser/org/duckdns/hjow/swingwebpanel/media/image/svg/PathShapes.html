Class PathShapes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.svg.PathShapes

public final class PathShapes
extends java.lang.Object

A public entry to the SVG path data parser for code outside of the SVG decoder: it turns the string of a path (the value of the d attribute of an SVG path, or the string of the CSS path() function of clip-path) into a Java2D shape. The parser keeps what it could read up to the first error, so parse(java.lang.String, boolean) reports a path that has no drawing segment at all as invalid (null).

SVG 디코더 밖의 코드를 위한 SVG 경로 데이터 파서의 공개 진입점: 경로 문자열(SVG path 의 d 속성 값, 또는 clip-path 의 CSS path() 함수의 문자열)을 Java2D 도형으로 바꾼다. 파서는 첫 오류까지 읽은 것을 유지하므로 그리는 구간이 하나도 없는 경로는 parse(java.lang.String, boolean) 가 올바르지 않은 것(null)으로 알린다.
