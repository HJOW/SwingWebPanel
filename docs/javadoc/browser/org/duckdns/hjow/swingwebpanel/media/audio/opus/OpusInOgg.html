org.duckdns.hjow.swingwebpanel.media.audio.opus
Class OpusInOgg

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.opus.OpusInOgg

public final class OpusInOgg
extends java.lang.Object

Wraps the Opus track of a WebM/Matroska file into an Ogg Opus stream so that the Ogg Opus decoder can play it: the CodecPrivate of the track is the identification header (OpusHead, RFC 7845 section 5.1; it is rebuilt from the track channels and the CodecDelay if it is missing or damaged), every block is one audio packet, and the granule positions of the pages count the decoded samples, with the DiscardPadding of the last block trimmed from the end. The pre-skip comes from the header (the Matroska CodecDelay is its equivalent in nanoseconds). The file bytes are copied once into the Ogg data.

WebM/Matroska 파일의 Opus 트랙을 Ogg Opus 스트림으로 감싸서 Ogg Opus 디코더가 재생하게 한다: 트랙의 CodecPrivate 는 식별 헤더 (OpusHead, RFC 7845 5.1. 없거나 손상되었으면 트랙의 채널 수와 CodecDelay 로 다시 만든다)이고, 블록 하나가 오디오 패킷 하나이며, 페이지의 그래뉼 위치는 디코딩한 샘플 수를 세고 마지막 블록의 DiscardPadding 은 끝에서 자른다. 사전 건너뛰기는 헤더에서 오며(Matroska 의 CodecDelay 는 그 나노초 표현이다) 파일 바이트는 Ogg 데이터로 한 번 복사한다.
