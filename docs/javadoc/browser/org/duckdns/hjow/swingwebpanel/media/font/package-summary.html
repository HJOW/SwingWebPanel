Package org.duckdns.hjow.swingwebpanel.media.font

Class Summary
Brotli A decoder for the Brotli compressed data format (RFC 7932, https://www.rfc-editor.org/rfc/rfc7932.txt, July 2016), written in plain Java without a library: it reads the stream header and every meta-block (empty and metadata blocks, uncompressed blocks, and compressed blocks with their block types, context maps, prefix codes, insert-and-copy commands, the ring buffer of distances and the static dictionary with its 121 transformations; the tables come from BrotliData, which the tool tools/brotlidict made from the RFC).
Woff2 The decoder of WOFF 2.0 web fonts (plan item P10-08-e, W3C Recommendation "WOFF File Format 2.0", https://www.w3.org/TR/WOFF2/, last modified 2024-08-05, read with tools/webfetch on 2026-11-18): a WOFF2 file holds the tables of an sfnt font in one Brotli stream (Brotli) after a table directory with known-tag codes and variable-length numbers.
 

Exception Summary
BrotliException Thrown by Brotli when compressed data is not valid Brotli (RFC 7932: the stream is "rejected as invalid"), is cut off, or would produce more output than the caller allows.
