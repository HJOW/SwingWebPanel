public final class BmpDecoder
extends java.lang.Object

A pure Java decoder for Windows and OS/2 bitmaps (plan items P18-02, P18-03; FEATURE_MATRIX IMG-05). The same code decodes the device independent bitmaps inside ICO/CUR files (see IcoDecoder).

Supported: BITMAPCOREHEADER (12 bytes), BITMAPINFOHEADER (40), V2/V3 (52, 56), OS/2 v2 (64, without its special compressions), V4 (108) and V5 (124) headers; 1, 4, 8, 16, 24 and 32 bits per pixel; palettes; BI_RGB, BI_BITFIELDS and BI_ALPHABITFIELDS masks of any layout; RLE4 and RLE8; bottom-up and top-down row order. Pixels that an RLE bitmap skips stay transparent. For formats with an alpha channel (32 bits per pixel BI_RGB, or an alpha mask) the alpha values are used, but if every alpha value is 0 the bitmap is treated as opaque (many encoders leave the fourth byte at 0). Compressions BI_JPEG, BI_PNG, Huffman 1D and RLE24 are reported as UNSUPPORTED_FORMAT. The colour space of a V4/V5 header converts the pixels of a BMP file to sRGB (ColorProfile): the calibrated RGB endpoints and gammas (LCS_CALIBRATED_RGB) and an embedded ICC profile (PROFILE_EMBEDDED) of the matrix/TRC or gray kind; sRGB, Windows colour space, a linked profile (a file name) and every unsupported profile leave the samples as sRGB. The bitmaps inside ICO/CUR files are not converted.

Windows 와 OS/2 비트맵을 위한 순수 Java 디코더(계획 P18-02, P18-03; FEATURE_MATRIX IMG-05). ICO/CUR 파일 안의 장치 독립 비트맵도 같은 코드로 디코딩한다(IcoDecoder 참조).

지원: BITMAPCOREHEADER(12바이트), BITMAPINFOHEADER(40), V2/V3(52, 56), OS/2 v2(64, 특수 압축 제외), V4(108), V5(124) 헤더, 픽셀당 1, 4, 8, 16, 24, 32비트, 팔레트, BI_RGB/BI_BITFIELDS/BI_ALPHABITFIELDS 의 임의 배치 마스크, RLE4, RLE8, 아래에서 위/위에서 아래 행 순서. RLE 비트맵이 건너뛴 픽셀은 투명으로 남는다. 알파 채널이 있는 형식(32비트 BI_RGB 또는 알파 마스크)은 알파 값을 쓰되 모든 알파가 0 이면 불투명으로 본다(많은 인코더가 네 번째 바이트를 0 으로 둔다). BI_JPEG, BI_PNG, Huffman 1D, RLE24 압축은 UNSUPPORTED_FORMAT 으로 보고한다. V4/V5 헤더의 색 공간은 BMP 파일의 픽셀을 sRGB 로 바꾼다(ColorProfile): 보정된 RGB 끝점과 감마(LCS_CALIBRATED_RGB), 행렬/TRC 나 회색조 종류의 내장 ICC 프로파일(PROFILE_EMBEDDED). sRGB, Windows 색 공간, 연결된 프로파일(파일 이름), 지원하지 않는 모든 프로파일은 샘플을 sRGB 로 남긴다. ICO/CUR 안의 비트맵은 바꾸지 않는다.
