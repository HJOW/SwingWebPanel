Class FileByteSource

ByteSource
public final class FileByteSource
extends java.lang.Object
implements ByteSource

A ByteSource over a complete file (the temporary file into which a long media resource was spooled, plan item P18-08). Only one window of the file (64 KiB by default) is kept in memory: a read inside the window is a copy, a read outside loads the window that contains it, and a large read goes to the file directly. The length is the file length when the source was opened (the file must not grow afterwards). Thread-safe: all methods are synchronized. close() releases the handle; on Windows a file can be deleted only after every handle of it is closed, which is why the owner (MediaData) closes its sources before it deletes the file.

완성된 파일 위의 ByteSource(긴 미디어 리소스를 받아 둔 임시 파일, 계획 P18-08). 파일의 창 하나(기본 64 KiB)만 메모리에 둔다: 창 안의 읽기는 복사이고, 창 밖의 읽기는 그 위치를 담은 창을 읽어 들이며, 큰 읽기는 파일에서 바로 읽는다. 길이는 원천을 열 때의 파일 길이이다(그 뒤 파일이 자라면 안 된다). 모든 메서드가 동기화되어 스레드 안전하다. close() 는 핸들을 놓는다. Windows 에서는 모든 핸들을 닫아야 파일을 지울 수 있으므로 소유자(MediaData)는 파일을 지우기 전에 원천을 닫는다.
