org.duckdns.hjow.swingwebpanel.media.audio.mp4
Class Mp4Track

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.mp4.Mp4Track

public final class Mp4Track
extends java.lang.Object

One track of an MP4 / ISO base media file: its sample entry (codec, channels, sampling frequency, codec configuration) and the sample table (position, size and duration of every sample), with the edit list start offset. Filled by Mp4File.

MP4 / ISO 기본 미디어 파일의 트랙 하나: 샘플 엔트리(코덱, 채널, 샘플링 주파수, 코덱 구성)와 샘플 표(샘플마다 위치, 크기, 길이), 편집 목록의 시작 오프셋. Mp4File 이 채운다.
