The DistanceModelType of a panner: how the volume of a source falls with the distance from the listener (Web Audio API 1.27).

패너의 DistanceModelType: 청취자와의 거리에 따라 음원의 음량이 줄어드는 방식(Web Audio API 1.27).

Enum Constant Summary
EXPONENTIAL
          Exponential model: the gain falls with a power of the distance, (max(d, dref) / dref) ^ -f.
INVERSE
          Inverse model: the gain is the reference distance over the distance, dref / (dref + f (max(d, dref) - dref)).
LINEAR
          Linear model: the gain falls in a straight line between the two distances, 1 - f (clamp(d, dref', dmax') - dref') / (dmax' - dref').
