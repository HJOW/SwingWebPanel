Class BiquadFilter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.BiquadFilter

public final class BiquadFilter
extends java.lang.Object

The processing of a biquad filter (direct form I, double precision): for every channel it keeps the last two inputs and the last two outputs and applies the coefficients that are given for the block. The coefficients may change from frame to frame (an a-rate parameter that is automated); the caller passes the coefficient arrays of the block and a flag that says whether only the first element is used.

쌍이차 필터의 처리(직접형 I, 배정밀도): 채널마다 마지막 두 입력과 마지막 두 출력을 기억하고 블록에 주어진 계수를 적용한다. 계수는 프레임마다 바뀔 수 있다(자동화되는 a-rate 파라미터). 호출자는 블록의 계수 배열과 첫 요소만 쓰는지 알리는 표시를 넘긴다.
