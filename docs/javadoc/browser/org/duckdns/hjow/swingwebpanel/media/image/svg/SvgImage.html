org.duckdns.hjow.swingwebpanel.media.image.svg
Class SvgImage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.image.svg.SvgImage

public final class SvgImage
extends java.lang.Object

A parsed SVG document that can be drawn at any size (plan item P18-04; FEATURE_MATRIX IMG-07). parse(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) reads the XML with the project's own parser, runs the CSS cascade and computes the natural size; render(java.awt.Graphics2D, int, int) draws the document with Java2D into a box of a requested size (so the image stays sharp when it is shown larger than its natural size), and toDecodedImage() rasterizes it at the natural size for the common image pipeline. The document is immutable after parsing and can be drawn from several threads, each draw uses its own state. Nothing external is loaded: only data: URIs are followed for images, use and paint servers refer to elements of the same document, scripts are never run. The natural size follows the rules of browsers for an SVG used as an image: absolute width/height lengths, otherwise derived from the viewBox ratio, otherwise 300x150 (contained), rounded to whole pixels.

임의의 크기로 그릴 수 있는 해석된 SVG 문서(계획 P18-04; FEATURE_MATRIX IMG-07). parse(byte[], org.duckdns.hjow.swingwebpanel.media.DecodeLimits) 는 자체 파서로 XML 을 읽고 CSS 연쇄를 실행하며 자연 크기를 계산한다. render(java.awt.Graphics2D, int, int) 는 요청한 크기의 상자에 Java2D 로 문서를 그리므로(자연 크기보다 크게 보여도 선명함) 공통 이미지 처리 경로에는 toDecodedImage() 가 자연 크기로 래스터화한다. 해석한 뒤에는 문서가 바뀌지 않으며 여러 스레드가 그릴 수 있고 그릴 때마다 자기 상태를 쓴다. 외부 자원은 읽지 않는다: 이미지는 data: URI 만 따라가고, use 와 페인트 서버는 같은 문서의 요소만 참조하며, 스크립트는 실행하지 않는다. 자연 크기는 이미지로 쓰인 SVG 에 대한 브라우저의 규칙을 따른다: 절대 길이의 width/height, 없으면 viewBox 비율로 유도, 그것도 없으면 300x150(비율 유지), 결과는 정수 픽셀로 반올림한다.

render

public void render(java.awt.Graphics2D target,
                   int width,
                   int height)
            throws MediaException
Draws the document into the box (0, 0, width, height) of a graphics context. The view box and preserveAspectRatio map the document to the box. The drawing is done on an internal image and then copied, so the transform of the target only moves and scales that copy; call with a target at the final scale for the best quality.

그래픽스 문맥의 상자 (0, 0, 너비, 높이)에 문서를 그린다. viewBox 와 preserveAspectRatio 가 문서를 상자에 대응시킨다. 그리기는 내부 이미지에서 한 뒤 복사하므로 대상의 변환은 그 복사본만 옮기고 키운다. 가장 좋은 품질을 위해 최종 배율의 대상으로 호출한다.

Parameters:
target - the graphics context / 그래픽스 문맥
width - box width in pixels (at least 1) / 상자 너비(픽셀, 1 이상)
height - box height in pixels (at least 1) / 상자 높이(픽셀, 1 이상)
Throws:
MediaException - TOO_LARGE if the document is too complex or the box too large, CANCELLED if the thread is interrupted / 문서가 너무 복잡하거나 상자가 너무 크면 TOO_LARGE, 스레드가 인터럽트되면 CANCELLED
