Class DynamicsCompressorKernel

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.dsp.DynamicsCompressorKernel

public final class DynamicsCompressorKernel
extends java.lang.Object

The signal processing of a dynamics compressor (Web Audio API 1.19, section 1.19.4): a look-ahead pre-delay of 6 ms, a peak detector on the undelayed input that is linked across the channels, the static compression curve with a soft knee, an envelope with an attack and an adaptive release, a fixed makeup gain, and the metering of the gain reduction.

The specification fixes the structure and the constraints of the curves and leaves their shape to the implementation. This class follows the design of the Blink implementation (Chromium third_party/blink/renderer/platform/audio/dynamics_compressor.cc, commit 8d101571406d3ef5bda7446b34568192ad99b3b5, read 2026-11-22, BSD license; the notice above is kept because the structure, the constants of the release polynomial and the equations are carried over): an exponential knee whose parameter k is chosen so that the slope after the knee is 1 / ratio, a linear segment in decibels after the knee, an attack rate that depends on the largest gain difference of the attack, a release rate from a fourth-order polynomial of the gain difference (the adaptive release zones), the pre-warp by asin and sin, and the makeup gain (1 / curve(1)) ^ 0.6.

다이내믹 컴프레서의 신호 처리(Web Audio API 1.19, 1.19.4절): 6 ms 의 선행 지연, 채널을 묶은 지연 전 입력의 피크 검출기, 부드러운 무릎이 있는 정적 압축 곡선, 어택과 적응형 릴리즈가 있는 엔벨로프, 고정 메이크업 게인, 이득 감소 측정.

규격은 구조와 곡선의 제약만 정하고 곡선 모양은 구현에 맡긴다. 이 클래스는 Blink 구현(Chromium third_party/blink/renderer/platform/audio/dynamics_compressor.cc, 커밋 8d101571406d3ef5bda7446b34568192ad99b3b5, 2026-11-22 열람, BSD 라이선스. 구조, 릴리즈 다항식의 상수, 식을 가져왔으므로 위의 고지를 유지한다)의 설계를 따른다. 무릎 뒤 기울기가 1 / ratio 가 되도록 매개변수 k 를 고르는 지수 무릎, 무릎 뒤의 데시벨 직선, 어택의 최대 이득 차이에 따른 어택 속도, 이득 차이의 4차 다항식으로 구하는 릴리즈 속도(적응형 릴리즈 구간), asin 과 sin 으로 하는 사전 왜곡, 메이크업 게인 (1 / curve(1)) ^ 0.6 을 따른다.

Compresses a block. The channels of the input are read for every frame (the detector uses the largest absolute value of all channels, so every channel gets the same gain), and the output has the same number of channels.

블록을 압축한다. 프레임마다 입력의 채널을 읽고(검출기는 모든 채널의 절댓값 최댓값을 쓰므로 모든 채널이 같은 게인을 받는다) 출력은 같은 채널 수이다.

Parameters:
in - the input channels / 입력 채널
out - the output channels, as many as the input / 출력 채널(입력과 같은 수)
channels - the number of channels, at most the number given to the constructor / 채널 수(생성자에 준 수 이하)
frames - the number of frames / 프레임 수
thresholdDb - the threshold in decibels / 임계값(dB)
kneeDb - the knee in decibels / 무릎(dB)
newRatio - the ratio / 비율
attackTime - the attack time in seconds / 어택 시간(초)
releaseTime - the release time in seconds / 릴리즈 시간(초)
