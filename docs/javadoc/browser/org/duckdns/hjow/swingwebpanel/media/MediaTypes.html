Class MediaTypes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.MediaTypes

public final class MediaTypes
extends java.lang.Object

Helpers for MIME type strings used by the media decoders: removes parameters, white space and letter case so that a Content-Type value such as Image/PNG; charset=binary can be compared with image/png.

미디어 디코더가 쓰는 MIME 타입 문자열 도우미: 매개변수, 공백, 대소문자를 제거해 Image/PNG; charset=binary 같은 Content-Type 값을 image/png 와 비교할 수 있게 한다.
