Class ArrayByteSource

All Implemented Interfaces:
ByteSource
public final class ArrayByteSource
extends java.lang.Object
implements ByteSource

A ByteSource over a byte array that is already in memory (a short resource, a test, the derived Ogg stream of a small WebM file). The array is not copied and must not be changed while the source is used. Thread-safe (reads only).

이미 메모리에 있는 바이트 배열 위의 ByteSource(짧은 리소스, 시험, 작은 WebM 파일에서 만든 Ogg 스트림). 배열은 복사하지 않으며 원천을 쓰는 동안 바꾸면 안 된다. 읽기만 하므로 스레드 안전하다.
