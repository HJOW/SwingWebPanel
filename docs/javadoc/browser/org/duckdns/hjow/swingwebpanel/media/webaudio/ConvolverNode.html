Class ConvolverNode

  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioNode
      org.duckdns.hjow.swingwebpanel.media.webaudio.ConvolverNode

public final class ConvolverNode
extends AudioNode

A linear convolution effect given an impulse response (Web Audio API 1.17), as used for reverbs. The impulse response is an AudioBuffer of 1, 2 or 4 channels at the sample rate of the context; the input has one or two channels. The convolution has no latency (see PartitionedConvolver) and the node keeps producing output for the length of the response after the input became silent.

Channels: the output is mono only for a mono input and a mono response; in every other case it is stereo. A mono response is applied to every input channel; a stereo response with a mono input gives the left output from the first response channel and the right output from the second; with a stereo input every channel is convolved with its own response channel; a four channel response is the "true stereo" matrix: the left output is L * h0 + R * h2 and the right output is L * h1 + R * h3 (a mono input is used as both L and R).

With normalize true (the default) the response is scaled when the buffer is set so that the loudness of convolutions with different responses is alike: the scale of the specification is 0.00125 / rms * 44100 / sampleRate (halved for four channels), where rms is the root mean square over all samples of the response, at least 0.000125.

임펄스 응답으로 하는 선형 합성곱 효과(Web Audio API 1.17). 리버브에 쓴다. 임펄스 응답은 컨텍스트와 같은 샘플링 주파수의 채널 1, 2, 4개인 AudioBuffer 이고 입력은 채널이 하나나 둘이다. 합성곱은 지연이 없고(PartitionedConvolver 참고) 입력이 무음이 된 뒤에도 응답의 길이만큼 출력을 계속 만든다.

채널: 출력이 모노인 것은 모노 입력과 모노 응답일 때뿐이고 그 밖에는 스테레오이다. 모노 응답은 모든 입력 채널에 적용된다. 모노 입력에 스테레오 응답이면 왼쪽 출력은 첫 응답 채널, 오른쪽 출력은 둘째 응답 채널에서 나온다. 스테레오 입력이면 채널마다 자기 응답 채널과 합성곱한다. 채널 넷인 응답은 "진짜 스테레오" 행렬이다: 왼쪽 출력은 L * h0 + R * h2, 오른쪽 출력은 L * h1 + R * h3 이다(모노 입력은 L 과 R 둘 다로 쓴다).

normalize 가 true(기본)이면 서로 다른 응답으로 한 합성곱의 음량이 비슷해지도록 버퍼를 설정할 때 응답의 크기를 맞춘다. 규격의 배율은 0.00125 / rms * 44100 / sampleRate(채널이 넷이면 절반)이며, rms 는 응답 모든 샘플의 제곱 평균 제곱근(최소 0.000125)이다.

setBuffer

public void setBuffer(AudioBuffer newBuffer)
Sets the impulse response. The content of the buffer is acquired now: later changes of the buffer have no effect, and the state of the convolution starts empty. The normalize flag at this moment decides whether the response is scaled. Setting null makes the node output silence.

임펄스 응답을 설정한다. 버퍼의 내용은 지금 가져간다. 이후 버퍼를 바꿔도 영향이 없고 합성곱의 상태는 빈 채로 시작한다. 이 순간의 normalize 가 응답의 크기를 맞출지 정한다. null 을 설정하면 노드가 무음을 출력한다.

Parameters:
newBuffer - the response, or null / 응답. 없으면 null
Throws:
AudioException - NotSupportedError if the buffer does not have 1, 2 or 4 channels, its sample rate differs from the one of the context, it is longer than ConvolutionKernel.MAX_LENGTH, or the render quantum size of the context is not a power of two / 버퍼의 채널 수가 1, 2, 4 가 아니거나, 샘플링 주파수가 컨텍스트와 다르거나, ConvolutionKernel.MAX_LENGTH 보다 길거나, 컨텍스트의 render quantum 크기가 2 의 거듭제곱이 아니면 NotSupportedError
