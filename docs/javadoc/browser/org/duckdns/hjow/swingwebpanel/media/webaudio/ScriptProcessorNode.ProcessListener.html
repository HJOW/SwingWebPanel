Processes one block: reads the input and writes the output; what the output buffer holds when the method returns is played.

블록 하나를 처리한다: 입력을 읽고 출력을 쓴다. 메서드가 돌아올 때 출력 버퍼에 있는 것이 재생된다.

Parameters:
inputBuffer - the block of the input, with numberOfInputChannels channels, or null if the node has none; valid only during the call / 입력의 블록(numberOfInputChannels 채널). 없으면 null. 호출 동안만 유효
outputBuffer - the buffer to fill, silent at first, with numberOfOutputChannels channels, or null if the node has none / 채울 버퍼. 처음에는 무음이며 numberOfOutputChannels 채널. 없으면 null
playbackTime - the context time in seconds at which the output buffer starts to play / 출력 버퍼가 재생되기 시작하는 컨텍스트 시간(초)
