Interface RealtimeAudioContext.Driver

All Known Implementing Classes:
ClockRenderDriver, OutputRenderDriver
Enclosing class:
RealtimeAudioContext
public static interface RealtimeAudioContext.Driver

Drives the rendering of a real-time context: it calls RealtimeAudioContext.Renderer.renderQuantum() at the pace of its output while it is started. The methods may be called from any thread, one at a time (the context serializes them).

실시간 컨텍스트의 렌더링을 구동한다: 시작된 동안 출력의 속도에 맞춰 RealtimeAudioContext.Renderer.renderQuantum() 을 부른다. 메서드는 어느 스레드에서나 한 번에 하나씩 부를 수 있다(컨텍스트가 직렬화한다).
