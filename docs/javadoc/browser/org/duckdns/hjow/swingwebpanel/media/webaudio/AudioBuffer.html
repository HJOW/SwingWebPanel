org.duckdns.hjow.swingwebpanel.media.webaudio
Class AudioBuffer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.webaudio.AudioBuffer

public final class AudioBuffer
extends java.lang.Object

An in-memory audio asset: linear PCM floats in a number of channels with a sample rate (Web Audio API 1.4). A source node plays it and an offline context renders into it. The channel arrays are live: getChannelData(int) returns the array itself, so the script layer can wrap it without a copy. A playing source node shares the arrays (the specification says it acquires the content at start(); this engine does not copy, so a change of the arrays while the buffer plays is heard).

메모리 안의 오디오 자료: 샘플링 주파수를 가진 여러 채널의 선형 PCM float(Web Audio API 1.4). 원천 노드가 재생하고 오프라인 컨텍스트가 여기에 렌더링한다. 채널 배열은 살아 있다: getChannelData(int) 는 배열 자체를 반환하므로 스크립트 계층이 복사 없이 감쌀 수 있다. 재생 중인 원천 노드는 배열을 공유한다(규격은 start() 때 내용을 획득한다고 하지만 이 엔진은 복사하지 않으므로, 재생 중에 배열을 바꾸면 그 소리가 들린다).

wrap

public static AudioBuffer wrap(float[][] channels,
                               float sampleRate)
Creates a buffer that adopts the given channel arrays (no copy). Used by code that has already produced the samples, such as the audio file decoder, to avoid allocating and copying a second set of arrays. The arrays must not be modified by the caller through a second reference unless it wants the buffer to change.

주어진 채널 배열을 그대로 가져가는(복사하지 않는) 버퍼를 만든다. 오디오 파일 디코더처럼 샘플을 이미 만든 코드가 두 번째 배열 묶음을 할당하고 복사하는 일을 피하려고 쓴다. 버퍼가 바뀌기를 원하는 경우가 아니라면 호출한 쪽은 두 번째 참조로 배열을 수정하지 않아야 한다.

copyFromChannel

public void copyFromChannel(float[] destination,
                            int channelNumber,
                            int bufferOffset)
Copies the samples of a channel into an array, starting at a frame of the channel (copyFromChannel, Web Audio API 1.4.3). With Nb frames in the buffer, Nf elements in the destination and the offset k, exactly max(0, min(Nb - k, Nf)) frames are copied to the start of the destination and the rest of the destination is not modified. An offset at or after the end is therefore not an error: nothing is copied. The two integer arguments stand for WebIDL unsigned long values (a negative Java value is a value of 231 or more).

채널의 샘플을 배열로 복사한다. 채널의 어느 프레임에서 시작할지 정할 수 있다(copyFromChannel, Web Audio API 1.4.3). 버퍼의 프레임이 Nb, 목적지 배열의 원소가 Nf, 시작이 k 이면 정확히 max(0, min(Nb - k, Nf)) 프레임을 목적지의 앞에서부터 복사하고 목적지의 나머지는 바꾸지 않는다. 그래서 시작이 끝과 같거나 그 뒤여도 오류가 아니며 아무것도 복사하지 않는다. 두 정수 인수는 WebIDL unsigned long 값을 뜻한다(음수인 Java 값은 231 이상인 값이다).

Parameters:
destination - the array that receives the samples / 샘플을 받는 배열
channelNumber - the channel index / 채널 인덱스
bufferOffset - the first frame of the channel to copy / 복사할 채널의 첫 프레임
Throws:
AudioException - IndexSizeError if the channel does not exist / 채널이 없으면 IndexSizeError

copyToChannel

public void copyToChannel(float[] source,
                          int channelNumber,
                          int bufferOffset)
Copies the samples of an array into a channel, starting at a frame of the channel (copyToChannel, Web Audio API 1.4.3). With Nb frames in the buffer, Nf elements in the source and the offset k, exactly max(0, min(Nb - k, Nf)) frames are copied from the start of the source and the rest of the buffer is not modified; elements of the source that do not fit are ignored and an offset at or after the end copies nothing. The two integer arguments stand for WebIDL unsigned long values (a negative Java value is a value of 231 or more).

배열의 샘플을 채널로 복사한다. 채널의 어느 프레임에서 시작할지 정할 수 있다(copyToChannel, Web Audio API 1.4.3). 버퍼의 프레임이 Nb, 원본 배열의 원소가 Nf, 시작이 k 이면 정확히 max(0, min(Nb - k, Nf)) 프레임을 원본의 앞에서부터 복사하고 버퍼의 나머지는 바꾸지 않는다. 들어가지 않는 원본 원소는 무시하고 시작이 끝과 같거나 그 뒤이면 아무것도 복사하지 않는다. 두 정수 인수는 WebIDL unsigned long 값을 뜻한다(음수인 Java 값은 231 이상인 값이다).

Parameters:
source - the array with the samples / 샘플이 든 배열
channelNumber - the channel index / 채널 인덱스
bufferOffset - the first frame of the channel to overwrite / 덮어쓸 채널의 첫 프레임
Throws:
AudioException - IndexSizeError if the channel does not exist / 채널이 없으면 IndexSizeError
