One packet of a logical Ogg bitstream, reassembled from the segments of one or more pages.

getGranule

public long getGranule()
Returns the granule position of the page if this packet is the last one that ends on it, else -1. Its meaning depends on the codec (for Vorbis: the number of PCM frames up to the end of this packet).

이 패킷이 페이지에서 끝나는 마지막 패킷이면 그 페이지의 그래뉼 위치를, 아니면 -1 을 반환한다. 의미는 코덱마다 다르다(Vorbis 는 이 패킷의 끝까지의 PCM 프레임 수).

Returns:
granule position or -1 / 그래뉼 위치 또는 -1

isLast

public boolean isLast()
Tells whether this packet is the last one of the logical bitstream (it ends on a page flagged as the end of the stream).

이 패킷이 논리 비트스트림의 마지막 패킷인지(스트림 끝으로 표시된 페이지에서 끝나는지) 알려 준다.
