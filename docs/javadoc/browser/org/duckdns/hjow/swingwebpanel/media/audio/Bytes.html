org.duckdns.hjow.swingwebpanel.media.audio
Class Bytes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.media.audio.Bytes

public final class Bytes
extends java.lang.Object

Helpers to read integers of a given byte order from a byte array, with overflow-safe range checks. Decoders use them for headers; reading outside the array is never silently allowed: callers check has(byte[], int, int) first.

바이트 배열에서 지정한 바이트 순서의 정수를 읽는 도우미이며 범위 검사는 오버플로 없이 한다. 디코더가 헤더를 읽을 때 쓴다. 배열 밖을 조용히 읽지 않으므로 호출자는 먼저 has(byte[], int, int) 로 확인한다.
