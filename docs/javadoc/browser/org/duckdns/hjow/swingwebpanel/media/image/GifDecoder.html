public final class GifDecoder
extends java.lang.Object

A pure Java decoder for GIF87a and GIF89a including animation (plan items P18-02, P18-03; FEATURE_MATRIX IMG-03).

It decodes the LZW data itself and composes every frame onto the logical screen. Supported: global and local colour tables, transparency (graphic control extension), interlaced frames, disposal methods 0 to 3 (methods 4 to 7 are treated like 0), the NETSCAPE2.0 loop extension (a loop count N gives N + 1 plays, no extension gives one play, 0 means forever). Decisions: a frame delay of 10 ms or less (including 0) is replaced by 100 ms like browsers do; "restore to background" clears to transparent, not to the background colour; the canvas is the logical screen, enlarged to the extent of the first frame when that is larger or when the screen size is 0, and later frames are clipped to it; a palette index outside the colour table is transparent; a frame whose data ends early (end code before all pixels) keeps the pixels that were decoded; a file that ends in the middle of a frame drops that frame and keeps the complete ones (CORRUPT if there is none); a missing trailer is tolerated.

GIF87a 와 GIF89a(애니메이션 포함)를 위한 순수 Java 디코더(계획 P18-02, P18-03; FEATURE_MATRIX IMG-03).

LZW 데이터를 직접 풀고 모든 프레임을 논리 화면에 합성한다. 지원: 전역/지역 색 표, 투명도(그래픽 제어 확장), 인터레이스 프레임, 처리 방법 0~3(4~7 은 0 처럼 다룸), NETSCAPE2.0 반복 확장(반복 횟수 N 은 N + 1 번 재생, 확장이 없으면 한 번, 0 이면 무한). 결정: 프레임 지연이 10 ms 이하 (0 포함)이면 브라우저처럼 100 ms 로 바꾼다. "배경으로 복원"은 배경색이 아니라 투명으로 지운다. 캔버스는 논리 화면이며 첫 프레임의 범위가 더 크거나 화면 크기가 0 이면 첫 프레임 범위로 넓히고 이후 프레임은 캔버스에 맞춰 자른다. 색 표 밖의 팔레트 인덱스는 투명이다. 데이터가 일찍 끝난 프레임(모든 픽셀 전에 종료 코드)은 디코딩된 픽셀을 유지한다. 프레임 중간에서 끝난 파일은 그 프레임을 버리고 완전한 프레임만 유지한다(하나도 없으면 CORRUPT). 트레일러가 없는 것은 허용한다.
