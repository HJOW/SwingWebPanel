Class CssStyleSource

java.lang.Object

All Implemented Interfaces:
ContainerSource, CounterStyleSource, PositionTrySource, StyleSource
public final class CssStyleSource
extends java.lang.Object
implements StyleSource, ContainerSource, CounterStyleSource, PositionTrySource

A StyleSource on top of the CSS engine: computed styles come from the cascade of CssEngine (user-agent, author and inline styles, media queries, ::before/::after rules).

CSS 엔진 위의 StyleSource: 계산 스타일은 CssEngine 의 캐스케이드(사용자 에이전트, 작성자, 인라인 스타일, 미디어 질의, ::before/::after 규칙)에서 온다.
