Class ClipPaths

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.ClipPaths

public final class ClipPaths
extends java.lang.Object

The shape of clip-path (plan items P10-08, CSS Masking Level 1 section 5 "Clipping paths", https://www.w3.org/TR/css-masking-1/, Candidate Recommendation Draft 2021-08-05, retrieved 2026-11-17, and CSS Shapes Level 1 section 3 for the basic shapes): the basic shapes inset() (with round and one to four radii per axis like border-radius), circle(), ellipse(), polygon() (with nonzero and evenodd), rect(), xywh() and path() (SVG path data with nonzero or evenodd), with the reference boxes border-box (the default), padding-box, content-box and margin-box (fill-box is the content box, stroke-box and view-box are the border box). A reference box alone clips to the (square) edge of that box. The shape is a Shape in document coordinates; everything outside of it is neither painted nor hit (CSS Masking 1 section 5.1). A url() reference to an SVG clipPath, shape() and a path() without a drawing segment are not supported: such a declaration clips nothing. A box with clip-path other than none is a stacking context (like opacity) and the containing block of its fixed and absolutely positioned descendants.

clip-path 의 모양(계획 P10-08, CSS Masking Level 1 5 절 "Clipping paths", https://www.w3.org/TR/css-masking-1/, Candidate Recommendation Draft 2021-08-05, 조회 2026-11-17, 기본 도형은 CSS Shapes Level 1 3 절): 기본 도형 inset()(round 와 border-radius 처럼 축마다 1~4 개 반지름), circle(), ellipse(), polygon()(nonzero, evenodd), rect(), xywh(), path()(SVG 경로 데이터, nonzero 나 evenodd)과 기준 상자 border-box(기본), padding-box, content-box, margin-box(fill-box 는 content 상자, stroke-box 와 view-box 는 border 상자). 기준 상자만 쓰면 그 상자의 (각진) 가장자리로 자른다. 모양은 문서 좌표의 Shape 이며 그 밖은 그려지지도 히트되지도 않는다(CSS Masking 1 5.1 절). SVG clipPath 를 가리키는 url(), shape(), 그리는 구간이 없는 path() 는 지원하지 않으며 그런 선언은 아무것도 자르지 않는다. clip-path 가 none 이 아닌 상자는 (opacity 처럼) 쌓임 맥락이며 자신의 fixed 와 절대 배치 자손의 포함 블록이다.
