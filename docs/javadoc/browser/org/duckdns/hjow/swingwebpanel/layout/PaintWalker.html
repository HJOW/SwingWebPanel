org.duckdns.hjow.swingwebpanel.layout
Class PaintWalker

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.PaintWalker

public final class PaintWalker
extends java.lang.Object

Walks the box tree in the painting order of CSS 2.1 Appendix E (plan item P10-01) and reports what is to be painted to a PaintWalker.Visitor. The renderer builds its display list from this walk and the hit test uses the same walk in reverse, so what is on top on the screen is also what a click finds.

A stacking context (the root, a positioned box with an integer z-index, a fixed box, a box with opacity below 1, a box with a transform; see LayoutBox.isStackingContext()) paints in this order: its own background and border, the stacking contexts of its descendants with a negative z-index (in order of z-index, then tree order), the backgrounds and borders of the in-flow block-level descendants (in tree order), the floats (each as a whole, in tree order), the inline content of the in-flow descendants (lines, text, list markers, replaced content, inline blocks as a whole), the positioned descendants with z-index auto or 0 and the contexts with 0 (in tree order) and last the contexts with a positive z-index. A float, an inline block and a positioned box with z-index:auto is painted as a whole as if it formed a stacking context, except that its positioned descendants and the contexts inside it belong to the enclosing stacking context, which paints them in its own order. overflow other than visible clips the descendants whose containing block chain contains the box (an absolutely positioned box is not clipped by an ancestor that is not its containing block); clip: rect() clips an absolutely positioned box itself; position:fixed boxes are reported inside a fixed group so that the renderer can keep them in place when the page scrolls.

상자 트리를 CSS 2.1 부록 E 의 그리기 순서로 훑으며 그릴 것을 PaintWalker.Visitor 에 알린다(계획 P10-01). 렌더러는 이 순회로 디스플레이 리스트를 만들고 히트 테스트는 같은 순회를 거꾸로 쓰므로 화면에서 맨 위에 있는 것을 클릭도 찾는다.

쌓임 맥락(루트, 정수 z-index 를 가진 위치 지정 상자, fixed 상자, opacity 가 1 보다 작은 상자, transform 이 있는 상자. LayoutBox.isStackingContext() 참조)은 이 순서로 그린다: 자신의 배경과 border, z-index 가 음수인 자손 맥락(z-index, 그다음 트리 순서), 정상 흐름 블록 수준 자손의 배경과 border(트리 순서), float(각각 통째로, 트리 순서), 정상 흐름 자손의 인라인 콘텐츠(줄, 텍스트, 목록 표식, 치환 콘텐츠, inline-block 은 통째로), z-index 가 auto 이거나 0 인 위치 지정 자손과 0 인 맥락(트리 순서), 마지막으로 z-index 가 양수인 맥락. float, inline-block, z-index:auto 인 위치 지정 상자는 쌓임 맥락을 만드는 것처럼 통째로 그리되 그 안의 위치 지정 자손과 맥락은 둘러싼 쌓임 맥락에 속하며 그 맥락이 자기 순서로 그린다. overflow 가 visible 이 아니면 포함 블록 사슬에 그 상자가 있는 자손을 자른다(절대 배치 상자는 자신의 포함 블록이 아닌 조상에게는 잘리지 않는다). clip: rect() 는 절대 배치 상자 자신을 자른다. position:fixed 상자는 fixed 그룹 안에서 알려 주므로 렌더러가 페이지가 스크롤되어도 제자리에 둘 수 있다.
