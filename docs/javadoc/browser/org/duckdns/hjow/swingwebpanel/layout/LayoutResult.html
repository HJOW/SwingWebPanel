org.duckdns.hjow.swingwebpanel.layout
Class LayoutResult

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.LayoutResult

public final class LayoutResult
extends java.lang.Object

The result of a layout run (plan items P09-01, P09-02, P09-03): the root of the box tree, the size of the whole document for preferredSize, the map from DOM nodes to their boxes and hit testing. Nothing in a result changes after LayoutEngine.layout(org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.layout.StyleSource, org.duckdns.hjow.swingwebpanel.layout.ReplacedResolver, double, double) has returned, so it can be handed to the event dispatch thread and painted there while the document thread lays out the next version.

레이아웃 실행의 결과(계획 P09-01, P09-02, P09-03): 상자 트리의 루트, preferredSize 를 위한 문서 전체 크기, DOM 노드에서 상자로의 대응, hit testing. LayoutEngine.layout(org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.layout.StyleSource, org.duckdns.hjow.swingwebpanel.layout.ReplacedResolver, double, double) 이 돌아온 뒤 결과의 어떤 것도 바뀌지 않으므로 이벤트 디스패치 스레드에 넘겨 그리고 그동안 문서 스레드가 다음 판을 배치할 수 있다.

boxAt

public LayoutBox boxAt(double x,
                       double y)
Finds the topmost box at a point (document coordinates): the last box in painting order (CSS 2.1 Appendix E: positive z-index contexts above the positioned boxes, above the inline content, above the floats, above the block backgrounds, above the negative contexts) that contains the point. A box that is clipped by an ancestor (overflow other than visible, clip: rect()) is found only inside the clip, and boxes with visibility:hidden or pointer-events:none are never found. Fixed boxes are looked up as if the page were not scrolled; see boxAt(double, double, double, double).

점(문서 좌표)의 가장 위 상자를 찾는다: 점을 포함하는 그리기 순서(CSS 2.1 부록 E: 양수 z-index 맥락이 위치 지정 상자 위, 그것이 인라인 콘텐츠 위, 그것이 float 위, 그것이 블록 배경 위, 그것이 음수 맥락 위)의 마지막 상자. 조상에게 잘린 상자(overflow 가 visible 이 아님, clip: rect())는 자르기 안에서만 찾고 visibility:hidden 이나 pointer-events:none 인 상자는 찾지 않는다. fixed 상자는 페이지가 스크롤되지 않은 것으로 찾는다. boxAt(double, double, double, double) 참조.

Parameters:
x - x in document coordinates / 문서 좌표 x
y - y in document coordinates / 문서 좌표 y
Returns:
the box or null / 상자 또는 null

boxAt

public LayoutBox boxAt(double x,
                       double y,
                       double scrollX,
                       double scrollY)
Finds the topmost box at a point of the document while the page is scrolled: boxes of position:fixed stay at the same place of the viewport, so the point is compared with them after the scroll offset is subtracted.

페이지가 스크롤된 상태에서 문서의 점의 가장 위 상자를 찾는다: position:fixed 상자는 뷰포트의 같은 자리에 머무르므로 스크롤 오프셋을 뺀 점을 그 상자와 비교한다.

Parameters:

the box or null / 상자 또는 null
