org.duckdns.hjow.swingwebpanel.layout
Class LayoutBox

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.LayoutBox

public final class LayoutBox
extends java.lang.Object

A box of the layout tree (plan item P09-01). The layout tree is separate from the DOM: display:none elements have no box, anonymous boxes exist where CSS needs them, text is split into line fragments and every box keeps the DOM node it came from for hit testing. After LayoutEngine.layout(org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.layout.StyleSource, org.duckdns.hjow.swingwebpanel.layout.ReplacedResolver, double, double) returns, a box never changes again, so a renderer on another thread can read the tree while the document thread builds the next one.

Geometry: all values are CSS pixels in document coordinates (the origin is the top-left corner of the page, scrolling is the renderer's job). getX()/getY()/getWidth()/getHeight() describe the border box; the margin, border and padding widths are the used values, so the padding box, content box and margin box follow by addition. Line boxes (LayoutBox.Type.LINE) span the content width of their block; fragments (LayoutBox.Type.TEXT, LayoutBox.Type.INLINE, atomic inline boxes) are children of the line. The children of a box are listed in paint order for in-flow content (a renderer paints a box, then its children).

레이아웃 트리의 상자(계획 P09-01). 레이아웃 트리는 DOM 과 분리되어 있다: display:none 요소는 상자가 없고, CSS 가 필요로 하는 곳에는 익명 상자가 있으며, 텍스트는 줄 조각으로 나뉘고, 모든 상자는 hit testing 을 위해 자신이 나온 DOM 노드를 가진다. LayoutEngine.layout(org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.layout.StyleSource, org.duckdns.hjow.swingwebpanel.layout.ReplacedResolver, double, double) 이 돌아온 뒤 상자는 다시 바뀌지 않으므로 다른 스레드의 렌더러가 읽는 동안 문서 스레드가 다음 트리를 만들 수 있다.

기하: 모든 값은 문서 좌표(원점은 페이지의 왼쪽 위, 스크롤은 렌더러의 몫)의 CSS 픽셀이다. getX()/getY()/getWidth()/ getHeight() 는 border box 를 나타내며 margin, border, padding 너비는 사용 값이므로 padding box, content box, margin box 는 더해서 얻는다. 줄 상자(LayoutBox.Type.LINE)는 블록의 콘텐츠 너비에 걸치고 조각(LayoutBox.Type.TEXT, LayoutBox.Type.INLINE, 원자적 인라인 상자)은 줄의 자식이다. 정상 흐름 콘텐츠의 자식은 그리기 순서로 나열되어 있다(렌더러는 상자를 그린 뒤 자식을 그린다).

Returns the computed style of the ::placeholder pseudo-element of a text field or a text area (the color of the placeholder text), or null for the other boxes.

텍스트 필드나 텍스트 영역의 ::placeholder 의사 요소의 계산 스타일(placeholder 글의 색)을 반환한다. 다른 상자는 null.

Returns:
the style or null / 스타일. 없으면 null

getMarkerImage

public CssValue getMarkerImage()
Returns the image that a MARKER box shows (list-style-image), or null for a text marker.

MARKER 상자가 보여 주는 이미지(list-style-image)를 반환한다. 텍스트 표식이면 null.

Returns:
the image value or null / 이미지 값 또는 null

getFileButtonStyle

public ComputedStyle getFileButtonStyle()
Returns the computed style of the ::file-selector-button pseudo-element of a file control (the button that the painter draws), or null if no rule targets it or the box is not a file control.

파일 컨트롤의 ::file-selector-button 의사 요소(그리는 쪽이 그리는 단추)의 계산 스타일을 반환한다. 그것을 가리키는 규칙이 없거나 파일 컨트롤이 아니면 null.

Returns:
the style or null / 스타일. 없으면 null

getFileButtonDeclared

public java.util.BitSet getFileButtonDeclared()
Returns the properties that the rules of ::file-selector-button declare (the painter keeps its own look for the others), or null.

::file-selector-button 규칙이 선언하는 속성을 반환한다(그리는 쪽은 나머지 속성에 대해 자신의 모양을 지킨다). 없으면 null.

Returns:
a copy of the property ids, or null / 속성 id 의 복사본. 없으면 null
