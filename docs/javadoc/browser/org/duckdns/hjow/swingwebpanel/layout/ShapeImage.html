org.duckdns.hjow.swingwebpanel.layout
Class ShapeImage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.ShapeImage

public final class ShapeImage
extends java.lang.Object

The alpha channel of an image that gives the float area of a float whose shape-outside is an image (CSS Shapes Module Level 1 section 4 "Shapes from Image", https://www.w3.org/TR/css-shapes-1/#shapes-from-image): the width and the height in image pixels and one alpha value from 0 (transparent) to 255 (opaque) for every pixel in row order. The layout reads only this mask, never the colors, and the mask is immutable once it was built.

shape-outside 가 이미지인 float 의 float 영역을 주는 이미지의 알파 채널(CSS Shapes Module Level 1 4 절 "Shapes from Image", https://www.w3.org/TR/css-shapes-1/#shapes-from-image): 이미지 픽셀 단위의 너비와 높이, 행 순서로 놓인 픽셀마다의 알파 값(0 투명 ~ 255 불투명). 레이아웃은 이 마스크만 읽고 색은 읽지 않으며, 만든 뒤에는 바뀌지 않는다.
