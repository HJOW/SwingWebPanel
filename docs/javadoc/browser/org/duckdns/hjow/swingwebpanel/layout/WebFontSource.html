Interface WebFontSource

All Known Implementing Classes:
WebFontSet
public interface WebFontSource

The web fonts of a page for the layout (plan item P10-05, CSS Fonts Level 3 @font-face): the font resolver asks it for every family name of font-family before it looks for an installed font of that name. An implementation answers with the font of a loaded @font-face of that family, or null if the family is not a web font family, the font is still loading (the text then uses the next family, as with font-display: swap), failed, or does not cover the text.

레이아웃을 위한 페이지의 웹 글꼴(계획 P10-05, CSS Fonts Level 3 @font-face): 글꼴 리졸버는 font-family 의 패밀리 이름마다 그 이름의 설치된 글꼴을 찾기 전에 이것에 묻는다. 구현은 그 패밀리의 읽힌 @font-face 글꼴로 답하거나, 패밀리가 웹 글꼴 패밀리가 아니거나 글꼴을 아직 읽는 중이거나(그러면 텍스트는 font-display: swap 처럼 다음 패밀리를 쓴다) 실패했거나 텍스트를 덮지 못하면 null 로 답한다.

blockedUntil

long blockedUntil(java.lang.String family,
                  int weight,
                  boolean italic,
                  java.lang.String text)
Tells until when a text that asks for a family must be invisible: the face that would show it is still loading and in the block period of its font-display (CSS Fonts 4 section 4.8). The font resolver asks after find(java.lang.String, int, boolean, java.lang.String, float) returned null; a blocked text is laid out with the next family that is available and is not painted.

패밀리를 요청한 텍스트가 언제까지 보이지 않아야 하는지 알려 준다: 그 텍스트를 보일 면이 아직 읽는 중이고 font-display 의 block 기간에 있을 때이다(CSS Fonts 4 4.8 절). 글꼴 리졸버는 find(java.lang.String, int, boolean, java.lang.String, float) 가 null 을 반환한 뒤에 묻는다. 막힌 텍스트는 쓸 수 있는 다음 패밀리로 배치하고 그리지 않는다.

Parameters:
family - the family name of font-family / font-family 의 패밀리 이름
weight - the requested weight, 100 to 900 / 요청한 굵기. 100~900
italic - true for an italic or oblique style / 이탤릭이나 oblique 스타일이면 true
text - the text that the font has to show, may be null / 글꼴이 보여야 하는 텍스트. null 가능
Returns:
the end of the block period in milliseconds of the system clock, or 0 if the text is not blocked / block 기간의 끝(시스템 시계 ms). 막히지 않았으면 0
