Class StickyConstraint

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.StickyConstraint

public final class StickyConstraint
extends java.lang.Object

The geometry that decides how far a position:sticky box is shifted while the page scrolls (CSS Positioned Layout Module Level 3, section 3.4 "Sticky positioning", https://www.w3.org/TR/css-position-3/#sticky-pos). The layout puts a sticky box where it would be in the normal flow; what is shifted is the painting and the hit test: for each side with an top/right/bottom/left inset that is not auto, a box whose border edge would be outside the sticky view rectangle (the viewport inset by that value) is moved inward of that edge as far as it can while its margin box (the "position box") stays inside the content box of its containing block. When the box is too large for both insets of one axis, the start edge wins (top; left, or right in a right-to-left box). The shift is computed from the viewport rectangle, which is given in the coordinates of the box (so an ancestor transform is taken into account by the caller).

Documented limits: the nearest scroll container is always the viewport. The engine has no scrolling overflow boxes (those clip only; see EXC-13), so a box inside an overflow box other than visible is never shifted (its scroll container does not scroll); inline (non-atomic) boxes are not shifted; the geometry queries of the DOM (getBoundingClientRect) and the highlight of a text selection report the unshifted position.

페이지가 스크롤될 때 position:sticky 상자를 얼마나 옮길지 정하는 기하(CSS Positioned Layout Module Level 3 3.4 절 "Sticky positioning"). 레이아웃은 sticky 상자를 정상 흐름에서의 자리에 두고, 옮기는 것은 그리기와 히트 테스트이다: top/right/bottom/left 가 auto 가 아닌 변마다, border 가장자리가 sticky 뷰 사각형(그 값만큼 줄인 뷰포트) 밖에 나가게 될 상자를 그 가장자리 안쪽으로, 마진 상자("위치 상자")가 포함 블록의 콘텐츠 상자 안에 머무는 한도까지 옮긴다. 한 축의 두 값을 모두 만족시킬 수 없을 만큼 상자가 크면 시작 가장자리(위쪽, 왼쪽. 오른쪽에서 왼쪽 상자는 오른쪽)가 이긴다. 옮김은 상자의 좌표로 준 뷰포트 사각형에서 계산한다(조상의 변환은 호출자가 반영한다).

문서화된 한계: 가장 가까운 스크롤 컨테이너는 항상 뷰포트이다. 이 엔진에는 스크롤하는 overflow 상자가 없으므로(자르기만 함. EXC-13 참조) visible 이 아닌 overflow 상자 안의 상자는 옮기지 않는다(그 스크롤 컨테이너는 스크롤되지 않는다). 인라인(원자적이 아닌) 상자는 옮기지 않으며, DOM 의 기하 조회(getBoundingClientRect)와 텍스트 선택 강조는 옮기기 전 위치를 알려 준다.
