org.duckdns.hjow.swingwebpanel.layout
Class Woff

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.Woff

public final class Woff
extends java.lang.Object

The decoder of WOFF 1.0 web fonts (plan item P10-05, https://www.w3.org/TR/WOFF/, W3C Recommendation 2012-12-13): a WOFF file is an sfnt (TrueType or OpenType) font whose tables are compressed one by one with zlib. toSfnt(byte[]) rebuilds the plain sfnt file with Inflater (a public JRE class), so that the font can be read like a TrueType font. The header, the table directory (offsets, lengths, the order of the tables, the size limits, the decompressed lengths) are checked; a table whose compressed length equals the original length is stored without compression. The metadata and private blocks are ignored. WOFF 2 (Brotli) is another format with another signature: it is read by Woff2 and isWoff2(byte[]) only detects it.

WOFF 1.0 웹 글꼴 디코더(계획 P10-05, https://www.w3.org/TR/WOFF/, W3C 권고안 2012-12-13): WOFF 파일은 테이블마다 zlib 로 압축한 sfnt(TrueType 또는 OpenType) 글꼴이다. toSfnt(byte[]) 는 JRE 공개 클래스 Inflater 로 압축을 풀어 평범한 sfnt 파일을 다시 만들므로 TrueType 글꼴처럼 읽을 수 있다. 헤더와 테이블 디렉터리(오프셋, 길이, 테이블 순서, 크기 한도, 풀린 길이)를 검사한다. 압축 길이가 원래 길이와 같은 테이블은 압축하지 않고 저장한 것이다. 메타데이터와 비공개 블록은 무시한다. WOFF 2(Brotli)는 서명이 다른 별개의 형식이며 Woff2 가 읽고 isWoff2(byte[]) 는 알아내기만 한다.
