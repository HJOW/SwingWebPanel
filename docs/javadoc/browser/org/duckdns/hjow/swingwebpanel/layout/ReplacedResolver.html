Interface ReplacedResolver

All Known Implementing Classes:
ImageReplacedResolver
public interface ReplacedResolver

Tells the layout engine what external content a replaced element has (the loaded image, the media placeholder, the form control ...). Elements that the engine treats as replaced (img video audio canvas iframe embed object input select textarea svg) fall back to their width/height attributes and to built-in default sizes when the resolver returns null.

치환 요소가 가진 외부 콘텐츠(읽은 이미지, 미디어 표시, 폼 컨트롤 등)를 레이아웃 엔진에 알려 준다. 엔진이 치환 요소로 다루는 요소(img video audio canvas iframe embed object input select textarea svg)는 리졸버가 null 을 돌려주면 width/height 속성과 내장 기본 크기를 쓴다.
