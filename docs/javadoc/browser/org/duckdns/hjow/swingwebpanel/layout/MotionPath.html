Class MotionPath

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.MotionPath

public final class MotionPath
extends java.lang.Object

The offset transform of CSS Motion Path Module Level 1 (https://www.w3.org/TR/motion-1/, W3C Working Draft 5 November 2024): offset-path (path(), circle(), ellipse(), inset(), rect(), xywh(), polygon(), ray() and a reference box alone), offset-distance, offset-position, offset-anchor and offset-rotate. A box with an offset path is placed so that its anchor point is on the point of the path that offset-distance gives, and it is rotated about that point (2.7 of the specification); the transform takes part in the transform of the box in the order of CSS Transforms Level 2 (translate, rotate, scale, the offset transform, transform), so that the box is a stacking context and the containing block of its fixed and absolutely positioned descendants like any transformed box, and hit testing follows the moved box.

The path is the equivalent path of the shape (section 3): a circle or ellipse starts at its rightmost point and runs clockwise, a rectangle starts at the left end of the top edge and runs clockwise, a polygon and a path() follow their own points. The reference box is the border box of the box that establishes the containing block. The used distance is the distance modulo the length of a closed path, clamped for an open path, and not limited for a ray() without contain (2.2.1).

offset-path 가 있는 상자는 앵커 점이 offset-distance 가 주는 경로 위의 점에 오도록 놓이고 그 점을 중심으로 회전한다(규격 2.7). 변환은 CSS Transforms Level 2 의 순서(translate, rotate, scale, 오프셋 변환, transform)로 상자의 변환에 참여하므로 상자는 다른 변환된 상자처럼 쌓임 맥락이고 fixed 와 절대 배치 자손의 포함 블록이며, 히트 테스트는 옮겨진 상자를 따른다. 경로는 도형의 동등한 경로(3 절)이다: 원과 타원은 가장 오른쪽 점에서 시계 방향으로, 직사각형은 윗변의 왼쪽 끝에서 시계 방향으로 시작하고, 다각형과 path() 는 자신의 점을 따른다. 기준 상자는 포함 블록을 만드는 상자의 border box 이다. 실제 거리는 닫힌 경로에서는 길이로 나눈 나머지, 열린 경로에서는 한정한 값이며 contain 없는 ray() 는 제한이 없다(2.2.1).

boxTransform

public static java.awt.geom.AffineTransform boxTransform(LayoutBox b)
Returns the transform of a box with an offset path in document coordinates: the individual transform properties, the offset transform and the transform property in the order of CSS Transforms Level 2, each about the transform-origin of the box. The geometry of the box and of its containing block must be final.

오프셋 경로가 있는 상자의 문서 좌표 변환을 반환한다: 개별 변환 속성, 오프셋 변환, transform 속성을 CSS Transforms Level 2 의 순서로, 각각 상자의 transform-origin 둘레에서. 상자와 그 포함 블록의 기하가 확정되어 있어야 한다.

Parameters:
b - the box / 상자
Returns:
the transform, or null if the box has no usable offset path / 변환. 쓸 수 있는 오프셋 경로가 없으면 null
