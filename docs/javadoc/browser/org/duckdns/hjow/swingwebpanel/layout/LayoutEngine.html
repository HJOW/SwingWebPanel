org.duckdns.hjow.swingwebpanel.layout
Class LayoutEngine

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.LayoutEngine

public final class LayoutEngine
extends java.lang.Object

The layout engine (plan items P09-01, P09-02, P09-03): turns a DOM document and the computed styles into a tree of boxes with coordinates, see LayoutBox and LayoutResult. The engine is stateless; every call builds a new result from scratch (a full relayout), so a width change is handled by calling it again with the new viewport width. The caller (the document thread) decides when to relayout: only when the viewport width, the DOM, the styles or the replaced content changed, never from inside a layout callback, so relayout cannot loop.

Threading: the call reads the DOM and the styles and must run on the thread that owns the document (it blocks the caller). The work is done on a helper thread with a large stack, because block nesting up to BoxBuilder.MAX_DEPTH levels is laid out recursively; the helper never writes to the document. The returned LayoutResult is immutable by convention and may be read on any thread. Layout cannot be cancelled while it runs.

Floats, clear, relative, absolute and fixed positioning, stacking order and clipping are implemented (P10-01); position:sticky is laid out like position:relative without an offset (no scroll-dependent shift). Tables (P10-02), flex containers, multi-column containers, grid containers and vertical writing modes (P10-03, see FlexLayouter, MulticolLayouter, GridLayouter and OrthogonalLayouter) are implemented.

레이아웃 엔진(계획 P09-01, P09-02, P09-03): DOM 문서와 계산 스타일을 좌표를 가진 상자 트리로 바꾼다(LayoutBox, LayoutResult 참고). 엔진은 상태가 없고 호출마다 새 결과를 처음부터 만든다(전체 재배치). 너비 변화는 새 뷰포트 너비로 다시 호출해서 처리한다. 재배치 시점은 호출자(문서 스레드)가 정한다: 뷰포트 너비, DOM, 스타일, 치환 콘텐츠가 바뀌었을 때만 하며 레이아웃 콜백 안에서는 하지 않으므로 재배치가 반복되지 않는다.

스레드: 호출은 DOM 과 스타일을 읽으며 문서를 소유한 스레드에서 실행해야 한다(호출자를 막는다). BoxBuilder.MAX_DEPTH 단계까지의 블록 중첩을 재귀로 배치하므로 큰 스택을 가진 보조 스레드에서 작업하며 보조 스레드는 문서에 쓰지 않는다. 반환된 LayoutResult 는 관례상 불변이며 어느 스레드에서나 읽을 수 있다. 실행 중인 레이아웃은 취소할 수 없다.

float, clear, 상대/절대/고정 배치, 쌓임 순서, 자르기를 구현했다(P10-01). position:sticky 는 오프셋이 없는 position:relative 처럼 배치한다(스크롤에 따라 움직이지 않음). 표(P10-02), 플렉스 컨테이너, 다단 컨테이너, 그리드 컨테이너, 세로 쓰기 모드(P10-03, FlexLayouter, MulticolLayouter, GridLayouter, OrthogonalLayouter 참조)는 구현했다.
