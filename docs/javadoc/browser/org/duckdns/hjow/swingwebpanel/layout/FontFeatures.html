org.duckdns.hjow.swingwebpanel.layout
Class FontFeatures

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.FontFeatures

public final class FontFeatures
extends java.lang.Object

The OpenType features that a style asks for (CSS Fonts Level 4, https://www.w3.org/TR/css-fonts-4/#feature-precedence): the font-variant-* properties (and the font-variant shorthand) and font-kerning turn into feature tags, and the tags of font-feature-settings are applied after them, so that the settings win (the order of precedence of the specification). Java2D of JRE 6 cannot switch OpenType features of a font, so only the features that this engine can reproduce have an effect on the page, and the engine reproduces them itself: small capitals (smcp, c2sc, pcap, c2pc: the lower case letters are drawn as smaller capitals), superscript and subscript (sups, subs: the text is made smaller and moved) and full width forms (fwid). Everything else (ligatures, numerals, alternates ...) is resolved here and can be asked for with value(java.lang.String), but changes nothing on the screen.

Usage: FontFeatures.of(style).caps() is the effective capitals variant, FontFeatures.of(style).value("tnum") the value of a tag.

스타일이 요구하는 OpenType 기능(CSS Fonts Level 4 기능 우선순위): font-variant-* 속성(과 font-variant 단축 속성)과 font-kerning 이 기능 태그가 되고, font-feature-settings 의 태그는 그 뒤에 적용되어 이긴다(규격의 우선순위). JRE 6 의 Java2D 는 글꼴의 OpenType 기능을 켜고 끌 수 없으므로 이 엔진이 직접 재현할 수 있는 기능만 화면에 효과가 있다: 작은 대문자(smcp, c2sc, pcap, c2pc. 소문자를 더 작은 대문자로 그린다), 위첨자와 아래첨자 (sups, subs. 글자를 줄이고 옮긴다), 전각 형태(fwid). 나머지(합자, 숫자, 대체 형태 등)는 여기서 해석되어 value(java.lang.String) 로 물을 수 있지만 화면에는 아무 변화가 없다.

사용법: FontFeatures.of(style).caps() 는 실제 대문자 변형, FontFeatures.of(style).value("tnum") 은 태그의 값이다.

Returns the glyph alternate features that a style asks for from a font of a family (CSS Fonts 4 sections 6.8 and 6.9): the function values of font-variant-alternates with their names looked up in the @font-feature-values rules of the family (stylistic(n) is salt, styleset(n#) turns on ss01 to ss99, character-variant(n#) sets cv01 to cv99, swash(n) is swsh and cswh, ornaments(n) is ornm, annotation(n) is nalt, historical-forms is hist; an undefined name does nothing), then the same tags of font-feature-settings, which win (feature precedence).

스타일이 패밀리의 글꼴에 요구하는 대체 글리프 기능을 반환한다(CSS Fonts 4 6.8, 6.9 절): font-variant-alternates 의 함수 값의 이름을 그 패밀리의 @font-feature-values 규칙에서 찾은 것(stylistic(n) 은 salt, styleset(n#) 은 ss01~ss99 를 켬, character-variant(n#) 은 cv01~cv99 를 정함, swash(n) 은 swsh 와 cswh, ornaments(n) 은 ornm, annotation(n) 은 nalt, historical-forms 는 hist. 정의되지 않은 이름은 아무것도 하지 않는다), 그다음 이기는 font-feature-settings 의 같은 태그(기능 우선순위).

mayRealize

public static boolean mayRealize(ComputedStyle s,
                                 java.lang.String kind)
Tells whether the user agent may synthesize a face or a variant that the font does not have: the longhand of the kind (font-synthesis-weight, -style, -small-caps or -position, set together by the shorthand font-synthesis) must not be none. This engine has no OpenType glyphs for small capitals and the positions, so every one of them is synthesized; the bold and the italic are made by the JRE.

글꼴에 없는 면이나 변형을 사용자 에이전트가 합성해도 되는지 알려 준다: 그 종류의 개별 속성(font-synthesis-weight, -style, -small-caps, -position. 단축 속성 font-synthesis 가 함께 정한다)이 none 이 아니어야 한다. 이 엔진에는 작은 대문자와 위치 변형의 OpenType 글리프가 없으므로 모두 합성하며, 굵게와 기울임은 JRE 가 만든다.

Parameters:
s - the style / 스타일
kind - weight, style, small-caps or position / 합성의 종류
Returns:
true if the synthesis is allowed / 합성이 허용되면 true
