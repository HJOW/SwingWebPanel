Interface ContainerSource

All Known Implementing Classes:
CssStyleSource
public interface ContainerSource

A StyleSource whose styles depend on the size of the query containers of the layout (the style sheets contain @container rules). The layout engine lays the document out, reports the measured sizes of the containers, and lays it out again if the styles changed because of them (container query evaluation, CSS Conditional Level 5, needs the layout of the container first).

스타일이 레이아웃의 질의 컨테이너 크기에 달려 있는(스타일 시트에 @container 규칙이 있는) StyleSource. 레이아웃 엔진은 문서를 배치하고 잰 컨테이너 크기를 알린 뒤, 그것 때문에 스타일이 바뀌었으면 다시 배치한다(컨테이너 질의 평가는 컨테이너의 레이아웃이 먼저 필요하다. CSS Conditional Level 5).
