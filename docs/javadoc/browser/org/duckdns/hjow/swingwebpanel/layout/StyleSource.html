CssStyleSource
public interface StyleSource

Supplies the computed styles that the layout engine needs. The CSS style resolver implements it (or is adapted to it); tests may supply fixed styles. Both methods are called on the thread that runs the layout and must return immutable ComputedStyle objects.

레이아웃 엔진이 필요로 하는 계산 스타일을 제공한다. CSS 스타일 리졸버가 구현하거나 어댑터로 연결하며 시험은 고정 스타일을 줄 수 있다. 두 메서드는 레이아웃을 실행하는 스레드에서 호출되며 불변 ComputedStyle 을 반환해야 한다.

getHighlightStyle

ComputedStyle getHighlightStyle(Element element,
                                java.lang.String name)
Returns the style of the custom highlight pseudo-element ::highlight(name) of an element (CSS Custom Highlight API 1): the highlight properties (color, background-color, text-decoration...) inherit from the highlight of the parent element when no rule sets them, the other properties are those of the element; color may be the keyword currentcolor (the color of the text).

요소의 사용자 정의 하이라이트 의사 요소 ::highlight(이름) 의 스타일을 반환한다(CSS Custom Highlight API 1): 규칙이 정하지 않은 하이라이트 속성(color, background-color, text-decoration 등)은 부모 요소의 하이라이트에서 물려받고 나머지 속성은 요소의 것이다. color 는 키워드 currentcolor(텍스트의 색)일 수 있다.

Parameters:

name - the custom highlight name / 사용자 정의 하이라이트 이름
Returns:
the style, never null / 스타일(null 이 아님)
