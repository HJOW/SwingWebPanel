Interface WebFontSet.TimedLoader

public static interface WebFontSet.TimedLoader
extends WebFontSet.Loader

A WebFontSet.Loader that also tells when the request of a font started and when its bytes arrived, so that font-display can tell whether the font arrived in time (CSS Fonts 4 section 4.8). The times are measured where the request runs (not where the layout asks), so that a late layout does not make a font late.

글꼴 요청이 언제 시작되었고 바이트가 언제 도착했는지도 알려 주는 WebFontSet.Loader. font-display 가 글꼴이 제때 도착했는지 가릴 수 있게 한다(CSS Fonts 4 4.8 절). 시간은 레이아웃이 묻는 곳이 아니라 요청이 실행되는 곳에서 재므로 레이아웃이 늦어도 글꼴이 늦은 것이 되지 않는다.
