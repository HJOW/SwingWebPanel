org.duckdns.hjow.swingwebpanel.layout
Interface PaintWalker.Visitor

Enclosing class:
PaintWalker
public static interface PaintWalker.Visitor

Receives the painting events of PaintWalker. Every box that has a border box is reported once with decorate(org.duckdns.hjow.swingwebpanel.layout.LayoutBox) (including line boxes and anonymous boxes, which the renderer ignores but the hit test records); the text, markers and replaced content follow with content(org.duckdns.hjow.swingwebpanel.layout.LayoutBox).

PaintWalker 의 그리기 이벤트를 받는다. border box 를 가진 모든 상자는 decorate(org.duckdns.hjow.swingwebpanel.layout.LayoutBox) 로 한 번 알려진다(줄 상자와 익명 상자 포함. 렌더러는 무시하지만 히트 테스트는 기록한다). 텍스트, 표식, 치환 콘텐츠는 content(org.duckdns.hjow.swingwebpanel.layout.LayoutBox) 로 이어진다.

beginEffects

void beginEffects(LayoutBox box)
Starts a group whose content is painted into a buffer that gets the effects of the box applied before it is drawn: the filter functions of filter and then the mask of mask-image (CSS Filter Effects 1 and CSS Masking 1; the order of the compositing model is filter, clip, mask, opacity). Everything until the matching endEffects(org.duckdns.hjow.swingwebpanel.layout.LayoutBox) belongs to the group.

상자의 효과를 입히는 버퍼에 내용을 그리는 그룹을 시작한다: filter 의 필터 함수, 그다음 mask-image 의 마스크(CSS Filter Effects 1, CSS Masking 1. 합성 모델의 순서는 필터, 자르기, 마스크, 불투명도이다). 짝이 되는 endEffects(org.duckdns.hjow.swingwebpanel.layout.LayoutBox) 까지의 모든 것이 그룹에 속한다.

Parameters:
box - the box with a filter or a mask / 필터나 마스크가 있는 상자
