org.duckdns.hjow.swingwebpanel.layout
Class FilterSpec

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.FilterSpec

public final class FilterSpec
extends java.lang.Object

The parsed value of the filter property (CSS Filter Effects Module Level 1, https://www.w3.org/TR/filter-effects-1/, Working Draft 2018-12-18, retrieved 2026-11-17, section 6 "Filter functions" and section 13.1 "Filter functions in SVG terms"): the list of the filter functions blur(), brightness(), contrast(), drop-shadow(), grayscale(), hue-rotate(), invert(), opacity(), saturate() and sepia() with their amounts, in the order of the declaration (the first function takes the element as input, the next ones take the output of the previous one). The amounts are already clamped the way the specification requires (grayscale(), invert(), opacity() and sepia() to at most 1). A url(#id) reference to an SVG filter element of the same document is a function of the chain too (see resolve(org.duckdns.hjow.swingwebpanel.layout.FilterSpec.Resolver, double, double)); a reference to another document or to an element that does not exist drops the whole chain (section 5.1: no filter is applied). The class belongs to the layout package because a box with a filter is a stacking context and the containing block of its positioned descendants, and because the painted extent of a filter is larger than the box; the pixel work is in org.duckdns.hjow.swingwebpanel.render.

filter 속성의 파싱된 값(CSS Filter Effects Module Level 1, https://www.w3.org/TR/filter-effects-1/, 워킹 드래프트 2018-12-18, 조회 2026-11-17, 6 절 "Filter functions", 13.1 절 "Filter functions in SVG terms"): 필터 함수 blur(), brightness(), contrast(), drop-shadow(), grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia() 의 목록과 그 양. 선언 순서대로이며 첫 함수는 요소를 입력으로 받고 다음 함수는 앞 함수의 출력을 입력으로 받는다. 양은 규격이 요구하는 대로 이미 한정되어 있다(grayscale(), invert(), opacity(), sepia() 는 최대 1). 같은 문서의 SVG filter 요소를 가리키는 url(#id) 참조도 사슬의 함수이다(resolve(org.duckdns.hjow.swingwebpanel.layout.FilterSpec.Resolver, double, double) 참조). 다른 문서나 존재하지 않는 요소를 가리키는 참조가 있으면 사슬 전체를 버린다(5.1 절: 필터를 적용하지 않음). 이 클래스가 layout 패키지에 있는 이유는 필터가 있는 상자가 쌓임 맥락이고 위치 지정 자손의 포함 블록이며 필터가 그리는 범위가 상자보다 크기 때문이다. 픽셀 처리는 org.duckdns.hjow.swingwebpanel.render 에 있다.

resolve

public FilterSpec resolve(FilterSpec.Resolver resolver,
                          double w,
                          double h)
Resolves the references to SVG filter elements for a box of a size: the whole chain is dropped (null) if one of them names no filter element of the document, as the specification demands for a reference to an element that does not exist (Filter Effects 1, section 5).

SVG filter 요소 참조를 주어진 크기의 상자에 대해 푼다: 하나라도 문서에 없는 필터 요소를 가리키면 사슬 전체를 버린다(null). 존재하지 않는 요소의 참조에 대해 규격이 요구하는 대로이다(Filter Effects 1, 5 절).

Parameters:
resolver - the resolver of the document of the box / 상자의 문서의 해석기
w - the width of the border box / border box 너비
h - the height of the border box / border box 높이
Returns:
the specification (this one if it has no reference), or null if a reference cannot be resolved / 명세(참조가 없으면 자신). 참조를 풀 수 없으면 null
