org.duckdns.hjow.swingwebpanel.layout
Class Resizing

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.Resizing

public final class Resizing
extends java.lang.Object

The geometry of the resize property (CSS Basic User Interface Module Level 4, https://www.w3.org/TR/css-ui-4/#resize, section 6.1 "resize: Resizability of elements"): which boxes the user may resize, in which directions, and where their resize handle is. A box is resizable when resize is not none, when it is a block container (a block or an inline block) and when its overflow is neither visible nor clip in at least one axis (the property "applies to elements with overflow other than visible"). The handle is a square of HANDLE_SIZE pixels at the bottom right corner of the padding box (the corner where a scrollbar corner is); a box whose padding box is smaller than the handle has none. block and inline are resolved against the writing mode of the box. The input handling that changes the size is in org.duckdns.hjow.swingwebpanel.core.PageResize and the picture of the handle in org.duckdns.hjow.swingwebpanel.render.

resize 속성의 기하(CSS Basic User Interface Module Level 4, https://www.w3.org/TR/css-ui-4/#resize, 6.1 절 "resize: Resizability of elements"): 사용자가 크기를 바꿀 수 있는 상자, 방향, 크기 조절 핸들의 위치. resize 가 none 이 아니고, 블록 컨테이너(블록 또는 inline-block)이며, 적어도 한 축에서 overflow 가 visible 도 clip 도 아니면 크기를 바꿀 수 있는 상자이다(속성은 "overflow 가 visible 이 아닌 요소에 적용된다"). 핸들은 padding box 의 오른쪽 아래 모서리(스크롤바 모서리가 있는 곳)에 놓이는 HANDLE_SIZE 픽셀의 정사각형이며, padding box 가 핸들보다 작은 상자는 핸들이 없다. block 과 inline 은 상자의 쓰기 모드에 따라 푼다. 크기를 바꾸는 입력 처리는 org.duckdns.hjow.swingwebpanel.core.PageResize, 핸들 그림은 org.duckdns.hjow.swingwebpanel.render 에 있다.

Finds the box whose resize handle is at a point: the box that was hit or its closest ancestor with a handle that contains the point. The point is mapped back through the transform of the box, so that a handle that was moved by transform is found where it is seen.

insets

public static double insets(LayoutBox b,
                            boolean width)
Returns how much larger the border box is than the value of width (or height) of a box: the padding and the border along the axis for box-sizing: content-box and zero for border-box. The new value of the property that gives the box the border box size that the user dragged it to is that size minus this amount (not below zero).

상자의 border box 가 width(또는 height) 값보다 얼마나 큰지 반환한다: box-sizing: content-box 이면 축을 따른 padding 과 border, border-box 이면 0. 사용자가 끌어 정한 border box 크기를 상자에 주는 속성의 새 값은 그 크기에서 이 값을 뺀 것이다(0 미만이 아님).

Parameters:
b - the box / 상자
width - true for the width, false for the height / 너비이면 true, 높이이면 false
Returns:
the amount in CSS pixels / 크기(CSS 픽셀)
