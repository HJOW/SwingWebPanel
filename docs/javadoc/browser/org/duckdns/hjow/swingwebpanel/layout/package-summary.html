Package org.duckdns.hjow.swingwebpanel.layout

Layout engine: layout box tree, block/inline/table/flex layouts and font measurement.

See:
          Description

Interface Summary
ContainerSource A StyleSource whose styles depend on the size of the query containers of the layout (the style sheets contain @container rules).
CounterStyleSource A StyleSource that knows the counter styles the style sheets define with @counter-style (CSS Counter Styles Level 3), so that list-style-type and counter() can use them.
FilterSpec.Resolver Finds the SVG definitions that a reference to a filter element names (the renderer implements it with the document of the box).
MarkerImageSource Tells the layout the size of the image of a list marker (list-style-image, CSS Lists 3 section 3.3): the renderer knows the images that have arrived and the image functions of CSS Images 4.
OrientedContent The content of a replaced element whose picture was turned by metadata of the file (the EXIF orientation of a JPEG, PNG or WebP image).
PaintWalker.Visitor Receives the painting events of PaintWalker.
PositionTrySource A StyleSource that knows the position options that the style sheets define with @position-try (CSS Anchor Positioning Level 1 section 6.4), so that position-try-fallbacks can use them when an anchor-positioned box overflows.
ReplacedContent The external content of a replaced element (an image, audio controls, a canvas, a form control, an unsupported-video placeholder ...).
ReplacedFallback An optional extension of a ReplacedResolver for the elements that cannot show their content: it gives the text that an img element without a usable image stands for (HTML5 REC 2014-10-28 section 10.4.2, https://www.w3.org/TR/2014/REC-html5-20141028/rendering.html#images).
ReplacedResolver Tells the layout engine what external content a replaced element has (the loaded image, the media placeholder, the form control ...).
ShapeImageSource An optional extension of a ReplacedResolver that gives the images that define a shape-outside (CSS Shapes Module Level 1 section 4): the resolver of the renderer implements it, a resolver without it (as in many layout tests) treats an image shape like none.
StyleSource Supplies the computed styles that the layout engine needs.
WebFontSet.Loader The source of the bytes of a font file: the request layer of the page.
WebFontSet.TimedLoader A WebFontSet.Loader that also tells when the request of a font started and when its bytes arrived, so that font-display can tell whether the font arrived in time (CSS Fonts 4 section 4.8).
WebFontSource The web fonts of a page for the layout (plan item P10-05, CSS Fonts Level 3 @font-face): the font resolver asks it for every family name of font-family before it looks for an installed font of that name.
 

Class Summary
ClipPaths The shape of clip-path (plan items P10-08, CSS Masking Level 1 section 5 "Clipping paths", https://www.w3.org/TR/css-masking-1/, Candidate Recommendation Draft 2021-08-05, retrieved 2026-11-17, and CSS Shapes Level 1 section 3 for the basic shapes): the basic shapes inset() (with round and one to four radii per axis like border-radius), circle(), ellipse(), polygon() (with nonzero and evenodd), rect(), xywh() and path() (SVG path data with nonzero or evenodd), with the reference boxes border-box (the default), padding-box, content-box and margin-box (fill-box is the content box, stroke-box and view-box are the border box).
CssStyleSource A StyleSource on top of the CSS engine: computed styles come from the cascade of CssEngine (user-agent, author and inline styles, media queries, ::before/::after rules).
Effects Small helpers for the properties that paint a stacking context as one group: filter (CSS Filter Effects 1), mix-blend-mode and isolation (CSS Compositing and Blending Level 1, https://www.w3.org/TR/compositing-1/) and the mask properties (CSS Masking Level 1).
FilterSpec The parsed value of the filter property (CSS Filter Effects Module Level 1, https://www.w3.org/TR/filter-effects-1/, Working Draft 2018-12-18, retrieved 2026-11-17, section 6 "Filter functions" and section 13.1 "Filter functions in SVG terms"): the list of the filter functions blur(), brightness(), contrast(), drop-shadow(), grayscale(), hue-rotate(), invert(), opacity(), saturate() and sepia() with their amounts, in the order of the declaration (the first function takes the element as input, the next ones take the output of the previous one).
FilterSpec.Op One filter function with its arguments.
FontFeatures The OpenType features that a style asks for (CSS Fonts Level 4, https://www.w3.org/TR/css-fonts-4/#feature-precedence): the font-variant-* properties (and the font-variant shorthand) and font-kerning turn into feature tags, and the tags of font-feature-settings are applied after them, so that the settings win (the order of precedence of the specification).
LayoutBox A box of the layout tree (plan item P09-01).
LayoutEngine The layout engine (plan items P09-01, P09-02, P09-03): turns a DOM document and the computed styles into a tree of boxes with coordinates, see LayoutBox and LayoutResult.
LayoutResult The result of a layout run (plan items P09-01, P09-02, P09-03): the root of the box tree, the size of the whole document for preferredSize, the map from DOM nodes to their boxes and hit testing.
MotionPath The offset transform of CSS Motion Path Module Level 1 (https://www.w3.org/TR/motion-1/, W3C Working Draft 5 November 2024): offset-path (path(), circle(), ellipse(), inset(), rect(), xywh(), polygon(), ray() and a reference box alone), offset-distance, offset-position, offset-anchor and offset-rotate.
PaintWalker Walks the box tree in the painting order of CSS 2.1 Appendix E (plan item P10-01) and reports what is to be painted to a PaintWalker.Visitor.
Resizing The geometry of the resize property (CSS Basic User Interface Module Level 4, https://www.w3.org/TR/css-ui-4/#resize, section 6.1 "resize: Resizability of elements"): which boxes the user may resize, in which directions, and where their resize handle is.
ShapeImage The alpha channel of an image that gives the float area of a float whose shape-outside is an image (CSS Shapes Module Level 1 section 4 "Shapes from Image", https://www.w3.org/TR/css-shapes-1/#shapes-from-image): the width and the height in image pixels and one alpha value from 0 (transparent) to 255 (opaque) for every pixel in row order.
StickyConstraint The geometry that decides how far a position:sticky box is shifted while the page scrolls (CSS Positioned Layout Module Level 3, section 3.4 "Sticky positioning", https://www.w3.org/TR/css-position-3/#sticky-pos).
TableBorder One segment of a collapsed table border (plan item P10-02): the winner of the conflict between the borders of the cells, rows, row groups, columns, column groups and the table that meet at a grid line (CSS 2.1 17.6.2.1), as a rectangle to paint.
TextEmphasis The emphasis marks of a style (CSS Text Decoration Module Level 4, https://www.w3.org/TR/css-text-decor-4/#emphasis-marks, W3C Working Draft 4 May 2022): text-emphasis-style (a filled or open shape: dot, circle, double-circle, triangle, sesame, or a string), text-emphasis-color and text-emphasis-position (over or under the text in horizontal text).
WebFontSet The @font-face faces of a page (plan item P10-05, CSS Fonts Level 3 section 4 https://www.w3.org/TR/css-fonts-3/ edition (edition of the feature table); WOFF 1.0 https://www.w3.org/TR/WOFF/): the faces are made from the rules, the sources of a face are tried in order, and a face that is loaded is chosen for a request by the font matching of CSS Fonts 3 section 5.2 (the style first, then the weight in the order that depends on the requested weight).
Woff The decoder of WOFF 1.0 web fonts (plan item P10-05, https://www.w3.org/TR/WOFF/, W3C Recommendation 2012-12-13): a WOFF file is an sfnt (TrueType or OpenType) font whose tables are compressed one by one with zlib.
