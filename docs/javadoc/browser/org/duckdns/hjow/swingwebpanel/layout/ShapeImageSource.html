org.duckdns.hjow.swingwebpanel.layout
Interface ShapeImageSource

All Known Implementing Classes:
ImageReplacedResolver
public interface ShapeImageSource

An optional extension of a ReplacedResolver that gives the images that define a shape-outside (CSS Shapes Module Level 1 section 4): the resolver of the renderer implements it, a resolver without it (as in many layout tests) treats an image shape like none. Both methods return null while the picture is not available (it is still loading, failed, or may not be used because it is a cross-origin image without permission), and then the float is wrapped around by its margin box; the layout runs again when the image arrived.

shape-outside 를 정하는 이미지를 주는 ReplacedResolver 의 선택적 확장(CSS Shapes Module Level 1 4 절): 렌더러의 리졸버가 구현하며, 구현하지 않은 리졸버(많은 레이아웃 시험)에서는 이미지 모양을 none 처럼 다룬다. 두 메서드는 그림을 쓸 수 없는 동안(아직 가져오는 중, 실패, 허락 없는 다른 오리진의 이미지라 쓸 수 없음) null 을 반환하며, 그러면 float 는 margin box 로 감싼다. 이미지가 도착하면 레이아웃을 다시 한다.
