org.duckdns.hjow.swingwebpanel.layout
Class TableBorder

java.lang.Object
  org.duckdns.hjow.swingwebpanel.layout.TableBorder

public final class TableBorder
extends java.lang.Object

One segment of a collapsed table border (plan item P10-02): the winner of the conflict between the borders of the cells, rows, row groups, columns, column groups and the table that meet at a grid line (CSS 2.1 17.6.2.1), as a rectangle to paint. The segment is centered on the grid line, so half of its thickness lies in each of the two cells beside it. The geometry of a segment of LayoutBox.collapsedEdges is relative to the border box of the table; the segments that LayoutBox.getCollapsedBorders() returns are in document coordinates. A segment is immutable.

합쳐진 표 border 의 선분 하나(계획 P10-02): 격자선에서 만나는 셀, 행, 행 그룹, 열, 열 그룹, 표의 border 충돌의 승자(CSS 2.1 17.6.2.1)를 그릴 사각형으로 나타낸 것이다. 선분은 격자선을 중심으로 하므로 두께의 절반씩이 옆의 두 셀에 놓인다. LayoutBox.collapsedEdges 의 선분 기하는 표 border box 기준이고 LayoutBox.getCollapsedBorders() 가 반환하는 선분은 문서 좌표이다. 선분은 바뀌지 않는다.
