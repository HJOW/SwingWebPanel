Class ImageMaps

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ImageMaps

public final class ImageMaps
extends java.lang.Object

Client-side image maps of HTML (HTML5 REC 2014-10-28 section 4.7.13, https://www.w3.org/TR/2014/REC-html5-20141028/embedded-content-0.html#image-maps, retrieved 2026-11-17): an img with a usemap attribute is associated with the map element that the attribute names, and the area elements of the map are shapes that are layered on the image in reverse tree order (the first area in tree order is the top-most shape). A point of the image belongs to the first shape that contains it, also when that shape has no href (a dead area catches the point, so the image or the link around the image is not used). The coordinates of the shapes are in CSS pixels of the displayed image, so they are not affected by the zoom and by transforms. This class only reads the DOM and computes; it is thread-confined to its caller like the DOM.

HTML 의 클라이언트 쪽 이미지 맵(HTML5 REC 2014-10-28 §4.7.13): usemap 속성이 있는 img 는 속성이 가리키는 map 요소와 연결되고, 맵의 area 요소는 트리 순서의 역순으로 이미지 위에 겹쳐지는 모양이다(트리 순서의 첫 area 가 맨 위 모양). 이미지의 한 점은 그 점을 포함하는 첫 모양에 속하며, 그 모양에 href 가 없어도 마찬가지이다(죽은 영역이 점을 잡으므로 이미지나 이미지를 감싼 링크는 쓰이지 않는다). 모양의 좌표는 표시된 이미지의 CSS 픽셀이므로 확대와 변환의 영향을 받지 않는다. 이 클래스는 DOM 을 읽고 계산만 하며 DOM 처럼 호출자의 스레드에 묶인다.

Finds the map element that a usemap value refers to: the rules for parsing a hash-name reference of HTML5 2014 section 2.4.9 return the first map in tree order that has an id equal to the text after the first "#" or a name that matches it without regard to case. contains

public static boolean contains(Element area,
                               double x,

                               double w,
                               double h)
Tells whether the shape of an area contains a point of the image (HTML5 2014 section 4.7.13.2): the shape is empty if the coords list has fewer items than its state needs, an odd last item of a polygon and the items past the ones that a state uses are dropped, a rectangle with its corners in the wrong order is swapped, and a circle needs a positive radius. The edges of a rectangle belong to it on the left and the top, the points of a circle include its edge, and a polygon uses the even-odd rule.

area 의 모양이 이미지의 한 점을 포함하는지 알려 준다(HTML5 2014 §4.7.13.2): coords 목록의 항목이 상태에 필요한 수보다 적으면 모양이 비어 있고, 다각형의 홀수 마지막 항목과 상태가 쓰는 것을 넘는 항목은 버리며, 모서리 순서가 틀린 직사각형은 서로 바꾸고, 원은 양의 반지름이 필요하다. 직사각형은 왼쪽과 위쪽 가장자리를 포함하고 원은 가장자리를 포함하며 다각형은 짝홀 규칙을 쓴다.

Finds the area of the image map of an image that covers a point of the page. The point is moved into the coordinate system of the image (see localPoint(org.duckdns.hjow.swingwebpanel.layout.LayoutBox, double, double, int, int)) and the content box of the image is the origin, because the coordinates of an image map are in CSS pixels of the displayed image.

이미지 맵이 있는 이미지에서 페이지의 한 점을 덮는 area 를 찾는다. 점을 이미지의 좌표계로 옮기고(localPoint(org.duckdns.hjow.swingwebpanel.layout.LayoutBox, double, double, int, int) 참조) 이미지 맵 좌표는 표시된 이미지의 CSS 픽셀이므로 이미지의 content box 를 원점으로 삼는다.

localPoint

public static double[] localPoint(LayoutBox box,

Moves a point of the page into the coordinate system of a box: the scroll offset is subtracted if the box is inside a fixed box (as the hit test does), and the transforms of the box and its ancestors are undone, so zoom and transforms do not change what a point of the displayed image means.

페이지의 한 점을 상자의 좌표계로 옮긴다: 상자가 fixed 상자 안이면 (히트 테스트처럼) 스크롤 오프셋을 빼고 상자와 조상의 변환을 되돌리므로 확대와 변환은 표시된 이미지의 점이 뜻하는 바를 바꾸지 않는다.

Returns the hyperlink suffix of a server-side image map (HTML5 2014 section 4.5.1, the activation behavior of a): if the click went to an img with an ismap attribute inside an a link, the address that is followed gets ?x,y appended, with the distance in CSS pixels from the left and top edge of the border of the image to the click as integers (a point in the part of the image that has no such distance is zero).

서버 쪽 이미지 맵의 하이퍼링크 접미사를 반환한다(HTML5 2014 §4.5.1, a 의 활성화 동작): a 링크 안의 ismap 속성이 있는 img 로 클릭이 갔으면 따라가는 주소 뒤에 ?x,y 가 붙는다. 값은 이미지 border 의 왼쪽과 위쪽 가장자리에서 클릭까지의 CSS 픽셀 거리이며 정수이다 (그런 거리가 없는 부분의 점은 0).

Parameters:
hit - the box of the element that was hit / 맞은 요소의 상자
target - the element that received the click / 클릭을 받은 요소
link - the link that is followed / 따라가는 링크
docX - x of the click in document coordinates / 클릭의 문서 좌표 x
docY - y of the click in document coordinates / 클릭의 문서 좌표 y
scrollX - horizontal scroll offset / 가로 스크롤 오프셋
scrollY - vertical scroll offset / 세로 스크롤 오프셋
Returns:
the suffix such as ?12,34, or the empty string if the click is not on a server-side image map / ?12,34 같은 접미사. 서버 쪽 이미지 맵 위의 클릭이 아니면 빈 문자열
