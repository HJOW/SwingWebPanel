Class CanvasSizes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.CanvasSizes

public final class CanvasSizes
extends java.lang.Object

The size rules of the canvas element: the width and height attributes are parsed with the rules for non-negative integers and fall back to 300 and 150 when they are absent or invalid (each independently). The layout uses the result as the natural size of the replaced element and the canvas bindings as the size of the bitmap, so both always agree.

canvas 요소의 크기 규칙: width 와 height 속성은 음이 아닌 정수 해석 규칙으로 읽으며, 없거나 올바르지 않으면 (각각 독립적으로) 300 과 150 을 쓴다. 레이아웃은 결과를 치환 요소의 자연 크기로, 캔버스 연결은 비트맵의 크기로 쓰므로 둘은 언제나 일치한다.

Parses a dimension attribute with the rules for non-negative integers (leading white space and a plus sign are allowed, trailing characters after the digits are ignored; a minus sign, no digits or a value above 2147483647 is an error).
