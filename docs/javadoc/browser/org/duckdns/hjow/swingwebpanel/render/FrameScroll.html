org.duckdns.hjow.swingwebpanel.render
Class FrameScroll

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.FrameScroll

public final class FrameScroll
extends java.lang.Object

The arithmetic of the scrolling of a frame: how far a frame may scroll, where the thumb of an overlay scrollbar is and how a position of the thumb maps back to a scroll offset. The painter and the input handling use the same functions, so a thumb that is drawn can be grabbed where it is drawn.

프레임 스크롤의 계산: 프레임이 얼마나 스크롤할 수 있는지, 오버레이 스크롤바의 썸이 어디에 있는지, 썸의 위치가 스크롤 오프셋으로 어떻게 되돌아가는지. 그리는 쪽과 입력 처리가 같은 함수를 쓰므로 그려진 썸을 그려진 곳에서 잡을 수 있다.
