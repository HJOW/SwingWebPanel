org.duckdns.hjow.swingwebpanel.render
Class RenderedPage

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.RenderedPage

public final class RenderedPage
extends java.lang.Object

An immutable, fully rendered page (plan items P09-04 to P09-07): the LayoutResult, the DisplayList built from it and a HitTester. The document thread builds it with PageRenderer and hands it over; from then on the event dispatch thread only reads it: paint(java.awt.Graphics2D, java.awt.Rectangle, int, int) in paintComponent, hitTest(double, double, int, int, double) for mouse events, getPreferredWidth() and getPreferredHeight() for getPreferredSize (the scrollable area in unscaled document pixels). A new page object replaces the old one after every relayout; the old one stays valid while a paint is still using it.

완전히 렌더링된 불변 페이지(계획 P09-04~P09-07): LayoutResult, 그것으로 만든 DisplayList, HitTester. 문서 스레드가 PageRenderer 로 만들어 넘기며, 그 뒤 이벤트 디스패치 스레드는 읽기만 한다: paintComponent 에서 paint(java.awt.Graphics2D, java.awt.Rectangle, int, int), 마우스 이벤트에서 hitTest(double, double, int, int, double), getPreferredSize 에서 getPreferredWidth() 와 getPreferredHeight()(배율을 적용하지 않은 문서 픽셀의 스크롤 영역). 다시 배치할 때마다 새 페이지 객체가 옛것을 대체하며, 옛것은 그리기가 아직 쓰는 동안 유효하다.

getControl

public ControlSnapshot getControl(Element element)
Returns the snapshot of the form control of an element as it was drawn in this page, or null if the element is not a drawn control (or has no box). The Swing editors of the text controls take their position, font and colors from it.

요소의 폼 컨트롤이 이 페이지에서 그려진 대로의 스냅샷을 반환한다. 그려지는 컨트롤이 아니거나 상자가 없으면 null. 텍스트 컨트롤의 Swing 편집기가 이것에서 위치, 글꼴, 색을 가져간다.

Paints the page of a host that does the scrolling itself (a JScrollPane moves the component, so the graphics are already scrolled): position:fixed boxes stay at the viewport and position:sticky boxes stick to it, which needs the position of the viewport that the host scrolled to.

스크롤을 스스로 하는 호스트의 페이지를 그린다(JScrollPane 이 컴포넌트를 옮기므로 그래픽스는 이미 스크롤되어 있다): position:fixed 상자는 뷰포트에 머물고 position:sticky 상자는 뷰포트에 붙으므로 호스트가 스크롤한 뷰포트의 위치가 필요하다.

Parameters:
g - the graphics / 그래픽스
clip - the area to paint or null / 그릴 영역 또는 null
scrollX - horizontal offset applied here (0 if the graphics are scrolled already) / 여기서 적용하는 가로 오프셋(그래픽스가 이미 스크롤되었으면 0)
scrollY - vertical offset applied here / 여기서 적용하는 세로 오프셋
scale - the zoom factor / 확대 배율
timeMillis - animation time in milliseconds / 애니메이션 시각(밀리초)
viewX - x of the viewport in document px / 문서 px 단위 뷰포트의 x
viewY - y of the viewport in document px / 문서 px 단위 뷰포트의 y
