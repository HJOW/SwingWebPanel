org.duckdns.hjow.swingwebpanel.render
Class DisplayList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.DisplayList

public final class DisplayList
extends java.lang.Object

The immutable list of drawing commands of one page in paint order (plan items P09-04, P09-05). It is built once per layout on the document thread by DisplayListBuilder and then only read, so the event dispatch thread can paint it while the document thread builds the next one. Group commands (clip, opacity) are nested properly: every start command names the index of its end command.

한 페이지의 그리기 명령을 그리기 순서로 담은 불변 리스트(계획 P09-04, P09-05). 레이아웃마다 문서 스레드에서 DisplayListBuilder 가 한 번 만들고 이후에는 읽기만 하므로, 문서 스레드가 다음 것을 만드는 동안 이벤트 디스패치 스레드가 이것을 그릴 수 있다. 그룹 명령(클립, 불투명도)은 올바르게 중첩되며 모든 시작 명령은 끝 명령의 위치를 안다.
