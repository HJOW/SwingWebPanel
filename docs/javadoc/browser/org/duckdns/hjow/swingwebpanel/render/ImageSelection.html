Class ImageSelection

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ImageSelection

public final class ImageSelection
extends java.lang.Object

Chooses the source of an img element (plan item P18-05): the src attribute, the srcset and sizes attributes, and the source siblings in front of it when its parent is a picture element. The algorithm is "update the source set" and "select an image source from a source set" of the HTML Standard (the image-selection parts that the W3C HTML5 2014 recommendation lacks, from HTML 5.1 / the WHATWG HTML Living Standard): a source is skipped when it has no srcset, when its type is not an image type that this component decodes, or when its media query does not match; the first usable one provides the source set. The candidates carry a density (x) or a width (w) descriptor; widths are turned into densities with the source size that sizes gives (default 100vw). The chosen candidate is the smallest density that is not lower than the device pixel ratio of the environment, or else the largest density. The class has no state; the renderer, the layout resolver and the script image loader call it with the same environment so that all of them agree on the same currentSrc.

img 요소의 소스를 고른다(계획 P18-05): src 속성, srcset 과 sizes 속성, 그리고 부모가 picture 이면 앞에 있는 source 형제들. 알고리즘은 HTML 표준의 "update the source set" 과 "select an image source from a source set" 이다(W3C HTML5 2014 권고안에 없는 이미지 선택 부분은 HTML 5.1/WHATWG HTML Living Standard 를 따른다). source 는 srcset 이 없거나, type 이 이 컴포넌트가 디코딩하지 않는 이미지 형식이거나, media 질의가 맞지 않으면 건너뛰고 처음 쓸 수 있는 것이 소스 집합을 제공한다. 후보는 밀도(x) 또는 너비(w) 기술자를 갖고, 너비는 sizes 가 주는 소스 크기(기본 100vw)로 밀도로 바꾼다. 고르는 후보는 환경의 장치 픽셀 비율 이상인 가장 작은 밀도, 없으면 가장 큰 밀도이다. 이 클래스는 상태가 없다. 렌더러, 레이아웃 리졸버, 스크립트의 이미지 로더가 같은 환경으로 부르므로 모두 같은 currentSrc 에 합의한다.

public static ImageSelection.Choice select(Element img,

Selects the source of an image element for a viewport. The environment decides the media queries, the vw units of sizes and the device pixel ratio.

뷰포트에 대한 이미지 요소의 소스를 고른다. 환경이 미디어 질의, sizes 의 vw 단위, 장치 픽셀 비율을 정한다.
