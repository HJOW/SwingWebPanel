Class ImageReplacedResolver

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ImageReplacedResolver
All Implemented Interfaces:
MarkerImageSource, ReplacedFallback, ReplacedResolver, ShapeImageSource
public final class ImageReplacedResolver
extends java.lang.Object
implements ReplacedResolver, ReplacedFallback, ShapeImageSource, MarkerImageSource

Gives the layout the natural size of loaded img elements, read from an ImageSource; images that are not loaded give no content, so the layout falls back to the width/height attributes and its defaults (plan items P09-02, P18-05).

읽은 img 요소의 자연 크기를 ImageSource 에서 읽어 레이아웃에 알려 준다. 읽지 않은 이미지는 콘텐츠를 주지 않으므로 레이아웃이 width/height 속성과 기본값을 쓴다(계획 P09-02, P18-05).

Returns the natural size of the image of a list marker (list-style-image): any <image> that the renderer paints (a URL, image-set(), a gradient, cross-fade(), image()); element() is not known before the layout and an image that has not arrived is null, so the marker uses list-style-type until it arrives.

getShapeImage

public ShapeImage getShapeImage(java.lang.String absoluteUrl)
Returns the alpha mask of an image for a shape-outside (CSS Shapes 1 section 4). The image is fetched in the CORS mode anonymous when the source supports it, so that a cross-origin image without permission is not available (the shape must be CORS-same-origin); the first frame of an animated image is used.

shape-outside 를 위한 이미지의 알파 마스크를 반환한다(CSS Shapes 1 4 절). 소스가 지원하면 CORS 모드 anonymous 로 가져오므로 허락 없는 다른 오리진의 이미지는 쓸 수 없다(모양은 CORS 같은 오리진이어야 한다). 애니메이션 이미지는 첫 프레임을 쓴다.
