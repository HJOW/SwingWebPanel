org.duckdns.hjow.swingwebpanel.render
Class ControlSnapshot

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ControlSnapshot

public final class ControlSnapshot
extends java.lang.Object

An immutable copy of everything that is needed to draw a form control or to put an editor over it: the kind of control, its boxes in document coordinates, its font and colors, and its state (the shown text, checked, disabled, the rows of a list ...). The display list builder makes it on the document thread; the EDT reads it when it paints the control or places the Swing editor of the text controls.

폼 컨트롤을 그리거나 그 위에 편집기를 놓는 데 필요한 모든 것의 불변 복사본: 컨트롤의 종류, 문서 좌표의 상자, 글꼴과 색, 상태(보이는 글, 체크, 비활성, 목록의 행 등). 디스플레이 리스트 빌더가 문서 스레드에서 만들고, EDT 가 컨트롤을 그리거나 텍스트 컨트롤의 Swing 편집기를 놓을 때 읽는다.
