org.duckdns.hjow.swingwebpanel.render
Class BlendModes

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.BlendModes

public final class BlendModes
extends java.lang.Object

The blend modes of CSS Compositing and Blending Level 1 (https://www.w3.org/TR/compositing-1/, Candidate Recommendation Draft 2024-03-21, retrieved 2026-11-17, section 10 "Blending"): the separable modes multiply, screen, overlay, darken, lighten, color-dodge, color-burn, hard-light, soft-light, difference and exclusion, the non-separable modes hue, saturation, color and luminosity, and plus-lighter (the sum of the premultiplied colors, limited to 1). blend(int, int, int, float) computes the result of drawing one source pixel over a backdrop pixel with the formula of section 9 (source over with the blended color): Cr = (1 - as/ar) * Cb + as/ar * ((1 - ab) * Cs + ab * B(Cb, Cs)), ar = as + ab * (1 - as). composite(int, float) wraps that in a Composite that is used to draw the buffer of a group onto the graphics, so that the group is blended with what has been painted so far. Java2D public API only.

CSS Compositing and Blending Level 1 의 혼합 모드(https://www.w3.org/TR/compositing-1/, Candidate Recommendation Draft 2024-03-21, 조회 2026-11-17, 10 절 "Blending"): 분리 가능한 모드 multiply, screen, overlay, darken, lighten, color-dodge, color-burn, hard-light, soft-light, difference, exclusion, 분리 불가능한 모드 hue, saturation, color, luminosity, 그리고 plus-lighter(미리 곱한 색의 합, 1 로 제한). blend(int, int, int, float) 는 9 절의 식(혼합한 색을 쓰는 source over)으로 원본 픽셀 하나를 배경 픽셀 위에 그린 결과를 계산한다. composite(int, float) 는 이것을 Composite 로 감싸 그룹의 버퍼를 그래픽스에 그릴 때 쓰며, 그룹은 지금까지 그려진 것과 혼합된다. Java2D 공개 API 만 쓴다.
