org.duckdns.hjow.swingwebpanel.render
Class HitResult

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.HitResult

public final class HitResult
extends java.lang.Object

The result of a hit test (plan item P09-06): the deepest layout box at a point, the DOM element it belongs to, the nearest enclosing link with its absolute URL and, over text, the text node with the character offset. Instances are immutable.

히트 테스트 결과(계획 P09-06): 점 위의 가장 깊은 레이아웃 상자, 그것이 속한 DOM 요소, 가장 가까운 링크와 그 절대 URL, 텍스트 위라면 텍스트 노드와 문자 오프셋. 인스턴스는 불변이다.
