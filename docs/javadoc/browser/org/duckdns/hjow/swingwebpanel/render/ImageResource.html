org.duckdns.hjow.swingwebpanel.render
Class ImageResource

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ImageResource

public final class ImageResource
extends java.lang.Object

The state of an image or media resource as the renderer sees it when it builds a display list (plan items P09-05, P18-06): loaded (with the decoded image for images), failed (with the reason) or still pending. Instances are immutable; when a resource changes the host builds a new display list.

디스플레이 리스트를 만들 때 렌더러가 보는 이미지/미디어 리소스의 상태(계획 P09-05, P18-06): 읽음(이미지는 디코딩된 이미지 포함), 실패(이유 포함), 아직 진행 중. 인스턴스는 불변이며 리소스가 바뀌면 호스트가 새 디스플레이 리스트를 만든다.
