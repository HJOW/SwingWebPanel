Interface CorsImageSource

All Superinterfaces:
ImageSource
public interface CorsImageSource
extends ImageSource

An ImageSource that can also give the state of an image that is fetched in CORS mode, for an img element with a crossorigin attribute. The same address may be an image of a plain element and of a crossorigin element at once, and the two are different resources (the CORS one carries Origin and fails when the server gives no permission), so the renderer asks for the one that belongs to the element (ImageLookup). A source that does not implement this interface knows only plain images.

CORS 모드로 가져오는 이미지의 상태도 줄 수 있는 ImageSource. crossorigin 속성이 있는 img 요소를 위한 것이다. 같은 주소가 일반 요소와 crossorigin 요소의 이미지일 수 있고 둘은 다른 리소스이므로(CORS 쪽은 Origin 을 싣고 서버가 허락하지 않으면 실패한다) 렌더러는 요소에 속하는 쪽을 묻는다(ImageLookup). 이 인터페이스를 구현하지 않는 소스는 일반 이미지만 안다.
