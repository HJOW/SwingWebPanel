org.duckdns.hjow.swingwebpanel.render
Interface ImageSource

All Known Subinterfaces:
CorsImageSource
public interface ImageSource

Supplies the images and media states that the renderer needs while it builds a display list. The host implements it on top of its resource loader and decoders (media.image.ImageDecoders); the renderer only reads states and never starts a fetch. A method may be called from the document thread many times per build, so it must be cheap and must not block.

렌더러가 디스플레이 리스트를 만들 때 필요한 이미지와 미디어 상태를 제공한다. 호스트가 리소스 로더와 디코더(media.image.ImageDecoders) 위에 구현하며 렌더러는 상태만 읽고 가져오기를 시작하지 않는다. 메서드는 한 번 만드는 동안 문서 스레드에서 여러 번 불릴 수 있으므로 값싸고 막지 않아야 한다.
