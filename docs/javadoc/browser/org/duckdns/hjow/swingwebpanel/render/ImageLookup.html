Class ImageLookup

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.ImageLookup

public final class ImageLookup
extends java.lang.Object

Finds the image of an img element in an ImageSource: the element with a crossorigin attribute gets the image that was fetched in CORS mode (when the source offers it, see CorsImageSource), every other element the plain image. The CORS mode is use-credentials for that value of the attribute and anonymous for any other value of the attribute (also the empty one and an unknown one); an element without the attribute has none.

ImageSource 에서 img 요소의 이미지를 찾는다: crossorigin 속성이 있는 요소는 CORS 모드로 가져온 이미지를 받고(소스가 제공하면. CorsImageSource 참조) 다른 요소는 일반 이미지를 받는다. CORS 모드는 속성이 그 값이면 use-credentials, 속성의 다른 모든 값(빈 값과 모르는 값 포함)이면 anonymous 이고, 속성이 없는 요소에는 없다.
