org.duckdns.hjow.swingwebpanel.render
Interface FrameSource

public interface FrameSource

Supplies the pictures of nested browsing contexts (iframe and frame elements) to the renderer. The owner of the frames lays the document of a frame out for the size of the box that the parent page gave the frame element and returns the immutable result, which the renderer paints with a clip inside that box. The renderer calls it on the document thread while it builds a display list, so it may do the layout of the frame at once, but it must not wait for the network. An ImageSource that also implements this interface is used for the frames of the page (like CanvasSource for canvases).

렌더러에 중첩된 브라우징 문맥(iframe, frame 요소)의 그림을 제공한다. 프레임의 소유자가 프레임 문서를 부모 페이지가 프레임 요소에 준 상자 크기에 맞춰 배치하고 불변 결과를 돌려주면, 렌더러가 그 상자 안에서 클립하여 그린다. 렌더러가 디스플레이 리스트를 만드는 동안 문서 스레드에서 호출하므로 프레임의 배치를 곧바로 할 수 있지만 네트워크를 기다리면 안 된다. 이 인터페이스도 구현하는 ImageSource 가 페이지의 프레임에 쓰인다(CanvasSource 가 캔버스에 쓰이듯이).
