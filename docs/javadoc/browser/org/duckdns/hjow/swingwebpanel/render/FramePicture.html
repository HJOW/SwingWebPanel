org.duckdns.hjow.swingwebpanel.render
Class FramePicture

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.FramePicture

public final class FramePicture
extends java.lang.Object

The picture of a nested browsing context (iframe, frame) that the renderer paints inside the content box of the frame element: the immutable, fully rendered page of the frame (laid out for the size of the box), the scroll position of the frame and which overlay scrollbars to draw. Instances are immutable; the frame owner makes a new one whenever anything changes.

렌더러가 프레임 요소의 콘텐츠 상자 안에 그리는 중첩된 브라우징 문맥(iframe, frame)의 그림: 프레임의 불변이며 완전히 렌더링된 페이지(상자 크기에 맞춰 배치됨), 프레임의 스크롤 위치, 그릴 오버레이 스크롤바. 인스턴스는 불변이며 무엇이든 바뀌면 프레임 소유자가 새로 만든다.
