Class DisplayCommand

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.DisplayCommand

public abstract class DisplayCommand
extends java.lang.Object

One drawing command of a DisplayList (plan items P09-04, P09-05). A command knows the area it paints in document coordinates (so partial repaints skip commands outside the clip) and the DOM node it belongs to (for diagnostics). Commands are immutable after the builder has finished and can be painted by any number of threads one after another; group commands (DisplayCommand.Type.CLIP_START, DisplayCommand.Type.OPACITY_START) carry the index of their matching end command so the painter can skip a whole group at once. Only this package creates commands.

DisplayList 의 그리기 명령 하나(계획 P09-04, P09-05). 명령은 자신이 그리는 영역을 문서 좌표로 알고(부분 다시 그리기가 클립 밖의 명령을 건너뛰도록) 속한 DOM 노드를 안다(진단용). 만들기가 끝난 뒤 명령은 불변이며 여러 스레드가 차례로 그릴 수 있다. 그룹 명령(DisplayCommand.Type.CLIP_START, DisplayCommand.Type.OPACITY_START)은 짝이 되는 끝 명령의 위치를 가지므로 그리는 쪽이 그룹 전체를 한 번에 건너뛸 수 있다. 명령은 이 패키지만 만든다.
