org.duckdns.hjow.swingwebpanel.render
Class PageRenderer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.PageRenderer

public final class PageRenderer
extends java.lang.Object

Renders a document: layout followed by the display list (plan items P09-04 to P09-07). Call it on the document thread (it reads the DOM and the styles) whenever the viewport width, the DOM, the styles or a resource changed; it always lays out from scratch, so a caller that relayouts on width changes must compare the new width with the last one to avoid repeated work. The result is immutable and meant to be handed to the event dispatch thread.

문서를 렌더링한다: 레이아웃 다음에 디스플레이 리스트(계획 P09-04~P09-07). DOM 과 스타일을 읽으므로 문서 스레드에서 부르며, 뷰포트 너비, DOM, 스타일, 리소스가 바뀌었을 때 부른다. 항상 처음부터 배치하므로 너비 변경에 맞춰 다시 배치하는 호출자는 반복 작업을 피하도록 새 너비를 직전 너비와 비교해야 한다. 결과는 불변이며 이벤트 디스패치 스레드로 넘기기 위한 것이다.
