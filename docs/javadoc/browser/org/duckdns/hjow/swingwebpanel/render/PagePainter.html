org.duckdns.hjow.swingwebpanel.render
Class PagePainter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.PagePainter

public final class PagePainter
extends java.lang.Object

Paints a DisplayList with Java2D (plan items P09-04, P09-05). The painter maps the document to the component with device = (document - scroll) * scale, the same transform that HitTester inverts for input, skips every command (and every clip or opacity group) outside the clip rectangle, and puts all state of the Graphics2D back when it is done (transform, clip, color, paint, stroke, font, composite and all rendering hints). It sets only hints of the graphics it was given: shapes are drawn without anti-aliasing so that boxes and borders are crisp, text is anti-aliased, no JVM-wide Java2D property is touched and nothing depends on OpenGL or Direct3D. Opacity groups are painted into an off-screen image and blended once. The painter reads the display list only, so it may run on the event dispatch thread while the document thread builds the next list. A fixed group (DisplayCommand.Type.FIXED_START) undoes the scroll offset, so a position:fixed box stays at the same place of the viewport.

DisplayList 를 Java2D 로 그린다(계획 P09-04, P09-05). 문서를 컴포넌트에 기기 좌표 = (문서 좌표 − 스크롤) × 배율 로 대응시키며 이는 HitTester 가 입력을 위해 역변환하는 것과 같은 변환이다. 클립 사각형 밖의 모든 명령(과 클립/불투명도 그룹)을 건너뛰고 끝나면 Graphics2D 의 모든 상태(변환, 클립, 색, 페인트, 스트로크, 글꼴, 합성, 모든 렌더링 힌트)를 되돌린다. 받은 그래픽스의 힌트만 설정한다: 도형은 상자와 경계선이 또렷하도록 안티앨리어싱 없이 그리고 텍스트는 안티앨리어싱을 쓰며, JVM 전역 Java2D 속성을 건드리지 않고 OpenGL 이나 Direct3D 에 의존하지 않는다. 불투명도 그룹은 화면 밖 이미지에 그린 뒤 한 번 섞는다. 디스플레이 리스트만 읽으므로 문서 스레드가 다음 리스트를 만드는 동안 이벤트 디스패치 스레드에서 실행할 수 있다. fixed 그룹(DisplayCommand.Type.FIXED_START)은 스크롤 오프셋을 되돌리므로 position:fixed 상자는 뷰포트의 같은 자리에 머문다.

Paints a display list of a page whose scroll is done by the host: the origin of the graphics may already be moved by the scroll (a JScrollPane moves the component), so the offset that is applied here and the position of the viewport are separate. The viewport position is what position:fixed boxes stay at and what position:sticky boxes stick to; the size of the viewport is the one that the layout used.

스크롤을 호스트가 하는 페이지의 디스플레이 리스트를 그린다: 그래픽스의 원점이 이미 스크롤만큼 옮겨져 있을 수 있으므로(JScrollPane 은 컴포넌트를 옮긴다) 여기서 적용하는 오프셋과 뷰포트의 위치를 따로 받는다. 뷰포트의 위치는 position:fixed 상자가 머무르고 position:sticky 상자가 붙는 기준이며 뷰포트의 크기는 레이아웃이 쓴 것이다.

Parameters:
g - the graphics of the component / 컴포넌트의 그래픽스
list - the display list / 디스플레이 리스트
clip - the area to paint in device coordinates, null for the clip of the graphics / 기기 좌표로 그릴 영역. null 이면 그래픽스의 클립
scrollX - horizontal offset that is applied to the graphics here (0 if the host moved it already) / 여기서 그래픽스에 적용하는 가로 오프셋(호스트가 이미 옮겼으면 0)

viewX - x of the top-left corner of the viewport in document px / 뷰포트 왼쪽 위 모서리의 문서 px 단위 x
viewY - y of the top-left corner of the viewport in document px / 뷰포트 왼쪽 위 모서리의 y
