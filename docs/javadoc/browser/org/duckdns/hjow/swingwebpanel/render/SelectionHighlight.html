org.duckdns.hjow.swingwebpanel.render
Class SelectionHighlight

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.SelectionHighlight

public final class SelectionHighlight
extends java.lang.Object

The drawn highlight of a selection (plan item P11-08): the area of the selected text and replaced elements of one rendered page, as one shape in document coordinates. The document thread computes it with TextSelections.highlight(org.duckdns.hjow.swingwebpanel.dom.Range) when the selection or the layout changed and hands it over; the event dispatch thread only paints it on top of the page, scaled by the zoom factor. It is immutable. The area is filled in one operation, so rectangles that overlap by a fraction of a pixel are not blended twice. The default color is the system blue as a translucent overlay (the text stays visible below it); the ::selection pseudo-element is not applied yet.

선택의 그려지는 강조(계획 P11-08): 한 렌더링된 페이지의 선택된 텍스트와 치환 요소의 영역을 문서 좌표의 도형 하나로 나타낸다. 선택이나 레이아웃이 바뀌면 문서 스레드가 TextSelections.highlight(org.duckdns.hjow.swingwebpanel.dom.Range) 로 계산해 넘기고, 이벤트 디스패치 스레드는 그것을 배율에 맞춰 페이지 위에 그리기만 한다. 불변이다. 영역은 한 번에 채우므로 조금씩 겹치는 사각형이 두 번 섞이지 않는다. 기본 색은 시스템 파란색의 반투명 덧칠이다(그 아래 글자가 보인다). ::selection 의사 요소는 아직 적용하지 않는다.

paint

public void paint(java.awt.Graphics2D g,
                  double scale)
Paints the highlight. The graphics must be in component coordinates (the page is painted with the same call: the document is scaled by the zoom factor and the scroll position is the translation of the component); its state is put back when this returns.

강조를 그린다. 그래픽스는 컴포넌트 좌표여야 한다(페이지도 같은 방식으로 그려진다: 문서를 배율로 확대하며 스크롤 위치는 컴포넌트의 이동이다). 돌아올 때 그래픽스의 상태를 되돌린다.

Parameters:
g - the graphics of the component / 컴포넌트의 그래픽스
scale - the zoom factor, 1 for 100 percent / 확대 배율. 1 이면 100 %
