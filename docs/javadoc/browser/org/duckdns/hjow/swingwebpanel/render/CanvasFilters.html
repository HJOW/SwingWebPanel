Class CanvasFilters

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.CanvasFilters

public final class CanvasFilters
extends java.lang.Object

The filter functions of the 2D canvas (context.filter, HTML Living Standard 4.12.5.1.20): the public door to the pixel code of FilterRenderer that the page layout uses for the CSS filter property, with a parser for a string that is a <filter-value-list>. A value is valid when the grammar of the filter property accepts it (CSS-wide keywords such as inherit and var() are refused as the canvas specification demands); only the functions (blur(), brightness(), contrast(), drop-shadow(), grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia()) have an effect, a url() reference to an SVG filter is valid but filters nothing (the filter of the canvas is applied "with no filtering" as for a document that is not loaded). Relative lengths (em) are resolved against the font size that is given at the time the value is parsed. The lengths are pixels of the bitmap and are not affected by the transformation of the context.

2D 캔버스의 필터 함수(context.filter, HTML Living Standard 4.12.5.1.20): 페이지 레이아웃이 CSS filter 속성에 쓰는 FilterRenderer 의 화소 코드로 가는 공개 문이며 <filter-value-list> 인 문자열의 해석기가 딸려 있다. 값은 filter 속성의 문법이 받아들이면 올바르다(inherit 같은 CSS 전역 키워드와 var() 는 캔버스 규격이 요구하는 대로 거부한다). 함수(blur(), brightness(), contrast(), drop-shadow(), grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia())만 효과가 있고 SVG 필터를 가리키는 url() 은 올바르지만 아무것도 거르지 않는다 (문서가 로드되지 않은 것처럼 "필터 없이" 그린다). 상대 길이(em)는 값을 해석할 때 주어진 글꼴 크기를 기준으로 환산한다. 길이는 비트맵의 화소이며 컨텍스트의 변환의 영향을 받지 않는다.
