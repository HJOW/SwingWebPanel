Package org.duckdns.hjow.swingwebpanel.render

Rendering: display list, Java2D painter, coordinate transforms and hit testing.

See:
          Description

Interface Summary
CanvasSource Supplies the pictures of canvas elements to the renderer.
CorsImageSource An ImageSource that can also give the state of an image that is fetched in CORS mode, for an img element with a crossorigin attribute.
FrameSource Supplies the pictures of nested browsing contexts (iframe and frame elements) to the renderer.
ImageSource Supplies the images and media states that the renderer needs while it builds a display list.
MediaControlSource Supplies the state of the control bars of audio elements to the renderer (plan item P18-08).
 

Class Summary
BlendModes The blend modes of CSS Compositing and Blending Level 1 (https://www.w3.org/TR/compositing-1/, Candidate Recommendation Draft 2024-03-21, retrieved 2026-11-17, section 10 "Blending"): the separable modes multiply, screen, overlay, darken, lighten, color-dodge, color-burn, hard-light, soft-light, difference and exclusion, the non-separable modes hue, saturation, color and luminosity, and plus-lighter (the sum of the premultiplied colors, limited to 1).
CanvasFilters The filter functions of the 2D canvas (context.filter, HTML Living Standard 4.12.5.1.20): the public door to the pixel code of FilterRenderer that the page layout uses for the CSS filter property, with a parser for a string that is a <filter-value-list>.
CanvasFilters.Parsed The result of parsing a filter string.
CanvasSizes The size rules of the canvas element: the width and height attributes are parsed with the rules for non-negative integers and fall back to 300 and 150 when they are absent or invalid (each independently).
ControlSnapshot An immutable copy of everything that is needed to draw a form control or to put an editor over it: the kind of control, its boxes in document coordinates, its font and colors, and its state (the shown text, checked, disabled, the rows of a list ...).
ControlSnapshot.Row One row of a list box.
DisplayCommand One drawing command of a DisplayList (plan items P09-04, P09-05).
DisplayList The immutable list of drawing commands of one page in paint order (plan items P09-04, P09-05).
FramePicture The picture of a nested browsing context (iframe, frame) that the renderer paints inside the content box of the frame element: the immutable, fully rendered page of the frame (laid out for the size of the box), the scroll position of the frame and which overlay scrollbars to draw.
FrameScroll The arithmetic of the scrolling of a frame: how far a frame may scroll, where the thumb of an overlay scrollbar is and how a position of the thumb maps back to a scroll offset.
HitResult The result of a hit test (plan item P09-06): the deepest layout box at a point, the DOM element it belongs to, the nearest enclosing link with its absolute URL and, over text, the text node with the character offset.
HitTester Maps points to page content and content to rectangles (plan item P09-06), on top of the immutable LayoutResult.
ImageLookup Finds the image of an img element in an ImageSource: the element with a crossorigin attribute gets the image that was fetched in CORS mode (when the source offers it, see CorsImageSource), every other element the plain image.
ImageMaps Client-side image maps of HTML (HTML5 REC 2014-10-28 section 4.7.13, https://www.w3.org/TR/2014/REC-html5-20141028/embedded-content-0.html#image-maps, retrieved 2026-11-17): an img with a usemap attribute is associated with the map element that the attribute names, and the area elements of the map are shapes that are layered on the image in reverse tree order (the first area in tree order is the top-most shape).
ImageReplacedResolver Gives the layout the natural size of loaded img elements, read from an ImageSource; images that are not loaded give no content, so the layout falls back to the width/height attributes and its defaults (plan items P09-02, P18-05).
ImageResource The state of an image or media resource as the renderer sees it when it builds a display list (plan items P09-05, P18-06): loaded (with the decoded image for images), failed (with the reason) or still pending.
ImageSelection Chooses the source of an img element (plan item P18-05): the src attribute, the srcset and sizes attributes, and the source siblings in front of it when its parent is a picture element.
ImageSelection.Choice The result of a selection: the chosen URL as written in the document and its density.
MediaControls The geometry of the control bar of an audio element with controls (plan item P18-08): where the play button, the time label, the seek bar, the mute button and the volume slider are in a bar of a given size, which one lies under a point, and what position or volume a point on a slider means.
MediaControls.Layout The rectangles of the parts, each as x, y, width, height relative to the top left corner of the bar, or null if the part is not shown.
MediaControlState An immutable snapshot of what the control bar of an audio element with the controls attribute shows (plan item P18-08): whether a resource is loaded, whether the element is paused or ended, the position and the length in seconds, the volume and the mute flag.
PagePainter Paints a DisplayList with Java2D (plan items P09-04, P09-05).
PageRenderer Renders a document: layout followed by the display list (plan items P09-04 to P09-07).
RenderedPage An immutable, fully rendered page (plan items P09-04 to P09-07): the LayoutResult, the DisplayList built from it and a HitTester.
RenderedText Collects the layout text read by HTMLElement.innerText (HTML §3.2.7).
SelectionHighlight The drawn highlight of a selection (plan item P11-08): the area of the selected text and replaced elements of one rendered page, as one shape in document coordinates.
TextSelections What a selection means on the screen of one rendered page (plan item P11-08): where the caret goes for a point of the page, which part of the page a Range covers (the SelectionHighlight), and which text the user copies.
TextSelections.Caret The position of the caret for a point: a text node and an offset in its data, with the layout fragment that the point belongs to.
