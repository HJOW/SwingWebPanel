org.duckdns.hjow.swingwebpanel.render
Class TextSelections

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.TextSelections

public final class TextSelections
extends java.lang.Object

What a selection means on the screen of one rendered page (plan item P11-08): where the caret goes for a point of the page, which part of the page a Range covers (the SelectionHighlight), and which text the user copies. It joins the DOM Range with the layout of the page, using the same mapping between the characters of a text node and the layout fragments that HitTester.hit(double, double) uses (a fragment keeps the range of the source data that it painted). An instance belongs to one RenderedPage; it reads only immutable layout data, but it must be used on the document thread because it reads the DOM.

Copied text rules (innerText-like): the painted text of the selected fragments (white space already collapsed); nothing between fragments of one line; a space between lines of one block that were broken by wrapping, a line feed when the source has a line feed and white-space keeps it; a line feed for br; a line feed between different blocks, two for a p; a tab between table cells of one row and a line feed between rows; nothing for text that is user-select: none or hidden.

한 렌더링된 페이지의 화면에서 선택이 뜻하는 것(계획 P11-08): 페이지의 한 점에 캐럿이 놓일 곳, Range 가 덮는 페이지의 부분(SelectionHighlight), 사용자가 복사하는 텍스트. DOM Range 를 페이지의 레이아웃과 잇는다. 텍스트 노드의 문자와 레이아웃 조각 사이의 대응은 HitTester.hit(double, double) 가 쓰는 것과 같다(조각은 자기가 그린 원본 데이터의 범위를 가진다). 인스턴스는 한 RenderedPage 에 속하며 불변 레이아웃 데이터만 읽지만 DOM 을 읽으므로 문서 스레드에서 써야 한다.

복사 문자열 규칙(innerText 와 비슷): 선택된 조각의 그려진 텍스트(공백은 이미 접혀 있다). 한 줄의 조각 사이에는 아무것도 없고, 한 블록에서 자동으로 줄이 바뀐 곳에는 공백 한 칸, 원본에 개행이 있고 white-space 가 보존하면 줄바꿈 한 개, br 은 줄바꿈 한 개, 다른 블록 사이는 줄바꿈 한 개 (p 이면 두 개), 한 행의 표 셀 사이는 탭, 행 사이는 줄바꿈이다. user-select: none 이거나 숨겨진 텍스트는 넣지 않는다.

caretRectAt

public java.awt.geom.Rectangle2D caretRectAt(Node container,
                                             int offset)
Returns the rectangle of the caret at any DOM position (zero width, as high as the line), in document coordinates, or null if the position has no place on the page. A position in a text node is the position of that character boundary; a position in an element takes the end of the text before it, else the start of the text or the box after it, else the content box of the element itself (an empty block); a position right after a br is the start of the next line. This is where the editing caret is drawn and what a collapsed range reports as its rectangle.

아무 DOM 위치의 캐럿 사각형(너비 0, 줄 높이)을 문서 좌표로 반환한다. 위치가 페이지에 자리가 없으면 null. 텍스트 노드 안의 위치는 그 문자 경계이고, 요소 안의 위치는 앞의 텍스트의 끝, 없으면 뒤의 텍스트나 상자의 시작, 그것도 없으면 요소 자신의 내용 상자(빈 블록)이다. br 바로 뒤의 위치는 다음 줄의 시작이다. 편집 캐럿을 그리는 곳이며 접힌 범위가 자신의 사각형으로 알리는 값이다.

Parameters:
container - the node of the position / 위치의 노드
offset - the offset of the position / 위치의 오프셋
Returns:
the rectangle or null / 사각형. 없으면 null

rects

public java.util.List<java.awt.geom.Rectangle2D> rects(Range range)
Returns the client rectangles of a range in document coordinates (CSSOM View, Range.getClientRects()): the border boxes of every element that the range selects completely and whose parent it does not select, and for every text node that the range selects or partly selects the rectangles of the selected characters, one per line (the fragments of one line are joined). The result is in tree order. A collapsed range in a text node gives one rectangle of zero width at the caret; a collapsed range elsewhere gives the place of the caret if there is one. The rectangles include the transform of the boxes; clipping by overflow does not apply.

범위의 클라이언트 사각형을 문서 좌표로 반환한다(CSSOM View, Range.getClientRects()): 범위가 완전히 선택하고 부모는 선택하지 않는 모든 요소의 border box, 그리고 범위가 선택하거나 일부 선택하는 모든 텍스트 노드의 선택된 글자 사각형(줄마다 하나이며 한 줄의 조각은 합친다). 결과는 트리 순서이다. 텍스트 노드 안의 접힌 범위는 캐럿 위치의 너비 0 사각형 하나이고, 그 밖의 접힌 범위는 캐럿 자리가 있으면 그것이다. 사각형에는 상자의 변환이 들어가며 overflow 로 자르는 것은 적용하지 않는다.

Parameters:
range - the range, may be null / 범위. null 가능
Returns:
the rectangles / 사각형 목록

step

public TextSelections.Caret step(Node node,
                                 int offset,
                                 boolean forward,
                                 boolean word)
Moves a caret position by one character (or one word) to the visible position that follows or precedes it, crossing into the next or the previous text node of the page. A position in an element (after Select All) is first moved to the text position nearest to it. White space that the layout collapsed is skipped, so every step moves to a position that the user can see.

캐럿 위치를 글자 하나(또는 낱말 하나)만큼 뒤나 앞의 보이는 위치로 옮기며, 페이지의 다음이나 이전 텍스트 노드로 넘어간다. 요소 안의 위치(전체 선택 뒤)는 먼저 가장 가까운 텍스트 위치로 옮긴다. 레이아웃이 접은 공백은 건너뛰므로 모든 걸음은 사용자가 볼 수 있는 위치로 간다.

Parameters:
node - the node of the position / 위치의 노드
offset - the offset of the position / 위치의 오프셋
forward - true to move forward (to the right), false to move backward / 앞(오른쪽)으로 가면 true, 뒤로 가면 false
word - true to move by a word / 낱말 단위이면 true
Returns:
the new position, or null if there is no further position / 새 위치. 더 갈 곳이 없으면 null
