org.duckdns.hjow.swingwebpanel.render
Class MediaControlState

java.lang.Object
  org.duckdns.hjow.swingwebpanel.render.MediaControlState

public final class MediaControlState
extends java.lang.Object

An immutable snapshot of what the control bar of an audio element with the controls attribute shows (plan item P18-08): whether a resource is loaded, whether the element is paused or ended, the position and the length in seconds, the volume and the mute flag. The script host takes the snapshot on the document thread and the renderer paints it, so painting never reads the live state of the element.

controls 속성이 있는 audio 요소의 컨트롤 막대가 보여 주는 것의 불변 스냅샷(계획 P18-08): 리소스가 로드되었는지, 요소가 일시정지되었거나 끝났는지, 초 단위의 위치와 길이, 음량과 음소거 플래그. 스크립트 호스트가 문서 스레드에서 스냅샷을 떠고 렌더러가 그것을 그리므로 그리기는 요소의 실시간 상태를 읽지 않는다.
