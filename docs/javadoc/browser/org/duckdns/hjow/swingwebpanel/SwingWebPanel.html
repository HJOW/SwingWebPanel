public class SwingWebPanel
extends javax.swing.JPanel
implements javax.swing.Scrollable

A web browser component for Swing, written in pure Java 6 without external libraries. Put it in a window directly, or wrap it in a JScrollPane to get scrolling: new JScrollPane(new SwingWebPanel()); the component never creates a scroll pane of its own.

Basic use: panel.setPage("http://example.com/") starts an asynchronous navigation and returns at once; panel.setContent("<h1>Hi</h1>", "text/html") shows content you already have. Query methods return the last confirmed state, so while a page is loading they still describe the previous page. All public methods can be called from the event dispatch thread or from any other thread; property changes ("page", "statusText", "progress", "title") are announced on the event dispatch thread. Call dispose() when the component is no longer needed. The full contract of every method is in docs/API_CONTRACT.md.

Scrolling policy (Scrollable): the content tracks the viewport width as long as the laid-out content can fit (its minimum width is not larger than the viewport); only when the page needs more width than the viewport offers does the view keep its own width and a horizontal scroll bar appear. The view tracks the viewport height when the content is shorter than the viewport, otherwise it scrolls vertically. One scroll step is the line height reported by the layout engine (16 pixels until one exists); a block step is the visible size minus one step.

Swing 용 웹 브라우저 컴포넌트. 외부 라이브러리 없이 순수 Java 6 로 작성했다. 창에 직접 넣거나 JScrollPane 으로 감싸 스크롤을 얻는다: new JScrollPane(new SwingWebPanel()). 컴포넌트가 자체 스크롤 창을 만들지는 않는다.

기본 사용: panel.setPage("http://example.com/") 는 비동기 이동을 시작하고 즉시 반환한다. panel.setContent("<h1>Hi</h1>", "text/html") 은 이미 가진 콘텐츠를 보여 준다. 조회 메서드는 마지막 확정된 상태를 반환하므로 로딩 중에는 이전 페이지를 설명한다. 모든 공개 메서드는 이벤트 디스패치 스레드나 다른 어떤 스레드에서도 호출할 수 있고, 속성 변경("page", "statusText", "progress", "title")은 이벤트 디스패치 스레드에서 통지한다. 컴포넌트가 더 필요 없으면 dispose() 를 호출한다. 모든 메서드의 상세 계약은 docs/API_CONTRACT.md 에 있다.

스크롤 정책(Scrollable): 배치된 콘텐츠가 들어갈 수 있는 동안(최소 폭이 뷰포트보다 크지 않은 동안)에는 콘텐츠가 뷰포트 폭을 따라간다. 페이지가 뷰포트보다 넓은 폭을 필요로 할 때만 자기 폭을 유지하며 가로 스크롤 막대가 나타난다. 콘텐츠가 뷰포트보다 낮으면 뷰포트 높이를 따라가고, 아니면 세로로 스크롤한다. 스크롤 한 단위는 레이아웃 엔진이 알려 주는 줄 높이(엔진이 생기기 전에는 16 픽셀)이고, 블록 단위는 보이는 크기에서 한 단위를 뺀 값이다.
