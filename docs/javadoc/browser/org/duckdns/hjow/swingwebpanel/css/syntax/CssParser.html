Class CssParser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.syntax.CssParser

public final class CssParser
extends java.lang.Object

The parser of CSS Syntax Module Level 3 (section 5, "Parsing"): it turns text into component values and the component values into rules and declarations, with the error recovery of the specification. A broken declaration is skipped up to the next semicolon, a rule without a block is dropped, an unterminated block is closed at the end of input, and none of this affects the neighbouring declarations and rules.

Entry points: parseStylesheet(java.lang.String, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics), parseRuleList(java.util.List, boolean, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics) (the contents of @media), parseDeclarationList(java.lang.String, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics) (a style attribute), parseDeclaration(java.lang.String), parseComponentValues(java.lang.String), splitCommas(java.util.List).

CSS Syntax Module Level 3 의 파서(5절 "Parsing"): 텍스트를 컴포넌트 값으로, 컴포넌트 값을 규칙과 선언으로 바꾸며 규격의 오류 복구를 따른다. 잘못된 선언은 다음 세미콜론까지 건너뛰고, 블록이 없는 규칙은 버리며, 끝나지 않은 블록은 입력 끝에서 닫는다. 이런 처리는 이웃 선언과 규칙에 영향을 주지 않는다.

진입점: parseStylesheet(java.lang.String, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics), parseRuleList(java.util.List, boolean, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics)(@media 의 내용), parseDeclarationList(java.lang.String, org.duckdns.hjow.swingwebpanel.css.CssDiagnostics)(style 속성), parseDeclaration(java.lang.String), parseComponentValues(java.lang.String), splitCommas(java.util.List).

MAX_NESTING

public static final int MAX_NESTING
Maximum nesting depth of blocks and functions. Hostile input that nests deeper is treated as if the text ended there, so that no recursive consumer (calc parsing, var() substitution, serialization) can overflow the Java stack.

블록과 함수의 최대 중첩 깊이. 이보다 깊이 중첩한 악의적인 입력은 거기서 텍스트가 끝난 것으로 다뤄, 재귀하는 소비자(calc 파싱, var() 치환, 직렬화)가 Java 스택을 넘치게 하지 못한다.

parseComponentValues

public static java.util.List<ComponentValue> parseComponentValues(java.lang.String text)
Tokenizes text and groups the tokens into component values (blocks and functions are nested). The nesting is handled with an explicit stack, so even extremely deep input cannot overflow the Java stack; blocks left open at the end of input are closed implicitly.

텍스트를 토큰화하고 토큰을 컴포넌트 값(블록과 함수는 중첩)으로 묶는다. 중첩은 명시적 스택으로 처리하므로 아주 깊은 입력도 Java 스택을 넘치게 하지 않으며, 입력 끝에서 열려 있는 블록은 암묵적으로 닫는다.

parseBlockContents

public static java.util.List<java.lang.Object> parseBlockContents(java.util.List<ComponentValue> list,
                                                                  CssDiagnostics diag)
Parses the contents of a style rule block that may nest rules (CSS Nesting Module Level 1, CSS Syntax Level 3 "consume a block's contents"): the declarations, the nested qualified rules and the nested at-rules in source order. A segment that starts with an identifier is a declaration unless it contains a top-level {} block next to other values (a:hover { ... } is a nested rule, --x: { } is a custom property declaration); a segment that ends in a block is a nested qualified rule whose prelude is what precedes the block.

규칙을 중첩할 수 있는 스타일 규칙 블록의 내용을 파싱한다(CSS Nesting Module Level 1, CSS Syntax Level 3 "consume a block's contents"): 선언, 중첩된 한정 규칙, 중첩된 at-규칙을 소스 순서대로. 식별자로 시작하는 조각은, 다른 값과 함께 최상위 {} 블록이 들어 있지 않으면 선언이다(a:hover { ... } 는 중첩 규칙이고 --x: { } 는 사용자 정의 속성 선언이다). 블록으로 끝나는 조각은 블록 앞이 전문인 중첩 한정 규칙이다.

Parameters:
list - component values (block contents) / 컴포넌트 값(블록의 내용)
diag - collector or null / 수집기 또는 null
Returns:
a list of SyntaxDeclaration and SyntaxRule objects in source order / 소스 순서의 SyntaxDeclaration 과 SyntaxRule 목록
