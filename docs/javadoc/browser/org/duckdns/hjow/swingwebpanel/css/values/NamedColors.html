Class NamedColors

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.values.NamedColors

public final class NamedColors
extends java.lang.Object

The named colors of CSS Color Level 4 (148 keywords including the grey/gray spellings) and the system colors, with the values of the light color scheme. transparent and currentcolor are handled by the callers.

CSS Color Level 4 의 이름 있는 색(grey/gray 철자를 포함한 148개 키워드)과 시스템 색(밝은 색 구성표의 값). transparent 와 currentcolor 는 호출하는 쪽이 처리한다.
