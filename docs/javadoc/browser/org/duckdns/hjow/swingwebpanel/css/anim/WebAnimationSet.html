org.duckdns.hjow.swingwebpanel.css.anim
Class WebAnimationSet

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.WebAnimationSet

public final class WebAnimationSet
extends java.lang.Object

The Web Animations state of one document (Web Animations Level 1): the animations created by scripts in their global order (the composite order among them), the time of the document that the WebTimelines follow, the pending animation event queue and the procedure "update animations and send events" (update(double) for the timelines, the pending tasks, the finished states and the removal of replaced animations, then takeEvents() after the host's microtask checkpoint). The style side uses apply(Element, String, ComputedStyle): the AnimationEngine calls it after the CSS transitions and animations, so script animations are at the top of the effect stack (5.4.2: CSS transitions, then CSS animations, then the other animations). Only the animations that can still change something are kept ("tracked"); an idle animation or one that finished without fill is let go and comes back when a script changes it, so finished animations do not accumulate. The document time is the time of the host's clock while nothing is waiting for a frame and it stays at the time of the last frame while animations run, as the specification wants (document.timeline.currentTime does not change between frames). Every method runs on the document thread.

한 문서의 Web Animations 상태(Web Animations Level 1): 스크립트가 만든 애니메이션의 전역 순서(그 사이의 합성 순서), WebTimeline 이 따르는 문서 시간, 대기 애니메이션 이벤트 큐, "update animations and send events" 절차(타임라인, 대기 작업, 끝남 상태, 교체된 애니메이션 제거는 update(double), 호스트의 마이크로태스크 검사점 뒤의 takeEvents()). 스타일 쪽은 apply(Element, String, ComputedStyle) 를 쓴다: AnimationEngine 이 CSS 전환과 애니메이션 뒤에 부르므로 스크립트 애니메이션이 효과 스택의 맨 위에 있다(5.4.2: CSS 전환, CSS 애니메이션, 그 밖의 애니메이션 순). 아직 무언가를 바꿀 수 있는 애니메이션만 보관하며("추적") 유휴 상태이거나 채움 없이 끝난 애니메이션은 놓아 주고 스크립트가 바꾸면 다시 돌아오므로 끝난 애니메이션이 쌓이지 않는다. 문서 시간은 프레임을 기다리는 것이 없을 때는 호스트 시계의 시간이고 애니메이션이 도는 동안은 마지막 프레임의 시간에 머문다(규격대로 document.timeline.currentTime 은 프레임 사이에 바뀌지 않는다). 모든 메서드는 문서 스레드에서 실행된다.

update

public void update(double now)
Runs the first part of "update animations and send events" (4.3) at a time of the document: the timelines take the time, the pending play and pause tasks of the ready animations run, the finished states are updated and the replaced animations are removed; the targets are restyled. The host then performs a microtask checkpoint and dispatches takeEvents().

문서 시각에서 "update animations and send events"(4.3)의 앞부분을 실행한다: 타임라인이 시간을 받고, 준비된 애니메이션의 대기 play/pause 작업이 실행되며, 끝남 상태를 갱신하고 교체된 애니메이션을 제거한다. 대상의 스타일을 다시 계산하게 한다. 그 뒤 호스트가 마이크로태스크 검사점을 수행하고 takeEvents() 를 전달한다.

Parameters:
now - the time of the document in milliseconds / 문서 시각(밀리초)
