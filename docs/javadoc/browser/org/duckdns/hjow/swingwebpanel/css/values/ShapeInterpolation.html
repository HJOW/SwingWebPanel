Class ShapeInterpolation

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.values.ShapeInterpolation

public final class ShapeInterpolation
extends java.lang.Object

Interpolation of offset paths (plan item P10-08-h, CSS Motion Path 1 section 2.1, "Animation type: by computed value", with the rules of CSS Shapes 1 for <basic-shape>): two shape functions of the same kind with the same structure interpolate their numbers (lengths with lengths, percentages with percentages, angles, numbers; keywords and the reference box must be equal), two path() values with the same commands interpolate their coordinates (an arc keeps its flags only if they are equal), and two ray() values interpolate their angle and position when the size and contain are equal. Anything else (another function, another reference box, a url(), a length mixed with a percentage) is not interpolated, and the animation is discrete.

오프셋 경로의 보간(계획 P10-08-h, CSS Motion Path 1 2.1 절의 "계산 값으로", <basic-shape> 에 대한 CSS Shapes 1 의 규칙): 같은 종류이고 구조가 같은 두 도형 함수는 수를 보간하고(길이는 길이와, 백분율은 백분율과, 각도, 수. 키워드와 기준 상자는 같아야 한다), 명령이 같은 두 path() 는 좌표를 보간하며(호는 깃발이 같을 때만), 크기와 contain 이 같은 두 ray() 는 각도와 위치를 보간한다. 그 밖의 경우(다른 함수, 다른 기준 상자, url(), 길이와 백분율이 섞임)는 보간하지 않으며 애니메이션은 이산이다.
