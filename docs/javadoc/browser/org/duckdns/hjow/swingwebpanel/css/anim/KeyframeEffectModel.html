org.duckdns.hjow.swingwebpanel.css.anim
Class KeyframeEffectModel

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.KeyframeEffectModel

public final class KeyframeEffectModel
extends java.lang.Object

A keyframe effect of Web Animations Level 1 (sections 5.3 and 6.6, KeyframeEffect): an effect target (an element and an optional pseudo-element such as ::before), the timing properties (EffectTiming), the composite operation of the effect and the list of keyframes. A KeyframeEffectModel.Keyframe holds its offset (null for automatic spacing), its computed offset, its timing function, its keyframe-specific composite operation (null for auto) and its property values as specified (CSS names and serialized values, what getKeyframes() reports) together with the parsed declarations. apply(org.duckdns.hjow.swingwebpanel.css.cascade.StyleResolver, org.duckdns.hjow.swingwebpanel.dom.Element, org.duckdns.hjow.swingwebpanel.css.cascade.ComputedStyle, double) computes the effect value of every target property for an iteration progress (section 5.3.4: property-specific keyframes, the implicit keyframes at 0 and 1 with the underlying value, the interval, the keyframe timing function, interpolation by Interpolator and composition by Compositor) and returns the style with these values. The values of the keyframes are computed against the target element (relative lengths use its font size, logical properties map to physical ones) and cached while the keyframes, the font size, the color and the writing mode of the target do not change. The iteration composite operation of Web Animations Level 2 is stored and reported but not applied.

Web Animations Level 1 의 키프레임 효과(5.3 절과 6.6 절, KeyframeEffect): 효과 대상(요소와 ::before 같은 선택적 의사 요소), 시간 속성 (EffectTiming), 효과의 합성 연산, 키프레임 목록. KeyframeEffectModel.Keyframe 는 오프셋(자동 간격이면 null), 계산된 오프셋, 완화 함수, 키프레임별 합성 연산 (auto 이면 null), 지정한 속성 값(CSS 이름과 직렬화한 값, getKeyframes() 가 알려 주는 것)과 해석한 선언을 가진다. apply(org.duckdns.hjow.swingwebpanel.css.cascade.StyleResolver, org.duckdns.hjow.swingwebpanel.dom.Element, org.duckdns.hjow.swingwebpanel.css.cascade.ComputedStyle, double) 는 반복 진행도에 대한 모든 대상 속성의 효과 값을 계산하고(5.3.4 절: 속성별 키프레임, 기저 값을 가진 0 과 1 의 암묵 키프레임, 구간, 키프레임 완화 함수, Interpolator 의 보간, Compositor 의 합성) 그 값을 가진 스타일을 반환한다. 키프레임의 값은 대상 요소를 기준으로 계산하며(상대 길이는 그 글꼴 크기, 논리 속성은 물리 속성으로) 키프레임, 대상의 글꼴 크기, 색, 쓰기 모드가 바뀌지 않는 동안 캐시한다. Web Animations Level 2 의 반복 합성 연산은 보관하고 알려 주지만 적용하지 않는다.

Creates a keyframe from the values of a script (the result of "process a keyframe-like object" for one keyframe): the property-value pairs whose value does not parse for the property are discarded (section 6.6.3). When several pairs name the same longhand, a longhand wins over a shorthand, a shorthand with fewer longhands over one with more, and among equal shorthands the one whose IDL name sorts first (5.3.3).

스크립트의 값으로 키프레임을 만든다(키프레임 하나에 대한 "process a keyframe-like object" 의 결과): 속성에 대해 해석되지 않는 값을 가진 쌍은 버린다(6.6.3 절). 여러 쌍이 같은 개별 속성을 가리키면 개별 속성이 단축 속성을, 개별 속성이 적은 단축 속성이 많은 것을, 같은 단축 속성끼리는 IDL 이름이 먼저 오는 것이 이긴다(5.3.3).
