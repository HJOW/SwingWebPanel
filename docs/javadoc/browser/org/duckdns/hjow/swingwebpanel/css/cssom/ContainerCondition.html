Class ContainerCondition

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.ContainerCondition

public final class ContainerCondition
extends java.lang.Object

The prelude of an @container rule (CSS Conditional Level 5, section 4, "Container Queries"): an optional container name and a condition built from size features in parentheses ((min-width: 400px), (width > 400px), (inline-size < 30em), (aspect-ratio > 1/1), (orientation: landscape)), custom property queries (style(--theme: dark)), nested conditions, and the operators not, and, or. A size feature is evaluated by the media query evaluator against an environment whose size is the content box of the query container (the logical features inline-size and block-size are rewritten to the physical ones by the writing mode of the container). Anything the grammar does not recognise is "unknown", which counts as false; an invalid prelude makes the rule never match.

@container 규칙의 전문(CSS Conditional Level 5, 4 절 "Container Queries"): 선택적인 컨테이너 이름, 그리고 괄호 안의 크기 특성 ((min-width: 400px), (width > 400px), (inline-size < 30em), (aspect-ratio > 1/1), (orientation: landscape)), 사용자 정의 속성 질의(style(--theme: dark)), 중첩된 조건, 연산자 not, and, or 로 만든 조건. 크기 특성은 질의 컨테이너의 content box 크기를 가진 환경에서 미디어 질의 평가기로 평가한다(논리 특성 inline-size, block-size 는 컨테이너의 쓰기 모드에 따라 물리 특성으로 바꾼다). 문법이 알아보지 못하는 것은 "unknown" 이며 거짓으로 센다. 올바르지 않은 전문은 규칙이 절대 일치하지 않게 한다.
