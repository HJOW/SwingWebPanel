Class Easing

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.Easing

public abstract class Easing
extends java.lang.Object

An easing (timing) function (plan item P10-07, CSS Easing Functions Level 1, https://www.w3.org/TR/css-easing-1/): a function from the input progress of an animation or a transition to the output progress. The keywords linear, ease, ease-in, ease-out, ease-in-out, step-start, step-end and the functions cubic-bezier() and steps() (with the jump terms jump-start, jump-end, jump-none, jump-both, start, end) are read from the computed value. The linear() function with stops is not interpreted: it behaves as the linear easing. A cubic Bezier output may leave the range 0..1 (overshoot) because only the x values of the control points are limited to 0..1. An instance is immutable.

완화(타이밍) 함수(계획 P10-07, CSS Easing Functions Level 1, https://www.w3.org/TR/css-easing-1/): 애니메이션이나 전환의 입력 진행도를 출력 진행도로 바꾸는 함수. 키워드 linear, ease, ease-in, ease-out, ease-in-out, step-start, step-end 와 함수 cubic-bezier(), steps()(점프 항 jump-start, jump-end, jump-none, jump-both, start, end)를 계산 값에서 읽는다. 정지점이 있는 linear() 함수는 해석하지 않고 선형 완화처럼 동작한다. 3차 베지어 출력은 0..1 을 벗어날 수 있다(제어점의 x 만 0..1 로 제한되기 때문). 인스턴스는 불변이다.
