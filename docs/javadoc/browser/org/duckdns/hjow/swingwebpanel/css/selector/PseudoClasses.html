org.duckdns.hjow.swingwebpanel.css.selector
Class PseudoClasses

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.PseudoClasses

public final class PseudoClasses
extends java.lang.Object

The registry of the pseudo-classes and pseudo-elements the selector parser knows. Each pseudo-class has a numeric id (used by the matcher instead of string comparisons) and an argument kind that tells the parser what its parentheses may contain. A name that is not in the registry makes the whole selector invalid, exactly as in a browser. Some pseudo-classes are known and valid but can never match in this engine (for example :fullscreen); they are registered with NEVER.

선택자 파서가 아는 의사 클래스와 의사 요소의 등록부. 각 의사 클래스에는 숫자 id(매처가 문자열 비교 대신 사용)와 괄호 안에 올 수 있는 내용을 알려 주는 인수 종류가 있다. 등록부에 없는 이름은 브라우저처럼 선택자 전체를 무효로 만든다. 일부 의사 클래스(예: :fullscreen)는 올바르지만 이 엔진에서는 일치할 수 없으며 NEVER 로 등록한다.
