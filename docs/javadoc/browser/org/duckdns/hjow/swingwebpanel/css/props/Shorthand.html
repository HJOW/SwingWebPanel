Class Shorthand

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.props.Shorthand

public abstract class Shorthand
extends java.lang.Object

A shorthand property: a name that sets several longhand properties from one value. The parser of a shorthand receives the component values of the declaration (whitespace removed) and writes one specified value for every longhand it sets; longhands the written value does not mention are set to initial. Subclasses live in Shorthands.

단축 속성: 값 하나로 여러 개별 속성을 정하는 이름. 단축 속성의 파서는 선언의 컴포넌트 값(공백 제거)을 받아 정하는 모든 개별 속성에 지정 값 하나씩을 쓰며, 쓰인 값이 언급하지 않는 개별 속성은 initial 로 정한다. 하위 클래스는 Shorthands 에 있다.
