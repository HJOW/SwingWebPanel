org.duckdns.hjow.swingwebpanel.css.anim
Class WebTimeline

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.WebTimeline

public final class WebTimeline
extends java.lang.Object

A document timeline of Web Animations Level 1 (sections 4.3.1, 4.3.2 and 6.3, DocumentTimeline): its current time is the time of the document (milliseconds since the time origin of the page, the clock of performance.now() and requestAnimationFrame) minus its origin time. The default document timeline (document.timeline) has the origin time 0; scripts create others with new DocumentTimeline({originTime}). A timeline is inactive (its current time is NaN) while the document has no time, which is the case for a document without a script host and after the page was disposed. It is monotonically increasing.

Web Animations Level 1 의 문서 타임라인(4.3.1, 4.3.2, 6.3 절, DocumentTimeline): 현재 시간은 문서의 시간(페이지의 시간 기준점 이후 밀리초, performance.now() 와 requestAnimationFrame 의 시계)에서 원점 시간을 뺀 것이다. 기본 문서 타임라인(document.timeline)의 원점 시간은 0 이며 스크립트는 new DocumentTimeline({originTime}) 으로 다른 것을 만든다. 문서에 시간이 없는 동안(스크립트 호스트가 없는 문서와 폐기된 페이지) 타임라인은 비활성(현재 시간이 NaN)이다. 단조 증가한다.
