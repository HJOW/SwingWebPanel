Class CssUrl

public final class CssUrl
extends CssValue

A url() value. The URL text is kept as written; the style sheet builder resolves it against the base URL of the style sheet (the URL of the sheet, not of the document) into an absolute URL when one is known, so that background images and fonts load from the right place.

url() 값. URL 문자열은 쓰인 그대로 보관하며, 스타일 시트 구성기는 기준 URL(문서가 아니라 스타일 시트의 URL)이 알려져 있으면 그에 대해 절대 URL 로 해석해 배경 이미지와 글꼴이 올바른 곳에서 읽히게 한다.
