org.duckdns.hjow.swingwebpanel.css.selector
Class SimpleSelector

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.SimpleSelector

public final class SimpleSelector
extends java.lang.Object

One simple selector: a type or universal selector, an id, a class, an attribute selector or a pseudo-class. A compound selector is a sequence of these. Instances are immutable; the parser builds them with the static factory methods.

단순 선택자 하나: 타입 또는 전체 선택자, id, 클래스, 속성 선택자, 의사 클래스. 복합 선택자는 이들의 나열이다. 인스턴스는 불변이며 파서가 정적 팩토리 메서드로 만든다.
