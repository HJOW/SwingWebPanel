Class Compositor

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.Compositor

public final class Compositor
extends java.lang.Object

The composite operations add and accumulate of Web Animations Level 1 (section 5.4.4) for the computed values that this engine can combine: numbers (an integer stays an integer when both are integers), lengths in pixels, percentages, angles, colors (component-wise sum in the premultiplied space, clamped), transform lists, and space or comma lists of such values of the same length. For transform, add appends the effect list to the underlying list; accumulate adds the arguments of matching functions (scale factors as a + b - 1) and appends when the functions differ (the matrix accumulation of CSS Transforms 2 is not implemented). A value that cannot be combined (a keyword, a length and a percentage) gives null, and the caller uses the effect value as for replace.

이 엔진이 결합할 수 있는 계산 값에 대한 Web Animations Level 1(5.4.4 절)의 합성 연산 add, accumulate: 숫자(둘 다 정수이면 정수 유지), 픽셀 길이, 백분율, 각도, 색(전승산 공간의 성분별 합, 제한), transform 목록, 같은 길이의 그런 값의 공백·쉼표 목록. transform 에서 add 는 효과 목록을 기저 목록 뒤에 붙이고 accumulate 는 같은 함수의 인수를 더하며(배율은 a + b - 1) 함수가 다르면 붙인다 (CSS Transforms 2 의 행렬 누적은 구현하지 않음). 결합할 수 없는 값(키워드, 길이와 백분율)은 null 을 주고 호출자는 replace 처럼 효과 값을 쓴다.
