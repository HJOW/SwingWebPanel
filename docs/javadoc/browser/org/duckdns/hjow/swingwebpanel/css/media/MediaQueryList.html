org.duckdns.hjow.swingwebpanel.css.media
Class MediaQueryList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.media.MediaQueryList

public final class MediaQueryList
extends java.lang.Object

A parsed media query list (Media Queries Level 4): media types with not and only, and / or / not conditions with parentheses, features in boolean ((color)), plain ((min-width: 600px)) and range ((400px <= width < 700px)) form, and unknown features or functions (which are false and cannot be negated into true). A query that cannot be parsed is replaced by not all, as the specification says, without affecting the other queries of the list. The list matches an environment when any of its queries does.

파싱한 미디어 질의 목록(Media Queries Level 4): not, only 가 붙은 미디어 종류, 괄호가 있는 and / or / not 조건, 불리언((color)), 일반((min-width: 600px)), 범위((400px <= width < 700px)) 형태의 특성, 알 수 없는 특성이나 함수(거짓이며 부정해도 참이 되지 않음). 파싱할 수 없는 질의는 규격대로 not all 로 바뀌며 목록의 다른 질의에 영향을 주지 않는다. 목록은 질의 중 하나라도 일치하면 환경과 일치한다.
