org.duckdns.hjow.swingwebpanel.css.anim
Class EffectTiming

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.EffectTiming

public final class EffectTiming
extends java.lang.Object

The timing properties of an animation effect and the timing calculations of Web Animations Level 1 (W3C Working Draft 5 June 2023, https://www.w3.org/TR/2023/WD-web-animations-1-20230605/, sections 4.5 to 4.11 and 6.5): the start delay, the end delay, the fill mode, the iteration start, the iteration count, the iteration duration (auto is zero in this level), the playback direction and the timing function. compute(double, boolean, boolean) turns a local time into the phase, the active time, the overall progress, the simple iteration progress, the current iteration and the transformed progress with the endpoint-exclusive rules of the specification. An unresolved time is NaN. Use: create one, change the members through setDelay(double) and the other setters (which do not check: validate(double, java.lang.Double, java.lang.Double, java.lang.String) checks the values that a script passes first), then call compute(double, boolean, boolean). Not thread-safe; it belongs to the document thread.

애니메이션 효과의 시간 속성과 Web Animations Level 1(W3C Working Draft 2023-06-05, https://www.w3.org/TR/2023/WD-web-animations-1-20230605/, 4.5~4.11 절과 6.5 절)의 시간 계산: 시작 지연, 끝 지연, 채움 모드, 반복 시작, 반복 횟수, 반복 지속 시간(auto 는 이 수준에서 0), 재생 방향, 완화 함수. compute(double, boolean, boolean) 은 지역 시간을 규격의 끝점 제외 규칙에 따라 단계, 활성 시간, 전체 진행도, 단순 반복 진행도, 현재 반복, 변환된 진행도로 바꾼다. 결정되지 않은 시간은 NaN 이다. 사용법: 만들고 setDelay(double) 등의 설정자로 값을 바꾼 뒤(설정자는 검사하지 않는다. 스크립트가 넘긴 값은 validate(double, java.lang.Double, java.lang.Double, java.lang.String) 로 먼저 검사한다) compute(double, boolean, boolean) 를 부른다. 스레드 안전하지 않으며 문서 스레드에 속한다.
