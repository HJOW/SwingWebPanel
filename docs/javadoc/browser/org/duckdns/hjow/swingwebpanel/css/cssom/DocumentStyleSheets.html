Class DocumentStyleSheets

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.DocumentStyleSheets

public final class DocumentStyleSheets
extends java.lang.Object

Collects the author style sheets of a document in tree order: the <style> elements (their text, with the media, title and type attributes) and the <link rel="stylesheet"> elements (loaded through a StyleSheetLoader; alternate style sheets and links without a URL are skipped). @import rules inside the sheets are loaded with the same loader. The collector is synchronous: the page loader calls it on a loading thread, not on the event dispatch thread.

문서의 작성자 스타일 시트를 트리 순서로 모은다: <style> 요소(media, title, type 속성이 있는 텍스트)와 <link rel="stylesheet"> 요소(StyleSheetLoader 로 읽음. 대체 스타일 시트와 URL 이 없는 link 는 건너뜀). 시트 안의 @import 규칙은 같은 로더로 읽는다. 수집기는 동기식이며 페이지 로더가 이벤트 디스패치 스레드가 아니라 로딩 스레드에서 호출한다.

public static java.util.List<StyleSheet> collect(Document doc,
                                                 StyleSheetLoader loader,
                                                 CssDiagnostics diag,
                                                 java.util.Map<Element,StyleSheet> previous)
Collects the style sheets of a document and keeps the sheet objects of the previous collection while their source did not change: a <style> element whose text is the same and a <link> element whose address is the same get the sheet they had, so a script that holds a CSSStyleSheet (and the rules it inserted into it) keeps working when another style element is added or a linked sheet arrives. A kept sheet still loads the @import rules that were pending the last time.

문서의 스타일 시트를 모으되, 출처가 바뀌지 않는 동안에는 이전 수집의 시트 객체를 유지한다: 텍스트가 같은 <style> 요소와 주소가 같은 <link> 요소는 가졌던 시트를 그대로 받으므로, 스크립트가 CSSStyleSheet(와 그 안에 넣은 규칙)를 붙잡고 있어도 다른 style 요소가 추가되거나 링크한 시트가 도착할 때 계속 동작한다. 유지한 시트도 지난번에 대기 중이던 @import 규칙을 읽는다.

Parameters:
doc - the document / 문서
loader - loads linked and imported sheets, or null to skip them / 링크와 가져오기 시트를 읽는다. null 이면 건너뜀
diag - collector or null / 수집기 또는 null
previous - the sheets of the previous collection by owner element, or null / 이전 수집의 시트(소유 요소별). 없으면 null
Returns:
the sheets in document order / 문서 순서의 시트
