public final class FontFaceRule
extends CssRule

An @font-face rule: the descriptors of a web font. The family, the sources (url() with an optional format(), or local()) and the style, weight, stretch and unicode range are available; the font loading policy (plan item P10-05) decides what to do with them.

@font-face 규칙: 웹 글꼴의 디스크립터. 글꼴 계열, 출처(format() 이 붙을 수 있는 url() 또는 local()), 스타일, 두께, 폭, 유니코드 범위를 알 수 있으며, 글꼴을 읽는 정책(계획 P10-05)이 이들로 무엇을 할지 정한다.

getStyle

public CssStyleDeclaration getStyle()
Returns the descriptors as a declaration block (the CSSOM style of CSSFontFaceRule). The block holds the descriptors that are also CSS properties (font-family, font-style, font-weight ...); a descriptor that is not a property (src, unicode-range, font-display) is not in it. Changing the block does not change the rule: the web font loader reads the descriptors that the rule was parsed with.

디스크립터를 선언 블록으로 반환한다(CSSFontFaceRule 의 CSSOM style). 블록에는 CSS 속성이기도 한 디스크립터(font-family, font-style, font-weight 등)가 들어 있고, 속성이 아닌 디스크립터(src, unicode-range, font-display)는 없다. 블록을 바꿔도 규칙은 바뀌지 않는다: 웹 글꼴 로더는 규칙을 파싱한 디스크립터를 읽는다.

Returns:
the block / 블록
