Class UaStyleSheet

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.UaStyleSheet

public final class UaStyleSheet
extends java.lang.Object

The user agent default style sheet: the rendering defaults the HTML Standard prescribes for HTML elements (which elements are blocks, lists, tables, what is hidden; margins and sizes of headings, lists and tables; colors of links; bold, italic, underline and monospace elements; the look of form controls and fieldsets), with the additions of browsers where the standard is silent. A second small sheet holds the rules that only apply to documents in quirks mode and a third one the rules of HTML documents only (forms in tables). All are written as Java string constants so that they travel with the class files (no resource files are needed) and are parsed once, lazily. Type selectors only match HTML elements because the sheet declares the XHTML namespace as the default namespace.

사용자 에이전트 기본 스타일 시트: HTML 표준이 HTML 요소에 정한 렌더링 기본값(어떤 요소가 블록, 목록, 표인지, 무엇이 숨겨지는지, 제목과 목록과 표의 여백과 크기, 링크 색, 굵은/기울임/밑줄/고정폭 요소, 폼 컨트롤과 fieldset 의 모양)과, 표준이 말하지 않은 곳의 브라우저 보완. 작은 두 번째 시트에는 호환 모드 문서에만, 세 번째 시트에는 HTML 문서에만(표 안의 폼) 적용되는 규칙이 있다. 모두 Java 문자열 상수로 써서 클래스 파일과 함께 다니며(리소스 파일 불필요) 한 번만 지연 파싱한다. 시트가 XHTML 네임스페이스를 기본 네임스페이스로 선언하므로 타입 선택자는 HTML 요소에만 일치한다.
