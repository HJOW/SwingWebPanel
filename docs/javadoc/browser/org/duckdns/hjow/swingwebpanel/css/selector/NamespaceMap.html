org.duckdns.hjow.swingwebpanel.css.selector
Class NamespaceMap

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.NamespaceMap

public final class NamespaceMap
extends java.lang.Object

The namespace prefixes declared by @namespace rules of a style sheet: a default namespace and prefix to URI bindings. The selector parser consults it to resolve ns|name; without a map (as in querySelector) prefixes are not allowed and no default namespace applies.

스타일 시트의 @namespace 규칙이 선언한 네임스페이스 접두사: 기본 네임스페이스와 접두사-URI 연결. 선택자 파서가 ns|name 을 해석할 때 참조한다. 맵이 없으면(querySelector 처럼) 접두사는 허용되지 않고 기본 네임스페이스도 적용되지 않는다.
