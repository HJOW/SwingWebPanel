org.duckdns.hjow.swingwebpanel.css.cssom
Class MediaList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.MediaList

public final class MediaList
extends java.lang.Object

The CSSOM MediaList of a style sheet, of an @media rule or of an @import rule: the media queries as text (mediaText) and as a list of query strings (length, item()), changed through mediaText, appendMedium() and deleteMedium(). Every change replaces the media query list of the owner, marks a sheet as changed by a script and tells the sheet, so that the style resolver evaluates the media again. The list parsed from empty text has no medium and the text "" but still matches every environment.

스타일 시트, @media 규칙, @import 규칙의 CSSOM MediaList: 미디어 질의를 텍스트(mediaText)와 질의 문자열 목록 (length, item())으로 보여 주며 mediaText, appendMedium(), deleteMedium() 으로 바꾼다. 바꿀 때마다 소유자의 미디어 질의 목록을 교체하고 시트를 스크립트가 바꿨다고 표시하며 시트에 알려, 스타일 리졸버가 미디어를 다시 평가하게 한다. 빈 텍스트에서 파싱한 목록은 미디어가 없고 텍스트가 "" 이지만 여전히 모든 환경에 일치한다.
