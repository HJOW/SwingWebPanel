Class GroupRule

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.CssRule
      org.duckdns.hjow.swingwebpanel.css.cssom.GroupRule

public final class GroupRule
extends CssRule

A conditional group rule: @media, @supports and @layer blocks, which contain other rules. Its rules apply when the condition holds: a media group while its query list matches the environment, a supports group when its condition was true when the sheet was parsed, a layer group always (cascade layers are parsed but their ordering is not applied). The rules of a group can be inserted and deleted (insertRule(java.lang.String, int), deleteRule(int)) and the media list of a media group can be replaced, as the CSSOM allows.

조건부 그룹 규칙: 다른 규칙을 담는 @media, @supports, @layer 블록. 조건이 성립할 때 그 안의 규칙이 적용된다: media 그룹은 질의 목록이 환경과 일치하는 동안, supports 그룹은 스타일 시트를 파싱할 때 조건이 참이었으면, layer 그룹은 항상(캐스케이드 레이어는 파싱하지만 순서는 적용하지 않는다). 그룹의 규칙은 CSSOM 이 허용하는 대로 넣고 지울 수 있고(insertRule(java.lang.String, int), deleteRule(int)) media 그룹의 미디어 목록은 바꿀 수 있다.
