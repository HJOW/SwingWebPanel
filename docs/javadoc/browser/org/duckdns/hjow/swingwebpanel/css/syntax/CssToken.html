org.duckdns.hjow.swingwebpanel.css.syntax
Class CssToken

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.syntax.ComponentValue
      org.duckdns.hjow.swingwebpanel.css.syntax.CssToken

public final class CssToken
extends ComponentValue

A token of the CSS Syntax Module Level 3. Besides the type it carries the data of the token: the text of identifiers, strings, at-keywords, functions and hashes, the numeric value and unit of numbers, percentages and dimensions, the "id" flag of hash tokens and the source position.

CSS Syntax Module Level 3 의 토큰. 종류 외에 토큰의 데이터를 가진다: 식별자, 문자열, at-키워드, 함수, 해시의 문자열, 숫자/백분율/차원의 값과 단위, 해시 토큰의 "id" 플래그, 소스 위치.
