public final class MarginRule
extends CssRule

A page-margin at-rule inside @page (CSS Paged Media Level 3, section 4.3, W3C Working Draft 14 September 2023): one of the sixteen margin boxes @top-left-corner, @top-left, @top-center, @top-right, @top-right-corner, @bottom-*, @left-*, @right-* with a block of declarations (CSSOM CSSMarginRule, legacy type 9). The rule only holds what was written; there is no printing, so the margin boxes are never laid out.

@page 안의 쪽 여백 at-규칙(CSS Paged Media Level 3 4.3 절, W3C 작업 초안 2023-09-14): 열여섯 개의 여백 상자 @top-left-corner, @top-left, @top-center, @top-right, @top-right-corner, @bottom-*, @left-*, @right-* 중 하나와 선언 블록(CSSOM CSSMarginRule, 옛 종류 9). 규칙은 쓰인 것만 보관하며 인쇄가 없으므로 여백 상자를 배치하지 않는다.
