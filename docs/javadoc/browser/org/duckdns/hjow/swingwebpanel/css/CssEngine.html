org.duckdns.hjow.swingwebpanel.css
Class CssEngine

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.CssEngine

public final class CssEngine
extends java.lang.Object

The CSS engine of one document, wired together: it installs the selector engine (querySelector and friends), collects the style sheets of the document (<style>, <link rel="stylesheet">, @import) through a StyleSheetLoader, and creates the StyleResolver that computes the styles. The current DOM owner creates one engine per document, calls loadStyleSheets() during parsing or on the confirmed document queue, and shares it with layout. When the sources of the style sheets change (refreshIfNeeded()) the sheets are collected again.

문서 하나의 CSS 엔진을 하나로 묶은 것: 선택자 엔진(querySelector 등)을 설치하고, StyleSheetLoader 로 문서의 스타일 시트(<style>, <link rel="stylesheet">, @import)를 모으고, 스타일을 계산하는 StyleResolver 를 만든다. 현재 DOM 소유자는 문서마다 엔진 하나를 만들고 파싱 중 또는 확정된 문서 큐에서 loadStyleSheets() 를 호출하며 레이아웃과 공유한다. 스타일 시트의 출처가 바뀌면(refreshIfNeeded()) 시트를 다시 모은다.
