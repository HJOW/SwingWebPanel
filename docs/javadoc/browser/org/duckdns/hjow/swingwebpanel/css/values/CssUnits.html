org.duckdns.hjow.swingwebpanel.css.values
Class CssUnits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.values.CssUnits

public final class CssUnits
extends java.lang.Object

The unit tables of CSS Values and Units: which unit names are lengths, angles, times, frequencies, resolutions or flex fractions, and the conversion of the absolute units to their canonical unit (pixels, degrees, seconds, hertz, dots per pixel).

CSS Values and Units 의 단위 표: 어떤 단위 이름이 길이, 각도, 시간, 주파수, 해상도, flex 비율인지, 그리고 절대 단위를 기준 단위(픽셀, 도, 초, 헤르츠, 픽셀당 점)로 바꾸는 변환.
