public final class CssPending
extends CssValue

A pending-substitution value: a declaration whose value contains var() cannot be parsed when the style sheet is read, because the custom properties it refers to are only known per element. The declaration is kept as component values together with the name of the property it was written for, and substituted and parsed at computed-value time (see css.cascade.StyleResolver).

치환 대기 값: var() 가 든 선언은 참조하는 사용자 정의 속성을 요소마다 알 수 있으므로 스타일 시트를 읽을 때 파싱할 수 없다. 선언은 컴포넌트 값과 쓰인 속성 이름으로 보관했다가 계산 값을 구할 때 치환하고 파싱한다(css.cascade.StyleResolver 참조).
