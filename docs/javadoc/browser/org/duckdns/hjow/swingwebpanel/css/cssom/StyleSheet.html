org.duckdns.hjow.swingwebpanel.css.cssom
Class StyleSheet

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.StyleSheet

public final class StyleSheet
extends java.lang.Object

A style sheet: its rules in order, its origin (user agent, user or author), the URL it came from (the base of the relative urls inside it), the media queries that decide whether it applies at all, and a title and a disabled flag as the owning <style> or <link> element gives them. A parsed sheet is the same object that the style resolver reads and that scripts see as a CSSStyleSheet (CSSOM): its rules can be inserted and deleted (insertRule(java.lang.String, int), deleteRule(int)), the rules and their declaration blocks tell the sheet when they change, and the sheet passes that on to the listener of the CSS engine, which drops what it computed from the sheet. @import rules carry their imported sheets, and an imported sheet knows its importing sheet and rule.

스타일 시트: 순서대로 놓인 규칙, 출처(사용자 에이전트, 사용자, 작성자), 가져온 URL(그 안의 상대 url 의 기준), 시트 전체의 적용 여부를 정하는 미디어 질의, 소유한 <style> 이나 <link> 요소가 주는 제목과 비활성 플래그. 파싱한 시트는 스타일 리졸버가 읽는 객체이자 스크립트가 CSSStyleSheet(CSSOM)로 보는 객체와 같다: 규칙을 넣고 지울 수 있고(insertRule(java.lang.String, int), deleteRule(int)), 규칙과 선언 블록이 바뀌면 시트에 알리며, 시트는 그것을 CSS 엔진의 리스너에 전달하여 엔진이 그 시트로 계산한 것을 버리게 한다. @import 규칙은 가져온 시트를 가지며 가져온 시트는 자신을 가져온 시트와 규칙을 안다.

생성한 시트의 모든 규칙을 텍스트의 규칙으로 바꾼다(CSSOM replaceSync). @import 규칙은 무시한다.

Parameters:
text - the style sheet text / 스타일 시트 텍스트

resolvePendingImports

public boolean resolvePendingImports(StyleSheetLoader l,
                                     CssDiagnostics diag)
Loads the @import rules that could not be loaded when the sheet was parsed (the resource was still arriving): a rule whose sheet is still missing asks the loader again and, if the sheet is there now, gets it, so that the sheet object (and the changes a script made to it) stays the same while its imports arrive.

시트를 파싱할 때 읽지 못한(리소스가 아직 오는 중이던) @import 규칙을 읽는다: 시트가 아직 없는 규칙은 로더에 다시 물어 시트가 이제 있으면 받는다. 그러므로 가져오기가 도착하는 동안에도 시트 객체(와 스크립트가 거기 한 변경)는 그대로이다.

Parameters:
l - the loader of the current scope, or null to use the loader the sheet has / 현재 범위의 로더. null 이면 시트가 가진 로더
diag - collector or null / 수집기 또는 null
Returns:
true if an import was loaded now / 이번에 가져오기를 읽었으면 true

hasPendingImports

Returns:
true if an import is missing / 가져오기가 빠져 있으면 true
