Package org.duckdns.hjow.swingwebpanel.css.media

Media queries and conditional rules: media query parsing and evaluation, @supports conditions and the media environment.

See:
          Description

Class Summary
MediaEnvironment The properties of the output device that media queries test: the viewport size, the pixel density, the color depth, the input capabilities (hover, pointer), the user preferences (prefers-color-scheme, prefers-reduced-motion, ...) and the media type (screen or print).
MediaQueryList A parsed media query list (Media Queries Level 4): media types with not and only, and / or / not conditions with parentheses, features in boolean ((color)), plain ((min-width: 600px)) and range ((400px <= width < 700px)) form, and unknown features or functions (which are false and cannot be negated into true).
