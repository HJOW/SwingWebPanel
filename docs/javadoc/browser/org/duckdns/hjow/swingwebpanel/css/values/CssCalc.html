Class CssCalc

public final class CssCalc
extends CssValue

A math expression value: calc() and the math functions min() max() clamp() abs() sign() round() mod() rem() sin() cos() tan() asin() acos() atan() atan2() pow() sqrt() hypot() log() exp() of CSS Values and Units Level 4. The parser enforces the type rules (a sum needs compatible types, a product needs a number on one side, a quotient a number on the right) and rejects expressions that break them. At computed-value time simplify(LengthContext) folds everything that does not depend on a percentage; what depends on a percentage stays a CssCalc and is finished by the layout with resolve(LengthContext, double) once the reference length is known.

수식 값: calc() 와 CSS Values and Units Level 4 의 수학 함수 min() max() clamp() abs() sign() round() mod() rem() sin() cos() tan() asin() acos() atan() atan2() pow() sqrt() hypot() log() exp(). 파서는 형식 규칙(합은 호환되는 형식, 곱은 한쪽이 숫자, 나눗셈은 오른쪽이 숫자)을 검사하고 어기는 식을 거부한다. 계산 값을 구할 때 simplify(LengthContext) 가 백분율에 의존하지 않는 부분을 모두 접으며, 백분율에 의존하는 식은 CssCalc 로 남아 기준 길이가 정해진 뒤 레이아웃이 resolve(LengthContext, double) 로 마무리한다.
