Class CssSelectorEngine

All Implemented Interfaces:
SelectorEngine
public final class CssSelectorEngine
extends java.lang.Object
implements SelectorEngine

The selector engine behind querySelector, querySelectorAll, matches and closest (plan item P08-09): it plugs into the DOM through SelectorEngine. Selector text is parsed with SelectorParser (an invalid selector raises a DOM SyntaxError), parsed lists are cached, results come in tree order, and the node list returned by querySelectorAll is a static snapshot. Selectors with namespace prefixes are not valid here because no namespace map exists. Pseudo-elements never match an element. Install it with install(Document).

querySelector, querySelectorAll, matches, closest 뒤에 있는 선택자 엔진(계획 P08-09). SelectorEngine 로 DOM 에 연결된다. 선택자 텍스트는 SelectorParser 로 파싱하며(올바르지 않으면 DOM SyntaxError), 파싱한 목록은 캐시하고, 결과는 트리 순서이며, querySelectorAll 이 반환하는 목록은 고정된 스냅샷이다. 네임스페이스 맵이 없으므로 네임스페이스 접두사가 있는 선택자는 여기서 올바르지 않다. 의사 요소는 요소와 일치하지 않는다. install(Document) 로 설치한다.
