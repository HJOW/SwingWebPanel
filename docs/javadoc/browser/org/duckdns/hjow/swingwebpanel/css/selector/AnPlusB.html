Class AnPlusB

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.AnPlusB

public final class AnPlusB
extends java.lang.Object

The An+B micro-syntax of :nth-child() and its relatives: the keywords odd and even, a plain integer, or An+B with all the sign and whitespace variants of the specification (2n+1, -n + 3, +n, n- 2, ...). Because the tokenizer glues signs and digits into dimensions and identifiers, parsing is done on the token pattern, not on the text.

:nth-child() 계열의 An+B 미세 문법: 키워드 odd, even, 정수 하나, 또는 규격의 모든 부호와 공백 변형을 가진 An+B(2n+1, -n + 3, +n, n- 2 등). 토큰화기가 부호와 숫자를 차원과 식별자로 붙이므로 텍스트가 아니라 토큰 패턴으로 해석한다.
