Class ComputedStyle

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cascade.ComputedStyle

public final class ComputedStyle
extends java.lang.Object

The computed style of one element (or pseudo-element): the result of the cascade and of the computation of values. This is the contract between the style engine and the layout and rendering code.

What a value is. Every longhand property (see Prop) has a computed value that is never null: relative lengths are absolute pixels (CssLength with unit px), calc() without percentages is folded, colors are CssColor (or the keyword currentcolor for properties other than color, see color(int)), keywords are CssKeyword, and lists keep the structure the grammar of the property gives them. Percentages stay CssPercentage (or a CssCalc that contains one): the layout turns them into used values with resolve(int, double). Custom properties are available as raw component values.

How to read it. Use the typed helpers: px(int), number(int), keyword(int), isAuto(int), resolve(int, double), color(int); the few most used ones have a name (display(), position(), fontSizePx(), fontWeight(), lineHeightPx()). A computed style is immutable and may be shared between elements.

요소(또는 의사 요소) 하나의 계산 스타일: 캐스케이드와 값 계산의 결과. 스타일 엔진과 레이아웃, 렌더링 코드 사이의 계약이다.

값이란. 모든 개별 속성(Prop 참조)은 null 이 아닌 계산 값을 가진다: 상대 길이는 절대 픽셀(CssLength, 단위 px), 백분율 없는 calc() 는 접히고, 색은 CssColor(color 가 아닌 속성은 키워드 currentcolor 일 수 있음, color(int) 참조), 키워드는 CssKeyword, 목록은 속성 문법이 준 구조를 유지한다. 백분율은 CssPercentage(또는 그것을 담은 CssCalc)로 남으며 레이아웃이 resolve(int, double) 로 실제 값을 만든다. 사용자 정의 속성은 원본 컴포넌트 값으로 제공한다.

읽는 방법. 형식별 도우미를 쓴다: px(int), number(int), keyword(int), isAuto(int), resolve(int, double), color(int). 가장 많이 쓰는 몇 개는 이름이 있다(display(), position(), fontSizePx(), fontWeight(), lineHeightPx()). 계산 스타일은 불변이며 요소끼리 공유할 수 있다.

overlay

public ComputedStyle overlay(ComputedStyle base,
                             ComputedStyle top,
                             int[] ids)
Returns a copy of this style on which the values that top sets over base are applied to the listed properties. A property is taken from top only if this style still has the value of base (it inherited the property unchanged, so an element inside the first line that sets a property itself keeps its own value) and top differs from base. ::first-line uses it: base is the style of the element, top the style of its ::first-line, this is the style of a text item or of an inline element in the first line.

top 이 base 위에 정한 값을 나열한 속성에 적용한 이 스타일의 사본을 반환한다. 이 스타일이 아직 base 의 값을 가질 때 (그 속성을 바꾸지 않고 상속했을 때. 스스로 속성을 정한 첫 줄 안의 요소는 자기 값을 유지한다)이고 top 이 base 와 다를 때만 그 속성을 top 에서 가져온다. ::first-line 이 쓴다: base 는 요소의 스타일, top 은 그 ::first-line 스타일이고, 이 스타일은 첫 줄 안의 텍스트 항목이나 인라인 요소의 스타일이다.

Parameters:
base - the style the values are compared with / 값을 비교하는 기준 스타일
top - the style that is laid over it / 그 위에 덮는 스타일
ids - the property ids that may be taken / 가져올 수 있는 속성 id
Returns:
this style when nothing changes, else a changed copy / 바뀌는 것이 없으면 이 스타일, 아니면 바뀐 사본
