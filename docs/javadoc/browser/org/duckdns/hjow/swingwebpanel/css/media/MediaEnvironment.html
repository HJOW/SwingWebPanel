org.duckdns.hjow.swingwebpanel.css.media
Class MediaEnvironment

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.media.MediaEnvironment

public final class MediaEnvironment
extends java.lang.Object

The properties of the output device that media queries test: the viewport size, the pixel density, the color depth, the input capabilities (hover, pointer), the user preferences (prefers-color-scheme, prefers-reduced-motion, ...) and the media type (screen or print). The defaults describe a desktop screen with a mouse. The object is mutable; after changing it hand it to StyleResolver.setMediaEnvironment so that the styles are recomputed.

미디어 질의가 검사하는 출력 장치의 속성: 뷰포트 크기, 픽셀 밀도, 색 깊이, 입력 능력(hover, pointer), 사용자 선호 (prefers-color-scheme, prefers-reduced-motion 등), 미디어 종류(screen 또는 print). 기본값은 마우스가 있는 데스크톱 화면이다. 객체는 가변이며, 바꾼 뒤 StyleResolver.setMediaEnvironment 에 넘겨야 스타일이 다시 계산된다.
