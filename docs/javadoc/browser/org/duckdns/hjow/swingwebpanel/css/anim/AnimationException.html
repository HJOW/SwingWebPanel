public final class AnimationException
extends java.lang.RuntimeException

An error that a procedure of Web Animations throws: a TypeError or a DOMException with a name (InvalidStateError, NoModificationAllowedError, SyntaxError). The script binding turns it into the JavaScript error of that kind; Java callers catch it like any runtime exception.

Web Animations 의 절차가 던지는 오류: TypeError 또는 이름을 가진 DOMException(InvalidStateError, NoModificationAllowedError, SyntaxError). 스크립트 연결은 그 종류의 JavaScript 오류로 바꾸고 Java 호출자는 다른 실행 시간 예외처럼 잡는다.
