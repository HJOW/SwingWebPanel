KeyframeEffectModel
public static final class KeyframeEffectModel.Keyframe
extends java.lang.Object

One keyframe as the script specified it, with its parsed declarations. Instances are immutable except for the computed offset, which KeyframeEffectModel.computeMissingOffsets(List) sets.

스크립트가 지정한 키프레임 하나와 그 해석한 선언. 인스턴스는 계산된 오프셋을 빼면 바뀌지 않으며 계산된 오프셋은 KeyframeEffectModel.computeMissingOffsets(List) 가 정한다.
