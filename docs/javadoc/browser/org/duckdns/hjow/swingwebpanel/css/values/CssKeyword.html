Class CssKeyword

java.lang.Object

      org.duckdns.hjow.swingwebpanel.css.values.CssKeyword

public final class CssKeyword
extends CssValue

An identifier used as a keyword value (auto, none, inherit, a font family name written as an identifier, a custom identifier ...). The name is kept in lower case for the predefined keywords; custom identifiers keep their case.

키워드 값으로 쓰인 식별자(auto, none, inherit, 식별자로 쓴 글꼴 이름, 사용자 정의 식별자 등). 미리 정의된 키워드는 소문자로 보관하고 사용자 정의 식별자는 대소문자를 유지한다.
