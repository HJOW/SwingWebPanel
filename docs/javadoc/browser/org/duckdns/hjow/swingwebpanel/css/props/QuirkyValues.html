Class QuirkyValues

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.props.QuirkyValues

public final class QuirkyValues
extends java.lang.Object

The value quirks of CSS that is parsed in quirks mode: the <quirky-length> (a unitless number is a px length in a fixed list of properties, CSS Values 4 appendix C) and the <quirky-color> (a hex color without the leading hash in color, background-color and the border colors, CSS Color 4 appendix B), as the Quirks Mode Standard sections 3.2 and 3.1 refer to them. The quirks are applied to the top level components of the value only, never inside functions such as calc() or rgb(), and not to shorthands that merely contain the listed properties (background, border, font). The component values are rewritten into the ordinary dimension and hash tokens before the regular grammar runs, so everything after that point is unchanged. Sources: https://drafts.csswg.org/css-values-4/#quirky-length and https://drafts.csswg.org/css-color-4/#quirky-color (living drafts, retrieved 2026-11-17, last modified 2026-11-16) and https://quirks.spec.whatwg.org/ (Living Standard of 2026-10-19). The one exception to the rule about functions is the rect() of clip, whose arguments may be quirky lengths.

호환 모드로 파싱하는 CSS 의 값 quirk: <quirky-length>(정해진 속성 목록에서 단위 없는 숫자가 px 길이, CSS Values 4 부록 C)와 <quirky-color>(color, background-color, border 색에서 # 없는 16진수 색, CSS Color 4 부록 B)이며 호환 모드 표준 3.2, 3.1절이 가리킨다. quirk 는 값의 최상위 구성 요소에만 적용하고 calc(), rgb() 같은 함수 안에는 적용하지 않으며 나열된 속성을 담기만 하는 단축 속성(background, border, font)에도 적용하지 않는다. 구성 요소 값을 일반 차원/해시 토큰으로 바꾼 뒤 평소의 문법을 돌리므로 그 뒤는 달라지지 않는다. 함수에 적용하지 않는다는 규칙의 유일한 예외는 clip 의 rect() 이며 그 인수는 quirky length 일 수 있다.

Rewrites the quirky components of a declaration value into ordinary tokens. The list is returned unchanged if the property takes no quirks or no component needs rewriting.

선언 값의 quirk 구성 요소를 일반 토큰으로 바꾼다. 속성이 quirk 를 받지 않거나 바꿀 구성 요소가 없으면 목록을 그대로 반환한다.
