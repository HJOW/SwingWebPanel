Package org.duckdns.hjow.swingwebpanel.css.syntax

CSS Syntax Module Level 3: tokenizer, component values and the generic parser that turns text into rules and declarations.

See:
          Description

Class Summary
ComponentValue A component value of the CSS Syntax Module: a preserved token, a simple block or a function.
CssBlock A simple block: component values between a pair of brackets, parentheses or curly braces.
CssEscape Serialization helpers of the CSSOM: escaping of identifiers and strings, and the number format of the standard.
CssFunction A function: a name and the component values between its parentheses.
CssParser The parser of CSS Syntax Module Level 3 (section 5, "Parsing"): it turns text into component values and the component values into rules and declarations, with the error recovery of the specification.
CssToken A token of the CSS Syntax Module Level 3.
CssTokenizer The tokenizer of CSS Syntax Module Level 3 (section 4, "Tokenization"), written as an explicit state machine over the preprocessed input: carriage returns and form feeds become line feeds, NUL and lone surrogates become U+FFFD, comments are skipped.
DeclarationBlock The contents of a declaration block: the declarations and the at-rules found inside it (for example the margin at-rules of @page).
SyntaxDeclaration A declaration as produced by the parser: a property name, the component values of its value and the !
SyntaxRule A rule as produced by the parser: either a qualified rule (a prelude and a block, such as a style rule) or an at-rule (an at-keyword name, a prelude and an optional block).
