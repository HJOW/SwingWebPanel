Package org.duckdns.hjow.swingwebpanel.css.values

CSS value types: lengths, colors, calc expressions, generic values and the value definition grammar matcher.

See:
          Description

Interface Summary
CssCalc.AnchorResolver Resolves one anchor() or anchor-size() function of an expression when the box is positioned.
CssCalc.FunctionMapper Rewrites one anchor() or anchor-size() function of an expression into another function (the position fallback tactics).
GrammarRegistry The lookup of named value definitions (<line-width>, <position>, <family-name> ...) used by a ValueGrammar to resolve the references that are not built-in types.
 

Class Summary
CssCalc A math expression value: calc() and the math functions min() max() clamp() abs() sign() round() mod() rem() sin() cos() tan() asin() acos() atan() atan2() pow() sqrt() hypot() log() exp() of CSS Values and Units Level 4.
CssColor An sRGB color with an alpha channel, stored as four 8-bit channels.
CssDimension A number with a non-length unit: an angle (45deg), a time (200ms), a frequency, a resolution (2dppx) or a flexible length (1fr).
CssFunctionValue A functional value that is kept structurally: translate(10px, 5px), linear-gradient(...)
CssKeyword An identifier used as a keyword value (auto, none, inherit, a font family name written as an identifier, a custom identifier ...).
CssLength A length: a number with a length unit.
CssList A list of values: space separated (the components of one value such as 1px solid red) or comma separated (alternatives such as a font family list or several backgrounds).
CssNumber A number (integer or real).
CssOperator A punctuation value inside a structured value: the slash of 12px/1.5, 16 / 9 or a / b and the commas of function arguments that are kept inside a sequence.
CssPending A pending-substitution value: a declaration whose value contains var() cannot be parsed when the style sheet is read, because the custom properties it refers to are only known per element.
CssPercentage A percentage.
CssRaw A value kept as component values without further interpretation: the value of a custom property, or the value of a property whose syntax is only checked loosely (grid-template-areas, src of @font-face ...).
CssString A string value ("Arial", the argument of content, a quoted font name).
CssUnits The unit tables of CSS Values and Units: which unit names are lengths, angles, times, frequencies, resolutions or flex fractions, and the conversion of the absolute units to their canonical unit (pixels, degrees, seconds, hertz, dots per pixel).
CssUrl A url() value.
CssValue Base class of all typed CSS values: keywords, numbers, lengths, percentages, colors, strings, urls, lists, functions and calc expressions.
LengthContext The reference sizes needed to turn relative lengths into pixels: the font size of the element (for em), the font size of the root element (rem), the line height (lh), the viewport size (vw, vh, ...) and approximations of the x-height and zero-advance of the font (ex, ch).
NamedColors The named colors of CSS Color Level 4 (148 keywords including the grey/gray spellings) and the system colors, with the values of the light color scheme.
ParseEnv The environment of one value parse: the registry of named definitions and the base URL against which url() values are resolved (the URL of the style sheet that contains the declaration, or null if it is not known).
ShapeInterpolation Interpolation of offset paths (plan item P10-08-h, CSS Motion Path 1 section 2.1, "Animation type: by computed value", with the rules of CSS Shapes 1 for <basic-shape>): two shape functions of the same kind with the same structure interpolate their numbers (lengths with lengths, percentages with percentages, angles, numbers; keywords and the reference box must be equal), two path() values with the same commands interpolate their coordinates (an arc keeps its flags only if they are equal), and two ray() values interpolate their angle and position when the size and contain are equal.
ValueGrammar A compiled value definition in the notation of CSS Values and Units: keywords, <type> references (with an optional [min,max] range), juxtaposition, &&, ||, |, brackets, the multipliers ?
ValueGrammar.Prefix The result of a prefix match.
