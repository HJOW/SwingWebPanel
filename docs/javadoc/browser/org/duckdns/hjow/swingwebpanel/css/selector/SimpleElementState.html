ElementState
public final class SimpleElementState
extends java.lang.Object
implements ElementState

A small mutable ElementState: the host sets which element is hovered, active, focused and which one is the fragment target. It answers :focus-within from the focused element's ancestry and leaves everything else UNKNOWN. The element references are held strongly, so clear them (or drop this object) when the page is replaced.

작은 가변 ElementState: 호스트가 마우스가 올라간 요소, 활성 요소, 포커스 요소, 프래그먼트 대상 요소를 설정한다. :focus-within 은 포커스 요소의 조상으로 답하고 나머지는 UNKNOWN 으로 둔다. 요소 참조를 강하게 쥐므로 페이지를 바꿀 때 지우거나 이 객체를 버려야 한다.
