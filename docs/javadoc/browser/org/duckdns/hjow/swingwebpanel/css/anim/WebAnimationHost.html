Interface WebAnimationHost

All Known Implementing Classes:
WebAnimationsApi
public interface WebAnimationHost

What the Web Animations model needs from the script side of a page (Web Animations Level 1): promises for the ready and finished attributes of the animations, microtasks for the "finish notification steps", and a new animation frame (a call of WebAnimationSet.update(double) followed by a microtask checkpoint and the dispatch of WebAnimationSet.takeEvents()) whenever something waits for one. The page's script host implements it with real promises and its event loop; tests implement it with plain records. Every method is called on the document thread.

Web Animations 모델이 페이지의 스크립트 쪽에서 필요로 하는 것(Web Animations Level 1): 애니메이션의 ready, finished 속성을 위한 프라미스, "finish notification steps" 를 위한 마이크로태스크, 무언가가 기다릴 때의 새 애니메이션 프레임(WebAnimationSet.update(double) 호출과 이어지는 마이크로태스크 검사점, WebAnimationSet.takeEvents() 의 전달). 페이지의 스크립트 호스트는 실제 프라미스와 이벤트 루프로 구현하고 시험은 단순한 기록으로 구현한다. 모든 메서드는 문서 스레드에서 불린다.
