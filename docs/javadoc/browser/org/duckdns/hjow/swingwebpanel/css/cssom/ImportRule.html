Class ImportRule

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.CssRule
      org.duckdns.hjow.swingwebpanel.css.cssom.ImportRule

public final class ImportRule
extends CssRule

An @import rule: the URL, the media queries and the style sheet that was loaded for it (null if the sheet could not be loaded, was part of an import cycle or exceeded the import depth limit, or has not arrived yet). The imported sheet applies in the position of the rule, before the rules that follow. The imported sheet knows this rule and the sheet that contains it (the CSSOM ownerRule and parentStyleSheet).

@import 규칙: URL, 미디어 질의, 그에 대해 읽은 스타일 시트(읽지 못했거나 가져오기 순환이거나 가져오기 깊이 제한을 넘었거나 아직 도착하지 않았으면 null). 가져온 시트는 규칙의 위치에서 뒤따르는 규칙보다 먼저 적용된다. 가져온 시트는 이 규칙과 이 규칙을 담은 시트를 안다(CSSOM ownerRule, parentStyleSheet).
