org.duckdns.hjow.swingwebpanel.css.values
Class LengthContext

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.values.LengthContext

public final class LengthContext
extends java.lang.Object

The reference sizes needed to turn relative lengths into pixels: the font size of the element (for em), the font size of the root element (rem), the line height (lh), the viewport size (vw, vh, ...) and approximations of the x-height and zero-advance of the font (ex, ch). Percentages are not resolved here; they depend on the layout.

상대 길이를 픽셀로 바꾸는 데 필요한 기준 크기: 요소의 글꼴 크기(em), 루트 요소의 글꼴 크기(rem), 줄 높이(lh), 뷰포트 크기(vw, vh 등), 글꼴의 x 높이와 0 의 폭 근사값(ex, ch). 백분율은 여기서 계산하지 않으며 레이아웃에 달려 있다.

Returns a copy that knows the size of the query container of the element (CSS Conditional Level 5, 4.4 "Container Relative Lengths"): a size that is NaN has no container, and cqw/cqh then fall back to the viewport.
