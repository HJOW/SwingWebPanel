Class FontFeatureValuesRule

public final class FontFeatureValuesRule
extends CssRule

An @font-feature-values rule (CSS Fonts Level 4 section 6.9, https://www.w3.org/TR/css-fonts-4/ WD 12 November 2026, and its CSSOM interface CSSFontFeatureValuesRule): a list of named font families and, for each type of feature value block (@swash, @stylistic, @ornaments, @annotation, @character-variant, @styleset, @historical-forms), a map from case-sensitive names to lists of non-negative feature indexes, plus the font-display descriptor that sets the default display policy of the faces of the families. The function values of font-variant-alternates look their names up here for the family of the font in use (lookup(java.util.List, java.lang.String, java.lang.String, java.lang.String)).

Use: the style sheet builder creates the rule from @font-feature-values Family { @styleset { nice: 3; } }; scripts change the maps through FontFeatureValuesRule.ValueMap (the CSSFontFeatureValuesMap maplike); getCssText() serializes the rule as the specification says.

@font-feature-values 규칙(CSS Fonts Level 4 6.9 절과 CSSOM 인터페이스 CSSFontFeatureValuesRule): 이름 있는 글꼴 패밀리의 목록과, 기능 값 블록 종류 (@swash, @stylistic, @ornaments, @annotation, @character-variant, @styleset, @historical-forms)마다 대소문자를 구분하는 이름에서 음이 아닌 기능 번호 목록으로 가는 맵, 그리고 패밀리의 글꼴 면의 기본 표시 정책을 정하는 font-display 서술자. font-variant-alternates 의 함수 값은 쓰는 글꼴의 패밀리에 대해 여기서 이름을 찾는다(lookup(java.util.List, java.lang.String, java.lang.String, java.lang.String)).

사용법: 스타일 시트 빌더가 @font-feature-values Family { @styleset { nice: 3; } } 에서 규칙을 만들고, 스크립트는 FontFeatureValuesRule.ValueMap (CSSFontFeatureValuesMap maplike)으로 맵을 바꾸며, getCssText() 는 규격대로 규칙을 직렬화한다.

lookup

public static int[] lookup(java.util.List<FontFeatureValuesRule> rules,
                           java.lang.String family,
                           java.lang.String type,
                           java.lang.String name)
Looks a name up in the rules for a family (CSS Fonts 4 section 6.9.1): the rules are given in document order, a later definition of the same (family, type, name) wins, and the families are compared without regard to ASCII case.

패밀리에 대해 규칙에서 이름을 찾는다(CSS Fonts 4 6.9.1 절): 규칙은 문서 순서로 주며 같은 (패밀리, 종류, 이름)의 나중 정의가 이기고, 패밀리는 ASCII 대소문자를 구분하지 않고 비교한다.

Parameters:
rules - the rules in document order / 문서 순서의 규칙
family - the family of the font / 글꼴의 패밀리
type - the type (styleset ...) / 종류
name - the name / 이름
Returns:
the indexes, or null if the name is not defined for the family / 번호. 그 패밀리에 정의되지 않았으면 null
