Class CssColor

public final class CssColor
extends CssValue

An sRGB color with an alpha channel, stored as four 8-bit channels. The parser accepts every notation of CSS Color Level 3 and Level 4 that does not need a context: named colors, system colors (light scheme), #rgb #rgba #rrggbb #rrggbbaa, rgb(), rgba(), hsl(), hsla(), hwb(), lab(), lch(), oklab(), oklch(), color() (srgb, srgb-linear, display-p3, a98-rgb, prophoto-rgb, rec2020, xyz, xyz-d50, xyz-d65), color-mix() in sRGB and light-dark() (the light value). Colors outside the sRGB gamut are clipped. Relative color syntax (from) is not supported and makes the value invalid. currentcolor is not a CssColor; it is the keyword CssKeyword.CURRENTCOLOR.

알파 채널이 있는 sRGB 색. 8비트 채널 넷으로 저장한다. 파서는 컨텍스트 없이 쓸 수 있는 CSS Color Level 3 와 4 의 모든 표기를 받아들인다: 이름 있는 색, 시스템 색(밝은 구성표), #rgb #rgba #rrggbb #rrggbbaa, rgb(), rgba(), hsl(), hsla(), hwb(), lab(), lch(), oklab(), oklch(), color()(srgb, srgb-linear, display-p3, a98-rgb, prophoto-rgb, rec2020, xyz, xyz-d50, xyz-d65), sRGB 의 color-mix(), light-dark()(밝은 값). sRGB 범위 밖의 색은 잘라 낸다. 상대 색 문법(from)은 지원하지 않으며 값을 무효로 한다. currentcolor 는 CssColor 가 아니라 키워드 CssKeyword.CURRENTCOLOR 이다.
