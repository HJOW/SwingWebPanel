public abstract class CssRule
extends java.lang.Object

Base class of the rules of a style sheet. The numeric types follow the CSSOM (CSSRule.type) where an equivalent exists.

스타일 시트 규칙의 기반 클래스. 숫자 종류는 대응하는 것이 있으면 CSSOM(CSSRule.type)을 따른다.

getCssomType

public int getCssomType()
Returns the number that the CSSOM CSSRule.type attribute reports: the type constant for the rule kinds that have a legacy number and 0 for the others (@layer, @property ...). Scripts use this, not getType(), which also numbers the kinds that the CSSOM does not. @counter-style reports 11 (CSSRule.COUNTER_STYLE_RULE).

CSSOM CSSRule.type 속성이 알려 주는 숫자를 반환한다: 옛 번호가 있는 규칙 종류는 종류 상수, 그 밖의 것(@layer, @property 등)은 0. 스크립트는 CSSOM 에 없는 종류에도 번호를 붙인 getType() 이 아니라 이것을 쓴다. 단 @counter-style 는 옛 번호 11(CSSRule.COUNTER_STYLE_RULE)을 가진다.

Returns:
the CSSOM type number / CSSOM 종류 번호
