Class ValueGrammar

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.values.ValueGrammar

public final class ValueGrammar
extends java.lang.Object

A compiled value definition in the notation of CSS Values and Units: keywords, <type> references (with an optional [min,max] range), juxtaposition, &&, ||, |, brackets, the multipliers ? * + {A,B} # !, literal commas and slashes, and function notations such as translate(<length>, <length>?). Matching is a backtracking search over the component values of a declaration; it returns the typed value mirroring the written structure (a CssList for sequences, the single value itself for one component, a comma list for #), or null if the value does not satisfy the definition. A prefix match supports the shorthands whose parts may come in any order.

CSS Values and Units 표기로 컴파일한 값 정의: 키워드, <type> 참조(선택적인 [min,max] 범위), 나열, &&, ||, |, 대괄호, 반복 표기 ? * + {A,B} # !, 쉼표와 슬래시 리터럴, translate(<length>, <length>?) 같은 함수 표기. 일치 검사는 선언의 컴포넌트 값에 대한 역추적 탐색이며, 쓰인 구조를 반영한 값(나열은 CssList, 컴포넌트 하나는 그 값 자체, # 는 쉼표 목록)을 반환하고 정의를 만족하지 않으면 null 을 반환한다. 접두사 일치는 부분의 순서가 자유로운 단축 속성을 지원한다.
