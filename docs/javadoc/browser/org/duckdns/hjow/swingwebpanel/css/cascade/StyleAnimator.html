org.duckdns.hjow.swingwebpanel.css.cascade
Interface StyleAnimator

All Known Implementing Classes:
AnimationEngine
public interface StyleAnimator

Turns the style that the cascade computed for an element into the style that the element has at the moment (plan item P10-07, CSS Transitions Level 1 and CSS Animations Level 1): the StyleResolver calls it every time it computes the style of an element, before the style is cached and given to the children for inheritance. An implementation compares the style with the previous one to start transitions and returns the style with the values of the running transitions and animations.

캐스케이드가 요소에 대해 계산한 스타일을 요소가 지금 가진 스타일로 바꾼다(계획 P10-07, CSS Transitions Level 1, CSS Animations Level 1): StyleResolver 가 요소의 스타일을 계산할 때마다, 스타일을 캐시하고 자식이 상속하기 전에 부른다. 구현은 스타일을 이전 것과 비교해 전환을 시작하고 실행 중인 전환과 애니메이션의 값을 가진 스타일을 돌려준다.
