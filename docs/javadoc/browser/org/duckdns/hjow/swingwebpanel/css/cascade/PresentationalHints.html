public interface PresentationalHints

The plug-in that turns the presentational attributes of the markup (bgcolor, align, width, border ...) into style declarations. The cascade treats them as author declarations with the lowest specificity that come before every author rule. The default implementation is HtmlPresentationalHints; a different markup language can supply its own.

마크업의 표현 속성(bgcolor, align, width, border 등)을 스타일 선언으로 바꾸는 플러그인. 캐스케이드는 이들을 모든 작성자 규칙보다 앞서는, 구체성이 가장 낮은 작성자 선언으로 다룬다. 기본 구현은 HtmlPresentationalHints 이며 다른 마크업 언어는 자체 구현을 제공할 수 있다.
