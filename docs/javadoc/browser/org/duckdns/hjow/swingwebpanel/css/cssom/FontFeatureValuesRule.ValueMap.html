public static final class FontFeatureValuesRule.ValueMap
extends java.lang.Object

The map of one type of feature value block (the CSSFontFeatureValuesMap maplike of the CSSOM): names in the order of their first definition, each with its list of indexes. Setting a name keeps its place and replaces its value.

기능 값 블록 한 종류의 맵(CSSOM 의 CSSFontFeatureValuesMap maplike): 처음 정의한 순서의 이름과 각각의 번호 목록. 이름을 다시 정하면 자리를 지키고 값을 바꾼다.
