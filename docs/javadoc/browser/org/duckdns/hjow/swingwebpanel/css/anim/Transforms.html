Class Transforms

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.Transforms

public final class Transforms
extends java.lang.Object

The 2D transform of an element (plan item P10-06, CSS Transforms Level 1, https://www.w3.org/TR/css-transforms-1/ section 8 and 13): turns the computed value of transform and transform-origin into an AffineTransform. The list of functions is multiplied left to right (matrix = F1 * F2 * ... * Fn, so the last function is applied to the points first); translate percentages refer to the width and height of the reference box (the border box of the element, the view-box of an HTML element); the transform is applied around the transform origin (default 50% 50%): translate(origin) * T * translate(-origin). 3D (CSS Transforms Level 2, explicit exception EXC-03 of the feature table): the property grammar accepts only the 3D function names whose arguments make them exactly 2D (translate3d(x, y, 0), translateZ(0), scale3d(x, y, 1), scaleZ(1), rotateZ(a), rotate3d(0, 0, 1, a) and a matrix3d() whose 3D entries are those of the identity); they are projected to the 2D function. Any other 3D value (rotateX(), perspective(), a real translateZ() ...) makes the declaration invalid, as for any unknown function, so it is ignored; perspective, transform-style and backface-visibility have no effect. This class is stateless. interpolate(org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double, double, double) blends two transform lists for transitions and animations (CSS Transforms 1 section 15: a pair of lists with the same function names is interpolated function by function, otherwise the matrices are interpolated through their decomposition).

요소의 2D 변환(계획 P10-06, CSS Transforms Level 1, https://www.w3.org/TR/css-transforms-1/ 8, 13 절): transform 과 transform-origin 의 계산 값을 AffineTransform 으로 바꾼다. 함수 목록은 왼쪽에서 오른쪽으로 곱한다(행렬 = F1 * F2 * ... * Fn, 곧 마지막 함수가 점에 가장 먼저 적용됨). translate 의 백분율은 기준 상자(요소의 border box, HTML 요소의 view-box)의 너비와 높이를 참조한다. 변환은 변환 원점 둘레에 적용한다(기본 50% 50%): translate(원점) * T * translate(-원점). 3D(CSS Transforms Level 2, 기능 표의 명시적 예외 EXC-03): 속성 문법은 인수가 정확히 2D 가 되는 3D 함수 이름만 받는다(translate3d(x, y, 0), translateZ(0), scale3d(x, y, 1), scaleZ(1), rotateZ(a), rotate3d(0, 0, 1, a), 3D 항목이 단위 행렬의 것인 matrix3d()). 이들은 2D 함수로 투영한다. 그 밖의 3D 값(rotateX(), perspective(), 0 이 아닌 translateZ() 등)은 모르는 함수처럼 선언을 무효로 만들어 무시된다. perspective, transform-style, backface-visibility 는 효과가 없다. 이 클래스는 상태가 없다. interpolate(org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double, double, double) 는 전환과 애니메이션을 위해 두 변환 목록을 섞는다(CSS Transforms 1 15 절: 함수 이름이 같은 목록 쌍은 함수별로 보간하고, 아니면 행렬을 분해해서 보간한다).

interpolate

public static CssValue interpolate(CssValue from,
                                   CssValue to,
                                   double p,
                                   double w,
                                   double h)
Interpolates two computed transform values (CSS Transforms 1 section 15): two lists with the same number of functions with the same names are interpolated function by function (numbers, lengths and angles linearly; a missing length is 0 and a missing scale is 1); other pairs (and none against a list) are interpolated as matrices through the decomposition into translation, rotation, skew and scale. The result of the second kind is a matrix() function.

계산된 transform 값 둘을 보간한다(CSS Transforms 1 15 절): 같은 이름의 함수가 같은 수만큼 있는 목록 쌍은 함수별로 보간하고(숫자, 길이, 각도는 선형. 없는 길이는 0, 없는 배율은 1), 그 밖의 쌍(과 목록 대 none)은 이동, 회전, 기울임, 배율로 분해한 행렬로 보간한다. 둘째 경우의 결과는 matrix() 함수이다.

Parameters:
from - the start value / 시작 값
to - the end value / 끝 값
p - the progress, may lie outside 0..1 for cubic-bezier overshoot / 진행도. cubic-bezier 의 넘침으로 0..1 밖일 수 있다
w - width of the reference box (for percentages in the matrix fallback) / 기준 상자 너비(행렬 대체의 백분율용)
h - height of the reference box / 기준 상자 높이
Returns:
the interpolated value / 보간한 값
