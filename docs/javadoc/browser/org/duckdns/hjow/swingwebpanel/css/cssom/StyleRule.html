Class StyleRule

public final class StyleRule
extends CssRule

A style rule: a selector list and a declaration block, for example a:hover, a:focus { color: red }. The declaration block is live: a change made through it (the CSSOM style of the rule) reaches the style sheet, which tells the style resolver. The selector text can be replaced (setSelectorText(java.lang.String)); text that is not a valid selector list leaves the rule unchanged, as the CSSOM requires.

스타일 규칙: 선택자 목록과 선언 블록. 예: a:hover, a:focus { color: red }. 선언 블록은 실시간이다: 그것(규칙의 CSSOM style)을 통한 변경은 시트에 닿고 시트가 스타일 리졸버에 알린다. 선택자 문자열은 바꿀 수 있으며(setSelectorText(java.lang.String)), 올바른 선택자 목록이 아닌 텍스트는 CSSOM 대로 규칙을 그대로 둔다.
