Class Interpolator

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.Interpolator

public final class Interpolator
extends java.lang.Object

The interpolation of computed property values (plan item P10-07, CSS Transitions Level 1 section 4 and CSS Values 3 section 9, https://www.w3.org/TR/css-transitions-1/): numbers and lengths linearly, percentages linearly, colors with premultiplied alpha (CSS Color 4 section 12), transform as lists of functions (see Transforms.interpolate(org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double, double, double)), lists of the same length element by element (for example the two components of transform-origin or background-position), and visibility as in CSS Transitions (visible during the interpolation if one end is visible). Every other pair has no interpolation: interpolate(int, org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double) returns null, which means that a transition does not start and an animation switches halfway (discrete). A length and a percentage, or lengths that are not absolute, are not mixed (the calc() of the mix is not built). The class is stateless.

계산된 속성 값의 보간(계획 P10-07, CSS Transitions Level 1 4 절, CSS Values 3 9 절, https://www.w3.org/TR/css-transitions-1/): 숫자와 길이는 선형, 백분율은 선형, 색은 알파를 미리 곱해서(CSS Color 4 12 절), transform 은 함수 목록으로(Transforms.interpolate(org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double, double, double) 참조), 같은 길이의 목록은 요소별로(예: transform-origin, background-position 의 두 성분), visibility 는 CSS Transitions 처럼(한쪽 끝이 visible 이면 보간 중 visible) 보간한다. 그 밖의 쌍은 보간이 없다: interpolate(int, org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double) 는 null 을 반환하며 전환은 시작하지 않고 애니메이션은 중간에서 바뀐다(이산). 길이와 백분율, 절대가 아닌 길이는 섞지 않는다(섞은 calc() 를 만들지 않는다). 클래스는 상태가 없다.
