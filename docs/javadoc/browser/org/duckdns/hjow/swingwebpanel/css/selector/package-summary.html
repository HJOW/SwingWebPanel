Package org.duckdns.hjow.swingwebpanel.css.selector

Selectors Level 3/4: selector parser, specificity, matching against DOM elements and the querySelector engine.

See:
          Description

Interface Summary
ElementState The plug-in through which the selector matcher learns the dynamic state of elements: pointer and focus state, the fragment target, form control state that lives outside the attributes (the user typed into a field, a checkbox was clicked, a script changed a property) and validity.
MatchContext.ScopeRoot Decides which elements :scope matches when a rule of an @scope block is matched: every element that is a scoping root, as @scope can have several roots.
 

Class Summary
AnPlusB The An+B micro-syntax of :nth-child() and its relatives: the keywords odd and even, a plain integer, or An+B with all the sign and whitespace variants of the specification (2n+1, -n + 3, +n, n- 2, ...).
ComplexSelector A complex selector: compound selectors joined by combinators (descendant, child, next-sibling, subsequent-sibling), for example nav > ul li + li.
CompoundSelector A compound selector: a sequence of simple selectors that must all match the same element (for example a.link#top:hover), optionally ending in a pseudo-element.
CssSelectorEngine The selector engine behind querySelector, querySelectorAll, matches and closest (plan item P08-09): it plugs into the DOM through SelectorEngine.
MatchContext The state of one matching operation: the scoping element (for :scope), the dynamic element state provider, the pseudo-element being styled, and a work budget that protects against selectors with pathological backtracking.
NamespaceMap The namespace prefixes declared by @namespace rules of a style sheet: a default namespace and prefix to URI bindings.
PseudoClasses The registry of the pseudo-classes and pseudo-elements the selector parser knows.
SelectorList A comma separated list of complex selectors (the prelude of a style rule, or the argument of :is(), :not(), :has()).
SelectorMatcher The selector matcher: decides whether an element matches a selector.
SelectorParser The parser of Selectors Level 3/4 selector text.
SimpleElementState A small mutable ElementState: the host sets which element is hovered, active, focused and which one is the fragment target.
SimpleSelector One simple selector: a type or universal selector, an id, a class, an attribute selector or a pseudo-class.
 

Exception Summary
SelectorSyntaxException Thrown by the selector parser when a selector text is not valid.
