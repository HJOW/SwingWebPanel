Class UnknownRule

public final class UnknownRule
extends CssRule

A rule that the engine keeps without interpreting it: @page, @property, @counter-style, @container and similar at-rules. It preserves the written text so that the style sheet can be serialized again.

엔진이 해석하지 않고 보관하는 규칙: @page, @property, @counter-style, @container 같은 at-규칙. 스타일 시트를 다시 직렬화할 수 있도록 쓰인 문자열을 보존한다.
