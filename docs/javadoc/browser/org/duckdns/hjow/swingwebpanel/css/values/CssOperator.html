public final class CssOperator
extends CssValue

A punctuation value inside a structured value: the slash of 12px/1.5, 16 / 9 or a / b and the commas of function arguments that are kept inside a sequence. It carries no meaning of its own; it keeps the structure of the written value so that it can be serialized again and analysed by the consumers.

구조를 가진 값 안의 구두점 값: 12px/1.5, 16 / 9, a / b 의 슬래시와 시퀀스 안에 남긴 함수 인수의 쉼표. 자체 의미는 없으며 쓰인 값의 구조를 유지해 다시 직렬화하고 사용하는 쪽이 분석할 수 있게 한다.
