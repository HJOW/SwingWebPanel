Class Prop

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.props.Prop

public final class Prop
extends java.lang.Object

The numeric ids of the longhand properties. The constants are generated from the rows of PropertyTable: constant N is the N-th row, and the name is the property name in upper case with hyphens replaced by underscores. Layout and rendering code switches on these ids and reads them with ComputedStyle.get(Prop.WIDTH).

개별 속성의 숫자 id. 상수는 PropertyTable 의 행에서 생성한다: 상수 N 은 N 번째 행이며 이름은 속성 이름을 대문자로 하고 하이픈을 밑줄로 바꾼 것이다. 레이아웃과 렌더링 코드는 이 id 로 분기하고 ComputedStyle.get(Prop.WIDTH) 로 읽는다.
