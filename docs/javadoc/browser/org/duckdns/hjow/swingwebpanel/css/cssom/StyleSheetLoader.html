Interface StyleSheetLoader

All Known Subinterfaces:
ContextualStyleSheetLoader
public interface StyleSheetLoader

The plug-in through which style sheet sources are loaded: @import rules and <link rel="stylesheet"> elements ask it for the text of a style sheet. The host implements it on top of the common request layer (User-Agent, extra headers, cookies, the allowed URL schemes, the cache), so that style sheets use the same policies as every other resource. The implementation decodes the bytes with StyleSheetDecoder.

스타일 시트 출처를 읽는 플러그인: @import 규칙과 <link rel="stylesheet"> 요소가 스타일 시트의 텍스트를 요청한다. 호스트가 공통 요청 계층(User-Agent, 추가 헤더, 쿠키, 허용 URL 스키마, 캐시) 위에 구현하여 스타일 시트도 다른 모든 리소스와 같은 정책을 쓰게 한다. 구현은 StyleSheetDecoder 로 바이트를 디코딩한다.
