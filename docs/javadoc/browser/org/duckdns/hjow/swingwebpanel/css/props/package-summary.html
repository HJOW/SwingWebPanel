Class Summary
LogicalProps The mapping of the logical properties to the physical ones (CSS Logical Properties and Values Level 1, https://www.w3.org/TR/css-logical-1/, retrieved 2026-11-17): margin-block-start, padding-inline-end, inset-block-start, border-inline-start-width (and the style and the color), border-start-end-radius, inline-size, min-block-size and the rest of the logical longhands (the ids Prop.MARGIN_BLOCK_START to Prop.MAX_BLOCK_SIZE).
Prop The numeric ids of the longhand properties.
Property The definition of one longhand property: id, name, inheritance, initial value, value grammar and whether it is only parsed.
PropertyRegistry The table of CSS properties known to the engine: the longhands (Property, ids in Prop), the shorthands (Shorthand), the vendor-prefixed aliases, the named value definitions, and the names that are recognised but deliberately unsupported (3D transforms, logical properties, ...).
QuirkyValues The value quirks of CSS that is parsed in quirks mode: the <quirky-length> (a unitless number is a px length in a fixed list of properties, CSS Values 4 appendix C) and the <quirky-color> (a hex color without the leading hash in color, background-color and the border colors, CSS Color 4 appendix B), as the Quirks Mode Standard sections 3.2 and 3.1 refer to them.
Shorthand A shorthand property: a name that sets several longhand properties from one value.
