The prelude of an @scope rule (CSS Cascading and Inheritance Level 6, section 2, "Scoping Styles"): @scope (<scope-start>) to (<scope-end>). The scoping roots are the elements that match the start selector (the root element if there is none); the scope of a root is its descendants except the elements that match the end selector (:scope in the end selector is the root) and their descendants. The rules inside the block only apply to the elements in a scope, and among rules of equal specificity the one whose scoping root is nearer to the element wins (scoping proximity).

@scope 규칙의 전문(CSS Cascading and Inheritance Level 6, 2 절 "Scoping Styles"): @scope (<scope-start>) to (<scope-end>). 범위 루트는 시작 선택자와 일치하는 요소이고(없으면 루트 요소), 루트의 범위는 그 자손에서 끝 선택자와 일치하는 요소(끝 선택자의 :scope 는 루트이다)와 그 자손을 뺀 것이다. 블록 안의 규칙은 범위 안의 요소에만 적용되며, 구체성이 같으면 범위 루트가 요소에 더 가까운 규칙이 이긴다(범위 근접도).
