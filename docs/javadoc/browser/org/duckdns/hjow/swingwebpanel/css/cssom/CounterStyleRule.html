Class CounterStyleRule

public final class CounterStyleRule
extends CssRule

A @counter-style rule (CSS Counter Styles Level 3, https://www.w3.org/TR/css-counter-styles-3/): the definition of a named way to write a counter value, with the descriptors system, symbols, additive-symbols, negative, prefix, suffix, range, pad, fallback and speak-as (kept but not used: there is no speech). The rule only holds the descriptors as written; the layout reads them (layout.CounterStyles) and drops a definition that is not valid for its system.

@counter-style 규칙(CSS Counter Styles Level 3, https://www.w3.org/TR/css-counter-styles-3/): 카운터 값을 쓰는 이름 있는 방법의 정의. 서술자는 system, symbols, additive-symbols, negative, prefix, suffix, range, pad, fallback, speak-as(보관하지만 쓰지 않는다. 음성이 없다)이다. 규칙은 서술자를 쓰인 그대로 보관하고, 레이아웃이 (layout.CounterStyles) 읽어 시스템에 맞지 않는 정의는 버린다.
