Class CssStyleDeclaration

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.CssStyleDeclaration

public final class CssStyleDeclaration
extends java.lang.Object

A declaration block: the declarations of a style rule, of a style attribute or of a keyframe, parsed into longhand values. Shorthands are expanded when they are stored; the normal and the !important declarations are kept apart because the cascade treats them as different layers (within a block a later declaration replaces an earlier one of the same importance only). Custom properties are kept as component values. The object also offers the CSSOM view of a declaration block (getPropertyValue, setProperty, removeProperty, cssText) for the style object of an element.

선언 블록: 스타일 규칙, style 속성, 키프레임의 선언을 개별 속성 값으로 파싱한 것. 단축 속성은 저장할 때 전개한다. 일반 선언과 !important 선언은 캐스케이드가 서로 다른 층으로 다루므로 따로 보관한다(한 블록 안에서는 중요도가 같은 앞 선언만 뒤 선언으로 대체된다). 사용자 정의 속성은 컴포넌트 값으로 보관한다. 요소의 style 객체를 위한 CSSOM 관점(getPropertyValue, setProperty, removeProperty, cssText)도 제공한다.
