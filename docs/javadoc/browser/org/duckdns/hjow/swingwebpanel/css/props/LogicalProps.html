org.duckdns.hjow.swingwebpanel.css.props
Class LogicalProps

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.props.LogicalProps

public final class LogicalProps
extends java.lang.Object

The mapping of the logical properties to the physical ones (CSS Logical Properties and Values Level 1, https://www.w3.org/TR/css-logical-1/, retrieved 2026-11-17): margin-block-start, padding-inline-end, inset-block-start, border-inline-start-width (and the style and the color), border-start-end-radius, inline-size, min-block-size and the rest of the logical longhands (the ids Prop.MARGIN_BLOCK_START to Prop.MAX_BLOCK_SIZE). A logical property is a different name for a physical property that depends on the writing-mode and the direction of the element: the block axis is vertical in horizontal-tb and horizontal in the vertical modes (block-start is the top, or the right in vertical-rl and sideways-rl, the left in vertical-lr and sideways-lr), the inline axis is the other one and its start is the left (right in rtl) in horizontal-tb, the top (bottom in rtl) in vertical-rl, vertical-lr and sideways-rl and the bottom (top in rtl) in sideways-lr. The cascade writes the value of a logical declaration to the physical longhand that this class names, so a logical and a physical declaration of the same side compete in the order of the cascade (the later one wins) and the layout code only knows the physical properties.

논리 속성을 물리 속성으로 옮기는 규칙(CSS Logical Properties and Values Level 1, https://www.w3.org/TR/css-logical-1/, 조회 2026-11-17): margin-block-start, padding-inline-end, inset-block-start, border-inline-start-width(와 스타일, 색), border-start-end-radius, inline-size, min-block-size 등 논리 개별 속성(Prop.MARGIN_BLOCK_START 부터 Prop.MAX_BLOCK_SIZE 까지의 id). 논리 속성은 요소의 writing-mode 와 direction 에 따라 정해지는 물리 속성의 다른 이름이다: 블록 축은 horizontal-tb 에서 세로이고 세로쓰기에서 가로이다(block-start 는 위쪽이며 vertical-rl, sideways-rl 에서는 오른쪽, vertical-lr, sideways-lr 에서는 왼쪽). 인라인 축은 다른 축이며 그 시작은 horizontal-tb 에서 왼쪽(rtl 이면 오른쪽), vertical-rl, vertical-lr, sideways-rl 에서 위쪽(rtl 이면 아래쪽), sideways-lr 에서 아래쪽(rtl 이면 위쪽)이다. 계단식은 논리 선언의 값을 이 클래스가 알려 주는 물리 개별 속성에 쓰므로 같은 변의 논리 선언과 물리 선언은 계단식 순서(나중 것이 이김)로 겨루고, 레이아웃 코드는 물리 속성만 안다.
