Package org.duckdns.hjow.swingwebpanel.css.anim

Transforms, transitions and animations: the 2D transform math, easing functions, the interpolation of property values, the @keyframes timeline and the per-document animation clock.

See:
          Description

Interface Summary
AnimationClock The time source of the animations of a document (plan item P10-07): the engine reads it whenever it computes styles or advances.
WebAnimationHost What the Web Animations model needs from the script side of a page (Web Animations Level 1): promises for the ready and finished attributes of the animations, microtasks for the "finish notification steps", and a new animation frame (a call of WebAnimationSet.update(double) followed by a microtask checkpoint and the dispatch of WebAnimationSet.takeEvents()) whenever something waits for one.
WebAnimationHost.PromiseSlot A promise of an animation (ready or finished) that the model settles.
WebAnimationSet.TimeSource The clock of the document: milliseconds since the time origin of the page.
 

Class Summary
AnimationEngine The CSS transitions and animations of one document (plan item P10-07, CSS Transitions Level 1 https://www.w3.org/TR/css-transitions-1/ and CSS Animations Level 1 https://www.w3.org/TR/css-animations-1/, with the easing of CSS Easing Level 1).
AnimationPlaybackEvent An animation playback event of Web Animations Level 1 (section 6.12, AnimationPlaybackEvent): finish, cancel and remove, fired at a WebAnimation.
Compositor The composite operations add and accumulate of Web Animations Level 1 (section 5.4.4) for the computed values that this engine can combine: numbers (an integer stays an integer when both are integers), lengths in pixels, percentages, angles, colors (component-wise sum in the premultiplied space, clamped), transform lists, and space or comma lists of such values of the same length.
CssAnimationEvent The event of a CSS transition or animation (plan item P10-07): transitionrun, transitionstart, transitionend, transitioncancel (with CssAnimationEvent.getPropertyName()) and animationstart, animationiteration, animationend, animationcancel (with CssAnimationEvent.getAnimationName()).
CssKeyframesEvent The event of a CSS animation (animationstart, animationiteration, animationend, animationcancel): the script interface AnimationEvent with animationName, elapsedTime and pseudoElement.
CssTransitionEvent The event of a CSS transition (transitionrun, transitionstart, transitionend, transitioncancel): the script interface TransitionEvent with propertyName, elapsedTime and pseudoElement.
Easing An easing (timing) function (plan item P10-07, CSS Easing Functions Level 1, https://www.w3.org/TR/css-easing-1/): a function from the input progress of an animation or a transition to the output progress.
EffectTiming The timing properties of an animation effect and the timing calculations of Web Animations Level 1 (W3C Working Draft 5 June 2023, https://www.w3.org/TR/2023/WD-web-animations-1-20230605/, sections 4.5 to 4.11 and 6.5): the start delay, the end delay, the fill mode, the iteration start, the iteration count, the iteration duration (auto is zero in this level), the playback direction and the timing function.
EffectTiming.Computed The result of the timing calculations at one local time.
Interpolator The interpolation of computed property values (plan item P10-07, CSS Transitions Level 1 section 4 and CSS Values 3 section 9, https://www.w3.org/TR/css-transitions-1/): numbers and lengths linearly, percentages linearly, colors with premultiplied alpha (CSS Color 4 section 12), transform as lists of functions (see Transforms.interpolate(org.duckdns.hjow.swingwebpanel.css.values.CssValue, org.duckdns.hjow.swingwebpanel.css.values.CssValue, double, double, double)), lists of the same length element by element (for example the two components of transform-origin or background-position), and visibility as in CSS Transitions (visible during the interpolation if one end is visible).
KeyframeEffectModel A keyframe effect of Web Animations Level 1 (sections 5.3 and 6.6, KeyframeEffect): an effect target (an element and an optional pseudo-element such as ::before), the timing properties (EffectTiming), the composite operation of the effect and the list of keyframes.
KeyframeEffectModel.Keyframe One keyframe as the script specified it, with its parsed declarations.
Transforms The 2D transform of an element (plan item P10-06, CSS Transforms Level 1, https://www.w3.org/TR/css-transforms-1/ section 8 and 13): turns the computed value of transform and transform-origin into an AffineTransform.
WebAnimation An animation of Web Animations Level 1 (sections 4.4 and 6.4, Animation): it binds a KeyframeEffectModel to a WebTimeline and controls its playback with a start time, a hold time and a playback rate.
WebAnimationSet The Web Animations state of one document (Web Animations Level 1): the animations created by scripts in their global order (the composite order among them), the time of the document that the WebTimelines follow, the pending animation event queue and the procedure "update animations and send events" (WebAnimationSet.update(double) for the timelines, the pending tasks, the finished states and the removal of replaced animations, then WebAnimationSet.takeEvents() after the host's microtask checkpoint).
WebAnimationSet.PendingEvent An event in the pending animation event queue with its target and its scheduled event time.
WebTimeline A document timeline of Web Animations Level 1 (sections 4.3.1, 4.3.2 and 6.3, DocumentTimeline): its current time is the time of the document (milliseconds since the time origin of the page, the clock of performance.now() and requestAnimationFrame) minus its origin time.
 

Exception Summary
AnimationException An error that a procedure of Web Animations throws: a TypeError or a DOMException with a name (InvalidStateError, NoModificationAllowedError, SyntaxError).
