Class DeclarationBlock

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.syntax.DeclarationBlock

public final class DeclarationBlock
extends java.lang.Object

The contents of a declaration block: the declarations and the at-rules found inside it (for example the margin at-rules of @page). Qualified rules inside a declaration block are not part of the supported grammar and are dropped by the parser.

선언 블록의 내용: 그 안의 선언들과 at-규칙들(예: @page 의 여백 at-규칙). 선언 블록 안의 한정 규칙은 지원하는 문법이 아니므로 파서가 버린다.
