Class AnimationEngine

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.anim.AnimationEngine
All Implemented Interfaces:
StyleAnimator
public final class AnimationEngine
extends java.lang.Object
implements StyleAnimator

The CSS transitions and animations of one document (plan item P10-07, CSS Transitions Level 1 https://www.w3.org/TR/css-transitions-1/ and CSS Animations Level 1 https://www.w3.org/TR/css-animations-1/, with the easing of CSS Easing Level 1). The engine is the StyleAnimator of the StyleResolver: when the style of an element is computed it compares it with the previous one and starts a transition for every property that changed and for which the new style has a transition with a duration or a delay, it starts the animations that animation-name lists (finding the @keyframes by name, the last one wins), and it returns the style with the values of the running transitions and animations at the moment of the AnimationClock in the composite order of Web Animations (the transitions at the bottom, the CSS animations above them, the script animations of getWebAnimations() on top). The descendants inherit the animated values, because the style of the element is what they inherit from. tick() advances the engine: it finishes the transitions and animations that ran out, drops the cached styles of the elements whose value is moving (so that the next style computation gives the new value), and then fires the events in the order in which they happened: transitionrun, transitionstart, transitionend, transitioncancel, animationstart, animationiteration, animationend, animationcancel (see CssAnimationEvent). The host calls tick() before it renders and asks isActive() whether to render again soon (about 60 times a second) or to stop; nothing in the engine starts a thread, so everything runs on the document thread, and the animations of a page that is replaced or disposed end with dispose() without any event. JavaScript being disabled does not change anything here: the engine does not depend on the script engine.

Supported: every property whose two computed values can be interpolated (Interpolator: numbers, lengths, percentages, colors, transform, lists of those, visibility); transition-property with all, names and shorthand names; transition-duration/delay/timing-function lists repeated to the length of the property list; animation-* lists matched by name index; keyframes with several selectors (0%, 50%), missing from/to (the underlying value), the animation-timing-function inside a keyframe (for the interval that starts there), animation-play-state (pausing keeps the progress), the directions, fill modes and iteration counts (also fractional and infinite). Documented limits: no transition starts for the style that is computed first (no @starting-style); a transition that is interrupted starts from the current value over the full duration (no reversing shortening factor); percentages inside the interpolation of two transform lists with different functions are resolved against a reference box of size 0; pseudo-elements run transitions only (no keyframe animations); the properties of a keyframe that are parsed but not interpolable change halfway (discrete); changes of @keyframes after an animation started do not restart it.

한 문서의 CSS 전환과 애니메이션(계획 P10-07, CSS Transitions Level 1 https://www.w3.org/TR/css-transitions-1/, CSS Animations Level 1 https://www.w3.org/TR/css-animations-1/, 완화는 CSS Easing Level 1). 엔진은 StyleResolver 의 StyleAnimator 이다: 요소의 스타일을 계산할 때 이전 것과 비교해 바뀐 속성 중 새 스타일이 지속 시간이나 지연을 가진 전환을 정한 것마다 전환을 시작하고, animation-name 이 나열한 애니메이션을 시작하며(@keyframes 를 이름으로 찾고 마지막 것이 이긴다), AnimationClock 의 지금 시각의 실행 중인 전환과 애니메이션의 값을 Web Animations 의 합성 순서(가장 아래에 전환, 그 위에 CSS 애니메이션, 맨 위에 getWebAnimations() 의 스크립트 애니메이션)로 적용한 스타일을 돌려준다. 자손은 요소의 스타일을 상속하므로 애니메이션 값을 상속한다. tick() 은 엔진을 진행한다: 끝난 전환과 애니메이션을 마치고, 값이 움직이는 요소의 캐시한 스타일을 버리며(다음 스타일 계산이 새 값을 주도록), 일어난 순서대로 이벤트를 발생시킨다: transitionrun, transitionstart, transitionend, transitioncancel, animationstart, animationiteration, animationend, animationcancel(CssAnimationEvent 참조). 호스트는 렌더링 전에 tick() 을 부르고 isActive() 로 곧(초당 약 60번) 다시 렌더링할지 멈출지 묻는다. 엔진은 스레드를 만들지 않으므로 모두 문서 스레드에서 동작하며, 교체되거나 폐기되는 페이지의 애니메이션은 dispose() 로 이벤트 없이 끝난다. JavaScript 를 끄는 것은 여기에 영향이 없다: 엔진은 스크립트 엔진에 의존하지 않는다.

지원: 두 계산 값을 보간할 수 있는 모든 속성(Interpolator: 숫자, 길이, 백분율, 색, transform, 그들의 목록, visibility), all, 이름, 단축 속성 이름을 쓴 transition-property, 속성 목록 길이로 되풀이되는 transition-duration/delay/timing-function 목록, 이름 위치로 짝짓는 animation-* 목록, 선택자가 여럿인 키프레임(0%, 50%), 없는 from/to(기저 값), 키프레임 안의 animation-timing-function(그 키프레임에서 시작하는 구간), animation-play-state(멈추면 진행도 유지), 방향, 채움, 반복 횟수(소수와 infinite 포함). 문서화된 한계: 처음 계산한 스타일에는 전환이 시작되지 않는다(@starting-style 없음), 중단된 전환은 현재 값에서 전체 지속 시간으로 다시 시작한다(되돌림 단축 계수 없음), 함수가 다른 두 transform 목록을 보간할 때 백분율은 크기 0 인 기준 상자로 푼다, 의사 요소는 전환만 하고 키프레임 애니메이션은 하지 않는다, 보간할 수 없는 키프레임 속성은 중간에서 바뀐다(이산), 애니메이션이 시작된 뒤 @keyframes 가 바뀌어도 다시 시작하지 않는다.

tick

public boolean tick()
Advances the engine to the time of the clock: ends what ran out, drops the cached styles of the elements whose animated value changes (so that the next computation gives the value of this moment) and fires the queued events. Call it on the document thread before a frame is rendered.

시계의 시각까지 엔진을 진행한다: 끝난 것을 마치고, 애니메이션 값이 바뀌는 요소의 캐시한 스타일을 버리며(다음 계산이 이 순간의 값을 주도록) 큐의 이벤트를 발생시킨다. 프레임을 렌더링하기 전에 문서 스레드에서 부른다.

animatePseudo

public ComputedStyle animatePseudo(Element element,
                                   java.lang.String pseudo,
                                   ComputedStyle computed)
Returns the style of a pseudo-element of an element at the moment (CSS Transitions Level 1: the pseudo-elements ::before, ::after, ::marker ... are transitioned like elements): starts the transitions that the style of the pseudo-element asks for when its style changed and applies the values of the running ones. The first style of a pseudo-element starts no transition, and animations (@keyframes) do not run on pseudo-elements.

요소의 의사 요소의 지금 스타일을 반환한다(CSS Transitions Level 1: ::before, ::after, ::marker 등 의사 요소도 요소처럼 전환한다): 의사 요소의 스타일이 바뀌었을 때 그 스타일이 요구하는 전환을 시작하고 실행 중인 것의 값을 적용한다. 의사 요소의 처음 스타일은 전환을 시작하지 않으며 애니메이션(@keyframes)은 의사 요소에서 실행하지 않는다.
