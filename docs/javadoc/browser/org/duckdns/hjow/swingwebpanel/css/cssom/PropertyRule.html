public final class PropertyRule
extends CssRule

An @property rule (CSS Properties and Values API Level 1, https://www.w3.org/TR/css-properties-values-api-1/, section 3): the registration of a custom property with a syntax (a string in the value definition syntax of the data types <length>, <number>, <percentage>, <length-percentage>, <color>, <image>, <url>, <integer>, <angle>, <time>, <resolution>, <transform-function>, <transform-list>, <custom-ident>, <string>, keywords, with the combinators |, + and #, or * for anything), whether it inherits and its initial-value (required unless the syntax is *). The rule only holds what was written; the cascade computes the values (css.cascade.RegisteredProperty), and checks that the initial value does not depend on its context.

@property 규칙(CSS Properties and Values API Level 1, https://www.w3.org/TR/css-properties-values-api-1/, 3 절): 사용자 정의 속성을 syntax(자료형 <length>, <number>, <percentage>, <length-percentage>, <color>, <image>, <url>, <integer>, <angle>, <time>, <resolution>, <transform-function>, <transform-list>, <custom-ident>, <string>, 키워드를 |, +, # 로 조합한 값 정의 문법의 문자열, 또는 무엇이든 되는 *), 상속 여부(inherits), 초기값 (initial-value, 문법이 * 가 아니면 필수)과 함께 등록한다. 규칙은 쓰인 것만 보관하고, 값의 계산은 캐스케이드가 (css.cascade.RegisteredProperty) 하며 초기값이 문맥에 의존하지 않는지도 거기서 검사한다.

Creates the rule from its descriptors, or null if the registration is invalid: the name is not a custom property name, the syntax is missing or malformed, inherits is missing or not true/false, or the initial value is missing for a syntax that is not * or does not match the syntax.
