Class PropertyRegistry

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.props.PropertyRegistry
All Implemented Interfaces:
GrammarRegistry
public final class PropertyRegistry
extends java.lang.Object
implements GrammarRegistry

The table of CSS properties known to the engine: the longhands (Property, ids in Prop), the shorthands (Shorthand), the vendor-prefixed aliases, the named value definitions, and the names that are recognised but deliberately unsupported (3D transforms, logical properties, ...). It parses a declaration into longhand values with the error handling of a browser: an invalid value drops the whole declaration.

엔진이 아는 CSS 속성의 표: 개별 속성(Property, id 는 Prop), 단축 속성(Shorthand), 접두사 붙은 별칭, 이름 있는 값 정의, 알아보지만 의도적으로 지원하지 않는 이름(3D 변형, 논리 속성 등). 브라우저처럼 오류를 처리하여 선언을 개별 속성 값으로 파싱한다: 올바르지 않은 값은 선언 전체를 버린다.

parseDeclaration

public int parseDeclaration(java.lang.String name,
                            java.util.List<ComponentValue> value,
                            ParseEnv env,
                            java.util.Map<java.lang.Integer,CssValue> out)
Parses a declaration into longhand values.

선언을 개별 속성 값으로 파싱한다.

A CSS-wide keyword is written to every longhand; a value that contains var() becomes a CssPending for every longhand; otherwise the shorthand parser or the longhand grammar decides. Custom properties (--x) are not handled here.

CSS 전역 키워드는 모든 개별 속성에 쓰고, var() 가 든 값은 모든 개별 속성에 대해 CssPending 이 되며, 그 밖에는 단축 속성 파서나 개별 속성 문법이 판정한다. 사용자 정의 속성(--x)은 여기서 다루지 않는다.

Parameters:
name - the property name as written / 쓰인 속성 이름
value - the declaration value / 선언 값
env - the parse environment / 파싱 환경
out - receives longhand id and specified value in order / 개별 속성 id 와 지정 값을 순서대로 받는다
Returns:
OK, UNKNOWN, UNSUPPORTED or INVALID / OK, UNKNOWN, UNSUPPORTED, INVALID 중 하나
