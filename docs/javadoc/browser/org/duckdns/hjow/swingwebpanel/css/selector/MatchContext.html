org.duckdns.hjow.swingwebpanel.css.selector
Class MatchContext

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.MatchContext

public final class MatchContext
extends java.lang.Object

The state of one matching operation: the scoping element (for :scope), the dynamic element state provider, the pseudo-element being styled, and a work budget that protects against selectors with pathological backtracking. A context is cheap and is not thread-safe; create one per thread or per operation.

매칭 작업 하나의 상태: :scope 용 범위 요소, 동적 요소 상태 제공자, 스타일을 계산하는 의사 요소, 비정상적으로 역추적하는 선택자를 막는 작업량 한도. 컨텍스트는 가볍고 스레드 안전하지 않으므로 스레드나 작업마다 만든다.
