Class XmlStylesheetInstruction

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.XmlStylesheetInstruction

public final class XmlStylesheetInstruction
extends java.lang.Object

The pseudo-attributes of an xml-stylesheet processing instruction (Associating Style Sheets with XML documents 1.0, https://www.w3.org/TR/xml-stylesheet/, W3C Recommendation 2010-10-28), which XHTML documents use to link a style sheet: <?xml-stylesheet type="text/css" href="style.css" media="screen" title="Main" alternate="no"?>. The data of the instruction is a sequence of name="value" pairs (single or double quotes), the five predefined entities and the character references are decoded in the values, and an unreadable instruction has no pseudo-attributes at all.

xml-stylesheet 처리 명령의 의사 속성(Associating Style Sheets with XML documents 1.0, W3C 권고안 2010-10-28). XHTML 문서가 스타일 시트를 연결하는 데 쓴다: <?xml-stylesheet type="text/css" href="style.css" media="screen" title="Main" alternate="no"?>. 처리 명령의 데이터는 name="value" 쌍(작은따옴표나 큰따옴표)의 나열이며, 값의 미리 정의된 엔티티 다섯 개와 문자 참조는 풀어 주고, 읽을 수 없는 처리 명령은 의사 속성이 하나도 없다.

Parses the data of the instruction into its pseudo-attributes. The first occurrence of a name wins; the names are case-sensitive.
