public final class PageRule
extends CssRule

A @page rule (CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, section 4, W3C Working Draft 14 September 2023; CSSOM CSSPageRule, legacy type 6): a list of page selectors (an optional page type name followed by the page pseudo-classes :left, :right, :first, :blank; an empty selector list matches every page), a block of page descriptors (size, margin, marks, bleed, page-orientation ...) and the page-margin rules inside it (MarginRule). The engine does not print, so the rule is parsed, kept and exposed through the CSSOM, and its selectors can be tested against a page (matches(java.lang.String, int, boolean, boolean)); the page boxes are never laid out.

@page 규칙(CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, 4 절, W3C 작업 초안 2023-09-14, CSSOM CSSPageRule, 옛 종류 6): 쪽 선택자 목록(선택적인 쪽 이름 뒤에 쪽 의사 클래스 :left, :right, :first, :blank. 선택자 목록이 비면 모든 쪽에 일치), 쪽 서술자 블록(size, margin, marks, bleed, page-orientation 등), 그 안의 쪽 여백 규칙(MarginRule). 엔진은 인쇄하지 않으므로 규칙은 파싱해 보관하고 CSSOM 으로 보여 주며 선택자를 쪽에 대해 시험할 수 있다(matches(java.lang.String, int, boolean, boolean)). 쪽 상자는 배치하지 않는다.
