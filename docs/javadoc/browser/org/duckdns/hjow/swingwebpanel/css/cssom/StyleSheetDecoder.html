Class StyleSheetDecoder

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.StyleSheetDecoder

public final class StyleSheetDecoder
extends java.lang.Object

Decodes the bytes of a style sheet to text, with the encoding detection of CSS Syntax Level 3: a byte order mark wins, then the charset of the Content-Type header, then an @charset "name"; rule at the very start, then the encoding of the referring document or sheet, and finally UTF-8. A UTF-16 name in @charset is treated as UTF-8, as the specification says. Malformed input is replaced, never fatal.

스타일 시트의 바이트를 CSS Syntax Level 3 의 인코딩 판정으로 텍스트로 디코딩한다: 바이트 순서 표시가 우선이고, 다음은 Content-Type 헤더의 charset, 맨 앞의 @charset "name"; 규칙, 참조한 문서나 시트의 인코딩, 마지막으로 UTF-8 이다. @charset 의 UTF-16 이름은 규격대로 UTF-8 로 본다. 잘못된 입력은 치환하며 치명적이지 않다.
