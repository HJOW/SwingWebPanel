org.duckdns.hjow.swingwebpanel.css.anim
Class WebAnimation

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.EventTarget
      org.duckdns.hjow.swingwebpanel.css.anim.WebAnimation

public class WebAnimation
extends EventTarget

An animation of Web Animations Level 1 (sections 4.4 and 6.4, Animation): it binds a KeyframeEffectModel to a WebTimeline and controls its playback with a start time, a hold time and a playback rate. The procedures of the specification are implemented as they are written: setting the timeline, the effect, the current time and the start time; playing (with auto-rewind), pausing, finishing, canceling and reversing; the playback rate and its seamless update through a pending playback rate; the pending play and pause tasks, which run at the next animation frame of the document (WebAnimationSet.update(double)), so that the ready promise resolves asynchronously with the time of that frame as the ready time; "update an animation's finished state" with the finish notification steps in a microtask (or at once for finish()); the replace state. Events (finish, cancel, remove) go to the pending animation event queue of the document and are dispatched at the next frame. An unresolved time is NaN. The methods that the specification lets throw throw AnimationException. All methods run on the document thread.

Web Animations Level 1 의 애니메이션(4.4 절과 6.4 절, Animation): KeyframeEffectModel 을 WebTimeline 에 묶고 시작 시간, 유지 시간, 재생 속도로 재생을 제어한다. 규격의 절차를 쓰인 그대로 구현한다: 타임라인, 효과, 현재 시간, 시작 시간 설정, 재생(자동 되감기 포함), 일시정지, 끝내기, 취소, 뒤집기, 재생 속도와 대기 재생 속도를 통한 매끄러운 갱신, 문서의 다음 애니메이션 프레임(WebAnimationSet.update(double))에서 실행되는 대기 중인 play/pause 작업(그래서 ready 프라미스는 그 프레임의 시간을 준비 시간으로 하여 비동기로 resolve 된다), 마이크로태스크에서(finish() 는 즉시) 실행되는 끝 알림 단계를 가진 "update an animation's finished state", 교체 상태. 이벤트(finish, cancel, remove)는 문서의 대기 애니메이션 이벤트 큐로 가서 다음 프레임에 전달된다. 결정되지 않은 시간은 NaN 이다. 규격이 던지게 한 메서드는 AnimationException 을 던진다. 모든 메서드는 문서 스레드에서 실행된다.
