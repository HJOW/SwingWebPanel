org.duckdns.hjow.swingwebpanel.css
Class CssDiagnostics

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.CssDiagnostics

public final class CssDiagnostics
extends java.lang.Object

Collects the diagnostics of the CSS engine: dropped declarations, unknown properties, invalid values, unsupported features and so on. A browser silently ignores such input; this object keeps a record of it so that developers (and the feature matrix) can see which part of a style sheet was not applied. Passing null wherever a collector is accepted switches the recording off. Instances are thread-safe.

CSS 엔진의 진단을 모은다: 버려진 선언, 알 수 없는 속성, 잘못된 값, 지원하지 않는 기능 등. 브라우저는 이런 입력을 조용히 무시하지만 이 객체는 그 기록을 남겨 개발자(와 기능 표)가 스타일 시트의 어느 부분이 적용되지 않았는지 볼 수 있게 한다. 수집기를 받는 곳에 null 을 넘기면 기록하지 않는다. 인스턴스는 스레드 안전하다.
