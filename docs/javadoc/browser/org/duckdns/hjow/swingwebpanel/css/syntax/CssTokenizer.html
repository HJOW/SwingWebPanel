Class CssTokenizer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.syntax.CssTokenizer

public final class CssTokenizer
extends java.lang.Object

The tokenizer of CSS Syntax Module Level 3 (section 4, "Tokenization"), written as an explicit state machine over the preprocessed input: carriage returns and form feeds become line feeds, NUL and lone surrogates become U+FFFD, comments are skipped. Every parse error of the specification is recovered the way the specification says (bad strings and bad urls become their own tokens, an unterminated comment or string ends at the end of input). The older unicode-range token is recognised unless it is switched off.

CSS Syntax Module Level 3 의 토큰화기(4절 "Tokenization"). 전처리한 입력 위의 명시적 상태 기계로 작성했다: 캐리지 리턴과 폼 피드는 줄바꿈이 되고, NUL 과 홀로 있는 서로게이트는 U+FFFD 가 되며, 주석은 건너뛴다. 규격의 모든 파싱 오류는 규격이 정한 대로 복구한다(잘못된 문자열과 잘못된 url 은 별도 토큰, 끝나지 않은 주석이나 문자열은 입력 끝에서 끝남). 이전의 unicode-range 토큰은 끄지 않으면 인식한다.
