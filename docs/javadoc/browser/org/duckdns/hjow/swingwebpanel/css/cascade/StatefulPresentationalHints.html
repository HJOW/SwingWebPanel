public interface StatefulPresentationalHints
extends PresentationalHints

Optional presentational-hint provider that consults dynamic selector state. Reusing the resolver's match context records dependencies so stateChanged invalidates the computed style. Ordinary providers can keep implementing PresentationalHints.

동적 선택자 상태를 조회하는 선택적 표현 힌트 제공자. 리졸버의 매칭 문맥을 공유하여 상태 변경 시 계산 스타일을 무효화하도록 의존성을 기록한다. 일반 제공자는 기존 PresentationalHints 구현을 유지할 수 있다.
