Class SelectorParser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.SelectorParser

public final class SelectorParser
extends java.lang.Object

The parser of Selectors Level 3/4 selector text. It works on the component values produced by the CSS parser, resolves namespace prefixes against a NamespaceMap, and reports anything it does not understand with a SelectorSyntaxException: a rule with an invalid selector is dropped as a whole, and querySelector raises a SyntaxError. Inside :is() and :where() invalid entries are ignored (forgiving lists).

Supported: type, universal, id, class, attribute (all operators and the i/s flags), the combinators ' ' > + ~, every pseudo-class of PseudoClasses, the pseudo-elements listed there.

Selectors Level 3/4 선택자 텍스트의 파서. CSS 파서가 만든 컴포넌트 값 위에서 동작하며 NamespaceMap 으로 네임스페이스 접두사를 해석하고, 이해하지 못하는 것은 SelectorSyntaxException 으로 알린다. 올바르지 않은 선택자를 가진 규칙은 통째로 버려지고 querySelector 는 SyntaxError 를 낸다. :is() 와 :where() 안에서는 잘못된 항목을 무시한다(관대한 목록).

지원: 타입, 전체, id, 클래스, 속성(모든 연산자와 i/s 플래그), 결합자 ' ' > + ~, PseudoClasses 의 모든 의사 클래스와 거기 나열한 의사 요소.
