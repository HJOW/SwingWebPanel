public final class PositionTryRule
extends CssRule

A @position-try rule (CSS Anchor Positioning Level 1 section 6.4, https://www.w3.org/TR/css-anchor-position-1/#position-try-rule, W3C Working Draft, Last-Modified 2026-03-27): a named position option, a block of positioning declarations that position-try-fallbacks can apply to an anchor-positioned box when the box overflows. The block takes the inset properties, the margin properties, the sizing properties, the self-alignment properties, position-anchor and position-area only; any other declaration is dropped, and !important makes a declaration invalid. Several rules of one name cascade like @keyframes: the last one wins. The rule is the CSSOM CSSPositionTryRule: name and style.

@position-try 규칙(CSS Anchor Positioning Level 1 6.4 절, W3C 작업 초안): 이름 있는 위치 대안으로, position-try-fallbacks 가 앵커 위치 상자가 넘칠 때 적용할 수 있는 위치 선언 블록이다. 블록은 오프셋 속성, 마진 속성, 크기 속성, 자기 정렬 속성, position-anchor, position-area 만 받고 다른 선언은 버리며 !important 는 선언을 무효로 만든다. 이름이 같은 여러 규칙은 @keyframes 처럼 캐스케이드되어 마지막 것이 이긴다. 규칙은 CSSOM CSSPositionTryRule(name, style)이다.
