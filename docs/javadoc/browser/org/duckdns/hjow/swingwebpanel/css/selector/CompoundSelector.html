Class CompoundSelector

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.CompoundSelector

public final class CompoundSelector
extends java.lang.Object

A compound selector: a sequence of simple selectors that must all match the same element (for example a.link#top:hover), optionally ending in a pseudo-element.

복합 선택자: 같은 요소에 모두 일치해야 하는 단순 선택자의 나열(예: a.link#top:hover). 끝에 의사 요소가 올 수 있다.
