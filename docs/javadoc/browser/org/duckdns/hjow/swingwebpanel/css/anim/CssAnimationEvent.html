CssKeyframesEvent, CssTransitionEvent
public class CssAnimationEvent
extends Event

The event of a CSS transition or animation (plan item P10-07): transitionrun, transitionstart, transitionend, transitioncancel (with getPropertyName()) and animationstart, animationiteration, animationend, animationcancel (with getAnimationName()). The events bubble and cannot be canceled; getElapsedTime() is in seconds, getPseudoElement() names the pseudo-element of a transition (empty for an element; the keyframe animations do not run on pseudo-elements, only the transitions do).

CSS 전환이나 애니메이션의 이벤트(계획 P10-07): transitionrun, transitionstart, transitionend, transitioncancel (getPropertyName() 포함)과 animationstart, animationiteration, animationend, animationcancel (getAnimationName() 포함). 이벤트는 버블링되고 취소할 수 없다. getElapsedTime() 은 초 단위이며 getPseudoElement() 는 의사 요소의 전환이면 그 이름이고 요소이면 비어 있다(의사 요소에서는 키프레임 애니메이션은 실행하지 않고 전환만 한다).
