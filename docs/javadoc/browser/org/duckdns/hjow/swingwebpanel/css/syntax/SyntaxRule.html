org.duckdns.hjow.swingwebpanel.css.syntax
Class SyntaxRule

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.syntax.SyntaxRule

public final class SyntaxRule
extends java.lang.Object

A rule as produced by the parser: either a qualified rule (a prelude and a block, such as a style rule) or an at-rule (an at-keyword name, a prelude and an optional block). The contents are not interpreted here; the style sheet builder (css.cssom) does that.

파서가 만든 규칙: 한정 규칙(전문과 블록, 예: 스타일 규칙) 또는 at-규칙(at-키워드 이름, 전문, 선택적 블록). 내용은 여기서 해석하지 않으며 스타일 시트 구성기(css.cssom)가 해석한다.
