public final class SelectorMatcher
extends java.lang.Object

The selector matcher: decides whether an element matches a selector. Complex selectors are matched right to left (the subject first, then the combinators walk towards the ancestors and previous siblings) with backtracking for the descendant and subsequent-sibling combinators. The HTML case rules are applied: type and attribute names are case-insensitive for HTML elements of HTML documents, a fixed list of attributes has case-insensitive values, and ids and classes are case-insensitive in quirks mode. The matcher only reads the DOM and keeps no state, so it can be called from any thread that owns the document.

선택자 매처: 요소가 선택자와 일치하는지 판정한다. 복합 선택자는 오른쪽에서 왼쪽으로(대상이 먼저, 이어서 결합자가 조상과 이전 형제 쪽으로) 맞추며 자손 결합자와 이후 형제 결합자에는 역추적이 있다. HTML 대소문자 규칙을 적용한다: HTML 문서의 HTML 요소에서는 타입과 속성 이름이 대소문자를 구분하지 않고, 정해진 속성 목록은 값도 구분하지 않으며, 호환 모드에서는 id 와 클래스도 구분하지 않는다. 매처는 DOM 을 읽기만 하고 상태가 없으므로 문서를 소유한 어느 스레드에서든 호출할 수 있다.
