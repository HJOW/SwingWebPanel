public static interface MatchContext.ScopeRoot

Decides which elements :scope matches when a rule of an @scope block is matched: every element that is a scoping root, as @scope can have several roots.

@scope 블록의 규칙을 매칭할 때 :scope 가 어떤 요소와 일치하는지 정한다: @scope 는 범위 루트가 여럿일 수 있으므로 범위 루트인 모든 요소.
