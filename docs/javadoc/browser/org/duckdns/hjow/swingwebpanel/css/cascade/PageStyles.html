public final class PageStyles
extends java.lang.Object

The cascade of the page context (CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, W3C Working Draft 14 September 2023, section 4.4 "Cascading in the page context" and section 7 "Page Size"): it takes the @page rules of the style sheets and works out the PageStyles.PageBox of one page, that is the size of the page box (size), its margins (margin; a percentage is relative to the page size), the marks and the bleed. The engine does not print, so nothing here is laid out: the class gives the computed descriptors that a printing host (or a script through the CSSOM) can read.

Usage: PageStyles.resolve(resolver.getPageRules(), null, 1, false, true) returns the box of the first (right) page without a name.

쪽 문맥의 계단식(CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, W3C 작업 초안 2023-09-14, 4.4 절 "쪽 문맥의 계단식"과 7 절 "쪽 크기"): 스타일 시트의 @page 규칙으로 한 쪽의 PageStyles.PageBox, 즉 쪽 상자의 크기 (size), 여백(margin. 백분율은 쪽 크기 기준), 표시와 재단 여유를 구한다. 엔진은 인쇄하지 않으므로 아무것도 배치하지 않는다. 인쇄하는 호스트나 (CSSOM 을 통한) 스크립트가 읽을 계산된 서술자를 준다.

사용법: PageStyles.resolve(resolver.getPageRules(), null, 1, false, true) 는 이름 없는 첫(오른쪽) 쪽의 상자를 반환한다.

Works out the page box of a page. The rules that match the page are applied from the least to the most specific (the order of the sources breaks a tie); the declarations of one rule are applied in order, and an !important declaration of any rule wins over every normal one. A property that no rule sets has the initial value; the initial margin is 0 (this engine has no default page margin, as there is no unprintable area).

쪽의 쪽 상자를 구한다. 쪽에 일치하는 규칙을 구체성이 낮은 것부터 높은 것까지(같으면 소스 순서) 적용하고, 한 규칙의 선언은 순서대로 적용하며, 어느 규칙의 !important 선언이든 모든 보통 선언을 이긴다. 어떤 규칙도 정하지 않은 속성은 초기값이다. 초기 여백은 0 이다(이 엔진에는 인쇄할 수 없는 영역이 없으므로 기본 쪽 여백이 없다).

Parameters:
rules - the @page rules in the order of the sources / 소스 순서의 @page 규칙
pageName - the named page, or null/empty for the unnamed page / 쪽의 이름. 이름 없는 쪽이면 null 이나 빈 문자열
number - the page number counted from 1 / 1 부터 센 쪽 번호
blank - true for a blank page that a forced break made / 강제 나눔이 만든 빈 쪽이면 true
right - true for a right page, false for a left page / 오른쪽 쪽이면 true, 왼쪽 쪽이면 false
Returns:
the page box / 쪽 상자
