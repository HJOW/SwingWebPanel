Interface ContextualStyleSheetLoader

All Superinterfaces:
StyleSheetLoader
public interface ContextualStyleSheetLoader
extends StyleSheetLoader

Optional stylesheet loading policy scoped to an owning element and nested import media. A child policy inherits the parent's conditions, allowing parser-blocking loads to wait only for applicable parser-created sheets.

소유 요소와 중첩 import 미디어에 범위를 둔 선택적 스타일시트 로딩 정책. 자식 정책은 부모 조건을 상속하여 파서를 막는 로딩이 적용 가능한 파서 생성 시트만 기다리게 한다. 일반 StyleSheetLoader 구현에는 영향을 주지 않는다.
