Style sheet object model (CSSOM): style sheets, rules, declaration blocks, the style sheet parser, import resolution and the user agent style sheet.

Interface Summary
ContainerCondition.StyleLookup Looks up the computed custom properties of the container for style() queries.
ContextualStyleSheetLoader Optional stylesheet loading policy scoped to an owning element and nested import media.
StyleSheetLoader The plug-in through which style sheet sources are loaded: @import rules and <link rel="stylesheet"> elements ask it for the text of a style sheet.
 

Class Summary
ContainerCondition The prelude of an @container rule (CSS Conditional Level 5, section 4, "Container Queries"): an optional container name and a condition built from size features in parentheses ((min-width: 400px), (width > 400px), (inline-size < 30em), (aspect-ratio > 1/1), (orientation: landscape)), custom property queries (style(--theme: dark)), nested conditions, and the operators not, and, or.
CounterStyleRule A @counter-style rule (CSS Counter Styles Level 3, https://www.w3.org/TR/css-counter-styles-3/): the definition of a named way to write a counter value, with the descriptors system, symbols, additive-symbols, negative, prefix, suffix, range, pad, fallback and speak-as (kept but not used: there is no speech).
CssRule Base class of the rules of a style sheet.
CssRuleList The CSSOM CSSRuleList: a live, read-only list of the rules of a style sheet, of a group rule or of a keyframes rule.
CssStyleDeclaration A declaration block: the declarations of a style rule, of a style attribute or of a keyframe, parsed into longhand values.
DocumentStyleSheets Collects the author style sheets of a document in tree order: the <style> elements (their text, with the media, title and type attributes) and the <link rel="stylesheet"> elements (loaded through a StyleSheetLoader; alternate style sheets and links without a URL are skipped).
FontFaceRule An @font-face rule: the descriptors of a web font.
FontFaceRule.Source One source of a web font.
FontFeatureValuesRule An @font-feature-values rule (CSS Fonts Level 4 section 6.9, https://www.w3.org/TR/css-fonts-4/ WD 12 November 2026, and its CSSOM interface CSSFontFeatureValuesRule): a list of named font families and, for each type of feature value block (@swash, @stylistic, @ornaments, @annotation, @character-variant, @styleset, @historical-forms), a map from case-sensitive names to lists of non-negative feature indexes, plus the font-display descriptor that sets the default display policy of the faces of the families.
FontFeatureValuesRule.ValueMap The map of one type of feature value block (the CSSFontFeatureValuesMap maplike of the CSSOM): names in the order of their first definition, each with its list of indexes.
GroupRule A conditional group rule: @media, @supports and @layer blocks, which contain other rules.
ImportRule An @import rule: the URL, the media queries and the style sheet that was loaded for it (null if the sheet could not be loaded, was part of an import cycle or exceeded the import depth limit, or has not arrived yet).
KeyframesRule A @keyframes rule: the animation name and its keyframes in source order.
KeyframesRule.Keyframe One keyframe: offsets and declarations; a rule of its own (the CSSOM CSSKeyframeRule).
LoadedStyleSheet The result of loading a style sheet: its decoded text and the URL it was finally loaded from (the base for the relative urls inside it).
MarginRule A page-margin at-rule inside @page (CSS Paged Media Level 3, section 4.3, W3C Working Draft 14 September 2023): one of the sixteen margin boxes @top-left-corner, @top-left, @top-center, @top-right, @top-right-corner, @bottom-*, @left-*, @right-* with a block of declarations (CSSOM CSSMarginRule, legacy type 9).
MediaList The CSSOM MediaList of a style sheet, of an @media rule or of an @import rule: the media queries as text (mediaText) and as a list of query strings (length, item()), changed through mediaText, appendMedium() and deleteMedium().
NamespaceRule An @namespace rule: the default namespace or a prefix bound to a namespace URI.
PageRule A @page rule (CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, section 4, W3C Working Draft 14 September 2023; CSSOM CSSPageRule, legacy type 6): a list of page selectors (an optional page type name followed by the page pseudo-classes :left, :right, :first, :blank; an empty selector list matches every page), a block of page descriptors (size, margin, marks, bleed, page-orientation ...) and the page-margin rules inside it (MarginRule).
PageRule.Selector One page selector: an optional page type name and any of the page pseudo-classes.
PositionTryRule A @position-try rule (CSS Anchor Positioning Level 1 section 6.4, https://www.w3.org/TR/css-anchor-position-1/#position-try-rule, W3C Working Draft, Last-Modified 2026-03-27): a named position option, a block of positioning declarations that position-try-fallbacks can apply to an anchor-positioned box when the box overflows.
PropertyRule An @property rule (CSS Properties and Values API Level 1, https://www.w3.org/TR/css-properties-values-api-1/, section 3): the registration of a custom property with a syntax (a string in the value definition syntax of the data types <length>, <number>, <percentage>, <length-percentage>, <color>, <image>, <url>, <integer>, <angle>, <time>, <resolution>, <transform-function>, <transform-list>, <custom-ident>, <string>, keywords, with the combinators |, + and #, or * for anything), whether it inherits and its initial-value (required unless the syntax is *).
ScopeSpec The prelude of an @scope rule (CSS Cascading and Inheritance Level 6, section 2, "Scoping Styles"): @scope (<scope-start>) to (<scope-end>).
StyleRule A style rule: a selector list and a declaration block, for example a:hover, a:focus { color: red }.
StyleSheet A style sheet: its rules in order, its origin (user agent, user or author), the URL it came from (the base of the relative urls inside it), the media queries that decide whether it applies at all, and a title and a disabled flag as the owning <style> or <link> element gives them.
StyleSheetDecoder Decodes the bytes of a style sheet to text, with the encoding detection of CSS Syntax Level 3: a byte order mark wins, then the charset of the Content-Type header, then an @charset "name"; rule at the very start, then the encoding of the referring document or sheet, and finally UTF-8.
SupportsCondition The condition of @supports and of CSS.supports(): (property: value) is true when this engine parses the declaration (a property that is merely parsed-only counts as supported, an unsupported one does not), selector(...)
UaStyleSheet The user agent default style sheet: the rendering defaults the HTML Standard prescribes for HTML elements (which elements are blocks, lists, tables, what is hidden; margins and sizes of headings, lists and tables; colors of links; bold, italic, underline and monospace elements; the look of form controls and fieldsets), with the additions of browsers where the standard is silent.
UnknownRule A rule that the engine keeps without interpreting it: @page, @property, @counter-style, @container and similar at-rules.
XmlStylesheetInstruction The pseudo-attributes of an xml-stylesheet processing instruction (Associating Style Sheets with XML documents 1.0, https://www.w3.org/TR/xml-stylesheet/, W3C Recommendation 2010-10-28), which XHTML documents use to link a style sheet: <?
