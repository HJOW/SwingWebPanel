Class Summary
CssDiagnostics Collects the diagnostics of the CSS engine: dropped declarations, unknown properties, invalid values, unsupported features and so on.

CssEngine The CSS engine of one document, wired together: it installs the selector engine (querySelector and friends), collects the style sheets of the document (<style>, <link rel="stylesheet">, @import) through a StyleSheetLoader, and creates the StyleResolver that computes the styles.
