matches

public boolean matches(java.lang.String pageName,
                       int number,
                       boolean isBlank,
                       boolean isRight)
Tells whether the selector matches a page (all of its components must match). A page type name auto never matches.

선택자가 쪽에 일치하는지 알려 준다(모든 구성 요소가 일치해야 한다). 쪽 이름 auto 는 절대 일치하지 않는다.

Parameters:
pageName - the named page of the page, or null/empty for the unnamed page / 쪽의 이름. 이름 없는 쪽이면 null 이나 빈 문자열
number - the page number counted from 1 / 1 부터 센 쪽 번호
isBlank - true if the page is a blank page that a forced break made / 강제 쪽 나눔이 만든 빈 쪽이면 true
isRight - true for a right page, false for a left page / 오른쪽 쪽이면 true, 왼쪽 쪽이면 false
Returns:
true if it matches / 일치하면 true

getSpecificity

public int getSpecificity()
Returns the specificity packed in an integer: the page type name counts as the highest (a), :first and :blank as the middle (b) and :left and :right as the lowest (c) component (section 4.2 of the specification).

Returns:
the specificity / 구체성
