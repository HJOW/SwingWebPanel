Class AnimationPlaybackEvent

java.lang.Object
  org.duckdns.hjow.swingwebpanel.dom.Event
      org.duckdns.hjow.swingwebpanel.css.anim.AnimationPlaybackEvent

public final class AnimationPlaybackEvent
extends Event

An animation playback event of Web Animations Level 1 (section 6.12, AnimationPlaybackEvent): finish, cancel and remove, fired at a WebAnimation. The event does not bubble and cannot be canceled. Its getCurrentTime() is the current time of the animation when the event was queued and getTimelineTime() the time of its timeline; both are null when unresolved. Scripts create one with new AnimationPlaybackEvent(type, init).

Web Animations Level 1 의 애니메이션 재생 이벤트(6.12 절, AnimationPlaybackEvent): WebAnimation 에 발생하는 finish, cancel, remove. 버블링되지 않고 취소할 수 없다. getCurrentTime() 은 이벤트를 큐에 넣을 때의 애니메이션 현재 시간이고 getTimelineTime() 은 타임라인의 시간이며 결정되지 않았으면 둘 다 null 이다. 스크립트는 new AnimationPlaybackEvent(type, init) 으로 만든다.
