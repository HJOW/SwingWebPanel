Class SupportsCondition

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.cssom.SupportsCondition

public final class SupportsCondition
extends java.lang.Object

The condition of @supports and of CSS.supports(): (property: value) is true when this engine parses the declaration (a property that is merely parsed-only counts as supported, an unsupported one does not), selector(...) when the selector parses, not, and and or combine conditions, and anything else (font-tech(), unknown functions) is false.

@supports 와 CSS.supports() 의 조건: (property: value) 는 이 엔진이 선언을 파싱하면 참(파싱만 하는 속성은 지원으로 치고, 지원하지 않는 속성은 거짓), selector(...) 는 선택자가 파싱되면 참, not, and, or 로 조건을 합치며, 그 밖의 것(font-tech(), 알 수 없는 함수)은 거짓이다.

supports

public static boolean supports(java.lang.String property,
                               java.lang.String value,
                               boolean quirks)
Evaluates a declaration of an @supports condition, optionally in the quirks mode of its style sheet: there the properties of the Quirks Mode Standard accept unitless lengths (CSS Values 4 appendix C: <quirky-length> must be valid when parsing the affected properties in the @supports rule, but not in the method CSS.supports(), which calls supports(String, String)).

@supports 조건의 선언을 평가한다. 스타일 시트가 호환 모드이면 그 모드로 평가하며 호환 모드 표준의 속성은 단위 없는 길이를 받는다(CSS Values 4 부록 C: <quirky-length> 는 @supports 규칙에서는 올바르고 CSS.supports() 메서드에서는 올바르지 않다. 메서드는 supports(String, String) 을 부른다).

Parameters:
property - the property name / 속성 이름
value - the value text / 값 문자열
quirks - true if the style sheet is parsed in quirks mode / 스타일 시트를 호환 모드로 파싱하면 true
Returns:
true if the declaration is valid / 선언이 올바르면 true
