Package org.duckdns.hjow.swingwebpanel.css.cascade

Cascade and style resolution: origins, specificity, computed style, pseudo-element styles and invalidation driven by DOM changes.

See:
          Description

Interface Summary
PresentationalHints The plug-in that turns the presentational attributes of the markup (bgcolor, align, width, border ...)
StatefulPresentationalHints Optional presentational-hint provider that consults dynamic selector state.
StyleAnimator Turns the style that the cascade computed for an element into the style that the element has at the moment (plan item P10-07, CSS Transitions Level 1 and CSS Animations Level 1): the StyleResolver calls it every time it computes the style of an element, before the style is cached and given to the children for inheritance.
StyleChangeListener Receives notifications from a StyleResolver when cached computed styles became stale: after a DOM change, a change of the dynamic element state, new style sheets or a new media environment.
 

Class Summary
ComputedStyle The computed style of one element (or pseudo-element): the result of the cascade and of the computation of values.
FramesetTracks Turns the rows and cols attributes of a frameset (HTML 4.01 section 16.2.1: a comma-separated list of pixel lengths, percentages and relative lengths such as * and 2*) into the track list of a CSS grid: pixels become px tracks, percentages stay percentages and a relative length becomes a flexible fr track that shares what remains.
HtmlPresentationalHints The presentational hints of HTML (the "non-CSS presentational hints" of the HTML Standard and the long-standing browser behaviour for old pages): bgcolor, background, text, margins of body; border, cellpadding, cellspacing, width, height, align, valign, nowrap of tables and cells; align of block elements; width, height, hspace, vspace, border, align of images and objects; color, face, size of font; clear of br; type of lists; align, size, width, noshade of hr; frameborder of frames.
PageStyles The cascade of the page context (CSS Paged Media Level 3, https://www.w3.org/TR/css-page-3/, W3C Working Draft 14 September 2023, section 4.4 "Cascading in the page context" and section 7 "Page Size"): it takes the @page rules of the style sheets and works out the PageStyles.PageBox of one page, that is the size of the page box (size), its margins (margin; a percentage is relative to the page size), the marks and the bleed.
PageStyles.PageBox The computed descriptors of one page: the page box size and the page margins in CSS pixels, the marks, the bleed and the orientation of the output.
StyleResolver The style engine of a document: it finds the rules that match an element, orders their declarations by the cascade (origin and importance, then specificity, then source order), computes the values and caches the ComputedStyle of every element.
