Class SelectorList

java.lang.Object
  org.duckdns.hjow.swingwebpanel.css.selector.SelectorList

public final class SelectorList
extends java.lang.Object

A comma separated list of complex selectors (the prelude of a style rule, or the argument of :is(), :not(), :has()). The list matches an element when any of its selectors does.

쉼표로 구분한 복합 선택자 목록(스타일 규칙의 전문이나 :is(), :not(), :has() 의 인수). 목록의 선택자 중 하나라도 일치하면 요소와 일치한다.
