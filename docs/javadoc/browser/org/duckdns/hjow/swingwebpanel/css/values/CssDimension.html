public final class CssDimension
extends CssValue

A number with a non-length unit: an angle (45deg), a time (200ms), a frequency, a resolution (2dppx) or a flexible length (1fr). The kind is derived from the unit.

길이가 아닌 단위가 붙은 숫자: 각도(45deg), 시간(200ms), 주파수, 해상도(2dppx), 유연한 길이(1fr). 종류는 단위에서 정한다.
