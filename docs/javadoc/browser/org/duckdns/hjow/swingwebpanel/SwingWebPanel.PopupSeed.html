public static final class SwingWebPanel.PopupSeed
extends java.lang.Object

What a component needs to become the window that a page of another component opens (extension, API contract 5.28): it is passed to SwingWebPanel.createPopupPanel(PopupSeed) and from there to the constructor SwingWebPanel.SwingWebPanel(PopupSeed). A seed can be used for one component only.

컴포넌트가 다른 컴포넌트의 페이지가 연 창이 되는 데 필요한 것(확장, API 계약 5.28): SwingWebPanel.createPopupPanel(PopupSeed) 에 넘겨지고 거기서 생성자 SwingWebPanel.SwingWebPanel(PopupSeed) 로 넘긴다. 씨앗 하나는 컴포넌트 하나에만 쓸 수 있다.
