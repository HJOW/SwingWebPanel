org.duckdns.hjow.swingwebpanel.core
Class PageSnapshot

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.PageSnapshot

public final class PageSnapshot
extends java.lang.Object

An immutable snapshot of one confirmed page: its URL, the received source text, MIME type, base URL and kind. The browser session replaces the whole snapshot at once when a navigation is confirmed, so the URL and the content that callers read always belong to the same page. The source text is never overwritten by DOM changes or by conversions such as Markdown to HTML (API contract 5.9). A snapshot may carry a PageDocument with the page's live objects.

확정된 페이지 하나의 불변 스냅샷: URL, 수신한 원문, MIME 타입, 기준 URL, 종류. 이동이 확정되면 브라우저 세션이 스냅샷 전체를 한 번에 교체하므로 호출자가 읽는 URL 과 콘텐츠는 항상 같은 페이지에 속한다. 원문은 DOM 변경이나 Markdown 의 HTML 변환 같은 가공으로 덮어쓰지 않는다(API 계약 5.9). 스냅샷은 페이지의 살아 있는 객체인 PageDocument 를 가질 수 있다.

Returns a copy of this snapshot that remembers the form submission that made the page. A history move then shows the stored source instead of sending the form again, and a refresh sends it again only after the user agreed.
