org.duckdns.hjow.swingwebpanel.core
Class PageSelection

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.PageSelection

public final class PageSelection
extends java.lang.Object

The selection of the text of the page by the user (plan item P11-08): the mouse gestures that select (drag, double click for a word, triple click for a paragraph, a drag that goes on from those, Shift+click), Select All, the copy of the selection, and the highlight that the page shows. The model is the Selection of the DOM document, the same one that window.getSelection() gives to scripts, so a script sees what the user selected and the highlight shows what a script selected with addRange. All work on the DOM (and the TextSelections geometry of the rendered page) happens on the document queue; the event dispatch thread only paints the immutable SelectionHighlight that the document thread published, and writes to the clipboard.

Every change of the selection (whoever makes it) fires selectionchange at the document once per burst of changes, as a task of the document queue, and rebuilds the highlight; a new layout of the page rebuilds the highlight as well.

사용자의 페이지 텍스트 선택(계획 P11-08): 선택하는 마우스 동작(드래그, 더블 클릭의 낱말, 트리플 클릭의 문단, 그 뒤에 이어지는 드래그, Shift+클릭), 전체 선택, 선택의 복사, 페이지가 보여 주는 강조. 모델은 DOM 문서의 Selection 이며 window.getSelection() 이 스크립트에 주는 것과 같다. 그래서 스크립트는 사용자가 선택한 것을 보고, 강조는 스크립트가 addRange 로 선택한 것을 보여 준다. DOM(과 렌더링된 페이지의 TextSelections 기하)에 대한 모든 일은 문서 큐에서 일어나고, 이벤트 디스패치 스레드는 문서 스레드가 게시한 불변 SelectionHighlight 를 그리고 클립보드에 쓰기만 한다.

선택이 바뀔 때마다(누가 바꾸든) 문서에 selectionchange 를 변경 묶음마다 한 번 문서 큐의 작업으로 보내고 강조를 다시 만든다. 페이지의 새 레이아웃도 강조를 다시 만든다.

extendByKey

public boolean extendByKey(PageSnapshot snapshot,
                           java.lang.String key,
                           boolean byWord)
Extends the selection with a key (Shift+arrow keys, Shift+Home, Shift+End; document queue): the focus of the selection moves one character (or one word with Ctrl) to the left or right, one line up or down, or to the start or the end of the line, while the anchor stays. Nothing happens if the page has no selection (a click makes a collapsed one) or if the focus cannot be located.

키로 선택을 확장한다(Shift+화살표, Shift+Home, Shift+End. 문서 큐): 선택의 focus 가 anchor 는 그대로인 채 왼쪽이나 오른쪽으로 글자 하나(Ctrl 이면 낱말 하나), 위나 아래로 한 줄, 줄의 처음이나 끝으로 움직인다. 페이지에 선택이 없거나(클릭하면 접힌 선택이 생긴다) focus 의 위치를 찾을 수 없으면 아무 일도 없다.

Parameters:

copy

public boolean copy(PageSnapshot snapshot)
Copies the selection (document queue): fires the cancelable copy event at the focused element (the body if none has the focus) with the selected text (text/plain) and markup (text/html) in its clipboardData; if no listener cancelled it, the selection goes to the clipboard, otherwise what the listener put into clipboardData does. Nothing is written when there is nothing to copy.

선택을 복사한다(문서 큐): 취소할 수 있는 copy 이벤트를 포커스를 가진 요소(없으면 body)에 선택한 텍스트(text/plain)와 마크업(text/html)을 clipboardData 에 담아 보낸다. 리스너가 취소하지 않았으면 선택이, 취소했으면 리스너가 clipboardData 에 넣은 것이 클립보드로 간다. 복사할 것이 없으면 아무것도 쓰지 않는다.

Parameters:
snapshot - the page / 페이지
Returns:
true if data was written (handed to the clipboard sink) / 데이터를 썼으면(클립보드 쪽에 넘겼으면) true
