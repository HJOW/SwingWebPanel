Class BrowserSession

FormSubmitSink
public final class BrowserSession
extends java.lang.Object
implements FormSubmitSink

All state of one browser component: user agent, extra headers, JavaScript flag, the confirmed page, history, status text and progress. It is the heart of the behavior described in docs/API_CONTRACT.md; SwingWebPanel is only a thin Swing wrapper around it. Every method may be called from any thread. Navigation is asynchronous: a request number is taken, a PageLoader runs on the component's document thread, and the result is committed only if its number is still the current one. The confirmed page (URL, source, history position) is replaced in one step, so readers never see a half-updated state. Observers are told on the event dispatch thread.

브라우저 컴포넌트 하나의 모든 상태: User-Agent, 추가 헤더, JavaScript 설정, 확정된 페이지, 이력, 상태 메시지, 진행률. docs/API_CONTRACT.md 에 적힌 동작의 핵심이며 SwingWebPanel 은 이것을 감싼 얇은 Swing 껍데기이다. 모든 메서드는 어느 스레드에서나 호출할 수 있다. 이동은 비동기이다: 요청 번호를 받고, PageLoader 가 컴포넌트의 문서 스레드에서 실행되며, 결과의 번호가 여전히 현재일 때만 확정한다. 확정된 페이지(URL, 원문, 이력 위치)는 한 번에 교체되므로 읽는 쪽이 반쯤 바뀐 상태를 볼 수 없다. 관찰자에게는 이벤트 디스패치 스레드에서 알린다.

startAsOpenedWindow

public void startAsOpenedWindow(BrowserSession from,
                                OpenRequest request,
                                boolean related)
Makes this new session the window that a page opened (plan item P31-08): the window counts as created by web content, takes over the settings of the window that opened it, and gets its scriptable first about:blank document at once. A related window also gets the opener, the group and a copy of the session storage. Then the requested address is loaded. It is called by the opening session right after the component of the new window was created.

이 새 세션을 페이지가 연 창으로 만든다(계획 P31-08): 창은 웹 콘텐츠가 만든 것으로 치고, 자신을 연 창의 설정을 이어받으며, 스크립트를 실행할 수 있는 처음 about:blank 문서를 곧바로 가진다. 관계가 있는 창은 opener, 그룹, sessionStorage 의 복사본도 받는다. 그 뒤 요청한 주소를 읽는다. 새 창의 컴포넌트를 만든 직후에 여는 세션이 부른다.

Parameters:
from - the session that opened the window / 창을 연 세션
request - what was asked for / 요청한 것
related - true if the window keeps a connection to its opener / 창이 여는 창과 관계를 유지하면 true
