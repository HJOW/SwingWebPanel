Class Summary
BrowserSession All state of one browser component: user agent, extra headers, JavaScript flag, the confirmed page, history, status text and progress.
ConsoleDispatcher Registry and dispatcher of the host's console listeners (API contract 5.20).
ControlOverlays The Swing components that the page puts over its form controls and the dialogs that the controls need: the editor over the text field or text area that has the focus (ControlEditor), the bubble that shows a validation message next to a control, and the file chooser of a file upload control.
DefaultPageLoader The loader used until the real network/content/rendering pipeline is connected (plan stages P04 to P09).
DocumentLoop The document thread of one or more components: a single thread that runs their document tasks (page confirmation, script tasks, layout) one after the other.
FontDefaults The default fonts of one component (API contract 5.27): the family for content whose author named no font, the families behind the generic names serif, sans-serif and monospace, the size of font-size: medium, and the size of the monospace elements.
HtmlPageDocument The live document of a page: the DOM tree that the HTML parser built from the page source (plan items P07, P15-01).
HyperlinkDispatcher Registry and dispatcher of the host's hyperlink listeners.
NavigationRequest Everything a PageLoader needs to load one page: what to load, the settings that were in effect when the navigation started (user agent, extra headers, JavaScript flag, forced reload) and the means to report progress and to notice cancellation.
NetworkPageLoader The page loader of the component: it connects the navigation machinery to the network layer.
OpenRequest What a page asked for when it needs a new window (plan item P31-08): a call of window.open, a link or form whose target names no existing browsing context, or a link that the user chose to open elsewhere (Ctrl, Shift or the middle button).
PageComposition Text input by an input method into an editing host of the page (plan item P20-06), for languages that assemble characters before they are final, such as Korean (Hangul letters become a syllable) and Japanese.
PageDragDrop HTML drag and drop of the page (plan item P20-06, HTML Standard 6.11): the user presses the main mouse button on a draggable element (an element with draggable="true", an image or a link) or on the selected text, moves the pointer, and releases it over another place of the same page.
PageEditing Editing by the user in the rendered page (plan item P20-06): what the keys do inside an editing host (an element with contenteditable, or a document in design mode).
PageInput Basic pointer/link input for the rendered component.
PageKeyboard Keyboard and focus input of the rendered component (plan items P11-01 and P11-02): AWT key events become DOM keydown, keypress and keyup events for the element that has the focus (the body if none has it), a key that is not cancelled does what the browser does (Tab moves the focus along the tab order and leaves the component after the last element, Enter follows a link or presses a button, Space releases a button), and the focus of the component itself is passed on to the document so that its focused element gets focus and blur.
PageSelection The selection of the text of the page by the user (plan item P11-08): the mouse gestures that select (drag, double click for a word, triple click for a paragraph, a drag that goes on from those, Shift+click), Select All, the copy of the selection, and the highlight that the page shows.
PageSnapshot An immutable snapshot of one confirmed page: its URL, the received source text, MIME type, base URL and kind.
PageView Connects a session's DOM/CSS/layout to Swing.
PageZoom The rules of the page zoom (plan item P11-08): the allowed range of the zoom factor and the steps that the keyboard and the wheel go through.
ParsingPageLoader A page loader that completes the snapshots of another loader with a DOM tree (plan items P07, P17-02, P17-04): text/html source is parsed by the HTML parser, text/markdown is converted to HTML first and then parsed, and text/plain becomes a document with one pre element.
PostData The request body of a form submission that made a page (POST), kept with the page so that the page can be shown again without sending the form a second time (history moves use the stored source) and sent again only after the user agreed (refresh).
Version Build-time constants that identify the SwingWebPanel library.
ViewMetrics Size information that the layout engine reports to the component so that it can behave as a Scrollable view: the minimum width the laid-out content needs, the height of the content and the scroll step.
WebMessageDispatcher Owns the component's bounded page-to-Java message queue and EDT listener registry.
