org.duckdns.hjow.swingwebpanel.core
Interface PageLoader

All Known Implementing Classes:
DefaultPageLoader, NetworkPageLoader, ParsingPageLoader
public interface PageLoader

Strategy that turns a NavigationRequest into a confirmed PageSnapshot. It runs on the component's document thread, never on the EDT. An implementation must poll NavigationRequest.getCancelToken() during long work, close every stream on every path and report failures as an error page snapshot rather than by throwing, except for cancellation which is signalled by CancelledException. Later stages of the project replace the default loader with the real network, content and rendering pipeline.

NavigationRequest 를 확정된 PageSnapshot 으로 바꾸는 전략. 컴포넌트의 문서 스레드에서 실행되며 EDT 에서는 실행되지 않는다. 구현은 긴 작업 중 NavigationRequest.getCancelToken() 을 확인하고, 모든 경로에서 스트림을 닫으며, 실패는 던지지 않고 오류 페이지 스냅샷으로 보고해야 한다. 취소만은 CancelledException 으로 알린다. 프로젝트 후반 단계에서 기본 로더를 실제 네트워크, 콘텐츠, 렌더링 파이프라인으로 교체한다.
