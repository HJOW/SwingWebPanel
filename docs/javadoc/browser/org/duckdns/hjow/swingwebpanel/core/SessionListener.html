org.duckdns.hjow.swingwebpanel.core
Interface SessionListener

public interface SessionListener

Observer of the state of a BrowserSession. The session calls every method on the Swing event dispatch thread, in the order in which the changes happened, and only when the value really changed.

BrowserSession 의 상태를 관찰하는 객체. 세션은 모든 메서드를 Swing 이벤트 디스패치 스레드에서, 변경이 일어난 순서대로, 값이 실제로 달라졌을 때만 호출한다.

fragmentChanged

void fragmentChanged(java.lang.String oldUrl,
                     PageSnapshot snapshot,
                     double[] target)
A navigation inside the confirmed page changed only the fragment of its URL (the page and its document stay). The listener scrolls to the target if there is one; it is called on the EDT after the URL has changed.

확정된 페이지 안의 이동이 URL의 프래그먼트만 바꾸었다(페이지와 문서는 그대로). 리스너는 대상이 있으면 그곳으로 스크롤한다. URL이 바뀐 뒤에 EDT 에서 호출된다.

Parameters:
oldUrl - previous URL / 이전 URL
snapshot - the page, whose URL is the new one / 새 URL을 가진 페이지
target - border box of the target in document coordinates as x, y, width, height, or null / 대상의 border box(문서 좌표, x·y·폭·높이). 없으면 null

scrollRequested

void scrollRequested(double x,
                     double y)
A script asked to scroll the viewport (window.scrollTo, scrollBy, Element.scrollIntoView); it is called on the EDT. The listener scrolls so that the point is at the top left of the viewport, clamped to the content, if the component sits in a viewport.

스크립트가 뷰포트를 스크롤하라고 요청했다(window.scrollTo, scrollBy, Element.scrollIntoView). EDT 에서 호출된다. 컴포넌트가 뷰포트 안에 있으면 리스너가 그 점이 뷰포트 왼쪽 위에 오도록 내용 범위 안에서 스크롤한다.

Parameters:
x - the x in document pixels / 문서 픽셀의 x
y - the y in document pixels / 문서 픽셀의 y
