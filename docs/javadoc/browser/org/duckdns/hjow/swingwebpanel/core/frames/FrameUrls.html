org.duckdns.hjow.swingwebpanel.core.frames
Class FrameUrls

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.frames.FrameUrls

public final class FrameUrls
extends java.lang.Object

The address rules of iframe attributes (HTML5 REC 2014-10-28 4.7.2 "process the iframe attributes"): an empty or unresolvable src means about:blank, and an address that an ancestor browsing context already shows (ignoring the fragment) must not be loaded again, which stops pages that embed themselves.

iframe 속성의 주소 규칙(HTML5 REC 2014-10-28 4.7.2 "process the iframe attributes"): 비어 있거나 해석할 수 없는 src 는 about:blank 이고, 조상 브라우징 문맥이 이미 보여 주는 주소(프래그먼트 제외)는 다시 로드하지 않는다. 자기 자신을 임베드하는 페이지를 막는다.

resolveSrc

public static java.lang.String resolveSrc(java.lang.String base,
                                          java.lang.String src)
Resolves the src attribute against the base URL of the document of the frame element: a missing or empty value, a base that cannot resolve it (for example an about: document) or a malformed value give ABOUT_BLANK.

src 속성을 프레임 요소가 속한 문서의 기준 URL 로 해석한다. 없거나 빈 값, 해석할 수 없는 기준(예: about: 문서), 잘못된 값이면 ABOUT_BLANK 이다.

Parameters:
base - the base URL of the document / 문서의 기준 URL
src - the attribute value or null / 속성 값 또는 null
Returns:
the absolute address / 절대 주소

isLoop

public static boolean isLoop(java.lang.String url,
                             java.util.List<java.lang.String> ancestors)
Tells whether an ancestor shows the address (ignoring fragments): then the navigation of the frame is cancelled. The special addresses about:blank and about:srcdoc never count as a loop.

조상이 그 주소(프래그먼트 제외)를 보여 주는지 알려 준다. 그러면 프레임 이동은 취소된다. 특수 주소 about:blank 와 about:srcdoc 는 순환으로 세지 않는다.

Parameters:
url - the address that the frame would load / 프레임이 로드할 주소
ancestors - the addresses of the active documents of all ancestors, nearest first / 모든 조상의 활성 문서 주소(가까운 것부터)
Returns:
true if it is a loop / 순환이면 true
