org.duckdns.hjow.swingwebpanel.core
Class PageDragDrop

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.PageDragDrop

public final class PageDragDrop
extends java.lang.Object

HTML drag and drop of the page (plan item P20-06, HTML Standard 6.11): the user presses the main mouse button on a draggable element (an element with draggable="true", an image or a link) or on the selected text, moves the pointer, and releases it over another place of the same page. The drag begins when the pointer has moved a few pixels from the press; the component then fires dragstart at the source, and on every pointer move (and every 350 milliseconds while it stands still) drag at the source, dragenter, dragover and dragleave at the elements under the pointer, following the processing model of the specification (a cancelled dragenter or dragover accepts the element, the dropEffect and the effectAllowed choose the drag operation, a text field or an editing host accepts text without any script). At the release it fires drop at the current target (a text control or an editing host gets the dragged text as its default action, and a drag that moves a selection out of an editing host deletes it), then dragend at the source. Escape cancels the drag. The mouse and key events are suppressed while the drag runs. Every DragEvent gets its own DataTransfer on top of the drag data store, in the mode that the specification gives that event, and it is disabled when the event is over.

Limits: the drag is simulated inside the component (it does not start a drag of the operating system, so text cannot be dragged to another application, and nothing is dropped from outside), files are not dragged, the picture of setDragImage is not drawn (the mouse cursor shows the operation), and the events go to the document under the pointer (frames included) without a drag across two frames being treated specially.

페이지의 HTML 끌어다 놓기(계획 P20-06, HTML 표준 6.11): 사용자가 끌 수 있는 요소(draggable="true" 요소, 이미지, 링크)나 선택한 텍스트 위에서 주 마우스 버튼을 누르고, 포인터를 옮기고, 같은 페이지의 다른 곳에서 뗀다. 포인터가 누른 곳에서 몇 픽셀 움직이면 끌기가 시작하고, 컴포넌트는 원본에 dragstart 를 보낸 뒤 포인터가 움직일 때마다(서 있는 동안은 350 밀리초마다) 원본에 drag, 포인터 아래 요소에 dragenter, dragover, dragleave 를 규격의 처리 모델대로 보낸다(dragenter 나 dragover 를 취소하면 그 요소가 받아들이는 것이고, dropEffect 와 effectAllowed 가 끌기 동작을 정하며, 텍스트 필드와 편집 호스트는 스크립트 없이도 텍스트를 받는다). 뗄 때 현재 대상에 drop 을 보내고(텍스트 컨트롤이나 편집 호스트는 기본 동작으로 끌어온 텍스트를 받고, 편집 호스트에서 선택을 옮기는 끌기는 그것을 지운다) 원본에 dragend 를 보낸다. Esc 는 끌기를 취소한다. 끌기가 도는 동안 마우스와 키 이벤트는 막는다. 모든 DragEvent 는 드래그 데이터 저장소 위에 자기 DataTransfer 를 가지며 그 이벤트에 규격이 정한 모드이고 이벤트가 끝나면 무효화된다.

한계: 끌기는 컴포넌트 안에서 흉내 낸다(운영체제의 끌기를 시작하지 않으므로 다른 응용 프로그램으로 텍스트를 끌 수 없고 바깥에서 놓는 것도 없다). 파일은 끌지 않는다. setDragImage 의 그림은 그리지 않는다(마우스 커서가 동작을 보인다). 이벤트는 포인터 아래 문서(프레임 포함)로 가며 두 프레임에 걸친 끌기를 따로 다루지 않는다.
