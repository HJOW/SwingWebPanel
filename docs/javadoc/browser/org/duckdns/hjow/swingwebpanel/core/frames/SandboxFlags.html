org.duckdns.hjow.swingwebpanel.core.frames
Class SandboxFlags

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.frames.SandboxFlags

public final class SandboxFlags
extends java.lang.Object

The sandboxing flags of a browsing context, parsed from the sandbox attribute of an iframe (HTML5 REC 2014-10-28 4.7.2). An absent attribute gives NONE: nothing is restricted. A present attribute restricts scripts, forms, popups, navigation of the top-level context and gives the document a unique origin, except for the allow-* tokens that it lists. The flags of nested frames accumulate: a restriction of an ancestor cannot be lifted by a descendant (see inherit(SandboxFlags)). Instances are immutable.

브라우징 문맥의 샌드박스 플래그. iframe 의 sandbox 속성에서 해석한다(HTML5 REC 2014-10-28 4.7.2). 속성이 없으면 NONE: 아무것도 제한하지 않는다. 속성이 있으면 나열한 allow-* 토큰을 뺀 스크립트, 폼, 팝업, 최상위 문맥 이동을 제한하고 문서에 유일한 오리진을 준다. 중첩된 프레임의 플래그는 누적된다: 조상의 제한을 자손이 풀 수 없다(inherit(SandboxFlags) 참조). 인스턴스는 불변이다.

parse

public static SandboxFlags parse(java.lang.String attribute)
Parses the value of a sandbox attribute: space-separated tokens, compared ASCII case-insensitively; unknown tokens are ignored. A null value (no attribute) gives NONE.

sandbox 속성 값을 해석한다: 공백으로 구분한 토큰이며 ASCII 대소문자를 구분하지 않고 비교한다. 모르는 토큰은 무시한다. null(속성 없음)이면 NONE.
