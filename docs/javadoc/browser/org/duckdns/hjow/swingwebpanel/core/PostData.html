org.duckdns.hjow.swingwebpanel.core
Class PostData

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.PostData

public final class PostData
extends java.lang.Object

The request body of a form submission that made a page (POST), kept with the page so that the page can be shown again without sending the form a second time (history moves use the stored source) and sent again only after the user agreed (refresh). A body larger than MAX_RETAINED_BYTES is not kept; such a page can be shown again from its stored source but never be sent again. Instances are immutable.

페이지를 만든 폼 제출(POST)의 요청 본문. 페이지와 함께 보관하여, 폼을 다시 보내지 않고 페이지를 다시 보여 주고(이력 이동은 저장한 원문을 쓴다) 사용자가 동의한 뒤에만 다시 보낼 수 있게 한다(새로고침). MAX_RETAINED_BYTES 보다 큰 본문은 보관하지 않으며, 그런 페이지는 저장한 원문으로 다시 보여 줄 수는 있어도 다시 보낼 수는 없다. 인스턴스는 불변이다.

Field Detail

MAX_RETAINED_BYTES

public static final int MAX_RETAINED_BYTES
The largest body that is kept for sending the form again: 4 MiB. A bigger body (for example an upload of a large file) is dropped once it was sent, so that a history of many submissions does not hold large uploads in memory.

폼을 다시 보내려고 보관하는 가장 큰 본문: 4 MiB. 더 큰 본문(예: 큰 파일 업로드)은 한 번 보낸 뒤 버리므로, 제출이 많은 이력이 큰 업로드를 메모리에 붙잡지 않는다.
