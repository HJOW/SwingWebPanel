Text input by an input method into an editing host of the page (plan item P20-06), for languages that assemble characters before they are final, such as Korean (Hangul letters become a syllable) and Japanese. The component registers it as its input method listener. An InputMethodEvent carries the text that the input method has committed and the text that it still composes; this class passes both to the editing engine (PageEditing.compose(org.duckdns.hjow.swingwebpanel.core.PageSnapshot, org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.dom.Element, java.lang.String, java.lang.String)), which shows the composed text in the DOM and sends the composition events and the insertCompositionText input events. It also answers the questions of the input method about where the text is (the caret of the page), so that the window of the candidates opens next to the caret. When no editing host has the focus, the component switches the input methods off, so this listener is not called. Form controls have their own Swing editors with their own composition. The listener runs on the event dispatch thread; the work goes to the document queue.

입력기가 페이지의 편집 호스트에 하는 텍스트 입력(계획 P20-06). 글자를 확정하기 전에 조립하는 언어(한글은 음절로 조립되고, 일본어 등)를 위한 것이다. 컴포넌트가 이것을 입력기 리스너로 등록한다. InputMethodEvent 는 입력기가 확정한 텍스트와 아직 조합 중인 텍스트를 나르며, 이 클래스는 둘을 편집 엔진 (PageEditing.compose(org.duckdns.hjow.swingwebpanel.core.PageSnapshot, org.duckdns.hjow.swingwebpanel.dom.Document, org.duckdns.hjow.swingwebpanel.dom.Element, java.lang.String, java.lang.String))에 넘긴다. 엔진은 조합 중인 텍스트를 DOM 에 보이고 조합 이벤트와 insertCompositionText 입력 이벤트를 보낸다. 또 텍스트가 어디 있는지에 대한 입력기의 질문(페이지의 캐럿)에 답해, 후보 창이 캐럿 옆에 열리게 한다. 편집 호스트가 포커스를 가지지 않으면 컴포넌트가 입력기를 끄므로 이 리스너는 불리지 않는다. 폼 컨트롤은 자기 조합을 가진 자기 Swing 편집기가 있다. 리스너는 이벤트 디스패치 스레드에서 실행되며 일은 문서 큐로 간다.
