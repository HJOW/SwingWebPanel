public final class DownloadRequiredException
extends java.lang.Exception

Thrown by a PageLoader when the response of a main document navigation must be downloaded as a file instead of being shown (API contract section 7): the server marked it as an attachment, or its type is not a displayable document. The page, the URL, the history and the progress of the component stay unchanged. The session passes the exception to its DownloadHandler.

주 문서 이동의 응답을 보여 주는 대신 파일로 내려받아야 할 때 PageLoader 가 던진다(API 계약 7절): 서버가 첨부 파일로 표시했거나 표시할 수 있는 문서 형식이 아닌 경우이다. 컴포넌트의 페이지, URL, 이력, 진행률은 바뀌지 않는다. 세션은 이 예외를 DownloadHandler 에 넘긴다.
