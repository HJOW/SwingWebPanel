org.duckdns.hjow.swingwebpanel.core
Class PageView

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.PageView

public final class PageView
extends java.lang.Object

Connects a session's DOM/CSS/layout to Swing. DOM reads and rebuilding run on the session's document thread; only immutable drawing commands and dimensions cross to the EDT. Page identity is checked again before painting or delivering a callback. Viewport and DOM changes are coalesced, and equal viewport sizes do not schedule another layout (P09-07).

세션의 DOM·CSS·배치를 Swing에 연결한다. DOM 접근과 재배치는 문서 스레드에서, 불변 그림 명령과 크기의 게시 및 그리기는 EDT에서 처리한다. 그리기와 통지 전에도 페이지 동일성을 확인한다. 뷰포트·DOM 변경은 합치며 같은 뷰포트 크기는 재배치를 예약하지 않는다.

setZoom

public void setZoom(double factor)
Sets the page zoom factor. The layout works in CSS pixels, so the CSS viewport (extent divided by the factor) and the scroll position in CSS pixels are computed again, and a layout is scheduled if the viewport changed; painting, hit testing and the scroll size use the factor from now on. Call it on the event dispatch thread.

페이지 확대 배율을 정한다. 레이아웃은 CSS 픽셀로 일하므로 CSS 뷰포트(크기를 배율로 나눈 값)와 CSS 픽셀 스크롤 위치를 다시 계산하고, 뷰포트가 바뀌었으면 재배치를 예약한다. 그리기, 좌표 조회, 스크롤 크기는 이제부터 배율을 쓴다. 이벤트 디스패치 스레드에서 호출한다.

Parameters:
factor - the factor, a finite positive number / 배율. 유한한 양수
Throws:
java.lang.IllegalArgumentException - for NaN, infinite or not positive numbers / NaN, 무한, 양수가 아닌 수일 때
