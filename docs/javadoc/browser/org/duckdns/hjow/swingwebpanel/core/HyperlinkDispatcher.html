org.duckdns.hjow.swingwebpanel.core
Class HyperlinkDispatcher

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.HyperlinkDispatcher

public final class HyperlinkDispatcher
extends java.lang.Object

Registry and dispatcher of the host's hyperlink listeners. Registration follows the usual Swing behavior: the same listener added twice is notified twice, and a removal removes one registration. Notification always happens on the event dispatch thread. The browser's own link navigation does not go through this class, so removing all listeners never disables link following (API contract 5.12).

호스트의 하이퍼링크 리스너 등록부이자 통지기. 등록은 일반적인 Swing 동작을 따른다: 같은 리스너를 두 번 등록하면 두 번 통지하고, 제거는 등록 하나를 제거한다. 통지는 항상 이벤트 디스패치 스레드에서 한다. 브라우저 자체의 링크 이동은 이 클래스를 거치지 않으므로 모든 리스너를 제거해도 링크 이동은 멈추지 않는다(API 계약 5.12).
