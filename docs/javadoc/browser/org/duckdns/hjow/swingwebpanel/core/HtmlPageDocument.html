Class HtmlPageDocument

PageDocument
public final class HtmlPageDocument
extends java.lang.Object
implements PageDocument

The live document of a page: the DOM tree that the HTML parser built from the page source (plan items P07, P15-01). It is attached to a PageSnapshot and released with it; the received source text in the snapshot is never replaced by a serialization of this tree. Before confirmation the loader owns the tree; afterwards only the component's document queue may change it.

페이지의 살아 있는 문서: HTML 파서가 페이지 원문으로 만든 DOM 트리(계획 P07, P15-01). PageSnapshot 에 붙으며 스냅샷과 함께 해제된다. 스냅샷의 수신 원문은 이 트리의 직렬화로 바뀌지 않는다. 확정 전에는 로더가 트리를 소유하며 이후에는 컴포넌트의 문서 큐에서만 바꾼다.
