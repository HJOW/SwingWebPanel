Editing by the user in the rendered page (plan item P20-06): what the keys do inside an editing host (an element with contenteditable, or a document in design mode). Typed characters, Enter, Shift+Enter, Backspace, Delete (with Ctrl: by word), the shortcuts Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z, Ctrl+A, Ctrl+X and Ctrl+V, and the caret keys (arrows, Home and End, with Ctrl by word or to the edge of the host) become operations of the Editor of the document. The editor does the work on the DOM and sends beforeinput and input; this class only decides what a key means, joins the editor with the layout (the blocks and the preserved white space come from the computed style, the caret moves along the lines of the page) and with the clipboard (cut and paste events). All work happens on the document queue; the clipboard is read on the event dispatch thread before the paste is queued.

렌더링된 페이지에서 사용자의 편집(계획 P20-06): 편집 호스트(contenteditable 요소나 디자인 모드 문서) 안에서 키가 하는 일. 입력한 글자, Enter, Shift+Enter, Backspace, Delete(Ctrl 이면 낱말 단위), 단축키 Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z, Ctrl+A, Ctrl+X, Ctrl+V, 캐럿 키(화살표, Home, End. Ctrl 이면 낱말 단위나 호스트의 가장자리)가 문서의 Editor 의 작업이 된다. 편집기가 DOM 을 바꾸고 beforeinput 과 input 을 보낸다. 이 클래스는 키의 뜻을 정하고, 편집기를 레이아웃(블록과 보존되는 공백은 계산 스타일에서, 캐럿은 페이지의 줄을 따라 움직인다)과 클립보드(cut, paste 이벤트)에 잇는다. 모든 일은 문서 큐에서 일어나며, 클립보드는 붙여넣기를 큐에 넣기 전에 이벤트 디스패치 스레드에서 읽는다.
