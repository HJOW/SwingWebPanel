The page loader of the component: it connects the navigation machinery to the network layer. Addresses of the kinds http, https, ftp and classpath are fetched with the component's user agent, extra headers and cookies through a ResourceFetcher; the result becomes a PageSnapshot that keeps the received source text unchanged. Failures become error pages (server errors keep the server's own body), responses that must be saved as files are reported with DownloadRequiredException, and images, audio and video addresses are wrapped into a tiny generated document (as desktop browsers do). about:blank, about:text and addresses with forbidden schemes are answered by the DefaultPageLoader without any connection.

컴포넌트의 페이지 로더: 이동 장치를 네트워크 계층에 연결한다. http, https, ftp, classpath 주소는 컴포넌트의 User-Agent, 추가 헤더, 쿠키로 ResourceFetcher 를 통해 가져오며, 결과는 수신 원문을 그대로 보관하는 PageSnapshot 이 된다. 실패는 오류 페이지가 되고 (서버 오류는 서버 자신의 본문을 유지), 파일로 저장해야 하는 응답은 DownloadRequiredException 으로 알리며, 이미지/오디오/비디오 주소는 (데스크톱 브라우저처럼) 작은 생성 문서로 감싼다. about:blank, about:text, 금지된 스킴의 주소는 연결 없이 DefaultPageLoader 가 처리한다.
