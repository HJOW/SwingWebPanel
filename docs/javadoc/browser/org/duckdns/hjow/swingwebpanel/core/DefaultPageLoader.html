The loader used until the real network/content/rendering pipeline is connected (plan stages P04 to P09). It honestly handles what it can: about:blank becomes the empty page and about:text keeps the given source unchanged. Addresses that need the network get a clearly marked error page that says loading is not implemented yet (never a fake success), and addresses with a forbidden scheme get the "unsupported address" error page without any connection being made (API contract 5.2).

실제 네트워크/콘텐츠/렌더링 파이프라인이 연결되기 전(계획 P04~P09 단계)까지 쓰는 로더. 할 수 있는 것은 정직하게 처리한다: about:blank 는 빈 페이지가 되고 about:text 는 받은 원문을 그대로 보관한다. 네트워크가 필요한 주소에는 아직 구현되지 않았다고 분명히 표시한 오류 페이지를 주며(거짓 성공 금지), 금지된 스킴의 주소에는 연결 없이 "지원하지 않는 주소" 오류 페이지를 준다(API 계약 5.2).
