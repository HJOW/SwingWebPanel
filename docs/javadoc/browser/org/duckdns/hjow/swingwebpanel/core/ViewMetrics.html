org.duckdns.hjow.swingwebpanel.core
Class ViewMetrics

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.ViewMetrics

public final class ViewMetrics
extends java.lang.Object

Size information that the layout engine reports to the component so that it can behave as a Scrollable view: the minimum width the laid-out content needs, the height of the content and the scroll step. The values are volatile, so the layout thread may write them and the event dispatch thread may read them. Until a layout engine exists they stay at their defaults (an empty page).

컴포넌트가 Scrollable 뷰로 동작할 수 있도록 레이아웃 엔진이 알려 주는 크기 정보: 배치된 콘텐츠가 필요로 하는 최소 폭, 콘텐츠 높이, 스크롤 단위. 값은 volatile 이라 레이아웃 스레드가 쓰고 이벤트 디스패치 스레드가 읽을 수 있다. 레이아웃 엔진이 생기기 전에는 기본값(빈 페이지)을 유지한다.
