org.duckdns.hjow.swingwebpanel.core
Class OpenRequest

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.OpenRequest

public final class OpenRequest
extends java.lang.Object

What a page asked for when it needs a new window (plan item P31-08): a call of window.open, a link or form whose target names no existing browsing context, or a link that the user chose to open elsewhere (Ctrl, Shift or the middle button). The session builds the request and gives it to the WindowOpener of its component, which decides whether and where the window appears.

페이지가 새 창을 필요로 할 때 요청한 것(계획 P31-08): window.open 호출, 대상이 기존 브라우징 문맥을 가리키지 않는 링크나 폼, 사용자가 다른 곳에서 열기로 고른 링크(Ctrl, Shift, 가운데 단추). 세션이 요청을 만들어 컴포넌트의 WindowOpener 에 주고, 그것이 창을 보일지와 어디에 보일지를 정한다.
