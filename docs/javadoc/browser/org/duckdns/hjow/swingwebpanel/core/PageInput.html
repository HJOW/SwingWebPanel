extends java.awt.event.MouseAdapter
implements java.awt.event.MouseMotionListener, java.awt.event.MouseWheelListener

Basic pointer/link input for the rendered component. Component coordinates already include JScrollPane's view translation. Hit testing and DOM click dispatch run on the document queue; Swing link notifications and default navigation run on the EDT. User notifications are separate from internal navigation, so removing listeners never disables links (P09-08-a/P11-03/04).

렌더링 컴포넌트의 기본 포인터·링크 입력. 컴포넌트 좌표에는 이미 JScrollPane의 뷰 이동이 반영된다. 좌표 조회·DOM click은 문서 큐, Swing 링크 통지·기본 이동은 EDT에서 처리한다. 사용자 통지와 내부 이동을 분리하므로 리스너를 모두 제거해도 링크는 작동한다.
