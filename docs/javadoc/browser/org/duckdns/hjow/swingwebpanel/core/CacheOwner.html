Interface CacheOwner

All Known Implementing Classes:
NetworkPageLoader, ParsingPageLoader
public interface CacheOwner

Implemented by a PageLoader that keeps caches for its component (the HTTP cache of the network loader, later also caches of decoded resources). BrowserSession.clean() and BrowserSession.dispose() call clearCache() so that "clean" really removes every cache of the component (plan items P01-15, P19-05, P21-02).

컴포넌트를 위해 캐시를 가진 PageLoader 가 구현한다(네트워크 로더의 HTTP 캐시, 이후 디코딩된 리소스의 캐시). BrowserSession.clean() 과 BrowserSession.dispose() 가 clearCache() 를 호출하므로 "clean" 이 컴포넌트의 모든 캐시를 실제로 지운다(계획 P01-15, P19-05, P21-02).
