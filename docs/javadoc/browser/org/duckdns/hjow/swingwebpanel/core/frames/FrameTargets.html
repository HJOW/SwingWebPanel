org.duckdns.hjow.swingwebpanel.core.frames
Class FrameTargets

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.frames.FrameTargets

public final class FrameTargets
extends java.lang.Object

Classifies the name that selects a browsing context in target attributes and window.open: the keywords _self, _parent, _top and _blank (ASCII case-insensitive) and plain names (HTML5 REC 2014-10-28 5.1 "rules for choosing a browsing context"). Which context is chosen for a name is decided by the frame tree, not here.

target 속성과 window.open 에서 브라우징 문맥을 고르는 이름을 분류한다: 키워드 _self, _parent, _top, _blank(ASCII 대소문자 무시)와 일반 이름(HTML5 REC 2014-10-28 5.1 "rules for choosing a browsing context"). 이름으로 어떤 문맥이 선택되는지는 프레임 트리가 정하며 여기서 정하지 않는다.
