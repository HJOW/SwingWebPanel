org.duckdns.hjow.swingwebpanel.core
Class FontDefaults

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.FontDefaults

public final class FontDefaults
extends java.lang.Object

The default fonts of one component (API contract 5.27): the family for content whose author named no font, the families behind the generic names serif, sans-serif and monospace, the size of font-size: medium, and the size of the monospace elements. An instance is immutable; the component replaces it as a whole when the host changes a value, and every page of the component (frames included) reads the same instance. Nothing here is static, so two components never share their defaults.

컴포넌트 하나의 기본 글꼴(API 계약 5.27): 작성자가 글꼴을 지정하지 않은 내용에 쓰는 패밀리, 일반 이름 serif, sans-serif, monospace 뒤의 패밀리, font-size: medium 의 크기, 고정폭 요소의 크기. 인스턴스는 바뀌지 않는다. 호스트가 값을 바꾸면 컴포넌트가 통째로 교체하고, 컴포넌트의 모든 페이지(프레임 포함)가 같은 인스턴스를 읽는다. 정적인 것이 없으므로 두 컴포넌트가 기본값을 공유하는 일은 없다.

userStyleSheet

public java.lang.String userStyleSheet()
Returns the user style sheet that carries the defaults which are expressed as rules: the standard family as the font of the root element, and the size of the monospace elements relative to the default size (so that it scales inside headings, and does not shrink a second time when monospace elements are nested). Author rules win over these rules.

규칙으로 표현하는 기본값을 담은 사용자 스타일 시트를 반환한다: 표준 패밀리는 루트 요소의 글꼴로, 고정폭 요소의 크기는 기본 크기에 대한 비율로 적는다(그래서 제목 안에서는 함께 커지고, 고정폭 요소가 중첩되어도 한 번 더 작아지지 않는다). 작성자 규칙이 이 규칙을 이긴다.

Returns:
the CSS text, empty if no rule is needed / CSS 텍스트. 규칙이 필요 없으면 비어 있다
