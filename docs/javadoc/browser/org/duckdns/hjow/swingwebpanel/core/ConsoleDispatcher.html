org.duckdns.hjow.swingwebpanel.core
Class ConsoleDispatcher

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.ConsoleDispatcher

public final class ConsoleDispatcher
extends java.lang.Object

Registry and dispatcher of the host's console listeners (API contract 5.20). Registration follows the usual Swing behavior: the same listener added twice is notified twice and a removal removes one registration. Messages come from the threads that run page scripts and are handed to the listeners on the event dispatch thread, one at a time in the order they were published; the script thread never waits for the event dispatch thread. At most MAX_PENDING_EVENTS messages wait for delivery: when the listeners cannot keep up the next messages are dropped and counted, and a ConsoleEvent.Kind#MESSAGES_DROPPED event tells the listeners how many were lost. Delivery happens in batches of BATCH_SIZE so that other events of the event dispatch thread are not starved.

호스트의 콘솔 리스너 등록부이자 통지기(API 계약 5.20). 등록은 일반적인 Swing 동작을 따른다: 같은 리스너를 두 번 등록하면 두 번 통지하고 제거는 등록 하나를 제거한다. 메시지는 페이지 스크립트를 실행하는 스레드에서 오며, 이벤트 디스패치 스레드에서 발행된 순서대로 하나씩 리스너에 전달된다. 스크립트 스레드는 이벤트 디스패치 스레드를 기다리지 않는다. 전달을 기다리는 메시지는 최대 MAX_PENDING_EVENTS 개이며, 리스너가 따라가지 못하면 다음 메시지는 버리고 개수를 세어 ConsoleEvent.Kind#MESSAGES_DROPPED 이벤트로 몇 개를 잃었는지 알린다. 이벤트 디스패치 스레드의 다른 이벤트가 굶지 않도록 전달은 BATCH_SIZE 개씩 나눠서 한다.

Publishes one message. It returns at once on any thread: the message is queued and handed to the listeners on the event dispatch thread. Without a listener nothing is built or queued. When MAX_PENDING_EVENTS messages already wait, the message is dropped and counted.

메시지 하나를 발행한다. 어느 스레드에서든 곧바로 반환한다: 메시지는 큐에 넣고 이벤트 디스패치 스레드에서 리스너에 전달한다. 리스너가 없으면 아무것도 만들거나 넣지 않는다. 이미 MAX_PENDING_EVENTS 개가 기다리고 있으면 메시지를 버리고 센다.
