org.duckdns.hjow.swingwebpanel.core.frames
Class FrameLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.frames.FrameLimits

public final class FrameLimits
extends java.lang.Object

The fixed limits of nested browsing contexts (frames): how deep frames may be nested, how many frames one page may create and the default size. Exceeding a limit never throws; the frame that would break it is not loaded and shows an error document instead (plan item P20-02). The scrollbar sizes live in FrameScroll.

중첩된 브라우징 문맥(프레임)의 고정 한도: 프레임을 얼마나 깊이 중첩할 수 있는지, 한 페이지가 프레임을 몇 개까지 만들 수 있는지, 기본 크기. 한도를 넘어도 예외를 던지지 않는다. 한도를 깨는 프레임은 로드하지 않고 오류 문서를 보여 준다(계획 P20-02). 스크롤바 크기는 FrameScroll 에 있다.

MAX_DEPTH

public static final int MAX_DEPTH
The deepest nesting level that is loaded: the top-level document is level 0 and its frames are level 1. A frame at a deeper level is not loaded; it shows an error document.
