Class ParsingPageLoader

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.ParsingPageLoader
All Implemented Interfaces:
CacheOwner, PageLoader
public final class ParsingPageLoader
extends java.lang.Object
implements PageLoader, CacheOwner

A page loader that completes the snapshots of another loader with a DOM tree (plan items P07, P17-02, P17-04): text/html source is parsed by the HTML parser, text/markdown is converted to HTML first and then parsed, and text/plain becomes a document with one pre element. The text kept in the snapshot (the value of getContent()) is never changed; the page title comes from the parsed document. application/xhtml+xml is parsed by the XML parser (a document that is not well-formed becomes an error page). Other types (images are wrapped into HTML by the network loader beforehand) keep their snapshot without a document. The DOM is built on the loading thread and handed over together with the snapshot, so nothing else touches it before the document thread confirms the page. Cache clearing is forwarded to the wrapped loader.

다른 로더의 스냅샷에 DOM 트리를 붙여 완성하는 페이지 로더(계획 P07, P17-02, P17-04): text/html 원문은 HTML 파서로 해석하고, text/markdown 은 먼저 HTML 로 바꾼 뒤 해석하며, text/plain 은 pre 요소 하나를 가진 문서가 된다. 스냅샷에 보관한 원문(getContent() 값)은 바꾸지 않으며 페이지 제목은 해석한 문서에서 얻는다. application/xhtml+xml 은 XML 파서로 해석한다(well-formed 가 아니면 오류 페이지가 된다). 그 밖의 형식(이미지는 네트워크 로더가 미리 HTML 로 감싼다)은 문서 없이 스냅샷을 그대로 둔다. DOM 은 로딩 스레드에서 만들어 스냅샷과 함께 넘기므로 문서 스레드가 페이지를 확정하기 전에는 아무도 건드리지 않는다. 캐시 삭제는 감싼 로더로 전달한다.
