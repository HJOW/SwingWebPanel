Class DocumentLoop

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.DocumentLoop

public final class DocumentLoop
extends java.lang.Object

The document thread of one or more components: a single thread that runs their document tasks (page confirmation, script tasks, layout) one after the other. A component normally has a loop of its own. A window that a page opens with window.open shares the loop of the window that opened it (plan item P31-08-a), as browsers put windows that can reach each other on one event loop: the opener can then use the document of the popup directly, because no two of their tasks ever run at the same time.

The loop counts its users. Every NavigationController that uses it calls retain() once and release() when its component is disposed; the thread ends when the last user released the loop. A user that leaves does not stop the tasks of the others: its own queued tasks are skipped by its controller.

컴포넌트 하나 또는 여럿의 문서 스레드: 그들의 문서 작업(페이지 확정, 스크립트 작업, 배치)을 차례로 실행하는 단일 스레드. 컴포넌트는 보통 자기 루프를 가진다. 페이지가 window.open 으로 연 창은 자신을 연 창의 루프를 함께 쓴다(계획 P31-08-a). 브라우저가 서로 닿을 수 있는 창을 하나의 이벤트 루프에 두는 것과 같다: 두 창의 작업이 동시에 실행되는 일이 없으므로 여는 창이 팝업의 문서를 직접 쓸 수 있다.

루프는 사용자 수를 센다. 루프를 쓰는 NavigationController 마다 retain() 을 한 번 부르고 컴포넌트가 폐기될 때 release() 를 부른다. 마지막 사용자가 놓으면 스레드가 끝난다. 떠나는 사용자는 다른 사용자의 작업을 멈추지 않는다: 자기가 줄 세운 작업은 자기 제어기가 건너뛴다.
