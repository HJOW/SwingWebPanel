org.duckdns.hjow.swingwebpanel.core
Interface UploadChooser

public interface UploadChooser

Lets the user choose the files of a file upload control. The default implementation of the component shows a Swing file chooser; a host or a test replaces it to choose files without a dialog. It is called on the event dispatch thread.

사용자가 파일 업로드 컨트롤의 파일을 고르게 한다. 컴포넌트의 기본 구현은 Swing 파일 선택기를 보여 주며, 호스트나 시험은 대화상자 없이 파일을 고르도록 이것을 바꿀 수 있다. 이벤트 디스패치 스레드에서 호출된다.
