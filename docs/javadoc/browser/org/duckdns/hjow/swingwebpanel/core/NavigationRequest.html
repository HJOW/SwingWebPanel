org.duckdns.hjow.swingwebpanel.core
Class NavigationRequest

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.NavigationRequest

public final class NavigationRequest
extends java.lang.Object

Everything a PageLoader needs to load one page: what to load, the settings that were in effect when the navigation started (user agent, extra headers, JavaScript flag, forced reload) and the means to report progress and to notice cancellation. Instances are immutable except for the cancel token.

PageLoader 가 페이지 하나를 읽는 데 필요한 모든 것: 읽을 대상, 이동이 시작될 때의 설정(User-Agent, 추가 헤더, JavaScript 설정, 강제 새로고침), 진행률 보고 수단과 취소 확인 수단. 취소 토큰을 제외하면 불변이다.
