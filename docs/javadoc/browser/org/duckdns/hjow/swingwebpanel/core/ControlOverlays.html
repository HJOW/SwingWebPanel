org.duckdns.hjow.swingwebpanel.core
Class ControlOverlays

java.lang.Object
  org.duckdns.hjow.swingwebpanel.core.ControlOverlays

public final class ControlOverlays
extends java.lang.Object

The Swing components that the page puts over its form controls and the dialogs that the controls need: the editor over the text field or text area that has the focus (ControlEditor), the bubble that shows a validation message next to a control, and the file chooser of a file upload control. The components are children of the page component, so they scroll with the page and their coordinates are those of the document. Everything here runs on the event dispatch thread (the form host of the document posts its work to it), and clear() removes every component when the page is replaced, cleaned or disposed.

페이지가 폼 컨트롤 위에 얹는 Swing 컴포넌트와 컨트롤이 필요로 하는 대화상자: 포커스를 가진 텍스트 필드나 텍스트 영역 위의 편집기(ControlEditor), 컨트롤 옆에 검증 메시지를 보여 주는 말풍선, 파일 업로드 컨트롤의 파일 선택기. 컴포넌트는 페이지 컴포넌트의 자식이므로 페이지와 함께 스크롤되고 좌표는 문서의 좌표이다. 여기의 모든 것은 이벤트 디스패치 스레드에서 실행되며(문서의 폼 호스트가 작업을 그곳에 넘긴다), 페이지가 교체, clean, dispose 될 때 clear() 가 모든 컴포넌트를 없앤다.
