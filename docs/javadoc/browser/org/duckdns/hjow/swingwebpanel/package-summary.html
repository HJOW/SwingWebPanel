Package org.duckdns.hjow.swingwebpanel

Public entry point of the SwingWebPanel library: the SwingWebPanel component, a pure Java 6 web browser component for Swing.

See:
          Description

Interface Summary
ConsoleListener Receives the output of the page scripts' console object: console.log, console.error and the other console methods of the main document, of its frames and of its workers, plus the problems the browser reports for the scripts (uncaught exceptions, unhandled promise rejections).
WebMessageEvent.Reply Internal endpoint for a copied reply.
WebMessageListener Receives a page's message on the Swing event dispatch thread.
 

Class Summary
ConsoleEvent One message of the page scripts' console, delivered to a ConsoleListener.
CookieJar A cookie store that several SwingWebPanel components share (extension, API contract 5.24).
SwingWebPanel A web browser component for Swing, written in pure Java 6 without external libraries.
SwingWebPanel.PopupSeed What a component needs to become the window that a page of another component opens (extension, API contract 5.28): it is passed to SwingWebPanel.createPopupPanel(PopupSeed) and from there to the constructor SwingWebPanel.SwingWebPanel(PopupSeed).
WebMessageEvent A copied message sent by a document through its Java host window.
WindowRequest A new window that a page of a SwingWebPanel asked for (extension, API contract 5.28).
