Class BlankPageExample

java.lang.Object

public final class BlankPageExample
extends java.lang.Object

Minimal browser window: a SwingWebPanel wrapped in a JScrollPane, an address field, back/forward/refresh buttons, a progress bar and a status line. It shows how the component is used and how it is released: closing the window calls SwingWebPanel.dispose(). The start page of the example has a button that calls window.close(): the example allows that with SwingWebPanel.setRootWindowClosingEnabled(boolean) for its own page only and overrides closeRootWindow() to close this window instead of ending the JVM at once. Run it with examples/run.sh BlankPageExample; with the argument --smoke the window closes after the page finishes loading or a timeout, and the program prints a one-line result.

최소한의 브라우저 창: JScrollPane 으로 감싼 SwingWebPanel, 주소 입력란, 뒤로/앞으로/새로고침 버튼, 진행 막대, 상태 줄. 컴포넌트를 쓰는 방법과 해제하는 방법을 보여 준다: 창을 닫으면 SwingWebPanel.dispose() 를 호출한다. 예제의 시작 페이지에는 window.close() 를 부르는 단추가 있다. 예제는 자기 페이지에 한해 SwingWebPanel.setRootWindowClosingEnabled(boolean) 로 그것을 허용하고, closeRootWindow() 를 재정의하여 JVM 을 곧바로 끝내는 대신 이 창을 닫는다. examples/run.sh BlankPageExample 로 실행하며, --smoke 인수를 주면 페이지 로드 완료 또는 제한 시간 뒤 창을 닫고 한 줄 결과를 출력한다.
