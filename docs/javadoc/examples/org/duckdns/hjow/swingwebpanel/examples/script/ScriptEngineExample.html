org.duckdns.hjow.swingwebpanel.examples.script
Class ScriptEngineExample

java.lang.Object
  org.duckdns.hjow.swingwebpanel.examples.script.ScriptEngineExample

public final class ScriptEngineExample
extends java.lang.Object

Shows the engine of this project through the standard Java Scripting API (JSR 223, javax.script) in a program that has no other dependency than the engine classes: the engine is found by its unique name swingwebpanel-js (the common name javascript belongs to the engine of the Java runtime, Rhino or Nashorn, if it has one, and is never answered by this engine), then the example evaluates scripts, uses Bindings and the writer of the context, compiles a script, calls functions and methods through Invocable, implements a Java interface with script functions, and reads the position of a ScriptException. Run it with SWP_CLASSES=build/engine-classes examples/run.sh script.ScriptEngineExample; with --smoke it checks every result and prints one line, and the exit code is 1 if a check fails.

이 프로젝트의 엔진을 표준 Java Scripting API(JSR 223, javax.script)로 쓰는 방법을 엔진 클래스 외에는 의존하는 것이 없는 프로그램으로 보여 준다. 엔진은 고유한 이름 swingwebpanel-js 로 찾는다(흔한 이름 javascript 는 Java 런타임의 엔진, 즉 Rhino 나 Nashorn 이 있으면 그것의 몫이며 이 엔진은 절대 대답하지 않는다). 그 다음 스크립트를 평가하고, Bindings 와 컨텍스트의 라이터를 쓰고, 스크립트를 컴파일하고, Invocable 로 함수와 메서드를 호출하고, 스크립트 함수로 Java 인터페이스를 구현하고, ScriptException 의 위치를 읽는다. SWP_CLASSES=build/engine-classes examples/run.sh script.ScriptEngineExample 로 실행하며, --smoke 를 주면 모든 결과를 확인하고 한 줄을 출력하며 확인이 실패하면 종료 코드가 1 이다.
