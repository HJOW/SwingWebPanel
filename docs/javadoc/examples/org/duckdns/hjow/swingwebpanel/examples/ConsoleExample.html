org.duckdns.hjow.swingwebpanel.examples
Class ConsoleExample

java.lang.Object
  org.duckdns.hjow.swingwebpanel.examples.ConsoleExample

public final class ConsoleExample
extends java.lang.Object

Shows how a host application receives the output of the page's console object: a SwingWebPanel with a page whose buttons call console.log, console.warn, console.error, throw an exception or reject a promise, and a text area below that lists every ConsoleEvent the registered ConsoleListener gets. The listener is called on the event dispatch thread, so it may touch Swing components directly. Closing the window calls SwingWebPanel.dispose(), which also removes the console listener. Run it with examples/run.sh ConsoleExample; with --smoke the page logs by itself, and the window closes after both events arrive or a timeout, printing a one-line result.

호스트 응용이 페이지의 console 객체 출력을 받는 방법을 보여 준다: 단추가 console.log, console.warn, console.error 를 호출하거나 예외를 던지거나 promise 를 거부하는 페이지가 있는 SwingWebPanel, 그리고 등록한 ConsoleListener 가 받은 모든 ConsoleEvent 를 나열하는 아래쪽 텍스트 영역. 리스너는 이벤트 디스패치 스레드에서 호출되므로 Swing 컴포넌트를 바로 만져도 된다. 창을 닫으면 SwingWebPanel.dispose() 를 호출하며 콘솔 리스너도 함께 제거된다. examples/run.sh ConsoleExample 로 실행하며, --smoke 를 주면 페이지가 스스로 로그를 쓴다. 두 이벤트를 받거나 제한 시간이 지나면 창을 닫고 한 줄 결과를 출력한다.
