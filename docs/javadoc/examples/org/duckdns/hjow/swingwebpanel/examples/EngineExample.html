org.duckdns.hjow.swingwebpanel.examples
Class EngineExample

java.lang.Object
  org.duckdns.hjow.swingwebpanel.examples.EngineExample

public final class EngineExample
extends java.lang.Object

Shows the stand-alone JavaScript engine JsEngine without any browser component, window or AWT class: running an ECMAScript 2015 script, giving values and a Java function to it, reading results as live Map and List views, calling a script function from Java, promise jobs, a timer that the host implements itself (a stand-alone engine has no event loop), the position of a script error, and a time limit that stops an endless loop. The program needs only the engine classes: SWP_CLASSES=build/engine-classes examples/run.sh EngineExample. With --smoke it checks every result and prints one line (used for automatic checks); the exit code is 1 if a check fails.

브라우저 컴포넌트, 창, AWT 클래스 없이 독립 JavaScript 엔진 JsEngine 을 쓰는 방법을 보여 준다: ECMAScript 2015 스크립트 실행, 스크립트에 값과 Java 함수 주기, 결과를 살아 있는 Map, List 보기로 읽기, Java 에서 스크립트 함수 호출, promise 작업, 호스트가 직접 구현하는 타이머(독립 엔진에는 이벤트 루프가 없다), 스크립트 오류의 위치, 끝없는 반복을 멈추는 시간 제한. 이 프로그램은 엔진 클래스만 있으면 된다: SWP_CLASSES=build/engine-classes examples/run.sh EngineExample. --smoke 를 주면 모든 결과를 확인하고 한 줄을 출력하며(자동 확인용) 확인이 실패하면 종료 코드가 1 이다.
