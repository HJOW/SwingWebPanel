Class EditingExample

java.lang.Object
  org.duckdns.hjow.swingwebpanel.examples.EditingExample

public final class EditingExample
extends java.lang.Object

Opens a page with an editable area (contenteditable), draggable items, a drop zone and a text field, so that a person can try what the automatic tests cannot: typing and Hangul input with a real input method, the real mouse for drag and drop, and the real system clipboard (Ctrl+C, Ctrl+X, Ctrl+V). Run examples/run.sh EditingExample; --smoke loads the page offscreen (works without a display) and checks that the editing elements are there. Closing the window releases the component.

편집 영역(contenteditable), 끌 수 있는 항목, 놓는 곳, 텍스트 필드가 있는 페이지를 열어, 자동 시험이 못 하는 것을 사람이 해 볼 수 있게 한다: 실제 입력기로 하는 입력과 한글 입력, 끌어다 놓기의 실제 마우스, 실제 시스템 클립보드(Ctrl+C, Ctrl+X, Ctrl+V). examples/run.sh EditingExample 로 실행하며 --smoke 는 화면 없이 페이지를 읽어 편집 요소가 있는지 확인한다. 창을 닫으면 컴포넌트를 해제한다.
