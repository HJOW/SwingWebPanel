Package org.duckdns.hjow.swingwebpanel.examples

Class Summary
BlankPageExample Minimal browser window: a SwingWebPanel wrapped in a JScrollPane, an address field, back/forward/refresh buttons, a progress bar and a status line.
ConsoleExample Shows how a host application receives the output of the page's console object: a SwingWebPanel with a page whose buttons call console.log, console.warn, console.error, throw an exception or reject a promise, and a text area below that lists every ConsoleEvent the registered ConsoleListener gets.
DownloadPopupExample Manual check of the download popup: it starts a small web server on the local machine that serves a slow 3 MB file, a file of unknown size and a missing file, and shows a window with one button for each.
EditingExample Opens a page with an editable area (contenteditable), draggable items, a drop zone and a text field, so that a person can try what the automatic tests cannot: typing and Hangul input with a real input method, the real mouse for drag and drop, and the real system clipboard (Ctrl+C, Ctrl+X, Ctrl+V).
EngineExample Shows the stand-alone JavaScript engine JsEngine without any browser component, window or AWT class: running an ECMAScript 2015 script, giving values and a Java function to it, reading results as live Map and List views, calling a script function from Java, promise jobs, a timer that the host implements itself (a stand-alone engine has no event loop), the position of a script error, and a time limit that stops an endless loop.
MessageExample Demonstrates host messages and replies with a local classpath document.
StaticPageExample Opens the bundled static HTML/CSS pages in the browser window.
