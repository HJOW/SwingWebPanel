Class DownloadPopupExample

java.lang.Object
  org.duckdns.hjow.swingwebpanel.examples.DownloadPopupExample

public final class DownloadPopupExample
extends java.lang.Object

Manual check of the download popup: it starts a small web server on the local machine that serves a slow 3 MB file, a file of unknown size and a missing file, and shows a window with one button for each. Click a button to see the real popup (progress bar, Save as... with a file chooser, Cancel, the replace confirmation when the file already exists); click several buttons to run downloads at the same time. Run it with examples/run.sh DownloadPopupExample. With the argument --smoke no window is shown: the program downloads the file into a temporary directory through a popup that only records what happens, prints one line and exits with 0 on success (used for automatic checks, also in a headless environment).

다운로드 팝업의 수동 확인용 예제: 이 컴퓨터에서 느리게 보내는 3 MB 파일, 크기를 알 수 없는 파일, 없는 파일을 제공하는 작은 웹 서버를 시작하고 각각의 버튼이 있는 창을 보여 준다. 버튼을 누르면 실제 팝업(진행 막대, 파일 선택기가 뜨는 다른 이름으로 저장..., 취소, 파일이 이미 있을 때의 교체 확인)을 볼 수 있고, 버튼을 여러 번 누르면 다운로드가 동시에 실행된다. examples/run.sh DownloadPopupExample 로 실행한다. --smoke 인수를 주면 창을 보여 주지 않고 상태만 기록하는 팝업으로 임시 디렉터리에 파일을 내려받은 뒤 한 줄을 출력하고 성공하면 0 으로 끝난다(자동 확인용이며 헤드리스 환경에서도 동작한다).
