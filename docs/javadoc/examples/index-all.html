ConsoleExample - Class in org.duckdns.hjow.swingwebpanel.examples
Shows how a host application receives the output of the page's console object: a SwingWebPanel with a page whose buttons call console.log, console.warn, console.error, throw an exception or reject a promise, and a text area below that lists every ConsoleEvent the registered ConsoleListener gets.

Manual check of the download popup: it starts a small web server on the local machine that serves a slow 3 MB file, a file of unknown size and a missing file, and shows a window with one button for each.

EditingExample - Class in org.duckdns.hjow.swingwebpanel.examples
Opens a page with an editable area (contenteditable), draggable items, a drop zone and a text field, so that a person can try what the automatic tests cannot: typing and Hangul input with a real input method, the real mouse for drag and drop, and the real system clipboard (Ctrl+C, Ctrl+X, Ctrl+V).
EngineExample - Class in org.duckdns.hjow.swingwebpanel.examples
Shows the stand-alone JavaScript engine JsEngine without any browser component, window or AWT class: running an ECMAScript 2015 script, giving values and a Java function to it, reading results as live Map and List views, calling a script function from Java, promise jobs, a timer that the host implements itself (a stand-alone engine has no event loop), the position of a script error, and a time limit that stops an endless loop.

ScriptEngineExample - Class in org.duckdns.hjow.swingwebpanel.examples.script
Shows the engine of this project through the standard Java Scripting API (JSR 223, javax.script) in a program that has no other dependency than the engine classes: the engine is found by its unique name swingwebpanel-js (the common name javascript belongs to the engine of the Java runtime, Rhino or Nashorn, if it has one, and is never answered by this engine), then the example evaluates scripts, uses Bindings and the writer of the context, compiles a script, calls functions and methods through Invocable, implements a Java interface with script functions, and reads the position of a ScriptException.
