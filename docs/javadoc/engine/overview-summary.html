org.duckdns.hjow.swingwebpanel.js JavaScript engine written from scratch: values, lexer, parser, interpreter, built-in objects and event loop.
org.duckdns.hjow.swingwebpanel.js.ast The syntax tree of the JavaScript engine.
org.duckdns.hjow.swingwebpanel.js.builtins The standard built-in objects of the JavaScript engine.
org.duckdns.hjow.swingwebpanel.js.builtins.corelib Fundamental ECMAScript 2015 built-in objects: Object, Function.prototype methods, Boolean, Symbol, the Error family, Number, Math and the global functions and value properties.
org.duckdns.hjow.swingwebpanel.js.builtins.datajson JavaScript-visible built-in objects Date, RegExp, JSON, Map, Set, WeakMap and WeakSet (ECMA-262 6th edition sections 20.3, 21.2, 24.3 and 23) built on the standalone libraries of the packages js.date, js.regexp, js.text and js.num.
org.duckdns.hjow.swingwebpanel.js.builtins.meta Built-in objects that work on the object model itself (ECMA-262 6th edition): Proxy, Reflect, Promise and the Annex B global functions escape/unescape.
org.duckdns.hjow.swingwebpanel.js.builtins.stringarray ECMAScript 2015 built-in objects String and Array: constructors, static functions, prototype methods (including the Annex B HTML methods), the String and Array iterator objects and the shared helpers they use.
org.duckdns.hjow.swingwebpanel.js.builtins.typed ECMAScript 2015 binary data objects: ArrayBuffer, DataView, the abstract %TypedArray% intrinsic and the nine concrete typed array constructors (Int8Array to BigUint64Array).
org.duckdns.hjow.swingwebpanel.js.date Date arithmetic, parsing and formatting on ECMAScript time values (milliseconds since the epoch as double) with an injectable time zone.
org.duckdns.hjow.swingwebpanel.js.embed The embedding API of the stand-alone JavaScript engine: JsEngine creates an engine, runs scripts, reads and writes global variables, calls functions and converts values between Java and script; the handle classes give live access to script objects, arrays and functions; JsHostFunction is how a script calls Java code.
org.duckdns.hjow.swingwebpanel.js.interp The tree-walking interpreter of the JavaScript engine: environments and bindings, completion records, function objects and calls, statements, expressions, destructuring, classes, generators that resume without Java threads, modules and dynamic code.
org.duckdns.hjow.swingwebpanel.js.num Exact number/string conversions (ECMAScript Number::toString, toFixed, toExponential, toPrecision, StringToNumber, parseInt, parseFloat, ToInt32 ...) on plain Java doubles.
org.duckdns.hjow.swingwebpanel.js.parser Source text analysis of the JavaScript engine: the lexer that turns source text into tokens (identifiers, numbers, strings, templates, regular expression literals, punctuators) and the parser that builds the syntax tree and reports early errors with source positions.
org.duckdns.hjow.swingwebpanel.js.regexp ECMAScript regular expression engine written from scratch (parser, compiler and backtracking virtual machine over UTF-16 strings), including named groups, lookbehind, indices and Unicode 13 property escapes.
org.duckdns.hjow.swingwebpanel.js.script The Java Scripting API (JSR 223, javax.script) provider of the stand-alone JavaScript engine: a JsScriptEngineFactory (registered under the unique name swingwebpanel-js) that creates JsScriptEngines, which implement ScriptEngine, Compilable and Invocable on top of JsEngine.
org.duckdns.hjow.swingwebpanel.js.text Text helpers independent of the JavaScript value model: character classification, URI coding, legacy escape, normalization, case conversion, code point helpers and JSON text helpers.
