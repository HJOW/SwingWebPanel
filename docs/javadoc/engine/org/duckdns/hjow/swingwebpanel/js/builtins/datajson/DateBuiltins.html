Class DateBuiltins

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.datajson.DateBuiltins

public final class DateBuiltins
extends java.lang.Object

The built-in Date constructor and Date.prototype (ECMA-262 6th edition 20.3) including the Annex B methods getYear, setYear and toGMTString. The calendar arithmetic, parsing and formatting come from the package js.date; this class only implements the JavaScript argument handling and receiver checks. The local time zone is TimeZone.getDefault() read at every call unless the host (or a test) fixed one for the realm with setTimeZone(JsRealm, TimeZone).

Deviation from the 6th edition text, taken from later editions and all browsers: Date.UTC(year) treats a missing month as 0 instead of NaN.

내장 Date 생성자와 Date.prototype(ECMA-262 6판 20.3). 부속서 B 의 getYear, setYear, toGMTString 을 포함한다. 달력 연산, 해석, 서식은 js.date 패키지가 맡고 이 클래스는 JavaScript 인수 처리와 수신 객체 검사만 구현한다. 지역 시간대는 호스트(또는 시험)가 setTimeZone(JsRealm, TimeZone) 으로 realm 에 고정하지 않는 한 호출마다 읽는 TimeZone.getDefault() 이다.

6판 본문과 다른 점(이후 판과 모든 브라우저를 따름): Date.UTC(year) 는 월이 없으면 NaN 이 아니라 0 으로 본다.
