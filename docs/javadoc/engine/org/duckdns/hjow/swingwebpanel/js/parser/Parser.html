org.duckdns.hjow.swingwebpanel.js.parser
Class Parser

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.parser.Parser

public final class Parser
extends java.lang.Object

The JavaScript parser (ECMA-262 6th edition clauses 12 to 15) with the early errors of the specification: statements, declarations with redeclaration checks, strict mode, labels, break/continue/return validity, automatic semicolon insertion, the Script and Module goals (import/export), eval code and the Function constructor. Syntax that is not part of ES2015 is reported as a SyntaxError with its position; nothing is silently ignored.

Use the static methods: parseScript(String, String), parseModule(String, String), parseEval(String, String, EvalOptions) and parseFunctionConstructor(String, String, boolean, String). Each returns a PROGRAM node (or a FUNCTION node) of Node.

ECMA-262 6판 12~15장의 JavaScript 파서이며 규격의 조기 오류를 구현한다: 문장, 재선언 검사가 있는 선언, 엄격 모드, 레이블, break/continue/return 유효성, 자동 세미콜론 삽입, Script 와 Module 목표(import/export), eval 코드, Function 생성자. ES2015 에 없는 문법은 위치가 있는 SyntaxError 로 보고하며 조용히 무시하지 않는다.

정적 메서드를 사용한다: parseScript(String, String), parseModule(String, String), parseEval(String, String, EvalOptions), parseFunctionConstructor(String, String, boolean, String). 각각 Node 의 PROGRAM 노드(또는 FUNCTION 노드)를 반환한다.
