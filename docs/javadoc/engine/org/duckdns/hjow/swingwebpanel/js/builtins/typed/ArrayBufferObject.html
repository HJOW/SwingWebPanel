public class ArrayBufferObject
extends JsObject

An ArrayBuffer object with a fixed length or a specified maximum length. Typed arrays and DataViews refer to its current byte array. A detached buffer has length zero and releases its storage.

고정 길이 또는 최대 길이를 지정한 ArrayBuffer 객체. 형식화 배열과 DataView는 현재 바이트 배열을 참조한다. 분리된 버퍼는 길이가 0이 되고 저장소를 놓아 준다.

detach

public void detach()
Detaches the buffer: the bytes are released, the length becomes 0 and every view on it behaves as empty (typed array methods then throw a TypeError as ECMAScript 2015 requires).
