public final class UriCodec
extends java.lang.Object

ECMAScript 2015 URI handling functions (section 18.2.6): encodeURI, encodeURIComponent, decodeURI and decodeURIComponent operating on UTF-16 strings. Characters are encoded as UTF-8 percent sequences with upper case hexadecimal digits; decoding validates UTF-8 strictly (no overlong forms, no surrogates, at most U+10FFFF) and, for decodeURI, keeps escapes of reserved characters and "#" unchanged. Malformed input throws UriFormatException. All methods are static and thread-safe.

UTF-16 문자열 위의 ECMAScript 2015 URI 처리 함수(18.2.6절): encodeURI, encodeURIComponent, decodeURI, decodeURIComponent. 문자는 대문자 16진수를 쓰는 UTF-8 퍼센트 시퀀스로 부호화한다. 복호화는 UTF-8 을 엄격하게 검사하고(과도하게 긴 형태, 서로게이트, U+10FFFF 초과 불가) decodeURI 는 예약 문자와 "#" 의 escape 를 그대로 둔다. 올바르지 않은 입력은 UriFormatException 을 던진다. 모든 메서드는 정적이며 스레드 안전하다.
