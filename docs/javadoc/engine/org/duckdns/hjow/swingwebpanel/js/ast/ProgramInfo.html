Class ProgramInfo

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ast.ProgramInfo

public final class ProgramInfo
extends java.lang.Object

Information about a whole script or module, stored in the value field of the PROGRAM node: strictness, the goal, the source text and, for modules, the import and export entries (ECMA-262 6th edition 15.2.1.16 Source Text Module Records).

스크립트 또는 모듈 전체에 대한 정보. PROGRAM 노드의 value 필드에 저장된다: 엄격 여부, 파싱 목표, 소스 텍스트, 모듈의 import/export 항목(ECMA-262 6판 15.2.1.16 Source Text Module Record).
