public final class PromiseInterop
extends java.lang.Object

Small public bridge for the interpreter's async functions. It keeps Promise internal classes private while exposing only intrinsic capability creation and await reaction attachment.

인터프리터 async 함수를 위한 작은 공개 연결점이다. Promise 내부 클래스는 비공개로 두고, intrinsic capability 생성과 await 반응 연결만 제공한다.
