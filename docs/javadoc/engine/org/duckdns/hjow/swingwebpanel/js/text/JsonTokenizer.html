org.duckdns.hjow.swingwebpanel.js.text
Class JsonTokenizer

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.text.JsonTokenizer

public final class JsonTokenizer
extends java.lang.Object

Pull tokenizer for strict JSON text (RFC 8259 / ECMA-404 grammar as used by JSON.parse), independent of JavaScript values. White space is limited to space, tab, line feed and carriage return. Numbers must match -?(0|[1-9][0-9]*)(.[0-9]+)?([eE][+-]?[0-9]+)?; strings reject unescaped control characters and unknown escapes. The tokenizer returns tokens only; the caller (or validate(String)) checks the structure. The number lexeme is returned as text so that the caller converts it with its own number conversion. Instances are not thread-safe.

엄격한 JSON 텍스트(JSON.parse 가 쓰는 RFC 8259 / ECMA-404 문법)용 당겨 읽기 토큰화기. JavaScript 값과 무관하다. 공백은 스페이스, 탭, 줄 바꿈, 캐리지 리턴뿐이다. 숫자는 -?(0|[1-9][0-9]*)(.[0-9]+)?([eE][+-]?[0-9]+)? 여야 하고, 문자열은 escape 되지 않은 제어 문자와 알 수 없는 escape 를 거부한다. 토큰만 돌려주며 구조 검사는 호출자(또는 validate(String))가 한다. 숫자는 호출자가 자기 숫자 변환으로 바꾸도록 텍스트 그대로 반환한다. 인스턴스는 스레드 안전하지 않다.
