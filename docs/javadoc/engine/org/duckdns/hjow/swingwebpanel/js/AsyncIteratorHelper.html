Class AsyncIteratorHelper

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.AsyncIteratorHelper

public final class AsyncIteratorHelper
extends java.lang.Object

Async iterator operations used by for await and Array.fromAsync. A synchronous iterator is wrapped by CreateAsyncFromSyncIterator and each next/return result value is Promise-resolved.

for await와 Array.fromAsync가 쓰는 비동기 이터레이터 연산. 동기 이터레이터는 CreateAsyncFromSyncIterator로 감싸고 next/return 결과 값을 Promise 해결한다.
