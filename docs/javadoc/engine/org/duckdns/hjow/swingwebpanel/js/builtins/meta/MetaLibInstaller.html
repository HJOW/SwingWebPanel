Installer of the object-model built-ins: Proxy (26.2), Reflect (26.1), Promise (25.4) and the Annex B global functions escape and unescape (B.2.1). The engine core loads it by class name after the other library installers, so it may rely on Object.prototype, Function.prototype, the Symbol well-known symbols and the iterator helpers of the core. Hosts: set the job queue with PromiseJobs.setQueue(JsRealm, org.duckdns.hjow.swingwebpanel.js.JobQueue) (or provide one on the realm) and observe unhandled rejections with PromiseJobs.setRejectionTracker(JsRealm, PromiseRejectionTracker).

객체 모델 내장 객체의 설치기: Proxy(26.2), Reflect(26.1), Promise(25.4), 부속서 B 의 전역 함수 escape, unescape(B.2.1). 엔진 코어가 다른 라이브러리 설치기 뒤에 클래스 이름으로 불러오므로 코어의 Object.prototype, Function.prototype, Symbol 의 잘 알려진 심볼, 이터레이터 도우미를 쓸 수 있다. 호스트: 작업 큐는 PromiseJobs.setQueue(JsRealm, org.duckdns.hjow.swingwebpanel.js.JobQueue) 로 지정하고(또는 realm 이 제공하고), 처리되지 않은 거부는 PromiseJobs.setRejectionTracker(JsRealm, PromiseRejectionTracker) 로 관찰한다.
