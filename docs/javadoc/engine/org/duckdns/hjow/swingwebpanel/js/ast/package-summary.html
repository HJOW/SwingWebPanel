Package org.duckdns.hjow.swingwebpanel.js.ast Description

The syntax tree of the JavaScript engine. All nodes are instances of Node whose layout is defined per NodeType constant, plus the scope, function, template and module descriptions the parser computes for the interpreter.

JavaScript 엔진의 구문 트리. 모든 노드는 Node 이며 배치 규칙은 NodeType 상수마다 정의한다. 파서가 인터프리터를 위해 계산하는 스코프, 함수, 템플릿, 모듈 설명도 있다.
