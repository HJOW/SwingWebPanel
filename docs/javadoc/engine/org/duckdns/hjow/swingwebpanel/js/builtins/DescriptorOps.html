Class DescriptorOps

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.DescriptorOps

public final class DescriptorOps
extends java.lang.Object

Conversion between property descriptor objects of scripts ({ value, writable, get, set, enumerable, configurable }) and the PropertyDescriptor specification type: ToPropertyDescriptor and FromPropertyDescriptor (ECMA-262 6th edition 6.2.4.4 and 6.2.4.5). Used by Object.defineProperty, Reflect.defineProperty and similar built-ins.

스크립트의 프로퍼티 기술자 객체({ value, writable, get, set, enumerable, configurable })와 명세 형식 PropertyDescriptor 사이의 변환: ToPropertyDescriptor 와 FromPropertyDescriptor(ECMA-262 6판 6.2.4.4, 6.2.4.5). Object.defineProperty, Reflect.defineProperty 같은 내장 함수가 쓴다.
