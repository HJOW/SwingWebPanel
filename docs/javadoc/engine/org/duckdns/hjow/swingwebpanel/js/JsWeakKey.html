public abstract class JsWeakKey
extends JsValue

Base class for JavaScript values that may carry WeakMap associations. Associations live with the key, so a value referring back to its key does not keep that key alive through the map.

WeakMap 항목을 가질 수 있는 JavaScript 값의 기반 클래스. 항목은 키와 함께 있으므로 값에서 키를 참조해도 맵을 통해 키를 계속 살려 두지 않는다.
