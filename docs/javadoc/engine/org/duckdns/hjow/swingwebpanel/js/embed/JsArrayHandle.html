public final class JsArrayHandle
extends java.util.AbstractList<java.lang.Object>
implements JsHandle, java.util.RandomAccess

A live view of a script array as a List<Object>. The size is the length of the array; reading and writing an element reads and writes the array; add and remove change the array the way push and splice do. Holes of a sparse array read as JsEngine.UNDEFINED. Elements follow the conversion rules of JsEngine. Two handles are equal when they refer to the same script array; the equals, hashCode and toString of the List interface are not used because they would not terminate for an array that contains itself.

스크립트 배열을 List<Object> 로 보여 주는 살아 있는 보기. 크기는 배열의 length 이고, 요소를 읽고 쓰면 배열을 읽고 쓰며, add 와 remove 는 push 와 splice 처럼 배열을 바꾼다. 희소 배열의 구멍은 JsEngine.UNDEFINED 로 읽힌다. 요소는 JsEngine 의 변환 규칙을 따른다. 핸들 두 개는 같은 스크립트 배열을 가리킬 때 같다. 자기 자신을 포함한 배열에서는 끝나지 않으므로 List 인터페이스의 equals, hashCode, toString 은 쓰지 않는다.
