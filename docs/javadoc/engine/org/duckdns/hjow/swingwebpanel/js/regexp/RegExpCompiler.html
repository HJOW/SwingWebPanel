Class RegExpCompiler

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.regexp.RegExpCompiler

public final class RegExpCompiler
extends java.lang.Object

Compiles an ECMAScript regular expression into a RegExpProgram: the pattern is parsed into a syntax tree by RegExpParser and translated to the instruction set interpreted by the backtracking matcher.

Translation rules (ECMA-262 21.2.2): alternation and quantifiers become split/jump instructions; a quantifier whose atom is a single character or class becomes one REPEAT instruction that needs constant backtracking memory; other quantifiers use counted loops with an empty-iteration check (an iteration that matches the empty string after the minimum count is a failure) and reset the captures of the group range at the start of every iteration; groups store their capture only when they complete; lookaheads are atomic (they leave only their captures behind).

Use compile(String, int) or compile(String, String); validate(String, String) only checks the early errors of a regular expression literal. All methods are static and thread-safe.

ECMAScript 정규식을 RegExpProgram 으로 컴파일한다. RegExpParser 가 패턴을 구문 트리로 해석하고, 이를 역추적 일치 검색기가 해석하는 명령으로 번역한다.

번역 규칙(ECMA-262 21.2.2): 선택과 수량자는 분기/점프 명령이 된다. 원자가 문자 하나나 클래스인 수량자는 일정한 역추적 메모리만 쓰는 REPEAT 명령 하나가 된다. 그 밖의 수량자는 빈 반복 검사(최솟값을 채운 뒤 빈 문자열과 일치한 반복은 실패)가 있는 횟수 반복문을 쓰고 반복이 시작될 때마다 그룹 범위의 캡처를 초기화한다. 그룹은 끝났을 때만 캡처를 저장한다. 선행 탐색은 원자적이어서 캡처만 남긴다.

compile(String, int) 또는 compile(String, String) 을 쓴다. validate(String, String) 은 정규식 리터럴의 조기 오류만 검사한다. 모든 메서드는 정적이며 스레드 안전하다.
