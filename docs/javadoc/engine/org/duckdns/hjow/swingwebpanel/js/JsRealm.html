org.duckdns.hjow.swingwebpanel.js
Class JsRealm

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.JsRealm

public class JsRealm
extends java.lang.Object

A realm (ECMA-262 6th edition 8.2): a global object together with a complete, independent set of built-in objects. One realm is created per web page by the host. This class is the host-facing facade of the engine and the registry of the intrinsic objects that built-ins and the interpreter need.

Built-in authors: create functions with newFunction(String, int, NativeFunction.Call), attach them with #method(JsObject, String, int, NativeFunction.Call), throw errors with JsException, look up prototypes with the getters of this class or getIntrinsic(String), and install whole groups through a BuiltinInstaller.

realm (ECMA-262 6판 8.2): 전역 객체와 독립적이고 완전한 내장 객체 집합. 호스트가 웹 페이지마다 realm 하나를 만든다. 이 클래스는 엔진의 호스트용 창구이며, 내장 객체와 인터프리터가 필요로 하는 내장(intrinsic) 객체의 등록부이다.

내장 객체 작성자: newFunction(String, int, NativeFunction.Call) 로 함수를 만들고 #method(JsObject, String, int, NativeFunction.Call) 로 붙이며, 오류는 JsException 으로 던지고, 프로토타입은 이 클래스의 getter 나 getIntrinsic(String) 으로 찾고, 묶음 설치는 BuiltinInstaller 로 한다.

setCallSite

public void setCallSite(java.lang.String sourceName,
                        int line,
                        int column)
Remembers where the script code is that calls a native function. The interpreter calls it just before each call of a native function, so a native function (for example console.log) can tell where it was called from. The values are only valid while the native function runs, on the thread that runs the script.

기본 함수를 호출하는 스크립트 코드의 위치를 기억한다. 인터프리터가 기본 함수를 호출하기 직전마다 부르므로, 기본 함수(예: console.log)가 자신이 어디서 호출되었는지 알 수 있다. 값은 기본 함수가 실행되는 동안, 스크립트를 실행하는 스레드에서만 유효하다.

Parameters:
sourceName - the script name or null / 스크립트 이름 또는 null
line - the 1-based line / 1부터 시작하는 줄
column - the 1-based column / 1부터 시작하는 열
