public final class Descriptors
extends java.lang.Object

Conversions between JavaScript property descriptor objects and PropertyDescriptor records, and the descriptor algorithms that the Proxy invariants and Reflect need (ECMA-262 6th edition 6.2.4): ToPropertyDescriptor, FromPropertyDescriptor, CompletePropertyDescriptor and IsCompatiblePropertyDescriptor.

JavaScript 프로퍼티 기술자 객체와 PropertyDescriptor 기록 사이의 변환, 그리고 Proxy 불변 조건과 Reflect 에 필요한 기술자 알고리즘(ECMA-262 6판 6.2.4): ToPropertyDescriptor, FromPropertyDescriptor, CompletePropertyDescriptor, IsCompatiblePropertyDescriptor.
