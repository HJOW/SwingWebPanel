BoundFunction, NativeFunction, ScriptFunction
public abstract class JsFunction
extends JsObject

Base class of all function objects (objects with a [[Call]] internal method). Subclasses: NativeFunction (implemented in Java), BoundFunction (result of Function.prototype.bind) and the interpreter's script functions. Every function knows the JsRealm it was created in.

모든 함수 객체([[Call]] 내부 메서드를 가진 객체)의 기반 클래스. 하위 클래스: NativeFunction(Java 로 구현), BoundFunction(Function.prototype.bind 의 결과), 인터프리터의 스크립트 함수. 모든 함수는 자신이 만들어진 JsRealm 을 안다.
