Class RegExpBuiltins

public final class RegExpBuiltins
extends java.lang.Object

The built-in RegExp constructor and RegExp.prototype (ECMA-262 6th edition 21.2) on top of the regular expression engine of the package js.regexp: construction and Annex B compile, exec with the lastIndex protocol of the global and sticky flags, test, toString, the flag accessors, [Symbol.match], [Symbol.replace], [Symbol.search], [Symbol.split] and RegExp[Symbol.species].

Resource limits: a match that exceeds the step or backtrack limit of the engine becomes a RangeError with a message that names the limit. If a cancellation hook (see setCancelHook(JsRealm, RegExpCancel)) reports cancellation, the match is aborted with a ScriptAbortedException (reason CANCELLED) so the host can stop the script. The step limit can be changed per realm with setStepLimit(JsRealm, long).

Extensions beyond ES2015: s/d, named capture result groups, lookbehind, matchAll and Unicode property escapes. Not implemented: the legacy static properties RegExp.$1 and RegExp.lastMatch.

js.regexp 패키지의 정규식 엔진 위에 만든 내장 RegExp 생성자와 RegExp.prototype(ECMA-262 6판 21.2): 생성과 부속서 B 의 compile, g/y 플래그의 lastIndex 규약을 따르는 exec, test, toString, 플래그 접근자, [Symbol.match], [Symbol.replace], [Symbol.search], [Symbol.split], RegExp[Symbol.species].

자원 제한: 엔진의 단계 수나 역추적 제한을 넘는 일치는 제한 이름을 알리는 RangeError 가 된다. 취소 훅(setCancelHook(JsRealm, RegExpCancel))이 취소를 알리면 일치를 ScriptAbortedException(이유 CANCELLED)으로 중단하여 호스트가 스크립트를 멈출 수 있게 한다. 단계 제한은 setStepLimit(JsRealm, long) 으로 realm 마다 바꿀 수 있다.

ES2015 를 넘는 확장: s/d, 이름 있는 캡처 결과, 뒤쪽 탐색, matchAll, 유니코드 속성 escape. 미구현: 구형 정적 프로퍼티 RegExp.$1, RegExp.lastMatch.
