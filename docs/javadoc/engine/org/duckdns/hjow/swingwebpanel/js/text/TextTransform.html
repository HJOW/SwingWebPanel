org.duckdns.hjow.swingwebpanel.js.text
Class TextTransform

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.text.TextTransform

public final class TextTransform
extends java.lang.Object

String transformations used by String.prototype: normalize, toUpperCase/toLowerCase (and the locale variants), trim, repeat. Default case conversion uses the generated full Unicode mappings. Normalization uses the generated Unicode 18 data. Explicit Java locales use the running JRE.

String.prototype 이 쓰는 문자열 변환: normalize, toUpperCase/toLowerCase(와 로캘 변형), trim, repeat. 기본 대소문자 변환과 정규화는 생성한 Unicode 18 자료를 쓴다. 명시적 Java 로케일은 실행 중인 JRE에 따른다. 모든 메서드는 정적이며 스레드 안전하다.
