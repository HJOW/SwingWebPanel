Interface JsCallable

All Known Implementing Classes:
JsFunctionHandle
public interface JsCallable

A script function that Java code can call. JsEngine returns it (as a JsFunctionHandle) wherever a script value is a function. Arguments and results follow the conversion rules of JsEngine; a script error is thrown as JsScriptError.

Java 코드가 호출할 수 있는 스크립트 함수. 스크립트 값이 함수이면 JsEngine 이 이것(JsFunctionHandle)을 돌려준다. 인수와 결과는 JsEngine 의 변환 규칙을 따르며, 스크립트 오류는 JsScriptError 로 던져진다.
