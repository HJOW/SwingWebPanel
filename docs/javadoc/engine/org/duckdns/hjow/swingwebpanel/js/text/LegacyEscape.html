Class LegacyEscape

public final class LegacyEscape
extends java.lang.Object

ECMAScript Annex B legacy functions escape and unescape (B.2.1, B.2.2). escape keeps ASCII letters, digits and the characters @*_+-./; code units below 256 become percent plus two upper case hex digits; other code units become percent, the letter u and four upper case hex digits. unescape reverses both forms and leaves malformed sequences untouched. All methods are static and thread-safe.

ECMAScript 부속서 B 의 레거시 함수 escape, unescape(B.2.1, B.2.2). escape 는 ASCII 글자, 숫자, @*_+-./ 를 그대로 두고, 256 미만 코드 단위는 퍼센트와 대문자 16진수 두 자리로, 그 밖의 코드 단위는 퍼센트, 글자 u, 대문자 16진수 네 자리로 바꾼다. unescape 는 두 형태를 되돌리며 올바르지 않은 시퀀스는 그대로 둔다. 모든 메서드는 정적이며 스레드 안전하다.
