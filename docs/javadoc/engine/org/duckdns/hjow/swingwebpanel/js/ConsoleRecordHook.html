Interface ConsoleRecordHook

ConsoleHook
public interface ConsoleRecordHook
extends ConsoleHook

A ConsoleHook that also wants the structured form of every message. The engine calls record(ConsoleRecord) instead of ConsoleHook.message(String, String) for a hook of this type, so an implementation gets each message exactly once: it must implement message too (for callers that still use the plain form) and normally forwards it as a record without a position.

모든 메시지의 구조화된 형태까지 받으려는 ConsoleHook. 엔진은 이 타입의 연결에는 ConsoleHook.message(String, String) 대신 record(ConsoleRecord) 를 호출하므로 구현은 메시지를 정확히 한 번 받는다. 아직 일반 형태를 쓰는 호출자를 위해 message 도 구현해야 하며, 보통 위치 정보 없는 기록으로 바꿔 전달한다.

void record(ConsoleRecord record)
Receives one console record. It runs on the thread that runs the script, inside the script task, so it must return quickly and must not call back into the engine.
