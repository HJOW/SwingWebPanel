Package org.duckdns.hjow.swingwebpanel.js.embed

The embedding API of the stand-alone JavaScript engine: JsEngine creates an engine, runs scripts, reads and writes global variables, calls functions and converts values between Java and script; the handle classes give live access to script objects, arrays and functions; JsHostFunction is how a script calls Java code.

See:
          Description

Interface Summary
JsCallable A script function that Java code can call.
JsHandle A live reference from Java code to an object of a script, implemented by JsObjectHandle (any object, seen as a Map), JsArrayHandle (an array, seen as a List) and JsFunctionHandle (a function).
JsHostFunction A function that the host application (Java code) gives to scripts.
 

Class Summary
JsArrayHandle A live view of a script array as a List<Object>.
JsEngine A self contained JavaScript engine targeting ECMAScript 2026 that any Java program can use, with or without the browser component.
JsEngine.Undefined The type of JsEngine.UNDEFINED.
JsFunctionHandle A live reference to a script function.
JsObjectHandle A live view of a script object as a Map<String, Object>.
 

Exception Summary
JsScriptError An error that script code threw (or that the engine raised while running script code) and that nobody caught inside the script.
 

Package org.duckdns.hjow.swingwebpanel.js.embed Description

The embedding API of the stand-alone JavaScript engine: JsEngine creates an engine, runs scripts, reads and writes global variables, calls functions and converts values between Java and script; the handle classes give live access to script objects, arrays and functions; JsHostFunction is how a script calls Java code. This package needs no browser class and no AWT or Swing class (plan item P26-02).

독립 JavaScript 엔진의 내장(embedding) API: JsEngine 이 엔진을 만들고, 스크립트를 실행하고, 전역 변수를 읽고 쓰고, 함수를 호출하고, Java 와 스크립트 사이에서 값을 변환한다. 핸들 클래스는 스크립트 객체, 배열, 함수에 대한 살아 있는 접근을 주며, JsHostFunction 은 스크립트가 Java 코드를 호출하는 방법이다. 이 패키지는 브라우저 클래스나 AWT, Swing 클래스를 필요로 하지 않는다(계획 항목 P26-02).
