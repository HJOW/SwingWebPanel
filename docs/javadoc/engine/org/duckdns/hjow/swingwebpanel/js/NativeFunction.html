public class NativeFunction
extends JsFunction

A function implemented in Java. This is the building block of every built-in function and of host (DOM) functions.

Define one with an anonymous class: 

 proto.defineBuiltin("toString", new NativeFunction(realm, "toString", 0, new NativeFunction.Call() {
     public JsValue call(JsRealm r, JsValue thisValue, JsValue[] args) { return Js.str("x"); }
 }));
Constructors additionally pass a NativeFunction.Construct; the function object is then a constructor. When a constructor is called without new the NativeFunction.Call part runs, so a built-in constructor normally supplies both.

Java 로 구현한 함수. 모든 내장 함수와 호스트(DOM) 함수의 기본 부품이다.

익명 클래스로 정의한다(위 예시 참조). 생성자는 추가로 NativeFunction.Construct 를 넘기며 그러면 함수 객체가 생성자가 된다. 생성자를 new 없이 호출하면 NativeFunction.Call 부분이 실행되므로 내장 생성자는 보통 둘 다 제공한다.
