public final class JsNumber
extends JsValue

The ECMAScript Number value: an IEEE 754 double with NaN, Infinity and negative zero preserved. Instances are immutable; small integers are cached by of(double).

ECMAScript 의 Number 값: IEEE 754 double 이며 NaN, Infinity, 음의 0 을 보존한다. 인스턴스는 불변이고 작은 정수는 of(double) 에서 캐시한다.
