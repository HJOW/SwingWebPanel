Class TypedLibInstaller

public class TypedLibInstaller
extends java.lang.Object
implements BuiltinInstaller

Installs the binary data library of ECMAScript 2015 into a realm: ArrayBuffer, DataView and the typed arrays Int8Array, Uint8Array, Uint8ClampedArray, Int16Array, Uint16Array, Int32Array, Uint32Array, Float16Array, Float32Array, Float64Array and the BigInt typed arrays together with the abstract %TypedArray% intrinsic. The standard built-in setup creates this class by name and calls install(JsRealm) after the core, the base library, the string/array library and the data library have been installed (so that Array.prototype.toString exists); if it does not exist yet, an equivalent function is created for %TypedArray%.prototype.toString.

ECMAScript 2015 의 이진 데이터 라이브러리를 realm 에 설치한다: ArrayBuffer, DataView, 형식화 배열 Int8Array, Uint8Array, Uint8ClampedArray, Int16Array, Uint16Array, Int32Array, Uint32Array, Float16Array, Float32Array, Float64Array, BigInt 형식화 배열과 추상 내장 객체 %TypedArray%. 표준 내장 객체 설정이 이 클래스를 이름으로 만들어 코어, 기본 라이브러리, 문자열/배열 라이브러리, 데이터 라이브러리를 설치한 뒤에 install(JsRealm) 을 호출한다(그래서 Array.prototype.toString 이 이미 있다). 아직 없으면 %TypedArray%.prototype.toString 을 위해 같은 동작의 함수를 만든다.
