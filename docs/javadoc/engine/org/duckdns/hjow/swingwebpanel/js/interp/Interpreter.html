org.duckdns.hjow.swingwebpanel.js.interp
Class Interpreter

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.interp.Interpreter

public final class Interpreter
extends java.lang.Object

The interpreter of one realm: it runs scripts, eval code and modules over the syntax tree produced by Parser. This class owns the global environment, function objects and calls (FunctionDeclarationInstantiation, [[Call]] and [[Construct]] of script functions), and the dynamic code entry points; expressions, statements, destructuring, classes, generators and modules are implemented by the collaborating classes of this package.

The interpreter must only be used from one thread at a time (the realm's owner thread). It is not re-entrant across threads.

realm 하나의 인터프리터: Parser 가 만든 구문 트리 위에서 스크립트, eval 코드, 모듈을 실행한다. 이 클래스는 전역 환경, 함수 객체와 호출(FunctionDeclarationInstantiation, 스크립트 함수의 [[Call]], [[Construct]]), 동적 코드 진입점을 담당하며, 표현식, 문장, 구조 분해, 클래스, 제너레이터, 모듈은 이 패키지의 협력 클래스가 구현한다.

인터프리터는 한 번에 한 스레드(realm 의 소유 스레드)에서만 써야 한다. 스레드 사이에서 재진입할 수 없다.
