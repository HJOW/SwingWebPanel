public enum ElementType
extends java.lang.Enum<ElementType>

The element types of typed arrays and the accessors of DataView: how many bytes an element takes, how a JavaScript number is converted into the stored bytes and how stored bytes are turned back into a number. Typed arrays always store little endian (ECMAScript leaves the platform endianness implementation-defined; this library chooses little endian); DataView passes the endianness of every call. Float32 and Float64 write canonical NaN bit patterns. Float16 carries the sign and available payload bits.

형식화 배열의 요소 형식과 DataView 접근자: 요소가 몇 바이트인지, JavaScript 숫자를 저장 바이트로 바꾸는 방법, 저장 바이트를 다시 숫자로 바꾸는 방법. 형식화 배열은 항상 리틀 엔디언으로 저장한다(ECMAScript 는 플랫폼 엔디언을 구현 정의로 남겨 두며 이 라이브러리는 리틀 엔디언을 고른다). DataView는 호출마다 엔디언을 받는다. Float32와 Float64는 표준 NaN 비트 패턴을 쓰며 Float16은 부호와 표현 가능한 페이로드 비트를 보존한다.
