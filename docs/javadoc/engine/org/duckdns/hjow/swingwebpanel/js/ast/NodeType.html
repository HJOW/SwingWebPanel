Class NodeType

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ast.NodeType

public final class NodeType
extends java.lang.Object

The node kinds of the syntax tree. Each constant documents how the generic fields of Node are used: a b c d (child nodes), list (child list), name, value, op, flag, fn (function description) and scope (scope description). Operators and property kinds are the integer constants of Op.

구문 트리의 노드 종류. 각 상수는 Node 의 범용 필드를 어떻게 쓰는지 설명한다: a b c d(자식 노드), list(자식 목록), name, value, op, flag, fn(함수 설명), scope(스코프 설명). 연산자와 프로퍼티 종류는 Op 의 정수 상수이다.
