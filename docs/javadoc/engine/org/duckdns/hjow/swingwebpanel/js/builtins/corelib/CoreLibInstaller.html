BuiltinInstaller
public final class CoreLibInstaller
extends java.lang.Object
implements BuiltinInstaller

Installs the fundamental ECMAScript 2015 built-in objects of this package into a realm: the Error family, Object, the methods of Function.prototype, Boolean, Symbol, the global functions and value properties, Number and Math. The engine's StandardBuiltins loads this class by name after its own minimal versions of Object, Function, Error, Symbol and Array, so the constructors and prototype members installed here replace the minimal ones (the prototype objects themselves are the realm's own, so objects that already exist keep working). It can also be used on a bare new JsRealm().

이 패키지의 ECMAScript 2015 기본 내장 객체를 realm 에 설치한다: Error 계열, Object, Function.prototype 의 메서드, Boolean, Symbol, 전역 함수와 전역 값 프로퍼티, Number, Math. 엔진의 StandardBuiltins 가 Object, Function, Error, Symbol, Array 의 자체 최소 구현을 설치한 뒤 이 클래스를 이름으로 불러 오므로 여기서 설치하는 생성자와 프로토타입 멤버가 최소 구현을 대체한다(프로토타입 객체 자체는 realm 의 것이라 이미 만들어진 객체는 계속 동작한다). 빈 new JsRealm() 에도 쓸 수 있다.
