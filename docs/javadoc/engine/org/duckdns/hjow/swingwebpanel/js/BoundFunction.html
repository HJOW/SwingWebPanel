public final class BoundFunction
extends JsFunction

A bound function exotic object (ECMA-262 6th edition 9.4.1), the result of Function.prototype.bind. Calling it calls the target function with the bound this value and the bound arguments followed by the call arguments.

바운드 함수 이국적 객체(ECMA-262 6판 9.4.1). Function.prototype.bind 의 결과이다. 호출하면 바인딩된 this 와 바인딩된 인수 뒤에 호출 인수를 붙여 대상 함수를 호출한다.

BoundFunction

public BoundFunction(JsRealm realm,
                     JsObject target,
                     JsValue boundThis,
                     JsValue[] boundArgs)
Creates a bound function. The name and length properties are set by the caller (Function.prototype.bind) because they depend on the target's properties.

바운드 함수를 만든다. name, length 프로퍼티는 대상의 프로퍼티에 따라 달라지므로 호출자(Function.prototype.bind)가 설정한다.
