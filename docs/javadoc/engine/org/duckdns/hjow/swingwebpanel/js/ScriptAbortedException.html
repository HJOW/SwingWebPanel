public final class ScriptAbortedException
extends java.lang.RuntimeException

Thrown when running script code is aborted by the host or by an execution limit (step limit, time limit, cancellation). It is a plain Java exception that script code can not catch and that does not run script finally blocks, so a runaway script cannot defeat the limit by catching the error. The host catches it around JsRealm.evaluateScript(String, String) and similar calls.

호스트가 실행을 중단했거나 실행 제한(단계 수, 시간, 취소)에 걸려 스크립트 실행이 중단될 때 던진다. 스크립트 코드가 잡을 수 없고 스크립트의 finally 블록도 실행하지 않는 일반 Java 예외이므로, 폭주하는 스크립트가 오류를 잡아 제한을 무력화할 수 없다. 호스트는 JsRealm.evaluateScript(String, String) 같은 호출 주위에서 이를 잡는다.
