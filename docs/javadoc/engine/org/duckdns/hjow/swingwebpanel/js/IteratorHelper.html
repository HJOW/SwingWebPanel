org.duckdns.hjow.swingwebpanel.js
Class IteratorHelper

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.IteratorHelper

public final class IteratorHelper
extends java.lang.Object

The iterator abstract operations of ECMA-262 6th edition 7.4 (GetIterator, IteratorNext, IteratorStep, IteratorClose, CreateIterResultObject) and a convenience to drain an iterable into a Java list. Built-ins that consume iterables (Array.from, Map, Set, Promise.all, spread ...) and the interpreter (for-of, destructuring, spread) use these methods so that the protocol, including closing the iterator on early exit, is implemented exactly once.

ECMA-262 6판 7.4 의 이터레이터 추상 연산(GetIterator, IteratorNext, IteratorStep, IteratorClose, CreateIterResultObject)과 반복 가능 객체를 Java 목록으로 모으는 편의 메서드. 반복 가능 객체를 소비하는 내장 객체(Array.from, Map, Set, Promise.all, 전개 ...)와 인터프리터(for-of, 구조 분해, 전개)가 이 메서드를 쓰므로, 조기 종료 시 이터레이터를 닫는 것을 포함한 프로토콜이 한 곳에만 구현된다.
