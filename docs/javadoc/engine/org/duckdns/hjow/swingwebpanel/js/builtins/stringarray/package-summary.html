Package org.duckdns.hjow.swingwebpanel.js.builtins.stringarray Description

ECMAScript 2015 built-in objects String and Array: constructors, static functions, prototype methods (including the Annex B HTML methods), the String and Array iterator objects and the shared helpers they use. The entry point is StringArrayInstaller, which the realm's standard built-in list loads after the core minimal built-ins.

ECMAScript 2015 내장 객체 String 과 Array: 생성자, 정적 함수, 프로토타입 메서드(부속서 B 의 HTML 메서드 포함), String/Array 이터레이터 객체와 이들이 공유하는 도우미. 진입점은 StringArrayInstaller 이며 realm 의 표준 내장 목록이 코어의 최소 내장 객체 뒤에 이 설치기를 적재한다.
