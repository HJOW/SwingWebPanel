org.duckdns.hjow.swingwebpanel.js.date
Class DateMath

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.date.DateMath

public final class DateMath
extends java.lang.Object

ECMAScript 2015 date arithmetic (ECMA-262 section 20.3.1) on time values: a double holding milliseconds since 1970-01-01T00:00:00Z, NaN for an invalid date, valid range +-8.64e15. Day numbers, year/month/day extraction, MakeTime, MakeDay, MakeDate, TimeClip and the local time conversions LocalTime and UTC are provided.

Local time uses an injectable TimeZone. For a local time that occurs twice (clock set back) or not at all (clock set forward) the offset in effect before the transition is used, as ES2015 requires. The lookup assumes that at most one offset transition happens within two days around the requested instant. Years are the proleptic Gregorian years of the specification, independent of the JRE calendar. All methods are static and thread-safe (a TimeZone instance is read only).

시간값(1970-01-01T00:00:00Z 이후 밀리초를 담은 double, 올바르지 않은 날짜는 NaN, 유효 범위 +-8.64e15) 위의 ECMAScript 2015 날짜 연산 (ECMA-262 20.3.1절). 날짜 번호, 연/월/일 추출, MakeTime, MakeDay, MakeDate, TimeClip, 지역 시간 변환 LocalTime 과 UTC 를 제공한다.

지역 시간은 주입할 수 있는 TimeZone 을 쓴다. 두 번 나타나는 지역 시간(시계를 되돌림)이나 아예 없는 지역 시간(시계를 앞당김)은 ES2015 규칙대로 전환 이전의 오프셋을 쓴다. 조회는 요청한 시각 앞뒤 이틀 안에 오프셋 전환이 많아야 한 번이라고 가정한다. 연도는 규격의 그레고리력 연도이며 JRE 달력과 무관하다. 모든 메서드는 정적이고 스레드 안전하다(TimeZone 은 읽기만 한다).
