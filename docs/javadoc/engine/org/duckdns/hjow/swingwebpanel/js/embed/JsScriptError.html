public final class JsScriptError
extends java.lang.RuntimeException

An error that script code threw (or that the engine raised while running script code) and that nobody caught inside the script. It is what JsEngine throws to its Java callers for a syntax error, for throw and for a runtime error such as a TypeError. It carries the name and the message of the JavaScript error, the position in the script where it happened (the position of a syntax error, or of the expression that failed or of the throw statement), and the thrown value as a Java value. An execution that the engine had to stop (step limit, time limit, cancellation) is not reported with this class but with ScriptAbortedException, because a script cannot catch it.

스크립트 코드가 던졌거나(또는 스크립트 코드를 실행하다 엔진이 일으켰고) 스크립트 안에서 아무도 잡지 않은 오류. JsEngine 이 구문 오류, throw, TypeError 같은 런타임 오류를 Java 호출자에게 알릴 때 던진다. JavaScript 오류의 이름과 메시지, 오류가 난 스크립트의 위치(구문 오류의 위치, 또는 실패한 표현식이나 throw 문의 위치), 던져진 값을 Java 값으로 담는다. 엔진이 멈춰야 했던 실행(단계 수 제한, 시간 제한, 취소)은 스크립트가 잡을 수 없으므로 이 클래스가 아니라 ScriptAbortedException 으로 알린다.
