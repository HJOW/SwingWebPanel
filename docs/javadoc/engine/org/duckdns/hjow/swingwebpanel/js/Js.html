public final class Js
extends java.lang.Object

Constants and small factories for ECMAScript values, meant to be used by built-in authors: Js.UNDEFINED, Js.num(1.5), Js.str("a"), Js.bool(true).

ECMAScript 값의 상수와 간단한 생성 도구. 내장 객체 작성자가 쓰도록 만들었다: Js.UNDEFINED, Js.num(1.5), Js.str("a"), Js.bool(true).
