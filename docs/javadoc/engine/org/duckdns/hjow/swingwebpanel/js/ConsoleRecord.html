Class ConsoleRecord

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ConsoleRecord

public final class ConsoleRecord
extends java.lang.Object

One message of the script's console object, or one diagnostic that the host reports on behalf of the script (an uncaught exception, an unhandled promise rejection, a dialog function). It is immutable and holds only Java strings and numbers, never a reference to a script object, so a host may keep it and hand it to another thread. A host that wants the structured form implements ConsoleRecordHook; every other ConsoleHook receives getText() and getLegacyLevel() as before.

스크립트의 console 객체의 메시지 하나, 또는 호스트가 스크립트를 대신해 보고하는 진단 하나(잡히지 않은 예외, 처리되지 않은 promise 거부, 대화 상자 함수). 불변이며 Java 문자열과 숫자만 가지고 스크립트 객체를 참조하지 않으므로 호스트가 보관하거나 다른 스레드에 넘겨도 된다. 구조화된 형태가 필요한 호스트는 ConsoleRecordHook 을 구현하고, 다른 ConsoleHook 은 지금까지처럼 getText() 와 getLegacyLevel() 을 받는다.
