public class JsObject
extends JsWeakKey

An ECMAScript object with the ordinary object internal methods of ECMA-262 6th edition 9.1: [[GetPrototypeOf]], [[SetPrototypeOf]], [[IsExtensible]], [[PreventExtensions]], [[GetOwnProperty]], [[DefineOwnProperty]], [[HasProperty]], [[Get]], [[Set]], [[Delete]], [[OwnPropertyKeys]] (and [[Call]]/[[Construct]] for function subclasses). Exotic objects (arrays, string wrappers, arguments, proxies, host objects) subclass this class and override the internal methods; every other part of the engine goes through these methods only.

Property keys are String or JsSymbol objects held in a Java Object reference. Own keys are listed in the order required by 9.1.12: array indices ascending, then strings in creation order, then symbols in creation order.

Built-in authors mostly use the convenience methods: get(Object), set(Object, JsValue), setStrict(Object, JsValue), defineBuiltin(Object, JsValue), defineData(Object, JsValue, boolean, boolean, boolean), defineAccessor(Object, JsObject, JsObject, boolean, boolean), createDataProperty(Object, JsValue).

ECMA-262 6판 9.1 의 일반 객체 내부 메서드를 가진 ECMAScript 객체: [[GetPrototypeOf]], [[SetPrototypeOf]], [[IsExtensible]], [[PreventExtensions]], [[GetOwnProperty]], [[DefineOwnProperty]], [[HasProperty]], [[Get]], [[Set]], [[Delete]], [[OwnPropertyKeys]] (함수 하위 클래스는 [[Call]]/[[Construct]] 도). 이국적 객체(배열, 문자열 래퍼, arguments, 프록시, 호스트 객체)는 이 클래스를 상속해 내부 메서드를 재정의하며, 엔진의 다른 부분은 이 메서드들만 거쳐 접근한다.

프로퍼티 키는 Java Object 참조에 담긴 String 또는 JsSymbol 이다. 자체 키 나열 순서는 9.1.12 를 따른다: 배열 인덱스 오름차순, 문자열(생성 순서), 심볼(생성 순서).

내장 객체 작성자는 주로 편의 메서드를 쓴다: get(Object), set(Object, JsValue), setStrict(Object, JsValue), defineBuiltin(Object, JsValue), defineData(Object, JsValue, boolean, boolean, boolean), defineAccessor(Object, JsObject, JsObject, boolean, boolean), createDataProperty(Object, JsValue).
