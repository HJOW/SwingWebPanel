Class JsCompiledScript

java.lang.Object
  javax.script.CompiledScript
      org.duckdns.hjow.swingwebpanel.js.script.JsCompiledScript

public final class JsCompiledScript
extends javax.script.CompiledScript

A script that a JsScriptEngine parsed in advance (Compilable.compile(String)). Parsing found the syntax errors; every eval runs the parsed script without parsing it again, in the scope of the context that is given to eval. Like the engine that created it, it may be used from any thread.

JsScriptEngine 이 미리 파싱한 스크립트(Compilable.compile(String)). 파싱할 때 구문 오류를 찾았으며, eval 은 다시 파싱하지 않고 파싱된 스크립트를 eval 에 준 컨텍스트의 스코프에서 실행한다. 만든 엔진처럼 어느 스레드에서나 쓸 수 있다.
