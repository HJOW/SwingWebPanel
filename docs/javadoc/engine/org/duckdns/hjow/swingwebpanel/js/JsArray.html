public class JsArray
extends JsObject

An Array exotic object (ECMA-262 6th edition 9.4.2). Elements are kept in a dense Java array while the array is "plain" (all elements writable, enumerable and configurable, no huge gaps); the array silently switches to a sparse mode that stores indices as ordinary properties when needed (for example after Object.defineProperty(a, 0, {writable:false}) or a[1e9] = 1). The virtual "length" property follows ArraySetLength (9.4.2.4).

Built-in authors can use add(JsValue) to fill a fresh array quickly and getLength() for the length; generic algorithms should go through JsObject.get(Object) so that they also work for array-like objects.

Array 이국적 객체(ECMA-262 6판 9.4.2). 배열이 "평범"하면(모든 요소가 writable, enumerable, configurable 이고 큰 빈 구간이 없으면) 요소를 조밀한 Java 배열에 보관하고, 필요하면(Object.defineProperty(a, 0, {writable:false}) 나 a[1e9] = 1 등) 인덱스를 일반 프로퍼티로 저장하는 희소 모드로 조용히 전환한다. 가상 "length" 프로퍼티는 ArraySetLength(9.4.2.4)를 따른다.

내장 객체 작성자는 새 배열을 빠르게 채울 때 add(JsValue), 길이는 getLength() 를 쓸 수 있다. 일반 알고리즘은 유사 배열 객체에서도 동작하도록 JsObject.get(Object) 를 거치는 것이 좋다.
