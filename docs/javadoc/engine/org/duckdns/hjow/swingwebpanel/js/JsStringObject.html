public class JsStringObject
extends JsObject

A String exotic object (ECMA-262 6th edition 9.4.3): a wrapper around a primitive string that exposes the code units as read-only enumerable index properties and a read-only "length" property.

String 이국적 객체(ECMA-262 6판 9.4.3): 원시 문자열을 감싸며 코드 단위를 읽기 전용 열거 가능 인덱스 프로퍼티로, 길이를 읽기 전용 "length" 프로퍼티로 보여 준다.
