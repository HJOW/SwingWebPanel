Interface BuiltinInstaller

All Known Implementing Classes:
CoreLibInstaller, DataLibInstaller, IteratorBuiltins, MetaLibInstaller, StringArrayInstaller, TypedLibInstaller
public interface BuiltinInstaller

Installs a group of built-in objects into a realm (for example "Math", or "Map and Set"). Implementations create the constructor and prototype objects, define their properties and register them on the realm (realm.getGlobalObject().defineBuiltin("Math", math) and, for objects needed elsewhere, realm.setIntrinsic("%MapPrototype%", proto)). Installers run once per realm, in the order given by the realm factory.

내장 객체 묶음(예: "Math", "Map 과 Set")을 realm 에 설치한다. 구현체는 생성자와 프로토타입 객체를 만들고 프로퍼티를 정의한 뒤 realm 에 등록한다(realm.getGlobalObject().defineBuiltin("Math", math), 다른 곳에서 필요한 객체는 realm.setIntrinsic("%MapPrototype%", proto)). 설치기는 realm 마다 한 번, realm 팩터리가 정한 순서로 실행된다.
