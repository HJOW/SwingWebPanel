Class CharClass

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.text.CharClass

public final class CharClass
extends java.lang.Object

Character classification used by the ECMAScript lexer, regular expressions and string conversions: WhiteSpace, LineTerminator, decimal/hex digits and the ID_Start / ID_Continue identifier classes.

Identifier and space separator data is shared with regular expressions through UnicodeProperties.

ECMAScript 렉서, 정규식, 문자열 변환에서 쓰는 문자 분류: WhiteSpace, LineTerminator, 10진/16진 숫자, ID_Start / ID_Continue 식별자 분류.

식별자와 공백 구분자 데이터는 UnicodeProperties를 통해 정규식과 공유한다.
