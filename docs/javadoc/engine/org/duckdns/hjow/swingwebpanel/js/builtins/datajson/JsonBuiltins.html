Class JsonBuiltins

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.datajson.JsonBuiltins

public final class JsonBuiltins
extends java.lang.Object

The built-in JSON object (ECMA-262 6th edition 24.3): JSON.parse with reviver and JSON.stringify with replacer function, replacer property list, indentation, toJSON, wrapper object unboxing and cycle detection. Text scanning comes from JsonTokenizer and string quoting from JsonText; neither eval nor Java serialization is used.

Design notes: parsing is iterative, so any nesting depth of the input text works; creating objects uses CreateDataProperty, so a key named __proto__ becomes an ordinary own property. Serializing and reviving walk the value recursively and stop with a RangeError deeper than MAX_DEPTH levels (a Java stack overflow would otherwise kill the engine).

내장 JSON 객체(ECMA-262 6판 24.3): reviver 가 있는 JSON.parse 와 replacer 함수, replacer 속성 목록, 들여쓰기, toJSON, 래퍼 객체 풀기, 순환 검출이 있는 JSON.stringify. 텍스트 읽기는 JsonTokenizer, 문자열 인용은 JsonText 를 쓰며 eval 도 Java 직렬화도 쓰지 않는다.

설계 메모: 파싱은 반복 방식이라 입력 텍스트의 중첩 깊이에 제한이 없고, 객체는 CreateDataProperty 로 만들므로 __proto__ 라는 키도 평범한 자체 프로퍼티가 된다. 직렬화와 reviver 는 값을 재귀로 훑으며 MAX_DEPTH 단계보다 깊으면 RangeError 로 멈춘다(Java 스택 오버플로가 엔진을 죽이지 않도록).
