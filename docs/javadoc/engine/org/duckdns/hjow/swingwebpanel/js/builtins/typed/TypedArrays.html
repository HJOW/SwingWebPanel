Class TypedArrays

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.typed.TypedArrays

public final class TypedArrays
extends java.lang.Object

Stable Java API for the rest of the library (canvas ImageData, XMLHttpRequest and Fetch bodies, Blob, media decoders) to create and read the binary objects of a realm without going through script calls. The realm must have been prepared with TypedLibInstaller. Buffers can wrap an existing byte[] without copying; views never copy; arguments are checked and wrong ones throw IllegalArgumentException.

라이브러리의 다른 부분(캔버스 ImageData, XMLHttpRequest 와 Fetch 본문, Blob, 미디어 디코더)이 스크립트 호출 없이 realm 의 이진 객체를 만들고 읽을 수 있게 하는 안정적인 Java API. realm 은 TypedLibInstaller 로 준비되어 있어야 한다. 버퍼는 기존 byte[] 를 복사 없이 감쌀 수 있고, 뷰는 절대 복사하지 않으며, 인수를 검사해 잘못된 것은 IllegalArgumentException 을 던진다.
