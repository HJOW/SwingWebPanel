Class StandardBuiltins

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.StandardBuiltins

public final class StandardBuiltins
extends java.lang.Object

Installs the standard built-in objects into a realm, in a fixed order. First come the minimal built-ins that the language itself needs (Object, Function, Error types, Symbol, iterators and generators, Array basics, primitive wrappers, global functions and the console); after them the optional installers of the full built-in library are loaded by class name. A class that does not exist is silently skipped (so that library parts can be delivered independently); any other failure, including an exception thrown by an installer, propagates.

Later installers may extend or override properties created by earlier ones with JsObject.defineBuiltin(java.lang.Object, org.duckdns.hjow.swingwebpanel.js.JsValue); all minimal definitions are therefore writable and configurable as the specification says.

표준 내장 객체를 정해진 순서로 realm 에 설치한다. 먼저 언어 자체가 필요로 하는 최소 내장 객체(Object, Function, 오류 형식, Symbol, 이터레이터와 제너레이터, Array 기본, 원시 값 래퍼, 전역 함수, 콘솔)를 설치하고, 그 뒤에 전체 내장 라이브러리의 선택적 설치기를 클래스 이름으로 불러온다. 존재하지 않는 클래스는 조용히 건너뛰며(라이브러리의 각 부분을 따로 전달할 수 있도록), 설치기가 던진 예외를 포함한 그 밖의 실패는 그대로 전파한다.

뒤의 설치기는 JsObject.defineBuiltin(java.lang.Object, org.duckdns.hjow.swingwebpanel.js.JsValue) 으로 앞의 설치기가 만든 프로퍼티를 확장하거나 덮어쓸 수 있다. 그래서 모든 최소 정의는 규격대로 writable 이고 configurable 이다.
