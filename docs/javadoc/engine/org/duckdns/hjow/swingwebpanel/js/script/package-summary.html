Package org.duckdns.hjow.swingwebpanel.js.script Description

The Java Scripting API (JSR 223, javax.script) provider of the stand-alone JavaScript engine: a JsScriptEngineFactory (registered under the unique name swingwebpanel-js) that creates JsScriptEngines, which implement ScriptEngine, Compilable and Invocable on top of JsEngine. This is the only package of the project (apart from its tests and the example that shows its use) that may use javax.script; the engine never delegates to the Rhino or Nashorn engine of the Java runtime (plan items P26-04 and P26-05).

독립 JavaScript 엔진의 Java Scripting API(JSR 223, javax.script) 제공자: 고유한 이름 swingwebpanel-js 로 등록된 JsScriptEngineFactory 가 JsScriptEngine 을 만들고, 이것이 JsEngine 위에서 ScriptEngine, Compilable, Invocable 을 구현한다. 이 프로젝트에서 javax.script 를 쓸 수 있는 유일한 패키지이다(시험과 그 사용을 보여 주는 예제는 제외). 엔진은 Java 런타임의 Rhino 나 Nashorn 엔진에 위임하지 않는다 (계획 항목 P26-04, P26-05).
