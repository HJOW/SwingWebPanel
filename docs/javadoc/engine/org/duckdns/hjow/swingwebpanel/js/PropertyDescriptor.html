org.duckdns.hjow.swingwebpanel.js
Class PropertyDescriptor

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.PropertyDescriptor

public final class PropertyDescriptor
extends java.lang.Object

A Property Descriptor specification type (ECMA-262 6th edition 6.2.4). Every field may be absent: a Java null field means "absent" (not specified), unlike a JavaScript value. For get and set the present values are either a callable object or Js.UNDEFINED. Use isAccessor(), isData() and isGeneric() to classify it.

프로퍼티 기술자 명세 형식(ECMA-262 6판 6.2.4). 모든 필드는 없을 수 있다. Java null 필드는 "지정되지 않음"을 뜻하며 JavaScript 값이 아니다. get, set 이 있으면 호출 가능 객체 또는 Js.UNDEFINED 이다. 분류에는 isAccessor(), isData(), isGeneric() 를 사용한다.
