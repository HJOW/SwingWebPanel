public static final class ProgramInfo.ExportEntry
extends java.lang.Object

An export entry. A local export has a localName and no moduleRequest; an indirect export has moduleRequest and importName (importName "*" with exportName null is export * from).

export 항목. 로컬 export 는 localName 이 있고 moduleRequest 가 없다. 간접 export 는 moduleRequest 와 importName 이 있다 (exportName 이 null 이고 importName 이 "*" 이면 export * from).
