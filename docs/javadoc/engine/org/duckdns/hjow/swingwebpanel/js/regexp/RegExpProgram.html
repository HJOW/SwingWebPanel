org.duckdns.hjow.swingwebpanel.js.regexp
Class RegExpProgram

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.regexp.RegExpProgram

public final class RegExpProgram
extends java.lang.Object

A compiled ECMAScript regular expression. It is immutable apart from the two resource limits, so one program can be executed by several threads at the same time (each execution has its own matcher state).

Matching works on UTF-16 strings. Without the u flag characters are code units; with the u flag they are code points (a surrogate pair is one character). Flags g and y are not interpreted here: the caller chooses the start index and decides between exec(String, int) (scan forward, as for the global flag or a plain exec) and matchAt(String, int) (match exactly at the index, as for the sticky flag). Results are arrays of 2 * (groupCount + 1) ints: start and end offset of the whole match followed by start and end of every group, -1 for groups that did not participate.

Protection against catastrophic backtracking: every execution counts steps and fails with RegExpLimitException when more than getStepLimit() steps are used or when the backtracking stack holds more than getMaxBacktrackEntries() entries; an optional RegExpCancel is polled every 1024 steps.

컴파일된 ECMAScript 정규식. 두 가지 자원 제한을 빼면 불변이므로 한 프로그램을 여러 스레드가 동시에 실행할 수 있다(실행마다 자기 일치 상태를 가진다).

일치 검색은 UTF-16 문자열 위에서 한다. u 플래그가 없으면 문자는 코드 단위이고, 있으면 코드 포인트(서로게이트 쌍이 한 문자)이다. 플래그 g 와 y 는 여기서 해석하지 않는다. 호출자가 시작 위치를 정하고 exec(String, int) (앞쪽으로 훑음: 전역 플래그나 일반 exec)와 matchAt(String, int) (정확히 그 위치에서 일치: 고정 플래그) 중 하나를 고른다. 결과는 2 * (groupCount + 1) 개의 int 배열이다: 전체 일치의 시작/끝 위치, 이어서 각 그룹의 시작/끝 위치이며 참여하지 않은 그룹은 -1 이다.

치명적인 역추적 방어: 실행마다 단계를 세어 getStepLimit() 보다 많이 쓰거나 역추적 스택이 getMaxBacktrackEntries() 개보다 많아지면 RegExpLimitException 으로 실패한다. 선택적인 RegExpCancel 은 1024 단계마다 확인한다.
