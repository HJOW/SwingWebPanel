org.duckdns.hjow.swingwebpanel.js
Class ExecutionLimits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ExecutionLimits

public final class ExecutionLimits
extends java.lang.Object

Execution limits and cancellation of one realm (plan item P13-12). The interpreter calls tick() for every executed statement, loop iteration and function call, and built-ins that run long loops should call tick() too.

  • Steps: after getMaxSteps() ticks in one task a ScriptAbortedException (STEP_LIMIT) is thrown. Default 200 million.
  • Time: after getMaxTimeMillis() milliseconds of one task a ScriptAbortedException (TIME_LIMIT) is thrown. Default 0 = unlimited (the host normally sets a value).
  • Cancellation: cancel() may be called from any thread; the running script stops at the next tick with ScriptAbortedException (CANCELLED). reset() clears the flag.
  • Call depth: more than getMaxCallDepth() nested script calls throw a script-visible RangeError "Maximum call stack size exceeded". Default 400. Each script call uses several Java stack frames, so run the engine on a thread with a large stack (for example 16 MB) when raising this value.
  • String length: strings longer than getMaxStringLength() code units cannot be created by concatenation or repetition (RangeError "Invalid string length"). Default 33,554,432.
  • Array length: arrays with a dense storage are limited by memory; the JavaScript maximum 2^32 - 1 applies to the length property. A script cannot allocate more than 50 million dense elements (larger indices switch to sparse mode).
Time and steps are measured per task: the host (or the realm's JsRealm.evaluateScript(String, String)) calls beginTask() when the outermost script call starts.

realm 하나의 실행 제한과 취소(계획 P13-12). 인터프리터는 실행하는 문장, 반복 한 번, 함수 호출마다 tick() 을 호출하며, 긴 반복을 도는 내장 함수도 tick() 을 호출해야 한다.

  • 단계 수: 한 작업에서 getMaxSteps() 번 넘으면 ScriptAbortedException(STEP_LIMIT). 기본 2억.
  • 시간: 한 작업이 getMaxTimeMillis() 밀리초를 넘으면 ScriptAbortedException(TIME_LIMIT). 기본 0 = 무제한(호스트가 보통 지정).
  • 취소: cancel() 은 어느 스레드에서나 호출할 수 있고, 실행 중인 스크립트는 다음 tick 에서 ScriptAbortedException(CANCELLED)으로 멈춘다. reset() 이 표시를 지운다.
  • 호출 깊이: 중첩된 스크립트 호출이 getMaxCallDepth() 를 넘으면 스크립트가 볼 수 있는 RangeError "Maximum call stack size exceeded". 기본 400. 스크립트 호출마다 Java 스택 프레임이 여러 개 쓰이므로 값을 올릴 때는 큰 스택(예: 16MB)의 스레드에서 엔진을 실행한다.
  • 문자열 길이: getMaxStringLength() 코드 단위를 넘는 문자열은 연결이나 반복으로 만들 수 없다(RangeError "Invalid string length"). 기본 33,554,432.
  • 배열 길이: 조밀 저장 배열은 메모리로 제한된다. length 프로퍼티는 JavaScript 최댓값 2^32 - 1 이다. 조밀 요소는 5천만 개를 넘지 못하며 더 큰 인덱스는 희소 모드로 바뀐다.
시간과 단계 수는 작업 단위로 측정한다: 호스트(또는 realm 의 JsRealm.evaluateScript(String, String))가 가장 바깥 스크립트 호출이 시작될 때 beginTask() 를 호출한다.

isAbortRequested

public boolean isAbortRequested()
Non-throwing query for long running native code (regular expression matching, built-in loops): returns true when the running task should stop because cancellation was requested or the time limit of the task is exceeded. Step counting is not part of this query. Safe to call from the thread that runs the script at any frequency.

오래 걸리는 네이티브 코드(정규식 일치, 내장 객체의 반복)용 비예외 조회: 취소가 요청되었거나 작업의 시간 제한을 넘어 실행 중인 작업을 멈춰야 하면 true 를 반환한다. 단계 수는 이 조회에 포함되지 않는다. 스크립트를 실행하는 스레드에서 얼마든지 자주 호출해도 된다.

Returns:
true if the task should stop / 작업을 멈춰야 하면 true

poll

public void poll()
Throwing variant of isAbortRequested() for long running native loops: throws ScriptAbortedException (CANCELLED or TIME_LIMIT) when the task must stop. Built-ins that loop over large inputs should call it every few thousand iterations.

오래 걸리는 네이티브 반복을 위한 isAbortRequested() 의 예외 버전: 작업을 멈춰야 하면 ScriptAbortedException (CANCELLED 또는 TIME_LIMIT)을 던진다. 큰 입력을 반복하는 내장 객체는 수천 번 반복마다 호출해야 한다.
