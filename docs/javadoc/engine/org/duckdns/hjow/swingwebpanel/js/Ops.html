org.duckdns.hjow.swingwebpanel.js
Class Ops

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.Ops

public final class Ops
extends java.lang.Object

The abstract operations of ECMA-262 6th edition clauses 7.1 (type conversion), 7.2 (testing and comparison) and 7.3 (operations on objects), implemented once so that the interpreter and every built-in share the same JavaScript semantics. Java equals, int casts and string concatenation must not replace these operations. Methods that may run user code (valueOf, toString, getters) can throw JsException.

ECMA-262 6판 7.1(형 변환), 7.2(검사와 비교), 7.3(객체 연산)의 추상 연산을 한 곳에 구현하여 인터프리터와 모든 내장 객체가 같은 JavaScript 의미를 공유하게 한다. Java 의 equals, int 캐스트, 문자열 연결로 이 연산을 대신해서는 안 된다. 사용자 코드(valueOf, toString, getter)를 실행할 수 있는 메서드는 JsException 을 던질 수 있다.
