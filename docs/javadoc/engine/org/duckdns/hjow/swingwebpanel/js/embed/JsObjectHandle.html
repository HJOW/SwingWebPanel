public class JsObjectHandle
extends java.util.AbstractMap<java.lang.String,java.lang.Object>
implements JsHandle

A live view of a script object as a Map<String, Object>. The entries are the enumerable own properties with string keys (what Object.keys returns), in the order of the script. get reads any property including inherited and non-enumerable ones (a missing property gives null, a property that holds undefined gives JsEngine.UNDEFINED), put assigns a property (strictly: assigning to a read-only property throws), and remove deletes it (a property that cannot be deleted, such as a global var, is set to undefined instead). Values follow the conversion rules of JsEngine. Two handles are equal when they refer to the same script object; the equals, hashCode and toString of the Map interface are not used because they would not terminate for an object that contains itself.

스크립트 객체를 Map<String, Object> 로 보여 주는 살아 있는 보기. 항목은 열거 가능한 고유 문자열 키 프로퍼티(Object.keys 가 돌려주는 것)이며 스크립트의 순서를 따른다. get 은 상속된 것과 열거 불가인 것을 포함해 모든 프로퍼티를 읽고(없는 프로퍼티는 null, undefined 를 담은 프로퍼티는 JsEngine.UNDEFINED), put 은 프로퍼티를 대입하며(엄격하게: 읽기 전용 프로퍼티에 대입하면 예외), remove 는 삭제한다(전역 var 처럼 삭제할 수 없는 프로퍼티는 대신 undefined 로 만든다). 값은 JsEngine 의 변환 규칙을 따른다. 핸들 두 개는 같은 스크립트 객체를 가리킬 때 같다. 자기 자신을 포함한 객체에서는 끝나지 않으므로 Map 인터페이스의 equals, hashCode, toString 은 쓰지 않는다.
