public final class ProxyObject
extends JsObject

A Proxy exotic object (ECMA-262 6th edition 9.5). Every internal method looks up the matching trap on the handler; without a trap it forwards to the target. When a trap answers, the result is checked against the invariants that the spec derives from the state of the target (non-configurable properties, non-extensible targets, frozen data properties, key lists), and a violated invariant is a TypeError. After revoke() every operation fails with a TypeError.

Assumptions where the 6th edition text could not be read: key lists returned by ownKeys must not contain duplicates (the rule of later editions, stricter than ES2015); [[GetOwnProperty]] checks only the configurable invariants of ES2015 (the later non-writable check is not applied); [[Delete]] does not check the extensibility of the target (later editions do).

Proxy 이국적 객체(ECMA-262 6판 9.5). 모든 내부 메서드는 핸들러에서 같은 이름의 trap 을 찾고, trap 이 없으면 대상에 전달한다. trap 이 답하면 대상의 상태에서 규격이 유도한 불변 조건(설정 불가 프로퍼티, 확장 불가 대상, 얼려진 데이터 프로퍼티, 키 목록)에 맞는지 검사하며 어기면 TypeError 이다. revoke() 뒤에는 모든 연산이 TypeError 로 실패한다.

6판 본문을 읽지 못해 둔 가정: ownKeys 가 돌려준 키 목록에는 중복이 없어야 한다(ES2015 보다 엄격한 후속 판의 규칙). [[GetOwnProperty]] 는 ES2015 의 설정 가능 불변 조건만 검사한다(후속 판의 writable 검사는 적용하지 않음). [[Delete]] 는 대상의 확장 가능 여부를 검사하지 않는다(후속 판은 검사함).
