Class TypedArrayObject

public class TypedArrayObject
extends JsObject

A typed array: an integer-indexed exotic object (ECMA-262 6th edition, 9.4.5) that shows a window of an ArrayBufferObject as a list of numbers of one ElementType. Properties whose key is a canonical numeric string ("0", "12", "-0", "1.5", "NaN", "Infinity", ...) never reach the ordinary property table: valid integer indices read and write the buffer, every other numeric key is simply absent (reads give undefined, writes are ignored) and the prototype chain is not consulted for them. The element properties are writable, enumerable and not configurable. Writes to invalid indices are ignored without error (the behavior of ECMAScript 2017 and later and of browsers; the 2015 text would make a strict mode assignment fail). A detached buffer makes the array behave as empty.

형식화 배열: ArrayBufferObject 의 한 구간을 한 ElementType 숫자 목록으로 보여 주는 정수 인덱스 이국적 객체 (ECMA-262 6판, 9.4.5). 키가 정규 숫자 문자열("0", "12", "-0", "1.5", "NaN", "Infinity" 등)인 프로퍼티는 일반 프로퍼티 표에 들어가지 않는다: 올바른 정수 인덱스는 버퍼를 읽고 쓰며, 그 밖의 숫자 키는 아예 없는 것으로 취급되어(읽으면 undefined, 쓰기는 무시) 프로토타입 체인도 보지 않는다. 요소 프로퍼티는 writable, 열거 가능, configurable 아님이다. 잘못된 인덱스에 쓰는 것은 오류 없이 무시한다(ECMAScript 2017 이후와 브라우저의 동작이며, 2015 본문은 엄격 모드 대입을 실패시킨다). 버퍼가 분리되면 배열은 빈 것처럼 동작한다.
