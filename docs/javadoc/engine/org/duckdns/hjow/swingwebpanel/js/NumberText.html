Class NumberText

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.NumberText

public final class NumberText
extends java.lang.Object

Number to string and string to number conversion used by the engine core. It is a thin facade over the exact algorithms of org.duckdns.hjow.swingwebpanel.js.num.NumberConversion (shortest round-trip digits, radix conversion, correctly rounded parsing), so the core never calls the JDK number formatting directly and Number.MIN_VALUE prints as 5e-324.

엔진 코어가 쓰는 숫자-문자열 변환. org.duckdns.hjow.swingwebpanel.js.num.NumberConversion 의 정확한 알고리즘(최단 왕복 자릿수, 진법 변환, 올바르게 반올림하는 파싱) 위에 얹은 얇은 외관이며, 그래서 코어는 JDK 숫자 서식을 직접 호출하지 않고 Number.MIN_VALUE 는 5e-324 로 출력된다.
