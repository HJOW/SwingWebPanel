Package org.duckdns.hjow.swingwebpanel.js.text

Text helpers independent of the JavaScript value model: character classification, URI coding, legacy escape, normalization, case conversion, code point helpers and JSON text helpers.

See:
          Description

Class Summary
CharClass Character classification used by the ECMAScript lexer, regular expressions and string conversions: WhiteSpace, LineTerminator, decimal/hex digits and the ID_Start / ID_Continue identifier classes.
CodePoints Code point oriented helpers behind String.prototype.codePointAt, String.fromCodePoint, String.fromCharCode and String.raw.
JsonText JSON string quoting for JSON.stringify, independent of JavaScript values.
JsonTokenizer Pull tokenizer for strict JSON text (RFC 8259 / ECMA-404 grammar as used by JSON.parse), independent of JavaScript values.
LegacyEscape ECMAScript Annex B legacy functions escape and unescape (B.2.1, B.2.2).
TextTransform String transformations used by String.prototype: normalize, toUpperCase/toLowerCase (and the locale variants), trim, repeat.
UnicodeCase Default Unicode case conversion and simple case folding for ECMAScript.
UnicodeProperties Exact ECMAScript Unicode property names and ranges shared by the lexer and RegExp engine.
UriCodec ECMAScript 2015 URI handling functions (section 18.2.6): encodeURI, encodeURIComponent, decodeURI and decodeURIComponent operating on UTF-16 strings.
 

Exception Summary
JsonSyntaxException Signals invalid JSON text found by JsonTokenizer.
TextRangeException Signals an argument that ECMAScript reports as a RangeError (invalid normalization form, invalid code point, repeat count out of range ...).
UriFormatException Signals malformed input to encodeURI, encodeURIComponent, decodeURI or decodeURIComponent: a lone surrogate while encoding, or a bad percent sequence or bad UTF-8 while decoding.
