Class Property

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.Property

public final class Property
extends java.lang.Object

Stored form of an own property: either a data property (value + writable) or an accessor property (getter + setter), plus the enumerable and configurable attributes. Instances live inside the property table of a JsObject and are mutated in place; built-in authors normally use PropertyDescriptor and the helper methods of JsObject instead of touching this class.

자체 프로퍼티의 저장 형태: 데이터 프로퍼티(값 + writable) 또는 접근자 프로퍼티(getter + setter)와 enumerable, configurable 속성. 인스턴스는 JsObject 의 프로퍼티 표 안에 있으며 제자리에서 바뀐다. 내장 객체 작성자는 보통 이 클래스 대신 PropertyDescriptor 와 JsObject 의 도우미 메서드를 사용한다.
