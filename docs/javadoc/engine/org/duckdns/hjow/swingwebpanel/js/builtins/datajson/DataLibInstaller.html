public final class DataLibInstaller
extends java.lang.Object
implements BuiltinInstaller

Installs the built-in objects of this package into a realm: Date, RegExp, JSON, Map, Set, WeakMap and WeakSet. The standard realm factory loads this class by its name after the core, corelib and stringarray installers. Installation order inside this class does not matter except that the intrinsics %IteratorPrototype% (created with the realm) and the global object must exist.

이 패키지의 내장 객체 Date, RegExp, JSON, Map, Set, WeakMap, WeakSet 을 realm 에 설치한다. 표준 realm 팩터리가 core, corelib, stringarray 설치기 다음에 이 클래스를 이름으로 불러 쓴다. realm 과 함께 만들어지는 %IteratorPrototype% 와 전역 객체가 있어야 하는 것 외에는 이 클래스 안의 설치 순서가 중요하지 않다.
