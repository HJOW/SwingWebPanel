public final class JsGlobalBindings
extends java.util.AbstractMap<java.lang.String,java.lang.Object>
implements javax.script.Bindings

The ENGINE_SCOPE bindings of the default context of a JsScriptEngine: a live view of the global object of the engine. engine.put("x", 1) is globalThis.x = 1, and a var, function declaration or assignment of a script is visible through engine.get("x"). Values follow the conversion rules of JsEngine with one difference that fits the Java Scripting API: a script value undefined reads as null. The keys follow the contract of Bindings: a null key is a NullPointerException, a key that is not a string is a ClassCastException, an empty key is an IllegalArgumentException. The enumerable global variables are the entries; the built-in objects are readable by name but are not entries. A global declared with var cannot be deleted from a JavaScript global object, so remove sets it to undefined.

JsScriptEngine 의 기본 컨텍스트의 ENGINE_SCOPE 바인딩: 엔진의 전역 객체에 대한 살아 있는 보기. engine.put("x", 1) 은 globalThis.x = 1 이며, 스크립트의 var, 함수 선언, 대입은 engine.get("x") 로 보인다. 값은 JsEngine 의 변환 규칙을 따르되 Java Scripting API 에 맞춘 차이 하나가 있다: 스크립트 값 undefined 는 null 로 읽힌다. 키는 Bindings 의 규약을 따른다: null 키는 NullPointerException, 문자열이 아닌 키는 ClassCastException, 빈 키는 IllegalArgumentException. 항목은 열거 가능한 전역 변수이며 내장 객체는 이름으로 읽을 수 있지만 항목은 아니다. var 로 선언한 전역은 JavaScript 전역 객체에서 삭제할 수 없으므로 remove 는 그것을 undefined 로 만든다.
