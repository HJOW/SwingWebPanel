Interface ConsoleHook

ConsoleRecordHook
public interface ConsoleHook

The host hook that receives output of the script's console object and the test-only print function. The host decides where the text goes (a log, a developer console panel, standard output).

스크립트의 console 객체와 시험용 print 함수의 출력을 받는 호스트 연결 지점. 텍스트를 어디로 보낼지(로그, 개발자 콘솔 창, 표준 출력)는 호스트가 정한다.
