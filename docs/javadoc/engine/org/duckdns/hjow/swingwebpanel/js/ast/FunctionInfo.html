Class FunctionInfo

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ast.FunctionInfo

public final class FunctionInfo
extends java.lang.Object

Everything the interpreter needs to know about a function, class constructor, method or arrow function, computed by the parser: parameters, body, kind flags, strictness and the scope of the body.

인터프리터가 함수, 클래스 생성자, 메서드, 화살표 함수에 대해 알아야 하는 모든 정보. 파서가 계산한다: 매개변수, 본문, 종류 플래그, 엄격 여부, 본문 스코프.
