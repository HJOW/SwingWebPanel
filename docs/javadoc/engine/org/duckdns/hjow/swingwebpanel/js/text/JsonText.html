Class JsonText

public final class JsonText
extends java.lang.Object

JSON string quoting for JSON.stringify, independent of JavaScript values. quote(String) implements the ECMAScript 2015 behavior: only the quotation mark, the backslash and code units below U+0020 are escaped (\b \f \n \r \t or a lower case four digit unicode escape), lone surrogates pass through unchanged. quoteWellFormed(String) implements the ES2019 "well-formed JSON.stringify" extension that also escapes lone surrogates. U+2028 and U+2029 are never escaped. All methods are static and thread-safe.

JSON.stringify 용 JSON 문자열 인용. JavaScript 값과 무관하다. quote(String) 은 ECMAScript 2015 동작이다: 따옴표, 역슬래시, U+0020 미만의 코드 단위만 escape(\b \f \n \r \t 또는 소문자 4자리 유니코드 escape)하고 짝 없는 서로게이트는 그대로 둔다. quoteWellFormed(String) 은 짝 없는 서로게이트도 escape 하는 ES2019 "well-formed JSON.stringify" 확장이다. U+2028, U+2029 는 escape 하지 않는다. 모든 메서드는 정적이며 스레드 안전하다.
