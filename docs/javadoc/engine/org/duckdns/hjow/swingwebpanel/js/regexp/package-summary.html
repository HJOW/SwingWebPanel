Package org.duckdns.hjow.swingwebpanel.js.regexp

ECMAScript regular expression engine written from scratch (parser, compiler and backtracking virtual machine over UTF-16 strings), including named groups, lookbehind, indices and Unicode 13 property escapes.

          Description

Interface Summary
RegExpCancel Cancellation hook polled periodically by the matcher.
 

Class Summary
RegExpCompiler Compiles an ECMAScript regular expression into a RegExpProgram: the pattern is parsed into a syntax tree by RegExpParser and translated to the instruction set interpreted by the backtracking matcher.
RegExpFlags Bit constants and parsing of regular expression flags.
RegExpProgram A compiled ECMAScript regular expression.
 

Exception Summary
RegExpLimitException Thrown while matching when a configured resource limit is exceeded (step budget, backtracking stack) or the match was cancelled.
RegExpSyntaxException Signals that a regular expression pattern or flags string is invalid (an early error).
 

Package org.duckdns.hjow.swingwebpanel.js.regexp Description

ECMAScript regular expression engine written from scratch (parser, compiler and backtracking virtual machine over UTF-16 strings), including named groups, lookbehind, indices and Unicode 13 property escapes.

처음부터 직접 만든 ECMAScript 정규식 엔진(UTF-16 문자열 위의 파서, 컴파일러, 역추적 가상 기계). 이름 있는 그룹, 뒤쪽 탐색, indices, Unicode 13 속성 escape 를 포함한다.
