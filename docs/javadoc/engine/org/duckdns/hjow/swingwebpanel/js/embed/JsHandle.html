Interface JsHandle

All Known Implementing Classes:
JsArrayHandle, JsFunctionHandle, JsObjectHandle
public interface JsHandle

A live reference from Java code to an object of a script, implemented by JsObjectHandle (any object, seen as a Map), JsArrayHandle (an array, seen as a List) and JsFunctionHandle (a function). Reading and writing through a handle reads and writes the script object itself; nothing is copied. All operations lock the engine, so a handle may be used from any thread, but a script that is running on another thread makes the caller wait.

Java 코드에서 스크립트 객체로 가는 살아 있는 참조. JsObjectHandle(모든 객체, Map 으로 보임), JsArrayHandle(배열, List 로 보임), JsFunctionHandle(함수)이 구현한다. 핸들로 읽고 쓰면 스크립트 객체 자체를 읽고 쓰며 아무것도 복사하지 않는다. 모든 연산은 엔진을 잠그므로 핸들은 어느 스레드에서나 쓸 수 있지만, 다른 스레드에서 스크립트가 실행 중이면 호출자가 기다린다.
