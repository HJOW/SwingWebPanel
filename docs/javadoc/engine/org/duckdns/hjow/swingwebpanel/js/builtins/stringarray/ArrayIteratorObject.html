public final class ArrayIteratorObject
extends JsObject

An Array Iterator object (ECMA-262 6th edition 22.1.5): it walks the indexed elements of any array-like object and yields keys, values or [key, value] pairs. Arrays, typed arrays and arguments objects share the same %ArrayIteratorPrototype%.

Array Iterator 객체(ECMA-262 6판 22.1.5): 임의의 유사 배열 객체의 인덱스 요소를 걸으며 키, 값, [키, 값] 쌍을 돌려준다. 배열, 형식화 배열, arguments 객체가 같은 %ArrayIteratorPrototype%을 공유한다.
