public final class JsFunctionHandle
extends JsObjectHandle
implements JsCallable

A live reference to a script function. It is a JsObjectHandle (a function is an object and may have properties) that Java code can call through JsCallable. The engine lock rules and the conversion rules of JsEngine apply to every call.

스크립트 함수에 대한 살아 있는 참조. JsObjectHandle(함수도 객체이며 프로퍼티를 가질 수 있다)이며 Java 코드가 JsCallable 로 호출할 수 있다. 모든 호출에 엔진 잠금 규칙과 JsEngine 의 변환 규칙이 적용된다.
