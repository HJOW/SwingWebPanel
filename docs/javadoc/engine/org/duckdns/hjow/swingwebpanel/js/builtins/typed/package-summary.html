Package org.duckdns.hjow.swingwebpanel.js.builtins.typed Description

ECMAScript 2015 binary data objects: ArrayBuffer, DataView, the abstract %TypedArray% intrinsic and the nine concrete typed array constructors (Int8Array to BigUint64Array). Install them with TypedLibInstaller. Other parts of the library (canvas pixel data, XMLHttpRequest and Fetch bodies, Blob) use the stable Java API of TypedArrays.

ECMAScript 2015 이진 데이터 객체: ArrayBuffer, DataView, 추상 내장 객체 %TypedArray%, 구체적인 형식화 배열 생성자 아홉 개 (Int8Array ~ BigUint64Array). TypedLibInstaller 로 설치한다. 라이브러리의 다른 부분(캔버스 픽셀 데이터, XMLHttpRequest 와 Fetch 본문, Blob)은 TypedArrays 의 안정적인 Java API 를 쓴다.
