Class CodePoints

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.text.CodePoints

public final class CodePoints
extends java.lang.Object

Code point oriented helpers behind String.prototype.codePointAt, String.fromCodePoint, String.fromCharCode and String.raw. JavaScript strings are sequences of UTF-16 code units (lone surrogates are legal), so these helpers never reject lone surrogates unless the specification says so. All methods are static and thread-safe.

String.prototype.codePointAt, String.fromCodePoint, String.fromCharCode, String.raw 의 바탕이 되는 코드 포인트 도우미. JavaScript 문자열은 UTF-16 코드 단위의 나열이며(짝 없는 서로게이트도 허용) 규격이 요구하지 않는 한 짝 없는 서로게이트를 거부하지 않는다. 모든 메서드는 정적이며 스레드 안전하다.
