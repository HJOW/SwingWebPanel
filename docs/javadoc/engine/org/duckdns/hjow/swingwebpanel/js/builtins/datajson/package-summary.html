Package org.duckdns.hjow.swingwebpanel.js.builtins.datajson

JavaScript-visible built-in objects Date, RegExp, JSON, Map, Set, WeakMap and WeakSet (ECMA-262 6th edition sections 20.3, 21.2, 24.3 and 23) built on the standalone libraries of the packages js.date, js.regexp, js.text and js.num.

See:
          Description

Class Summary
DataAccess A small public facade over the internal slots of the built-in Date, RegExp, Map and Set objects, for host code that must read or create them without going through (changeable) script-visible methods: the structured clone algorithm of the HTML Standard uses it.
DataLibInstaller Installs the built-in objects of this package into a realm: Date, RegExp, JSON, Map, Set, WeakMap and WeakSet.
DateBuiltins The built-in Date constructor and Date.prototype (ECMA-262 6th edition 20.3) including the Annex B methods getYear, setYear and toGMTString.
GroupByBuiltins Installs Object.groupBy and Map.groupBy using the common GroupBy operation.
JsonBuiltins The built-in JSON object (ECMA-262 6th edition 24.3): JSON.parse with reviver and JSON.stringify with replacer function, replacer property list, indentation, toJSON, wrapper object unboxing and cycle detection.
RegExpBuiltins The built-in RegExp constructor and RegExp.prototype (ECMA-262 6th edition 21.2) on top of the regular expression engine of the package js.regexp: construction and Annex B compile, exec with the lastIndex protocol of the global and sticky flags, test, toString, the flag accessors, [Symbol.match], [Symbol.replace], [Symbol.search], [Symbol.split] and RegExp[Symbol.species].
