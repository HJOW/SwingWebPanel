Interface ModuleLoader

ModuleLoader.WithAttributes
public interface ModuleLoader

The host hook that resolves and loads modules (HostResolveImportedModule, ECMA-262 6th edition 15.2.1.17). The engine never touches the network or the file system itself: for import x from 'spec' it asks the host to turn the specifier into a unique key and to supply the source text. The same key must always denote the same module.

모듈을 해석하고 불러오는 호스트 연결 지점(HostResolveImportedModule, ECMA-262 6판 15.2.1.17). 엔진은 네트워크나 파일 시스템에 직접 접근하지 않는다. import x from 'spec' 에 대해 호스트에게 지정자를 고유한 키로 바꾸고 소스 텍스트를 달라고 요청한다. 같은 키는 항상 같은 모듈을 가리켜야 한다.
