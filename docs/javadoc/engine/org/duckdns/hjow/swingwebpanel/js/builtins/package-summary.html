Package org.duckdns.hjow.swingwebpanel.js.builtins Description

The standard built-in objects of the JavaScript engine. This package contains the minimal intrinsics the language itself needs (Object, Function, Error types, Symbol, Array basics, iterators and generators, global functions); the complete built-in library is installed by additional installers registered in StandardBuiltins.

JavaScript 엔진의 표준 내장 객체. 이 패키지에는 언어 자체가 필요로 하는 최소 내장 객체(Object, Function, 오류 형식, Symbol, Array 기본, 이터레이터와 제너레이터, 전역 함수)가 있으며, 전체 내장 라이브러리는 StandardBuiltins 에 등록하는 추가 설치기가 설치한다.
