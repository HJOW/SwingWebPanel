Class JsScriptEngineFactory

javax.script.ScriptEngineFactory
public final class JsScriptEngineFactory
extends java.lang.Object
implements javax.script.ScriptEngineFactory

The factory of the Java Scripting API (JSR 223) engine targeting ECMAScript 2026. It is registered in META-INF/services/javax.script.ScriptEngineFactory of the engine jar, so that 

 ScriptEngine engine = new ScriptEngineManager().getEngineByName("swingwebpanel-js");
finds it. Names. The Java runtime itself may already register an engine under the common names: JRE 6 and 7 have Rhino, JRE 8 to 14 have Nashorn (js, JavaScript, javascript, ECMAScript, ecmascript, the extension js, the MIME types application/javascript and so on), and which factory getEngineByName("javascript") returns then depends on the order in which the class path is searched. To make sure that nobody gets this engine by accident (or another engine by accident), this factory registers only its unique identifiers: the names swingwebpanel-js and swingwebpanel-javascript, the extension swjs, the MIME type application/x-swingwebpanel-javascript. A program that wants this engine under the common names (for example on a Java runtime that has no engine of its own, such as Java 15 and later) starts the JVM with -Dswingwebpanel.js.genericNames=true; the common names, the extension js and the common MIME types are then registered as well, and which engine getEngineByName("javascript") returns is up to the search order of the Java runtime. This engine never delegates to Rhino, Nashorn or any other engine.

ECMAScript 2026을 대상으로 하는 Java Scripting API(JSR 223) 엔진의 팩터리. 엔진 JAR 의 META-INF/services/javax.script.ScriptEngineFactory 에 등록되어 있어 위 코드의 getEngineByName("swingwebpanel-js") 가 찾는다. 이름. Java 런타임이 이미 흔한 이름으로 엔진을 등록했을 수 있다. JRE 6, 7 은 Rhino, JRE 8~14 는 Nashorn 이 있고(js, JavaScript, javascript, ECMAScript, ecmascript, 확장자 js, MIME application/javascript 등), 그때 getEngineByName("javascript") 가 어느 팩터리를 돌려주는지는 클래스패스를 찾는 순서에 달려 있다. 아무도 이 엔진을(또는 다른 엔진을) 우연히 얻지 않도록 이 팩터리는 고유한 식별자만 등록한다: 이름 swingwebpanel-js, swingwebpanel-javascript, 확장자 swjs, MIME application/x-swingwebpanel-javascript. 이 엔진을 흔한 이름으로 쓰려는 프로그램(예: 자체 엔진이 없는 Java 15 이상)은 JVM 을 -Dswingwebpanel.js.genericNames=true 로 시작한다. 그러면 흔한 이름, 확장자 js, 흔한 MIME 도 함께 등록되고 getEngineByName("javascript") 가 어느 엔진을 돌려주는지는 Java 런타임의 검색 순서에 달려 있다. 이 엔진은 Rhino, Nashorn 등 다른 엔진에 위임하지 않는다.
