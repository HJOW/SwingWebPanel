Package org.duckdns.hjow.swingwebpanel.js.num

Exact number/string conversions (ECMAScript Number::toString, toFixed, toExponential, toPrecision, StringToNumber, parseInt, parseFloat, ToInt32 ...) on plain Java doubles.

See:
          Description

Class Summary
DecimalDigits The shortest decimal digit string that uniquely identifies a positive finite double, as required by the ECMAScript Number::toString algorithm: value = 0.d1d2...dk * 10^pointPosition where k is as small as possible and, among candidates of that length, the one closest to the value (ties: even last digit) is chosen.
ExactDecimal Exact (correctly rounded, ties-to-even) conversion from arbitrary precision decimal or rational numbers to IEEE-754 double.
Float16 IEEE 754 binary16 conversions from and to binary64, with round-to-nearest, ties-to-even.
NumberConversion ECMAScript 2015 number conversions on plain Java doubles: Number::toString (radix 10 and other radixes), Number.prototype.toFixed / toExponential / toPrecision, StringToNumber, parseInt, parseFloat and the integer conversion abstract operations ToInteger, ToInt32, ToUint32, ToUint16 and ToLength.
PreciseSum Sums binary64 values without intermediate rounding.
 

Exception Summary
NumberRangeException Signals an argument that ECMAScript reports as a RangeError (for example a digit count outside 0..20 in toFixed or a radix outside 2..36 in toString).
