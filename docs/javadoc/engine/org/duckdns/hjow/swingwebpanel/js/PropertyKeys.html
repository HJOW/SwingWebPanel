Class PropertyKeys

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.PropertyKeys

public final class PropertyKeys
extends java.lang.Object

Helpers for property keys. A property key is either a String or a JsSymbol; engine code stores keys as plain Java Object references holding one of those two types.

프로퍼티 키 도우미. 프로퍼티 키는 String 또는 JsSymbol 이며, 엔진 코드는 키를 이 두 형식 중 하나를 담은 Java Object 참조로 저장한다.
