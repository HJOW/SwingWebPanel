org.duckdns.hjow.swingwebpanel.js.builtins.datajson
Class DataAccess

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.builtins.datajson.DataAccess

public final class DataAccess
extends java.lang.Object

A small public facade over the internal slots of the built-in Date, RegExp, Map and Set objects, for host code that must read or create them without going through (changeable) script-visible methods: the structured clone algorithm of the HTML Standard uses it. Every method works on the object itself, never calls a method that a page script may have replaced.

내장 Date, RegExp, Map, Set 객체의 내부 슬롯에 대한 작은 공개 창구. (바뀔 수 있는) 스크립트 공개 메서드를 거치지 않고 읽거나 만들어야 하는 호스트 코드를 위한 것으로, HTML 표준의 구조화 복제 알고리즘이 쓴다. 모든 메서드는 객체 자체에 작용하며 페이지 스크립트가 바꿨을 수 있는 메서드를 호출하지 않는다.
