Class ExactDecimal

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.num.ExactDecimal

public final class ExactDecimal
extends java.lang.Object

Exact (correctly rounded, ties-to-even) conversion from arbitrary precision decimal or rational numbers to IEEE-754 double. It exists because Java 6 Double.parseDouble is known to misround some inputs. All methods are static and thread-safe.

임의 정밀도 10진수 또는 유리수를 IEEE-754 double 로 정확하게(올바른 반올림, 동점이면 짝수) 변환한다. Java 6 의 Double.parseDouble 이 일부 입력을 잘못 반올림하는 것으로 알려져 있어 직접 구현했다. 모든 메서드는 정적이며 스레드 안전하다.
