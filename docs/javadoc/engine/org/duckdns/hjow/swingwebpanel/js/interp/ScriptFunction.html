public final class ScriptFunction
extends JsFunction

A function object created from JavaScript source (an ECMAScript function object, ECMA-262 6th edition 9.2): it keeps the parsed FunctionInfo, the environment it closes over and, for methods, its home object. Normal functions and generator functions receive their prototype property lazily on first access to keep closure creation cheap.

JavaScript 소스로 만든 함수 객체(ECMAScript 함수 객체, ECMA-262 6판 9.2). 파싱된 FunctionInfo, 닫아 둔 환경, 메서드의 홈 객체를 가진다. 일반 함수와 제너레이터 함수는 클로저 생성을 가볍게 하려고 prototype 프로퍼티를 처음 접근할 때 만든다.
