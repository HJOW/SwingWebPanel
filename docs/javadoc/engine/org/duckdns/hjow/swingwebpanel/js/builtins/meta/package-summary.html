Package org.duckdns.hjow.swingwebpanel.js.builtins.meta Description

Built-in objects that work on the object model itself (ECMA-262 6th edition): Proxy, Reflect, Promise and the Annex B global functions escape/unescape. The entry point is MetaLibInstaller.

객체 모델 자체를 다루는 내장 객체(ECMA-262 6판): Proxy, Reflect, Promise 와 부속서 B 의 전역 함수 escape/unescape. 진입점은 MetaLibInstaller 이다.
