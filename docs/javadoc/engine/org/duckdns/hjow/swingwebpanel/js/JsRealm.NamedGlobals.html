org.duckdns.hjow.swingwebpanel.js
Interface JsRealm.NamedGlobals

Enclosing class:
JsRealm
public static interface JsRealm.NamedGlobals

The names that a host gives to the global object besides its properties (the named properties of the Window object of a page: the ids of its elements and the names of some of them). A name is looked up only if the global object and its prototype chain do not have it, so a property that exists (a variable, a function, a built-in) is never hidden, and a script that declares a variable with such a name gets its own property.

호스트가 전역 객체에 프로퍼티 외에 주는 이름(페이지의 Window 객체의 이름 있는 프로퍼티: 요소의 id 와 일부 요소의 name). 전역 객체와 그 프로토타입 체인에 이름이 없을 때만 찾으므로 있는 프로퍼티(변수, 함수, 내장 객체)는 가려지지 않고, 그런 이름으로 변수를 선언하는 스크립트는 자신의 프로퍼티를 얻는다.
