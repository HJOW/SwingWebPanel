Package org.duckdns.hjow.swingwebpanel.js.date

Date arithmetic, parsing and formatting on ECMAScript time values (milliseconds since the epoch as double) with an injectable time zone.

See:
          Description

Class Summary
DateFormatter Date to string conversions of Date.prototype: toString, toDateString, toTimeString, toUTCString, toISOString, toJSON helper and English (en-US) fallbacks for toLocaleString, toLocaleDateString and toLocaleTimeString.
DateMath ECMAScript 2015 date arithmetic (ECMA-262 section 20.3.1) on time values: a double holding milliseconds since 1970-01-01T00:00:00Z, NaN for an invalid date, valid range +-8.64e15.
DateParser Date.parse: converts text to a time value (or NaN).
TimeZoneOffsets Parses the ECMAScript UTCOffset exchange format (21.4.1.33 and Annex A.7).
 

Exception Summary
DateRangeException Signals that ECMAScript reports a RangeError, for example toISOString on an invalid date ("Invalid time value").
