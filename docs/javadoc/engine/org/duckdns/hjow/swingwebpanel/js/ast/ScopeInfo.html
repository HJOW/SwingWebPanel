Class ScopeInfo

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ast.ScopeInfo

public final class ScopeInfo
extends java.lang.Object

The declarations of one scope, computed by the parser (early errors for duplicates are reported there) and used by the interpreter to create bindings on scope entry: hoisted var names, function declarations to initialize (hoisting), and lexical declarations that start in the temporal dead zone.

한 스코프의 선언 정보. 파서가 계산하며(중복에 대한 조기 오류는 파서가 보고) 인터프리터가 스코프 진입 시 바인딩을 만드는 데 쓴다: 끌어올려지는 var 이름, 초기화할 함수 선언(호이스팅), 일시적 사각지대에서 시작하는 렉시컬 선언.
