org.duckdns.hjow.swingwebpanel.js.parser
Class Token

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.parser.Token

public final class Token
extends java.lang.Object

A token with its value and source position. Tokens are plain data holders created by the Lexer. Lines and columns are 1-based; columns count UTF-16 code units.

값과 소스 위치를 가진 토큰. 토큰은 Lexer 가 만드는 단순한 자료 보관 객체이다. 줄과 열은 1부터 시작하며 열은 UTF-16 코드 단위로 센다.
