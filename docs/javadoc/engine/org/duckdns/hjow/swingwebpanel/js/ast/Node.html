org.duckdns.hjow.swingwebpanel.js.ast
Class Node

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.ast.Node

public final class Node
extends java.lang.Object

A syntax tree node. One generic class represents every construct; the meaning of the child fields depends on the NodeType constant in type (see the documentation of each constant). Nodes are created by the parser and read by the interpreter without changes after parsing.

구문 트리 노드. 모든 구문을 하나의 범용 클래스로 나타내며, 자식 필드의 의미는 type 의 NodeType 상수에 따라 달라진다 (각 상수의 설명 참조). 노드는 파서가 만들며, 인터프리터는 파싱이 끝난 노드를 변경하지 않고 읽는다.
