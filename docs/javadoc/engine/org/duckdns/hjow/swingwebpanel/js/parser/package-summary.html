Package org.duckdns.hjow.swingwebpanel.js.parser

Source text analysis of the JavaScript engine: the lexer that turns source text into tokens (identifiers, numbers, strings, templates, regular expression literals, punctuators) and the parser that builds the syntax tree and reports early errors with source positions.

          Description

Interface Summary
RegExpValidator Validates regular expression literal patterns during parsing (ECMA-262 6th edition 12.2.8.1).
 

Class Summary
Lexer The lexical analyzer (ECMA-262 6th edition clause 11).
Lexer.State A snapshot of the lexer position used for backtracking.
Parser The JavaScript parser (ECMA-262 6th edition clauses 12 to 15) with the early errors of the specification: statements, declarations with redeclaration checks, strict mode, labels, break/continue/return validity, automatic semicolon insertion, the Script and Module goals (import/export), eval code and the Function constructor.
Parser.EvalOptions Context of the caller of eval that affects how eval code may be parsed.
Token A token with its value and source position.
 

Enum Summary
TokenType The kinds of tokens produced by the Lexer.
