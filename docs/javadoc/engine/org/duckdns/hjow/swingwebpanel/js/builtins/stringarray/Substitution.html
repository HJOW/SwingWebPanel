GetSubstitution (ECMA-262 6th edition 21.1.3.14.1): expands the replacement patterns $$, $&, $`, $', $n and $nn of a replacement string. It is public so that the RegExp built-in can use the same implementation. Web compatible behavior is used where the specification text is ambiguous: for $nn with a two digit number larger than the number of captures the single digit form $n followed by a literal digit is used when n is a valid capture; references to captures that do not exist are left as written.

GetSubstitution(ECMA-262 6판 21.1.3.14.1): 치환 문자열의 $$, $&, $`, $', $n, $nn 패턴을 전개한다. RegExp 내장 객체가 같은 구현을 쓸 수 있도록 public 이다. 규격 문장이 모호한 곳은 웹 호환 동작을 따른다: 두 자리 $nn 이 캡처 수보다 크면 n 이 유효한 캡처일 때 한 자리 $n 뒤에 숫자 문자가 이어진 것으로 보며, 없는 캡처에 대한 참조는 쓴 그대로 둔다.
