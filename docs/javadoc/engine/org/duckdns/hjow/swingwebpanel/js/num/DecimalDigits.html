Class DecimalDigits

java.lang.Object
  org.duckdns.hjow.swingwebpanel.js.num.DecimalDigits

public final class DecimalDigits
extends java.lang.Object

The shortest decimal digit string that uniquely identifies a positive finite double, as required by the ECMAScript Number::toString algorithm: value = 0.d1d2...dk * 10^pointPosition where k is as small as possible and, among candidates of that length, the one closest to the value (ties: even last digit) is chosen. Computed with exact big integer arithmetic (Burger and Dybvig free-format algorithm); never uses Double.toString, which is not always shortest on Java 6. Instances are immutable.

양의 유한 double 을 유일하게 식별하는 가장 짧은 10진 숫자열. ECMAScript Number::toString 알고리즘이 요구한다: 값 = 0.d1d2...dk * 10^pointPosition 이며 k 는 가능한 한 작고, 같은 길이 후보 중 값에 가장 가까운 것(동점이면 끝자리가 짝수)을 고른다. 정확한 큰 정수 연산(Burger-Dybvig 자유 형식 알고리즘)으로 계산하며 Java 6 에서 항상 최단이 아닌 Double.toString 은 사용하지 않는다. 인스턴스는 불변이다.
