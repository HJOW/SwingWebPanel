Package org.duckdns.hjow.swingwebpanel.desktopapp Description

The Swing web browser application that is built on SwingWebPanel: the entry point (Main) and the state of the whole program (BrowserApp). The application uses only the public types of the component and its protected extension points, never its internal packages. Start it with java -jar swingwebpanel-desktopapp.jar [address].

SwingWebPanel 로 만든 Swing 웹 브라우저 응용 프로그램: 진입점 (Main)과 프로그램 전체의 상태 (BrowserApp). 응용 프로그램은 컴포넌트의 공개 타입과 보호 확장 지점만 쓰고 내부 패키지는 쓰지 않는다. java -jar swingwebpanel-desktopapp.jar [주소] 로 시작한다.
