Class TextFiles

public final class TextFiles
extends java.lang.Object

Reading and writing the UTF-8 text files of the user data (settings, bookmarks, session). A file is written into a temporary file of the same directory first and then put in the place of the old one, so that a failure in the middle leaves the old file as it was. A file that cannot be understood is kept under another name, so that the user can look at it, before the application starts with the defaults.

사용자 데이터(설정, 북마크, 세션)의 UTF-8 텍스트 파일을 읽고 쓰는 일. 파일은 먼저 같은 디렉터리의 임시 파일에 쓴 다음 이전 파일의 자리에 놓으므로, 도중에 실패해도 이전 파일이 그대로 남는다. 해석할 수 없는 파일은 응용 프로그램이 기본값으로 시작하기 전에 사용자가 볼 수 있도록 다른 이름으로 보존한다.

사용 예 / Example: 

 TextFiles.write(new File(dir, "settings.properties"), text);
 String back = TextFiles.read(new File(dir, "settings.properties"));

Writes text into a file as UTF-8: first into a temporary file of the same directory, which then takes the place of the file. The directory is created if it does not exist. If the replacement fails, the old file stays as it was.

텍스트를 UTF-8 로 파일에 쓴다: 먼저 같은 디렉터리의 임시 파일에 쓰고, 그 파일이 원래 파일의 자리를 차지한다. 디렉터리가 없으면 만든다. 교체에 실패하면 이전 파일이 그대로 남는다.
