Class Texts

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.Texts

public final class Texts
extends java.lang.Object

The language of the user interface texts: every text of the application is written in English and in Korean where it is used, and this class picks one. Korean is used when the default locale of the JVM is Korean, English otherwise; the system property swingwebpanel.desktopapp.lang (ko or en) overrides the locale.

사용자 인터페이스 글의 언어: 응용 프로그램의 모든 글은 쓰는 곳에 영어와 한국어로 함께 적고, 이 클래스가 하나를 고른다. JVM 의 기본 로캘이 한국어이면 한국어를, 아니면 영어를 쓴다. 시스템 속성 swingwebpanel.desktopapp.lang(ko 또는 en)이 로캘보다 우선한다.

사용 예 / Example: 

 button.setToolTipText(Texts.of("Back", "뒤로"));
