org.duckdns.hjow.swingwebpanel.desktopapp.model
Class Settings

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.Settings

public final class Settings
extends java.lang.Object

The settings of the browser application: named text values with defaults, shared by all windows of the process. A change is announced to the listeners, which apply it to the open windows. The values are plain strings so that they can be stored in a text file; the typed methods convert them and fall back to the default when a stored value cannot be understood.

브라우저 응용 프로그램의 설정: 기본값이 있는 이름 붙은 텍스트 값이며 프로세스의 모든 창이 공유한다. 변경은 리스너에 알리고, 리스너가 열린 창에 적용한다. 값은 텍스트 파일에 저장할 수 있도록 보통 문자열이다. 형식이 있는 메서드가 값을 변환하며, 저장된 값을 이해할 수 없으면 기본값을 쓴다.

사용 예 / Example: 

 Settings s = new Settings();
 s.set(Settings.HOME_PAGE, "https://example.com/");
 String home = s.get(Settings.HOME_PAGE);
