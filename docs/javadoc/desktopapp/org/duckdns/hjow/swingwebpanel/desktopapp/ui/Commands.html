org.duckdns.hjow.swingwebpanel.desktopapp.ui
Class Commands

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.ui.Commands

public final class Commands
extends java.lang.Object

The names of the commands of a browser window (plan item P31-05). Menu items, key bindings and tests all run a command through BrowserWindow.perform(String) with one of these names; a menu item also carries the name as its component name, so that a test can find it.

브라우저 창의 명령 이름(계획 P31-05). 메뉴 항목, 키 바인딩, 시험이 모두 이 이름 가운데 하나로 BrowserWindow.perform(String) 을 불러 명령을 실행한다. 메뉴 항목은 이 이름을 컴포넌트 이름으로도 가지므로 시험이 항목을 찾을 수 있다.

사용 예 / Example: 

 window.perform(Commands.NEW_TAB);
