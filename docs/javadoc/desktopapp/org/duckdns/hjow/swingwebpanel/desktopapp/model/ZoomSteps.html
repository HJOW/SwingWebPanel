org.duckdns.hjow.swingwebpanel.desktopapp.model
Class ZoomSteps

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.ZoomSteps

public final class ZoomSteps
extends java.lang.Object

The zoom factors that the zoom commands of the browser step through (plan item P31-05). They are the same steps that the component itself uses for Ctrl+plus and Ctrl+minus, so that a menu command and a key pressed inside the page give the same result.

브라우저의 확대 명령이 거치는 확대 배율(계획 P31-05). 컴포넌트가 Ctrl+플러스와 Ctrl+마이너스에 쓰는 단계와 같으므로, 메뉴 명령과 페이지 안에서 누른 키가 같은 결과를 낸다.

사용 예 / Example: 

 panel.setZoom(ZoomSteps.larger(panel.getZoom()));
