Class SettingsStore

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.SettingsStore

public final class SettingsStore
extends java.lang.Object

The file of the settings (plan item P31-07): settings.properties in the directory of the user data, UTF-8 text in the format of java.util.Properties with one key=value per line, written in a fixed order. The line settings.version=1 names the format. A missing file means the defaults; a file that cannot be read as properties, or that lacks the version line, is kept as settings.properties.broken and the application starts with the defaults. Keys that this version does not know are ignored; a value that cannot be understood falls back to its default when it is used.

설정의 파일(계획 P31-07): 사용자 데이터 디렉터리의 settings.properties. java.util.Properties 형식의 UTF-8 텍스트이며 한 줄에 키=값 하나를 정해진 순서로 쓴다. settings.version=1 줄이 형식의 이름이다. 파일이 없으면 기본값이고, 속성 형식으로 읽을 수 없거나 판 줄이 없는 파일은 settings.properties.broken 으로 보존한 뒤 기본값으로 시작한다. 이 판이 모르는 키는 무시하고, 이해할 수 없는 값은 쓸 때 기본값으로 돌아간다.

사용 예 / Example: 

 SettingsStore store = new SettingsStore(BrowserApp.homeDirectory());
 store.load(settings);
 store.save(settings);

Reads the file into settings. A missing file leaves the settings as they are. A file that cannot be used is kept under the name settings.properties.broken and the settings are left as they are.
