Class PageFiles

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.PageFiles

public final class PageFiles
extends java.lang.Object

Saving the received text of a page into a file (plan item P31-05): the name that is suggested to the user and the bytes that are written. The text is written as UTF-8. HTML and XHTML start with a byte order mark, because the text may declare another character set (the one it arrived in) and the mark takes precedence over that declaration when the file is opened again.

페이지의 수신 원문을 파일에 저장하는 일(계획 P31-05): 사용자에게 제안하는 이름과 쓰는 바이트. 원문은 UTF-8 로 쓴다. HTML 과 XHTML 은 바이트 순서 표시로 시작한다. 원문이 다른 문자셋(도착했을 때의 문자셋)을 선언하고 있을 수 있는데, 파일을 다시 열 때 이 표시가 그 선언보다 우선하기 때문이다.

사용 예 / Example: 

 String name = PageFiles.suggestName(panel.getPage(), panel.getMimeType());
 PageFiles.write(new File(dir, name), panel.getContent(), panel.getMimeType());
