Class BookmarkNode

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.BookmarkNode

public final class BookmarkNode
extends java.lang.Object

One entry of the bookmarks (plan item P31-06): a bookmark with a name and an address, or a folder with a name and entries inside it. An entry is created with bookmark(String, String) or folder(String) and then put into a BookmarkModel; after that only the model changes it, so that every change is announced to the listeners of the model.

북마크의 항목 하나(계획 P31-06): 이름과 주소가 있는 북마크, 또는 이름과 그 안의 항목들이 있는 폴더. 항목은 bookmark(String, String) 이나 folder(String) 로 만든 뒤 BookmarkModel 에 넣는다. 그 뒤에는 모델만 항목을 바꾸므로 모든 변경이 모델의 리스너에 알려진다.

사용 예 / Example: 

 BookmarkNode news = BookmarkNode.folder("News");
 model.add(model.getRoot(), news);
 model.add(news, BookmarkNode.bookmark("Example", "https://example.com/"));
