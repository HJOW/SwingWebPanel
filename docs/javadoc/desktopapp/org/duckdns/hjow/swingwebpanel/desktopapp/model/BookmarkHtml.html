Class BookmarkHtml

public final class BookmarkHtml
extends java.lang.Object

Bookmarks in the Netscape bookmark file format, the HTML file that browsers write and read to exchange bookmarks (plan item P31-06). Exporting writes the names and addresses with their special characters escaped. Importing reads the file as text: it looks for the folder headings (H3), the links (A with HREF) and the lists (DL) and takes nothing else from the file; the file is never shown as a page and nothing in it is run.

Netscape 북마크 파일 형식의 북마크. 브라우저들이 북마크를 주고받으려고 쓰고 읽는 HTML 파일이다(계획 P31-06). 내보내기는 이름과 주소의 특수 문자를 이스케이프하여 쓴다. 가져오기는 파일을 텍스트로 읽는다: 폴더 제목(H3), 링크(HREF 가 있는 A), 목록 (DL)을 찾고 그 밖의 것은 파일에서 가져오지 않는다. 파일을 페이지로 보이는 일은 없고 그 안의 어떤 것도 실행하지 않는다.

사용 예 / Example: 

 String html = BookmarkHtml.export(model.getRoot());
 BookmarkNode imported = BookmarkHtml.parse(html);
 model.addAll(model.getRoot(), imported);
