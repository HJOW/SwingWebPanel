org.duckdns.hjow.swingwebpanel.desktopapp.ui
Class BrowserTab

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.ui.BrowserTab

public final class BrowserTab
extends java.lang.Object

One page of the browser: a SwingWebPanel in a scroll pane together with what the window needs to know about it (plan items P31-03 and P31-04). A window shows the state of its active tab in the title bar, the navigation toolbar and the status bar; the tab tells its listener whenever that state changes. Use it on the event dispatch thread.

브라우저의 페이지 하나: 스크롤 창 안의 SwingWebPanel 과, 창이 그 페이지에 대해 알아야 하는 것들(계획 P31-03, P31-04). 창은 활성 탭의 상태를 제목 표시줄, 탐색 도구 모음, 상태 표시줄에 보인다. 탭은 그 상태가 바뀔 때마다 리스너에 알린다. 이벤트 디스패치 스레드에서 쓴다.
