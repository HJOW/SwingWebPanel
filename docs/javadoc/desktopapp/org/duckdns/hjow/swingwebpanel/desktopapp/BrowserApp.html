org.duckdns.hjow.swingwebpanel.desktopapp
Class BrowserApp

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.BrowserApp

public final class BrowserApp
extends java.lang.Object

The state of the whole browser program: the settings, the cookie jar that all tabs share, the open browser windows and what happens when the last one is closed. One instance exists per process. Create it and call its methods on the event dispatch thread.

브라우저 프로그램 전체의 상태: 설정, 모든 탭이 공유하는 쿠키 저장소, 열린 브라우저 창들, 마지막 창이 닫힐 때 일어나는 일. 프로세스에 인스턴스가 하나 있다. 이벤트 디스패치 스레드에서 만들고 그 메서드를 부른다.

사용 예 / Example: 

 BrowserApp app = new BrowserApp(null);          // null: end the JVM when the last window closes
 app.openWindow("https://example.com/").setVisible(true);

start

public java.util.List<BrowserWindow> start(java.lang.String url)
Opens the windows that the program starts with. An address given by the caller (the command line) is opened in one window. Otherwise the setting for the start decides: the home page, the empty page, or the windows and tabs of the last run (the home page if there is nothing to restore). The windows are created but not shown.

프로그램이 시작할 때의 창을 연다. 호출자(명령행)가 준 주소가 있으면 창 하나에 그 주소를 연다. 없으면 시작에 관한 설정이 정한다: 홈 페이지, 빈 페이지, 또는 지난번의 창과 탭(복원할 것이 없으면 홈 페이지). 창은 만들기만 하고 보이지는 않는다.

Parameters:
url - the address from the command line, or null / 명령행의 주소. 없으면 null
Returns:
the windows, at least one / 창들. 하나 이상이다

saveSession

public void saveSession()
Remembers the open windows and their tabs as the last session, for the setting that restores them at the next start. It is called before the windows are closed at the end of the program.

열린 창과 그 탭을 지난 세션으로 기억한다. 다음에 시작할 때 복원하는 설정이 쓴다. 프로그램이 끝날 때 창을 닫기 전에 호출된다.

exit

public boolean exit()
Closes all windows as the user asks for it, the newest first; each window may ask before it closes, and a refusal stops the exit. Closing the last window ends the program.

사용자가 요청한 대로 모든 창을 최근 것부터 닫는다. 창마다 닫기 전에 물을 수 있고, 거절하면 종료를 그만둔다. 마지막 창이 닫히면 프로그램이 끝난다.

Returns:
true if every window was closed / 모든 창을 닫았으면 true

lastWindowClosing

public void lastWindowClosing()
Called by the last open window before it closes as the user asked: its tabs become the last session, unless the program is already ending through exit(), which remembered all windows.

마지막으로 열린 창이 사용자의 요청으로 닫히기 전에 부른다: 그 창의 탭이 지난 세션이 된다. 단, 모든 창을 기억해 둔 exit() 로 프로그램이 이미 끝나는 중이면 그대로 둔다.
