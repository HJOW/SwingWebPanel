Class BookmarkStore

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.BookmarkStore

public final class BookmarkStore
extends java.lang.Object

The file of the bookmarks (plan item P31-06): bookmarks.txt in the directory of the user data, UTF-8 text with one entry per line. The first line names the format. An entry line has fields separated by tabs: the kind (F for a folder, B for a bookmark), the depth (0 for the entries of the root), the name and, for a bookmark, the address. Inside a field a tab is written as \t, a line feed as \n, a carriage return as \r and a backslash as \\. A missing file means no bookmarks; a file that cannot be understood is kept as bookmarks.txt.broken and the application starts without bookmarks.

북마크의 파일(계획 P31-06): 사용자 데이터 디렉터리의 bookmarks.txt. 한 줄에 항목 하나인 UTF-8 텍스트이다. 첫 줄은 형식의 이름이다. 항목 줄은 탭으로 구분한 필드를 가진다: 종류(폴더는 F, 북마크는 B), 깊이(루트의 항목이 0), 이름, 그리고 북마크이면 주소. 필드 안에서 탭은 \t, 줄 바꿈은 \n, 캐리지 리턴은 \r, 역슬래시는 \\ 로 적는다. 파일이 없으면 북마크가 없는 것이고, 해석할 수 없는 파일은 bookmarks.txt.broken 으로 보존한 뒤 북마크 없이 시작한다.

사용 예 / Example: 

 BookmarkStore store = new BookmarkStore(BrowserApp.homeDirectory());
 store.load(model);
 store.save(model);
