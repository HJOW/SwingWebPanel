Class SessionStore

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.SessionStore

public final class SessionStore
extends java.lang.Object

The file of the last session (plan item P31-07): session.txt in the directory of the user data holds the addresses of the tabs of the windows that were open when the program ended, for the setting that restores them at the next start. The first line names the format; then each window is a line W with the position of its active tab, followed by one line T and an address per tab (fields separated by a tab character). Only addresses are kept: the history and the content of forms are not restored. A missing or broken file means that there is nothing to restore.

지난 세션의 파일(계획 P31-07): 사용자 데이터 디렉터리의 session.txt 는 프로그램이 끝날 때 열려 있던 창의 탭 주소를 담는다. 다음에 시작할 때 그것을 복원하는 설정이 쓴다. 첫 줄은 형식의 이름이고, 그 뒤에 창마다 활성 탭의 위치가 붙은 W 줄이 오고 탭마다 T 와 주소가 있는 줄이 이어진다(필드는 탭 문자로 구분한다). 주소만 보관하므로 이력과 폼의 내용은 복원되지 않는다. 파일이 없거나 손상되었으면 복원할 것이 없는 것이다.

사용 예 / Example: 

 SessionStore store = new SessionStore(BrowserApp.homeDirectory());
 store.save(windows);
 List<SessionStore.Window> last = store.load();
