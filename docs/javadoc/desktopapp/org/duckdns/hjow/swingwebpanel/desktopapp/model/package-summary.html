Package org.duckdns.hjow.swingwebpanel.desktopapp.model Description

The model and control layer of the browser application: what the program knows and decides without a window (how typed text becomes an address, the settings, the bookmarks). Nothing here depends on Swing windows, so it is tested in a headless JVM.

브라우저 응용 프로그램의 모델/제어 계층: 창 없이 프로그램이 알고 판단하는 것들(입력한 글이 주소가 되는 방법, 설정, 북마크). 여기 있는 것은 Swing 창에 의존하지 않으므로 headless JVM 에서 시험한다.
