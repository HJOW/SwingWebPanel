org.duckdns.hjow.swingwebpanel.desktopapp.model
Class BookmarkModel

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.BookmarkModel

public final class BookmarkModel
extends java.lang.Object

The bookmarks of the browser application (plan item P31-06): a tree of folders and bookmarks under one root folder. One model exists per process and all windows share it, so a change made in one window is seen in the others at once; every change is announced to the listeners. Use it on the event dispatch thread.

브라우저 응용 프로그램의 북마크(계획 P31-06): 루트 폴더 하나 아래의 폴더와 북마크의 트리. 프로세스에 모델이 하나 있고 모든 창이 공유하므로, 한 창에서 한 변경이 다른 창에 바로 보인다. 모든 변경은 리스너에 알린다. 이벤트 디스패치 스레드에서 쓴다.

사용 예 / Example: 

 BookmarkModel model = new BookmarkModel();
 model.add(model.getRoot(), BookmarkNode.bookmark("Example", "https://example.com/"));
 boolean known = model.contains("https://example.com/");
