Class AddressInput

java.lang.Object
  org.duckdns.hjow.swingwebpanel.desktopapp.model.AddressInput

public final class AddressInput
extends java.lang.Object

Turns what the user typed into the address bar into an absolute address that the component can load (plan item P31-03). The rules, in this order:

  1. Empty input gives nothing.
  2. A local file path (a Windows drive path, a UNC path, or an existing absolute path) becomes a file: address.
  3. Input with a scheme is used as it is. The component itself decides whether the scheme is allowed and shows its error page for a blocked one. host:port is not a scheme.
  4. Text that looks like a search (it has white space, or it is one word without a dot that is not localhost) goes to the search address template of the settings, with %s replaced by the encoded text. Without a template, one word is treated as a host name and text with white space cannot be opened.
  5. Everything else is a host or an address without scheme and gets https:// in front (the component retries with HTTP when the secure connection fails).

사용자가 주소 표시줄에 입력한 것을 컴포넌트가 읽을 수 있는 절대 주소로 바꾼다(계획 P31-03). 규칙은 이 순서대로이다:

  1. 빈 입력은 아무것도 주지 않는다.
  2. 로컬 파일 경로(Windows 드라이브 경로, UNC 경로, 존재하는 절대 경로)는 file: 주소가 된다.
  3. 스킴이 있는 입력은 그대로 쓴다. 스킴을 허용할지는 컴포넌트가 판정하고 차단된 스킴에는 컴포넌트의 오류 화면이 보인다. 호스트:포트 는 스킴이 아니다.
  4. 검색처럼 보이는 글(공백이 있거나, 점이 없는 한 낱말이면서 localhost 가 아닌 것)은 설정의 검색 주소 서식으로 간다. 서식의 %s 를 인코딩한 글로 바꾼다. 서식이 없으면 한 낱말은 호스트 이름으로 보고, 공백이 있는 글은 열 수 없다.
  5. 그 밖의 것은 스킴 없는 호스트나 주소이며 앞에 https:// 를 붙인다(보안 연결이 실패하면 컴포넌트가 HTTP 로 다시 시도한다).

사용 예 / Example: 

 AddressInput.Result r = AddressInput.resolve("example.com/a b", "");
 if (r.getUrl() != null) { panel.setPage(r.getUrl()); }      // https://example.com/a b
