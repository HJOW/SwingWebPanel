Package org.duckdns.hjow.swingwebpanel.desktopapp.ui Description

The Swing parts of the browser application: the browser window and what it shows. They run on the event dispatch thread and talk to the pages only through the public methods of SwingWebPanel.

브라우저 응용 프로그램의 Swing 부품: 브라우저 창과 그 안에 보이는 것들. 이벤트 디스패치 스레드에서 동작하며 페이지와는 SwingWebPanel 의 공개 메서드로만 이야기한다.
